> **CRITICAL NOTE:** LEAP 2025 Mathematics uses **Louisiana Student Standards for Mathematics**, which are aligned to CCSS Mathematics. Standard codes follow the CCSS format (e.g., 5.NBT.5, 8.EE.7). Grade 11 testing covers high school course standards (Algebra I, Geometry, or Algebra II).

### Performance Levels

| Level | Label              | Description                                                                  |
|-------|--------------------|------------------------------------------------------------------------------|
| 1     | Unsatisfactory     | Student has not yet met grade-level expectations; major gaps in understanding|
| 2     | Approaching Basic  | Student is approaching basic mastery of grade-level content                  |
| 3     | Basic              | Student demonstrates basic mastery of knowledge and skills                  |
| 4     | Mastery            | Student has met grade-level expectations (proficient)                       |
| 5     | Advanced           | Student has exceeded grade-level expectations; advanced problem solving      |

> **Proficiency Target:** Level 4 (Mastery) is the proficiency target in Louisiana.

## 3. TEST STRUCTURE

LEAP 2025 Mathematics is administered in **multiple sessions** over two or more days.

```
+------------------------------------------------------------------+
|          LEAP 2025 MATHEMATICS STRUCTURE (Grades 3–8, 11)        |
+------------------------------------------------------------------+
|  SESSION 1 — No Calculator                                       |
|  ~60 minutes                                                      |
|                                                                   |
|  MC items (1 pt)                                                  |
|  Multi-Select items (1 pt)                                        |
|  Equation items (1 pt)                                            |
|  Short CR (0–2 pt)                                                |
+------------------------------------------------------------------+
|  SESSION 2 — Calculator Allowed (Grades 6–8, 11)                 |
|  ~60 minutes                                                      |
|                                                                   |
|  MC items (1 pt)                                                  |
|  Multi-Select items (1 pt)                                        |
|  Equation items (1 pt)                                            |
|  Short CR (0–2 pt)                                                |
|  Extended CR (0–4 pt) — multi-part problem with explanation      |
+------------------------------------------------------------------+
|  SESSION 3 (Grades 6–8, 11 only) — Calculator Allowed           |
|  ~60 minutes                                                      |
|                                                                   |
|  MC items (1 pt)                                                  |
|  Extended CR (0–4 pt) — multi-part with justification            |
+------------------------------------------------------------------+
```

### Session Item Counts by Grade Band

| Session       | Grades 3–5                       | Grades 6–8                       | Grade 11                         |
|---------------|----------------------------------|----------------------------------|----------------------------------|
| Session 1     | 18–22 MC/MS/EQ + 1–2 Short CR   | 14–18 MC/MS/EQ + 1–2 Short CR   | 14–18 MC/MS/EQ + 1–2 Short CR   |
| Session 2     | 14–18 MC/MS/EQ + 1–2 Short CR   | 14–18 MC/MS/EQ + 1–2 Ext CR     | 14–18 MC/MS/EQ + 1–2 Ext CR     |
| Session 3     | —                                | 10–14 MC + 1–2 Ext CR           | 10–14 MC + 1–2 Ext CR           |

> **Calculator Policy:** Grades 3–5 have no calculator for any session. Grades 6–8 and 11 have a no-calculator session (Session 1) and calculator-permitted sessions (Sessions 2–3). An online graphing calculator is available for Grade 11.

## 5. ITEM TYPES

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Single correct answer                                   |
|  Machine scored                                          |
|  All sessions                                            |
|  DOK 1–2                                                 |
+----------------------------------------------------------+
```

**MC Example (Grade 6, DOK 2, 6.RP.3 — Ratios):**

The Mississippi River flows at an average rate of 3 miles per hour near Baton Rouge, Louisiana. At this rate, how far does the water travel in 8 hours?

- A. 11 miles
- B. 16 miles
- C. 24 miles
- D. 32 miles

*Correct Answer: C (3 x 8 = 24)*
*Alignment: 6.RP.3b | DOK 2*

---

### Multi-Select (MS)

```
+----------------------------------------------------------+
|  MULTI-SELECT — 1 point (all-or-nothing)                 |
|                                                          |
|  5–6 options                                             |
|  Student selects ALL correct answers (typically 2)       |
|  Machine scored; no partial credit                       |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**MS Example (Grade 7, DOK 2, 7.EE.4 — Equations):**

Which TWO equations could be used to find the number of barrels of oil (b) produced if a Louisiana oil well produces 150 barrels per day for d days?

- A. b = 150 + d
- B. b = 150d
- C. d = 150b
- D. b = d / 150
- E. 150d = b

*Correct Answers: B and E*

---

### Equation Entry (EQ)

```
+----------------------------------------------------------+
|  EQUATION ENTRY — 1 point                                |
|                                                          |
|  Student types a numeric answer or expression            |
|  No partial credit                                       |
|  Machine scored                                          |
|  Accepts equivalent forms (e.g., 1/2 = 0.5)             |
|  All sessions                                            |
+----------------------------------------------------------+
```

**EQ Example (Grade 5, DOK 2, 5.NF.2 — Fraction Addition):**

*"A Louisiana farmer harvested 3/8 ton of sugar cane from one field and 5/8 ton from another field. What is the total weight, in tons, of sugar cane harvested?"*

*Answer: 1 (or 8/8 or equivalent)*

---

### Short Constructed Response (Short CR)

```
+----------------------------------------------------------+
|  SHORT CONSTRUCTED RESPONSE — 0–2 points                 |
|                                                          |
|  Brief numeric answer with work shown                    |
|  1–3 step solution                                       |
|  Human scored                                            |
|  DOK 2                                                   |
+----------------------------------------------------------+
```

**Short CR Example (Grade 4, DOK 2, 4.NBT.5):**

*"A sugar cane processing plant in Louisiana processes 1,250 pounds of sugar cane each hour. How many pounds of sugar cane does the plant process in 6 hours? Show your work."*

---

### Extended Constructed Response (Extended CR)

```
+----------------------------------------------------------+
|  EXTENDED CONSTRUCTED RESPONSE — 0–4 points              |
|                                                          |
|  Multi-part problem (Parts A, B, C)                      |
|  Requires showing work AND written explanation           |
|  DOK 2–3                                                 |
|  Human scored using CR rubric                            |
|  Sessions 2–3 (calculator allowed for Gr 6–8, 11)       |
+----------------------------------------------------------+
```

**Extended CR Example (Grade 8, DOK 3, 8.F.4 + 8.SP.1):**

*The table below shows the average elevation (in feet below sea level) at different locations in New Orleans.*

| Location          | Elevation (ft) |
|-------------------|----------------|
| French Quarter    | −2             |
| Mid-City          | −5             |
| Lakeview          | −8             |
| New Orleans East  | −4             |
| Gentilly          | −6             |

*Part A: What is the mean elevation of these five locations? Show your work.*

*Part B: A new neighborhood is planned at an elevation of −3 feet. If this location is added to the data set, how does the mean change? Show your work.*

*Part C: Explain what a negative elevation means in the context of New Orleans geography and why this information is important for city planning.*

## 7. MATHEMATICAL PRACTICES AND REASONING

### Standards for Mathematical Practice (SMP) on LEAP 2025

LEAP 2025 Mathematics assesses the CCSS Standards for Mathematical Practice through item design, particularly in constructed response items.

| SMP   | Practice                                          | How It Appears on LEAP 2025                                          |
|-------|---------------------------------------------------|----------------------------------------------------------------------|
| MP.1  | Make sense of problems; persevere                 | Multi-step CR items that require entry point identification          |
| MP.2  | Reason abstractly and quantitatively              | Items requiring translation between context and math                 |
| MP.3  | Construct arguments; critique reasoning           | CR items asking "Explain why" or "Is the student correct? Justify"  |
| MP.4  | Model with mathematics                            | Louisiana-context word problems; data interpretation                 |
| MP.5  | Use appropriate tools strategically               | Calculator/no-calculator section design                              |
| MP.6  | Attend to precision                               | Exact answers; appropriate units; precise vocabulary in explanations  |
| MP.7  | Look for and make use of structure                | Pattern items; equivalent expression identification                  |
| MP.8  | Express regularity in repeated reasoning          | Function rule items; generalization in context                       |

> **MP.3 and MP.4 are the most visible on LEAP 2025 Mathematics.** Extended CR items frequently require students to justify reasoning (MP.3) and apply math to real-world Louisiana contexts (MP.4).

## 8. SCORING RUBRICS

### Extended Constructed Response (Extended CR) Rubric — 0–4 Points

| Score | Criteria                                                                                                                                                                                            |
|-------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 4     | All parts of the problem are correctly and completely addressed. Mathematical work is fully shown, clearly organized, and leads to correct answers. Written explanations are mathematically precise, use accurate vocabulary, and address the context. Units and labels are correct throughout. |
| 3     | Most parts of the problem are correctly addressed. Mathematical work is mostly complete and leads to mostly correct answers. A minor computational error may be present but the approach is sound. Written explanations demonstrate adequate mathematical understanding. |
| 2     | Some parts of the problem are correctly addressed. Mathematical work is partially complete or contains procedural errors. Student demonstrates partial understanding of the mathematical concepts. Written explanations are present but may be incomplete or imprecise. |
| 1     | Little correct mathematical work is shown. Student demonstrates minimal understanding of the mathematical task. Significant errors are present across most parts. Written explanations are absent or demonstrate confusion about the concept. |
| 0     | No correct mathematical work is shown. Response is blank, off-task, or demonstrates no understanding of the mathematical task.                                                                      |

### Short Constructed Response (Short CR) Rubric — 0–2 Points

| Score | Criteria                                                                                   |
|-------|--------------------------------------------------------------------------------------------|
| 2     | Correct answer with complete work shown; solution process is clear and logical             |
| 1     | Partially correct answer or correct approach with computational error; some work shown     |
| 0     | Incorrect answer with no valid work; blank; or demonstrates no understanding               |

## 10. CONTEXTUALIZATION — LOUISIANA MATH

When generating real-world math contexts, prioritize authentic Louisiana settings:

### Recommended Math Contexts

| Context                                    | Grade Band | Math Domains                                          |
|--------------------------------------------|------------|-------------------------------------------------------|
| Mississippi River flow rate data           | 5–8        | Ratios, proportional reasoning, unit rates, functions |
| New Orleans elevation data (below sea level)| 4–8       | Negative numbers, integers, mean/median, data analysis|
| Louisiana petroleum production statistics  | 6–11       | Large numbers, ratios, percents, data analysis        |
| Sugar cane harvest quantities              | 3–6        | Multiplication, fractions, measurement                |
| Louisiana population data by parish        | 5–8        | Ratios, percents, data analysis, statistics           |
| Mardi Gras parade route distances          | 4–7        | Measurement, fractions, unit conversion               |
| Gulf Coast fishing catch data              | 5–8        | Ratios, data analysis, statistics                     |
| Louisiana bayou water level measurements   | 5–8        | Negative numbers, data analysis, rates of change      |
| New Orleans streetcar route scheduling     | 6–8        | Rates, unit rates, linear functions                   |
| Louisiana coastal land loss rates          | 7–11       | Rates of change, linear functions, statistics         |

### Sample Context Sentence Starters

- "The Mississippi River flows past Baton Rouge at an average rate of [X] cubic feet per second..."
- "A sugar cane farmer in Iberia Parish harvested [X] tons of sugar cane from [Y] acres..."
- "The table below shows the elevation of different neighborhoods in New Orleans..."
- "Louisiana produces approximately [X] barrels of crude oil per day..."
- "During Mardi Gras, a parade route in New Orleans covers [X] miles through the city..."
- "A shrimp boat in the Gulf of Mexico caught [X] pounds of shrimp in [Y] hours..."

## 11. QUALITY CHECKLIST

- [ ] Standard code uses CCSS format (e.g., 6.RP.3, 8.F.4)
- [ ] SMP alignment identified for CR items
- [ ] Calculator policy matches session (no calculator Session 1; calc allowed Sessions 2–3 for Gr 6–8, 11)
- [ ] Extended CR items have at least two parts (Part A and Part B minimum)
- [ ] Part C of Extended CR includes explanation/justification component
- [ ] Equation Entry accepts all equivalent forms
- [ ] Multi-Select has exactly 2 correct answers from 5–6 options
- [ ] Real-world context is Louisiana-specific and grade-appropriate
- [ ] All numerical values produce clean, non-ambiguous answers
- [ ] Distractors reflect specific, identifiable student error types
- [ ] DOK level verified against actual cognitive demand
- [ ] Grade 11 items specify course (Algebra I, Geometry, or Algebra II)

### Common Pitfalls

| Pitfall                                    | Problem                                                   | Fix                                                          |
|--------------------------------------------|-----------------------------------------------------------|--------------------------------------------------------------|
| Calculator on Session 1                    | Session 1 is no-calculator for all grades                 | Design Session 1 items to not require calculator             |
| No calculator for Grades 3–5 any session   | No calculator allowed at all for Grades 3–5               | All Gr 3–5 items must be solvable without calculator         |
| Extended CR with only one part             | LEAP 2025 CR requires multi-part structure                | Minimum Part A and Part B; Part C for DOK 3                  |
| EQ with ambiguous decimal/fraction         | System may not accept all equivalent forms                | List all accepted forms; test in platform                    |
| Generic context (no LA specificity)        | Louisiana test values authentic LA contexts               | Use Mississippi River, bayous, sugar cane, petroleum, etc.   |
| CR explanation prompt missing              | DOK 3 requires written justification                      | Include "Explain what this means in context"                 |
| Confusing Mastery (L4) with Basic (L3)     | Mastery is proficiency target, not Basic                  | Target item difficulty to Mastery-level performance          |
| Grade 11 items without course specification| Grade 11 tests Algebra I, Geometry, or Algebra II         | Always specify which course the item targets                 |

## 12. PROMPT PATTERNS

The following patterns reflect the most common LEAP 2025 Mathematics item structures.

### Pattern 1: Contextual Computation (MC, DOK 2)
> "[Louisiana setting]. [Given information]. [Mathematical question requiring multi-step application]."
> (Options: correct answer + three specific error-type distractors)

### Pattern 2: Multi-Step Context (Extended CR Part A, DOK 2)
> "A [Louisiana context] has [given data]. [Part A: computational task requiring setup + solve]. Show your work."

### Pattern 3: Rate of Change in Context (Extended CR Part C, DOK 3)
> "Your equation has a [slope/rate/coefficient] of [value]. Explain what this number means in the context of [Louisiana scenario]."

### Pattern 4: Error Analysis (MC or CR, DOK 3)
> "[Student name] solved the problem and wrote [incorrect answer/work]. What error did [student] make? Find and show the correct answer."

### Pattern 5: Comparison with Justification (Extended CR, DOK 3)
> "Two [Louisiana scenarios] are described: [Scenario A data] and [Scenario B data]. Which [option] is [more efficient/greater/better value]? Use mathematical evidence to justify your answer."

### Pattern 6: Data Interpretation (MC/MS, DOK 2)
> "The table/graph below shows [Louisiana data set]. Based on the data, which [conclusion/statement/value] is correct?"
