> **CRITICAL NOTE:** LEAP 2025 Science uses the **Louisiana Student Standards for Science**, which are Louisiana-specific science standards. Do NOT use NGSS PE codes (e.g., 5-LS2-1) for Louisiana items — use Louisiana Science Standard codes.

> **GRADE NOTE:** LEAP 2025 Science tests only **Grade 5, Grade 8, and Grade 11** (Biology I or high school science). Do not generate items for Grades 3, 4, 6, or 7.

## 2. STANDARDS FRAMEWORK

### Louisiana Student Standards for Science

Louisiana adopted its own science standards in 2017. The standards are organized around **Disciplinary Core Ideas (DCIs)**, **Science and Engineering Practices (SEPs)**, and **Crosscutting Concepts (CCCs)** — a three-dimensional framework similar in structure to NGSS but with Louisiana-specific content and coding.

Standard code format: **[Grade]-[Domain]-[Standard Number]**

### Three-Dimensional Assessment

LEAP 2025 Science items assess students across three dimensions simultaneously:

| Dimension                        | Description                                                      | How Assessed                                   |
|----------------------------------|------------------------------------------------------------------|-------------------------------------------------|
| Disciplinary Core Ideas (DCIs)   | Content knowledge in PS, LS, ESS                                | The "what" — science content of the item       |
| Science and Engineering Practices (SEPs) | Skills such as modeling, analyzing data, constructing explanations | The "how" — what students do with the content  |
| Crosscutting Concepts (CCCs)     | Patterns, cause and effect, systems, energy, stability and change | The "lens" — framework for thinking about content |

## 5. ITEM TYPES

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Single correct answer                                   |
|  Machine scored                                          |
|  Scenario-based items include data tables, diagrams,     |
|  graphs, and Louisiana-specific phenomena                |
|  Both sessions                                           |
+----------------------------------------------------------+
```

**MC Example (Grade 5, DOK 2, 5-LS2-1 — Ecosystems):**

In a Louisiana bayou, alligators eat fish, fish eat insects, and insects eat algae. If a disease killed most of the fish in the bayou, what would MOST LIKELY happen to the alligator population?

- A. The alligator population would increase because there is less competition
- B. The alligator population would decrease because their food source is reduced
- C. The alligator population would stay the same because alligators can eat plants
- D. The alligator population would increase because they would eat more insects

*Correct Answer: B*
*Alignment: 5-LS2-1 | DOK 2*

---

**MC Example (Grade 8, DOK 2, 8-ESS2-4 — Water Cycle):**

Scientists studying the Mississippi River Delta observed that saltwater from the Gulf of Mexico is moving farther inland each year. Which process BEST explains why this is occurring?

- A. Increased rainfall is pushing freshwater out of the delta
- B. Coastal land loss is reducing the barrier between saltwater and freshwater systems
- C. Ocean temperatures are causing salt to evaporate from the water
- D. Underground springs are adding more salt to the delta region

*Correct Answer: B*
*Alignment: 8-ESS2-4 | DOK 2*

### Multi-Select (MS)

```
+----------------------------------------------------------+
|  MULTI-SELECT — 1 point (all-or-nothing)                 |
|                                                          |
|  5–6 options                                             |
|  Student selects ALL correct answers (typically 2)       |
|  Machine scored; no partial credit                       |
|  Scenario-based; often includes data                     |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**MS Example (Grade 11, DOK 2, HS-LS2-6 — Ecosystem Stability):**

Scientists are studying the impact of the Deepwater Horizon oil spill on the Gulf Coast ecosystem near Louisiana. Which TWO factors would MOST LIKELY help the ecosystem recover over time?

- A. Adding more oil to the water to dilute the concentration
- B. Natural biodegradation of oil by microorganisms in the water
- C. Building concrete walls to contain the remaining oil
- D. Restoration of coastal wetlands that serve as natural filters
- E. Removing all wildlife from the affected area permanently

*Correct Answers: B and D*

### Short Constructed Response (Short CR)

```
+----------------------------------------------------------+
|  SHORT CONSTRUCTED RESPONSE — 0–2 points                 |
|                                                          |
|  Brief written response (1–3 sentences)                  |
|  Must reference data or phenomenon from stimulus         |
|  Human scored                                            |
|  DOK 2                                                   |
+----------------------------------------------------------+
```

**Short CR Example (Grade 5, DOK 2, 5-ESS2-1):**

*"A scientist observed that the Louisiana wetlands lost 1,900 square miles of land between 1932 and 2010. Using the concept of Earth's interacting systems, explain ONE way the loss of wetlands could affect the atmosphere or hydrosphere in Louisiana."*

---

### Extended Constructed Response (Extended CR)

```
+----------------------------------------------------------+
|  EXTENDED CONSTRUCTED RESPONSE — 0–4 points              |
|                                                          |
|  Multi-part response (Parts A, B, C)                     |
|  Requires explanation with scientific reasoning          |
|  Must cite data or evidence from stimulus                |
|  Human scored using CR rubric                            |
|  DOK 3                                                   |
|  Session 2 only                                          |
+----------------------------------------------------------+
```

**Extended CR Example (Grade 8, DOK 3, 8-LS2-3 + 8-ESS3-1):**

*The diagram below shows a simplified food web of the Louisiana coastal wetland ecosystem.*

```
Phytoplankton → Zooplankton → Shrimp → Redfish → Pelicans
                                    ↗
         Marsh grass → Crabs ------→
```

*Part A: Describe how energy flows through this food web, starting with the primary producers. Identify which organisms are producers and which are consumers.*

*Part B: Louisiana's coastal wetlands are disappearing at a rate of approximately one football field every 100 minutes. Explain how the loss of marsh grass habitat could affect the populations of TWO other organisms in this food web.*

*Part C: A coastal restoration project proposes to plant new marsh grass along the eroding shoreline. Using evidence from the food web, explain why this restoration effort could benefit the entire ecosystem.*

## 8. SCORING RUBRICS

### Extended CR Rubric — 0–4 Points

| Score | Criteria                                                                                                                                                |
|-------|---------------------------------------------------------------------------------------------------------------------------------------------------------|
| 4     | All parts fully and accurately addressed. Scientific reasoning is clear, precise, and well-supported with evidence from the stimulus. Models or explanations are complete and demonstrate thorough understanding of the scientific concept. Appropriate science vocabulary used throughout. |
| 3     | Most parts accurately addressed. Scientific reasoning is generally clear and supported with relevant evidence. Minor errors or omissions present but do not indicate fundamental misunderstanding. Adequate use of science vocabulary. |
| 2     | Some parts addressed. Scientific reasoning is partially developed or contains conceptual errors. Evidence is present but may be vague, incomplete, or partially irrelevant. Limited use of science vocabulary. |
| 1     | Minimal response. Little scientific reasoning demonstrated. Evidence is absent or inaccurate. Significant misconceptions present. Science vocabulary absent or used incorrectly. |
| 0     | No response, blank, off-topic, or demonstrates no understanding of the scientific concept.                                                              |

### Short CR Rubric — 0–2 Points

| Score | Criteria                                                                                         |
|-------|--------------------------------------------------------------------------------------------------|
| 2     | Accurately and completely addresses the prompt; references data or phenomenon from stimulus; clear scientific reasoning |
| 1     | Partially addresses the prompt; evidence may be vague or incomplete; limited scientific reasoning |
| 0     | Does not address the prompt; no evidence; blank; or demonstrates no understanding                |

### Suggested Anchoring Phenomena by Grade

**Grade 5 Phenomena:**
- "Every spring, the Mississippi River carries millions of tons of sediment downstream. Where does this sediment go, and how does it change the Louisiana coastline?"
- "In a Louisiana bayou, a student noticed that alligators spend hours basking in the sun on the bank before returning to the water. Why do alligators behave this way?"
- "After Hurricane Katrina, scientists found that areas with healthy wetlands experienced less flooding than areas without wetlands. What role do wetlands play in protecting communities?"
- "A Louisiana farmer noticed that sugar cane plants grow faster and taller in the summer months than in winter. What factors cause this difference in growth?"

**Grade 8 Phenomena:**
- "Louisiana has lost approximately 2,000 square miles of coastal wetlands since the 1930s. What natural and human-caused processes are responsible for this land loss?"
- "After the Deepwater Horizon oil spill in 2010, scientists found that some species of bacteria in the Gulf of Mexico actually increased in population. How can an oil spill lead to population growth for certain organisms?"
- "The Mississippi River Delta is one of the fastest-eroding landforms on Earth. Scientists are building sediment diversions to redirect river flow. How could this engineering solution help rebuild the delta?"
- "A student noticed that the water in a Louisiana salt marsh is much saltier during drought years than during wet years. What processes in the water cycle explain this observation?"

**Grade 11 Phenomena:**
- "Louisiana's barrier islands are shrinking, reducing protection for the coast. How do the interactions between Earth's systems (geosphere, hydrosphere, atmosphere, biosphere) contribute to barrier island loss?"
- "Scientists discovered that the Gulf of Mexico has a seasonal 'dead zone' — an area of extremely low oxygen. What biological and chemical processes create this dead zone, and how does it affect marine life?"
- "Coastal Louisiana supports a multibillion-dollar fishing industry. Evaluate the trade-offs between oil and gas extraction and fisheries sustainability in the Gulf Coast ecosystem."

## 11. QUALITY CHECKLIST AND COMMON PITFALLS

### Quality Checklist

- [ ] Grade verified as 5, 8, or 11 ONLY (not other LA grades for science)
- [ ] Standard code uses Louisiana Science Standard format
- [ ] Three-dimensional alignment verified: DCI + SEP + CCC
- [ ] Louisiana-specific phenomenon used in scenario items
- [ ] Multi-Select has exactly 2 correct answers from 5–6 options
- [ ] All MC distractors reflect identifiable student misconceptions
- [ ] Data tables and graphs are clearly labeled with units
- [ ] Science content is accurate and reviewed by subject-matter expert
- [ ] DOK level matches cognitive demand of item
- [ ] Item avoids vocabulary beyond grade-level expectations
- [ ] Extended CR has multi-part structure (Parts A, B, C)
- [ ] Extended CR includes explanation/justification component

### Common Pitfalls

| Pitfall                                        | Problem                                                 | Fix                                                          |
|------------------------------------------------|---------------------------------------------------------|--------------------------------------------------------------|
| Using NGSS PE codes directly                   | Louisiana has its own science standards                 | Use Louisiana Science Standard codes                         |
| Writing items for Grades 3, 4, 6, 7            | LEAP 2025 Science tests only Gr 5, 8, 11              | Restrict items to Grades 5, 8, and 11                        |
| One-dimensional items (content only)           | Louisiana science is three-dimensional                  | Include SEP and CCC alignment in every item                  |
| Generic phenomena (not Louisiana-specific)     | LA items should anchor in real Louisiana contexts       | Use bayous, delta, Gulf Coast, wetlands, etc.                |
| Extended CR with only one part                 | LEAP 2025 CR requires multi-part structure              | Minimum Part A and Part B; include Part C for DOK 3          |
| Ignoring oil spill and environmental contexts  | Louisiana's environmental challenges are rich assessment contexts | Include Deepwater Horizon, wetland loss, coastal restoration |
| MS with 3+ correct answers                     | LA MS items use exactly 2 correct answers               | Redesign MS to have exactly 2 correct options                |
| Confusing Mastery (L4) with Basic (L3)         | Mastery is Louisiana's proficiency target               | Target item difficulty to Mastery-level performance          |

## 12. PROMPT PATTERNS

The following patterns reflect the most common LEAP 2025 Science item structures at Grades 5, 8, and 11.

### Pattern 1: Observation to Explanation (MC, DOK 2)
> "Scientists observed [Louisiana organism/phenomenon] doing [specific behavior/change]. Which explanation BEST describes why this occurred?"

### Pattern 2: Data Table Interpretation (MC or MS, DOK 2)
> "The table/graph below shows [Louisiana science data collected over time / in an experiment]. Based on the data, which [conclusion/statement/pattern] is BEST supported?"

### Pattern 3: Cause and Effect — Ecosystem (MC, DOK 2)
> "In the [Louisiana bayou / Gulf Coast / Mississippi River Delta], [change in one variable] occurred. What would MOST LIKELY be the effect on [another organism or part of the system]?"

### Pattern 4: Experimental Design and Inquiry (MC, DOK 2–3)
> "A student designed an experiment to test whether [variable] affects [outcome] in a Louisiana [context]. Which change would make the experiment MORE valid? / What is the INDEPENDENT VARIABLE in this experiment?"

### Pattern 5: Model-Based Reasoning (Extended CR, DOK 3)
> "Using the [food web / diagram / model] provided, explain how [change or process] affects [system component]. Use evidence from the model and your knowledge of [scientific concept] to support your explanation."

### Pattern 6: Environmental Engineering Solution (CR, DOK 3)
> "Louisiana is [losing wetlands / experiencing erosion / addressing pollution]. A [proposed solution] has been suggested. Evaluate whether this solution would be effective. Use scientific evidence to support your reasoning."
