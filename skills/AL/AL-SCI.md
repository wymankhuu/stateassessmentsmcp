## 5. ITEM TYPES

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Single correct answer                                   |
|  Machine scored                                          |
|  Scenario-based items include data tables, diagrams,     |
|  graphs, and Alabama-specific phenomena                  |
|  DOK 1–2                                                 |
+----------------------------------------------------------+
```

**MC Example (Grade 5, DOK 2, 5-LS2 — Ecosystems):**

In the Mobile Bay ecosystem, marsh grasses provide food for small crabs. The crabs are eaten by wading birds. If a disease reduced the marsh grass population, what would MOST LIKELY happen to the crab population?

- A. The crab population would increase because there is less competition
- B. The crab population would decrease because there is less food available
- C. The crab population would stay the same because crabs eat other foods
- D. The crab population would move to a different ecosystem

*Correct Answer: B*

### Constructed Response (CR)

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE — 0–2 points                       |
|                                                          |
|  Written response explaining scientific phenomena        |
|  Must reference data or scenario information             |
|  Human scored using CR rubric                            |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**CR Example (Grade 8, DOK 3, 8-ESS3 — Natural Hazards):**

*"Alabama's Gulf Coast experiences hurricanes each year. Using the data provided about hurricane frequency and intensity over the past 50 years, explain how scientists use this data to predict future hurricane impacts on coastal communities. Include at least one specific pattern from the data in your response."*

## 7. ALABAMA SCIENCE STANDARDS vs. NGSS COMPARISON

### Side-by-Side Comparison

| Feature                     | Alabama Course of Study (USE THIS)            | NGSS (Reference Only)                      |
|-----------------------------|----------------------------------------------|--------------------------------------------|
| Adopted by Alabama          | YES — Alabama-specific standards              | Partially influenced but not adopted       |
| Standard Code Example       | 5-ESS2, 8-PS2, 5-LS1                        | 5-ESS2-1, MS-PS2-1                        |
| Structure                   | Domain + Grade-level indicators              | Performance Expectation with 3 dimensions  |
| Science Practices           | Embedded in standard language                | Explicit SEPs (8 practices)                |
| Crosscutting Concepts       | Integrated within standards                  | Explicit CCCs (7 concepts)                 |
| Assessment Implications     | Content knowledge + inquiry-based reasoning  | Three-dimensional assessment               |
| Tested Grades               | 5, 8                                         | Varies by adopting state                   |

> **KEY RULE:** When writing ACAP Science items, use Alabama standard codes (e.g., **5-LS2**, **8-PS2**) — reference NGSS only for conceptual alignment, never as item codes.

## 8. SCORING RUBRICS

### Constructed Response (CR) Rubric — 0–2 Points

| Score | Criteria                                                                                                    |
|-------|-------------------------------------------------------------------------------------------------------------|
| 2     | Accurate, complete explanation of the scientific phenomenon; references specific data or evidence from the scenario; demonstrates clear understanding of the relevant science concept |
| 1     | Partially accurate explanation; some reference to data or evidence; demonstrates partial understanding       |
| 0     | Inaccurate, irrelevant, insufficient, or blank                                                              |

### TEI Scoring

| Item Type            | Scoring                                                              |
|----------------------|----------------------------------------------------------------------|
| TEI (1-point)        | All-or-nothing: full credit for fully correct response               |
| TEI (2-point)        | Partial credit: 2 pts for fully correct; 1 pt for partially correct  |

### MC Scoring

| Item Type    | Scoring Method  | Points |
|--------------|-----------------|--------|
| MC           | Machine scored  | 1 pt   |

### Suggested Anchoring Phenomena by Grade

**Grade 5 Phenomena:**
- "Students observe that different types of plants grow in the marsh areas around Mobile Bay compared to the sandy dunes along Gulf Shores — what factors explain the difference?"
- "After heavy rains in Alabama, a student noticed the water in a creek turned brown — what process caused the water to change color?"
- "During a jubilee event in Mobile Bay, fish and crabs suddenly come to the shallow shoreline — what environmental conditions cause this?"

**Grade 8 Phenomena:**
- "Alabama has some of the longest caves in the United States, including Cathedral Caverns — what geoscience process formed these cave systems over thousands of years?"
- "Gulf Coast communities experience more flooding during hurricane season — what atmospheric and oceanic patterns contribute to hurricane formation?"
- "Students studying the Alabama coastline found that Dauphin Island has shrunk significantly over the past century — what processes contribute to this change?"

## 11. QUALITY CHECKLIST AND COMMON PITFALLS

### Quality Checklist

- [ ] Grade verified as 5 or 8 ONLY (ACAP Science does not test other grades)
- [ ] Standard code uses Alabama Course of Study format ([Grade]-[Domain][Standard])
- [ ] Alabama-specific phenomenon used in scenario items
- [ ] All MC distractors reflect identifiable student misconceptions
- [ ] Data tables and graphs are clearly labeled with units
- [ ] Science content is accurate and grade-appropriate
- [ ] DOK level matches cognitive demand of item
- [ ] Item avoids vocabulary beyond grade-level expectations
- [ ] Cultural and environmental contexts are authentic to Alabama
- [ ] CR items include evidence directive referencing scenario data
- [ ] TEI format clearly specified (drag-drop, multi-select, labeling, etc.)

### Common Pitfalls

| Pitfall                                   | Problem                                           | Fix                                                      |
|-------------------------------------------|---------------------------------------------------|----------------------------------------------------------|
| Using NGSS PE codes as item codes         | Alabama uses ACOS Science standards               | Use [Grade]-[Domain][Standard] format only               |
| Items for wrong grades                    | ACAP Science tests only Grades 5 and 8            | Restrict items to Grades 5 and 8                         |
| Generic phenomena (not Alabama-specific)  | ACAP items should anchor in real Alabama contexts  | Use Mobile Bay, Gulf Coast, caves, Appalachian foothills |
| CR rubric exceeds 0–2 range              | ACAP Science CR items are scored 0–2               | Use the 0–2 rubric scale                                |
| Vocabulary too advanced for grade level   | ACAP targets grade-appropriate terminology         | Review ACOS standards for expected vocabulary             |
| Data items without clear labels/units     | Students need labeled data to interpret correctly  | Always include units and clear column/axis labels        |
| Ignoring Alabama weather phenomena        | Alabama has unique weather (tornadoes, hurricanes) | Incorporate real Alabama weather data and events         |

## 12. PROMPT PATTERNS

The following patterns reflect the most common ACAP Science item structures.

### Pattern 1: Ecosystem Interactions (MC, DOK 2, Life Science)
> "In the [Mobile Bay / Gulf Coast / Alabama forest] ecosystem, [change in one variable] occurred. What would MOST LIKELY be the effect on [another organism or part of the system]?"

### Pattern 2: Data Table Interpretation (MC or TEI, DOK 2)
> "The table below shows [Alabama science data collected over time / in an experiment]. Based on the data, which [conclusion / statement / pattern] is BEST supported?"

### Pattern 3: Earth Process Identification (MC, DOK 1–2, Earth Science)
> "A student observed [erosion / weathering / deposition / cave formation] at [Alabama location]. Which process BEST explains the changes the student observed?"

### Pattern 4: Weather and Climate Analysis (MC or TEI, DOK 2, Earth Science)
> "The [graph / data table] shows weather data recorded in [Alabama city] over [time period]. Based on the data, what weather pattern is MOST LIKELY occurring?"

### Pattern 5: Adaptation and Survival (MC, DOK 2, Life Science)
> "[Alabama organism] has [specific physical or behavioral trait]. How does this [adaptation / feature] BEST help the organism survive in its environment?"

### Pattern 6: Experimental Design and Variables (MC or CR, DOK 2–3)
> "A student designed an experiment to test whether [variable] affects [outcome] in an [Alabama context]. What is the [independent variable / controlled variable / best improvement to the design]?"

### Pattern 7: Geological Processes (CR, DOK 3, Earth Science)
> "Using the data provided about [Alabama geological feature], explain the geoscience process that formed this feature. Include evidence from the data to support your explanation."
