## 3. TEST STRUCTURE

ACAP Mathematics is administered in **2 sessions** over one or two days.

```
+-------------------------------------------------------------------+
|           ACAP MATH TEST STRUCTURE (Grades 3–8, 10)               |
+---------------------------------+---------------------------------+
|   SESSION 1                     |   SESSION 2                     |
|   ~60–75 minutes                |   ~60–75 minutes                |
|                                 |                                 |
|  MULTIPLE CHOICE                |  MULTIPLE CHOICE                |
|  TECHNOLOGY-ENHANCED ITEMS      |  TECHNOLOGY-ENHANCED ITEMS      |
|  NO calculator (all grades)     |  CONSTRUCTED RESPONSE           |
|                                 |  Calculator allowed (Gr 6–8,10) |
+---------------------------------+---------------------------------+
```

### Session Item Counts by Grade Band

| Session       | Grades 3–5                       | Grades 6–8                       | Grade 10                         |
|---------------|----------------------------------|----------------------------------|----------------------------------|
| Session 1     | 18–24 MC/TEI items (no calc)     | 18–24 MC/TEI items (no calc)     | 18–24 MC/TEI items (no calc)     |
| Session 2     | 14–20 MC/TEI + 2–3 CR items     | 14–20 MC/TEI + 2–3 CR (calc)    | 14–20 MC/TEI + 2–3 CR (calc)    |

> **Calculator Policy:** No calculators for any portion of Grades 3–5. For Grades 6–8 and 10, a calculator is available during Session 2 only.

## 5. ITEM TYPES

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Single correct answer                                   |
|  Machine scored                                          |
|  DOK 1–2                                                 |
|  Both sessions                                           |
+----------------------------------------------------------+
```

**MC Example (Grade 6, DOK 2, 6.RP — Ratios):**

An Alabama cotton farmer plants 3 rows of cotton for every 2 rows of soybeans. If the farmer plants 24 rows of cotton, how many rows of soybeans does the farmer plant?

- A. 12
- B. 16
- C. 18
- D. 36

*Correct Answer: B (24 / 3 = 8 groups; 8 x 2 = 16)*

---

### Technology-Enhanced Item (TEI)

```
+----------------------------------------------------------+
|  TECHNOLOGY-ENHANCED ITEM — 1–2 points                   |
|                                                          |
|  Drag-and-drop, multi-select, drop-down menus,           |
|  equation entry, graphing, matching, number line          |
|  Machine scored                                          |
|  DOK 2–3                                                 |
|  Both sessions                                           |
+----------------------------------------------------------+
```

**TEI Example (Grade 8, DOK 2, 8.F — Functions, Equation Entry):**

*A rocket model launched at Space Camp in Huntsville reaches a height of h(t) = -16t^2 + 64t feet after t seconds. Enter the time in seconds when the rocket reaches its maximum height.*

*Correct Answer: 2 seconds*

---

### Constructed Response (CR)

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE — 0–2 points                       |
|                                                          |
|  Multi-step problem requiring shown work                 |
|  May include Parts A, B, C                               |
|  DOK 2–3                                                 |
|  Human scored using CR rubric                            |
|  Session 2 only (2–3 per test)                           |
+----------------------------------------------------------+
```

**CR Example (Grade 7, DOK 3, 7.RP — Proportional Relationships):**

*"A seafood restaurant on the Gulf Shores serves two shrimp platters. Platter A costs $18 for 1.5 pounds. Platter B costs $28 for 2.5 pounds.*

*Part A: Find the unit rate (cost per pound) for each platter. Show your work.*
*Part B: Which platter is a better value per pound? Explain your reasoning."*

## 7. ALABAMA MATHEMATICAL PRACTICE STANDARDS IN ASSESSMENT

Alabama's Mathematical Practice Standards guide item development:

| Practice Standard | Assessment Application                                                      |
|-------------------|-----------------------------------------------------------------------------|
| MP.1 Make Sense   | Multi-step word problems where students must identify the approach          |
| MP.2 Reason Abstractly | Items requiring decontextualization and recontextualization            |
| MP.3 Construct Arguments | CR items requiring written justification of reasoning               |
| MP.4 Model with Math | Real-world Alabama context problems (see Section 10)                    |
| MP.5 Use Tools    | Calculator-appropriate items in Grades 6–8, 10 Session 2                   |
| MP.6 Attend to Precision | Items requiring exact answers, correct units, and labels            |
| MP.7 Use Structure | Pattern recognition and algebraic structure items                         |
| MP.8 Repeated Reasoning | Items involving generalization from specific cases                   |

> **MP.4 (Model with Math)** is the most visible practice standard in test items, as ACAP emphasizes real-world application using Alabama-specific contexts.

## 8. SCORING RUBRICS

### Constructed Response (CR) Rubric — 0–2 Points

| Score | Criteria                                                                                                    |
|-------|-------------------------------------------------------------------------------------------------------------|
| 2     | Correct answer with complete, clearly shown work; mathematical reasoning is sound and organized              |
| 1     | Partially correct; work shown is incomplete or contains a minor error; some mathematical understanding       |
| 0     | Incorrect or no work shown; blank; off-task; no mathematical understanding demonstrated                     |

### TEI Scoring

| Item Type            | Scoring                                                              |
|----------------------|----------------------------------------------------------------------|
| TEI (1-point)        | All-or-nothing: full credit for fully correct response               |
| TEI (2-point)        | Partial credit: 2 pts for fully correct; 1 pt for partially correct  |

## 10. CONTEXTUALIZATION — ALABAMA MATH

When generating real-world math contexts, prioritize authentic Alabama settings:

### Recommended Math Contexts

| Context                                   | Grade Band | Math Domains                                    |
|-------------------------------------------|------------|-------------------------------------------------|
| Alabama agriculture data (cotton, soybeans, peanuts) | 3–8  | Ratios, multiplication, fractions, data analysis |
| Gulf Coast distances and navigation       | 5–10       | Measurement, geometry, proportional reasoning    |
| Huntsville rocket dimensions and trajectories | 6–10    | Functions, geometry, equations, quadratics       |
| Mobile Bay area and perimeter data        | 4–8        | Area, perimeter, measurement, geometry           |
| Alabama football stadium statistics       | 5–8        | Data analysis, statistics, percent               |
| Gulf Shores tourism revenue               | 6–10       | Proportional reasoning, percent, functions       |
| Space Camp mission calculations           | 5–10       | Equations, functions, unit conversion            |
| Alabama forestry and timber data          | 3–7        | Multiplication, fractions, measurement           |
| Birmingham steel production data          | 6–10       | Ratios, percent change, linear functions         |
| Alabama weather and temperature data      | 3–8        | Data analysis, integers, statistics              |

### Sample Context Sentence Starters

- "A farmer in Baldwin County harvested [X] bushels of peanuts from [Y] acres..."
- "The Saturn V rocket at the U.S. Space & Rocket Center in Huntsville is [X] feet tall..."
- "A fishing boat travels [X] miles from Gulf Shores to an island in Mobile Bay..."
- "The table shows the number of visitors to Alabama state parks over [time period]..."
- "Students measured the distances between landmarks along the Gulf Coast and recorded..."

## 11. QUALITY CHECKLIST AND COMMON PITFALLS

### Quality Checklist

- [ ] Standard code uses Alabama Course of Study format ([Grade].[Domain].[Standard])
- [ ] Practice standard alignment identified for CR items
- [ ] Calculator policy matches session and grade level
- [ ] CR items require shown work and may include multi-part structure
- [ ] All numerical values produce clean, non-ambiguous answers
- [ ] Alabama-specific real-world context used where appropriate
- [ ] Distractors reflect specific, identifiable student error types
- [ ] DOK level verified against actual cognitive demand
- [ ] Units and labels are correct throughout
- [ ] Grade 10 items include age-appropriate algebraic and functional content
- [ ] TEI format clearly specified (equation entry, graphing, multi-select, etc.)
- [ ] Data tables and graphs are clearly labeled

### Common Pitfalls

| Pitfall                                  | Problem                                           | Fix                                                      |
|------------------------------------------|---------------------------------------------------|----------------------------------------------------------|
| Calculator in Session 1 (Gr 3–5)        | No calculator allowed for any Grades 3–5 portion  | Design items without calculator dependence for Gr 3–5    |
| CR rubric exceeds 0–2 range             | ACAP Math CR items are scored 0–2                  | Use only the 0–2 rubric scale                            |
| Generic context (no AL specificity)      | ACAP values authentic Alabama contexts             | Use Gulf Shores, Huntsville, Mobile Bay, agriculture     |
| CR without "show your work" directive   | DOK 3 requires demonstrated reasoning              | Include "Show your work" or "Explain your reasoning"     |
| Missing Grade 10 content                | ACAP tests Grade 10 with advanced math             | Include algebra, functions, and geometry for Grade 10    |
| Distractor without a clear error type    | Each wrong answer should target a specific mistake | Map each distractor to a computation or conceptual error |
| TEI format unspecified                   | TEI has many possible formats                      | Always specify equation entry, graphing, drag-drop, etc. |

## 12. PROMPT PATTERNS

The following patterns reflect the most common ACAP Mathematics item structures.

### Pattern 1: Contextual Computation (MC, DOK 2)
> "[Alabama setting]. [Given information]. [Mathematical question requiring multi-step application]."
> (Options: correct answer + three specific error-type distractors)

### Pattern 2: Multi-Step Application (CR Part A, DOK 2)
> "A [Alabama context] has [given data]. [Part A: computation requiring setup + solve]. Show your work."

### Pattern 3: Rate or Ratio in Context (MC or CR, DOK 2)
> "[Alabama scenario] involves [quantity A] for every [quantity B]. [Question about scaling, unit rate, or comparison]."

### Pattern 4: Explain in Context (CR Part B, DOK 3)
> "Explain what your answer to Part A means in the context of [Alabama scenario]."

### Pattern 5: Comparison with Justification (CR, DOK 3)
> "Two [Alabama scenarios] are described: [Scenario A] and [Scenario B]. Which is [more efficient / greater / better value]? Use mathematical evidence to justify your answer."

### Pattern 6: Error Analysis (MC or TEI, DOK 3)
> "[Student name] solved the problem and got [incorrect answer]. What error did [student] make?"

### Pattern 7: Data Interpretation (MC or TEI, DOK 2)
> "The [table / graph] below shows [Alabama data]. Based on the data, which statement is BEST supported?"
