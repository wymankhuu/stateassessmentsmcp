## 2. STANDARDS FRAMEWORK

### Alabama Course of Study: English Language Arts (2021)

Alabama adopted revised ELA standards in 2021. The standards are organized by strand with grade-level indicators.

**Strand Overview:**

| Strand                 | Description                                                    |
|------------------------|----------------------------------------------------------------|
| Reading Literary       | Analysis of fiction, poetry, drama (RL standards)              |
| Reading Informational  | Analysis of nonfiction, argument, and functional text (RI standards) |
| Writing                | Narrative, informational/explanatory, and argument writing (W standards) |
| Speaking and Listening | Discussion, presentation, collaboration (SL standards)         |
| Language               | Vocabulary, grammar, and conventions (L standards)             |

### Key Reading Standards — Literary Text

| Standard Code | Description                                                                                      |
|---------------|--------------------------------------------------------------------------------------------------|
| RL.X.1        | Cite textual evidence to support analysis of what the text says explicitly and inferentially      |
| RL.X.2        | Determine a theme or central message and analyze its development over the course of the text      |
| RL.X.3        | Analyze how characters, settings, and events interact and develop throughout the text             |
| RL.X.4        | Determine the meaning of words and phrases, including figurative and connotative meanings         |
| RL.X.5        | Analyze the structure of the text and how sections contribute to the whole                        |
| RL.X.6        | Explain how the author develops the point of view or perspective of the narrator or speaker       |

### Key Reading Standards — Informational Text

| Standard Code | Description                                                                                      |
|---------------|--------------------------------------------------------------------------------------------------|
| RI.X.1        | Cite textual evidence to support analysis of what the text says explicitly and inferentially      |
| RI.X.2        | Determine a central idea and analyze how it is conveyed through particular details                |
| RI.X.3        | Analyze how key individuals, events, or ideas are introduced, illustrated, and elaborated         |
| RI.X.4        | Determine the meaning of domain-specific and academic vocabulary in context                       |
| RI.X.5        | Analyze the structure an author uses to organize a text and how sections relate                   |
| RI.X.8        | Trace and evaluate the argument and specific claims in a text, including validity of reasoning    |

### Key Vocabulary and Language Standards

| Standard Code | Description                                                                                      |
|---------------|--------------------------------------------------------------------------------------------------|
| L.X.4         | Determine or clarify the meaning of unknown words using context clues, affixes, and reference     |
| L.X.5         | Demonstrate understanding of figurative language, word relationships, and nuances in word meanings|
| L.X.6         | Acquire and use accurately grade-appropriate academic and domain-specific vocabulary              |

> **Coding Note:** Replace X with the actual grade number. For example, Grade 5 theme standard is **RL.5.2**. Grade 10 uses **RL.10.2**. Alabama ACOS standards use this RL/RI/W/L coding system.

## 3. TEST STRUCTURE

ACAP ELA is administered across **2 sessions** over one or two days.

```
+-------------------------------------------------------------------+
|              ACAP ELA TEST STRUCTURE (Grades 3–8, 10)             |
+---------------------------------+---------------------------------+
|   SESSION 1                     |   SESSION 2                     |
|   ~60–80 minutes                |   ~60–80 minutes                |
|                                 |                                 |
|  READING COMPREHENSION          |  READING + WRITING              |
|  - Literary passage(s)          |  - Informational passage(s)     |
|  - Informational passage(s)     |  - Constructed Response (CR)    |
|  - MC items                     |  - MC items                     |
|  - Technology-Enhanced Items    |  - Technology-Enhanced Items    |
|    (TEI)                        |    (TEI)                        |
+---------------------------------+---------------------------------+
```

### Session Item Counts by Grade Band

| Session       | Grades 3–5                       | Grades 6–8                       | Grade 10                         |
|---------------|----------------------------------|----------------------------------|----------------------------------|
| Session 1     | 16–22 MC/TEI items               | 18–24 MC/TEI items               | 20–26 MC/TEI items               |
| Session 2     | 14–18 MC/TEI + 1–2 CR items     | 16–20 MC/TEI + 1–2 CR items     | 16–22 MC/TEI + 1–2 CR items     |

## 5. ITEM TYPES

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Single correct answer                                   |
|  Machine scored                                          |
|  DOK 1–2                                                 |
|  Both sessions                                           |
+----------------------------------------------------------+
```

**MC Example (Grade 5, DOK 2, RL.5.2 — Theme):**

*Passage excerpt: A girl growing up near the Gulf Shores learns to care for injured sea birds from her grandfather, who has been a volunteer wildlife rescuer for decades.*

Which theme is BEST supported by the events in the passage?

- A. Wild animals should never be kept in captivity
- B. Caring for others can create strong bonds between generations
- C. Living near the ocean is better than living in a city
- D. Older people always know the best way to solve problems

*Correct Answer: B*

---

### Technology-Enhanced Item (TEI)

```
+----------------------------------------------------------+
|  TECHNOLOGY-ENHANCED ITEM — 1–2 points                   |
|                                                          |
|  Drag-and-drop, multi-select, highlighting,              |
|  drop-down menus, matching, reordering                   |
|  Machine scored                                          |
|  DOK 2–3                                                 |
|  Both sessions                                           |
+----------------------------------------------------------+
```

**TEI Example (Grade 7, DOK 2, RI.7.5 — Text Structure, Multi-Select):**

*After reading an article about the Alabama civil rights movement and the Selma to Montgomery marches:*

Select TWO ways the author organizes information in this article.

- A. By comparing Alabama's movement to other states' civil rights efforts
- B. By presenting events in the chronological order they occurred
- C. By describing the causes and effects of the Selma marches
- D. By listing famous landmarks in Alabama
- E. By presenting a fictional account of the events

*Correct Answers: B and C*

### Constructed Response (CR)

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE — 0–2 points                       |
|                                                          |
|  Written response (1–3 paragraphs)                       |
|  Must cite textual evidence                              |
|  Human scored using CR rubric                            |
|  DOK 3                                                   |
|  1–2 per test                                            |
+----------------------------------------------------------+
```

**CR Example (Grade 8, DOK 3, RI.8.8 — Argument Evaluation):**

*"The article 'Preserving Alabama's Appalachian Foothills' argues that state conservation funding is essential for protecting the biological diversity of the southern Appalachian region. How does the author use evidence and reasoning to support this argument? Use specific details from the text in your response."*

## 8. SCORING RUBRICS

### Constructed Response (CR) Rubric — 0–2 Points

| Score | Criteria                                                                                                           |
|-------|--------------------------------------------------------------------------------------------------------------------|
| 2     | Clearly and accurately addresses the prompt; cites specific, relevant textual evidence; provides elaboration connecting evidence to the analytical point |
| 1     | Partially addresses the prompt; includes some evidence that may be vague or incomplete; limited elaboration         |
| 0     | Does not address the prompt; no evidence cited; blank, off-topic, or copied from passage                           |

### TEI Scoring

| Item Type            | Scoring                                                              |
|----------------------|----------------------------------------------------------------------|
| TEI (1-point)        | All-or-nothing: full credit for fully correct response               |
| TEI (2-point)        | Partial credit: 2 pts for fully correct; 1 pt for partially correct  |

> **Scoring Note:** TEI items requiring multiple correct selections (e.g., multi-select) may award partial credit at 2-point value. Single-response TEI items are scored 1 point.

## 11. QUALITY CHECKLIST AND COMMON PITFALLS

### Quality Checklist

- [ ] Standard code uses Alabama Course of Study format (RL.X.#, RI.X.#, L.X.#)
- [ ] Passage Lexile is within grade-band range (see Section 7)
- [ ] MC options are plausible; no trick or obviously wrong choices
- [ ] TEI response format is clearly specified (multi-select, drag-and-drop, etc.)
- [ ] CR prompt includes clear analytical focus (not "summarize")
- [ ] CR prompt ends with evidence directive ("Use evidence from the text")
- [ ] Alabama context used where appropriate
- [ ] Item does not reference assessments from other states
- [ ] DOK level verified against item cognitive demand
- [ ] No performance task component (ACAP does not include PT)
- [ ] Vocabulary items use grade-appropriate academic and domain-specific words
- [ ] Cultural contexts are respectful and accurately represented
- [ ] Grade 10 items reflect appropriately advanced text complexity

### Common Pitfalls

| Pitfall                                      | Problem                                           | Fix                                                      |
|----------------------------------------------|---------------------------------------------------|----------------------------------------------------------|
| Using generic CCSS codes without AL context  | Alabama uses its own Course of Study standards     | Use Alabama ACOS coding conventions                       |
| CR prompt that asks students to summarize    | Summarizing is not DOK 3 analytical thinking       | Frame prompt around analysis, evaluation, or argument     |
| TEI format not specified                     | TEI can be multiple formats                        | Always specify whether multi-select, drag-drop, etc.     |
| Ignoring Alabama cultural contexts           | Test fairness requires authentic AL representation | Include civil rights, Gulf Coast, Appalachian settings   |
| Using non-Alabama geographic references      | ACAP values Alabama-specific authenticity           | Anchor passages in real Alabama places and communities   |
| CR rubric exceeds 0–2 range                  | ACAP CR items are scored 0–2                       | Use only the 0–2 rubric scale for CR items               |
| Missing Grade 10 in test design              | ACAP tests Grade 10 in addition to 3–8            | Include Grade 10 in item generation and blueprints       |

## 12. PROMPT PATTERNS

The following patterns reflect the most commonly tested item structures on ACAP ELA.

### Pattern 1: Theme Development (CR, DOK 3, RL.X.2)
> "In '[passage title],' the author develops the theme that [theme]. How do the characters' [actions / decisions / experiences] support this theme? Use evidence from the text to support your response."

### Pattern 2: Central Idea and Evidence (TEI or CR, DOK 2–3, RI.X.2)
> "What is the central idea of '[article title]'? How does the author use [details / examples / evidence] to develop this idea?"

### Pattern 3: Text Structure Analysis (TEI, DOK 2, RI.X.5)
> Multi-select: "Select TWO ways the author organizes the information in '[article title].'"

### Pattern 4: Figurative Language and Vocabulary (MC, DOK 2, L.X.5 or RL.X.4)
> "Read this sentence from the passage: '[sentence with figurative language].' What does this [metaphor / simile / idiom] MOST LIKELY mean?"

### Pattern 5: Author's Argument and Reasoning (CR, DOK 3, RI.X.8)
> "The author of '[article title]' argues that [claim]. How does the author use evidence and reasoning to support this argument? Use details from the text in your response."

### Pattern 6: Point of View and Perspective (MC or TEI, DOK 2, RL.X.6)
> "How does the [first-person / third-person] point of view affect the reader's understanding of [event / character / conflict] in the passage?"

### Pattern 7: Evidence-Based Inference (TEI, DOK 2–3, RL.X.1 or RI.X.1)
> Multi-select: "Select TWO details from the passage that BEST support the inference that [character/topic insight]."
