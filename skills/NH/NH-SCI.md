## 1. Overview

| Field | Detail |
|---|---|
| **Assessment Name** | NH Statewide Assessment System (NH SAS) — Science |
| **Administering Agency** | New Hampshire Department of Education (NH DOE) |
| **Vendor** | NH DOE |
| **Grades Tested** | 5, 8, and 11 |
| **Testing Window** | March – May |
| **Delivery** | Computer-based; fixed-form |
| **Standards** | Next Generation Science Standards (NGSS) as adopted by New Hampshire |
| **Score Scale** | Standard score (varies by grade); 4 performance levels |
| **Reporting** | Individual Student Report; School, District, State aggregate reports |

> **CRITICAL NOTE:** NH SAS Science is administered **only at Grades 5, 8, and 11**. Do not generate items for Grades 3, 4, 6, or 7.

### Performance Level Descriptors

| Level | Label | Description |
|---|---|---|
| 4 | **Standard Exceeded** | Student demonstrates thorough understanding of three-dimensional science; expertly integrates DCI, SEP, and CCC; constructs sophisticated, evidence-based explanations |
| 3 | **Standard Met** | Student demonstrates adequate understanding of three-dimensional science; appropriately applies practices and crosscutting concepts in grade-level contexts |
| 2 | **Standard Nearly Met** | Student demonstrates partial understanding; can recall disciplinary core ideas but struggles to integrate science practices or crosscutting concepts |
| 1 | **Standard Not Met** | Student demonstrates minimal science understanding; cannot apply practices or crosscutting concepts; limited to recall of isolated facts |

> **Item-writing target:** Level 3 (Standard Met) performance. Items should assess all three NGSS dimensions simultaneously.

## 3. Test Structure

NH SAS Science is a single-session, computer-based test. There is **no lab practical component** — all items are stimulus-based.

```
+------------------------------------------------------------------+
|                   NH SAS SCIENCE STRUCTURE (Grades 5, 8, 11)      |
+------------------------------------------------------------------+
|  SINGLE SESSION                                                   |
|  Computer-Based, Fixed-Form                                       |
|  Approximately 90–120 minutes                                     |
|                                                                   |
|  ~40 items per grade                                              |
|                                                                   |
|  Item types:                                                      |
|    - Selected Response (SR) — ~60–65% of items                    |
|    - Multi-Select Response (MS) — ~15–20% of items                |
|    - Constructed Response (CR) — ~15–20% of items (3 pts each)    |
+------------------------------------------------------------------+
```

### Grade-Level Test Specifications

| Specification | Grade 5 | Grade 8 | Grade 11 |
|---|---|---|---|
| Approximate Item Count | ~38–42 | ~38–42 | ~38–42 |
| Selected Response | ~25–28 | ~25–28 | ~25–28 |
| Multi-Select | ~6–8 | ~6–8 | ~6–8 |
| Constructed Response | ~4–6 | ~4–6 | ~4–6 |
| Approx. Testing Time | 90–120 min | 90–120 min | 90–120 min |
| Calculator | No | No | No |
| Reference Sheet | No | No | No |

> **Three-Dimensional Requirement:** Every NH SAS Science item must integrate at least one **Disciplinary Core Idea (DCI)**, one **Science and Engineering Practice (SEP)**, and one **Crosscutting Concept (CCC)**.

## 5. Item Types & Formats

### Selected Response (SR)

```
+----------------------------------------------------------+
|  SELECTED RESPONSE — 1 point                             |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Scenario, diagram, data table, or model stimulus        |
|  Must integrate DCI + SEP + CCC                          |
|  Machine scored                                          |
+----------------------------------------------------------+
```

**SR Example (Grade 8, DOK 2, MS-ESS2-2 — Geoscience Processes):**

Geologists studying the White Mountains found that the rocks at the summit of Mount Washington are approximately 400 million years old and show evidence of folding and metamorphism. Which statement BEST explains the geological process that formed these mountain features?

A. Volcanic eruptions deposited layers of ash that hardened into rock
B. Tectonic plate collisions compressed and folded ancient seafloor rocks, pushing them upward
C. Glaciers carved the mountains out of a flat plain during the last ice age
D. Earthquakes along a fault line lifted the rocks to their current elevation

*Correct Answer: B*
*Alignment: MS-ESS2-2 | SEP: Constructing Explanations | CCC: Cause and Effect | DOK 2*

---

### Multi-Select Response (MS)

```
+----------------------------------------------------------+
|  MULTI-SELECT RESPONSE — 1 point                         |
|                                                          |
|  5–6 options; select exactly 2 or 3 correct answers      |
|  Full credit only; partial credit not awarded            |
|  Machine scored                                          |
+----------------------------------------------------------+
```

**MS Example (Grade 8, DOK 2, MS-ESS3-3 — Human Impact):**

Scientists are studying the effects of acid rain on lakes in the White Mountain region. Select the TWO statements that describe evidence-based approaches to monitor and minimize the impact of acid rain on these lake ecosystems.

A. Add large amounts of salt to the lake to neutralize the acid
B. Collect water samples regularly to measure pH levels and track changes over time
C. Remove all fish from the lake until the acid rain stops
D. Work with regional agencies to reduce sulfur dioxide and nitrogen oxide emissions from power plants
E. Cover the lake surface with a plastic barrier to prevent acid rain from entering

*Correct Answers: B, D*
*Alignment: MS-ESS3-3 | SEP: Planning Investigations / Constructing Explanations | CCC: Cause and Effect | DOK 2*

---

### Constructed Response (CR)

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE — 0–3 points                       |
|                                                          |
|  Written explanation using evidence from stimulus        |
|  Stimulus always provided (data, diagram, scenario)      |
|  Must demonstrate three-dimensional reasoning            |
|  Human scored                                            |
+----------------------------------------------------------+
```

**CR Example (Grade 11, DOK 3, HS-ESS3-1 — Climate and Human Activity):**

*Stimulus: A data table showing average winter temperatures at Mount Washington Observatory from 1935–2025, alongside data on the length of the ski season at two NH resorts and snowfall totals. The data shows a trend of warming winters and shorter ski seasons.*

*"Using evidence from the data table, construct an explanation for how changes in climate have influenced human activity in the White Mountain region. Identify the cause-and-effect relationship and discuss how the pattern in the data could affect the regional economy."*

## 7. Three-Dimensional Design

Every NH SAS Science item must reflect all three NGSS dimensions simultaneously.

### Three-Dimensions Alignment Guide

| Dimension | What It Is | Example in Items |
|---|---|---|
| **DCI** (What students know) | Disciplinary science content | Weathering and erosion; ecosystem interactions; chemical reactions; plate tectonics |
| **SEP** (What students do) | How scientists work | Analyze data from a table; construct an explanation; use a model to predict |
| **CCC** (Lens of thinking) | Cross-domain thinking tools | Cause and effect; patterns; energy and matter; structure and function; systems |

### Crosscutting Concepts by Grade Band

| CCC | Grade 5 Emphasis | Grade 8 Emphasis | Grade 11 Emphasis |
|---|---|---|---|
| Patterns | Rock formations; seasonal weather; animal behaviors | Periodic table; population cycles; weather patterns | Inheritance patterns; population trends; climate data |
| Cause and Effect | Food web changes; erosion; weather events | Chemical reactions; ecosystem dynamics; geological processes | Mutations -> traits; climate -> ecosystem change; acid rain effects |
| Energy and Matter | Food chains; water cycle; plant growth | Chemical reactions; thermal transfer; matter cycling | Cellular respiration; photosynthesis; energy flow in ecosystems |
| Structure and Function | Plant/animal adaptations; leaf structure | Cell structures; molecular bonds; rock composition | DNA -> protein -> trait; organism adaptations |
| Systems and System Models | Ecosystems; water cycle; NH forests | Earth systems; lake ecosystems; watersheds | Ecosystems; genetic systems; climate systems |
| Scale, Proportion, Quantity | Particle size; distances; measurements | Atomic scale; geological time | Chromosome/gene scale; population modeling |
| Stability and Change | Habitat change; seasonal cycles | Climate; ecosystem stability; lake chemistry | Evolution; homeostasis; long-term environmental trends |

## 8. Scoring Rubrics

### Constructed Response (CR) Rubric — 0–3 Points

| Score | Criteria |
|---|---|
| 3 | Response accurately addresses the science concept; demonstrates clear three-dimensional understanding (DCI + SEP or CCC evident); includes specific, relevant evidence from the stimulus; explanation is complete, accurate, and logically connected |
| 2 | Response addresses the science concept with partial accuracy; shows understanding of the DCI but may only partially integrate a practice or crosscutting concept; evidence is present but may be incomplete |
| 1 | Response minimally addresses the science concept; shows limited understanding; little or no evidence from stimulus; explanation may be vague or contain minor inaccuracies |
| 0 | Response does not address the science concept; blank; off-topic; restates the stimulus without explanation; demonstrates no science understanding |

### CR Scoring Notes

- **Evidence must come from the stimulus.** Responses relying solely on prior knowledge without referencing provided data receive a maximum of 1 point.
- **Three-dimensional reasoning earns full credit.** A Score 3 response integrates DCI with at least one SEP or CCC.
- **Misconceptions lower the score.** A significant science misconception drops the response by one score point.

### Suggested Anchoring Phenomena by Grade

**Grade 5 Phenomena:**
- "Scientists at the Mount Washington Observatory record some of the most extreme weather on Earth, including winds that once reached 231 miles per hour. Why does the weather on top of Mount Washington differ so much from the weather in the valleys below?"
- "After a severe ice storm in New Hampshire, many trees lost their branches and some fell over entirely. Within a few months, new plants began growing on the forest floor where sunlight could now reach. What provided the energy for this new growth?"
- "Common loons on New Hampshire lakes dive underwater to catch fish but must return to the surface to breathe. What properties of loons help them survive in both air and water environments?"

**Grade 8 Phenomena:**
- "Geologists found that the rocks at the summit of Mount Washington contain minerals that could only form under extreme heat and pressure deep underground. How did these rocks end up at the top of a mountain?"
- "Scientists studying New Hampshire lakes in the 1980s found that many had become too acidic for fish to survive. After regulations reduced factory emissions, lake pH levels slowly improved over several decades. What caused the initial acidification and what explains the recovery pattern?"
- "Moose populations in New Hampshire have declined by nearly 50% since the 1990s. Scientists have linked this decline to increasing winter tick infestations, which are more severe in years with shorter winters. What cause-and-effect relationship explains this pattern?"

**Grade 11 Phenomena:**
- "Brook trout populations in New Hampshire streams with warmer water temperatures show different growth rates and reproductive timing compared to populations in cold mountain streams. What biological mechanisms could explain these differences between populations?"
- "Scientists studying acid rain recovery in the White Mountain National Forest found that while sulfur deposition has decreased significantly since the 1990s, some forest soils have not yet recovered their original calcium content. What explains the lag between reduced acid rain and soil recovery?"
- "Climate projections for New Hampshire predict that spruce-fir forests, currently found at high elevations in the White Mountains, will shift to higher elevations or disappear from the state by 2100. What ecological and evolutionary factors determine how these forests will respond to climate change?"

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] Grade verified as 5, 8, or 11 ONLY
- [ ] PE code is a valid NGSS Performance Expectation
- [ ] Item is three-dimensional: DCI + SEP + CCC all identified
- [ ] Anchoring phenomenon is authentic and NH-relevant where possible
- [ ] Stimulus has clear labels, units, and realistic data
- [ ] CR prompt directs students to use evidence from the stimulus
- [ ] All distractors represent real misconceptions
- [ ] MS items specify how many answers to select
- [ ] Score 3 anchor response written before finalizing CR item
- [ ] Science content is accurate and current
- [ ] Vocabulary is grade-appropriate

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Writing items for Grades 3, 4, 6, or 7 | NH SAS Science is only at Grades 5, 8, 11 | Restrict to tested grades |
| DCI-only items (no SEP or CCC) | NH SAS requires three-dimensional items | Always embed a practice and a crosscutting concept |
| CR prompts without evidence directive | Students may respond without citing data | Include "Use evidence from the [data/graph/diagram]" |
| Generic stimulus not tied to NH | NH SAS favors NH phenomena | Anchor to NH-specific contexts |
| Multi-select with only 2 correct in 4 options | Too easy to guess | Use 5–6 options with 2–3 correct |
| Recall-only SR items | DOK 1 under-represented | Elevate most items to DOK 2 |

## 12. Prompt Patterns

### Pattern 1: Data-to-Conclusion (SR, DOK 2)
> "The [graph / table / diagram] below shows [NH science scenario]. Based on the data, which [conclusion / explanation / pattern] is BEST supported?"

### Pattern 2: Phenomenon Explanation (CR, DOK 3)
> "Scientists observed [NH-anchored phenomenon]. Using evidence from the [data / model / diagram], construct an explanation for [specific science focus]. Explain the [cause-and-effect / pattern / energy flow] relationship."

### Pattern 3: Model Evaluation (SR or MS, DOK 2–3)
> "A student made a model showing [science concept]. Which statement BEST describes what the model shows about [DCI focus]?"

### Pattern 4: Investigation Design (CR, DOK 3)
> "A scientist wants to investigate whether [variable] affects [outcome] in [NH ecosystem/context]. Describe a procedure the scientist could follow."

### Pattern 5: Evidence-Based Argument (CR, DOK 3)
> "Two students disagree about [science claim]. Using evidence from the [data / diagram], explain which student is correct and why."

### Pattern 6: Multi-Select Evidence (MS, DOK 2)
> "A student is investigating [NH science scenario]. Select the TWO [pieces of evidence / strategies / explanations] that BEST support the conclusion that [DCI-based claim]."
