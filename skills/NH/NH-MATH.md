## 1. Overview

| Field | Detail |
|---|---|
| **Assessment Name** | NH Statewide Assessment System (NH SAS) — Mathematics (Smarter Balanced) |
| **Consortium** | Smarter Balanced Assessment Consortium (SBAC) |
| **Administering Agency** | New Hampshire Department of Education (NH DOE) |
| **Grades Tested** | 3, 4, 5, 6, 7, 8, 11 |
| **Testing Window** | March – May (operational window; districts schedule within this range) |
| **Delivery** | Computer-adaptive (CAT) for Part 1 (non-calculator + calculator); fixed-form Performance Task for Part 2 |
| **Standards** | Common Core State Standards for Mathematics (CCSS-M) as adopted by New Hampshire |
| **Score Scale** | 2000–3000 scale score (varies by grade) |
| **Reporting** | Individual Student Report (ISR); School, District, State aggregate reports |

### Achievement Level Descriptors (ALDs)

| Level | Label | Description |
|---|---|---|
| 4 | **Standard Exceeded** | Student demonstrates sophisticated understanding of mathematical concepts and procedures; applies mathematics fluently in novel situations; constructs valid mathematical arguments |
| 3 | **Standard Met** | Student demonstrates adequate understanding of grade-level concepts and procedures; applies mathematics to real-world and mathematical problems with reasonable accuracy |
| 2 | **Standard Nearly Met** | Student demonstrates partial understanding; can apply procedures in familiar contexts but struggles with novel problems |
| 1 | **Standard Not Met** | Student demonstrates minimal understanding; unable to apply grade-level mathematical concepts or procedures |

> **Cut scores** are set by the Smarter Balanced Assessment Consortium and adopted by the New Hampshire State Board of Education. For item-writing purposes, target ALDs 3 and 4 as the proficiency range.

## 4. Claims & Blueprint

### Claim Structure

| Claim | Description | Point Weight | Primary Focus |
|---|---|---|---|
| **Claim 1 — Concepts & Procedures** | Students can explain and apply mathematical concepts and carry out mathematical procedures with precision and fluency | **40%** | Procedural fluency; conceptual understanding |
| **Claim 2 — Problem Solving** | Students can solve a range of complex well-posed problems in pure and applied mathematics | **25%** | Multi-step problems; strategy selection; real-world contexts |
| **Claim 3 — Communicating Reasoning** | Students can clearly and precisely construct viable arguments to support their own reasoning and to critique the reasoning of others | **20%** | Explanation; justification; error analysis |
| **Claim 4 — Modeling & Data Analysis** | Students can analyze complex, real-world scenarios and can construct and use mathematical models to interpret and solve problems | **15%** | Modeling; data interpretation; multi-step real-world scenarios |

### Subclaims

#### Claim 1 — Concepts & Procedures Subclaims

| Subclaim | Description |
|---|---|
| **1A** | Apply mathematics to solve everyday problems (routine applications) |
| **1B** | Select and use appropriate tools strategically |
| **1C** | Attend to precision |
| **1D** | Look for and make use of structure |
| **1E** | Look for and express regularity in repeated reasoning |

#### Claim 2 — Problem Solving Subclaims

| Subclaim | Description |
|---|---|
| **2A** | Apply mathematics to solve well-posed problems |
| **2B** | Select and use appropriate tools strategically |
| **2C** | Interpret results in context |

#### Claim 3 — Communicating Reasoning Subclaims

| Subclaim | Description |
|---|---|
| **3A** | Test propositions with specific examples |

| **3C** | State logical assumptions |
| **3D** | Break an argument into cases |

## 5. Item Types & Formats

### SR — Selected Response (1 point)

```
+----------------------------------------------------------------+
|  [Stimulus: problem context, diagram, table, or equation]       |
|                                                                 |
|  Question stem targeting a specific standard and claim.         |
|                                                                 |
|  O  A. [Numerical / expression answer — plausible distractor]   |
|  O  B. [Numerical / expression answer — common error]           |
|  O  C. [Numerical / expression answer — CORRECT]                |
|  O  D. [Numerical / expression answer — off-track distractor]   |
+----------------------------------------------------------------+
Points: 1 (correct) / 0 (incorrect)
```

**Construction Rules:**
- Distractors must reflect real student errors
- Numerical answers should not reveal the correct answer through magnitude ordering
- Diagrams and tables must be clearly labeled

---

### MS — Multi-Select (1 point)

```
+----------------------------------------------------------------+
|  [Problem context or mathematical statement]                    |
|                                                                 |
|  Select the TWO [equations / values / expressions] that...     |
|                                                                 |
|  [ ]  A. [Option]                                               |
|  [ ]  B. [Option — CORRECT]                                     |
|  [ ]  C. [Option]                                               |
|  [ ]  D. [Option — CORRECT]                                     |
|  [ ]  E. [Option]                                               |
|  [ ]  F. [Option]                                               |
+----------------------------------------------------------------+
Points: 1 (all correct, none incorrect) / 0 (any error)
```

---

### EQ — Equation / Numeric Entry (1 point)

```
+----------------------------------------------------------------+
|  [Problem context: real-world scenario or pure math]            |
|                                                                 |
|  What is the value of [EXPRESSION / VARIABLE / QUANTITY]?      |
|                                                                 |
|  Enter your answer in the box.                                  |
|  +---------------+                                              |
|  |               |  [numeric / expression entry field]         |
|  +---------------+                                              |
+----------------------------------------------------------------+
Points: 1 (exact correct value or equivalent expression) / 0
```

---

### SCR — Short Constructed Response (0–2 points)

```
+----------------------------------------------------------------+
|  [Problem context — multi-step real-world scenario]             |
|                                                                 |
|  [PART A — Computational or procedural question]                |
|  [PART B — "Explain how you know" or "Show your work"]          |
|                                                                 |
|  +----------------------------------------------------------+  |
|  |  [Student response area — text input + scratchpad]        |  |
|  +----------------------------------------------------------+  |
+----------------------------------------------------------------+
Points: 0–2 (see rubric, Section 8)
```

---

### PT-ER — Performance Task Extended Response (0–6 points, multi-part)

```
+----------------------------------------------------------------+
|  PERFORMANCE TASK — EXTENDED RESPONSE                           |
|                                                                 |
|  SCENARIO:                                                      |
|  [3–5 sentence real-world context]                              |
|  [Data tables, diagrams, or charts]                             |
|                                                                 |
|  Part A: [Introductory computation or setup question]           |
|  Part B: [Intermediate reasoning or application question]       |
|  Part C: [Complex extension — explain, justify, model]          |
+----------------------------------------------------------------+
Points: 0–2 per part x 3 parts = 0–6 total
```

## 6. DOK / Cognitive Complexity

### DOK Level Descriptions for Mathematics

| DOK | Label | Description | Example Tasks |
|---|---|---|---|
| **1** | Recall & Reproduction | Recall a fact; perform a routine single-step procedure; read a value from a graph | *calculate, identify, recall, use, recognize, measure* |
| **2** | Skills & Concepts | Solve a multi-step problem; classify or organize; make inferences from data | *classify, organize, estimate, compare, interpret, solve [multi-step], apply* |
| **3** | Strategic Thinking | Solve non-routine problems; justify or prove a claim; analyze errors; design a model | *justify, prove, analyze, evaluate, formulate, critique, explain reasoning* |
| **4** | Extended Thinking | Multi-stage investigations; synthesize across domains; design and evaluate complex models | *synthesize, design, evaluate [complex], connect, create* |

> DOK 4 appears primarily in PT Extended Response Part C items.

### DOK Distribution Targets for Item Generation

| Item Type | Target DOK | Rationale |
|---|---|---|
| SR — single computation | 1 | Routine procedure |
| SR — two-step word problem | 2 | Application + computation |
| MS — identify equivalent forms | 1–2 | Depends on conceptual demand |
| EQ — numeric entry | 1–2 | Procedural; contextual use raises to DOK 2 |
| SCR — explain reasoning | 3 | Justification required |
| PT-ER Part A | 2 | Setup computation |
| PT-ER Part B | 2–3 | Application or partial modeling |
| PT-ER Part C | 3–4 | Full modeling, justify, evaluate |

## 8. Scoring Rubrics

### SCR — Short Constructed Response (0–2 Points)

| Score | Descriptor |
|---|---|
| **2** | Thorough understanding demonstrated; correct solution with clear, accurate explanation or justification; work is logical and complete. |
| **1** | Partial understanding; partially correct solution or correct solution with incomplete explanation; OR correct answer with no explanation. |
| **0** | Incorrect, irrelevant, or no mathematical understanding demonstrated. Blank = 0. |

### PT-ER — Performance Task Extended Response (0–6 Points)

#### Part A (0–2), Part B (0–2), Part C (0–2)

| Score | Part A | Part B | Part C |
|---|---|---|---|
| **2** | Correct setup and solution; calculations correct; units identified | Correctly applies Part A results; clear reasoning | Sophisticated reasoning; mathematical results used to justify decision |
| **1** | Correct approach with computational error or incomplete solution | Partial understanding; correct reasoning with wrong value OR correct conclusion with weak support | Some correct reasoning or partially valid justification |
| **0** | Incorrect, missing, or no understanding | Incorrect, missing, or no understanding | Incorrect, off-task, or unsupported assertions |

#### Error Carried Forward (ECF) Policy

If a student carries an incorrect value from Part A into Parts B and C but applies correct reasoning, award full credit for that part. ECF applies only to simple computational mistakes, not conceptual misunderstandings.

## 10. Contextualization

### New Hampshire–Specific Mathematics Context Bank

Item writers should anchor scenarios in authentic New Hampshire contexts to maximize student engagement.

#### Geography & Natural Features

| Topic | Mathematical Applications |
|---|---|
| **Mount Washington weather data** | Temperature ranges (summit avg: 27F annual, record low -47F, record high 72F); wind speed data (record 231 mph); rate of temperature change with altitude; data analysis; graphing; mean/median; comparison with base station data |
| **White Mountains elevation data** | Elevation gain/loss; slope calculations; Mount Washington (6,288 ft), Mount Adams (5,774 ft), Mount Jefferson (5,712 ft); distance-rate-time for hiking; comparing peak heights; proportional reasoning with map scales |
| **Lake Winnipesaukee dimensions** | Area calculations (72 square miles); perimeter/shoreline (182 miles); island counts (274); unit conversion; ratio and proportion; volume estimation; depth data analysis |
| **NH state park distances** | Distance-rate-time; proportional relationships; map scale; coordinate geometry; trail distances and elevation profiles |

#### Industry & Community

| Topic | Mathematical Applications |
|---|---|
| **NH granite industry** | Volume calculations; weight and density; unit conversion; data analysis of quarry production; historical production statistics |
| **NH tourism statistics** | Large numbers; percent; ratios; seasonal visitor data; economic impact calculations; White Mountain National Forest (~800,000 acres) |
| **NH school and community data** | Enrollment statistics; per-pupil spending; ratios; percentages; state population (~1.4 million) |
| **NH agricultural data** | Apple orchards; dairy farms; maple syrup production; farmers market pricing; unit rates |

### Grade-Band Contextualization Notes

#### Grades 3–5

| Principle | Guidance |
|---|---|
| **Concreteness** | Tangible quantities (trail distances, apples picked, rocks collected) |
| **Accessibility** | Avoid specialized vocabulary; define NH-specific terms |
| **Scale of numbers** | Gr 3: within 1,000; Gr 5: multi-digit, decimals, fractions |

#### Grades 6–8

| Principle | Guidance |
|---|---|
| **Real data** | Use approximate real data (Mount Washington 6,288 ft; Lake Winnipesaukee 72 sq mi; NH population ~1.4 million) |
| **Multiple representations** | Include tables, graphs, diagrams |
| **Social relevance** | Tourism economics, weather data, environmental topics |

#### Grade 11

| Principle | Guidance |
|---|---|
| **Workforce readiness** | Career-relevant contexts (tourism, technology, healthcare, forestry) |
| **Complex data** | Multi-variable data sets; scatter plots; regression |
| **Equity lens** | Include data representing NH's diversity |

### English Learner (EL) Considerations for Math

| Consideration | Guidance |
|---|---|
| **Mathematical vocabulary** | Pre-teach or define Tier 3 math vocabulary |
| **Word problem language** | Simple, direct sentence structure |
| **Bilingual glossary** | EL designated support; items should not be invalidated by glossary use |
| **Diagrams and visuals** | Clear, labeled diagrams to reduce linguistic load |

## 11. Quality Checklist

### Standards Alignment

- [ ] Item is tagged to one primary CCSS Math standard
- [ ] Standard matches the claim and subclaim
- [ ] DOK level is consistent with the cognitive demand
- [ ] Grade-level standard is appropriate

### Calculator Policy

- [ ] Item is flagged as calculator or non-calculator per grade-level policy
- [ ] Computational complexity matches calculator policy

### Reference Sheet

- [ ] Grades 8 and 11: item does not embed reference sheet formulas
- [ ] Grades 3–7: item does not require formulas not taught at grade level

### Item Quality (All Types)

- [ ] Stem is clear and unambiguous
- [ ] Numerical values are internally consistent
- [ ] Units clearly specified
- [ ] Diagrams clearly labeled with alt text
- [ ] SR distractors are plausible and represent specific errors
- [ ] Correct answer verified independently
- [ ] Context is realistic and meaningful

### SCR and PT-ER Checks

- [ ] Prompt requires both answer AND explanation
- [ ] Rubric included
- [ ] PT-ER parts are interdependent (A -> B -> C)
- [ ] ECF policy noted
- [ ] Common errors anticipated in scoring guide

### EL and Accessibility

- [ ] Clear, concise language
- [ ] Grade-appropriate vocabulary
- [ ] Diagrams usable with zoom/magnification
- [ ] No cultural knowledge disadvantaging EL students

## 12. Prompt Patterns

---

### Pattern 1: "Generate a math problem for Grade [X]"

**Interpretation:** Default to SR (1 point) for Claim 1 at DOK 2.

**Generation Recipe:**
1. Identify primary content domain for the grade
2. Select NH context from Section 10
3. Generate SR using Template 1 with two mathematical steps
4. Tag: state=NH, subject=MATH, grade=[X], claim=2, dok=2

---

### Pattern 2: "Generate a word problem that requires explanation"

**Interpretation:** Generate SCR (0–2 points) for Claim 3 at DOK 3.

**Generation Recipe:**
1. Select multi-step context from Section 10
2. Build Part A (computational, DOK 2) and Part B (justification, DOK 3)
3. Include scoring guide
4. Tag: state=NH, subject=MATH, grade=[X], claim=3, dok=3

---

### Pattern 3: "Generate a Performance Task math problem for Grade [X]"

**Interpretation:** Generate full PT-ER using Template 3.

**Generation Recipe:**
1. Choose multi-faceted NH context (Mount Washington data, Lake Winnipesaukee measurements, tourism statistics)
2. Create realistic data set
3. Scaffold Parts A (DOK 2), B (DOK 2–3), C (DOK 3–4)
4. Include rubric and ECF note
5. Tag: state=NH, subject=MATH, grade=[X], claim=4, dok=3-4

---

### Pattern 4: "Generate a set of math items covering multiple domains"

**Interpretation:** Generate mini-assessment covering 3–4 domains.

**Generation Recipe:**
1. Identify 3–4 primary domains for the grade
2. Generate: 1–2 SR (DOK 1–2), 1 MS (DOK 2), 1 EQ (DOK 1–2)
3. Distribute calculator per policy
4. Include standards and DOK summary table
5. Tag each item individually
