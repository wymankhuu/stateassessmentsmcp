### Achievement Level Descriptors (ALDs)

| Level | Label | Description |
|---|---|---|
| 4 | **Standard Exceeded** | Student demonstrates thorough understanding of concepts and procedures; sophisticated analysis; precise use of evidence from complex texts |
| 3 | **Standard Met** | Student demonstrates adequate understanding; appropriate analysis; uses relevant evidence from grade-level texts |
| 2 | **Standard Nearly Met** | Student demonstrates partial understanding; limited analysis; inconsistent use of evidence; needs support to access grade-level text |
| 1 | **Standard Not Met** | Student demonstrates minimal understanding; little to no evidence use; significant gaps relative to grade-level expectations |

> **Cut scores** are set by the Smarter Balanced Assessment Consortium and adopted by the New Hampshire State Board of Education. For item-writing purposes, focus on ALDs 3 and 4 as the target proficiency range.

## 2. Standards Framework

> **Reference:** See `_shared/ccss_ela_framework.md` for full CCR Anchor Standards and grade-by-grade progressions. This section highlights the key standards most heavily tested on NH SAS ELA.

### Reading Literature (RL) — Key Standards by Grade Band

| Standard | Gr 3–5 Focus | Gr 6–8 Focus | Gr 11 Focus |
|---|---|---|---|
| **RL.1** — Key details & inference | Explicit details; simple inference | Textual evidence for inference | Cite strong and thorough textual evidence |
| **RL.2** — Central idea / theme | Determine main message or lesson | Theme + how it is conveyed | Two or more themes; complex analysis |
| **RL.3** — Character, setting, events | Describe characters' traits and motivations | Analyze character development | Analyze impact of author's choices |
| **RL.4** — Word meaning | Determine meaning of words and phrases | Figurative language, connotations | Nuanced meanings, tone |
| **RL.6** — Point of view | Identify narrator's point of view | Analyze how POV shapes content | Evaluate unreliable narrators |
| **RL.9** — Compare / contrast texts | Compare similar themes across texts | Analyze how modern works draw on earlier | Demonstrate knowledge of 18th–20th century works |

### Reading Informational Text (RI) — Key Standards by Grade Band

| Standard | Gr 3–5 Focus | Gr 6–8 Focus | Gr 11 Focus |
|---|---|---|---|
| **RI.1** — Cite evidence | Refer explicitly to text | Cite textual evidence | Cite strong and thorough evidence |
| **RI.2** — Central idea | Main idea + key details | Analyze development of central idea | Determine two or more central ideas |
| **RI.3** — Connections | Describe relationships (compare/contrast, cause/effect) | Analyze how text makes connections and distinctions | Analyze sequence of events or ideas |
| **RI.6** — Author's purpose | Distinguish own point of view from author's | Determine author's point of view/purpose | Evaluate author's point of view and rhetoric |
| **RI.8** — Argument & evidence | Describe how reasons support points | Trace and evaluate argument | Evaluate effectiveness of evidence |
| **RI.9** — Integrate information | Compare texts on same topic | Analyze how texts address similar topics differently | Synthesize information from multiple sources |

### Writing (W) — Key Standards

| Standard | Description | NH SAS Claim |
|---|---|---|
| **W.1** | Write arguments with claims, reasons, and evidence | Claim 2 — Full Write; PT-FW argumentative |
| **W.2** | Write informative/explanatory texts | Claim 2 — Full Write; PT-FW informational |
| **W.3** | Write narratives | Claim 2 — occasionally, lower grades |
| **W.4** | Produce clear and coherent writing | Claim 2 — all writing tasks |
| **W.7** | Conduct short research projects | Claim 4 — Research |
| **W.8** | Gather relevant information from sources | Claim 4 — Research |
| **W.9** | Draw evidence from texts | Claims 2 and 4 |

### Language (L) — Key Standards

| Standard | Description |
|---|---|
| **L.1** | Grammar and usage conventions |
| **L.2** | Capitalization, punctuation, spelling |
| **L.4** | Determine word meanings (context clues, affixes, reference materials) |
| **L.5** | Figurative language, word relationships |
| **L.6** | Academic and domain-specific vocabulary |

## 5. Item Types & Formats

### SR — Selected Response (1 point)

Standard four-option multiple-choice. Student selects one best answer.

```
+----------------------------------------------------------------+
|  Read the following passage. Then answer the question.          |
|                                                                 |
|  [PASSAGE TEXT — 200–800 words depending on grade]              |
|                                                                 |
|  Question stem that targets a specific standard (RL/RI/L).      |
|                                                                 |
|  O  A. [Plausible distractor — partially correct]               |
|  O  B. [Correct answer — directly supported by text]            |
|  O  C. [Plausible distractor — common misconception]            |
|  O  D. [Plausible distractor — out of scope]                    |
+----------------------------------------------------------------+
Points: 1 (correct) / 0 (incorrect)
```

**Construction Rules:**
- All four options must be plausible; no obviously wrong answers
- Correct answer must be unambiguously supported by passage text
- Distractors should represent real student errors (misreading, overgeneralization)
- Avoid "All of the above" / "None of the above"
- Stem must be a complete question or clear directive

---

### MS — Multi-Select (1 point)

Student selects ALL correct answers from a set of typically five or six options. Full credit only when all correct options are selected and no incorrect options are selected.

```
+----------------------------------------------------------------+
|  Read the passage. Then answer the question.                    |
|                                                                 |
|  Question stem — note: "Select ALL that apply" or              |
|  "Select the TWO answers that..."                               |
|                                                                 |
|  [ ]  A. [Option]                                               |
|  [ ]  B. [Option — CORRECT]                                     |
|  [ ]  C. [Option]                                               |
|  [ ]  D. [Option — CORRECT]                                     |
|  [ ]  E. [Option]                                               |
|  [ ]  F. [Option]                                               |
+----------------------------------------------------------------+
Points: 1 (all correct selected, none incorrect) / 0 (any other)
```

**Construction Rules:**
- Specify the number of correct answers in the stem when count is fixed ("Select the TWO...")
- When count is unspecified, use "Select ALL that apply"
- Typically 2–3 correct answers from a field of 5–6
- Each option should be independently evaluable against the text

---

### EBSR — Evidence-Based Selected Response (2 points, two-part)

Part A is a standard SR question. Part B asks students to select the evidence from the text that best supports their Part A answer.

```
+----------------------------------------------------------------+
|  PART A                                                         |
|                                                                 |
|  What is the central idea of the passage?                       |
|                                                                 |
|  O  A. [Distractor]                                             |
|  O  B. [CORRECT — central idea statement]                       |
|  O  C. [Distractor]                                             |
|  O  D. [Distractor]                                             |
|                                                                 |
+----------------------------------------------------------------+
|  PART B                                                         |
|                                                                 |
|  Which detail from the passage BEST supports the answer to      |
|  Part A?                                                        |
|                                                                 |
|  O  A. "[Direct quote — supports distractor A]"                 |
|  O  B. "[Direct quote — CORRECT; supports central idea]"        |
|  O  C. "[Direct quote — tangentially related]"                  |
|  O  D. "[Direct quote — supports distractor C]"                 |
+----------------------------------------------------------------+
Scoring: Part A correct = 1 pt; Part B correct = 1 pt
Note: Part B correct without Part A correct = 0 pts for Part B
Total possible: 2 points
```

**Construction Rules:**
- Part B options must be direct quotes or very close paraphrases from the passage
- Each Part B distractor should be a plausible piece of evidence for one of the Part A distractors
- The correct Part B quote must unambiguously support the correct Part A answer
- Assign standard codes to both parts (e.g., RI.5.2 and RI.5.1)

### PT-FW — Performance Task Full Write (12 points, three traits)

```
+----------------------------------------------------------------+
|  PERFORMANCE TASK — FULL WRITE                                  |
|                                                                 |
|  You have read the following sources:                           |
|    Source 1: "[Title 1]" — [type: article, speech, excerpt]     |
|    Source 2: "[Title 2]" — [type]                               |
|    Source 3: "[Title 3]" — [type, Gr 6+ only]                   |
|                                                                 |
|  PROMPT:                                                        |
|  [Argumentative or Informational framing sentence]              |
|  Write a well-developed [essay/article/letter] in which you     |
|  [argue a position / explain / analyze].                        |
|                                                                 |
|  Use evidence from at least TWO of the sources to support       |
|  your [argument / explanation]. Be sure to:                     |
|    - Introduce your topic and state your [claim/thesis]         |
|    - Develop your ideas with relevant evidence and elaboration  |
|    - Use transitions to organize your ideas                     |
|    - Maintain a formal style and appropriate tone               |
|    - Provide a concluding section                               |
|                                                                 |
|  [Text input box — full word processor with spell check]        |
+----------------------------------------------------------------+
Scoring: 0–4 Organization/Purpose + 0–4 Evidence/Elaboration
         + 0–4 Conventions = 0–12 raw points
```

---

### PT-ST — Performance Task Short Text (2 points)

```
+----------------------------------------------------------------+
|  PERFORMANCE TASK — SHORT TEXT                                  |
|                                                                 |
|  You have read the sources listed above.                        |
|                                                                 |
|  Question: What does [Source 1] say about [topic]? How does    |
|  [Source 2] support or challenge this idea? Use evidence        |
|  from BOTH sources in your response.                            |
|                                                                 |
|  [Text input box — 3–5 sentence response expected]              |
+----------------------------------------------------------------+
Scoring: 0–2 points
  2 — Adequate evidence from both sources; clear connection
  1 — Evidence from only one source OR connection is vague
  0 — Off task, no evidence, or copied text only
```

## 6. DOK / Cognitive Complexity

### DOK Level Descriptions for ELA

| DOK | Label | Description | Example Verbs |
|---|---|---|---|
| **1** | Recall & Reproduction | Locate explicitly stated information; identify a defined term; recall a plot event | *identify, recall, locate, define, recognize, list* |
| **2** | Skills & Concepts | Make inferences; determine author's purpose; compare two ideas within a text; explain cause-effect; determine word meaning from context | *infer, explain, compare, classify, organize, summarize, interpret* |
| **3** | Strategic Thinking | Analyze how structural choices affect meaning; evaluate strength of evidence; synthesize across multiple texts; justify an interpretation with multiple pieces of evidence | *analyze, evaluate, justify, synthesize, critique, construct, formulate* |

> NH SAS ELA does not formally use DOK 4 on the summative assessment. Extended inquiry occurs in the PT but is scored through the three traits rather than a DOK 4 designation.

### DOK Distribution Targets for Item Generation

| Item Type | Target DOK | Rationale |
|---|---|---|
| SR — vocabulary in context | 1–2 | Primarily definitional; some inferential |
| SR — key details | 1–2 | Locate and explain; may require inference |
| SR — central idea / theme | 2–3 | Requires synthesis beyond literal reading |
| MS — evidence | 2–3 | Evaluate multiple pieces of evidence |
| EBSR | 2–3 | Part A often DOK 2; Part B requires justification (DOK 3) |
| PT-ST | 2–3 | Integrate evidence from two sources |
| PT-FW | 3 | Full argumentation with multi-source evidence |

### Passage Requirements

| Requirement | Specification |
|---|---|
| **Genre balance** | Literary and informational in roughly equal proportion across a test form |
| **Source authenticity** | Passages must be authentic published works OR high-quality original passages that simulate authentic style and purpose |
| **Cultural representation** | Passages should reflect diverse authors, subjects, and cultural perspectives |
| **Bias and sensitivity** | No depictions of violence, overtly partisan political content, religious advocacy, or brand names |
| **Artwork/Graphics** | Informational passages may include charts, diagrams, photographs (described in alt text) |
| **PT source sets** | 2 sources at Grades 3–5; 3 sources at Grades 6–8 and 11 |

## 8. Scoring Rubrics

### PT-FW Full Write — Three-Trait Rubric (0–4 each)

#### Trait 1: Organization / Purpose

| Score | Descriptor |
|---|---|
| **4** | Clear and effective organizational structure; compelling, fully elaborated controlling idea; varied transitions that consistently aid comprehension. |
| **3** | Evident organizational structure; adequately elaborated controlling idea; transitions generally appropriate with minor lapses. |
| **2** | Some evidence of structure, but formulaic or inconsistent; vague or insufficiently developed controlling idea. |
| **1** | Little or no organizational structure; controlling idea underdeveloped or hard to identify; minimal transitions. |
| **0** | Completely irrelevant, copied, too brief to assess, or in a language other than English. |

#### Trait 2: Evidence / Elaboration

| Score | Descriptor |
|---|---|
| **4** | Thorough, convincing support; evidence integrated from at least two sources; precise, varied vocabulary. |
| **3** | Adequate support; relevant evidence from sources; generally appropriate vocabulary. |
| **2** | Partial or uneven support; vague, repetitive, or single-source evidence; basic vocabulary. |
| **1** | Minimal support; evidence largely absent or unelaborated; predominantly basic vocabulary. |
| **0** | See Trait 1 score-point 0 conditions. |

#### Trait 3: Conventions

| Score | Descriptor |
|---|---|
| **4** | Consistent command of grammar, usage, capitalization, punctuation, and spelling; varied sentence structure. |
| **3** | Adequate command; some errors present but do not substantially impede meaning. |
| **2** | Partial command; noticeable errors may occasionally impede meaning. |
| **1** | Limited command; frequent errors significantly impede meaning. |
| **0** | See Trait 1 score-point 0 conditions. |

---

### PT-ST Short Text — 2-Point Rubric

| Score | Descriptor |
|---|---|
| **2** | Clearly addresses the question; relevant, specific evidence from both sources; explicit, logical connection. |
| **1** | Partially addresses the question; evidence from only one source or loosely connected. |
| **0** | Off topic, no source evidence, copied text, too brief, or in a language other than English. |

## 10. Contextualization

### New Hampshire–Specific Topic Bank

Item writers should anchor passages and scenarios in authentic New Hampshire contexts when possible. This increases ecological validity and engagement for NH students.

#### Geography & Environment

| Topic | Details for Item Use |
|---|---|
| **White Mountains** | Presidential Range; Mount Washington (6,288 ft, highest peak in the Northeast); Franconia Notch; Old Man of the Mountain (collapsed 2003, cultural significance); Appalachian Mountain Club huts; alpine ecology above treeline; White Mountain National Forest |
| **Robert Frost and New Hampshire** | Frost lived in Derry and Franconia; "Stopping by Woods on a Snowy Evening," "The Road Not Taken," "Mending Wall"; New Hampshire landscapes as literary inspiration; Frost's poetry about rural life, nature, and human choices; Pulitzer Prize–winning poet |
| **Lake Winnipesaukee** | Largest lake in New Hampshire; 72 square miles; 274 islands; 182 miles of shoreline; tourism and recreation economy; water quality and conservation; Abenaki name meaning "smile of the Great Spirit" |
| **Granite Quarrying** | "The Granite State" nickname; Concord granite used in the Library of Congress; quarrying history and techniques; economic significance; geological origins of New Hampshire granite |
| **NH Primary Elections** | First-in-the-nation presidential primary since 1920; civic engagement tradition; media and political significance; deliberative democracy in small-town settings; informational and argumentative passage topics |

#### History & Culture

| Topic | Suggested Use |
|---|---|
| **Textile Mill History** | Amoskeag Manufacturing Company in Manchester — once the largest textile mill in the world; Industrial Revolution in New England; immigration and labor history; mill architecture and adaptive reuse; primary source documents |
| **New Hampshire Statehood** | Ninth state to ratify the Constitution (decisive vote); "Live Free or Die" motto (General John Stark); New Hampshire's role in the founding era; constitutional convention |
| **Abenaki Heritage** | Western Abenaki people and traditional lands; cultural traditions; contemporary presence; respectful, accurate representation in passages |

#### Science & Current Events Contexts

| Topic | Suggested Use |
|---|---|
| **Mount Washington Weather** | Informational passages on extreme weather (world record wind speed of 231 mph held until 1996); observatory operations; weather research; cause-and-effect science writing |
| **White Mountain Tourism and Conservation** | Argumentative/informational; balancing recreation with environmental protection; AMC hut system; trail erosion; Leave No Trace principles |
| **New Hampshire Energy** | Renewable energy debates; wind power in the White Mountains; hydroelectric dams on the Connecticut and Merrimack Rivers; community energy decisions |

### English Learner (EL) Considerations

New Hampshire's EL population includes speakers of Spanish, Arabic, Nepali, Swahili, Portuguese, and various Southeast Asian languages, concentrated in Manchester, Concord, and Nashua. Item writers should:

| Consideration | Guidance |
|---|---|
| **Vocabulary** | Avoid idioms relying on cultural knowledge not shared by EL students; define domain-specific terms |
| **Sentence structure** | Use clear, well-formed sentences in stems and options |
| **Bilingual glossaries** | Designated support; passages should not be invalidated by glossary use |
| **Cultural familiarity** | Include contexts reflecting NH's diverse immigrant and refugee communities |
| **Stimulus art/photography** | When used, images should be inclusive and contextually supportive |

## 11. Quality Checklist

Use this checklist before finalizing any generated item or item set.

### Standards Alignment

- [ ] Item is tagged to one primary CCSS ELA standard (e.g., RI.6.2)
- [ ] Standard matches the claim and target subclaim
- [ ] DOK level is consistent with the cognitive demand of the task
- [ ] Grade-level standard is appropriate for the intended grade band

### Passage Requirements

- [ ] Passage Lexile falls within the target range for the grade (see Section 7)
- [ ] Passage is authentic or high-quality original writing
- [ ] Passage topic is appropriate (no bias, violence, religion, or brand names)
- [ ] Passage length is appropriate for the item type and grade
- [ ] Informational passages cite data accurately; no invented statistics

### Item Quality (All Types)

- [ ] Stem is a clear, complete question or directive
- [ ] All options are plausible (no obviously wrong distractors)
- [ ] Correct answer is unambiguously supported by the passage
- [ ] No grammatical clues in options (all options parallel in form and length)
- [ ] No "All of the above" or "None of the above" options
- [ ] Correct answer position rotated across an item set
- [ ] Item can be answered from the passage alone; no prior knowledge required

### EBSR-Specific Checks

- [ ] Part B options are direct quotes or near-quotes from the passage
- [ ] Each Part B distractor logically corresponds to a Part A distractor
- [ ] Correct Part B quote unambiguously supports correct Part A answer

### PT-FW Checks

- [ ] Source set includes 2 sources (Gr 3–5) or 3 sources (Gr 6–11)
- [ ] Sources represent at least two different perspectives
- [ ] Prompt clearly specifies writing type (argumentative or informational)
- [ ] Prompt includes "be sure to" checklist
- [ ] Rubric dimensions align to the three SBAC ELA FW traits

### EL and Accessibility

- [ ] No idioms or culturally exclusive references in item stems
- [ ] Text-to-speech compatible
- [ ] Item is appropriate for New Hampshire's diverse student population

## 12. Prompt Patterns

The following patterns map common user requests to generation strategies for the AI.

---

### Pattern 1: "Generate a reading comprehension item for Grade [X]"

**Interpretation:** Default to an EBSR (2-point, two-part) item for Claim 1 (Reading). Use DOK 2 for Grades 3–5, DOK 3 for Grades 6–11.

**Generation Recipe:**
1. Select or generate a passage at the appropriate Lexile (Section 7)
2. Identify the primary target standard (RL or RI based on genre)
3. Generate EBSR using Template 1 (Gr 3–5) or Template 2 (Gr 6–8)
4. Ensure Part B options are direct quotes from the passage
5. Tag item: state=NH, subject=ELA, grade=[X], claim=1A or 1B, dok=[2 or 3]

---

### Pattern 2: "Generate a Performance Task writing prompt for Grade [X]"

**Interpretation:** Generate a full PT package: source set description + PT-ST question + PT-FW argumentative or informational prompt.

**Generation Recipe:**
1. Choose a grade-appropriate debatable or explanatory topic (Section 10 New Hampshire topics strongly preferred)
2. Draft 2–3 source descriptions with Lexile and angle noted
3. Write PT-ST question requiring evidence from both sources
4. Write PT-FW prompt following Template 3 format
5. Include scoring rubric (Section 8) in the output
6. Tag: state=NH, subject=ELA, grade=[X], claim=2B+2C, dok=3

---

### Pattern 3: "Generate a vocabulary item"

**Interpretation:** Generate an SR item targeting L.[GRADE].4.a using Template 4.

**Generation Recipe:**
1. Select a passage excerpt with a Tier 2 or Tier 3 target word
2. Use Template 4 exactly
3. Construct four options: one correct, three plausible but wrong
4. Tag: state=NH, subject=ELA, grade=[X], claim=1A or 1B, standard=L.[X].4.a, dok=2

---

### Pattern 4: "Generate a multi-select item about author's purpose"

**Interpretation:** Generate an MS item for Claim 1, targeting RI/RL.[GRADE].6.

**Generation Recipe:**
1. Provide or reference a passage with clear authorial purpose
2. Stem: "Select the TWO [reasons / examples / details] that show how the author develops [purpose/point of view]."
3. Generate 5–6 options: 2–3 correct, 2–3 distractors
4. Tag: state=NH, subject=ELA, grade=[X], claim=1A or 1B, dok=2–3

---

### Pattern 5: "Generate a complete practice set for Grade [X]"

**Interpretation:** Generate a mini-assessment package with one passage set and items across all major NH SAS item types.

**Generation Recipe:**
1. Select or generate one literary passage and one informational passage at the appropriate Lexile
2. Generate items: 2–3 SR (DOK 1–2), 1 MS (DOK 2–3), 1–2 EBSR (DOK 2–3), 1 PT-ST (DOK 2–3), 1 PT-FW (DOK 3)
3. Tag each item with claim, subclaim, standard, DOK
4. Include scoring rubrics for PT-ST and PT-FW
