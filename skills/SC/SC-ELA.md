|-------|--------------------|----------------------------------------------------------------------|

## 2. STANDARDS FRAMEWORK

### South Carolina College- and Career-Ready Standards for ELA

SC adopted its College- and Career-Ready Standards in 2015. The standards are organized by strand with grade-level indicators.

**Strand Overview:**

| Strand           | Description                                                    |
|------------------|----------------------------------------------------------------|
| Reading Literary | Analysis of fiction, poetry, drama (RL standards)              |
| Reading Informational | Analysis of nonfiction, argument, and functional text (RI standards) |
| Writing          | Narrative, informational/explanatory, and argument writing (W standards) |
| Communication    | Speaking, listening, and collaborative discussion (C standards)|
| Language         | Vocabulary, grammar, and conventions (L standards)             |
| Inquiry          | Research, inquiry-based reading and writing (I standards)      |

### Key Reading Standards — Literary Text

| Standard Code | Description                                                                                      |
|---------------|--------------------------------------------------------------------------------------------------|
| RL.X.1        | Cite textual evidence to support analysis of what the text says explicitly and inferentially      |
| RL.X.2        | Determine a theme or central message and analyze its development over the course of the text      |
| RL.X.3        | Analyze how characters, settings, and events interact and develop throughout the text             |
| RL.X.4        | Determine the meaning of words and phrases, including figurative and connotative meanings         |
| RL.X.5        | Analyze the structure of the text and how sections contribute to the whole                        |
| RL.X.6        | Explain how the author develops the point of view or perspective of the narrator or speaker       |

### Key Reading Standards — Informational Text

| Standard Code | Description                                                                                      |
|---------------|--------------------------------------------------------------------------------------------------|
| RI.X.1        | Cite textual evidence to support analysis of what the text says explicitly and inferentially      |
| RI.X.2        | Determine a central idea and analyze how it is conveyed through particular details                |
| RI.X.3        | Analyze how key individuals, events, or ideas are introduced, illustrated, and elaborated         |
| RI.X.4        | Determine the meaning of domain-specific and academic vocabulary in context                       |
| RI.X.5        | Analyze the structure an author uses to organize a text and how sections relate                   |
| RI.X.8        | Trace and evaluate the argument and specific claims in a text, including validity of reasoning    |

### Key Vocabulary and Language Standards

| Standard Code | Description                                                                                      |
|---------------|--------------------------------------------------------------------------------------------------|
| L.X.4         | Determine or clarify the meaning of unknown words using context clues, affixes, and reference     |
| L.X.5         | Demonstrate understanding of figurative language, word relationships, and nuances in word meanings|
| L.X.6         | Acquire and use accurately grade-appropriate academic and domain-specific vocabulary              |

> **Coding Note:** Replace X with the actual grade number. For example, Grade 5 theme standard is **RL.5.2**. SC standards use this RL/RI/W/L coding system.

## 3. TEST STRUCTURE

SC READY ELA is administered across **2 sessions** over one or two days.

```
+-------------------------------------------------------------------+
|            SC READY ELA TEST STRUCTURE (Grades 3–8)               |
+---------------------------------+---------------------------------+
|   SESSION 1                     |   SESSION 2                     |
|   ~60–75 minutes                |   ~60–75 minutes                |
|                                 |                                 |
|  READING COMPREHENSION          |  READING + WRITING              |
|  - Literary passage(s)          |  - Informational passage(s)     |
|  - Informational passage(s)     |  - Constructed Response (CR)    |
|  - MC items                     |  - MC items                     |
|  - Evidence-Based Selected      |  - Evidence-Based Selected      |
|    Response (EBSR)              |    Response (EBSR)              |
+---------------------------------+---------------------------------+
```

### Session Item Counts by Grade Band

| Session       | Grades 3–5                       | Grades 6–8                       |
|---------------|----------------------------------|----------------------------------|
| Session 1     | 15–20 MC/EBSR items              | 18–22 MC/EBSR items              |
| Session 2     | 12–18 MC/EBSR + 1–2 CR items    | 14–20 MC/EBSR + 1–2 CR items    |

## 5. ITEM TYPES

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Single correct answer                                   |
|  Machine scored                                          |
|  DOK 1–2                                                 |
|  Both sessions                                           |
+----------------------------------------------------------+
```

**MC Example (Grade 5, DOK 2, RL.5.2 — Theme):**

*Passage excerpt: A boy growing up in the Lowcountry learns traditional basket weaving from his Gullah grandmother, even as his school friends spend their afternoons playing video games.*

Which theme is BEST supported by the events in the passage?

- A. Modern technology always improves daily life
- B. Cultural traditions can connect generations in meaningful ways
- C. Children should always follow the wishes of their grandparents
- D. Rural communities are better than urban communities

*Correct Answer: B*

---

### Evidence-Based Selected Response (EBSR)

```
+----------------------------------------------------------+
|  EVIDENCE-BASED SELECTED RESPONSE — 2 points             |
|                                                          |
|  TWO-PART item (Part A + Part B)                         |
|  Part A: Analytical question (1 pt)                      |
|  Part B: Select evidence supporting Part A (1 pt)        |
|  Part B credit depends on correct Part A                 |
|  Machine scored                                          |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**EBSR Example (Grade 7, DOK 2, RI.7.5 — Text Structure):**

*Part A: How does the author of "Protecting Charleston Harbor" organize the information in the article?*

- A. By comparing two opposing viewpoints on harbor conservation
- B. By presenting events in the order they occurred over time
- C. By describing a problem and then proposing solutions
- D. By listing causes and their effects on marine habitats

*Part B: Which sentence from the article BEST supports your answer to Part A?*

- A. "Charleston Harbor has been a vital waterway since the colonial era."
- B. "Scientists have identified three major threats, and local organizations have responded with targeted programs."
- C. "Dolphins are among the most recognizable residents of the harbor."
- D. "Thousands of tourists visit the harbor each year."

*Correct Answers: Part A: C, Part B: B*

---

### Constructed Response (CR)

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE — 0–2 or 0–4 points                |
|                                                          |
|  Written response (1–3 paragraphs)                       |
|  Must cite textual evidence                              |
|  Human scored using CR rubric                            |
|  DOK 3                                                   |
|  1–2 per test                                            |
+----------------------------------------------------------+
```

**CR Example (Grade 8, DOK 3, RI.8.8 — Argument Evaluation):**

*"The article 'Fort Sumter: Preserving a National Treasure' presents the argument that federal funding is essential for maintaining Civil War-era historical sites. How does the author use evidence and reasoning to support this argument? Use specific details from the text in your response."*

## 8. SCORING RUBRICS

### Constructed Response (CR) Rubric — 0–2 Points (Short CR)

| Score | Criteria                                                                                                           |
|-------|--------------------------------------------------------------------------------------------------------------------|
| 2     | Clearly and accurately addresses the prompt; cites specific, relevant textual evidence; provides elaboration connecting evidence to the analytical point |
| 1     | Partially addresses the prompt; includes some evidence that may be vague or incomplete; limited elaboration         |
| 0     | Does not address the prompt; no evidence cited; blank, off-topic, or copied from passage                           |

### Constructed Response (CR) Rubric — 0–4 Points (Extended CR)

| Score | Criteria                                                                                                           |
|-------|--------------------------------------------------------------------------------------------------------------------|
| 4     | Thoroughly addresses all parts of the prompt; cites multiple pieces of specific, accurate textual evidence; provides detailed elaboration demonstrating sophisticated analysis of the text |
| 3     | Adequately addresses the prompt; cites relevant evidence; provides sufficient elaboration with clear analytical thinking |
| 2     | Partially addresses the prompt; evidence is present but may be incomplete or loosely connected; some analysis shown  |
| 1     | Minimally addresses the prompt; little or vague evidence; response is largely summary without analysis              |
| 0     | Does not address the prompt; blank; off-topic; copied from passage; or incomprehensible                            |

### EBSR Scoring

| Score | Criteria                                                                                  |
|-------|-------------------------------------------------------------------------------------------|
| 2     | Part A correct AND Part B correct                                                         |
| 1     | Part A correct but Part B incorrect                                                       |
| 0     | Part A incorrect (Part B cannot earn credit if Part A is wrong)                           |

> **Scoring Note:** Short CR items (0–2 points) typically require citing one piece of evidence with explanation. Extended CR items (0–4 points) require multiple pieces of evidence and sustained analysis.

## 9. ITEM GENERATION TEMPLATES

### Template A: Multiple Choice DOK 2

```
ITEM TEMPLATE: MC DOK 2 — SC College-and Career-Ready Standards
----------------------------------------------------------------
TARGET STANDARD: [RL/RI/L].[Grade].[Standard Number]
DOK LEVEL: 2
POINT VALUE: 1 point

STIMULUS: [Literary or informational passage, grade-level Lexile]
          [South Carolina context preferred — see Section 10]

STEM: [Analytical question requiring inference or analysis,
       not simple recall or text lookup]

OPTIONS:
A. [Plausible distractor — common misreading or surface-level answer]
B. [Plausible distractor — partially correct but incomplete]
C. [CORRECT ANSWER — defensible with specific text evidence]
D. [Plausible distractor — thematically related but unsupported]

EVIDENCE ANCHOR: [Quote or detail from passage supporting C]
DISTRACTOR RATIONALE:
  A — [Specific misconception targeted]
  B — [Why student might choose this]
  D — [Why this is attractive but wrong]
```

---

### Template B: EBSR DOK 2–3

```
ITEM TEMPLATE: Evidence-Based Selected Response
-------------------------------------------------
TARGET STANDARD: [RL/RI].[Grade].[Standard Number]
DOK LEVEL: 2–3
POINT VALUE: 2 points (1 + 1)

STIMULUS: [Passage with SC-specific context]

PART A STEM: [Analytical question about meaning, structure,
             or author's craft]
  A. [Distractor]
  B. [Distractor]
  C. [CORRECT ANSWER]
  D. [Distractor]

PART B STEM: "Which [sentence / detail / paragraph] from the
             [passage / article] BEST supports your answer
             to Part A?"
  A. [Text excerpt — does not support Part A answer]
  B. [Text excerpt — CORRECT: directly supports Part A]
  C. [Text excerpt — tangentially related]
  D. [Text excerpt — supports a different interpretation]

SCORING: Part A correct = 1 pt; Part B correct (with Part A correct) = 1 pt
         Part B cannot earn credit if Part A is incorrect
```

## 11. QUALITY CHECKLIST AND COMMON PITFALLS

### Quality Checklist

- [ ] Standard code uses SC College- and Career-Ready format (RL.X.#, RI.X.#, L.X.#)
- [ ] Passage Lexile is within grade-band range (see Section 7)
- [ ] MC options are plausible; no trick or obviously wrong choices
- [ ] EBSR Part A and Part B are logically linked; Part B evidence supports Part A
- [ ] CR prompt includes clear analytical focus (not "summarize")
- [ ] CR prompt ends with evidence directive ("Use evidence from the text")
- [ ] South Carolina context used where appropriate
- [ ] Item does not reference assessments from other states
- [ ] DOK level verified against item cognitive demand
- [ ] No performance task component (SC READY does not include PT)
- [ ] Vocabulary items use grade-appropriate academic and domain-specific words
- [ ] Cultural contexts are respectful and accurately represented

### Common Pitfalls

| Pitfall                                      | Problem                                           | Fix                                                      |
|----------------------------------------------|---------------------------------------------------|----------------------------------------------------------|
| Using generic CCSS codes without SC context  | SC uses its own College-and Career-Ready Standards | Use SC standard coding conventions                        |
| CR prompt that asks students to summarize    | Summarizing is not DOK 3 analytical thinking       | Frame prompt around analysis, evaluation, or argument     |
| EBSR Part B unconnected to Part A            | Part B must provide evidence for the Part A answer | Verify each Part B option relates to a Part A choice      |
| Ignoring SC cultural diversity               | Test fairness requires authentic SC representation | Include Gullah, Lowcountry, and diverse SC communities    |
| Using non-SC geographic references           | SC test values SC-specific authenticity             | Anchor passages in real SC places and communities         |
| CR rubric applied inconsistently             | Short CR (0–2) vs. extended CR (0–4) differ        | Match rubric scale to CR type specified in the item       |
| EBSR scored as single item                   | EBSR is a 2-point item (1 + 1 with dependency)     | Score Part A and Part B separately with dependency rule   |

## 12. PROMPT PATTERNS

The following patterns reflect the most commonly tested item structures on SC READY ELA.

### Pattern 1: Theme Development (CR, DOK 3, RL.X.2)
> "In '[passage title],' the author develops the theme that [theme]. How do the characters' [actions / decisions / experiences] support this theme? Use evidence from the text to support your response."

### Pattern 2: Central Idea and Evidence (EBSR or CR, DOK 2–3, RI.X.2)
> "What is the central idea of '[article title]'? How does the author use [details / examples / evidence] to develop this idea?"

### Pattern 3: Text Structure Analysis (EBSR, DOK 2, RI.X.5)
> Part A: "How does the author organize the information in '[article title]'?"
> Part B: "Which sentence from the article BEST supports your answer to Part A?"

### Pattern 4: Figurative Language and Vocabulary (MC, DOK 2, L.X.5 or RL.X.4)
> "Read this sentence from the passage: '[sentence with figurative language].' What does this [metaphor / simile / idiom] MOST LIKELY mean?"

### Pattern 5: Author's Argument and Reasoning (CR, DOK 3, RI.X.8)
> "The author of '[article title]' argues that [claim]. How does the author use evidence and reasoning to support this argument? Use details from the text in your response."

### Pattern 6: Point of View and Perspective (MC or EBSR, DOK 2, RL.X.6)
> "How does the [first-person / third-person] point of view affect the reader's understanding of [event / character / conflict] in the passage?"

### Pattern 7: Evidence-Based Inference (EBSR, DOK 2–3, RL.X.1 or RI.X.1)
> Part A: "What can the reader infer about [character / topic] based on the passage?"
> Part B: "Which detail from the passage BEST supports this inference?"
