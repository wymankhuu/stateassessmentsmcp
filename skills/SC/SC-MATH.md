### SC Mathematical Process Standards

South Carolina emphasizes eight mathematical process standards that apply across all grade levels:

| Process | Description                                                        |
|---------|--------------------------------------------------------------------|
| PS.1    | Make sense of problems and persevere in solving them               |
| PS.2    | Reason abstractly and quantitatively                               |
| PS.3    | Construct viable arguments and critique the reasoning of others    |
| PS.4    | Model with mathematics                                             |
| PS.5    | Use appropriate tools strategically                                |
| PS.6    | Attend to precision                                                |
| PS.7    | Look for and make use of structure                                 |
| PS.8    | Look for and express regularity in repeated reasoning              |

## 3. TEST STRUCTURE

SC READY Mathematics is administered in **2 sessions** over one or two days.

```
+-------------------------------------------------------------------+
|            SC READY MATH TEST STRUCTURE (Grades 3–8)              |
+---------------------------------+---------------------------------+
|   SESSION 1                     |   SESSION 2                     |
|   ~60–75 minutes                |   ~60–75 minutes                |
|                                 |                                 |
|  MULTIPLE CHOICE                |  MULTIPLE CHOICE                |
|  NO calculator (all grades)     |  CONSTRUCTED RESPONSE           |
|                                 |  Calculator allowed (Gr 6–8)    |
+---------------------------------+---------------------------------+
```

### Session Item Counts by Grade Band

| Session       | Grades 3–5                       | Grades 6–8                       |
|---------------|----------------------------------|----------------------------------|
| Session 1     | 20–25 MC items (no calculator)   | 20–25 MC items (no calculator)   |
| Session 2     | 15–20 MC + 2–3 CR items         | 15–20 MC + 2–3 CR items (calc)  |

> **Calculator Policy:** No calculators for any portion of Grades 3–5. For Grades 6–8, a calculator is available during Session 2 only.

## 5. ITEM TYPES

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Single correct answer                                   |
|  Machine scored                                          |
|  DOK 1–2                                                 |
|  Both sessions                                           |
+----------------------------------------------------------+
```

**MC Example (Grade 6, DOK 2, 6.RP — Ratios):**

A sweetgrass basket weaver in the Lowcountry uses 3 bundles of sweetgrass for every 2 bundles of pine needles. If she uses 18 bundles of sweetgrass, how many bundles of pine needles does she need?

- A. 9
- B. 12
- C. 15
- D. 27

*Correct Answer: B (18 / 3 = 6 groups; 6 x 2 = 12)*

---

### Constructed Response (CR)

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE — 0–2 or 0–4 points                |
|                                                          |
|  Multi-step problem requiring shown work                 |
|  May include Parts A, B, C                               |
|  DOK 2–3                                                 |
|  Human scored using CR rubric                            |
|  Session 2 only (2–3 per test)                           |
+----------------------------------------------------------+
```

**CR Example (Grade 7, DOK 3, 7.RP — Proportional Relationships):**

*"Tourists visiting Charleston can take two different harbor boat tours. Tour A costs $25 for 2 hours. Tour B costs $40 for 3.5 hours.*

*Part A: Find the unit rate (cost per hour) for each tour. Show your work.*
*Part B: Which tour is a better value per hour? Explain your reasoning.*
*Part C: If a family has a budget of $100, how many hours of Tour A can they book? Show your work."*

## 7. SC MATHEMATICAL PROCESS STANDARDS IN ASSESSMENT

SC's Mathematical Process Standards guide item development and connect content to reasoning:

| Process Standard | Assessment Application                                                      |
|------------------|-----------------------------------------------------------------------------|
| PS.1 Make Sense  | Multi-step word problems where students must identify the approach          |
| PS.2 Reason Abstractly | Items requiring students to decontextualize and recontextualize      |
| PS.3 Construct Arguments | CR items requiring written justification of mathematical reasoning |
| PS.4 Model with Math | Real-world SC context problems (see Section 10)                       |
| PS.5 Use Tools   | Calculator-appropriate items in Grades 6–8 Session 2                       |
| PS.6 Attend to Precision | Items requiring exact answers, correct units, and labels           |
| PS.7 Use Structure | Pattern recognition and algebraic structure items                        |
| PS.8 Repeated Reasoning | Items involving generalization from specific cases                  |

> **PS.4 (Model with Math)** is the most visible process standard in test items, as SC READY emphasizes real-world application using SC-specific contexts.

## 8. SCORING RUBRICS

### Constructed Response (CR) Rubric — 0–2 Points (Short CR)

| Score | Criteria                                                                                                    |
|-------|-------------------------------------------------------------------------------------------------------------|
| 2     | Correct answer with complete, clearly shown work; mathematical reasoning is sound and organized              |
| 1     | Partially correct; work shown is incomplete or contains a minor error; some mathematical understanding       |
| 0     | Incorrect or no work shown; blank; off-task; no mathematical understanding demonstrated                     |

### Constructed Response (CR) Rubric — 0–4 Points (Extended CR)

| Score | Criteria                                                                                                    |
|-------|-------------------------------------------------------------------------------------------------------------|
| 4     | All parts fully and correctly addressed; work is complete, clearly organized, and mathematically precise; written explanations demonstrate thorough understanding with correct vocabulary and units |
| 3     | Most parts correctly addressed; work is mostly complete with minor errors; explanations demonstrate adequate understanding |
| 2     | Some parts correctly addressed; work is partially complete or contains procedural errors; partial understanding shown |
| 1     | Minimal correct work; significant errors across most parts; little mathematical understanding demonstrated   |
| 0     | No correct work; blank; off-task; demonstrates no understanding of the mathematical task                    |

## 11. QUALITY CHECKLIST AND COMMON PITFALLS

### Quality Checklist

- [ ] Standard code uses SC College- and Career-Ready format ([Grade].[Domain].[Standard])
- [ ] Process standard alignment identified for CR items
- [ ] Calculator policy matches session and grade level
- [ ] CR items have at least two parts (Part A and Part B minimum)
- [ ] Part C of extended CR includes explanation or justification component
- [ ] All numerical values produce clean, non-ambiguous answers
- [ ] SC-specific real-world context used where appropriate
- [ ] Distractors reflect specific, identifiable student error types
- [ ] DOK level verified against actual cognitive demand
- [ ] Units and labels are correct throughout
- [ ] Money amounts use appropriate SC-relevant scenarios
- [ ] Data tables and graphs are clearly labeled

### Common Pitfalls

| Pitfall                                  | Problem                                           | Fix                                                      |
|------------------------------------------|---------------------------------------------------|----------------------------------------------------------|
| Calculator in Session 1 (Gr 3–5)        | No calculator allowed for any Grades 3–5 portion  | Design items without calculator dependence for Gr 3–5    |
| CR with only one part                   | SC READY CR requires multi-part structure          | Include minimum Part A and Part B                         |
| Generic context (no SC specificity)      | SC test values authentic SC contexts               | Use Charleston, Lowcountry, Gullah, barrier islands      |
| CR explanation prompt missing            | DOK 3 requires written justification               | Include "Explain your reasoning" or context interpretation|
| Ambiguous decimal/fraction answers       | Scoring system needs exact match capability         | Verify answer has a single clean form                     |
| Distractor without a clear error type    | Each wrong answer should target a specific mistake | Map each distractor to a computation or conceptual error |
| Ignoring SC Mathematical Process Stds    | PS standards guide item design                     | Reference PS.3 and PS.4 for CR items                     |

## 12. PROMPT PATTERNS

The following patterns reflect the most common SC READY Mathematics item structures.

### Pattern 1: Contextual Computation (MC, DOK 2)
> "[SC setting]. [Given information]. [Mathematical question requiring multi-step application]."
> (Options: correct answer + three specific error-type distractors)

### Pattern 2: Multi-Step Application (CR Part A, DOK 2)
> "A [SC context] has [given data]. [Part A: computation requiring setup + solve]. Show your work."

### Pattern 3: Rate or Ratio in Context (MC or CR, DOK 2)
> "[SC scenario] involves [quantity A] for every [quantity B]. [Question about scaling, unit rate, or comparison]."

### Pattern 4: Explain in Context (CR Part C, DOK 3)
> "Your equation has a [slope / rate / coefficient] of [value]. Explain what this number means in the context of [SC scenario]."

### Pattern 5: Comparison with Justification (CR, DOK 3)
> "Two [SC scenarios] are described: [Scenario A data] and [Scenario B data]. Which [option] is [more efficient / greater / better value]? Use mathematical evidence to justify your answer."

### Pattern 6: Error Analysis (MC or CR, DOK 3)
> "[Student name] solved the problem and got [incorrect answer]. What error did [student] make? Show the correct solution."

### Pattern 7: Data Interpretation (MC, DOK 2)
> "The [table / graph] below shows [SC data]. Based on the data, which statement is BEST supported?"
