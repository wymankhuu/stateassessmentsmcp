> **KEY NOTE:** Alaska uses its own **Alaska Mathematics Standards**, which are state-specific. While structurally similar to national frameworks, they include Alaska-specific expectations. Always reference Alaska Math Standards, not CCSS, when coding items.

### Performance Levels

| Level | Label | Description |
|---|---|---|
| 4 | **Advanced** | Student demonstrates thorough understanding of grade-level math standards; applies concepts flexibly in novel situations |
| 3 | **Proficient** | Student demonstrates solid understanding of grade-level math standards; meets expectations for computation, reasoning, and problem solving |
| 2 | **Below Proficient** | Student demonstrates partial understanding of grade-level math standards; inconsistent application of skills |
| 1 | **Far Below Proficient** | Student demonstrates minimal understanding of grade-level math standards; significant gaps in foundational skills |

> **Item-writing target:** "Proficient" performance. Items should require genuine application of Alaska Mathematics Standards at the expected DOK level.

## 3. TEST STRUCTURE

The AK STAR Mathematics test is administered during the spring testing window.

```
+------------------------------------------------------------------+
|           AK STAR MATHEMATICS TEST STRUCTURE (Grades 3–8, 10)    |
+-------------------+--------------------+-------------------------+
|   SECTION 1       |   SECTION 2        |   SECTION 3             |
|   ~40–50 minutes  |   ~40–50 minutes   |   ~30–40 minutes        |
|                   |                    |                         |
| NO CALCULATOR     | CALCULATOR ALLOWED | CALCULATOR ALLOWED      |
| (all grades)      | (Gr 6–8, 10 only) | (Gr 6–8, 10 only)      |
|                   |                    |                         |

```

### Section Item Counts by Grade Band

| Section | Grades 3–5 | Grades 6–8 | Grade 10 |
|---|---|---|---|
| Section 1 (No Calculator) | 18–20 MC + 2 MS | 20–22 MC + 2 MS | 20–22 MC + 2 MS |

> **Section 1** is no-calculator for all grades and is designed to assess computational fluency and conceptual understanding. **Sections 2 and 3** allow calculator use for Grades 6–8 and 10.

## 5. ITEM TYPES

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Single correct answer                                   |
|  Machine scored                                          |
|  Sections 1 and 2                                        |
|  No calculator in Section 1 (all grades)                 |
+----------------------------------------------------------+
```

**MC Example (Grade 6, DOK 2, AK.Math.6.RP.1 — Ratios):**

A bush pilot flies 312 miles on Monday and 208 miles on Tuesday delivering supplies to remote Alaska villages. What is the ratio of Monday's distance to Tuesday's distance in simplest form?

- A. 312 : 208
- B. 4 : 3
- C. 3 : 2
- D. 2 : 3

*Correct Answer: C (GCF of 312 and 208 is 104; 312/104 = 3, 208/104 = 2)*

---

### Multi-Select (MS)

```
+----------------------------------------------------------+
|  MULTI-SELECT — 1 point                                  |
|                                                          |
|  5–7 options; student selects ALL that apply             |
|  All correct selections required for full credit         |
|  Machine scored                                          |
|  Typically DOK 2                                         |
+----------------------------------------------------------+
```

**MS Example (Grade 7, DOK 2, AK.Math.7.RP.2):**

*"A fishing vessel catches salmon at a constant rate. After 3 hours it has caught 180 salmon. Select ALL equations that represent the relationship between hours (h) and salmon caught (s)."*

- A. s = 60h
- B. h = 60s
- C. s/h = 60
- D. h/s = 60
- E. s = 180 + 60h

*Correct Answers: A, C*

---

### Constructed Response (CR)

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE — 0–2 points                       |
|                                                          |
|  Student must SHOW WORK in provided space                |
|  Partial credit awarded for correct process/setup        |
|  Human scored using CR rubric                            |
|  DOK 2–3                                                 |
|  Sections 2 and 3                                        |
+----------------------------------------------------------+
```

**CR Example (Grade 5, DOK 2, AK.Math.5.NF.4 — Multiply Fractions):**

*"A rectangular section of a Fairbanks community garden has a length of 3/4 yard and a width of 2/5 yard. What is the area of this section? Show your work."*

---

### Extended Response (ER)

```
+----------------------------------------------------------+
|  EXTENDED RESPONSE — 0–2 points                          |
|  (Note: AK STAR Math CR and ER both use 0–2 scale)      |
|                                                          |
|  Multi-part problem (Parts A, B, sometimes C)            |
|  Requires show work AND written explanation              |
|  Higher DOK — strategic thinking, justify reasoning      |
|  Human scored using ER rubric                            |
|  Section 3 only (1 per test)                             |
+----------------------------------------------------------+
```

**ER Example (Grade 8, DOK 3, AK.Math.8.EE.7 + 8.F.2):**

*"Researchers tracked the number of tourists visiting Denali National Park over two summer months. In June, weekly visitors followed the equation y = 850x + 12,000, where x is the week number. In July, weekly visitors followed y = 620x + 15,500.*

*Part A: During which week of June did the number of weekly visitors first exceed 16,000? Show your work.*

*Part B: Which month had a greater rate of increase in weekly visitors? Explain how you know using mathematical evidence."*

## 6. DEPTH OF KNOWLEDGE (DOK)

| DOK | Label | Math Application Examples |
|---|---|---|
| 1 | Recall & Reproduction | Compute 3/4 x 8; identify a geometric property; convert units |

| 3 | Strategic Thinking | Design a plan; justify a conclusion; analyze error; compare solution methods |

> **CR items are typically DOK 2–3.** The ER item is always DOK 3. All Section 1 MC are DOK 1–2.

## 7. MATHEMATICAL PRACTICES

The Alaska Mathematics Standards incorporate **Standards for Mathematical Practice (SMP)** as process standards. These practices should be embedded across all item types.

| SMP | Practice | Assessment Application |
|---|---|---|
| 1 | Make sense of problems; persevere | Multi-step CR/ER items; complex word problems with Alaska contexts |
| 2 | Reason abstractly and quantitatively | Contextual problems requiring decontextualization (Alaska data) |
| 3 | Construct viable arguments; critique | CR/ER items requiring explanation or error analysis |
| 4 | Model with mathematics | Real-world Alaska contexts (distances, temperatures, populations) |
| 5 | Use appropriate tools strategically | Calculator use decisions; reference sheet use |
| 6 | Attend to precision | Labeling units; exact vs. approximate answers; significant figures |
| 7 | Look for and make use of structure | Pattern recognition; algebraic reasoning items |
| 8 | Look for and express regularity | Generalization items; repeated reasoning in Alaska data sets |

## 8. SCORING RUBRICS

### Constructed Response (CR) Rubric — 0–2 Points

| Score | Criteria |
|---|---|
| 2 | Response shows correct mathematical work AND arrives at the correct answer. Units and labels are included where required. Work is clear and organized. |
| 1 | Response shows a correct mathematical approach or setup but contains a computational error OR shows correct answer without sufficient work shown. Partial understanding is demonstrated. |
| 0 | Response shows no correct mathematical approach; answer is incorrect with no supporting work; response is blank or completely off-task. |

---

### Extended Response (ER) Rubric — 0–2 Points

| Score | Criteria |
|---|---|
| 2 | All parts of the problem are correctly addressed. Mathematical work is complete, clearly shown, and leads to correct answers. Written explanations (if required) are mathematically sound and use accurate vocabulary. Units and labels are correct. |
| 1 | Some parts of the problem are correctly addressed. Mathematical work is partially correct with errors. Written explanations demonstrate partial understanding. One or more parts may be incomplete or contain errors. |
| 0 | No correct mathematical work is shown; response demonstrates no understanding of the mathematical task; response is blank or completely off-task. |

## 10. CONTEXTUALIZATION — ALASKA MATH

When generating real-world contexts for AK STAR Mathematics items, prioritize the following authentic Alaska settings. Alaska's vast geography, extreme climate, and unique economy provide exceptionally rich mathematical contexts.

### Recommended Math Contexts

| Context | Grade Band | Math Domains |
|---|---|---|
| Alaska distances (vast scale — Anchorage to Barrow: 725 mi) | 3–8, 10 | Measurement, unit conversion, large numbers, proportional reasoning |
| Iditarod race data (checkpoints, times, distances, speeds) | 3–8 | Ratios, unit rates, elapsed time, data analysis, fractions |
| Denali elevation (20,310 ft) and mountain data | 4–8, 10 | Large numbers, subtraction, unit conversion, geometry |
| Alaska temperature extremes (summer highs vs. winter lows) | 3–8, 10 | Integers, absolute value, range, data analysis |
| Fishing harvest data (salmon runs, commercial catch totals) | 4–8, 10 | Large numbers, ratios, statistics, proportional reasoning |
| Trans-Alaska Pipeline measurements (800 miles, diameter, flow rates) | 6–8, 10 | Unit rates, volume, geometry, proportional reasoning |
| Alaska population density (1.3 people per sq mi) | 5–8, 10 | Division, ratios, comparison with other states, area |
| Bush pilot flight distances and fuel calculations | 5–8, 10 | Unit rates, proportional reasoning, decimals |
| Daylight hours by season (extreme variation) | 4–8, 10 | Data analysis, elapsed time, graphing, functions |
| Glacier measurements (retreat rates, area, volume) | 6–8, 10 | Rates of change, linear functions, unit conversion |

### Sample Context Sentence Starters

- "A bush pilot flies from Anchorage to Nome, a distance of [X] miles..."
- "During the Iditarod, a musher's dog team averaged [X] miles per hour for [Y] hours..."
- "The summit of Denali stands at 20,310 feet. A climbing team at base camp is at..."
- "In Fairbanks, the temperature dropped from [X]°F to [Y]°F overnight..."
- "A fishing vessel in Bristol Bay caught [X] sockeye salmon in [Y] days..."
- "The Trans-Alaska Pipeline carries approximately [X] barrels of oil per day over [Y] miles..."
- "In Juneau, there are approximately [X] hours of daylight on the summer solstice and [Y] hours on the winter solstice..."

### Grade-Specific Context Examples

**Grades 3–4:**
- Counting and comparing Iditarod checkpoint distances
- Adding and subtracting temperatures in Fairbanks across seasons
- Measuring areas of rectangular dog sled lots
- Sharing salmon equally among family members (division)

**Grades 5–6:**
- Calculating fraction of the Iditarod trail completed between checkpoints
- Converting between miles and kilometers for Alaska Highway distances
- Comparing population densities: Alaska vs. other states
- Ratios of daylight to darkness hours across Alaska seasons

**Grades 7–8:**
- Proportional reasoning with fishing harvest rates over multiple seasons
- Linear equations modeling Denali climbing team elevation over time
- Statistical analysis of Alaska temperature data across decades
- Pythagorean theorem with bush plane flight paths (triangulated routes)

**Grade 10:**
- Modeling glacier retreat with linear and exponential functions
- Statistical inference from Alaska salmon population data sets
- Geometric proofs involving pipeline engineering angles
- Quadratic models for projectile paths (wildlife research tagging)

## 11. QUALITY CHECKLIST AND COMMON PITFALLS

### Quality Checklist

- [ ] Standard code uses AK.Math. format (not raw CCSS)
- [ ] Calculator policy matches section (no calculator in Section 1; scientific Gr 6+ in Sections 2–3)
- [ ] Reference sheet availability noted for Gr 5+ items with formulas
- [ ] CR and ER items include "Show your work" directive
- [ ] ER items have at least two parts (Part A and Part B minimum)
- [ ] Real-world context is authentic Alaska setting
- [ ] All numerical values produce clean, non-ambiguous computations
- [ ] Distractors for MC reflect specific, identifiable student error types
- [ ] DOK level is verified against item cognitive demand
- [ ] Formulas used are consistent with Alaska reference sheet (if applicable)
- [ ] Units are clearly specified; labels required where appropriate
- [ ] Grade 10 items reflect high school rigor expectations
- [ ] No grade-inappropriate content (e.g., no algebra in Gr 3)
- [ ] MS items specify how many selections to make

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Calculator allowed in Section 1 | Section 1 is no-calculator for all grades | Remove calculator-dependent computation in Section 1 |
| Using CCSS codes without AK prefix | Alaska uses Alaska Math Standards, not raw CCSS | Always use AK.Math. prefix |
| Generic "Lower 48" context | AK STAR values authentic Alaska settings | Anchor in Alaska geography, climate, economy |
| Answers requiring rounding in CR | Creates ambiguity for partial credit | Design problems with clean answers |
| Ignoring Grade 10 | AK STAR tests Grade 10 unlike many states that stop at 8 | Include Grade 10 items with appropriate rigor |
| ER with only one part | AK STAR ER requires multi-part structure | Ensure Part A + Part B minimum |
| Unrealistic Alaska data | Students may know Alaska facts | Use plausible, fact-checkable numbers |

## 12. PROMPT PATTERNS

The following five prompt patterns reflect the most common AK STAR Mathematics item structures.

### Pattern 1: Contextual Computation (MC, DOK 2)
> "[Alaska context]. [Student/character] needs to find [quantity]. What is [quantity]?"
> (Options: correct answer + three error-type distractors)

### Pattern 2: Show Work — One Step Up (CR, DOK 2)
> "A [Alaska setting] has [given information]. [Question requiring multi-step math]. Show your work."

### Pattern 3: Multi-Part with Explanation (ER, DOK 3)
> "[Alaska data scenario with table or graph].
> Part A: [Computational or procedural task]. Show your work.
> Part B: [Reasoning or justification task]. Use mathematical evidence to support your answer."

### Pattern 4: Error Analysis (CR or MC, DOK 3)
> "[Student name] solved the following problem and got [incorrect answer]. [Student's work shown]. Explain the error [student] made and find the correct answer."

### Pattern 5: Comparison and Generalization (ER, DOK 3)
> "Two [Alaska contexts — e.g., fishing seasons, flight routes, glacier measurements] are described. [Data for each]. Which [option] is [better/greater/more efficient]? Use mathematical evidence to justify your answer."
