# Vermont — VTSA Science (Vermont Science Assessment)
## AssessmentForge Skill Guide | Grades 5, 8, 11

---

## 1. Overview

| Field | Detail |
|---|---|
| **Assessment Name** | Vermont Science Assessment (VTSA) |
| **Administering Agency** | Vermont Agency of Education |
| **Vendor** | Vermont Agency of Education |
| **Grades Tested** | 5, 8, and 11 |
| **Testing Window** | March – May |
| **Delivery** | Computer-based; fixed-form |
| **Standards** | Next Generation Science Standards (NGSS) as adopted by Vermont |
| **Score Scale** | Standard score (varies by grade); 4 performance levels |
| **Reporting** | Individual Student Report; School, District, State aggregate reports |

> **CRITICAL NOTE:** VTSA Science is administered **only at Grades 5, 8, and 11**. Do not generate items for Grades 3, 4, 6, or 7.

### Performance Level Descriptors

| Level | Label | Description |
|---|---|---|
| 4 | **Standard Exceeded** | Student demonstrates thorough understanding of three-dimensional science; expertly integrates DCI, SEP, and CCC; constructs sophisticated, evidence-based explanations |
| 3 | **Standard Met** | Student demonstrates adequate understanding of three-dimensional science; appropriately applies practices and crosscutting concepts in grade-level contexts |
| 2 | **Standard Nearly Met** | Student demonstrates partial understanding; can recall disciplinary core ideas but struggles to integrate science practices or crosscutting concepts |
| 1 | **Standard Not Met** | Student demonstrates minimal science understanding; cannot apply practices or crosscutting concepts; limited to recall of isolated facts |

> **Item-writing target:** Level 3 (Standard Met) performance. Items should assess all three NGSS dimensions simultaneously.

## 3. Test Structure

VTSA Science is a single-session, computer-based test. There is **no lab practical component** — all items are stimulus-based (scenarios, data tables, diagrams, models, and graphs).

```
+------------------------------------------------------------------+
|                   VTSA SCIENCE STRUCTURE (Grades 5, 8, 11)        |
+------------------------------------------------------------------+
|  SINGLE SESSION                                                   |
|  Computer-Based, Fixed-Form                                       |
|  Approximately 90–120 minutes                                     |
|                                                                   |
|  ~40 items per grade                                              |
|                                                                   |
|  Item types:                                                      |
|    - Selected Response (SR) — ~60–65% of items                    |
|    - Multi-Select Response (MS) — ~15–20% of items                |
|    - Constructed Response (CR) — ~15–20% of items (3 pts each)    |
+------------------------------------------------------------------+
```

### Grade-Level Test Specifications

| Specification | Grade 5 | Grade 8 | Grade 11 |
|---|---|---|---|
| Approximate Item Count | ~38–42 | ~38–42 | ~38–42 |
| Selected Response | ~25–28 | ~25–28 | ~25–28 |
| Multi-Select | ~6–8 | ~6–8 | ~6–8 |
| Constructed Response | ~4–6 | ~4–6 | ~4–6 |
| Approx. Testing Time | 90–120 min | 90–120 min | 90–120 min |
| Calculator | No | No | No |
| Reference Sheet | No | No | No |

> **Three-Dimensional Requirement:** Every VTSA Science item must integrate at least one **Disciplinary Core Idea (DCI)**, one **Science and Engineering Practice (SEP)**, and one **Crosscutting Concept (CCC)**.

## 5. Item Types & Formats

### Selected Response (SR)

```
+----------------------------------------------------------+
|  SELECTED RESPONSE — 1 point                             |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Scenario, diagram, data table, or model stimulus        |
|  Must integrate DCI + SEP + CCC                          |
|  Machine scored                                          |
+----------------------------------------------------------+
```

**SR Example (Grade 8, DOK 2, MS-LS2-2 — Ecosystem Interactions):**

A scientist studying Lake Champlain observes that when zebra mussel populations increase, the water becomes clearer but native mussel populations decline. Which statement BEST explains the cause-and-effect relationship in this ecosystem?

A. Native mussels move to deeper water when zebra mussels arrive
B. Zebra mussels filter more water than native mussels, reducing food availability for native species
C. The clearer water causes native mussels to stop reproducing
D. Zebra mussels and native mussels are the same species with different names

*Correct Answer: B*
*Alignment: MS-LS2-2 | SEP: Constructing Explanations | CCC: Cause and Effect | DOK 2*

---

### Multi-Select Response (MS)

```
+----------------------------------------------------------+
|  MULTI-SELECT RESPONSE — 1 point                         |
|                                                          |
|  5–6 options; select exactly 2 or 3 correct answers      |
|  Full credit only; partial credit not awarded            |
|  Machine scored                                          |
+----------------------------------------------------------+
```

**MS Example (Grade 5, DOK 2, 5-LS2-1 — Matter Cycling in Ecosystems):**

A Vermont forest has sugar maple trees, deer, mushrooms, and earthworms. Select the TWO statements that correctly describe how matter moves through this ecosystem.

A. Sugar maples take in carbon dioxide from the air and water from the soil to produce food
B. Deer create new matter when they eat plants
C. Mushrooms break down fallen leaves and return nutrients to the soil
D. Earthworms produce energy from sunlight like plants do
E. Matter is created each time a new tree grows from a seed

*Correct Answers: A, C*
*Alignment: 5-LS2-1 | SEP: Developing and Using Models | CCC: Energy and Matter | DOK 2*

---

### Constructed Response (CR)

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE — 0–3 points                       |
|                                                          |
|  Written explanation using evidence from stimulus        |
|  Stimulus always provided (data, diagram, scenario)      |
|  Must demonstrate three-dimensional reasoning            |
|  Human scored                                            |
+----------------------------------------------------------+
```

**CR Example (Grade 8, DOK 3, MS-ESS2-2 — Geoscience Processes):**

*Stimulus: A diagram showing the geological layers of the Green Mountains, including metamorphic rocks, glacial till deposits, and a cross-section showing evidence of ancient volcanic activity and glacial erosion. Data table shows rock ages ranging from 400 million to 1 billion years.*

*"Using evidence from the diagram and data table, construct an explanation for how multiple geoscience processes shaped the Green Mountains over time. Identify at least two different processes and explain the cause-and-effect relationship between each process and the features it created."*

## 7. Three-Dimensional Design

Every VTSA Science item must reflect all three NGSS dimensions simultaneously.

### Three-Dimensions Alignment Guide

| Dimension | What It Is | Example in Items |
|---|---|---|
| **DCI** (What students know) | Disciplinary science content | Photosynthesis; ecosystem interactions; glacial geology; chemical reactions |
| **SEP** (What students do) | How scientists work | Analyze data from a table; construct an explanation using evidence; use a model to predict |
| **CCC** (Lens of thinking) | Cross-domain thinking tools | Cause and effect; patterns; energy and matter; structure and function; systems |

### Crosscutting Concepts by Grade Band

| CCC | Grade 5 Emphasis | Grade 8 Emphasis | Grade 11 Emphasis |
|---|---|---|---|
| Patterns | Rock formations; seasonal changes; maple sap flow timing | Periodic table patterns; population cycles | Inheritance patterns; population trends |
| Cause and Effect | Food web changes; erosion; weather | Chemical reactions; ecosystem dynamics; geological processes | Mutations -> traits; climate -> ecosystem change |
| Energy and Matter | Food chains; water cycle; plant growth | Chemical reactions; thermal transfer; matter cycling | Cellular respiration; photosynthesis at molecular level |
| Structure and Function | Plant/animal adaptations; leaf structure | Cell structures; molecular bonds; rock composition | DNA -> protein -> trait |
| Systems and System Models | Ecosystems; water cycle; Vermont forests | Earth systems; lake ecosystems; watersheds | Ecosystems; genetic systems; climate systems |
| Scale, Proportion, Quantity | Particle size; distances; tree measurements | Atomic scale; geological time | Chromosome/gene scale; population modeling |
| Stability and Change | Habitat change; seasonal cycles | Climate; ecosystem stability; Lake Champlain water quality | Evolution; homeostasis; long-term climate trends |

## 8. Scoring Rubrics

### Constructed Response (CR) Rubric — 0–3 Points

| Score | Criteria |
|---|---|
| 3 | Response accurately addresses the science concept; demonstrates clear three-dimensional understanding (DCI + SEP or CCC evident); includes specific, relevant evidence from the stimulus; explanation is complete, accurate, and logically connected |
| 2 | Response addresses the science concept with partial accuracy; shows understanding of the DCI but may only partially integrate a practice or crosscutting concept; evidence from stimulus is present but may be incomplete |
| 1 | Response minimally addresses the science concept; shows limited understanding; little or no evidence from stimulus; explanation may be vague or contain minor science inaccuracies |
| 0 | Response does not address the science concept; blank; off-topic; restates the stimulus without explanation; demonstrates no science understanding |

### CR Scoring Notes

- **Evidence must come from the stimulus.** Responses relying solely on prior knowledge without referencing provided data receive a maximum of 1 point.
- **Three-dimensional reasoning earns full credit.** A Score 3 response integrates DCI with at least one SEP or CCC.
- **Misconceptions lower the score.** A significant science misconception drops the response by one score point.

         [construct an explanation for / argue whether / analyze why]

         DCI + SEP or CCC clearly integrated; no misconceptions.

         or contains a minor misconception.
Score 0: Blank, off-task, or major misconception with no science content.

[2–4 sentence model response integrating evidence + DCI + CCC]

## 10. Contextualization — Vermont Science

When generating science items and phenomena, prioritize authentic Vermont settings:

### Vermont Science Context Guide

| Setting / Phenomenon | Grade | Science Domain | PE Alignment |
|---|---|---|---|
| Lake Champlain ecology (invasive species, water quality, food webs) | 5, 8, 11 | Life/Earth Science | 5-LS2, MS-LS2, MS-ESS3, HS-LS2 |
| Green Mountain geology (metamorphic rocks, glacial erosion, mountain formation) | 8, 11 | Earth Science | MS-ESS2-2, HS-ESS2-1 |
| Vermont forest ecology (sugar maple forests, succession, biodiversity) | 5, 8 | Life Science | 5-LS2, MS-LS2 |
| Maple tree biology (photosynthesis, sap flow, sugar transport) | 5, 8 | Life Science | 5-LS1-1, 5-PS3-1, MS-LS1-5 |
| Climate change impacts on maple sugaring season (earlier sap runs, reduced yields) | 8, 11 | Earth/Life Science | MS-ESS3, HS-ESS3-1, HS-LS2-1 |
| Lake Champlain watershed (phosphorus runoff, algae blooms, water cycling) | 5, 8, 11 | Earth/Life Science | 5-ESS3, MS-ESS3-3, HS-ESS3-1 |
| Vermont glacial history (glacial landforms, till deposits, Lake Vermont) | 8, 11 | Earth Science | MS-ESS2-2, HS-ESS2-1 |
| Vermont wildlife (moose, black bear, peregrine falcon recovery) | 5, 8 | Life Science | 5-LS2, MS-LS2-2 |
| Alpine tundra on Mount Mansfield (rare plant communities, climate sensitivity) | 8, 11 | Life/Earth Science | MS-LS2, MS-ESS3, HS-LS4 |
| Vermont renewable energy (wind, solar, biomass from forest products) | 8, 11 | Physical/Earth Science | MS-PS3, MS-ESS3, HS-ESS3 |

### Suggested Anchoring Phenomena by Grade

**Grade 5 Phenomena:**
- "Sugar maple trees in Vermont produce sweet sap in early spring when temperatures go above freezing during the day and below freezing at night. Where does the energy stored in the sap originally come from, and how does it get into the tree?"
- "After a heavy rainstorm, the water in a Vermont stream turns brown and muddy. Where does the brown material come from, and where does it end up?"
- "Scientists studying Lake Champlain noticed that when zebra mussels arrived, the water became clearer but some native fish species had less food. How does adding a new organism change the flow of matter in the ecosystem?"

**Grade 8 Phenomena:**
- "Geologists have found fossils of tropical sea creatures in rocks at the top of the Green Mountains, over 4,000 feet above sea level. What does this evidence tell us about how the Green Mountains formed?"
- "Vermont maple syrup producers report that the sugaring season has shifted earlier by about two weeks compared to 50 years ago. What environmental changes could explain this pattern, and how might it affect the maple ecosystem?"
- "Water quality data from Lake Champlain shows that phosphorus levels increase dramatically in the spring near agricultural areas. What is the cause-and-effect relationship between farming practices and lake water quality?"

**Grade 11 Phenomena:**
- "Two populations of brook trout in Vermont, one in a cold mountain stream and one in a warmer lowland river, show different growth rates and temperature tolerances after being separated for hundreds of generations. What biological processes explain these differences?"
- "Climate models predict that Vermont's average temperature will increase by 3–5 degrees F by 2100. Scientists predict this will cause sugar maple trees to decline in Vermont while expanding in northern Quebec. What factors explain this predicted shift?"
- "Lake Champlain experiences seasonal algal blooms that have increased in frequency over the past 30 years. Scientists have linked these blooms to both agricultural runoff and rising water temperatures. How do these two factors interact to affect the lake ecosystem?"

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] Grade verified as 5, 8, or 11 ONLY (not other grades)
- [ ] PE code is a valid NGSS Performance Expectation
- [ ] Item is three-dimensional: DCI + SEP + CCC all identified
- [ ] Anchoring phenomenon is authentic and Vermont-relevant where possible
- [ ] Stimulus (data table/graph/diagram) has clear labels, units, and realistic data
- [ ] CR prompt directs students to use evidence from the stimulus
- [ ] All distractors represent real misconceptions (not obviously wrong)
- [ ] MS items specify how many answers to select (TWO/THREE)
- [ ] Score 3 anchor response written before finalizing CR item
- [ ] Science content is accurate and reflects current scientific understanding
- [ ] Vocabulary is grade-appropriate (avoid jargon not in NGSS glossary)

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Writing items for Grades 3, 4, 6, or 7 | VTSA Science is only at Grades 5, 8, 11 | Restrict to tested grades |
| DCI-only items (no SEP or CCC) | VTSA requires three-dimensional items | Always embed a practice and a crosscutting concept |
| CR prompts without evidence directive | Students may respond without citing data | Include "Use evidence from the [data/graph/diagram]" |
| Generic stimulus data not tied to VT | VTSA favors Vermont phenomena | Anchor stimulus to Vermont-specific contexts |
| Multi-select with only 2 correct in 4 options | Too easy to guess | Use 5–6 options with exactly 2–3 correct |
| Recall-only SR items | DOK 1 items are under-represented on VTSA | Elevate most items to DOK 2 with a scenario |

## 12. Prompt Patterns

The following patterns reflect the most common VTSA Science item archetypes.

### Pattern 1: Data-to-Conclusion (SR, DOK 2)
> "The [graph / table / diagram] below shows [Vermont science scenario]. Based on the data, which [conclusion / explanation / pattern] is BEST supported?"

### Pattern 2: Phenomenon Explanation (CR, DOK 3)
> "Scientists observed [Vermont-anchored phenomenon]. Using evidence from the [data / model / diagram], construct an explanation for [specific science focus]. Explain the [cause-and-effect / pattern / energy flow] relationship."

### Pattern 3: Model Evaluation (SR or MS, DOK 2–3)
> "A student made a model showing [science concept]. Which statement BEST describes what the model shows about [DCI focus]? / Select the TWO statements that correctly describe what the model represents."

### Pattern 4: Investigation Design (CR, DOK 3)
> "A scientist wants to investigate whether [variable] affects [outcome] in [Vermont ecosystem/context]. Describe a procedure the scientist could follow. Include what the scientist would measure and how they would know if the variable made a difference."

### Pattern 5: Evidence-Based Argument (CR, DOK 3)
> "Two students disagree about [science claim]. Student A says [claim based on misconception]. Student B says [scientifically accurate claim]. Using evidence from the [data / diagram], explain which student is correct and why."

### Pattern 6: Multi-Select Evidence (MS, DOK 2)
> "A student is investigating [Vermont science scenario]. Select the TWO [pieces of evidence / strategies / explanations] that BEST support the conclusion that [DCI-based claim]."
