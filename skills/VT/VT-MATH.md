| Field | Detail |
|---|---|
| **Assessment Name** | Smarter Balanced Assessment (VT) — Mathematics |
| **Consortium** | Smarter Balanced Assessment Consortium (SBAC) |
| **Administering Agency** | Vermont Agency of Education |
| **Grades Tested** | 3, 4, 5, 6, 7, 8, 11 |
| **Testing Window** | March – May (operational window; districts schedule within this range) |
| **Delivery** | Computer-adaptive (CAT) for Part 1 (non-calculator + calculator); fixed-form Performance Task for Part 2 |
| **Standards** | Common Core State Standards for Mathematics (CCSS-M) as adopted by Vermont |
| **Score Scale** | 2000–3000 scale score (varies by grade) |
| **Reporting** | Individual Student Report (ISR); School, District, State aggregate reports |

### Achievement Level Descriptors (ALDs)

| Level | Label | Description |
|---|---|---|
| 4 | **Standard Exceeded** | Student demonstrates sophisticated understanding of mathematical concepts and procedures; applies mathematics fluently in novel situations; constructs valid mathematical arguments |
| 3 | **Standard Met** | Student demonstrates adequate understanding of grade-level concepts and procedures; applies mathematics to real-world and mathematical problems with reasonable accuracy |
| 2 | **Standard Nearly Met** | Student demonstrates partial understanding; can apply procedures in familiar contexts but struggles with novel problems; mathematical explanations are incomplete |
| 1 | **Standard Not Met** | Student demonstrates minimal understanding; unable to apply grade-level mathematical concepts or procedures; cannot construct or follow mathematical reasoning |

> **Cut scores** are set by the Smarter Balanced Assessment Consortium and adopted by the Vermont State Board of Education. For item-writing purposes, target ALDs 3 and 4 as the proficiency range.

## 4. Claims & Blueprint

### Claim Structure

| Claim | Description | Point Weight | Primary Focus |
|---|---|---|---|
| **Claim 1 — Concepts & Procedures** | Students can explain and apply mathematical concepts and carry out mathematical procedures with precision and fluency | **40%** | Procedural fluency; conceptual understanding of grade-level math |
| **Claim 2 — Problem Solving** | Students can solve a range of complex well-posed problems in pure and applied mathematics, making productive use of knowledge and problem-solving strategies | **25%** | Multi-step problems; strategy selection; real-world contexts |
| **Claim 3 — Communicating Reasoning** | Students can clearly and precisely construct viable arguments to support their own reasoning and to critique the reasoning of others | **20%** | Explanation; justification; error analysis; proof |
| **Claim 4 — Modeling & Data Analysis** | Students can analyze complex, real-world scenarios and can construct and use mathematical models to interpret and solve problems | **15%** | Mathematical modeling; data interpretation; multi-step real-world scenarios |

## 5. Item Types & Formats

### SR — Selected Response (1 point)

Standard four-option multiple-choice. Student selects one best answer.

```
+----------------------------------------------------------------+
|  [Stimulus: problem context, diagram, table, or equation]       |
|                                                                 |
|  Question stem targeting a specific standard and claim.         |
|                                                                 |
|  O  A. [Numerical / expression answer — plausible distractor]   |
|  O  B. [Numerical / expression answer — common error]           |
|  O  C. [Numerical / expression answer — CORRECT]                |
|  O  D. [Numerical / expression answer — off-track distractor]   |
+----------------------------------------------------------------+
Points: 1 (correct) / 0 (incorrect)
```

**Construction Rules:**
- Distractors must reflect real student errors (computational errors, conceptual mistakes, operation errors)
- Numerical answers should not reveal the correct answer through magnitude ordering
- Diagrams and tables must be clearly labeled and drawn to reasonable scale

---

### MS — Multi-Select (1 point)

Student selects ALL correct answers from a set of five or six options. Full credit only when all correct options are selected and no incorrect options are selected.

```
+----------------------------------------------------------------+
|  [Problem context or mathematical statement]                    |
|                                                                 |
|  Select the TWO [equations / values / expressions] that...     |
|                                                                 |
|  [ ]  A. [Option]                                               |
|  [ ]  B. [Option — CORRECT]                                     |
|  [ ]  C. [Option]                                               |
|  [ ]  D. [Option — CORRECT]                                     |
|  [ ]  E. [Option]                                               |
|  [ ]  F. [Option]                                               |
+----------------------------------------------------------------+
Points: 1 (all correct, none incorrect) / 0 (any error)
```

---

### EQ — Equation / Numeric Entry (1 point)

Student types a number, expression, or short equation into a response box. No choices are provided.

```
+----------------------------------------------------------------+
|  [Problem context: real-world scenario or pure math]            |
|                                                                 |
|  What is the value of [EXPRESSION / VARIABLE / QUANTITY]?      |
|                                                                 |
|  Enter your answer in the box.                                  |
|  +---------------+                                              |
|  |               |  [numeric / expression entry field]         |
|  +---------------+                                              |
|                                                                 |
|  [Unit label if applicable: "gallons", "feet", etc.]            |
+----------------------------------------------------------------+
Points: 1 (exact correct value or equivalent expression) / 0
```

**Construction Rules:**
- Clearly state the expected form of the answer (whole number, decimal, fraction, simplified expression)
- Specify units in the item when applicable
- For fraction entries, provide the fraction entry tool (numerator/denominator boxes)
- Answers should be unique; avoid prompts where multiple equivalent forms might cause scoring issues

---

### SCR — Short Constructed Response (0–2 points)

Student writes a brief explanation or solution — usually 1–4 sentences plus work shown.

```
+----------------------------------------------------------------+
|  [Problem context — multi-step real-world scenario]             |
|                                                                 |
|  [PART A — Computational or procedural question]                |
|  [PART B — "Explain how you know" or "Show your work"]          |
|                                                                 |
|  +----------------------------------------------------------+  |
|  |  [Student response area — text input + scratchpad]        |  |
|  +----------------------------------------------------------+  |
+----------------------------------------------------------------+
Points: 0–2 (see rubric, Section 8)
```

---

### PT-ER — Performance Task Extended Response (0–6 points, multi-part)

The PT Extended Response presents a complex real-world scenario with 3–5 interdependent sub-parts.

```
+----------------------------------------------------------------+
|  PERFORMANCE TASK — EXTENDED RESPONSE                           |
|                                                                 |
|  SCENARIO:                                                      |
|  [3–5 sentence real-world context establishing the situation]   |
|  [Data tables, diagrams, or charts may be provided here]        |
|                                                                 |
|  Part A: [Introductory computation or setup question]           |
|  [Student response area]                                        |
|                                                                 |
|  Part B: [Intermediate reasoning or application question]       |
|  [Student response area]                                        |
|                                                                 |
|  Part C: [Complex extension — explain, justify, model, or       |
|            evaluate a decision based on mathematical results]   |
|  [Student response area]                                        |
+----------------------------------------------------------------+
Points: 0–2 per part x 3 parts = 0–6 total
```

## 6. DOK / Cognitive Complexity

### DOK Level Descriptions for Mathematics

| DOK | Label | Description | Example Tasks |
|---|---|---|---|
| **1** | Recall & Reproduction | Recall a fact; perform a routine, single-step procedure; identify a property; solve a one-step equation | *calculate, identify, recall, use, recognize, measure* |
| **2** | Skills & Concepts | Solve a multi-step problem using a known procedure; classify or organize information; make inferences from data | *classify, organize, estimate, compare, interpret, solve [multi-step], apply* |
| **3** | Strategic Thinking | Solve non-routine problems requiring planning; justify or prove a mathematical claim; analyze errors in reasoning | *justify, prove, analyze, evaluate, formulate, critique, explain reasoning* |
| **4** | Extended Thinking | Conduct multi-stage investigations; synthesize mathematical ideas across domains; design and evaluate complex models | *synthesize, design, evaluate [complex], connect, create* |

> DOK 4 appears primarily in PT Extended Response Part C items, not in individual CAT items.

### DOK Distribution Targets for Item Generation

| Item Type | Target DOK | Rationale |
|---|---|---|
| SR — single computation | 1 | Routine procedure, one step |
| SR — two-step word problem | 2 | Application; concept + computation |
| MS — identify equivalent forms | 1–2 | Depends on conceptual demand |
| EQ — numeric entry | 1–2 | Usually procedural; contextual use raises to DOK 2 |
| SCR — explain reasoning | 3 | Justification required; non-routine |
| PT-ER Part A | 2 | Setup computation within context |
| PT-ER Part B | 2–3 | Application or partial modeling |
| PT-ER Part C | 3–4 | Full modeling, justify, evaluate |

## 8. Scoring Rubrics

### SCR — Short Constructed Response (0–2 Points)

| Score | Descriptor |
|---|---|
| **2** | The response demonstrates a thorough understanding of the mathematical concepts and procedures required. The student provides a correct solution with a clear, accurate explanation or justification. Work shown is logical and complete. |
| **1** | The response demonstrates partial understanding. The student provides a partially correct solution or a correct solution with an incomplete explanation. OR the student provides the correct answer with no explanation. |
| **0** | The response is incorrect, irrelevant, or demonstrates no mathematical understanding. Blank responses receive a score of 0. |

### PT-ER — Performance Task Extended Response (0–6 Points)

#### Part A Rubric (0–2 points)

| Score | Descriptor |
|---|---|
| **2** | Correctly sets up and solves the introductory problem. All calculations are correct and clearly shown. Units are correctly identified. |
| **1** | Correct approach or setup but contains a computational error, incomplete solution, or missing unit. |
| **0** | Incorrect, missing, or demonstrates no understanding. |

#### Part B Rubric (0–2 points)

| Score | Descriptor |
|---|---|
| **2** | Correctly applies mathematical results from Part A to solve the intermediate problem. Reasoning is clear. |
| **1** | Shows partial understanding. May use an incorrect value from Part A but apply correct reasoning. |
| **0** | Incorrect, missing, or shows no mathematical understanding. |

#### Part C Rubric (0–2 points)

| Score | Descriptor |
|---|---|
| **2** | Demonstrates sophisticated mathematical reasoning applied to the complex extension. Accurately uses mathematical results to justify a decision or evaluate a model. |
| **1** | Shows some correct reasoning or partially valid justification. |
| **0** | Incorrect, off-task, or provides only unsupported assertions. |

#### Error Carried Forward (ECF) Policy

When a student carries an incorrect value from Part A into Parts B and C, use ECF scoring: if the student's work is mathematically correct based on their Part A answer, award full credit for that part. ECF applies only to simple computational mistakes, not conceptual misunderstandings.

## 10. Contextualization

### Vermont-Specific Mathematics Context Bank

Item writers should anchor scenarios in authentic Vermont contexts to maximize student engagement and ecological validity.

#### Maple Syrup & Agriculture

| Topic | Mathematical Applications |
|---|---|
| **Maple syrup production data** | Ratio and proportion (40:1 sap-to-syrup ratio); unit conversion (gallons, liters); data analysis of annual production trends (Vermont produces ~2 million gallons/year); multi-step computation; percentage of national supply (~50%); cost per gallon calculations |
| **Dairy farm statistics** | Unit rates (gallons of milk per cow per day); proportional reasoning; data tables comparing farm sizes; area calculations for pastures; mean/median of herd sizes; fractions (portions of milk used for cheese vs. fluid milk) |
| **Seasonal agricultural data** | Time series data; graphing; elapsed time; temperature ranges for maple sap flow (above freezing days, below freezing nights); growing season calculations |

#### Geography & Recreation

| Topic | Mathematical Applications |
|---|---|
| **Ski resort elevation data** | Elevation gain/loss; slope calculations; vertical drop data (Stowe: 2,360 ft vertical; Killington: 3,050 ft vertical); distance-rate-time for ski runs; comparing resort statistics |
| **Lake Champlain dimensions** | Area and perimeter calculations; unit conversion (120 miles long, 12 miles wide, ~400 ft deep); volume estimation; proportional reasoning with map scales; data analysis of water quality measurements |
| **Green Mountain Trail distances** | Distance-rate-time; elapsed time; proportional reasoning; Long Trail statistics (273 miles end to end); elevation profile data; multi-step hiking time calculations |
| **Covered bridge measurements** | Length, width, height calculations; area; perimeter; scale drawings; comparing bridge dimensions across Vermont; ratio of covered bridges per county |

#### Community & Everyday Contexts

| Topic | Mathematical Applications |
|---|---|
| **Vermont town budgets** | Large numbers; percent; ratios; proportional reasoning; per capita calculations (Vermont population ~647,000) |
| **Farmers market pricing** | Unit price; discount; percent; multi-step computation; comparing prices across vendors |
| **Vermont weather data** | Temperature ranges (Burlington avg: 17F–83F); snowfall data; mean, median, mode; data displays; precipitation comparisons |
| **Vermont school data** | Enrollment statistics; ratios (student-to-teacher); percentages; data interpretation |

### Grade-Band Contextualization Notes

#### Grades 3–5

| Principle | Guidance |
|---|---|
| **Concreteness** | Contexts should involve tangible, observable quantities (maple sap buckets counted, dairy cows, trail distances) |
| **Accessibility** | Avoid highly specialized vocabulary; define Vermont-specific terms (sugarhouse, sugarbush, sap run) |
| **Scale of numbers** | Gr 3: within 1,000; Gr 5: multi-digit, decimals, fractions |

#### Grades 6–8

| Principle | Guidance |
|---|---|
| **Real data** | Use approximate real data (Vermont population ~647,000; Lake Champlain ~120 miles; Killington vertical 3,050 ft) |
| **Multiple representations** | Include tables, graphs, or diagrams alongside word problem contexts |
| **Social relevance** | Topics like maple syrup economics, farm sustainability, and Lake Champlain water quality connect to community life |

#### Grade 11

| Principle | Guidance |
|---|---|
| **Workforce readiness** | Career-relevant contexts (agriculture, tourism, forestry, healthcare) |
| **Complex data** | Multi-variable data sets; scatter plots; regression; real decision-making |
| **Equity lens** | Include data representing Vermont's diversity; avoid contexts that systematically advantage students from specific backgrounds |

### English Learner (EL) Considerations for Math

| Consideration | Guidance |
|---|---|
| **Mathematical vocabulary** | Pre-teach or define Tier 3 math vocabulary in a glossary |
| **Word problem language** | Use simple, direct sentence structure in word problem stems |
| **Bilingual glossary** | EL designated support; items should not be invalidated by glossary use |
| **Diagrams and visuals** | Use clear, labeled diagrams to reduce linguistic load |

## 11. Quality Checklist

Use this checklist before finalizing any generated item or item set.

### Standards Alignment

- [ ] Item is tagged to one primary CCSS Math standard (e.g., 7.RP.A.2)
- [ ] Standard matches the claim and subclaim
- [ ] DOK level is consistent with the cognitive demand of the task
- [ ] Grade-level standard is appropriate for the intended grade band
- [ ] Item does not require knowledge above or below grade level

### Calculator Policy

- [ ] Item is flagged as calculator or non-calculator consistent with grade-level policy (Section 3)
- [ ] Computational complexity is appropriate for the calculator policy
- [ ] Calculator-active items use numbers that would realistically benefit from a calculator

### Reference Sheet

- [ ] For Grades 8 and 11: item does not embed formulas on the reference sheet
- [ ] For Grades 3–7: item does not require formulas not taught at grade level

### Item Quality (All Types)

- [ ] Stem is a clear, unambiguous question or directive
- [ ] All numerical values are internally consistent
- [ ] Units are clearly specified and used correctly throughout
- [ ] Diagrams are clearly labeled, drawn to reasonable scale, and described in alt text
- [ ] Answer options for SR are plausible and each represents a specific student error
- [ ] Correct answer is verified independently (calculation checked)
- [ ] Word problem context is realistic and meaningful

### SCR and PT-ER Checks

- [ ] Constructed-response prompt requires both a numerical answer AND explanation/justification
- [ ] Rubric is included with the item
- [ ] PT-ER parts are interdependent and logically sequenced (A -> B -> C)
- [ ] Error-carried-forward (ECF) policy is noted
- [ ] Scoring guide anticipates common student errors

### EL and Accessibility

- [ ] Word problem language is clear and concise
- [ ] Mathematical vocabulary is appropriate for the grade
- [ ] Diagrams are usable with zoom or screen magnification
- [ ] Item does not require cultural knowledge that disadvantages EL students

## 12. Prompt Patterns

The following patterns map common user requests to generation strategies for the AI.

---

### Pattern 1: "Generate a math problem for Grade [X]"

**Interpretation:** Default to an SR item (1 point) for Claim 1 (Concepts & Procedures) at DOK 2. Use a real-world context from Section 10.

**Generation Recipe:**
1. Identify the primary content domain for the grade
2. Select a Vermont context from Section 10
3. Generate SR using Template 1, ensuring two mathematical steps
4. Construct four options where each distractor represents a distinct common error
5. Tag: state=VT, subject=MATH, grade=[X], claim=2, standard=[STANDARD], dok=2

---
