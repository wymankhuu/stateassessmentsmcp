## 1. Overview

| Field | Details |
|---|---|
| **State** | Michigan |
| **Assessment Name** | M-STEP (Michigan Student Test of Educational Progress) — Mathematics |
| **Grades Tested** | 3, 4, 5, 6, 7, 8, 11 |
| **Standards** | Michigan Academic Standards for Mathematics (CCSS-aligned) |
| **Vendor** | Michigan Department of Education (formerly PARCC-based) |
| **Administration** | April – May; computer-based |
| **Score Reporting** | Scale score; 4 performance levels |
| **High Stakes** | School and district accountability |

> **CRITICAL NOTE:** M-STEP Mathematics was formerly based on PARCC but is now administered by the Michigan DOE. The assessment retains PARCC-heritage item formats including Equation Response (EQ) items. Standards use Michigan Academic Standards codes aligned to CCSS-Math. Grade 11 M-STEP Math covers content through Algebra II and integrates modeling.

### Performance Levels

| Level | Name | Description |
|---|---|---|
| 4 | Advanced | Demonstrates thorough understanding; applies concepts flexibly and solves complex, non-routine problems |
| 3 | Proficient | Demonstrates adequate understanding of grade-level mathematics; solves problems accurately in familiar and moderately complex contexts |
| 2 | Partially Proficient | Demonstrates partial understanding; solves routine problems but struggles with multi-step or novel applications |
| 1 | Not Proficient | Does not demonstrate adequate understanding of grade-level mathematics |

## 3. Test Structure

M-STEP Mathematics is a two-unit assessment administered over two days. Calculator availability follows grade-level policy.

```
+------------------------------------------------------------------+
|          M-STEP MATHEMATICS STRUCTURE (Grades 3–8, 11)            |
+------------------------------------------------------------------+
|  UNIT 1 — Day 1                                                   |
|  ~60–80 minutes                                                   |
|  Mix of reporting categories                                      |
|  Item types: MC, MS, EQ                                           |
|  ~18–24 items                                                     |
|                                                                    |
+------------------------------------------------------------------+
|  UNIT 2 — Day 2                                                   |
|  ~60–80 minutes                                                   |
|  Mix of reporting categories                                      |
|  Item types: MC, MS, EQ, CR                                       |
|  ~18–24 items (includes Constructed Response)                     |
+------------------------------------------------------------------+
```

### Item Type Summary

| Item Type | Abbreviation | Points | Scored | Unit |
|---|---|---|---|---|
| Multiple Choice | MC | 1 | Machine | 1 and 2 |
| Multi-Select | MS | 1 | Machine | 1 and 2 |
| Equation/Numeric Entry | EQ | 1 | Machine | 1 and 2 |
| Constructed Response | CR | 0–2 or 0–4 | Human | 2 |

### Grade-Level Test Specifications

| Grade | Total Items (approx.) | Unit 1 Items | Unit 2 Items | CR Items |
|---|---|---|---|---|

## 5. Item Types & Formats

### Multiple Choice (MC) — 1 Point

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Real-world or mathematical context                      |
|  Machine scored                                          |
|  DOK 1–3                                                 |
+----------------------------------------------------------+
```

**MC Example (Grade 6, DOK 2, MI.Math.6.RP.A.3):**

A family drives from Detroit to Mackinac City, a distance of approximately 280 miles. They travel at an average speed of 56 miles per hour. How many hours will the drive take?

A. 4 hours
B. 5 hours
C. 6 hours
D. 7 hours

*Correct Answer: B*
*Alignment: MI.Math.6.RP.A.3 | Number & Operations | DOK 2*

---

### Multi-Select (MS) — 1 Point

```
+----------------------------------------------------------+
|  MULTI-SELECT — 1 point                                  |
|                                                          |
|  5–6 options; select ALL correct answers (2–3)           |
|  Full credit only; no partial credit                     |
|  Machine scored                                          |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**MS Example (Grade 8, DOK 2, MI.Math.8.EE.C.8):**

Select ALL ordered pairs that are solutions to the system of equations:
y = 2x + 1
y = -x + 7

A. (2, 5)
B. (3, 4)
C. (1, 3)
D. (0, 7)
E. (2, 5) and (3, 4)

*Correct Answer: A*
*Alignment: MI.Math.8.EE.C.8 | Algebra & Functions | DOK 2*

---

### Equation/Numeric Entry (EQ) — 1 Point

```
+----------------------------------------------------------+
|  EQUATION / NUMERIC ENTRY — 1 point                      |
|                                                          |
|  Student types numeric answer, fraction, or expression   |
|  No answer choices provided                              |
|  Machine scored                                          |
|  DOK 1–2                                                 |
+----------------------------------------------------------+
```

**EQ Example (Grade 4, DOK 2, MI.Math.4.MD.A.3):**

A rectangular cherry orchard near Traverse City measures 120 feet long and 85 feet wide. What is the area of the orchard in square feet?

Enter your answer: **10,200**

*Alignment: MI.Math.4.MD.A.3 | Geometry & Measurement | DOK 2*

### Constructed Response (CR) — 0–2 or 0–4 Points

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE — 0–2 or 0–4 points                |
|                                                          |
|  Short CR: Show work + brief explanation (0–2 pts)       |
|  Extended CR: Multi-part with justification (0–4 pts)    |
|  Human scored                                            |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**Short CR Example (Grade 7, DOK 3, MI.Math.7.RP.A.2):**

A fishing charter on Lake Michigan charges $45 per person for groups of up to 6 people or a flat rate of $210 for groups of 6 or more. A group of 5 friends wants to go fishing. Should they invite one more person to get the group rate? Show your work and explain your reasoning.

**Extended CR Example (Grade 11, DOK 3):**

*Part A:* The Mackinac Bridge is approximately 26,372 feet long. A construction crew needs to repaint lane markings at a rate of 350 feet per hour. Write an equation to represent the total feet remaining as a function of hours worked.

*Part B:* How many 8-hour workdays will the crew need to complete the job? Show your work.

*Part C:* If a second crew is added that paints at 275 feet per hour, write a new function and determine how many 8-hour workdays are needed. Explain whether adding the second crew cuts the time in half.

## 8. Scoring Rubrics

### Short Constructed Response (CR) Rubric — 0–2 Points

| Score | Criteria |
|---|---|
| 2 | Correct solution with clear mathematical reasoning. Work shown systematically. Appropriate mathematical vocabulary used. Explanation demonstrates conceptual understanding. |
| 1 | Partial understanding with minor errors. Correct approach demonstrated even if the final answer contains a computational error. OR Correct answer given without sufficient explanation or work. |
| 0 | Incorrect, shows no mathematical understanding, or blank. |

### Extended Constructed Response (CR) Rubric — 0–4 Points

| Score | Criteria |
|---|---|
| 4 | All parts correct with clear, complete mathematical reasoning. Work shown systematically. Explanations accurate, thorough, and demonstrate strong conceptual understanding. |
| 3 | Correct approach throughout with mostly accurate results. One minor computational or notational error that does not undermine overall reasoning. Explanations present and generally sound. |
| 2 | Correct approach on the majority of parts. One significant error or one part incomplete; some valid reasoning present. Partial explanations provided. |
| 1 | Minimal understanding shown. Correct approach on at least one element; some relevant mathematical work attempted but reasoning is largely incomplete or flawed. |
| 0 | Incorrect, irrelevant, or blank. No valid mathematical reasoning demonstrated. |

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] MI.Math standard code is accurate and grade-appropriate (including Grade 11 HS standards)
- [ ] Unit assignment is correct (CR items in Unit 2)
- [ ] Reporting category alignment matches the content domain tested
- [ ] CR items require work to be shown (not just a final answer)
- [ ] Extended CR has 2–3 parts of increasing complexity
- [ ] MS items specify "ALL" or number of correct answers; 5–6 options provided
- [ ] Michigan real-world context used where appropriate
- [ ] Distractors represent actual student computational or conceptual errors
- [ ] All computations verified before item is finalized
- [ ] DOK level matches the actual cognitive demand
- [ ] Calculator assumptions appropriate for the target grade band
- [ ] 4 performance levels referenced (Not Proficient, Partially Proficient, Proficient, Advanced)

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Using CCSS codes without MI prefix | Michigan uses MI.Math prefix | Add MI.Math to all standard codes |
| CR items placed in Unit 1 | Constructed Response items belong in Unit 2 | Move CR items to Unit 2 only |
| CR that only asks for an answer | CR must require explanation/justification | Add "Show your work and explain your reasoning" |
| Forgetting Grade 11 | M-STEP tests Math at Grade 11 | Include Grade 11 in item generation; use HS standards |
| Using 5 performance levels | Michigan uses 4 levels | Use: Not Proficient, Partially Proficient, Proficient, Advanced |
| Items testing only rote computation | M-STEP targets DOK 2 at ~55% | Add real-world context to elevate cognitive demand |
| Generic contexts | M-STEP benefits from Michigan settings | Use Great Lakes, Detroit, Mackinac Bridge, cherry orchards |

## 12. Prompt Patterns

### Pattern 1: Real-World Application (MC, DOK 2)
> "[Michigan context — e.g., cherry production, Great Lakes data]. [Multi-step problem requiring application of concept]. What is [answer]?"

### Pattern 2: Justify and Explain (CR, DOK 3)
> "[Michigan scenario requiring strategic thinking — e.g., Mackinac Bridge measurements]. [Multi-step problem]. Show your work and explain how you found your answer."

### Pattern 3: Equivalent Representations (MS, DOK 2)
> "Select ALL [expressions / equations / values] that are equivalent to [given value or expression]."

### Pattern 4: Data Interpretation (MC or CR, DOK 2–3)
> "The [table / graph] shows [Michigan data context — e.g., Lake Michigan water levels, Detroit population trends]. What is the [mean / rate of change / trend] shown by the data?"

### Pattern 5: Multi-Part Modeling (CR, DOK 3)
> "Part A: [Direct calculation using Michigan context]. Part B: [Extension or comparison]. Part C: [Justify whether... / Evaluate if this is reasonable using mathematics]."

### Pattern 6: Comparison and Reasoning (CR, DOK 3)
> "Two students solved this problem differently. Student A says [method/answer]. Student B says [method/answer]. Who is correct? Use mathematics to justify your answer."

### Pattern 7: Numeric Entry (EQ, DOK 1–2)
> "[Michigan context — e.g., a rectangular cherry orchard, Sleeping Bear Dunes trail]. [Computation or measurement problem]. Enter your answer."
