## 1. Overview

| Field | Details |
|---|---|
| **State** | Michigan |
| **Assessment Name** | M-STEP (Michigan Student Test of Educational Progress) — English Language Arts |
| **Grades Tested** | 3, 4, 5, 6, 7, 8, 11 |
| **Standards** | Michigan Academic Standards for ELA (CCSS-aligned) |
| **Vendor** | Michigan Department of Education (formerly PARCC-based) |
| **Administration** | April – May; computer-based |
| **Score Reporting** | Scale score; 4 performance levels |
| **High Stakes** | Third Grade Reading Law (Grade 3 retention); school accountability |

> **CRITICAL NOTE:** M-STEP was formerly based on PARCC but Michigan has since taken ownership of the assessment through the Michigan DOE. Item formats retain some PARCC heritage (EBSR, technology-enhanced items). Standards use Michigan Academic Standards codes, which are aligned to CCSS but use Michigan-specific prefixes.

### Performance Levels

| Level | Name | Description |
|---|---|---|
| 4 | Advanced | Demonstrates thorough understanding; applies skills flexibly in complex texts and tasks |
| 3 | Proficient | Demonstrates adequate understanding of grade-level ELA expectations |
| 2 | Partially Proficient | Demonstrates partial understanding; approaching grade-level expectations |
| 1 | Not Proficient | Does not demonstrate adequate understanding of grade-level ELA expectations |

> **Michigan Third Grade Reading Law:** Students scoring Not Proficient on Grade 3 M-STEP ELA may be subject to retention unless qualifying for a Good Cause Exemption.

## 3. Test Structure

M-STEP ELA is administered across two units over two days. Grade 11 includes an additional writing component.

```
+------------------------------------------------------------------+
|            M-STEP ELA STRUCTURE (Grades 3–8, 11)                  |
+------------------------------------------------------------------+
|  UNIT 1 — Day 1 (~60–80 minutes)                                 |
|  ┌────────────────────────────────────────┐                       |
|  │ READING SECTION                        │                       |
|  │ • 2–3 literary and informational       │                       |
|  │   passages                             │                       |
|  │ • MC, EBSR, Technology Enhanced items  │                       |
|  └────────────────────────────────────────┘                       |
|                                                                    |
|  UNIT 2 — Day 2 (~60–80 minutes)                                  |
|  ┌────────────────────────────────────────┐                       |
|  │ READING + WRITING SECTION              │                       |
|  │ • 2–3 passages (informational focus)   │                       |
|  │ • MC, EBSR, Technology Enhanced items  │                       |
|  │ • Constructed Response (CR) writing    │                       |
|  └────────────────────────────────────────┘                       |
+------------------------------------------------------------------+
```

### Test Component Summary

| Component | Item Types | Points |
|---|---|---|
| Multiple Choice (MC) | 4 options (A–D); 1 pt each | ~18–24 pts |
| Evidence-Based Selected Response (EBSR) | Two-part: Part A + Part B; 2 pts each | ~8–14 pts |
| Technology Enhanced (TE) | Drag-and-drop, multi-select, drop-down; 1–2 pts each | ~4–8 pts |
| Constructed Response (CR) | Written response; 0–2 or 0–4 pts | ~4–8 pts |
| **Total** | | **~38–54 pts** |

## 5. Item Types & Formats

### Multiple Choice (MC) — 1 Point

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|  4 options (A, B, C, D)                                  |
|  Passage-dependent                                       |
|  Machine scored                                          |
|  DOK 1–3                                                 |
+----------------------------------------------------------+
```

**MC Example (Grade 5, Literary, DOK 2, MI.ELA.RL.5.2):**

*[After reading a short story about a family visiting Mackinac Island]*

Which statement BEST expresses a theme of the story?

A. Exploring new places is always exciting for families
B. Learning about history helps people appreciate the present
C. Everyone should visit Michigan's most popular landmarks
D. Technology makes travel easier than it used to be

*Correct Answer: B*
*Alignment: MI.ELA.RL.5.2 | DOK 2*

---

### Evidence-Based Selected Response (EBSR) — 2 Points

```
+----------------------------------------------------------+
|  EVIDENCE-BASED SELECTED RESPONSE — 2 points             |
|                                                          |
|  Part A: Inference or analysis question (1 pt)           |
|  Part B: Select evidence that supports Part A (1 pt)     |
|  Passage-dependent                                       |
|  Machine scored                                          |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**EBSR Example (Grade 7, Informational, DOK 3, MI.ELA.RI.7.6):**

*[After reading an article about the history of the Detroit automotive industry]*

**Part A:** What is the author's primary purpose in writing this article?

A. To persuade readers that Detroit should invest more in electric vehicles
B. To explain how the automotive industry shaped Detroit's identity and economy
C. To compare Detroit's factories with those in other major cities
D. To entertain readers with stories about early car inventors

**Part B:** Which sentence from the article BEST supports your answer in Part A?

A. "By 1920, Detroit's population had quadrupled as workers streamed in from across the country."
B. "Some historians argue that electric vehicles will revitalize the city."
C. "Henry Ford's assembly line revolutionized manufacturing worldwide."
D. "Detroit's factory workers earned wages that built neighborhoods, schools, and a thriving middle class."

*Correct Answers: Part A: B, Part B: D*
*Alignment: MI.ELA.RI.7.6 | DOK 3*

### Technology Enhanced (TE) — 1–2 Points

```
+----------------------------------------------------------+
|  TECHNOLOGY ENHANCED — 1–2 points                        |
|                                                          |
|  Formats: drag-and-drop, multi-select, drop-down menu   |
|  Passage-dependent                                       |
|  Machine scored                                          |
|  DOK 2–3                                                 |

```

**TE Example (Grade 4, Informational, DOK 2, MI.ELA.RI.4.5):**

*[After reading an article about Michigan lighthouses]*

Drag each detail to the correct section of the article where it appears.

| Detail | Article Section |
|---|---|
| "Over 120 lighthouses line Michigan's coastline" | Introduction |

| "Many lighthouses are now museums open to visitors" | Lighthouses Today |

### Constructed Response (CR) — 0–2 or 0–4 Points

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE — 0–2 or 0–4 points                |
|                                                          |
|  Short CR: 2–4 sentences (0–2 pts)                       |
|  Extended CR: multi-paragraph essay (0–4 pts)            |
|  Must cite textual evidence                              |
|  Human scored                                            |
|  DOK 3–4                                                 |
+----------------------------------------------------------+
```

**Short CR Example (Grade 6, Literary, DOK 3, MI.ELA.RL.6.3):**

*[After reading a story set along the shores of Lake Michigan]*

How does the setting of the story influence the main character's decision at the end? Use TWO details from the story to support your answer.

**Extended CR Example (Grade 11):**

*[After reading two informational texts about the Underground Railroad in Michigan]*

Write a well-developed essay explaining how Michigan's geography and communities played a role in the Underground Railroad. Use evidence from BOTH texts to support your response.

## 8. Scoring Rubrics

### Short Constructed Response (CR) Rubric — 0–2 Points

| Score | Criteria |
|---|---|
| 2 | Accurate, specific response that fully addresses the prompt. Includes relevant textual evidence (quoted or paraphrased) that directly supports the answer. Clear reasoning. |
| 1 | Partially accurate response. OR Accurate response without sufficient textual evidence. Minor gaps in reasoning. |
| 0 | Inaccurate, irrelevant, too brief to evaluate, or blank. |

### Extended Constructed Response (CR) Rubric — 0–4 Points

| Score | Criteria |
|---|---|
| 4 | Clear, focused response that fully addresses the prompt. Synthesizes evidence from all provided sources with clear elaboration. Well organized with effective transitions. Strong command of conventions. |
| 3 | Response addresses the prompt adequately. Uses evidence from sources, though synthesis may be uneven. Organization is evident. Minor errors in conventions. |
| 2 | Partial response. Shows some understanding but uses limited evidence. Organization is inconsistent. Some errors in conventions. |
| 1 | Minimal response. Little evidence used, weak organization, frequent errors. |
| 0 | Blank, off-task, or copied from sources without original analysis. |

```
ITEM TEMPLATE: EBSR — Evidence-Based Analysis (DOK 3)
------------------------------------------------------
TARGET STANDARD: MI.ELA.RI.[GRADE].6 or MI.ELA.RL.[GRADE].6
PASSAGE TYPE: Literary or Informational
DOK LEVEL: 3
POINT VALUE: 2 points (Part A: 1 pt + Part B: 1 pt)

PART A STEM:
"What is the author's [purpose / point of view / perspective]
 in this [article / passage / text]?"

PART A OPTIONS:
A [Distractor — partially correct but too narrow]
B [CORRECT — accurate identification of purpose/point of view]
C [Distractor — confuses purpose with topic]
D [Distractor — opposite of the author's actual purpose]

PART B STEM:
"Which [sentence / detail] from the text BEST supports
 your answer in Part A?"

PART B OPTIONS:
A [Distractor — from passage but supports a different interpretation]
B [Distractor — tangentially related to Part A answer]
C [Distractor — explicitly stated but does not support Part A]
D [CORRECT — directly supports the Part A answer with evidence]

ALIGNMENT: MI.ELA.RI.[GRADE].6 or MI.ELA.RL.[GRADE].6 | DOK 3
```

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] MI.ELA standard code verified for grade level (including Grade 11)
- [ ] MC items are passage-dependent with 4 answer options
- [ ] EBSR items have two parts: Part A (inference) + Part B (evidence)
- [ ] EBSR Part B answer must logically support the Part A answer
- [ ] CR prompts require textual evidence explicitly
- [ ] Extended CR prompt specifies source set (2+ passages)
- [ ] Passage Lexile within grade-level range (see Section 7)
- [ ] Technology Enhanced items use appropriate digital format (drag-and-drop, multi-select, drop-down)
- [ ] Michigan context incorporated where appropriate
- [ ] 4 performance levels referenced (Not Proficient, Partially Proficient, Proficient, Advanced)

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Using CCSS codes without MI prefix | Michigan uses MI.ELA prefix | Add MI.ELA to all standard codes |
| EBSR with unrelated Part A / Part B | Part B evidence must support Part A answer | Verify logical connection between parts |
| Forgetting Grade 11 | M-STEP tests ELA at Grade 11 too | Include Grade 11 in item generation plans |
| Using 5 performance levels | Michigan uses 4 levels | Use: Not Proficient, Partially Proficient, Proficient, Advanced |
| CR without evidence requirement | M-STEP CR demands textual evidence | Include "Use details/evidence from the text" in all CR prompts |
| Generic Midwest contexts | M-STEP favors Michigan-specific settings | Use Great Lakes, Detroit, Mackinac Island, cherry orchards |

## 12. Prompt Patterns

### Pattern 1: Literary Theme (MC, DOK 2–3)
> "Which statement BEST expresses a theme of the [story / poem]?"

### Pattern 2: Evidence-Based Analysis (EBSR, DOK 3)
> "Part A: What is the author's [purpose / point of view] in this article? Part B: Which sentence from the text BEST supports your answer in Part A?"

### Pattern 3: Vocabulary in Context (MC, DOK 2)
> "As used in paragraph [#], what does the word [TARGET_WORD] most likely mean?"

### Pattern 4: Text Structure (TE, DOK 2)
> "Drag each detail to the section of the article where it belongs."

### Pattern 5: Extended Response — Synthesis (CR, DOK 3–4)
> "Write a well-developed essay explaining [TOPIC]. Use evidence from BOTH texts to support your response."

### Pattern 6: Character/Setting Analysis (MC or CR, DOK 3)
> "How does the [setting / character's actions / conflict] in the story contribute to the development of the theme?"

### Pattern 7: Cross-Text Comparison (EBSR or CR, DOK 3)
> "Both texts address [SHARED TOPIC]. How do the authors' perspectives on [TOPIC] differ? Use evidence from both texts."
