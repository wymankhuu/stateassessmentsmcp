## 1. Overview

| Field | Details |
|---|---|
| **State** | Michigan |
| **Assessment Name** | M-STEP (Michigan Student Test of Educational Progress) — Science |
| **Grades Tested** | **Grade 5, Grade 8, Grade 11** |
| **Standards** | Michigan Science Standards (NGSS-based, Michigan-adopted) |
| **Vendor** | Michigan Department of Education |
| **Administration** | April – May; computer-based; single session per grade |
| **Score Reporting** | Scale score; 4 performance levels |
| **Reporting** | Individual Student Report; School, District, State aggregates |

> **CRITICAL NOTE:** M-STEP Science is administered at **Grades 5, 8, and 11 only**. Do not generate M-STEP Science items for other grades. Michigan adopted the Next Generation Science Standards (NGSS) and uses Michigan Science Standards codes (MI.SCI prefix), which closely mirror NGSS Performance Expectations but may have Michigan-specific clarifications.

> **Michigan Science Standards vs. NGSS:** Michigan adopted NGSS in 2015 with minor modifications. Items should align to Michigan Science Standards codes (MI.SCI), which correspond to NGSS PEs but use Michigan's own coding. Items must reflect three-dimensional learning: Disciplinary Core Ideas (DCIs), Science and Engineering Practices (SEPs), and Crosscutting Concepts (CCCs).

### Performance Levels

| Level | Name | Description |
|---|---|---|
| 4 | Advanced | Demonstrates thorough understanding of science concepts; applies three-dimensional reasoning to complex phenomena |
| 3 | Proficient | Demonstrates adequate understanding of grade-level science expectations; applies practices and concepts appropriately |
| 2 | Partially Proficient | Demonstrates partial understanding; recalls some content but struggles with application and multi-step reasoning |
| 1 | Not Proficient | Does not demonstrate adequate understanding of grade-level science expectations |

## 3. Test Structure

M-STEP Science is a single-session, computer-based assessment. Items are anchored in phenomena and require three-dimensional reasoning.

```
+------------------------------------------------------------------+
|         M-STEP SCIENCE STRUCTURE (Grades 5, 8, 11)                |
+------------------------------------------------------------------+
|  SINGLE SESSION                                                   |
|  Computer-Based                                                   |
|  Approximately 80–120 minutes (untimed, with guidelines)          |
|                                                                    |
|  ~35–45 items per grade                                           |
|                                                                    |
|  Item types:                                                       |
|    • Multiple Choice (MC) — ~50% (~18–22 items; 1 pt each)       |
|    • Multi-Select (MS) — ~15% (~5–7 items; 1 pt each)            |
|    • Technology Enhanced (TE) — ~15% (~5–7 items; 1–2 pts each)  |
|    • Constructed Response (CR) — ~20% (~7–9 items; 0–2 or 0–4)   |
+------------------------------------------------------------------+
```

### Grade-Level Test Specifications

| Specification | Grade 5 | Grade 8 | Grade 11 |
|---|---|---|---|
| Total Items (approx.) | ~35–40 | ~38–42 | ~38–45 |
| Multiple Choice (MC) | ~18–20 | ~19–22 | ~19–22 |
| Multi-Select (MS) | ~5–6 | ~5–7 | ~5–7 |
| Technology Enhanced (TE) | ~5–6 | ~5–7 | ~5–7 |
| Constructed Response (CR) | ~7–8 | ~7–9 | ~7–9 |

> **Three-Dimensional Requirement:** All items must assess at least two dimensions of science learning. Stimulus-based item clusters (3–5 items sharing a common phenomenon) are common.

## 5. Item Types & Formats

### Multiple Choice (MC) — 1 Point

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Phenomenon or stimulus anchored                         |
|  Machine scored                                          |
|  DOK 1–2                                                 |
+----------------------------------------------------------+
```

**MC Example (Grade 8, DOK 2, MI.SCI.MS-ESS2-2):**

Scientists studying the Sleeping Bear Dunes observed that the sand dunes along Lake Michigan shift position over decades. Which process BEST explains why these sand dunes change shape over time?

A. Volcanic activity beneath the dunes pushes sand upward
B. Wind and wave action erode, transport, and deposit sand particles
C. Chemical weathering dissolves the sand grains into smaller pieces
D. Earthquakes along the Great Lakes fault lines rearrange the sand

*Correct Answer: B*
*Alignment: MI.SCI.MS-ESS2-2 | SEP: Constructing Explanations | CCC: Cause and Effect | DOK 2*

---

### Multi-Select (MS) — 1 Point

```
+----------------------------------------------------------+
|  MULTI-SELECT — 1 point                                  |
|                                                          |
|  5–6 options; select exactly 2 or 3 correct answers      |
|  All must be selected for full credit                    |
|  Machine scored                                          |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**MS Example (Grade 5, DOK 2, MI.SCI.5-ESS2-1):**

A Michigan farmer notices that after heavy spring rains, the creek running through the farm becomes muddy and the soil along the bank is washed away. Select the TWO Earth systems that are interacting in this scenario.

A. Geosphere and atmosphere
B. Hydrosphere and geosphere
C. Biosphere and atmosphere
D. Hydrosphere and atmosphere
E. Geosphere and biosphere

*Correct Answers: B, D*
*Alignment: MI.SCI.5-ESS2-1 | SEP: Developing Models | CCC: Systems and System Models | DOK 2*

---

### Technology Enhanced (TE) — 1–2 Points

```
+----------------------------------------------------------+
|  TECHNOLOGY ENHANCED — 1–2 points                        |
|                                                          |
|  Formats: drag-and-drop, sorting, graphing, labeling     |
|  Stimulus always provided                                |
|  Machine scored                                          |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**TE Example (Grade 8, DOK 2, MI.SCI.MS-LS2-4):**

*Stimulus: Data table showing moose and wolf populations on Isle Royale from 2000 to 2020.*

Drag the labels to correctly identify the predator-prey relationship shown in the data:
- When wolf population increases → [moose population decreases]
- When moose population decreases → [available vegetation increases]
- When wolf population drops sharply → [moose population increases]

### Constructed Response (CR) — 0–2 or 0–4 Points

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE — 0–2 or 0–4 points                |
|                                                          |
|  Short CR: 3–5 sentences (0–2 pts)                       |
|  Extended CR: multi-part, 5–10 sentences (0–4 pts)       |
|  Must use evidence from stimulus                         |
|  Human scored                                            |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**Short CR Example (Grade 5, DOK 2, MI.SCI.5-LS2-1):**

*Stimulus: Diagram of a Michigan forest food web showing oak trees, deer, wolves, mushrooms (decomposers), and soil nutrients.*

Using the diagram, explain how matter moves from a dead deer back to the oak trees. Describe the role of decomposers in this process.

**Extended CR Example (Grade 11, DOK 3, MI.SCI.HS-ESS3-4):**

*Stimulus: Data table showing phosphorus levels, algal bloom coverage, and fish population in a section of Lake Erie from 2010 to 2024.*

Part A: Using evidence from the data, explain the relationship between phosphorus levels and algal bloom coverage in Lake Erie. Identify the cause-and-effect relationship.

Part B: A local government proposes requiring farmers within 5 miles of the lake to reduce fertilizer use by 30%. Evaluate this solution using evidence from the data. Explain one advantage and one limitation of this approach.

## 7. Three-Dimensional Design

Michigan Science Standards integrate three dimensions of science learning. All items should reflect at least two dimensions.

### Three Dimensions

| Dimension | What It Is | Example in M-STEP Items |
|---|---|---|
| **Disciplinary Core Ideas (DCIs)** | Content knowledge: Physical, Life, Earth/Space Science | Properties of matter; ecosystem dynamics; Great Lakes geology; heredity |
| **Science and Engineering Practices (SEPs)** | How students do science | Analyze Isle Royale population data; design an investigation to test water quality; construct an explanation for dune formation |
| **Crosscutting Concepts (CCCs)** | Themes that bridge disciplines | Cause and effect; systems and system models; energy and matter; patterns; stability and change |

### Crosscutting Concepts Emphasized

| Crosscutting Concept | Grade 5 Emphasis | Grade 8 Emphasis | Grade 11 Emphasis |
|---|---|---|---|
| Patterns | Seasonal weather; organism traits | Population trends; periodic table | Mathematical patterns in data |
| Cause and Effect | Erosion; food web disruptions | Predator-prey; chemical reactions | Human impact on ecosystems |
| Energy and Matter | Food web energy flow; water cycle | Energy transformations; matter cycling | Ecosystem energy flow; conservation |
| Systems and System Models | Earth systems; watersheds | Ecosystems; water cycle | Complex ecosystems; Earth systems |
| Stability and Change | Erosion/deposition; seasons | Population dynamics; geological change | Ecosystem resilience; climate change |

### Sample Three-Dimensional Item Design (Grade 8)

```
+------------------------------------------------------------------+
|  THREE-DIMENSIONAL ITEM STRUCTURE                                 |
|                                                                    |
|  PHENOMENON: Wolf populations on Isle Royale crashed to 2        |
|  individuals by 2016, then were supplemented by relocating       |
|  wolves from the mainland. (Authentic Michigan phenomenon)        |
|                                                                    |
|  DCI: MI.SCI.MS-LS2-4 (Ecosystem dynamics)                       |
|  SEP: Analyzing and Interpreting Data                             |
|  CCC: Cause and Effect; Stability and Change                     |
|                                                                    |
|  STIMULUS: Data table — wolf population, moose population,       |
|  and balsam fir sapling density on Isle Royale, 2010–2024        |
|                                                                    |
|  PROMPT: "Part A: Using data from the table, explain how the     |
|  decline in wolf populations affected moose and balsam fir       |
|  populations. Include specific evidence.                          |
|  Part B: Predict how the ecosystem will change now that          |
|  wolves have been reintroduced. Explain your reasoning           |
|  using the data."                                                 |
+------------------------------------------------------------------+
```

## 8. Scoring Rubrics

### Short Constructed Response (CR) Rubric — 0–2 Points

| Score | Criteria |
|---|---|
| 2 | Accurately addresses the science concept; uses specific stimulus evidence; complete explanation demonstrating understanding of practices and core ideas |
| 1 | Partially addresses the concept; evidence present but incomplete; basic understanding with minor gaps or inaccuracy |
| 0 | Blank; off-topic; restates stimulus without explanation; no science understanding demonstrated |

### Extended Constructed Response (CR) Rubric — 0–4 Points

| Score | Criteria |
|---|---|
| 4 | Fully addresses all parts; thorough content understanding; specific stimulus evidence with clear reasoning; strong integration of practices and crosscutting concepts |
| 3 | Addresses all parts with mostly accurate content; evidence present but slightly incomplete; solid reasoning with minor gaps |
| 2 | Addresses some parts; partial understanding; evidence vague or loosely connected; reasoning underdeveloped |
| 1 | Minimal response; limited understanding; little or no stimulus evidence; vague or contains significant inaccuracies |
| 0 | Blank; off-topic; restates stimulus without explanation; no science understanding demonstrated |

### CR Scoring Notes

- **Evidence from the stimulus is required.** Responses relying solely on prior knowledge cannot earn the highest score.
- **Multi-part prompts require multi-part responses.** A complete response to only Part A earns a maximum of 2 points on extended CR.
- **Three-dimensional reasoning is valued.** Responses that integrate practices and crosscutting concepts with content knowledge score higher.
- **Michigan-relevant application is valued.** Connecting science to authentic Michigan phenomena demonstrates higher-level understanding.

### Suggested Anchoring Phenomena by Grade

**Grade 5 Phenomena:**
- "Michigan farmers near Traverse City noticed that cherry trees bloom earlier in years when Lake Michigan water is warmer in spring. How does the lake affect the local climate and growing season?"
- "After a heavy rainstorm, students at a school near the Huron River noticed the water turned brown and muddy, but a nearby pond surrounded by trees stayed clear. What caused this difference?"

- "Scientists studying Isle Royale observed that when the wolf population crashed to just 2 animals in 2016, the moose population exploded and young balsam fir trees nearly disappeared. What ecological relationships explain these changes?"

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] Grade verified as **5, 8, or 11 ONLY**
- [ ] Standard code uses MI.SCI prefix and is a valid Michigan Science Standard
- [ ] Item is three-dimensional: integrates DCI with at least one SEP and one CCC
- [ ] Anchoring phenomenon is authentic and Michigan-relevant where possible
- [ ] Stimulus has clear labels, units, and realistic data
- [ ] CR prompts direct students to use evidence from the stimulus
- [ ] All MC/MS distractors represent real misconceptions (not obviously wrong)
- [ ] MS items specify how many answers to select (TWO or THREE)
- [ ] CR-Extended items use Part A / Part B multi-part structure
- [ ] Extended CR anchor response (Score 4) written before finalizing
- [ ] Science content is accurate; vocabulary is grade-appropriate
- [ ] 4 performance levels referenced (Not Proficient, Partially Proficient, Proficient, Advanced)

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Writing items for untested grades | M-STEP Science tests only Grades 5, 8, 11 | Restrict to tested grades |
| Using raw NGSS PE codes | Michigan uses MI.SCI prefix | Use MI.SCI codes with Michigan numbering |
| One-dimensional items (content only) | Michigan requires three-dimensional learning | Embed SEPs and CCCs alongside DCIs |
| CR prompts without evidence directive | Students may skip citing data | Include "Using evidence from the [stimulus]" in all CR prompts |
| Using 5 performance levels | Michigan uses 4 levels | Use: Not Proficient, Partially Proficient, Proficient, Advanced |
| Generic Great Lakes phenomena | M-STEP benefits from Michigan-specific settings | Use Isle Royale, Sleeping Bear Dunes, Keweenaw copper, Michigan forests |
| MS items with only 4 options | Too easy to guess | Use 5–6 options with 2–3 correct |
| CR-Extended with single-part prompts | Should require multi-step reasoning | Use Part A / Part B structure |
| Ignoring engineering practices | Michigan standards include engineering design | Include design-solution items |

## 12. Prompt Patterns

### Pattern 1: Data-to-Conclusion (MC, DOK 2)
> "The [graph / table / diagram] shows [Michigan phenomenon]. Based on the data, which [conclusion / explanation / pattern] is BEST supported?"

### Pattern 2: Phenomenon Explanation (CR-Extended, DOK 3)
> "Scientists observed [Michigan phenomenon — e.g., Isle Royale population changes]. Part A: Using evidence from the [stimulus], explain [science focus] and the cause-and-effect relationship. Part B: Predict what would happen if [variable changed]. Explain your reasoning using evidence."

### Pattern 3: Model Evaluation (MC or MS, DOK 2–3)
> "A student made a model showing [Michigan science concept — e.g., Great Lakes water cycle]. Which statement BEST describes what the model shows? / Select the TWO statements that correctly describe the model."

### Pattern 4: Investigation Design (CR-Extended, DOK 3)
> "A scientist wants to investigate whether [variable] affects [outcome] in [Michigan context — e.g., Lake Michigan water quality]. Part A: Describe a procedure including variables to measure and control. Part B: Predict results if the hypothesis is correct."

### Pattern 5: Evidence-Based Argument (CR-Short or CR-Extended, DOK 2–3)
> "Two students disagree about [Michigan science claim — e.g., why sand dunes migrate]. Student A says [misconception]. Student B says [accurate claim]. Using evidence, explain which student is correct and why."

### Pattern 6: Engineering Design and Solutions (MS or CR, DOK 2–3)
> "Michigan communities need to [address environmental challenge — e.g., reduce Great Lakes pollution]. Select TWO strategies that would BEST help. / Propose a solution and explain how it uses science concepts."
