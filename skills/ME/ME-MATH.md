## 1. Overview

| Field | Detail |
|---|---|
| **Assessment Name** | Maine Educational Assessment (MEA) — Mathematics (Smarter Balanced) |
| **Consortium** | Smarter Balanced Assessment Consortium (SBAC) |
| **Administering Agency** | Maine Department of Education (Maine DOE) |
| **Grades Tested** | 3, 4, 5, 6, 7, 8, 11 |
| **Testing Window** | April – May (operational window; districts schedule within this range) |
| **Delivery** | Computer-adaptive (CAT) for Part 1 (non-calculator + calculator); fixed-form Performance Task for Part 2 |
| **Standards** | Common Core State Standards for Mathematics (CCSS-M) as adopted by Maine |
| **Score Scale** | 2000–3000 scale score (varies by grade) |
| **Reporting** | Individual Student Report (ISR); School, District, State aggregate reports |

### Achievement Level Descriptors (ALDs)

| Level | Label | Description |
|---|---|---|
| 4 | **Standard Exceeded** | Student demonstrates sophisticated understanding; applies mathematics fluently in novel situations; constructs valid mathematical arguments |
| 3 | **Standard Met** | Student demonstrates adequate understanding; applies mathematics to real-world problems with reasonable accuracy |
| 2 | **Standard Nearly Met** | Student demonstrates partial understanding; applies procedures in familiar contexts but struggles with novel problems |
| 1 | **Standard Not Met** | Student demonstrates minimal understanding; unable to apply grade-level concepts or procedures |

> **Cut scores** are set by the Smarter Balanced Assessment Consortium and adopted by the Maine State Board of Education. Target ALDs 3 and 4 for item-writing.

## 4. Claims & Blueprint

### Claim Structure

| Claim | Description | Point Weight | Primary Focus |
|---|---|---|---|
| **Claim 1 — Concepts & Procedures** | Explain and apply mathematical concepts; carry out procedures with precision and fluency | **40%** | Procedural fluency; conceptual understanding |
| **Claim 2 — Problem Solving** | Solve complex well-posed problems in pure and applied mathematics | **25%** | Multi-step problems; strategy selection; real-world contexts |
| **Claim 3 — Communicating Reasoning** | Construct viable arguments; critique the reasoning of others | **20%** | Explanation; justification; error analysis |
| **Claim 4 — Modeling & Data Analysis** | Analyze real-world scenarios; construct and use mathematical models | **15%** | Modeling; data interpretation |

### Subclaims

#### Claim 1 Subclaims

| Subclaim | Description |
|---|---|
| **1A** | Apply mathematics to everyday problems |
| **1B** | Select and use appropriate tools |
| **1C** | Attend to precision |
| **1D** | Make use of structure |
| **1E** | Express regularity in repeated reasoning |

#### Claim 2 Subclaims

| Subclaim | Description |
|---|---|
| **2A** | Apply mathematics to well-posed problems |
| **2B** | Select appropriate tools |
| **2C** | Interpret results in context |

#### Claim 3 Subclaims

| Subclaim | Description |
|---|---|

| **3C** | State logical assumptions |
| **3D** | Break arguments into cases |

## 5. Item Types & Formats

### SR — Selected Response (1 point)

```
+----------------------------------------------------------------+
|  [Stimulus: problem context, diagram, table, or equation]       |
|                                                                 |
|  Question stem targeting a specific standard and claim.         |
|                                                                 |
|  O  A. [Plausible distractor]                                   |
|  O  B. [Common error]                                           |
|  O  C. [CORRECT]                                                |
|  O  D. [Off-track distractor]                                   |
+----------------------------------------------------------------+
Points: 1 (correct) / 0 (incorrect)
```

---

### MS — Multi-Select (1 point)

```
+----------------------------------------------------------------+
|  Select the TWO [equations / values / expressions] that...     |
|                                                                 |
|  [ ]  A. [Option]                                               |
|  [ ]  B. [Option — CORRECT]                                     |
|  [ ]  C. [Option]                                               |
|  [ ]  D. [Option — CORRECT]                                     |
|  [ ]  E. [Option]                                               |
+----------------------------------------------------------------+
Points: 1 (all correct, none incorrect) / 0
```

---

### EQ — Equation / Numeric Entry (1 point)

```
+----------------------------------------------------------------+
|  [Problem context]                                              |
|                                                                 |
|  Enter your answer in the box.                                  |
|  +---------------+                                              |
|  |               |                                              |
|  +---------------+                                              |
+----------------------------------------------------------------+
Points: 1 / 0
```

```
+----------------------------------------------------------------+

|                                                                 |
|  PART A: [Computational question]                               |

|                                                                 |
|  [Student response area]                                        |

```

### PT-ER — Performance Task Extended Response (0–6 points)

```
+----------------------------------------------------------------+

```

| DOK | Label | Description | Example Tasks |
|---|---|---|---|

## 8. Scoring Rubrics

### SCR — Short Constructed Response (0–2 Points)

| Score | Descriptor |
|---|---|
| **2** | Correct solution with clear, accurate explanation; logical and complete work shown. |
| **1** | Partially correct solution or correct answer with incomplete explanation; OR correct answer with no explanation. |
| **0** | Incorrect, irrelevant, or no understanding. Blank = 0. |

### PT-ER — Performance Task Extended Response (0–6 Points)

| Score | Part A | Part B | Part C |
|---|---|---|---|
| **2** | Correct setup and solution; units correct | Correctly applies Part A; clear reasoning | Sophisticated reasoning; math used to justify decision |
| **1** | Correct approach with error or incomplete | Partial understanding; correct reasoning with wrong value | Some correct reasoning |
| **0** | Incorrect or missing | Incorrect or missing | Incorrect or unsupported |

#### ECF Policy

Error carried forward: if a student carries an incorrect Part A value into Parts B/C but applies correct reasoning, award full credit for those parts. ECF applies only to computational mistakes, not conceptual misunderstandings.

## 10. Contextualization

### Maine-Specific Mathematics Context Bank

#### Fishing & Marine Industry

| Topic | Mathematical Applications |
|---|---|
| **Lobster catch data** | Unit rates (pounds per trap); proportional reasoning; data analysis of seasonal catch trends; Maine lobster catch ~100+ million pounds/year; cost per pound calculations; profit and expense multi-step problems; comparing annual catches |
| **Tidal data** | Elapsed time; patterns; graphing periodic functions (Gr 11); tide height measurements; predicting high/low tide times; data tables with time and height |
| **Blueberry harvest statistics** | Area calculations (barrens); unit rates (pounds per acre); Maine produces ~99% of U.S. wild blueberries (~80 million pounds/year); seasonal data; percentage calculations |

#### Geography & Parks

| Topic | Mathematical Applications |
|---|---|
| **Acadia National Park dimensions** | Area calculations (49,000+ acres); Cadillac Mountain elevation (1,530 ft); trail distances; distance-rate-time for hiking; comparing park statistics; visitor data (3.5+ million/year) |
| **Maine coastline** | Maine has ~3,478 miles of coastline (with islands and inlets); distance measurement; map scale; proportional reasoning; comparing straight-line vs. actual coastline distance |
| **Island geography** | Area and perimeter of islands; counting and data analysis; distance between islands; ferry schedule elapsed time problems |

#### Community & Everyday

| Topic | Mathematical Applications |
|---|---|
| **Maine weather data** | Temperature ranges (Portland avg: 18F–79F); snowfall data; precipitation; mean, median, mode; data displays |
| **Farmers market and local economy** | Unit price; discount; percent; multi-step computation; comparing prices |
| **Maine school data** | Enrollment; student-to-teacher ratios; percentages; population data (Maine ~1.4 million) |
| **Lighthouse dimensions** | Height calculations; distance-to-horizon formulas (Gr 11); scale drawings; measurement |

### Grade-Band Contextualization Notes

#### Grades 3–5

| Principle | Guidance |
|---|---|
| **Concreteness** | Tangible quantities (lobster traps, blueberry baskets, trail distances, lighthouse heights) |
| **Accessibility** | Avoid specialized vocabulary; define Maine-specific terms (stern, buoy, barrens) |
| **Scale** | Gr 3: within 1,000; Gr 5: multi-digit, decimals, fractions |

#### Grades 6–8

| Principle | Guidance |
|---|---|
| **Real data** | Use approximate real data (Maine coastline ~3,478 mi; Acadia ~49,000 acres; Cadillac Mountain 1,530 ft) |
| **Multiple representations** | Tables, graphs, diagrams |
| **Social relevance** | Lobster industry economics, tourism data, tidal patterns |

#### Grade 11

| Principle | Guidance |
|---|---|
| **Workforce readiness** | Marine industry, tourism, healthcare, forestry contexts |
| **Complex data** | Multi-variable data; scatter plots; regression; tidal modeling |
| **Equity lens** | Include diverse contexts representing all of Maine's communities |

### EL Considerations for Math

| Consideration | Guidance |
|---|---|
| **Mathematical vocabulary** | Define Tier 3 terms in glossary |
| **Word problem language** | Simple, direct sentences |
| **Bilingual glossary** | Designated support |
| **Diagrams** | Clear, labeled; reduce linguistic load |

- [ ] Tagged to one primary CCSS Math standard

### Calculator Policy

- [ ] Flagged per grade-level policy

- [ ] Gr 8/11: no embedded reference sheet formulas

- [ ] Clear, unambiguous stem
- [ ] Internally consistent values

- [ ] Diagrams labeled with alt text

- [ ] ECF noted

- [ ] Clear language
- [ ] Grade-appropriate vocabulary
- [ ] Diagrams usable with zoom

**Interpretation:** SCR (0–2 points) for Claim 3 at DOK 3.

**Recipe:**
1. Select context from Section 10
2. Part A: computation (DOK 2); Part B: justification (DOK 3)
3. Include scoring guide
4. Tag: state=ME, subject=MATH, grade=[X], claim=3, dok=3

---

### Pattern 3: "Generate a Performance Task math problem for Grade [X]"

**Interpretation:** Full PT-ER using Template 3.

**Recipe:**
1. Choose Maine context (lobster catch data, Acadia dimensions, tidal data, blueberry harvest)
2. Create realistic data set
3. Scaffold Parts A/B/C
4. Include rubric and ECF
5. Tag: state=ME, subject=MATH, grade=[X], claim=4, dok=3-4

---

### Pattern 4: "Generate a set of math items covering multiple domains"

**Interpretation:** Mini-assessment covering 3–4 domains.

**Recipe:**
1. Identify domains for the grade
2. Generate: 1–2 SR, 1 MS, 1 EQ
3. Distribute calculator per policy
4. Standards and DOK summary table
5. Tag each item
