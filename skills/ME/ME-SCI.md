## AssessmentForge Skill Guide | Grades 5, 8, 11

---

## 1. Overview

| Field | Detail |
|---|---|
| **Assessment Name** | Maine Educational Assessment (MEA) — Science |
| **Administering Agency** | Maine Department of Education (Maine DOE) |
| **Vendor** | Maine DOE |
| **Grades Tested** | 5, 8, and 11 |
| **Testing Window** | April – May |
| **Delivery** | Computer-based; fixed-form |
| **Standards** | Next Generation Science Standards (NGSS) as adopted by Maine |
| **Score Scale** | Standard score (varies by grade); 4 performance levels |
| **Reporting** | Individual Student Report; School, District, State aggregate reports |

> **CRITICAL NOTE:** MEA Science is administered **only at Grades 5, 8, and 11**. Do not generate items for Grades 3, 4, 6, or 7.

### Performance Level Descriptors

| Level | Label | Description |
|---|---|---|
| 4 | **Standard Exceeded** | Student demonstrates thorough understanding of three-dimensional science; expertly integrates DCI, SEP, and CCC; constructs sophisticated, evidence-based explanations |
| 3 | **Standard Met** | Student demonstrates adequate understanding of three-dimensional science; appropriately applies practices and crosscutting concepts in grade-level contexts |
| 2 | **Standard Nearly Met** | Student demonstrates partial understanding; can recall disciplinary core ideas but struggles to integrate science practices or crosscutting concepts |
| 1 | **Standard Not Met** | Student demonstrates minimal science understanding; cannot apply practices or crosscutting concepts; limited to recall of isolated facts |

> **Item-writing target:** Level 3 (Standard Met) performance. Items should assess all three NGSS dimensions simultaneously.

## 3. Test Structure

MEA Science is a single-session, computer-based test. There is **no lab practical component** — all items are stimulus-based.

```
+------------------------------------------------------------------+
|                   MEA SCIENCE STRUCTURE (Grades 5, 8, 11)         |
+------------------------------------------------------------------+
|  SINGLE SESSION                                                   |
|  Computer-Based, Fixed-Form                                       |
|  Approximately 90–120 minutes                                     |
|                                                                   |
|  ~40 items per grade                                              |
|                                                                   |
|  Item types:                                                      |
|    - Selected Response (SR) — ~60–65% of items                    |
|    - Multi-Select Response (MS) — ~15–20% of items                |
|    - Constructed Response (CR) — ~15–20% of items (3 pts each)    |
+------------------------------------------------------------------+
```

### Grade-Level Test Specifications

| Specification | Grade 5 | Grade 8 | Grade 11 |
|---|---|---|---|
| Approximate Item Count | ~38–42 | ~38–42 | ~38–42 |
| Selected Response | ~25–28 | ~25–28 | ~25–28 |
| Multi-Select | ~6–8 | ~6–8 | ~6–8 |
| Constructed Response | ~4–6 | ~4–6 | ~4–6 |
| Approx. Testing Time | 90–120 min | 90–120 min | 90–120 min |
| Calculator | No | No | No |
| Reference Sheet | No | No | No |

> **Three-Dimensional Requirement:** Every MEA Science item must integrate at least one **Disciplinary Core Idea (DCI)**, one **Science and Engineering Practice (SEP)**, and one **Crosscutting Concept (CCC)**.

## 5. Item Types & Formats

### Selected Response (SR)

```
+----------------------------------------------------------+
|  SELECTED RESPONSE — 1 point                             |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Scenario, diagram, data table, or model stimulus        |
|  Must integrate DCI + SEP + CCC                          |
|  Machine scored                                          |
+----------------------------------------------------------+
```

**SR Example (Grade 8, DOK 2, MS-LS2-2 — Ecosystem Interactions):**

Scientists studying the Gulf of Maine observed that as ocean temperatures increased, lobster populations initially grew in some areas but shrimp populations declined sharply. Which statement BEST explains this pattern of ecosystem change?

A. Warmer water caused all marine species to grow faster
B. The temperature change favored lobsters over shrimp because different species have different temperature tolerances
C. Shrimp migrated to the Gulf of Maine when the water warmed
D. Lobsters and shrimp do not interact in the same ecosystem

*Correct Answer: B*
*Alignment: MS-LS2-2 | SEP: Analyzing Data | CCC: Cause and Effect | DOK 2*

---

### Multi-Select Response (MS)

```
+----------------------------------------------------------+
|  MULTI-SELECT RESPONSE — 1 point                         |
|                                                          |
|  5–6 options; select exactly 2 or 3 correct answers      |
|  Full credit only; partial credit not awarded            |
|  Machine scored                                          |
+----------------------------------------------------------+
```

**MS Example (Grade 5, DOK 2, 5-LS2-1 — Matter Cycling):**

A Maine forest ecosystem includes spruce trees, deer, mushrooms, and bacteria in the soil. Select the TWO statements that correctly describe how matter moves through this ecosystem.

A. Spruce trees take in carbon dioxide from the air and water from the soil to grow
B. Deer create new matter when they eat spruce bark
C. Mushrooms and bacteria break down fallen trees and return nutrients to the soil
D. Bacteria in the soil produce energy from sunlight
E. Matter is destroyed when a tree falls and decays

*Correct Answers: A, C*
*Alignment: 5-LS2-1 | SEP: Developing and Using Models | CCC: Energy and Matter | DOK 2*

---

### Constructed Response (CR)

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE — 0–3 points                       |
|                                                          |
|  Written explanation using evidence from stimulus        |
|  Stimulus always provided (data, diagram, scenario)      |
|  Must demonstrate three-dimensional reasoning            |
|  Human scored                                            |
+----------------------------------------------------------+
```

**CR Example (Grade 11, DOK 3, HS-LS2-1 — Carrying Capacity):**

*Stimulus: A data table showing lobster catch data (in millions of pounds) for the Gulf of Maine from 1980–2025, alongside sea surface temperature data. The data shows lobster catch increasing dramatically from 1990–2015 as temperatures warmed, but then beginning to plateau and decline after 2018 as temperatures continued to rise.*

*"Using evidence from the data table, construct an explanation for how changes in ocean temperature have affected lobster carrying capacity in the Gulf of Maine. Include evidence from the data and explain the cause-and-effect relationship between temperature and population dynamics."*

## 7. Three-Dimensional Design

Every MEA Science item must reflect all three NGSS dimensions simultaneously.

### Three-Dimensions Alignment Guide

| Dimension | What It Is | Example in Items |
|---|---|---|
| **DCI** (What students know) | Disciplinary science content | Lobster biology; coastal geology; ecosystem interactions; ocean chemistry |
| **SEP** (What students do) | How scientists work | Analyze data; construct explanations; use models; argue from evidence |
| **CCC** (Lens of thinking) | Cross-domain thinking tools | Cause and effect; patterns; energy and matter; structure and function; systems |

### Crosscutting Concepts by Grade Band

| CCC | Grade 5 Emphasis | Grade 8 Emphasis | Grade 11 Emphasis |
|---|---|---|---|
| Patterns | Rock formations; tidal patterns; seasonal changes | Periodic table; population cycles; ocean temperature trends | Inheritance patterns; population dynamics; climate trends |
| Cause and Effect | Food web changes; erosion; weather | Chemical reactions; ecosystem dynamics; human impacts | Mutations -> traits; ocean warming -> species shifts |
| Energy and Matter | Food chains; water cycle; plant growth | Chemical reactions; thermal transfer; matter cycling in oceans | Cellular respiration; photosynthesis; ocean carbon cycle |
| Structure and Function | Animal adaptations (lobster shell, puffin beak); plant structures | Cell structures; molecular bonds; rock composition | DNA -> protein -> trait; organism adaptations |
| Systems and System Models | Coastal ecosystems; water cycle; forest ecosystems | Earth systems; ocean systems; watersheds | Marine ecosystems; genetic systems; climate systems |
| Scale, Proportion, Quantity | Particle size; distances; tidal measurements | Atomic scale; geological time; ocean depth | Molecular scale; population modeling; global data |
| Stability and Change | Habitat change; seasonal tides | Climate; ecosystem stability; ocean chemistry | Evolution; homeostasis; long-term ocean warming |

## 8. Scoring Rubrics

### Constructed Response (CR) Rubric — 0–3 Points

| Score | Criteria |
|---|---|
| 3 | Accurately addresses the science concept; clear three-dimensional understanding; specific, relevant evidence from stimulus; complete, accurate, logically connected explanation |
| 2 | Addresses science concept with partial accuracy; DCI understood but SEP/CCC integration incomplete; evidence present but may be incomplete |
| 1 | Minimally addresses science concept; limited understanding; little evidence from stimulus; vague or minor inaccuracies |
| 0 | Does not address science concept; blank; off-topic; restates stimulus without explanation |

### CR Scoring Notes

- **Evidence must come from the stimulus.** Prior knowledge alone = max 1 point.
- **Three-dimensional reasoning earns full credit.** Score 3 integrates DCI + SEP or CCC.
- **Misconceptions lower the score** by one point.

## 10. Contextualization — Maine Science

When generating science items and phenomena, prioritize authentic Maine settings:

### Maine Science Context Guide

| Setting / Phenomenon | Grade | Science Domain | PE Alignment |
|---|---|---|---|
| Maine coastal ecosystems (rocky intertidal, estuaries, salt marshes) | 5, 8, 11 | Life/Earth Science | 5-LS2, MS-LS2, MS-ESS3, HS-LS2 |
| Lobster biology (anatomy, molting, life cycle, population dynamics) | 5, 8, 11 | Life Science | 5-LS1, MS-LS1-5, MS-LS2-2, HS-LS2-1 |
| Acadia National Park geology (glacial erosion, granite formations, Cadillac Mountain) | 8, 11 | Earth Science | MS-ESS2-2, HS-ESS2-1 |
| Gulf of Maine warming (fastest-warming body of water, species shifts) | 8, 11 | Earth/Life Science | MS-ESS3, MS-LS2, HS-ESS3-1, HS-LS2-1 |
| Maine forest ecology (spruce-fir, northern hardwood, succession, logging) | 5, 8 | Life Science | 5-LS2, MS-LS2 |
| Atlantic puffin conservation (Project Puffin, Seal Island restoration) | 5, 8, 11 | Life Science | 5-LS2, MS-LS2-2, HS-LS2-1, HS-LS4 |
| Penobscot Bay marine food web (phytoplankton, herring, seals, eagles) | 5, 8 | Life Science | 5-LS2-1, MS-LS2-2 |
| Maine tidal patterns (Bay of Fundy influence, intertidal zones) | 5, 8 | Earth Science | 5-ESS2, MS-ESS2 |
| Blueberry barrens ecology (managed burning, pollination, soil science) | 5, 8 | Life/Earth Science | 5-LS2, 5-ESS3, MS-LS2, MS-ESS3 |
| Climate change and Maine fisheries (lobster range shifts, cod decline) | 8, 11 | Life/Earth Science | MS-ESS3-3, HS-ESS3-1, HS-LS2-1 |
| Penobscot River restoration (dam removal, salmon return, ecosystem recovery) | 8, 11 | Life/Earth Science | MS-LS2, MS-ESS3, HS-LS2, HS-ESS3 |
| Maine island ecology (isolation, adaptation, conservation) | 8, 11 | Life Science | MS-LS2-2, HS-LS4-2 |

### Suggested Anchoring Phenomena by Grade

**Grade 5 Phenomena:**
- "Atlantic puffins disappeared from most Maine islands by 1900 because of hunting. Scientists brought puffin chicks from Canada and raised them on Seal Island, and now puffins nest there again. What did the puffin chicks need to survive and grow on the island?"
- "After a storm, students at a Maine beach noticed that the rocks at the top of the beach were large and round, while the rocks near the water were small and smooth. What forces caused the rocks to be different shapes and sizes?"
- "Lobsters found in the cold, deep waters off the Maine coast have darker shells than lobsters found in warmer, shallower water. What might explain this pattern?"

**Grade 8 Phenomena:**
- "The Gulf of Maine has warmed faster than 99% of the world's ocean over the past 20 years. During that time, lobster catches in Maine have increased dramatically, but cod populations have collapsed. What explains these opposite population trends in the same ecosystem?"
- "Geologists studying Acadia National Park found deep parallel scratches on granite rocks at the top of Cadillac Mountain, as well as large boulders sitting on top of different rock types. What geoscience processes could explain these features?"
- "After two dams were removed on the Penobscot River in Maine, scientists observed that Atlantic salmon returned to sections of the river they had not been able to reach for nearly 200 years. Within five years, the entire river ecosystem showed significant changes. What cause-and-effect relationships explain the ecosystem's response?"

**Grade 11 Phenomena:**
- "Lobster populations in southern New England have crashed as ocean temperatures have risen, while Maine's lobster catch has increased. However, scientists predict that Maine's lobster population will begin to decline as the Gulf of Maine continues to warm. What factors determine the carrying capacity for lobsters, and how does temperature affect population dynamics?"
- "Atlantic puffins on Maine islands feed their chicks primarily herring and hake. In recent years, warming waters have caused these fish to move farther offshore, forcing puffins to fly longer distances. Some puffin chicks are not surviving. What evolutionary pressures might this environmental change create for the puffin population over many generations?"
- "Scientists studying the Gulf of Maine have found that increasing CO2 levels are making the ocean more acidic. This is particularly threatening to organisms like lobsters, mussels, and sea urchins that build shells from calcium carbonate. How do changes in ocean chemistry affect the structure and function of these organisms?"

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] Grade verified as 5, 8, or 11 ONLY
- [ ] PE code is a valid NGSS Performance Expectation
- [ ] Item is three-dimensional: DCI + SEP + CCC all identified
- [ ] Anchoring phenomenon is authentic and Maine-relevant where possible
- [ ] Stimulus has clear labels, units, and realistic data
- [ ] CR prompt directs students to use evidence from stimulus
- [ ] All distractors represent real misconceptions
- [ ] MS items specify how many answers to select
- [ ] Score 3 anchor response written before finalizing CR item
- [ ] Science content is accurate and current
- [ ] Vocabulary is grade-appropriate

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Writing items for Grades 3, 4, 6, or 7 | MEA Science is only at Grades 5, 8, 11 | Restrict to tested grades |
| DCI-only items (no SEP or CCC) | MEA requires three-dimensional items | Always embed a practice and crosscutting concept |
| CR prompts without evidence directive | Students may not cite data | Include "Use evidence from the [data/graph/diagram]" |
| Generic stimulus not tied to Maine | MEA favors Maine phenomena | Anchor to Maine-specific contexts |
| Multi-select with only 2 correct in 4 options | Too easy to guess | Use 5–6 options with 2–3 correct |
| Recall-only SR items | DOK 1 under-represented | Elevate to DOK 2 with scenario |

## 12. Prompt Patterns

### Pattern 1: Data-to-Conclusion (SR, DOK 2)
> "The [graph / table / diagram] below shows [Maine science scenario]. Based on the data, which [conclusion / explanation / pattern] is BEST supported?"

### Pattern 2: Phenomenon Explanation (CR, DOK 3)
> "Scientists observed [Maine-anchored phenomenon]. Using evidence from the [data / model / diagram], construct an explanation for [specific science focus]. Explain the [cause-and-effect / pattern / energy flow] relationship."

### Pattern 3: Model Evaluation (SR or MS, DOK 2–3)
> "A student made a model showing [science concept]. Which statement BEST describes what the model shows about [DCI focus]?"

### Pattern 4: Investigation Design (CR, DOK 3)
> "A scientist wants to investigate whether [variable] affects [outcome] in [Maine ecosystem/context]. Describe a procedure the scientist could follow."

### Pattern 5: Evidence-Based Argument (CR, DOK 3)
> "Two students disagree about [science claim]. Using evidence from the [data / diagram], explain which student is correct and why."

### Pattern 6: Multi-Select Evidence (MS, DOK 2)
> "A student is investigating [Maine science scenario]. Select the TWO [pieces of evidence / strategies / explanations] that BEST support the conclusion that [DCI-based claim]."
