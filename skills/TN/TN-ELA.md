## 1. Overview

| Field | Detail |
|---|---|
| **Assessment Name** | TNReady — English Language Arts |
| **Administering Agency** | Tennessee Department of Education (TDOE) |
| **Vendor** | Pearson |
| **Grades Tested** | 3, 4, 5, 6, 7, 8; EOC (English I, English II, English III) |
| **Testing Window** | April – May |
| **Delivery** | Computer-based; paper accommodations available |
| **Standards** | Tennessee Academic Standards — English Language Arts |
| **Score Scale** | Scaled score; 4 performance levels |
| **Reporting** | Individual Student Report; School, District, State aggregates |

> **TNReady ELA Structure:** TNReady ELA uses multiple choice (MC), multi-select (MS), constructed response (CR, scored 0–2), and extended response (ER, scored 0–4) items. The test is passage-based, requiring students to analyze literary and informational texts with increasing complexity across grade bands.

### Performance Levels

| Level | Label | Description |
|---|---|---|
| 4 | **Mastered** | Demonstrates thorough understanding; applies Tennessee standards with sophistication and depth beyond grade-level expectations |
| 3 | **On Track** | Demonstrates solid understanding of grade-level Tennessee standards; meets proficiency expectations |
| 2 | **Approaching** | Demonstrates partial understanding; developing but not yet meeting grade-level expectations |
| 1 | **Below** | Demonstrates minimal understanding; significant gaps in mastery of grade-level standards |

> **Item-writing target:** "On Track" performance. Items should require genuine application of Tennessee Academic Standards — not mere recall.

## 2. Standards Framework

> TNReady ELA is aligned to the **Tennessee Academic Standards for English Language Arts**, organized by reading, writing, and language strands.

### Tennessee ELA Strands

| Strand | Focus | Grade Emphasis |
|---|---|---|
| **Reading — Literature** | Literary text comprehension; theme; character; craft; structure | Primary assessment focus |
| **Reading — Informational Text** | Informational text comprehension; argument; evidence; text features | Primary assessment focus |
| **Writing** | Narrative, argumentative, informational writing; conventions; editing | Assessed via CR and ER |
| **Language** | Grammar, usage, mechanics; vocabulary acquisition | Integrated throughout |

### Key Reading Standards by Grade Band

| Standard Code | Description | Grade Band | DOK |
|---|---|---|---|
| TN.ELA3.RL.KID.1 | Ask and answer questions to demonstrate understanding, referring explicitly to details in the text | 3–4 | 1–2 |
| TN.ELA5.RL.CS.4 | Determine the meaning of words and phrases as used in a text, including figurative language | 5 | 2 |
| TN.ELA6.RL.KID.2 | Determine a theme or central idea and how it is conveyed through details; summarize | 6 | 2–3 |
| TN.ELA7.RI.CS.6 | Determine an author's point of view or purpose and analyze how it is distinguished from others | 7 | 3 |
| TN.ELA8.RL.KID.3 | Analyze how particular lines of dialogue or incidents reveal aspects of a character or provoke a decision | 8 | 3 |
| TN.EOC.RL.KID.2 | Determine two or more themes or central ideas; analyze development over the course of a text | EOC | 3 |

### Key Writing / Language Standards

| Standard Code | Description | Grade Band | DOK |
|---|---|---|---|
| TN.ELA3.W.TTP.1 | Write opinion pieces on topics, supporting a point of view with reasons | 3–5 | 3 |
| TN.ELA6.W.TTP.2 | Write informative/explanatory texts to examine a topic | 6–8 | 3 |
| TN.ELA8.L.CSE.1 | Demonstrate command of conventions of standard English grammar and usage | 8 | 1–2 |
| TN.EOC.W.TTP.1 | Write arguments to support claims in an analysis of substantive topics using valid reasoning and evidence | EOC | 3–4 |

## 3. Test Structure

TNReady ELA is administered in two sub-parts. Items include MC, MS, CR (0–2), and ER (0–4) formats, all passage-based.

```
+------------------------------------------------------------------+
|            TNREADY ELA STRUCTURE (Grades 3–8, EOC)                |
+------------------------------------------------------------------+
|  TWO SUB-PARTS — Approximately 2–3 hours total                   |
|  Computer-Based                                                   |
|                                                                   |
|  SUB-PART 1: READING & LANGUAGE                                   |
|  ┌────────────────────────────────────────┐                      |
|  │ Passage Set 1 (Literary) → MC, MS     │                      |
|  │ Passage Set 2 (Informational) → MC,MS │                      |
|  │ Language / conventions items → MC      │                      |
|  └────────────────────────────────────────┘                      |
|                                                                   |
|  SUB-PART 2: READING & WRITING                                    |
|  ┌────────────────────────────────────────┐                      |
|  │ Passage Set 3 → MC, MS items          │                      |
|  │ Passage Set 4 (may be paired) → MC    │                      |
|  │ Constructed Response (CR) — 0–2 pts   │                      |
|  │ Extended Response (ER) — 0–4 pts      │                      |
|  └────────────────────────────────────────┘                      |
+------------------------------------------------------------------+
```

## 5. Item Types & Formats

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Passage-based                                           |
|  Machine scored                                          |
|  DOK 1–3                                                 |
+----------------------------------------------------------+
```

**MC Example (Grade 7 Informational, DOK 3, TN.ELA7.RI.CS.6):**

*[After reading an article about the history of Nashville's music industry and its cultural impact]*

How does the author develop the argument that Nashville's music scene shaped the city's modern identity?

A. By describing the personal lives of famous Nashville musicians
B. By showing how the growth of recording studios, concert venues, and tourism transformed the city's economy and culture over decades
C. By comparing Nashville's population to other Tennessee cities
D. By listing the number of songs recorded in Nashville each year

*Correct Answer: B*
*Alignment: TN.ELA7.RI.CS.6 | DOK 3*

---

**MC Example (Grade 5 Literary, DOK 2, TN.ELA5.RL.CS.4):**

*[After reading a story set in the Great Smoky Mountains about a family hiking to a waterfall]*

Read this sentence from paragraph 3: *"The mist from the falls draped across the rocks like a thin white curtain, hiding the dark pool below."*

What does the word *draped* suggest about the mist?

A. The mist was heavy and dangerous
B. The mist hung gently over the rocks like fabric
C. The mist was invisible to the hikers
D. The mist was caused by rain rather than the waterfall

*Correct Answer: B*
*Alignment: TN.ELA5.RL.CS.4 | DOK 2*

---

### Multi-Select (MS)

```
+----------------------------------------------------------+
|  MULTI-SELECT — 1 point                                  |
|                                                          |
|  5–6 options; select ALL correct answers (typically 2)   |
|  All correct must be selected for credit                 |
|  Machine scored                                          |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**MS Example (Grade 8, DOK 2, TN.ELA8.RL.KID.3):**

*[After reading a story set during the Memphis civil rights era]*

Select TWO details from the passage that BEST reveal the main character's growing courage.

A. "She remembered the route her mother took to the market each Saturday"
B. "She stepped forward and spoke clearly, though her hands trembled at her sides"
C. "The trees along Beale Street were tall and old, their roots cracking the sidewalk"
D. "She looked the shopkeeper directly in the eye and repeated her request without flinching"
E. "The afternoon sun cast long shadows across the front porch"

*Correct Answers: B, D*
*Alignment: TN.ELA8.RL.KID.3 | DOK 2*

### Constructed Response (CR)

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE — 0–2 points                       |
|                                                          |
|  2–4 sentence response                                   |
|  Must reference textual evidence                         |
|  Passage-based                                           |
|  Human scored                                            |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**CR Example (Grade 6, DOK 3, TN.ELA6.RL.KID.2 — 0–2 pts):**

*[After reading a story set in the Smoky Mountains about a young boy learning to appreciate his grandfather's knowledge of the land]*

Using evidence from the story, explain how the author develops the theme that wisdom comes from experience with the natural world.

### Extended Response (ER)

```
+----------------------------------------------------------+
|  EXTENDED RESPONSE — 0–4 points                          |
|                                                          |
|  Multi-paragraph response                                |
|  Must integrate textual evidence from passage(s)         |
|  May use paired passages                                 |
|  Human scored                                            |
|  DOK 3–4                                                 |
+----------------------------------------------------------+
```

**ER Example (Grade 10/EOC, DOK 4, TN.EOC.W.TTP.1 — 0–4 pts):**

*[After reading two passages: one about the history of Memphis during the civil rights movement, one about how the National Civil Rights Museum preserves that history]*

Using evidence from both passages, write an essay analyzing how the preservation of civil rights history in Memphis serves both as a memorial and as an educational tool. Use specific details from both texts to support your analysis.

## 8. Scoring Rubrics

### Multiple Choice (MC) — 1 Point

| Score | Criteria |
|---|---|
| 1 | Student selects the correct answer |
| 0 | Student selects an incorrect answer or leaves blank |

### Multi-Select (MS) — 1 Point

| Score | Criteria |
|---|---|
| 1 | Student selects ALL correct answers and no incorrect answers |
| 0 | Any incorrect selection or missing correct selection |

### Constructed Response (CR) Rubric — 0–2 Points

| Score | Criteria |
|---|---|
| 2 | Response accurately addresses the question with a clear, specific answer. Includes relevant textual evidence (quoted or paraphrased) that directly supports the response. |
| 1 | Response partially addresses the question. Evidence may be present but loosely connected, or answer is accurate but lacks sufficient evidence. |
| 0 | Response is inaccurate, irrelevant, insufficient to evaluate, or blank. |

### Extended Response (ER) Rubric — 0–4 Points

| Score | Criteria |
|---|---|
| 4 | Thorough, insightful response with a clear controlling idea. Multiple pieces of relevant textual evidence integrated smoothly. Analysis is sophisticated and well-organized. Strong command of conventions. |
| 3 | Adequate response with a clear controlling idea. Relevant evidence included and generally well-integrated. Analysis is sound. Minor convention errors. |
| 2 | Partial response with an evident controlling idea. Some evidence present but may be insufficient or loosely connected. Analysis is basic. Some convention errors. |
| 1 | Minimal response with a weak or unclear controlling idea. Little or no evidence. Analysis superficial or largely inaccurate. Frequent convention errors. |
| 0 | Blank, off-topic, or insufficient writing to evaluate. |

## 10. Contextualization — Tennessee ELA

When generating passages and prompts, prioritize authentic Tennessee settings, history, and culture:

### Tennessee Context Guide

| Context | Passage Type | Grade Band |
|---|---|---|
| Nashville music history (country, blues, recording industry) | Informational or Literary | 4–EOC |
| Great Smoky Mountains (ecology, hiking, Appalachian culture) | Literary or Informational | 3–8 |
| Memphis civil rights history (MLK, Beale Street, sit-ins) | Informational or Historical fiction | 5–EOC |
| Tennessee River and valley communities | Literary or Informational | 4–8 |
| Appalachian culture and traditions | Literary or Informational | 3–8 |
| Tennessee agriculture (cotton, tobacco, livestock) | Informational | 3–7 |
| Dollywood / tourism in East Tennessee | Informational | 4–7 |
| Tennessee authors (Alex Haley, Nikki Giovanni, Cormac McCarthy) | Literary text or excerpt | 7–EOC |
| Andrew Jackson / Tennessee political history | Informational or Historical fiction | 5–8 |
| Reelfoot Lake / natural wonders | Literary or Informational | 4–8 |

### Suggested Passage Topics by Grade Band

**Grades 3–4:**
- A story about a family visiting the Great Smoky Mountains for the first time
- An informational article about Tennessee's state symbols and wildlife
- A narrative about a student attending a country music festival in Nashville

**Grades 5–6:**
- An article about the ecology of the Great Smoky Mountains and conservation efforts
- Historical fiction set along the Tennessee River during the Civil War era
- A narrative about a student learning about Memphis's musical heritage on Beale Street

**Grades 7–EOC:**
- Paired informational texts about Memphis civil rights history and its modern legacy
- Literary fiction set in the Smoky Mountains exploring themes of tradition and change
- An argumentative essay about preserving Tennessee's natural and cultural heritage

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] Tennessee Academic Standard code verified as correct for the targeted grade
- [ ] MC items directly tied to the passage (not general knowledge)
- [ ] MS items have clearly correct answers with no ambiguity
- [ ] CR prompt requires textual evidence ("Using evidence from...")
- [ ] ER prompt provides clear task and references passage(s)
- [ ] Distractors represent authentic misconceptions
- [ ] Lexile of passage matches the grade-level range
- [ ] Tennessee context incorporated where appropriate
- [ ] Performance levels use Tennessee labels (Below/Approaching/On Track/Mastered)
- [ ] DOK level matches the cognitive demand

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| CR prompt without evidence requirement | Students may not cite text | Always include "using evidence from" language |
| ER scored on wrong scale | TNReady ER uses 0–4 scale | Use full 4-point rubric |
| MS with ambiguous options | All-or-nothing scoring requires unambiguous options | Verify each option is clearly correct or incorrect |
| Items not passage-dependent | TNReady ELA is passage-based | Tie all reading items to a specific passage |
| Using CCSS codes | Tennessee uses its own Academic Standards | Reference Tennessee standard codes exclusively |
| Wrong performance level labels | Tennessee uses Below/Approaching/On Track/Mastered | Use correct Tennessee terminology |

## 12. Prompt Patterns

### Pattern 1: Theme Development (MC or CR, DOK 3)
> "How does the author develop the theme of [theme] throughout the [story / passage]?"

### Pattern 2: Author's Craft (MC, DOK 2–3)
> "Read [line reference]. What effect does the author's use of [literary device / word choice] create?"

### Pattern 3: Central Idea / Argument (MC, DOK 2)
> "What is the MAIN [idea / argument / purpose] of this [article / passage]?"

### Pattern 4: Vocabulary in Context (MC, DOK 1–2)
> "As used in paragraph [#], what does the word [word] MOST LIKELY mean?"

### Pattern 5: Evidence Selection (MS, DOK 2–3)
> "Select the TWO details from the passage that BEST [support / reveal / develop] [element]."

### Pattern 6: Text Evidence Analysis (CR, DOK 3)
> "Using evidence from the passage, explain how [element] contributes to [theme / meaning / purpose]."

### Pattern 7: Cross-Text Synthesis (ER, DOK 3–4)
> "Using evidence from both passages, write an essay [analyzing / explaining] [focus]. Include details from both texts."
