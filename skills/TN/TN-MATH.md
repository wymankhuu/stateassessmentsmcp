## 1. Overview

| Field | Detail |
|---|---|
| **Assessment Name** | TNReady — Mathematics |
| **Administering Agency** | Tennessee Department of Education (TDOE) |
| **Vendor** | Pearson |
| **Grades Tested** | 3, 4, 5, 6, 7, 8; EOC (Algebra I, Geometry, Algebra II, Integrated Math I–III) |
| **Testing Window** | April – May |
| **Delivery** | Computer-based; paper accommodations available |
| **Standards** | Tennessee Academic Standards — Mathematics |
| **Score Scale** | Scaled score; 4 performance levels |
| **Reporting** | Individual Student Report; School, District, State aggregates |

> **TNReady Math Structure:** TNReady Mathematics uses multiple choice (MC), multi-select (MS), constructed response (CR, scored 0–2), and extended response (ER, scored 0–4) items. Items emphasize real-world application, multi-step reasoning, and conceptual understanding aligned to Tennessee Academic Standards.

### Performance Levels

| Level | Label | Description |
|---|---|---|
| 4 | **Mastered** | Demonstrates thorough understanding; applies Tennessee math standards in complex, non-routine situations beyond grade-level expectations |
| 3 | **On Track** | Demonstrates solid understanding of grade-level Tennessee math standards; meets proficiency expectations |
| 2 | **Approaching** | Demonstrates partial understanding; developing but not yet meeting grade-level expectations |
| 1 | **Below** | Demonstrates minimal understanding; significant gaps in mastery of grade-level mathematics |

> **Item-writing target:** "On Track" performance. Items should require genuine application of Tennessee Academic Standards — not mere recall of procedures.

## 2. Standards Framework

> TNReady Mathematics is aligned to the **Tennessee Academic Standards for Mathematics**, organized by domains that build progressively across grade bands.

### Tennessee Mathematics Domains

| Domain | Focus | Grade Emphasis |
|---|---|---|
| **Number and Operations** | Place value, fractions, decimals, integers, rational numbers | Primary focus Grades 3–6 |
| **Operations and Algebraic Thinking** | Expressions, equations, inequalities, properties | Grades 3–8 |
| **Geometry** | Shapes, area, volume, transformations, coordinate geometry, congruence/similarity | All grades |
| **Measurement and Data** | Units, conversions, data displays, applications | All grades |
| **Statistics and Probability** | Central tendency, distributions, probability, inference | Grades 6–8 and EOC |
| **Functions** | Linear, exponential, quadratic functions; modeling | Grade 8 and EOC |

## 3. Test Structure

TNReady Mathematics is administered in two sub-parts. Items include MC, MS, CR (0–2), and ER (0–4).

```
+------------------------------------------------------------------+
|            TNREADY MATHEMATICS STRUCTURE (Grades 3–8, EOC)        |
+------------------------------------------------------------------+
|  TWO SUB-PARTS — Approximately 2–3 hours total                   |
|  Computer-Based                                                   |
|                                                                   |
|  SUB-PART 1 (No Calculator for Grades 3–5)                       |
|  ┌────────────────────────────────────────┐                      |
|  │ MC items (4 options, 1 pt each)       │                      |
|  │ MS items (select all, 1 pt each)      │                      |
|  └────────────────────────────────────────┘                      |
|                                                                   |
|  SUB-PART 2 (Calculator allowed for Grades 6–8, EOC)             |
|  ┌────────────────────────────────────────┐                      |

|  │ Constructed Response — 0–2 pts        │                      |
|  │ Extended Response — 0–4 pts           │                      |
|  └────────────────────────────────────────┘                      |
+------------------------------------------------------------------+
```

## 5. Item Types & Formats

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Real-world or mathematical context                      |
|  Machine scored                                          |
|  DOK 1–3                                                 |
+----------------------------------------------------------+
```

**MC Example (Grade 6, DOK 2, TN.Math6.RP.A.3):**

The Tennessee River flows approximately 652 miles from Knoxville to the Ohio River. A boat travels the first 326 miles in 2 days. If the boat continues at the same rate, how many total days will the trip take?

A. 3 days
B. 4 days
C. 5 days
D. 6 days

*Correct Answer: B*
*Alignment: TN.Math6.RP.A.3 | DOK 2*

---

### Multi-Select (MS)

```
+----------------------------------------------------------+
|  MULTI-SELECT — 1 point                                  |
|                                                          |
|  5–6 options; select ALL correct answers (typically 2–3) |
|  All correct must be selected for credit                 |
|  Machine scored                                          |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**MS Example (Grade 8, DOK 2, TN.Math8.F.A.2):**

The table shows the population of Nashville (in thousands) for selected years.

| Year | Population (thousands) |
|---|---|
| 1990 | 511 |
| 2000 | 570 |
| 2010 | 627 |
| 2020 | 689 |

Select ALL statements that are true about this data.

A. The population increased by approximately the same amount each decade
B. The average rate of change from 1990 to 2020 is approximately 5,933 people per year
C. The population will definitely reach 800,000 by 2040
D. The relationship between year and population is approximately linear
E. The population decreased between 2000 and 2010

*Correct Answers: A, B, D*
*Alignment: TN.Math8.F.A.2 | DOK 2*

---

### Constructed Response (CR)

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE — 0–2 points                       |
|                                                          |
|  Show work + answer                                      |
|  Must demonstrate mathematical reasoning                 |
|  Human scored                                            |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**CR Example (Grade 7, DOK 3, TN.Math7.G.B.6 — 0–2 pts):**

A rectangular section of the Great Smoky Mountains National Park is being surveyed. The section measures 4.5 miles long and 2.8 miles wide. A trail cuts diagonally across the section. What is the length of the diagonal trail, to the nearest tenth of a mile? Show your work.

---

### Extended Response (ER)

```
+----------------------------------------------------------+
|  EXTENDED RESPONSE — 0–4 points                          |
|                                                          |
|  Multi-step problem with explanation                     |
|  Must show work and justify reasoning                    |
|  Human scored                                            |
|  DOK 3                                                   |
+----------------------------------------------------------+
```

**ER Example (Grade 10/EOC, DOK 3, TN.EOC.F.LE.A.2 — 0–4 pts):**

The table shows the elevation (in feet) at various points along a hiking trail in the Great Smoky Mountains.

| Distance from trailhead (miles) | Elevation (feet) |
|---|---|
| 0 | 2,000 |
| 1.5 | 2,600 |
| 3.0 | 3,200 |
| 4.5 | 3,800 |
| 6.0 | 4,400 |

Part A: Determine the rate of change in elevation per mile. Show your work.
Part B: Write a linear equation that models the elevation as a function of distance from the trailhead.
Part C: A mountain peak is at an elevation of 6,000 feet. Based on your model, how far from the trailhead is the peak? Show your work and explain whether your answer is reasonable.

## 7. Mathematical Representations

TNReady Mathematics items frequently require students to move between multiple representations.

### Representation Types

| Representation | Description | Common Item Use |
|---|---|---|
| **Tabular** | Input/output table; data table | Identify patterns; find missing values; analyze trends |
| **Graphical** | Coordinate plane; bar/line graph; scatterplot | Identify slope; read data; compare quantities |
| **Algebraic** | Equations; inequalities; expressions | Solve; write; simplify; model real-world contexts |
| **Verbal** | Word problem; real-world scenario | Apply to Tennessee context |
| **Visual/Geometric** | Diagrams; figures with measurements | Compute area/volume; apply transformations |

### Representation Connections by Grade Band

| Grade Band | Frequent Connections |
|---|---|
| 3–5 | Number line ↔ fraction; table ↔ pattern rule; model ↔ computation |
| 6–7 | Table ↔ equation ↔ graph; ratio ↔ percent ↔ proportion |
| 8/EOC | Equation ↔ graph ↔ table; scatterplot ↔ linear model; function ↔ multiple representations |

## 8. Scoring Rubrics

### Multiple Choice (MC) — 1 Point

| Score | Criteria |
|---|---|
| 1 | Student selects the correct answer |
| 0 | Student selects an incorrect answer or leaves blank |

### Multi-Select (MS) — 1 Point

| Score | Criteria |
|---|---|
| 1 | Student selects ALL correct answers and no incorrect answers |
| 0 | Any incorrect selection or missing correct selection |

### Constructed Response (CR) Rubric — 0–2 Points

| Score | Criteria |
|---|---|
| 2 | Correct answer with complete, accurate mathematical work shown; reasoning is clear |
| 1 | Partially correct; correct approach with computational error, OR correct answer without sufficient work |
| 0 | Incorrect, irrelevant, or blank |

### Extended Response (ER) Rubric — 0–4 Points

| Score | Criteria |
|---|---|
| 4 | All parts answered correctly with thorough mathematical reasoning; work is organized, accurate, and clearly explained |
| 3 | Most parts correct; reasoning is sound with minor errors or omissions |
| 2 | Partial response; demonstrates understanding but contains significant errors or incomplete reasoning |
| 1 | Minimal response; attempts the problem but demonstrates limited understanding |
| 0 | Blank, off-topic, or no mathematical reasoning demonstrated |

## 10. Contextualization — Tennessee Mathematics

When generating math problem contexts, use authentic Tennessee settings:

### Tennessee Math Context Guide

| Context | Domain | Grade Band |
|---|---|---|
| Tennessee River data (length, flow rate, locks, dams) | Rate, Proportionality, Measurement | 5–EOC |
| Nashville population growth (census data, trends, projections) | Data Analysis, Functions, Modeling | 6–EOC |
| Great Smoky Mountains elevation data (trail profiles, peak heights) | Measurement, Rate of Change, Functions | 5–EOC |
| Tennessee agriculture (cotton, tobacco, cattle, soybeans) | Operations, Ratio, Data Analysis | 3–7 |
| Memphis and Beale Street tourism data | Data Analysis, Operations | 4–8 |
| Tennessee highway distances (I-40, I-24, I-65) | Rate, Proportionality, Operations | 4–8 |
| Dollywood and state park attendance data | Data Analysis, Operations | 3–7 |
| Tennessee football and basketball statistics | Statistics, Data Analysis | 5–8 |
| Reelfoot Lake dimensions and ecology data | Measurement, Geometry | 5–8 |
| Tennessee state budget and economic data | Data Analysis, Financial Literacy | 6–EOC |

### Suggested Problem Contexts by Grade Band

**Grades 3–4:**
- A student counts visitors to a Tennessee state park and makes a bar graph
- A family drives along I-40 across Tennessee and calculates remaining distance
- A table shows the number of fish caught at Reelfoot Lake over several days

**Grades 5–6:**
- Tennessee River flow rate data used to calculate distance traveled over time
- A proportional relationship between trail distance and elevation gain in the Smoky Mountains
- Nashville tourism revenue compared across months using data tables

**Grades 7–EOC:**
- Scatterplot of Nashville population growth with line of best fit and projections
- Smoky Mountains elevation profile modeled with a linear function
- Tennessee River lock and dam data analyzed for rate and proportion relationships

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] Tennessee Academic Standard code is accurate and grade-appropriate
- [ ] Calculator policy followed (no calculator Sub-Part 1 for Gr 3–5; varies by grade for Sub-Part 2)
- [ ] Real-world context is relevant to Tennessee students
- [ ] MC distractors represent actual student errors (not trivially wrong)
- [ ] MS items have clearly correct answers with no ambiguity
- [ ] CR scored on 0–2 scale; ER scored on 0–4 scale
- [ ] DOK level matches the cognitive demand
- [ ] All computations verified before item is finalized
- [ ] Answer choices are in logical order (ascending/descending for numeric)
- [ ] Performance levels use Tennessee labels (Below/Approaching/On Track/Mastered)

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Calculator use at Grade 3–5 | TNReady Gr 3–5 has no calculator | Design problems solvable by hand |
| CR/ER scored on wrong scale | Short CR = 0–2; ER = 0–4 | Match rubric to item type |
| MS with ambiguous options | All-or-nothing scoring requires clear options | Verify each option independently |
| DOK 1 items that only require recall | TNReady aims for mostly DOK 2–3 | Embed problems in real-world context |
| Using CCSS codes | Tennessee uses its own Academic Standards | Reference Tennessee standard codes |
| Wrong performance level labels | Tennessee uses Below/Approaching/On Track/Mastered | Use correct Tennessee terminology |

## 12. Prompt Patterns

### Pattern 1: Real-World Multi-Step (MC or CR, DOK 2–3)
> "[Tennessee context — Tennessee River, Nashville, Smoky Mountains]. [Specific mathematical question]. What is [quantity]? Show your work."

### Pattern 2: Representation Connection (MC or MS, DOK 2)
> "A student created a [table / graph / equation] to represent [relationship]. Which [representation / statement] represents the SAME relationship? / Select ALL true statements."

### Pattern 3: Data Interpretation (MC or CR, DOK 2–3)
> "The [table / graph / scatterplot] shows [Tennessee data]. Based on the data, [what is the rate / which conclusion / what prediction] is BEST supported?"

### Pattern 4: Geometry Application (MC or CR, DOK 2)
> "[Tennessee context — park, building, trail]. What is the [area / volume / distance / perimeter] of [figure]?"

### Pattern 5: Proportional Reasoning (MC, DOK 2)
> "[Tennessee context — river, distance, agriculture]. If [proportional setup], then what is [unknown quantity]?"

### Pattern 6: Multi-Part Analysis (ER, DOK 3)
> "The [data set] shows [Tennessee context]. Part A: [Calculate]. Part B: [Model]. Part C: [Evaluate or extend]."
