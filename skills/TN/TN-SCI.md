| Field | Detail |
|---|---|
| **Assessment Name** | TNReady — Science |
| **Administering Agency** | Tennessee Department of Education (TDOE) |
| **Vendor** | Pearson |
| **Grades Tested** | **Grade 5**, **Grade 8**, and **EOC** (Biology I, Chemistry) |
| **Testing Window** | April – May |

| **Standards** | Tennessee Academic Standards — Science |
| **Score Scale** | Scaled score; 4 performance levels |
| **Reporting** | Individual Student Report; School, District, State aggregates |

> **CRITICAL NOTE:** TNReady Science is administered at **Grades 5, 8, and EOC only**. Do not generate TNReady-aligned science items for other grades for state accountability purposes.

### Performance Levels

| Level | Label | Description |
|---|---|---|
| 4 | **Mastered** | Demonstrates thorough understanding; applies Tennessee science standards in complex, novel situations beyond grade-level expectations |
| 3 | **On Track** | Demonstrates solid understanding of grade-level Tennessee science standards; meets proficiency expectations |
| 2 | **Approaching** | Demonstrates partial understanding; developing but not yet meeting grade-level expectations |
| 1 | **Below** | Demonstrates minimal understanding; significant gaps in mastery of grade-level science standards |

> **Item-writing target:** "On Track" performance. Items should require genuine application of science concepts — not mere recall of vocabulary.

## 2. Standards Framework

> TNReady Science is aligned to the **Tennessee Academic Standards for Science**, which incorporate three-dimensional learning: science and engineering practices, disciplinary core ideas, and crosscutting concepts. Tennessee developed its own standards distinct from NGSS.

### Science and Engineering Practices (All Grades)

| Practice | Description |
|---|---|
| SEP.1 | Asking questions and defining problems |
| SEP.2 | Developing and using models |
| SEP.3 | Planning and carrying out investigations |
| SEP.4 | Analyzing and interpreting data |
| SEP.5 | Using mathematics and computational thinking |
| SEP.6 | Constructing explanations and designing solutions |
| SEP.7 | Engaging in argument from evidence |
| SEP.8 | Obtaining, evaluating, and communicating information |

## 5. Item Types & Formats

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Scenario-based or data-based stimulus                   |
|  May include diagrams, data tables, graphs               |
|  Machine scored                                          |
|  DOK 1–3                                                 |
+----------------------------------------------------------+
```

**MC Example (Grade 5, DOK 2, TN.Sci5.LS2.1 — Great Smoky Mountains Ecology):**

*[Diagram shows a food web in the Great Smoky Mountains: Sunlight -> Wildflowers -> Butterflies -> Black Bears; Sunlight -> Oak Trees -> Squirrels -> Red-tailed Hawks]*

Based on the food web, what would MOST LIKELY happen to the red-tailed hawk population if the squirrel population decreased significantly?

A. The hawk population would increase because there would be less competition for nesting sites
B. The hawk population would decrease because they would have less food available
C. The hawk population would not change because hawks can eat oak trees
D. The hawk population would move to a different part of the mountains

*Correct Answer: B*
*Alignment: TN.Sci5.LS2.1 | DOK 2*

---

**MC Example (Grade 8, DOK 2, TN.Sci8.ESS3.1 — Tennessee River Watershed):**

Tennessee's natural resources include coal deposits in the Cumberland Plateau and limestone in Middle Tennessee. A geologist explains that these resources formed millions of years ago under very different conditions. Which statement BEST explains why coal and limestone are found in different regions of Tennessee?

A. Coal and limestone are the same type of rock found at different depths
B. Different geological processes — ancient swamp forests and shallow seas — created these resources in different environments
C. Coal was carried to the Cumberland Plateau by the Tennessee River
D. Limestone is a newer rock that formed on top of coal deposits

*Correct Answer: B*
*Alignment: TN.Sci8.ESS3.1 | DOK 2*

### Multi-Select (MS)

```
+----------------------------------------------------------+
|  MULTI-SELECT — 1 point                                  |
|                                                          |
|  5–6 options; select ALL correct (typically 2–3)         |
|  All correct must be selected for credit                 |
|  Machine scored                                          |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**MS Example (Grade 8, DOK 2, TN.Sci8.ESS2.2):**

Scientists studying Reelfoot Lake in northwest Tennessee determined that the lake was formed by a series of powerful earthquakes in 1811–1812 that caused the land to sink and the Mississippi River to temporarily flow backward. Select the TWO pieces of evidence that BEST support the conclusion that Reelfoot Lake was formed by earthquakes.

A. The lake contains many species of fish
B. The lake sits in a depression surrounded by raised ridges of displaced earth
C. The lake is located near the Mississippi River
D. Submerged tree stumps from a pre-existing forest are visible beneath the lake's surface
E. The lake freezes during particularly cold Tennessee winters

*Correct Answers: B, D*
*Alignment: TN.Sci8.ESS2.2 | DOK 2*

## 7. Scientific Investigation Design

TNReady Science emphasizes students' ability to design and evaluate scientific investigations through Tennessee's Science and Engineering Practices.

### Investigation Design Components

| Component | Description | Practice Alignment |
|---|---|---|
| **Testable Question** | Question that can be answered through investigation | SEP.1 |
| **Hypothesis** | Testable prediction about variable relationships | SEP.1 |
| **Independent Variable** | The variable the investigator changes | SEP.3 |
| **Dependent Variable** | The variable being measured | SEP.3 |
| **Control Group** | Condition held constant for comparison | SEP.3 |
| **Data Collection** | Measurement using appropriate tools | SEP.4 |
| **Evidence-Based Conclusion** | Inference drawn from data | SEP.6, SEP.7 |

### Investigation Item Structure

```
+------------------------------------------------------------------+
|  INVESTIGATION DESIGN ITEM (MC or TEI)                            |
|                                                                   |
|  SCENARIO: A Tennessee student investigates whether [variable]    |
|  affects [outcome] in a [Tennessee-relevant setting].             |
|                                                                   |
|  STEM (MC): Which experimental setup would BEST allow the         |
|  student to test this hypothesis?                                 |
|  — OR —                                                           |
|  STEM (TEI): Drag the labels to correctly identify the            |
|  independent, dependent, and controlled variables.                |
+------------------------------------------------------------------+
```

## 8. Scoring Rubrics

### Multiple Choice (MC) — 1 Point

| Score | Criteria |
|---|---|
| 1 | Student selects the correct answer |
| 0 | Student selects an incorrect answer or leaves blank |

### Multi-Select (MS) — 1 Point

| Score | Criteria |
|---|---|
| 1 | Student selects ALL correct answers and no incorrect answers |
| 0 | Any incorrect selection or missing correct selection |

### Technology Enhanced Item (TEI) Rubric — 1–2 Points

| Score | Criteria |
|---|---|
| 2 | All components correct (labels, sequences, selections accurate) |
| 1 | Partially correct; at least one component accurate |
| 0 | Incorrect or blank |

## 10. Contextualization — Tennessee Science

When generating science items, prioritize authentic Tennessee natural settings and phenomena:

### Tennessee Science Context Guide

| Setting / Phenomenon | Grade | Science Domain | Standard Alignment |
|---|---|---|---|
| Great Smoky Mountains ecology (food webs, biodiversity, forest layers) | 5, 8, EOC | Life Science | TN.Sci5.LS2.1, TN.Sci8.LS4.4 |
| Tennessee River watershed (water quality, erosion, dams, flood control) | 5, 8 | Earth/Life Science | TN.Sci5.ESS1.3, TN.Sci8.ESS2.2 |
| Reelfoot Lake formation (earthquakes, geological evidence) | 5, 8 | Earth Science | TN.Sci5.ESS2.1, TN.Sci8.ESS2.2 |
| Cumberland Plateau coal deposits (geological formation, mining impact) | 8, EOC | Earth Science | TN.Sci8.ESS3.1 |
| Tennessee limestone and cave systems (karst topography, groundwater) | 8 | Earth Science | TN.Sci8.ESS2.2, TN.Sci8.ESS3.1 |
| Great Smoky Mountains salamander diversity | 8, EOC | Life Science | TN.Sci8.LS4.1, TN.Sci8.LS4.4 |
| Tennessee River valley agriculture (soil erosion, nutrient runoff) | 5, 8 | Earth/Life Science | TN.Sci5.ESS1.3, TN.Sci8.ESS2.2 |
| Tennessee weather patterns (tornadoes, thunderstorms, elevation effects) | 5, 8 | Earth Science | TN.Sci5.ESS1.3 |
| Cherokee National Forest ecosystems | 5, 8 | Life Science | TN.Sci5.LS2.1, TN.Sci8.LS4.4 |
| Tennessee marble and mineral resources | 8, EOC | Earth Science | TN.Sci8.ESS3.1 |

### Suggested Anchoring Phenomena by Grade

**Grade 5 Phenomena:**
- "Scientists studying the Great Smoky Mountains noticed that wildflower blooms are occurring earlier in the spring than they did 30 years ago. What might explain this change, and how could it affect other organisms in the ecosystem?"
- "After heavy rains, a student near the Tennessee River observed that the riverbank had eroded significantly. What processes caused this change to Earth's surface?"
- "A Tennessee farmer noticed that mixing vinegar with baking soda created bubbles, but mixing salt with water did not. What is the difference between these two changes?"

**Grade 8 Phenomena:**
- "Reelfoot Lake in northwest Tennessee contains submerged tree stumps and sits in a depression surrounded by raised earth ridges. What geological events could explain how this lake formed?"
- "Scientists found that the Great Smoky Mountains have more species of salamanders than almost any other place on Earth. What factors might explain this extraordinary biodiversity?"
- "Tennessee has coal in the east and limestone in the middle of the state. What different geological processes created these resources in different locations?"

**EOC Phenomena:**
- "The Great Smoky Mountains support over 100 species of native trees, more than any other North American national park. How do natural selection and adaptation explain this diversity?"
- "The Tennessee River watershed drains 40,910 square miles across multiple states. How does matter and energy flow through this watershed ecosystem?"

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] Grade verified as 5, 8, or EOC ONLY (not other grades)
- [ ] Tennessee Academic Standard code is accurate and grade-appropriate
- [ ] Stimulus (data table/graph/diagram) clearly labeled with units
- [ ] MS items have clearly correct answers with no ambiguity
- [ ] TEI items use technology meaningfully (drag-and-drop, sequencing, labeling)
- [ ] All distractors represent real student misconceptions
- [ ] Investigation design items clearly identify variables
- [ ] Science content is accurate and reflects current scientific understanding
- [ ] Tennessee context incorporated where possible (Smoky Mountains, Tennessee River, Reelfoot Lake)
- [ ] Performance levels use Tennessee labels (Below/Approaching/On Track/Mastered)

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Writing science items for non-tested grades | TNReady Science only at Grades 5, 8, EOC | Restrict to tested grades |
| Using NGSS codes instead of Tennessee codes | Tennessee uses its own Academic Standards | Reference Tennessee standard codes exclusively |
| MS with ambiguous options | All-or-nothing scoring requires unambiguous options | Verify each option independently |
| Items assessing factual recall only | TNReady Science is ~55–60% DOK 2 | Elevate items with scenarios and data |
| Generic phenomena not anchored to Tennessee | Assessment favors Tennessee-specific contexts | Use Smoky Mountains, Tennessee River, Reelfoot Lake, coal/limestone |
| Wrong performance level labels | Tennessee uses Below/Approaching/On Track/Mastered | Use correct Tennessee terminology |

## 12. Prompt Patterns

### Pattern 1: Data-to-Conclusion (MC, DOK 2)
> "The [table / graph / diagram] shows [Tennessee science scenario]. Based on the data, which [conclusion / explanation / prediction] is BEST supported?"

### Pattern 2: Cause and Effect (MC, DOK 2)
> "A student [observed / measured] that [Tennessee phenomenon]. Which explanation BEST describes why this [occurred / changed]?"

### Pattern 3: Investigation Design (MC or TEI, DOK 2–3)
> "[Tennessee student] wants to investigate whether [variable] affects [outcome] in [Tennessee setting]. Which experimental design would BEST test this?"

### Pattern 4: Ecosystem Change (MC or MS, DOK 2–3)
> "[Tennessee ecosystem — Smoky Mountains / Tennessee River / Cherokee Forest] diagram shows [food web]. If [organism / factor] changed, what would MOST LIKELY happen?"

### Pattern 5: Geological Evidence (MC or MS, DOK 2)
> "A geologist studying [Tennessee region] discovered [feature / rock / fossil]. Which [process / explanation] BEST accounts for this observation?"

### Pattern 6: Evidence-Based Multi-Select (MS, DOK 2–3)
> "Select the TWO [observations / pieces of evidence] that BEST [support / explain] [Tennessee science phenomenon]."
