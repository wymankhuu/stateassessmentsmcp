## 1. Overview

| Field | Detail |
|---|---|
| **Assessment Name** | Minnesota Comprehensive Assessments (MCA) — Reading |
| **Administering Agency** | Minnesota Department of Education (MDE) |
| **Vendor** | Pearson |
| **Grades Tested** | 3, 4, 5, 6, 7, 8, and 10 |
| **Testing Window** | March – May |
| **Delivery** | Computer-based; paper accommodations available |
| **Standards** | Minnesota Academic Standards — English Language Arts |
| **Score Scale** | Scaled score; 4 performance levels |
| **Reporting** | Individual Student Report; School, District, State aggregates |

> **MCA ELA Structure:** The MCA Reading assessment uses multiple choice (MC), short response (SR, scored 0–2), and extended response (ER, scored 0–4) items. The test is passage-based, requiring students to analyze literary and informational texts with increasing complexity across grade bands.

### Performance Levels

| Level | Label | Description |
|---|---|---|
| 4 | **Exceeds the Standards** | Demonstrates advanced understanding; applies Minnesota ELA standards with sophistication and depth |
| 3 | **Meets the Standards** | Demonstrates solid understanding of grade-level Minnesota ELA standards; meets proficiency expectations |
| 2 | **Partially Meets the Standards** | Demonstrates partial understanding; developing but not yet meeting grade-level expectations |
| 1 | **Does Not Meet the Standards** | Demonstrates minimal understanding; significant gaps in mastery of grade-level standards |

> **Item-writing target:** "Meets the Standards" performance. Items should require genuine application of Minnesota Academic Standards — not mere recall.

## 2. Standards Framework

> MCA ELA is aligned to the **Minnesota Academic Standards for English Language Arts**, organized by reading, writing, speaking/viewing/listening/media literacy strands.

### Minnesota ELA Strands

| Strand | Focus | Grade Emphasis |
|---|---|---|
| **Reading Benchmarks — Literature** | Literary text comprehension; theme; character; craft; structure | Primary assessment focus |
| **Reading Benchmarks — Informational Text** | Informational text comprehension; argument; evidence; text features | Primary assessment focus |
| **Writing** | Narrative, argumentative, informational writing; conventions | Assessed via SR and ER items |
| **Speaking, Viewing, Listening, and Media Literacy** | Not directly assessed on MCA | N/A |

### Key Reading Standards by Grade Band

| Standard Code | Description | Grade Band | DOK |
|---|---|---|---|
| MN.ELA3.1.1 | Ask and answer questions about a text, referring explicitly to details | 3–4 | 1–2 |
| MN.ELA5.2.3 | Determine the meaning of words and phrases as used in a text, including figurative language | 5 | 2 |
| MN.ELA6.1.2 | Determine a theme or central idea and how it is conveyed through particular details | 6 | 2–3 |
| MN.ELA7.2.6 | Determine an author's point of view or purpose and analyze how it is distinguished from others | 7 | 3 |
| MN.ELA8.1.3 | Analyze how differences in the points of view of characters and audience create effects | 8 | 3 |
| MN.ELA10.1.1 | Cite strong and thorough textual evidence to support analysis of what the text says explicitly and inferentially | 10 | 2–3 |

### Key Writing / Conventions Standards

| Standard Code | Description | Grade Band | DOK |
|---|---|---|---|
| MN.ELA3.6.1 | Demonstrate command of conventions of standard English grammar and usage | 3–5 | 1–2 |
| MN.ELA6.7.1 | Write arguments to support claims with clear reasons and relevant evidence | 6–8 | 3 |
| MN.ELA8.6.1 | Demonstrate command of conventions including grammar, usage, and mechanics | 8 | 1–2 |

## 3. Test Structure

MCA ELA is a computer-based assessment administered across multiple sessions. Items include MC, SR (0–2), and ER (0–4) formats, all passage-based.

```
+------------------------------------------------------------------+
|            MCA ELA STRUCTURE (Grades 3–8, 10)                     |
+------------------------------------------------------------------+
|  MULTIPLE SESSIONS — Approximately 2–3 hours total               |
|  Computer-Based                                                   |
|                                                                   |
|  SESSION 1: READING                                               |
|  ┌────────────────────────────────────────┐                      |
|  │ Passage Set 1 (Literary) → MC, SR     │                      |
|  │ Passage Set 2 (Informational) → MC,SR │                      |
|  └────────────────────────────────────────┘                      |
|                                                                   |
|  SESSION 2: READING & WRITING                                     |

|  │ Passage Set 4 → MC items              │                      |
|  │ Extended Response (ER) — 0–4 pts      │                      |

+------------------------------------------------------------------+
```

## 5. Item Types & Formats

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Passage-based                                           |
|  Machine scored                                          |
|  DOK 1–3                                                 |
+----------------------------------------------------------+
```

**MC Example (Grade 7 Literary, DOK 3, MN.ELA7.1.2):**

*[After reading a retelling of a Paul Bunyan tall tale set in the Minnesota North Woods]*

How does the author use exaggeration in this passage to develop the theme of human resourcefulness?

A. By describing the realistic challenges of logging in Minnesota winters
B. By making Paul Bunyan's feats impossibly large to show that determination can overcome any obstacle
C. By comparing Paul Bunyan to other historical Minnesota figures
D. By explaining the scientific reasons why Bunyan's feats are impossible

*Correct Answer: B*
*Alignment: MN.ELA7.1.2 | DOK 3*

---

**MC Example (Grade 5 Informational, DOK 2, MN.ELA5.2.2):**

*[After reading an article about Lake Superior's role in Minnesota's economy and ecosystem]*

Based on the article, what is the MAIN reason Lake Superior is important to Minnesota's economy?

A. It provides drinking water to every city in Minnesota
B. It supports shipping, tourism, and fishing industries that provide thousands of jobs
C. It is the only source of freshwater fish in the state
D. It prevents severe weather from reaching Minnesota's interior

*Correct Answer: B*
*Alignment: MN.ELA5.2.2 | DOK 2*

### Short Response (SR)

```
+----------------------------------------------------------+
|  SHORT RESPONSE — 0–2 points                             |
|                                                          |
|  2–4 sentence written response                           |
|  Must reference textual evidence                         |
|  Passage-based                                           |
|  Human scored                                            |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**SR Example (Grade 8, DOK 3, MN.ELA8.1.3 — 0–2 pts):**

*[After reading a story set in the Boundary Waters Canoe Area about two friends navigating a challenging portage]*

Using evidence from the passage, explain how the author uses the setting of the Boundary Waters to reveal the narrator's internal conflict.

### Extended Response (ER)

```
+----------------------------------------------------------+
|  EXTENDED RESPONSE — 0–4 points                          |
|                                                          |
|  Multi-paragraph written response                        |
|  Must integrate textual evidence                         |
|  Passage-based (may use paired passages)                 |
|  Human scored                                            |
|  DOK 3–4                                                 |
+----------------------------------------------------------+
```

**ER Example (Grade 10, DOK 4, MN.ELA10.7.1 — 0–4 pts):**

*[After reading two passages: one about the history of the Iron Range mining communities, one about modern efforts to diversify the Iron Range economy]*

Using evidence from both passages, write an essay analyzing how the economic identity of the Iron Range has changed over time. Explain how details from both texts support the idea that communities must adapt to survive.

## 8. Scoring Rubrics

### Multiple Choice (MC) — 1 Point

| Score | Criteria |
|---|---|
| 1 | Student selects the correct answer |
| 0 | Student selects an incorrect answer or leaves blank |

### Short Response (SR) Rubric — 0–2 Points

| Score | Criteria |
|---|---|
| 2 | Response accurately addresses the question with a clear, specific answer. Includes relevant textual evidence that directly supports the response. |
| 1 | Response partially addresses the question. Evidence may be present but loosely connected, or answer is accurate but lacks sufficient evidence. |
| 0 | Response is inaccurate, irrelevant, insufficient to evaluate, or blank. |

### Extended Response (ER) Rubric — 0–4 Points

| Score | Criteria |
|---|---|
| 4 | Thorough, insightful response with a clear controlling idea. Multiple pieces of relevant textual evidence integrated smoothly. Analysis is sophisticated and well-organized. Strong command of conventions. |
| 3 | Adequate response with a clear controlling idea. Relevant evidence included and generally well-integrated. Analysis is sound. Minor convention errors. |
| 2 | Partial response with an evident controlling idea. Some evidence present but may be insufficient or loosely connected. Analysis is basic. Some convention errors. |
| 1 | Minimal response with a weak or unclear controlling idea. Little or no evidence. Analysis superficial or largely inaccurate. Frequent convention errors. |
| 0 | Blank, off-topic, or insufficient writing to evaluate. |

## 10. Contextualization — Minnesota ELA

When generating passages and prompts, prioritize authentic Minnesota settings, history, and culture:

### Minnesota Context Guide

| Context | Passage Type | Grade Band |
|---|---|---|
| Paul Bunyan tall tales and Minnesota folklore | Literary fiction or retelling | 3–6 |
| Lake Superior (ecology, shipping, storms, history) | Informational or Literary | 4–10 |
| Iron Range mining history and communities | Informational or Historical fiction | 5–10 |
| Boundary Waters Canoe Area Wilderness | Literary or Informational | 5–10 |
| Minnesota prairie and farmland | Literary or Informational | 3–7 |
| Minneapolis / St. Paul landmarks and history | Informational | 5–10 |
| Minnesota winters and seasonal changes | Literary or Informational | 3–6 |
| Minnesota authors (F. Scott Fitzgerald, Sinclair Lewis, Louise Erdrich) | Literary text or excerpt | 7–10 |
| Voyageurs and fur trade history | Historical fiction or Informational | 4–8 |
| 10,000 lakes and water resources | Informational | 4–8 |

### Suggested Passage Topics by Grade Band

**Grades 3–4:**
- A Paul Bunyan adventure set in the Minnesota North Woods
- An informational article about Minnesota's state symbols and natural resources
- A story about a family ice fishing on one of Minnesota's 10,000 lakes

**Grades 5–6:**
- An article about the ecology and history of Lake Superior
- Historical fiction set during the fur trade era along the Minnesota-Canada border
- A narrative about life on a Minnesota prairie farm

**Grades 7–10:**
- Paired informational texts about the Iron Range — its mining past and economic future
- Literary fiction set in the Boundary Waters exploring themes of solitude and self-reliance
- An argumentative essay about preserving Minnesota's wilderness areas

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] Minnesota Academic Standard code verified as correct for the targeted grade
- [ ] MC items directly tied to the passage (not general knowledge)
- [ ] SR prompt requires textual evidence ("Using evidence from...")
- [ ] ER prompt provides clear task and references passage(s)
- [ ] Distractors represent authentic misconceptions
- [ ] Lexile of passage matches the grade-level range
- [ ] Minnesota context incorporated where appropriate
- [ ] SR scored on 0–2 scale; ER scored on 0–4 scale
- [ ] DOK level matches the cognitive demand
- [ ] All item types appropriate for the grade level

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| SR prompt without evidence requirement | Students may not cite text | Always include "using evidence from" language |
| ER scored on wrong scale | MCA ER uses 0–4 scale | Use full 4-point rubric |
| Items not passage-dependent | MCA ELA is passage-based | Tie all reading items to a specific passage |
| Distractors obviously wrong | Reduces item quality | Each distractor must represent a plausible misreading |
| Using CCSS codes | Minnesota uses its own Academic Standards | Reference Minnesota standard codes |
| Ignoring Grade 10 | MCA tests Grade 10 | Include Grade 10 in planning |

## 12. Prompt Patterns

### Pattern 1: Theme Development (MC or SR, DOK 3)
> "How does the author develop the theme of [theme] throughout the [story / passage]?"

### Pattern 2: Author's Craft (MC, DOK 3)
> "Read [line reference]. What effect does the author's use of [literary device / word choice] create in this [passage / paragraph]?"

### Pattern 3: Central Idea / Purpose (MC, DOK 2)
> "What is the MAIN [idea / purpose] of this [article / passage]?"

### Pattern 4: Vocabulary in Context (MC, DOK 1–2)
> "As used in paragraph [#], what does the word [word] MOST LIKELY mean?"

### Pattern 5: Text Evidence (SR, DOK 2–3)
> "Using evidence from the passage, explain how [element] contributes to [effect / meaning]."

### Pattern 6: Cross-Text Synthesis (ER, DOK 3–4)
> "Using evidence from both passages, write an essay [explaining / analyzing] [specific focus]. Include details from both texts."

### Pattern 7: Text Structure (MC, DOK 2)
> "How does the author organize the information in this [article / section]?"
