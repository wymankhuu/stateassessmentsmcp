## 1. Overview

| Field | Detail |
|---|---|
| **Assessment Name** | Minnesota Comprehensive Assessments (MCA) — Science |
| **Administering Agency** | Minnesota Department of Education (MDE) |
| **Vendor** | Pearson |
| **Grades Tested** | **Grade 5**, **Grade 8**, and **Grade 10** (high school) |
| **Testing Window** | March – May |

| **Standards** | Minnesota Academic Standards — Science |
| **Score Scale** | Scaled score; 4 performance levels |
| **Reporting** | Individual Student Report; School, District, State aggregates |

> **CRITICAL NOTE:** MCA Science is administered at **Grades 5, 8, and 10 only**. Do not generate MCA-aligned science items for other grades for state accountability purposes.

### Performance Levels

| Level | Label | Description |
|---|---|---|
| 4 | **Exceeds the Standards** | Demonstrates advanced understanding; applies Minnesota science standards in complex, novel situations |
| 3 | **Meets the Standards** | Demonstrates solid understanding of grade-level science standards; meets proficiency expectations |
| 2 | **Partially Meets the Standards** | Demonstrates partial understanding; developing but not yet meeting proficiency |
| 1 | **Does Not Meet the Standards** | Demonstrates minimal understanding; significant gaps in science knowledge |

> **Item-writing target:** "Meets the Standards" performance. Items should require genuine application of science concepts — not mere recall of vocabulary.

## 2. Standards Framework

> MCA Science is aligned to the **Minnesota Academic Standards for Science**, which were updated in 2019 and draw from the Framework for K-12 Science Education. Minnesota standards emphasize science and engineering practices alongside disciplinary core ideas and crosscutting concepts.

### Science and Engineering Practices (All Grades)

| Practice | Description |
|---|---|
| SEP.1 | Asking questions and defining problems |
| SEP.2 | Developing and using models |
| SEP.3 | Planning and carrying out investigations |
| SEP.4 | Analyzing and interpreting data |
| SEP.5 | Using mathematics and computational thinking |
| SEP.6 | Constructing explanations and designing solutions |
| SEP.7 | Engaging in argument from evidence |
| SEP.8 | Obtaining, evaluating, and communicating information |

MCA Science is a computer-based assessment. Items include MC, SR (0–2), and TEI formats, scenario-based with data, diagrams, and investigation contexts.

```
+------------------------------------------------------------------+
|          MCA SCIENCE STRUCTURE (Grades 5, 8, 10)                  |
+------------------------------------------------------------------+
```

## 5. Item Types & Formats

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Scenario-based or data-based stimulus                   |
|  May include diagrams, data tables, graphs               |
|  Machine scored                                          |
|  DOK 1–3                                                 |
+----------------------------------------------------------+
```

**MC Example (Grade 5, DOK 2, MN.Sci5.3.2 — Lake Superior Ecology):**

*[Diagram shows a food web in Lake Superior: Sunlight -> Phytoplankton -> Zooplankton -> Lake Herring -> Lake Trout -> Bald Eagle]*

Based on the food web, what would MOST LIKELY happen to the lake trout population if the lake herring population decreased significantly?

A. The lake trout population would increase because there would be less competition
B. The lake trout population would decrease because they would have less food available
C. The lake trout population would not change because they could eat phytoplankton directly
D. The lake trout population would move to a different lake

*Correct Answer: B*
*Alignment: MN.Sci5.3.2 | DOK 2*

---

**MC Example (Grade 8, DOK 2, MN.Sci8.1.1 — Iron Range Geology):**

A geologist studying the Iron Range in northern Minnesota discovers layers of banded iron formation (BIF) — alternating bands of iron-rich minerals and silica. These rocks are approximately 1.8 billion years old. Which conclusion is BEST supported by this evidence?

A. The Iron Range was formed by recent volcanic activity
B. The iron was deposited when ancient oceans contained dissolved iron that precipitated as oxygen levels rose
C. The iron was carried to Minnesota by glaciers during the last ice age
D. The banded pattern was created by repeated forest fires

*Correct Answer: B*
*Alignment: MN.Sci8.1.1 | DOK 2*

## 7. Scientific Investigation Design

MCA Science emphasizes students' ability to design and evaluate scientific investigations through Minnesota's Science and Engineering Practices.

### Investigation Design Components

| Component | Description | Practice Alignment |
|---|---|---|
| **Testable Question** | Question that can be answered through investigation | SEP.1 |
| **Hypothesis** | Testable prediction about variable relationships | SEP.1 |
| **Independent Variable** | The variable the investigator changes | SEP.3 |
| **Dependent Variable** | The variable being measured | SEP.3 |
| **Control Group** | Condition held constant for comparison | SEP.3 |
| **Data Collection** | Measurement using appropriate tools | SEP.4 |
| **Evidence-Based Conclusion** | Inference drawn from data | SEP.6, SEP.7 |

### Investigation Item Structure

```
+------------------------------------------------------------------+
|  INVESTIGATION DESIGN ITEM (MC or TEI)                            |
|                                                                   |
|  SCENARIO: A Minnesota student investigates whether [variable]    |
|  affects [outcome] in a [Minnesota-relevant setting].             |
|                                                                   |
|  STEM (MC): Which experimental setup would BEST allow the         |
|  student to test this hypothesis?                                 |
|  — OR —                                                           |
|  STEM (TEI): Drag the labels to correctly identify the            |
|  independent, dependent, and controlled variables.                |
+------------------------------------------------------------------+
```

## 8. Scoring Rubrics

### Multiple Choice (MC) — 1 Point

| Score | Criteria |
|---|---|
| 1 | Student selects the correct answer |
| 0 | Student selects an incorrect answer or leaves blank |

### Short Response (SR) Rubric — 0–2 Points

| Score | Criteria |
|---|---|
| 2 | Response accurately addresses the question with a clear scientific explanation. Includes relevant evidence or data that directly supports the response. |
| 1 | Response partially addresses the question. Explanation may be incomplete or evidence loosely connected. |
| 0 | Response is inaccurate, irrelevant, insufficient to evaluate, or blank. |

### Technology Enhanced Item (TEI) Rubric — 1–2 Points

| Score | Criteria |
|---|---|
| 2 | All components correct (labels, sequences, selections accurate) |
| 1 | Partially correct; at least one component accurate |
| 0 | Incorrect or blank |

## 10. Contextualization — Minnesota Science

When generating science items, prioritize authentic Minnesota natural settings and phenomena:

### Minnesota Science Context Guide

| Setting / Phenomenon | Grade | Science Domain | Standard Alignment |
|---|---|---|---|
| Lake Superior ecology (food webs, invasive species, water temperature) | 5, 8, 10 | Life/Earth Science | MN.Sci5.3.2, MN.Sci8.3.3, MN.Sci10.3.2 |
| Boundary Waters Canoe Area (water quality, acid rain, wilderness ecology) | 5, 8, 10 | Life/Earth Science | MN.Sci5.1.1, MN.Sci8.1.4, MN.Sci10.1.4 |
| Iron Range geology (banded iron formation, mining, geological history) | 8, 10 | Earth Science | MN.Sci8.1.1, MN.Sci10.1.2 |
| Minnesota prairie restoration (succession, biodiversity, native grasses) | 5, 8, 10 | Life Science | MN.Sci5.3.2, MN.Sci8.3.3, MN.Sci10.3.5 |
| Minnesota glacial geology (moraines, drumlins, lake formation) | 5, 8 | Earth Science | MN.Sci5.1.1, MN.Sci8.1.1 |
| Minnesota winter weather and climate | 5, 8 | Earth Science | MN.Sci5.1.3 |
| Mississippi River headwaters (watershed, water quality) | 5, 8, 10 | Earth/Life Science | MN.Sci5.1.1, MN.Sci8.1.4 |
| Minnesota forests (boreal, deciduous, seasonal changes) | 5, 8 | Life Science | MN.Sci5.3.1, MN.Sci8.3.3 |
| Minnesota wetland ecosystems | 5, 8, 10 | Life/Earth Science | MN.Sci5.3.2, MN.Sci8.3.3 |
| Lake Superior shipping and ice cover data | 8, 10 | Earth Science | MN.Sci8.1.4, MN.Sci10.1.4 |

### Suggested Anchoring Phenomena by Grade

**Grade 5 Phenomena:**
- "Scientists monitoring Lake Superior noticed that the lake's ice cover has decreased over the past 30 years. What might explain this change, and how could it affect organisms in the lake?"
- "After a heavy rainstorm, students at a school near the Mississippi River headwaters noticed that the stream was muddy and had changed course. What process caused this change?"
- "A Minnesota farmer restored a section of prairie grassland. After five years, the area had more species of insects and birds. What explains this increase in biodiversity?"

**Grade 8 Phenomena:**
- "Geologists studying the Iron Range discovered alternating bands of iron and silica in rocks that are 1.8 billion years old. What does this evidence tell us about Earth's ancient atmosphere?"
- "Scientists found that some Boundary Waters lakes have lower pH levels than they did 50 years ago. What evidence connects human activities to these changes?"
- "Minnesota's landscape includes flat plains in the west and rolling hills with thousands of lakes in the east. What geological processes created these different landscapes?"

**Grade 10 Phenomena:**
- "Prairie restoration projects across Minnesota are reintroducing native grasses and wildflowers to areas that were previously farmed. How does this process of ecological succession affect matter and energy flow in the ecosystem?"
- "Lake Superior's average water temperature has increased by approximately 3.5 F over the past century. How might this change affect the food web and overall ecosystem?"

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] Grade verified as 5, 8, or 10 ONLY (not other grades)
- [ ] Minnesota Academic Standard code is accurate and grade-appropriate
- [ ] Stimulus (data table/graph/diagram) clearly labeled with units
- [ ] SR prompts require evidence-based explanation
- [ ] TEI items use technology meaningfully (multi-select, drag-and-drop, labeling)
- [ ] All distractors represent real student misconceptions
- [ ] Investigation design items clearly identify variables
- [ ] Science content is accurate and reflects current scientific understanding
- [ ] Minnesota context incorporated where possible (Lake Superior, Boundary Waters, Iron Range, prairie)
- [ ] DOK level matches the cognitive demand

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Writing science items for non-tested grades | MCA Science only at Grades 5, 8, 10 | Restrict to tested grades |
| Using NGSS codes instead of Minnesota codes | Minnesota uses its own Academic Standards | Reference Minnesota standard codes exclusively |
| SR without evidence requirement | MCA SR items require evidence-based explanation | Include "using evidence" or "explain" language |
| Items assessing factual recall only | MCA Science is ~55–60% DOK 2 | Elevate items with scenarios and data |
| Generic phenomena not anchored to Minnesota | Assessment favors Minnesota-specific contexts | Use Lake Superior, Boundary Waters, Iron Range, prairie settings |
| MC with two clearly correct options | Creates ambiguity | Review all options carefully; only one clearly correct |

## 12. Prompt Patterns

### Pattern 1: Data-to-Conclusion (MC, DOK 2)
> "The [table / graph / diagram] shows [Minnesota science scenario]. Based on the data, which [conclusion / explanation / prediction] is BEST supported?"

### Pattern 2: Cause and Effect (MC, DOK 2)
> "A student [observed / measured] that [Minnesota phenomenon]. Which explanation BEST describes why this [occurred / changed]?"

### Pattern 3: Investigation Design (MC or TEI, DOK 2–3)
> "[Minnesota student] wants to investigate whether [variable] affects [outcome] in [Minnesota setting]. Which experimental design would BEST test this?"

### Pattern 4: Ecosystem Change (MC or TEI, DOK 2–3)
> "[Minnesota ecosystem — Lake Superior / prairie / Boundary Waters] diagram shows [food web]. If [organism / factor] changed, what would MOST LIKELY happen?"

### Pattern 5: Geological Process (MC, DOK 2)
> "A geologist studying [Minnesota region] discovered [feature / rock type / formation]. Which [process / explanation] BEST accounts for this?"

### Pattern 6: Evidence-Based Explanation (SR, DOK 2–3)
> "Using evidence from [data / scenario], explain [how / why] [Minnesota phenomenon] occurs."
