| Field | Detail |
|---|---|
| **Assessment Name** | Kansas Assessment Program (KAP) — Mathematics |
| **Administering Agency** | Kansas State Department of Education (KSDE) |
| **Vendor** | KS State DOE |

| **Testing Window** | April – May |

| **Standards** | Kansas Academic Standards for Mathematics |
| **Score Scale** | 4 performance levels; scaled score varies by grade |
| **Reporting** | Individual Student Report; School, District, State aggregates |

> **KAP Mathematics:** The Kansas Assessment Program measures student mastery of the Kansas Academic Standards for Mathematics. Items assess conceptual understanding, procedural fluency, and application of mathematics in real-world and mathematical contexts.

### Performance Levels

| Level | Label | Description |
|---|---|---|
| 4 | **Level 4** | Thorough understanding; applies mathematics in novel and complex situations; constructs valid mathematical arguments |
| 3 | **Level 3** | Adequate understanding; solves grade-level problems accurately; applies mathematics to real-world contexts |
| 2 | **Level 2** | Partial understanding; applies procedures in familiar contexts but struggles with novel problems |
| 1 | **Level 1** | Minimal understanding; significant conceptual and procedural gaps |

## 5. Item Types & Formats

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Real-world or mathematical context                      |
|  Machine scored                                          |
|  DOK 1–3                                                 |
+----------------------------------------------------------+
```

**MC Example (Grade 6, DOK 2, 6.RP.A.3):**

A farmer near Salina, Kansas harvests 450 bushels of wheat from 6 acres. At this rate, how many bushels would the farmer expect to harvest from 10 acres?

A. 500 bushels
B. 675 bushels
C. 750 bushels
D. 900 bushels

*Correct Answer: C*
*Alignment: 6.RP.A.3 | Ratios & Proportional Relationships | DOK 2*

---

**MC Example (Grade 4, DOK 2, 4.MD.A.3):**

A rectangular wheat field near Dodge City measures 120 feet long and 85 feet wide. What is the perimeter of the wheat field?

A. 205 feet
B. 410 feet
C. 10,200 feet
D. 10,200 square feet

*Correct Answer: B*
*Alignment: 4.MD.A.3 | Measurement & Data | DOK 2*

### Constructed Response (CR)

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE — 0–2 points                       |
|                                                          |
|  Show work and explain reasoning                         |
|  Real-world or mathematical context                      |
|  Human scored                                            |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**CR Example (Grade 7, DOK 3, 7.RP.A.2):**

A Wichita aircraft factory produces airplane parts at a constant rate. The table below shows the number of parts produced over time:

| Hours | Parts Produced |
|---|---|
| 2 | 84 |
| 5 | 210 |
| 8 | 336 |

Is this a proportional relationship? Explain how you know using the data in the table. Then write an equation that represents this relationship.

*Scoring:*
- *2 pts: Correctly identifies proportional relationship with valid justification (e.g., constant unit rate of 42 parts/hour); writes correct equation (y = 42x)*
- *1 pt: Correct identification with incomplete justification, OR correct equation without explanation*
- *0 pts: Incorrect identification or blank*

## 8. Scoring Rubrics

### Constructed Response (CR) Rubric — 0–2 Points

| Score | Criteria |
|---|---|
| 2 | Correct solution with clear mathematical reasoning. Work shown systematically. Explanation demonstrates conceptual understanding. Appropriate mathematical vocabulary used. |
| 1 | Partial understanding with minor errors. Correct approach demonstrated but final answer contains an error. OR Correct answer given without sufficient work or explanation. |
| 0 | Incorrect approach, no understanding shown, or blank. |

### CR Scoring Notes

- **Work must be shown** for full credit on all CR items.
- **Explanations** should reference mathematical concepts, not just describe steps.
- **Computational errors** with correct reasoning earn partial credit (1 point).

## 10. Contextualization — Kansas Mathematics

When generating problem contexts, use authentic Kansas settings:

### Kansas Math Context Guide

| Context | Domain | Grade Band |
|---|---|---|
| Kansas wheat farming (bushels per acre, harvest data) | Ratios, Operations, Data | 3–8 |
| Wichita aviation factory (production rates, dimensions) | Proportionality, Measurement | 5–11 |
| Dodge City cattle ranching (costs, weights, areas) | Operations, Measurement | 3–7 |
| Kansas tornado statistics (frequency, speed, distance) | Data Analysis, Statistics | 5–11 |
| Flint Hills tallgrass prairie (area, perimeter, ecology data) | Geometry, Measurement | 4–8 |
| Kansas state fair (attendance, pricing, statistics) | Operations, Data Analysis | 3–7 |
| Kansas highway distances (travel, rates, time) | Ratios, Proportionality | 5–8 |
| Kansas wind farm energy production | Functions, Data Analysis | 6–11 |
| Topeka school district budgets | Financial applications | 6–11 |
| Kansas sunflower seed production | Operations, Fractions | 3–5 |

### Suggested Problem Contexts by Grade

**Grades 3–5:**
- Counting sunflower seeds; measuring wheat field dimensions
- Sharing bushels of wheat equally among grain elevators
- Calculating the area of a rectangular cattle pen near Dodge City

**Grades 6–8:**
- Comparing wheat production rates across Kansas counties
- Analyzing tornado frequency data for Kansas over 10 years
- Calculating production costs at a Wichita aircraft parts factory

**Grade 11:**
- Modeling wind energy output as a function of wind speed for a Kansas wind farm
- Analyzing scatter plots of wheat yield vs. rainfall across Kansas counties
- Using trigonometry to calculate distances in Kansas land surveying

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] Kansas Academic Standards code is accurate and grade-appropriate
- [ ] MC items have exactly 4 options with one correct answer
- [ ] CR items require work to be shown and reasoning explained
- [ ] CR scored on 0–2 point scale
- [ ] Calculator policy appropriate for grade level
- [ ] Kansas real-world context used where appropriate
- [ ] Distractors represent actual student computational or conceptual errors
- [ ] All computations verified before item is finalized
- [ ] DOK level matches actual cognitive demand
- [ ] Grade 11 items reflect high school mathematics complexity

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| CR asking only for a final answer | CR must require explanation | Add "Show your work and explain" |
| Using non-Kansas contexts | Misses state contextualization | Use Kansas farms, aviation, weather, and geography |
| Items testing only rote computation | KAP targets DOK 2 primarily | Add real-world context to elevate cognitive demand |
| Grade 11 items at middle school level | Underestimates high school expectations | Use algebra, functions, and statistics at HS level |
| Distractors that are obviously wrong | Does not assess real misconceptions | Base distractors on common student errors |

## 12. Prompt Patterns

### Pattern 1: Real-World Application (MC, DOK 2)
> "[Kansas context]. [Multi-step problem]. What is [answer]?"

### Pattern 2: Justify and Explain (CR, DOK 3)
> "[Kansas scenario]. [Problem]. Show your work and explain how you found your answer."

### Pattern 3: Proportional Reasoning (MC, DOK 2)
> "A [Kansas entity] produces/uses [quantity] in [time/unit]. At this rate, how much [quantity] in [different time/unit]?"

### Pattern 4: Data Interpretation (MC, DOK 2)
> "The [table / graph] shows [Kansas data context]. Based on the data, which statement is correct?"

### Pattern 5: Multi-Step Problem Solving (CR, DOK 3)
> "[Kansas scenario with multiple constraints]. Determine [answer]. Show your work and explain whether your answer is reasonable."

### Pattern 6: Comparison and Reasoning (CR, DOK 3)
> "Two students solved this problem differently. [Method A] and [Method B]. Who is correct? Use mathematics to justify your answer."
