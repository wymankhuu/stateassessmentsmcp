## AssessmentForge Skill Guide | Grades 5, 8, and 11

## 1. Overview

| Field | Detail |
|---|---|
| **Assessment Name** | Kansas Assessment Program (KAP) — Science |
| **Administering Agency** | Kansas State Department of Education (KSDE) |
| **Vendor** | KS State DOE |
| **Grades Tested** | **Grade 5**, **Grade 8**, and **Grade 11** |
| **Testing Window** | April – May |
| **Delivery** | Computer-based; single session |
| **Standards** | Kansas Academic Standards for Science (NGSS-based) |
| **Score Scale** | 4 performance levels; scaled score varies by grade |
| **Reporting** | Individual Student Report; School, District, State aggregates |

> **CRITICAL NOTE:** KAP Science is administered **only at Grades 5, 8, and 11**. Do not generate science items for Grades 3, 4, 6, or 7.

> **KAP Science and NGSS:** Kansas adopted science standards aligned to the Next Generation Science Standards (NGSS). All items must be three-dimensional: integrating **Disciplinary Core Ideas (DCI)**, **Science and Engineering Practices (SEP)**, and **Crosscutting Concepts (CCC)**.

### Performance Levels

| Level | Label | Description |
|---|---|---|
| 4 | **Level 4** | Demonstrates thorough three-dimensional science understanding; expertly integrates DCI, SEP, and CCC; constructs sophisticated evidence-based explanations |
| 3 | **Level 3** | Demonstrates adequate three-dimensional understanding; appropriately applies science practices and crosscutting concepts |
| 2 | **Level 2** | Demonstrates partial understanding; applies DCI content but struggles to integrate SEP or CCC meaningfully |
| 1 | **Level 1** | Demonstrates minimal science understanding; limited to recall of isolated facts |

## 3. Test Structure

KAP Science is a single-session, computer-based assessment. All items are scenario-based.

```
+------------------------------------------------------------------+
|           KAP SCIENCE STRUCTURE (Grades 5, 8, 11)                |
+------------------------------------------------------------------+
|  SINGLE SESSION                                                    |
|  Computer-Based, Fixed-Form                                        |
|  Approximately 90–120 minutes                                      |
|                                                                    |
|  ~35–40 items per grade                                            |
|                                                                    |
|  Item types:                                                       |
|    - Multiple Choice (MC) — ~55–60%                               |
|    - Multi-Select (MS) — ~15–20%                                  |
|    - Constructed Response (CR) — ~20–25% (0–2 pts each)           |
+------------------------------------------------------------------+
```

## 5. Item Types & Formats

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Scenario, diagram, data table, or model stimulus        |
|  Must integrate DCI + SEP + CCC                          |
|  Machine scored                                          |
+----------------------------------------------------------+
```

**MC Example (Grade 5, DOK 2, 5-LS2-1 — Ecosystem Energy Flow):**

A diagram shows a Kansas tallgrass prairie food chain: Sunlight -> Big Bluestem Grass -> Grasshoppers -> Prairie Chickens -> Red-tailed Hawks

Which statement BEST explains the role of big bluestem grass in this Flint Hills ecosystem?

A. Big bluestem grass receives energy from grasshoppers through the food chain
B. Big bluestem grass captures energy from the sun and converts it into food stored in its cells
C. Big bluestem grass is a decomposer that breaks down dead organisms in the prairie
D. Big bluestem grass gets most of its energy from nutrients in the soil

*Correct Answer: B*
*Alignment: 5-LS2-1 | SEP: Developing and Using Models | CCC: Energy and Matter | DOK 2*

---

**MC Example (Grade 8, DOK 2, MS-ESS2-2 — Earth's Surface):**

Scientists studying the Flint Hills region of Kansas observed that the limestone formations were created from the shells and skeletons of marine organisms millions of years ago. Which statement BEST explains what this evidence tells us about the geologic history of Kansas?

A. Kansas was always a flat prairie covered in grasses
B. The area that is now Kansas was once covered by a shallow sea
C. Limestone formed from volcanic activity in the region
D. Marine organisms migrated to Kansas through underground rivers

*Correct Answer: B*
*Alignment: MS-ESS2-2 | SEP: Constructing Explanations | CCC: Stability and Change | DOK 2*

---

### Multi-Select (MS)

```
+----------------------------------------------------------+
|  MULTI-SELECT RESPONSE — 1 point                         |
|                                                          |
|  5–6 options; select exactly 2 or 3 correct answers      |
|  All must be selected for credit                         |
|  Machine scored                                          |
+----------------------------------------------------------+
```

**MS Example (Grade 8, DOK 2, MS-ESS3-3 — Human Impact):**

Kansas farmers have noticed increased soil erosion on wheat fields during dry, windy seasons. Select the TWO strategies that would BEST help reduce soil erosion on Kansas farmland.

A. Remove all vegetation along field edges to make more room for crops
B. Plant cover crops during the off-season to hold soil in place
C. Increase the amount of chemical fertilizer applied to the fields
D. Use no-till farming methods to keep root systems intact in the soil
E. Irrigate the fields more frequently with water from the Ogallala Aquifer

*Correct Answers: B, D*
*Alignment: MS-ESS3-3 | SEP: Constructing Explanations | CCC: Cause and Effect | DOK 2*

### Constructed Response (CR)

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE — 0–2 points                       |
|                                                          |
|  Written explanation using evidence from the stimulus    |
|  Stimulus always provided (data, diagram, scenario)      |
|  Must demonstrate three-dimensional reasoning            |
|  Human scored                                            |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**CR Example (Grade 11, DOK 3, HS-LS2-2 — Biodiversity):**

*Stimulus: A data table showing the number of bird species, insect species, and plant species in three Kansas ecosystems: a monoculture wheat field, a mixed-crop farm with hedgerows, and a tallgrass prairie preserve in the Flint Hills. The prairie preserve has significantly higher biodiversity.*

Using evidence from the data table, explain why the tallgrass prairie preserve supports greater biodiversity than the monoculture wheat field. Describe TWO factors from the data that support your explanation.

*Scoring:*
- *2 pts: Accurately explains the relationship between habitat diversity and biodiversity; cites two specific data points from the table; integrates cause-and-effect reasoning*
- *1 pt: Partially correct explanation with one piece of evidence, OR two pieces of evidence without adequate cause-and-effect reasoning*
- *0 pts: Off-topic, blank, or major scientific misconception*

## 7. Three-Dimensional Design

Every KAP Science item must reflect all three NGSS dimensions simultaneously.

### Three-Dimensions Alignment Guide

| Dimension | What It Is | Example in KAP Items |
|---|---|---|
| **DCI** (What students know) | Disciplinary science content | Tallgrass prairie food webs; chemical reactions; Kansas geology; genetic inheritance |
| **SEP** (What students do) | How scientists work | Analyze population data; construct explanations from evidence; use a model to predict ecosystem changes |
| **CCC** (Lens of thinking) | Cross-domain thinking tools | Cause and effect; patterns; energy and matter; structure and function; systems and system models |

### Sample Three-Dimensional Item Design (Grade 8)

```
+------------------------------------------------------------------+
|  3D ITEM STRUCTURE                                               |
|                                                                  |
|  PHENOMENON: Soil erosion has increased dramatically on          |
|  western Kansas wheat farms during drought years                 |
|  (Authentic Kansas phenomenon)                                   |
|                                                                  |
|  DCI: MS-ESS2 — Earth's Systems; MS-ESS3 — Human impacts        |
|  SEP: Analyzing and Interpreting Data                            |
|  CCC: Cause and Effect                                           |
|                                                                  |
|  STIMULUS: Data table showing rainfall, wind speed, and          |
|  topsoil loss on Kansas farms over 10 years                      |
|                                                                  |
|  PROMPT: "Using data from the table, construct an explanation    |
|  for the increase in soil erosion during drought years.          |
|  Include specific evidence from the data and explain the         |
|  cause-and-effect relationships."                                |
+------------------------------------------------------------------+
```

### Crosscutting Concepts by Grade Band

| CCC | Grade 5 Emphasis | Grade 8 Emphasis | Grade 11 Emphasis |
|---|---|---|---|
| Patterns | Prairie seasonal cycles; weather patterns | Chemical reaction patterns; population trends | Periodic table patterns; evolutionary change |
| Cause and Effect | Food chain disruption; erosion | Human impacts on soil and water; chemical reactions | Evolution mechanisms; ecosystem feedback |
| Energy and Matter | Food webs; water cycle | Thermal energy transfer; chemical energy | Metabolic pathways; Earth system cycles |
| Structure and Function | Plant adaptations to prairie; animal structures | Cell structures; molecular properties | DNA/protein/trait; organ systems |
| Systems and System Models | Prairie ecosystems; water cycle | Earth systems; ecosystems | Ecosystem feedback; climate systems |

## 8. Scoring Rubrics

### Constructed Response (CR) Rubric — 0–2 Points

| Score | Criteria |
|---|---|
| 2 | Response accurately addresses the science concept; demonstrates three-dimensional understanding (DCI + SEP or CCC evident); includes specific, relevant evidence from the stimulus; explanation is complete, accurate, and logically connected |
| 1 | Response addresses the science concept with partial accuracy; shows understanding of the DCI but only partially integrates a practice or crosscutting concept; evidence present but may be incomplete |
| 0 | Response does not address the science concept; blank; off-topic; restates stimulus without explanation; no science understanding demonstrated |

### CR Scoring Notes

- **Evidence from the stimulus is required.** Responses relying solely on prior knowledge earn a maximum of 1 point.
- **Three-dimensional reasoning** (integrating DCI with SEP or CCC) is needed for full credit.
- **Scientific misconceptions** reduce the score by at least one point.

## 10. Contextualization — Kansas Science

When generating KAP Science items, prioritize authentic Kansas natural and agricultural settings:

### Kansas Science Context Guide

| Setting / Phenomenon | Grade | Science Domain | PE Alignment |
|---|---|---|---|
| Flint Hills tallgrass prairie prescribed burns | 5, 8 | Life Science | 5-LS2, MS-LS2 |
| Kansas wheat farming and soil science | 5, 8 | Earth/Life Science | 5-ESS3, MS-ESS3 |
| Kansas tornado formation and severe weather | 5, 8, 11 | Earth Science | 5-ESS2, MS-ESS2, HS-ESS2 |
| Ogallala Aquifer depletion in western Kansas | 8, 11 | Earth Science | MS-ESS3, HS-ESS3 |
| Kansas wind energy and turbine technology | 8, 11 | Physical Science | MS-PS3, HS-PS3 |
| Flint Hills limestone geology (ancient marine life) | 5, 8 | Earth Science | 5-ESS2, MS-ESS2 |
| Cheyenne Bottoms wetland bird migration | 5, 8 | Life Science | 5-LS2, MS-LS2 |
| Kansas bison restoration on tallgrass prairie | 8, 11 | Life Science | MS-LS2, HS-LS2 |
| Wichita aviation materials science | 11 | Physical Science | HS-PS1 |
| Kansas drought and Dust Bowl history | 8, 11 | Earth Science | MS-ESS3, HS-ESS3 |
| Prairie chicken population and habitat fragmentation | 8, 11 | Life Science | MS-LS2, HS-LS4 |

### Suggested Anchoring Phenomena by Grade

**Grade 5 Phenomena:**
- "Every spring, ranchers in the Flint Hills set fire to the tallgrass prairie. Instead of harming the grass, the fires help it grow back thicker than before. Why?"
- "A student noticed that after a Kansas windstorm, the wheat field on one side of a shelter belt had much less damage than the field on the other side. What explains this?"

**Grade 8 Phenomena:**
- "Water levels in the Ogallala Aquifer under western Kansas have dropped significantly over the past 50 years while wheat and corn production has increased. What explains this pattern?"
- "Kansas limestone quarries contain fossils of sea creatures, even though Kansas is now a landlocked prairie. What does this evidence tell us about Earth's history?"

**Grade 11 Phenomena:**
- "The greater prairie chicken population in Kansas has declined by 80% since 1960, even though hunting has been restricted. What ecological factors explain this decline?"
- "A Wichita aircraft manufacturer tested two different metal alloys for airplane wings. One alloy absorbed more thermal energy during welding. What does this tell us about the chemical bonds in each alloy?"

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] Grade verified as 5, 8, or 11 ONLY
- [ ] PE code is a valid NGSS Performance Expectation
- [ ] Item is three-dimensional: DCI + SEP + CCC all identified
- [ ] Anchoring phenomenon is authentic and Kansas-relevant where possible
- [ ] Stimulus has clear labels, units, and realistic data
- [ ] CR prompt directs students to use evidence from the stimulus
- [ ] All distractors represent real misconceptions
- [ ] MS items specify how many answers to select (TWO/THREE)
- [ ] Science content is accurate and reflects current scientific understanding
- [ ] Vocabulary is grade-appropriate

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Writing science items for Grades 3, 4, 6, or 7 | KAP Science is only at Grades 5, 8, 11 | Restrict to tested grades |
| DCI-only items (no SEP or CCC) | KAP requires three-dimensional items | Always embed a practice and crosscutting concept |
| CR prompts without evidence directive | Students may respond without citing data | Include "Use evidence from the [data/graph/diagram]" |
| Generic Midwest phenomena | KAP favors Kansas-specific contexts | Use Flint Hills, Kansas weather, wheat, aviation contexts |
| MS items with only 2 options in 4 total | Too easy to guess | Use 5–6 options with exactly 2–3 correct |

## 12. Prompt Patterns

### Pattern 1: Data-to-Conclusion (MC, DOK 2)
> "The [graph / table / diagram] below shows [Kansas science scenario]. Based on the data, which [conclusion / explanation / pattern] is BEST supported?"

### Pattern 2: Phenomenon Explanation (CR, DOK 3)
> "Scientists observed [Kansas-anchored phenomenon]. Using evidence from the [data / model / diagram], construct an explanation for [specific science focus]. Explain the [cause-and-effect / energy flow / pattern] relationship."

### Pattern 3: Model Evaluation (MC or MS, DOK 2–3)
> "A student made a model showing [Kansas science concept]. Which statement BEST describes what the model shows about [DCI focus]?"

### Pattern 4: Investigation Design (CR, DOK 3)
> "A scientist in Kansas wants to investigate whether [variable] affects [outcome] in [Kansas ecosystem/setting]. Describe a procedure including what would be measured and how results would be interpreted."

### Pattern 5: Evidence-Based Argument (CR, DOK 3)
> "Two students disagree about [Kansas science claim]. Student A says [misconception]. Student B says [correct claim]. Using evidence from the [data / diagram], explain which student is correct and why."

### Pattern 6: Human Impact and Solutions (MS or CR, DOK 2–3)
> "Human activities have [impacted Kansas environment]. Select the TWO strategies that BEST [monitor / reduce / address] this impact."
