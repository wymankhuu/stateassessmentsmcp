## 1. Overview

| Field | Detail |
|---|---|
| **Assessment Name** | New Mexico Statewide Assessment (NMSA) — Mathematics |
| **Administering Agency** | New Mexico Public Education Department (NMPED) |
| **Vendor** | Pearson |

| **Testing Window** | March – April |
| **Delivery** | Computer-based; multi-session test |
| **Standards** | New Mexico Common Core State Standards (NM-CCSS) — Mathematics |
| **Score Scale** | 650–850 scale score (varies by grade); 4 performance levels |
| **Reporting** | Individual Student Report; School, District, State aggregates |

> **NMSA and PARCC:** NMSA Mathematics is derived from the **PARCC** design. Content is organized into Major, Supporting, and Additional clusters at each grade level. Item types include SR, EQ, SCR (0–2 pts), and ECR (0–6 pts). New Mexico uses **NM-CCSS** for Mathematics, which are aligned to CCSS-Math.

### Performance Levels

| Level | Label | Description |
|---|---|---|
| 4 | **Exceeded Expectations** | Distinguished command; applies mathematics in complex, novel situations; constructs sophisticated mathematical arguments |
| 3 | **Met Expectations** | Strong command; applies mathematics effectively to real-world and mathematical problems |
| 2 | **Partially Met Expectations** | Partial command; limited ability to apply mathematical concepts beyond routine procedures |
| 1 | **Did Not Meet Expectations** | Minimal command; significant conceptual and procedural gaps |

## 5. Item Types & Formats

### Selected Response (SR)

```
+----------------------------------------------------------+
|  SELECTED RESPONSE — 1 point                             |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Real-world or mathematical context                      |
|  Machine scored                                          |
|  DOK 1–3                                                 |
+----------------------------------------------------------+
```

**SR Example (Grade 7, DOK 2, NM-CCSS.Math.7.RP.A.2):**

The Carlsbad Caverns gift shop sells 5 souvenir postcards for $3.75. At this rate, how much would 12 postcards cost?

A. $7.50
B. $8.25
C. $9.00
D. $10.50

*Correct Answer: C*
*Alignment: NM-CCSS.Math.7.RP.A.2 | Major Content | DOK 2*

---

### Equation/Numeric Entry (EQ)

```
+----------------------------------------------------------+
|  EQUATION / NUMERIC ENTRY — 1 point                      |
|                                                          |
|  Student types numeric answer or expression              |
|  No answer choices provided                              |
|  Machine scored                                          |
|  DOK 1–2                                                 |
+----------------------------------------------------------+
```

**EQ Example (Grade 5, DOK 2, NM-CCSS.Math.5.NF.A.1):**

A family hiking in the Sandia Mountains completed 3/8 of the trail before lunch and 1/4 of the trail after lunch. What fraction of the trail did the family complete that day?

Enter your answer as a fraction: **5/8**

*Alignment: NM-CCSS.Math.5.NF.A.1 | Major Content | DOK 2*

### Short Constructed Response (SCR)

```
+----------------------------------------------------------+
|  SHORT CONSTRUCTED RESPONSE — 0–2 points                 |
|                                                          |
|  Explain reasoning in 2–4 sentences                      |
|  Show work required for full credit                      |
|  Human scored                                            |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**SCR Example (Grade 6, DOK 3, NM-CCSS.Math.6.RP.A.3):**

The Big Room in Carlsbad Caverns is approximately 4,000 feet long and 625 feet wide. A park ranger walks a loop trail through the Big Room at a pace of 2.5 miles per hour. If the trail is 1.25 miles long, how many minutes will it take the ranger to complete one loop? Show your work and explain how you found your answer.

*Scoring:*
- *2 pts: Correct answer (30 minutes) with clear work shown; explanation demonstrates understanding of rate reasoning*
- *1 pt: Correct approach with minor arithmetic error, OR correct answer without process shown*
- *0 pts: Incorrect approach or blank*

### Extended Constructed Response (ECR)

```
+----------------------------------------------------------+
|  EXTENDED CONSTRUCTED RESPONSE — 0–6 points              |
|                                                          |
|  Multi-part problem with work and written justification  |
|  Assesses reasoning and modeling at DOK 3                |
|  Human scored                                            |
|  Session 2 (Calculator)                                  |
+----------------------------------------------------------+
```

**ECR Example (Grade 8 — Linear Modeling):**

*The table below shows the average monthly flow rate (in cubic feet per second) of the Rio Grande at five locations along its course through New Mexico.*

| Location | Distance from CO Border (mi) | Avg. Flow Rate (cfs) |
|---|---|---|
| Taos Junction | 35 | 890 |
| Albuquerque | 125 | 1,240 |
| Socorro | 200 | 980 |
| Elephant Butte Dam | 250 | 650 |
| Las Cruces | 320 | 420 |

**Part A:** Create a scatter plot of this data and describe the overall relationship between distance from the Colorado border and flow rate.

**Part B:** Between which two consecutive locations does the greatest decrease in flow rate occur? Calculate the rate of change (slope) for that segment. Show your work.

**Part C:** A hydrologist claims that the Rio Grande loses water at a constant rate as it flows south through New Mexico. Using your scatter plot and calculations, evaluate whether this claim is supported by the data. Explain your reasoning.

## 8. Scoring Rubrics

### Short Constructed Response (SCR) Rubric — 0–2 Points

| Score | Criteria |
|---|---|
| 2 | Correct solution with clear mathematical reasoning. Work shown systematically. Appropriate mathematical vocabulary used. Explanation demonstrates conceptual understanding. |
| 1 | Partial understanding with minor errors. Correct approach demonstrated even if the final answer contains a computational error. OR Correct answer given without sufficient explanation or work. |
| 0 | Response is incorrect, shows no understanding, or is blank. |

### Extended Constructed Response (ECR) Rubric — 0–6 Points

| Score | Criteria |
|---|---|
| 6 | All parts correct with clear, complete mathematical reasoning. Work shown systematically. All explanations accurate and complete. Justifications well-supported with evidence. |
| 5 | All parts essentially correct. Minor computational or notational error does not affect overall reasoning. |
| 4 | Correct approach throughout. One significant error or one part incorrect; reasoning otherwise sound. |
| 3 | Correct approach on majority of parts. Multiple minor errors or one major error; some reasoning present. |
| 2 | Partial understanding. Correct approach on at least one part; some valid mathematical work. |
| 1 | Minimal understanding shown. Some relevant mathematical work attempted. |
| 0 | Incorrect, irrelevant, or blank. |

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] NM-CCSS standard code is accurate and grade-appropriate
- [ ] Content cluster identified (Major, Supporting, or Additional)
- [ ] Session assignment is correct (calculator vs. non-calculator)
- [ ] SCR items require work to be shown (not just a final answer)
- [ ] ECR has exactly three parts of increasing complexity
- [ ] New Mexico real-world context used where appropriate
- [ ] Distractors represent actual student computational or conceptual errors
- [ ] All computations verified before item is finalized
- [ ] DOK level matches the actual cognitive demand
- [ ] Grade 11 items reflect high school content standards

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Calculator items in Session 1 | Session 1 is non-calculator | Design Session 1 items for mental math or standard algorithms |
| SCR that only asks for an answer | SCR must require explanation/justification | Add "Show your work and explain how you found your answer" |
| ECR with only one part | ECR requires multi-part structure | Design 3 parts of increasing complexity |
| Ignoring cluster weights | Major content should dominate | Ensure ~65–70% of items target Major cluster standards |
| Generic context without New Mexico flavor | NMSA items benefit from state context | Use Carlsbad Caverns, Rio Grande, White Sands, Santa Fe contexts |
| Items testing only rote computation | NMSA targets DOK 2 primarily | Add real-world context to elevate to application level |

## 12. Prompt Patterns

### Pattern 1: Real-World Application (SR, DOK 2)
> "[New Mexico context]. [Multi-step problem requiring application of concept]. What is [answer]?"

### Pattern 2: Justify and Explain (SCR, DOK 3)
> "[New Mexico scenario requiring strategic thinking]. [Multi-step problem]. Show your work and explain how you found your answer."

### Pattern 3: Equivalent Representations (SR or EQ, DOK 2)
> "Select the [expression / equation / value] that is equivalent to [given value or expression]."

### Pattern 4: Linear Relationship (SR or SCR, DOK 2–3)
> "The [table / graph] shows [New Mexico data context]. What is the [rate of change / slope / equation] that represents this relationship?"

### Pattern 5: Multi-Part Modeling (ECR, DOK 3)
> "Part A: [Direct calculation]. Part B: [Extension or comparison]. Part C: [Justify whether... / Evaluate if this is reasonable using mathematics]."

### Pattern 6: Comparison and Reasoning (SCR or SR, DOK 3)
> "Two students solved this problem differently. Student A says [method/answer]. Student B says [method/answer]. Who is correct? Use mathematics to justify your answer."
