## 1. Overview

| Field | Detail |
|---|---|
| **Assessment Name** | New Mexico Statewide Assessment (NMSA) — Science |
| **Administering Agency** | New Mexico Public Education Department (NMPED) |
| **Vendor** | Pearson |
| **Grades Tested** | **Grade 5**, **Grade 8**, **Grade 11** |
| **Testing Window** | March – April |
| **Delivery** | Computer-based; single session |
| **Standards** | New Mexico STEM-Ready Science Standards (incorporating NGSS) |
| **Score Scale** | 4 performance levels; scaled score varies by grade |
| **Reporting** | Individual Student Report; School, District, State aggregates |

> **CRITICAL NOTE:** NMSA Science is administered **only at Grades 5, 8, and 11**. Do not generate NMSA Science items for Grades 3, 4, 6, or 7.

> **NMSA and NGSS:** New Mexico STEM-Ready Science Standards fully incorporate the **Next Generation Science Standards (NGSS)** framework. All items must be three-dimensional: integrating **Disciplinary Core Ideas (DCI)**, **Science and Engineering Practices (SEP)**, and **Crosscutting Concepts (CCC)**.

### Performance Levels

| Level | Label | Description |
|---|---|---|
| 4 | **Exceeded Expectations** | Distinguished three-dimensional science understanding; expertly integrates DCI, SEP, and CCC |
| 3 | **Met Expectations** | Strong three-dimensional understanding; appropriately applies practices and crosscutting concepts |
| 2 | **Partially Met Expectations** | Partial understanding; limited to surface-level application of science concepts |
| 1 | **Did Not Meet Expectations** | Minimal understanding; limited to recall of isolated facts |

## 3. Test Structure

NMSA Science is a single-session, computer-based assessment. All items are scenario-based with data tables, diagrams, graphs, and models as stimuli.

```
+------------------------------------------------------------------+
|           NMSA SCIENCE STRUCTURE (Grades 5, 8, 11)                |
+------------------------------------------------------------------+
|  SINGLE SESSION                                                  |
|  Computer-Based, Fixed-Form                                      |
|  Approximately 90–120 minutes                                    |
|                                                                  |
|  ~40 items per grade                                             |
|                                                                  |
|  Item types:                                                     |
|    Selected Response (SR) — ~55–60% (~24 items)                 |
|    Constructed Response (CR) — ~20–25% (~8–10 items; 0–3 pts)   |
|    Technology Enhanced / Multi-Select — ~15–20% (~6–8 items)     |
+------------------------------------------------------------------+
```

### Grade-Level Test Specifications

| Specification | Grade 5 | Grade 8 | Grade 11 |
|---|---|---|---|
| Total Items (approx.) | ~38–42 | ~38–42 | ~38–42 |
| Selected Response | ~22–26 | ~22–26 | ~22–26 |
| Multi-Select / TE | ~6–8 | ~6–8 | ~6–8 |
| Constructed Response | ~6–10 | ~6–10 | ~6–10 |
| Testing Time | 90–120 min | 90–120 min | 90–120 min |

> **Three-Dimensional Requirement:** Every NMSA Science item must integrate at least one **DCI**, one **SEP**, and one **CCC**. Items that test DCI content in isolation are not aligned to the NM STEM-Ready Science Standards.

## 5. Item Types & Formats

### Selected Response (SR)

```
+----------------------------------------------------------+
|  SELECTED RESPONSE — 1 point                             |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Scenario, diagram, data table, or model stimulus        |
|  Must integrate DCI + SEP + CCC                          |
|  Machine scored                                          |
+----------------------------------------------------------+
```

**SR Example (Grade 8, DOK 2, MS-ESS2-2 — Geoscience Processes):**

Geologists studying Carlsbad Caverns found that the cave chambers contain massive stalactites and stalagmites made of calcium carbonate, yet the surrounding rock is primarily limestone that formed on an ancient seafloor. Which explanation BEST accounts for the formation of these cave features?

A. Underground rivers carved the chambers and deposited sand that hardened into stalactites
B. Slightly acidic groundwater dissolved the limestone over millions of years, and mineral-rich water dripping into the caves deposited calcium carbonate to form the structures
C. Volcanic heat melted the limestone, which re-solidified into stalactite and stalagmite formations
D. Earthquakes cracked the limestone, and wind blowing through the cracks shaped the formations over time

*Correct Answer: B*
*Alignment: MS-ESS2-2 | SEP: Constructing Explanations | CCC: Cause and Effect | DOK 2*

---

**SR Example (Grade 5, DOK 2, 5-LS2-1 — Ecosystem Matter Flow):**

A diagram shows: Sunlight -> Desert grasses -> Kangaroo rats -> Rattlesnakes -> Red-tailed hawks

Which statement BEST explains the role of desert grasses in this Chihuahuan Desert ecosystem model?

A. Desert grasses receive energy from kangaroo rats through a food chain
B. Desert grasses capture energy from the sun and store it in their cells
C. Desert grasses are decomposers that break down dead organisms in the desert soil
D. Desert grasses get energy from the sandy desert soil through their root system

*Correct Answer: B*
*Alignment: 5-LS2-1 | SEP: Developing and Using Models | CCC: Energy and Matter | DOK 2*

### Constructed Response (CR)

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE — 0–3 points                       |
|                                                          |
|  Written explanation using evidence from the stimulus    |
|  Stimulus always provided (data, diagram, scenario)      |
|  Must demonstrate three-dimensional reasoning            |
|  Human scored                                            |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**CR Example (Grade 8, DOK 3, MS-ESS3-3 — Human Impact):**

*Stimulus: A data table showing dissolved oxygen, salinity, fish species count, and invasive plant coverage at three locations along the Rio Grande: upstream in northern New Mexico, near Albuquerque, and near Las Cruces in southern New Mexico. Near Las Cruces, dissolved oxygen is lowest, salinity is highest, and invasive salt cedar coverage is greatest.*

*"Using data from the table, construct an explanation for the relationship between invasive salt cedar coverage and the Rio Grande's water quality and biodiversity at different locations. Include specific evidence from the data and explain the cause-and-effect relationships involved."*

---

**CR Example (Grade 11, DOK 3, HS-ESS2-2 — Earth Systems Feedbacks):**

*Stimulus: Graph showing gypsum dune migration rates at White Sands National Park from 1950–2020, with data on average wind speed, precipitation, and vegetation coverage alongside dune movement rates.*

*"Using evidence from the graph, analyze how changes in precipitation and vegetation have affected gypsum dune migration at White Sands. Explain how reduced vegetation could create feedback effects on other Earth systems, including wind erosion patterns and groundwater recharge in the Tularosa Basin."*

## 7. Three-Dimensional Design

Every NMSA Science item must reflect all three NGSS dimensions simultaneously.

### Three-Dimensions Alignment Guide

| Dimension | What It Is | Example in NMSA Items |
|---|---|---|
| **DCI** (What students know) | Disciplinary science content | Carlsbad Caverns geology; Rio Grande watershed ecology; White Sands gypsum dune formation; chemical reactions; energy transfer |
| **SEP** (What students do) | How scientists work | Analyze water quality data; construct explanations from evidence; use models to predict ecosystem changes |
| **CCC** (Lens of thinking) | Cross-domain thinking tools | Cause and effect; patterns; energy and matter; structure and function; systems and system models |

### Crosscutting Concepts by Grade Band

| CCC | Grade 5 Emphasis | Grade 8 Emphasis | Grade 11 Emphasis |
|---|---|---|---|
| Patterns | Seasonal cycles in desert ecosystems; rock layer patterns | Weather patterns; Rio Grande flow data trends | Periodic table patterns; evolutionary change |
| Cause and Effect | Food chain disruption; erosion in desert landscapes | Cave formation chemistry; invasive species impacts on Rio Grande | Climate feedbacks; homeostasis disruption |
| Energy and Matter | Food webs in desert ecosystems; water cycle | Chemical reactions in cave formation; thermal energy in geothermal areas | Metabolic pathways; Earth energy systems |
| Structure and Function | Desert plant adaptations (cacti, yucca) | Mineral crystal structures; bat wing adaptations | DNA and protein structure; organ systems |
| Systems and System Models | Desert ecosystems; water cycle in arid regions | Rio Grande watershed; Carlsbad Caverns as a system | Climate systems; biological feedback loops |

## 8. Scoring Rubrics

### Constructed Response (CR) Rubric — 0–3 Points

| Score | Criteria |
|---|---|
| 3 | Response accurately addresses the science concept; demonstrates clear three-dimensional understanding (DCI + SEP or CCC evident); includes specific, relevant evidence from the stimulus; explanation is complete, accurate, and logically connected |
| 2 | Response addresses the science concept with partial accuracy; shows understanding of the DCI but only partially integrates a practice or crosscutting concept; evidence present but may be incomplete |
| 1 | Response minimally addresses the science concept; shows limited understanding; little or no evidence from stimulus; explanation vague or contains science inaccuracies |
| 0 | Response does not address the concept; blank; off-topic; restates stimulus without explanation |

### CR Scoring Notes

- **Evidence from the stimulus is required.** Responses relying solely on prior knowledge without referencing the provided data earn a maximum of 1 point.
- **Three-dimensional reasoning earns full credit.** A Score 3 integrates content knowledge (DCI) with at least one SEP or CCC.
- **Misconceptions reduce the score.** A significant scientific misconception drops the response by one score point.

## 10. Contextualization — New Mexico Science

When generating NMSA Science items, prioritize authentic New Mexico natural settings:

### New Mexico Science Context Guide

| Setting / Phenomenon | Grade | Science Domain | PE Alignment |
|---|---|---|---|
| Carlsbad Caverns geology (stalactite/stalagmite formation, limestone dissolution) | 5, 8, 11 | Earth/Physical Science | 5-ESS2, MS-ESS2, MS-PS1 |
| Rio Grande ecosystem (water quality, fish populations, invasive species) | 5, 8, 11 | Life/Earth Science | 5-LS2, MS-LS2, MS-ESS3 |
| White Sands gypsum dune formation and migration | 5, 8 | Earth Science | 5-ESS2, MS-ESS2 |
| Chihuahuan Desert ecology and adaptations | 5, 8 | Life Science | 5-LS2, MS-LS2 |
| Carlsbad Caverns bat colony ecology (Brazilian free-tailed bats) | 5, 8 | Life Science | 5-LS2, MS-LS2 |
| New Mexico volcanic geology (Valles Caldera, Capulin Volcano) | 8, 11 | Earth Science | MS-ESS2, HS-ESS2 |
| Rio Grande water rights and drought impacts | 8, 11 | Earth/Life Science | MS-ESS3, HS-ESS3 |
| New Mexico solar energy and radiation | 8, 11 | Physical Science | MS-PS3, HS-PS3 |
| Bosque del Apache wildlife refuge ecology | 5, 8 | Life Science | 5-LS2, MS-LS2 |
| Jemez Mountains geothermal features | 8, 11 | Physical/Earth Science | MS-PS3, HS-PS3 |
| New Mexico wildfire ecology and forest recovery | 5, 8, 11 | Life/Earth Science | 5-LS2, MS-LS2, HS-LS2 |
| Very Large Array and electromagnetic radiation | 11 | Physical Science | HS-PS4 |

### Suggested Anchoring Phenomena by Grade

**Grade 5 Phenomena:**
- "Every evening from May through October, hundreds of thousands of Brazilian free-tailed bats spiral out of Carlsbad Caverns at sunset. How do these bats get the energy they need to fly for hours each night, and where does that energy originally come from?"
- "White Sands National Park has brilliant white sand dunes, but the sand is not made of quartz like most beaches. Scientists found that the sand is made of gypsum crystals. What processes could create sand from a mineral that usually dissolves in water?"
- "Students visiting the Rio Grande bosque noticed that the cottonwood trees near the river were green and tall, while plants just 100 yards away in the desert were small and dry. What explains this dramatic difference?"

**Grade 8 Phenomena:**
- "Carlsbad Caverns contains chambers as large as six football fields, carved entirely from solid limestone. Scientists measured that the cave is still slowly changing. What chemical and physical processes formed these enormous chambers, and are they still happening today?"
- "Water quality data from the Rio Grande shows that dissolved mineral concentrations and salinity increase dramatically as the river flows south from Taos to Las Cruces. What mechanisms cause this change, and how do they affect the river's ecosystems?"
- "The Valles Caldera in northern New Mexico is a 13-mile-wide depression formed by a massive volcanic eruption 1.25 million years ago. What geoscience processes created this landform, and how has it changed since the eruption?"

**Grade 11 Phenomena:**
- "White Sands gypsum dunes migrate northeast at rates that have increased over the past 50 years as drought has reduced vegetation anchoring the dunes. Analyze how changes in vegetation, wind, and precipitation create feedback effects across the Tularosa Basin's Earth systems."
- "The Rio Grande silvery minnow, once one of the most abundant fish in the river, is now endangered. Population data shows a correlation between declining river flows and minnow populations. Construct an explanation for how multiple environmental factors interact to threaten this species' survival."

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] Grade verified as 5, 8, or 11 ONLY
- [ ] PE code is a valid NGSS Performance Expectation
- [ ] Item is three-dimensional: DCI + SEP + CCC all identified
- [ ] Anchoring phenomenon is authentic and New Mexico-relevant where possible
- [ ] Stimulus (data table/graph/diagram) has clear labels, units, and realistic data
- [ ] CR prompt directs students to use evidence from the stimulus
- [ ] All distractors represent real misconceptions (not obviously wrong)
- [ ] MS items specify how many answers to select (TWO/THREE)
- [ ] Score 3 anchor response written before finalizing CR item
- [ ] Science content is accurate and reflects current scientific understanding
- [ ] Vocabulary is grade-appropriate

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Writing items for Grades 3, 4, 6, or 7 | NMSA Science only at Grades 5, 8, 11 | Restrict to tested grades |
| DCI-only items (no SEP or CCC) | NMSA requires three-dimensional items | Always embed a practice and crosscutting concept |
| CR prompts without evidence directive | Students may respond without citing data | Include "Use evidence from the [data/graph/diagram]" |
| Generic science phenomena not anchored to New Mexico | NMSA benefits from New Mexico contexts | Use Carlsbad Caverns, Rio Grande, White Sands, Chihuahuan Desert contexts |
| MS items with only 2 options in 4 total | Too easy to guess | Use 5–6 options with exactly 2–3 correct |

## 12. Prompt Patterns

### Pattern 1: Data-to-Conclusion (SR, DOK 2)
> "The [graph / table / diagram] below shows [New Mexico science scenario]. Based on the data, which [conclusion / explanation / pattern] is BEST supported?"

### Pattern 2: Phenomenon Explanation (CR, DOK 3)
> "Scientists observed [New Mexico-anchored phenomenon]. Using evidence from the [data / model / diagram], construct an explanation for [specific science focus]. Explain the [cause-and-effect / energy flow / pattern] relationship."

### Pattern 3: Model Evaluation (SR or MS, DOK 2–3)
> "A student made a model showing [New Mexico science concept]. Which statement BEST describes what the model shows about [DCI focus]?"

### Pattern 4: Investigation Design (CR, DOK 3)
> "A scientist in New Mexico wants to investigate whether [variable] affects [outcome] in [Carlsbad Caverns / Rio Grande / Chihuahuan Desert]. Describe a procedure the scientist could follow. Include what would be measured and how the scientist would know if the variable made a difference."

### Pattern 5: Evidence-Based Argument (CR, DOK 3)
> "Two students disagree about [New Mexico science claim]. Student A says [misconception]. Student B says [accurate claim]. Using evidence from the [data / diagram], explain which student is correct and why."

### Pattern 6: Human Impact and Solutions (MS or CR, DOK 2–3)
> "Human activities have [impacted New Mexico's environment]. Select the TWO strategies that BEST [monitor / reduce / address] this impact."
