## 2. STANDARDS FRAMEWORK

### NY P-12 Science Learning Standards (NGSS-Aligned)

New York adopted its **P-12 Science Learning Standards** in 2016, built on the **Next Generation Science Standards (NGSS)** framework. These standards use the same three-dimensional design as NGSS: **Science and Engineering Practices (SEPs)**, **Disciplinary Core Ideas (DCIs)**, and **Crosscutting Concepts (CCCs)**.

### Grade 4 Key Performance Expectations

| Domain               | PE Code      | Performance Expectation                                                                |
|----------------------|--------------|----------------------------------------------------------------------------------------|
| Physical Science     | 4-PS3-1      | Use evidence to construct an explanation relating the speed of an object to the energy |
| Physical Science     | 4-PS3-2      | Make observations to provide evidence that energy can be transferred                   |
| Physical Science     | 4-PS3-4      | Apply scientific ideas to design, test, and refine a device that converts energy       |
| Life Science         | 4-LS1-1      | Construct an argument that plants and animals have internal/external structures for survival |
| Life Science         | 4-LS1-2      | Use a model to describe how animals receive information through sense organs           |
| Earth Science        | 4-ESS1-1     | Identify evidence from patterns in rock formations about Earth's past                  |
| Earth Science        | 4-ESS2-1     | Make observations/measurements to provide evidence of effects of weathering/erosion    |
| Earth Science        | 4-ESS2-2     | Analyze and interpret data from maps to describe patterns of Earth's features          |
| Earth Science        | 4-ESS3-2     | Generate and compare multiple solutions to reduce impacts of natural Earth processes   |

### Grade 8 Key Performance Expectations

| Domain               | PE Code      | Performance Expectation                                                                |
|----------------------|--------------|----------------------------------------------------------------------------------------|
| Physical Science     | MS-PS1-1     | Develop models to describe the atomic composition of simple molecules and extended structures |
| Physical Science     | MS-PS1-2     | Analyze data on the properties of substances before/after interaction to determine if chemical reaction occurred |
| Physical Science     | MS-PS2-1     | Apply Newton's 3rd Law to design a solution to a problem involving motion             |
| Physical Science     | MS-PS3-1     | Construct/interpret graphical displays of data to describe energy relationships        |
| Life Science         | MS-LS1-1     | Conduct investigations to provide evidence that living things are made of cells        |
| Life Science         | MS-LS2-1     | Analyze and interpret data to provide evidence for effects of resource availability    |
| Life Science         | MS-LS4-2     | Apply scientific ideas to construct explanation for fossil record                      |
| Earth Science        | MS-ESS2-2    | Construct an explanation based on evidence for how geoscience processes have changed   |
| Earth Science        | MS-ESS3-3    | Apply scientific principles to design method for monitoring/minimizing human impact    |

## 3. TEST STRUCTURE

The NYS Science Test has **two distinct components**: the **Written Test** and the **Lab Practical**. This two-component design is a hallmark of the NY Science assessment and distinguishes it from most other state science tests.

```
+------------------------------------------------------------------+
|              NYS SCIENCE TEST STRUCTURE (Grades 4 & 8)           |
+------------------------------+-----------------------------------+
|    WRITTEN TEST              |    LAB PRACTICAL                  |
|    ~45–60 minutes            |    ~45 minutes                    |
|    Paper-based               |    Hands-on station format        |
|                              |                                   |
|  Part 1: MCQ (30–40 items)   |  3–4 lab stations                 |
|  Part 2: Constructed Response|  Hands-on investigation tasks     |
|          (CR, 3–5 items)     |  Data collection + recording      |
|                              |  Short written response per station|
+------------------------------+-----------------------------------+
```

### Written Test Structure

| Component              | Grades 4 & 8 Item Count   | Point Value           |
|------------------------|---------------------------|-----------------------|
| Multiple Choice (Part 1)| 30–40 items              | 1 pt each             |
| Constructed Response (Part 2)| 3–5 items           | 0–3 pts each          |
| **Total Written Points**| approximately 45–55 pts  |                       |

### Lab Practical Structure

| Station Type                  | Description                                            |
|-------------------------------|--------------------------------------------------------|
| Observation Station           | Examine specimen/material; record observations         |
| Measurement Station           | Measure physical properties; record data               |
| Data Analysis Station         | Interpret a provided graph, table, or diagram          |
| Procedure/Design Station      | Describe steps to test a hypothesis                    |

> **Lab Practical Note:** The Lab Practical component is **unique to New York** among state science assessments. Students rotate through stations and respond to prompts at each. This tests the Science and Engineering Practices (SEPs) in an authentic, hands-on context.

## 5. ITEM TYPES

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Scenario-based or direct concept questions              |
|  May include diagrams, data tables, or illustrations     |
|  Machine scored                                          |
|  Written Test Part 1                                     |
+----------------------------------------------------------+
```

**MC Example (Grade 4, DOK 2, 4-ESS2-1 — Erosion):**

Students along the Hudson River observed that a cliff face had changed over several years. Photographs showed that large rocks had broken into smaller rocks and moved downhill. Which process BEST explains this change?

- A. Evaporation
- B. Condensation
- C. Weathering and erosion
- D. Photosynthesis

*Correct Answer: C*

---

**MC Example (Grade 8, DOK 2, MS-PS1-2 — Chemical Reactions):**

A student combines two clear liquids in a beaker. After mixing, a yellow solid forms at the bottom of the beaker and the temperature of the mixture increases. Which observation provides the BEST evidence that a chemical reaction has occurred?

- A. The temperature of the mixture increased
- B. The liquids were both clear before mixing
- C. A new yellow solid was produced
- D. The student stirred the mixture during the experiment

*Correct Answer: C*

---

### Constructed Response (CR)

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE — 0–3 points                       |
|                                                          |
|  Written explanation with science evidence               |
|  May require data analysis, explanation of phenomenon,   |
|  or design of an investigation                           |
|  Human scored using CR rubric                            |
|  Written Test Part 2                                     |
+----------------------------------------------------------+
```

**CR Example (Grade 8, DOK 3, MS-ESS3-3):**

*"Human activities along the Hudson River have contributed to increased levels of pollution in the water. Using your knowledge of science, describe ONE human activity that negatively impacts the Hudson River ecosystem AND explain how scientists could design a method to monitor and reduce this impact. Use evidence to support your answer."*

---

### Lab Practical Items

```
+----------------------------------------------------------+
|  LAB PRACTICAL — variable points per station             |
|                                                          |
|  Hands-on data collection and recording                  |
|  Short written responses at each station                 |
|  Tests SEPs in authentic contexts                        |
|  Typically 3–4 stations, 10–15 minutes each             |
+----------------------------------------------------------+
```

**Lab Practical Station Example (Grade 4, Measurement Station):**

*"At this station, you have three rock samples labeled A, B, and C. Use the balance scale and ruler provided to measure and record the mass (in grams) and approximate length (in centimeters) of each sample. Then answer: Which rock sample has the greatest mass? How does its size compare to its mass?"*

## 7. THREE-DIMENSIONAL DESIGN

The NY P-12 Science Learning Standards require that items reflect all three NGSS dimensions. Below is a design guide for constructing three-dimensional items.

### Three Dimensions Alignment Guide

| Dimension                      | Example Application in Items                                           |
|-------------------------------|-------------------------------------------------------------------------|
| **DCI** (What students know)   | Hudson River food webs; energy transfer; rock cycle processes          |
| **SEP** (What students do)     | Analyze data; construct explanations; plan investigations; use models  |
| **CCC** (Lens of thinking)     | Cause and effect; patterns; energy and matter; structure and function  |

### Sample Three-Dimensional Item Design (Grade 8)

```
+------------------------------------------------------------------+
|  3D ITEM STRUCTURE                                               |
|                                                                  |
|  PHENOMENON: Dead zones appearing in Long Island Sound           |
|  (Anchoring phenomenon grounds the item in real NY context)      |
|                                                                  |
|  DCI: MS-LS2 — Ecosystems / MS-ESS3 — Human impacts             |
|  SEP: Construct explanations using evidence from data            |
|  CCC: Cause and Effect                                           |
|                                                                  |
|  STIMULUS: Data table showing dissolved oxygen levels and        |
|  fish populations in Long Island Sound over 10 years             |
|                                                                  |
|  PROMPT: "Using the data provided, construct an explanation       |
|  for the decline in fish populations in Long Island Sound.        |
|  Include specific evidence from the data table in your answer."  |
+------------------------------------------------------------------+
```

## 8. SCORING RUBRICS

### Constructed Response (CR) Rubric — 0–3 Points

| Score | Criteria                                                                                                                                                                                             |
|-------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 3     | Response accurately addresses the science concept; demonstrates clear understanding of the phenomenon or investigation; includes specific, relevant scientific evidence or data; explanation is complete and logically connected |
| 2     | Response partially addresses the science concept; demonstrates adequate understanding; includes some scientific evidence but it may be general or incompletely connected to the explanation; response is mostly correct |
| 1     | Response minimally addresses the science concept; demonstrates limited understanding; includes little or no scientific evidence; explanation may be vague, partially correct, or contain scientific inaccuracies |
| 0     | Response does not address the science concept; is blank, off-topic, or demonstrates no scientific understanding; restates the question without any explanation                                        |

### Lab Practical Response Scoring (per station)

| Score | Criteria                                                                                         |
|-------|--------------------------------------------------------------------------------------------------|
| 2     | Data accurately recorded; response demonstrates correct use of science practices; interpretation is accurate |
| 1     | Data partially recorded or has minor errors; response shows partial understanding of science practices |
| 0     | No data recorded or completely inaccurate; no meaningful response                               |

### Suggested Anchoring Phenomena by Grade

**Grade 4 Phenomena:**
- "Every fall, salmon return to the same streams in the Adirondacks to spawn — why do they return to the exact same location?"
- "After a rainstorm, students in Poughkeepsie noticed the Hudson River turned brown — what caused this?"

- "The temperature of Long Island Sound has increased 2°C since 1980 — what might be the effects on the ecosystem?"

## 11. QUALITY CHECKLIST AND COMMON PITFALLS

### Quality Checklist

- [ ] Grade verified as 4 or 8 ONLY (not other NY grades)
- [ ] PE code is from NY P-12 Science Learning Standards
- [ ] Item is three-dimensional (DCI + SEP + CCC identified)
- [ ] Phenomenon is authentic and grade-appropriate
- [ ] CR prompt includes evidence directive ("Use evidence to support")
- [ ] Lab Practical items specify materials and measurable outcomes
- [ ] Stimulus (data table/graph) is legible and clearly labeled
- [ ] All CR score anchors written before item is finalized
- [ ] Item avoids vocabulary beyond grade-band expectations
- [ ] Science content is accurate and current

### Common Pitfalls

| Pitfall                                    | Problem                                          | Fix                                                 |
|--------------------------------------------|--------------------------------------------------|-----------------------------------------------------|
| Writing items for Grades 3, 5, 6, 7        | NY Science tests only Gr4 and Gr8                | Restrict to Grades 4 and 8                          |
| Items with only one dimension (DCI only)   | NY requires three-dimensional assessment         | Embed SEP and CCC into item design                  |
| Lab Practical item without materials list  | Students cannot perform task without setup info  | Specify materials at each station                   |
| Generic natural phenomena, not NY-anchored | NY items use NY-specific contexts                | Use Hudson River, Adirondacks, Long Island Sound     |
| Using NGSS PE codes without NY prefix      | NY adopted NGSS but standards are NY-specific    | Reference NY P-12 SLS, not raw NGSS codes            |
| CR prompts without evidence requirement    | Students may respond without citing data         | Always include "Use evidence to support your answer" |

## 12. PROMPT PATTERNS

The following five patterns reflect the most common NYS Science item archetypes.

### Pattern 1: Observation to Explanation (CR, DOK 2)
> "Scientists observed [NY phenomenon]. Using your knowledge of [science concept], explain what is causing [observation]. Use evidence to support your answer."

### Pattern 2: Data Analysis (MC or CR, DOK 2)
> "The table/graph below shows [NY science data]. Based on the data, which conclusion is BEST supported? / What pattern do the data show? Explain your reasoning."

### Pattern 3: Cause and Effect (MC, DOK 2)
> "A student noticed that [NY-based observable change] occurred after [event]. Which explanation BEST describes why this happened?"

### Pattern 4: Investigation Design (CR or Lab Practical, DOK 3)
> "A scientist wants to test whether [variable] affects [outcome] in the [NY ecosystem]. Describe how the scientist could design an investigation to answer this question. Include what the scientist would measure and how they would know if the variable made a difference."

### Pattern 5: Human Impact and Solutions (CR, DOK 3)
> "Human activities have [impacted NY environment in specific way]. Describe TWO effects this has had on [ecosystem/organism]. Then explain ONE method scientists or engineers could use to reduce this impact."
