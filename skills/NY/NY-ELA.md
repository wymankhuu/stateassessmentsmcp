## 2. STANDARDS FRAMEWORK

### NY Next Generation Learning Standards (NGLS)

New York adopted its own modified version of CCSS in 2017, branded as the **Next Generation Learning Standards**. While structurally similar to CCSS, the NGLS includes additions, reordering, and clarifications specific to New York.

**Key Reading Literature Standards (RL)**

| Standard | Description                                                                                      |
|----------|--------------------------------------------------------------------------------------------------|
| RL 1     | Cite textual evidence to support analysis of what the text says explicitly and inferentially     |
| RL 2     | Determine theme or central idea; analyze development; provide summary                            |
| RL 3     | Analyze characters, setting, plot; how interact/contribute to meaning                            |
| RL 4     | Determine meaning of words and phrases, including figurative language                            |
| RL 5     | Analyze structure of text (chapters, scenes, stanzas, compare)                                   |
| RL 6     | Analyze point of view; how author develops narrator/character                                    |
| RL 9     | Compare/contrast two or more texts by same author or same theme                                  |

**Key Reading Informational Text Standards (RI)**

| Standard | Description                                                                                      |
|----------|--------------------------------------------------------------------------------------------------|
| RI 1     | Cite textual evidence; distinguish what text says from inferences                                |
| RI 2     | Determine central idea; analyze development; provide objective summary                           |
| RI 3     | Analyze how individuals, events, ideas introduced, illustrated, elaborated                       |
| RI 4     | Determine meaning of technical, figurative, connotative words                                    |
| RI 6     | Determine author's point of view/purpose; analyze rhetoric                                       |
| RI 8     | Evaluate evidence, reasoning, sufficiency in an argument                                         |
| RI 9     | Analyze how two or more authors treat similar topics (compare/contrast)                          |

**Key Writing Standards (W)**

| Standard | Description                                                                                       |
|----------|---------------------------------------------------------------------------------------------------|
| W 1      | Write arguments supported by evidence from literary or informational sources                      |
| W 2      | Write informative/explanatory texts; examine ideas clearly                                        |
| W 9      | Draw evidence from literary or informational texts to support analysis                            |

> **NGLS vs. CCSS Note:** NY NGLS retains all CCSS ELA standards but adds clarity notes and some NY-specific language arts standards (e.g., stronger emphasis on oral language in earlier grades). When coding items, use **NY.NGLS.RL** or **NY.NGLS.RI** notation, NOT the generic CCSS coding.

## 3. TEST STRUCTURE

The NYS ELA test spans **3 sessions** administered over **2–3 days**.

```
+---------------------------------------------------------------+
|               NYS ELA TEST STRUCTURE (Grades 3–8)            |
+------------------+------------------+------------------------+
|   SESSION 1      |   SESSION 2      |   SESSION 3            |
|   ~45 minutes    |   45–60 minutes  |   45–60 minutes        |
|                  |                  |                        |
| LISTENING        | LITERARY READING | INFORMATIONAL READING  |
| - Audio passage  | - Print passage  | - Print passage(s)     |
|   read aloud     |   (literature)   |   (nonfiction/info)    |
| - MCQ (4–6 items)| - MCQ (6–8 items)| - MCQ (6–8 items)      |
| - SR (1–2 items) | - SR (1–2 items) | - ER (1 item)          |
+------------------+------------------+------------------------+
```

### Session Details by Grade Band

| Session | Grade 3–4 Items | Grade 5–6 Items | Grade 7–8 Items |
|---------|----------------|----------------|----------------|
| Session 1 (Listening) | 4 MCQ + 1 SR | 5 MCQ + 1–2 SR | 6 MCQ + 2 SR |
| Session 2 (Literary)  | 6 MCQ + 1 SR | 7 MCQ + 1–2 SR | 8 MCQ + 2 SR |
| Session 3 (Info + ER) | 6 MCQ + 1 ER | 7 MCQ + 1 ER   | 8 MCQ + 1 ER |

> **Session 1 Listening:** The audio passage is played (or read aloud by the proctor) twice. Students may take notes. This component is unique to NY among major state assessments.

## 5. ITEM TYPES

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Single correct answer                                   |
|  Machine scored                                          |
|  Typically DOK 1–2                                       |
|  Tests reading comprehension, vocabulary, craft          |
+----------------------------------------------------------+
```

**MC Example (Grade 6, DOK 2, RL.4 — Figurative Language):**

*Passage excerpt: "The city was a river of light after the storm, flowing from corner to corner without stopping."*

Which phrase from the passage uses figurative language to describe the city?

- A. "after the storm"
- B. "from corner to corner"
- C. "a river of light"
- D. "without stopping"

*Correct Answer: C*

---

### Short Response (SR)

```
+----------------------------------------------------------+
|  SHORT RESPONSE — 0–2 points                             |
|                                                          |
|  Written response (2–4 sentences typical)                |
|  MUST cite evidence from the text                        |
|  Human scored using SR rubric                            |
|  DOK 2–3                                                 |
|  Tests reading comprehension + evidence use              |
+----------------------------------------------------------+
```

**SR Example (Grade 5, DOK 2, RI.2):**

*"Explain the central idea of the passage. Use evidence from the text to support your answer."*

---

### Extended Response (ER)

```
+----------------------------------------------------------+
|  EXTENDED RESPONSE — 0–4 points                          |
|                                                          |
|  Multi-paragraph essay (typically 3–5 paragraphs)        |
|  Draws from MULTIPLE texts (reading + listening)         |
|  Must include textual evidence with elaboration          |
|  Human scored using ER rubric                            |
|  DOK 3                                                   |
|  Tests synthesis + argumentation + writing craft         |
+----------------------------------------------------------+
```

**ER Example (Grade 7, DOK 3, W.1 + RI.9):**

*"Both the article 'Voices of the Harlem Renaissance' and the audio passage about Langston Hughes describe how art can shape a community. Using evidence from BOTH texts, write an essay explaining how artistic expression influences the identity of a community."*

## 6. DEPTH OF KNOWLEDGE (DOK)

| DOK | Label                  | ELA Application Examples                                         |
|-----|------------------------|------------------------------------------------------------------|
| 1   | Recall & Reproduction  | Identify a word's meaning from context; locate a detail in text  |
| 2   | Skills & Concepts      | Explain how a character's actions affect plot; analyze text structure |
| 3   | Strategic Thinking     | Compare two authors' perspectives; synthesize evidence across texts |
| 4   | Extended Thinking       | (Rare on NYS ELA) Long-term research or project-based tasks      |

> The **ER item is always DOK 3**. Most MCQ are DOK 2. Approximately 15% of MCQ are DOK 1 (recall or vocabulary lookup).

## 8. SCORING RUBRICS

### Short Response (SR) Rubric — Reading Comprehension Trait

| Score | Criteria                                                                                                             |
|-------|----------------------------------------------------------------------------------------------------------------------|
| 2     | The response accurately addresses the prompt; demonstrates understanding of the text; includes specific, relevant textual evidence; evidence is clearly connected to the response |
| 1     | The response partially addresses the prompt; demonstrates partial understanding; includes some evidence, but it may be general, loosely connected, or inaccurate              |
| 0     | The response does not address the prompt; demonstrates little or no understanding; includes no evidence or irrelevant content; blank or off-topic responses                    |

> **SR Key Reminder:** A score of 0 is given for responses that are entirely off-task, blank, or restate the question without engagement. Partial credit (1) requires at least an attempt at evidence.

---

### Extended Response (ER) Rubric — Writing from Sources Trait

| Score | Criteria                                                                                                                                                                          |
|-------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 4     | The response clearly addresses the prompt with a well-developed, focused claim or controlling idea. Evidence from multiple texts is specific, accurate, and effectively elaborated. Writing demonstrates strong organization, transitions, and command of language conventions.    |
| 3     | The response addresses the prompt with an adequate claim or idea. Evidence from texts is mostly specific and mostly accurate, with adequate elaboration. Organization is generally clear; minor errors in conventions do not impede meaning.                                      |
| 2     | The response partially addresses the prompt; claim may be unclear or underdeveloped. Evidence is present but may be general, partially inaccurate, or inadequately elaborated. Organization may be inconsistent; some errors in conventions.                                      |
| 1     | The response minimally addresses the prompt; claim is very weak or missing. Little or no textual evidence; response may summarize rather than analyze. Poor organization and significant convention errors that impede meaning.                                                   |
| 0     | The response does not address the prompt; is blank, off-topic, copied directly from the passage, or is incomprehensible.                                                          |

## 11. QUALITY CHECKLIST AND COMMON PITFALLS

### Quality Checklist

- [ ] Passage Lexile falls within grade-band range (see Section 7)
- [ ] All MC options are plausible; no "trick" options or clearly wrong choices
- [ ] SR prompt ends with "Use evidence from the text to support your answer"
- [ ] ER prompt references BOTH source texts explicitly
- [ ] DOK level matches intended cognitive demand
- [ ] Standard code uses NY.NGLS format (not CCSS)
- [ ] Item avoids cultural bias; reviewed for NY-specific fairness
- [ ] Listening passage (Session 1) is written for oral delivery, not silent reading
- [ ] ER rubric anchor responses are written before item is finalized
- [ ] Calculator/tools noted as N/A (ELA)

### Common Pitfalls

| Pitfall                                | Problem                                    | Fix                                              |
|----------------------------------------|--------------------------------------------|--------------------------------------------------|
| Using CCSS standard codes              | NY uses NGLS, not CCSS                     | Use NY.NGLS.RL/RI/W notation                     |
| SR prompt without evidence requirement | Students may respond without citing text   | Always include "Use evidence from the text"      |
| ER with only one source                | ER requires BOTH texts (Sessions 1+2/3)    | Build cross-session ER; reference two sources    |
| Listening passage too complex in syntax| Audio comprehension differs from reading   | Shorter sentences; signpost language; repetition |
| Over-reliance on DOK 1 MC              | NYS expects mostly DOK 2 MC                | Shift MC to inference/analysis tasks             |
| Generic "American" context             | NY test favors NY-specific authenticity    | Anchor passages in real NY places/events         |

## 12. PROMPT PATTERNS

The following five prompt patterns cover the most frequently tested item archetypes on the NYS ELA Grades 3–8 test.

### Pattern 1: Central Idea + Evidence (SR/ER, RI.2)
> "What is the central idea of [passage title]? Use evidence from the text to support your answer."

### Pattern 2: Character Analysis (SR, RL.3)
> "How does [character name]'s [action/decision/reaction] in the passage show [character trait]? Use evidence from the text to support your answer."

### Pattern 3: Author's Purpose / Point of View (MC/SR, RI.6 or RL.6)
> "Why does the author include [detail/section]? What does this reveal about the author's [purpose/perspective]?"

### Pattern 4: Compare Across Texts (ER, RI.9 or RL.9)
> "[Text 1 title] and [Text 2 title] both address [shared theme]. Using evidence from BOTH texts, write an essay explaining how each [author/source] [analyzes/presents/argues about] the theme of [topic]."

### Pattern 5: Vocabulary in Context (MC, RL.4 or RI.4)
> "As used in paragraph [#], what does the word '[word]' most likely mean?"
> - A. [synonym 1]
> - B. [synonym 2]
> - C. [CORRECT: contextually accurate meaning]
> - D. [common denotation that doesn't fit context]
