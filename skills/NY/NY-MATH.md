## 2. STANDARDS FRAMEWORK

## 3. TEST STRUCTURE

The NYS Mathematics test spans **3 sessions** administered over **2 days**.

```
+------------------------------------------------------------------+
|             NYS MATHEMATICS TEST STRUCTURE (Grades 3–8)         |
+-------------------+--------------------+------------------------+
|   SESSION 1       |   SESSION 2        |   SESSION 3            |
|   ~45 minutes     |   45–60 minutes    |   45–60 minutes        |
|   DAY 1           |   DAY 2            |   DAY 2                |
|                   |                   |                        |
| MCQ ONLY          | MCQ + SR           | MCQ + SR + ER          |
| No calculator     | Calculator (Gr6+)  | Calculator (Gr6+)      |
| No reference sheet| Ref sheet (Gr5+)   | Ref sheet (Gr5+)       |
+-------------------+--------------------+------------------------+
```

### Session Item Counts by Grade Band

| Session      | Grades 3–4          | Grades 5–6          | Grades 7–8          |
|--------------|---------------------|---------------------|---------------------|
| Session 1    | 20 MCQ              | 22 MCQ              | 24 MCQ              |
| Session 2    | 5 MCQ + 3 SR        | 5 MCQ + 3 SR        | 5 MCQ + 3 SR        |
| Session 3    | 5 MCQ + 3 SR + 1 ER | 5 MCQ + 3 SR + 1 ER | 5 MCQ + 3 SR + 1 ER |

> Session 1 is entirely multiple choice and designed for pacing and automaticity. Sessions 2 and 3 require students to show work and communicate mathematical reasoning.

## 5. ITEM TYPES

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Single correct answer                                   |
|  Machine scored                                          |
|  Sessions 1, 2, and 3                                    |
|  No calculator in Session 1 (all grades)                 |
+----------------------------------------------------------+
```

**MC Example (Grade 6, DOK 2, 6.RP.1 — Ratios):**

A subway train on the A line carries 312 passengers during morning rush hour and 208 passengers during the afternoon. What is the ratio of morning passengers to afternoon passengers in simplest form?

- A. 312 : 208
- B. 4 : 3
- C. 3 : 2
- D. 2 : 3

*Correct Answer: C (GCF of 312 and 208 is 104; 312/104 = 3, 208/104 = 2)*

---

### Short Response (SR)

```
+----------------------------------------------------------+
|  SHORT RESPONSE — 0–2 points                             |
|                                                          |
|  Student must SHOW WORK in provided space                |
|  Partial credit awarded for correct process/setup        |
|  Human scored using SR rubric                            |
|  DOK 2–3                                                 |
|  Sessions 2 and 3                                        |
+----------------------------------------------------------+
```

**SR Example (Grade 5, DOK 2, 5.NF.4 — Multiply Fractions):**

*"Central Park's rectangular Great Lawn has a length of 3/4 mile and a width of 2/5 mile. What is the area of the Great Lawn? Show your work."*

---

### Extended Response (ER)

```
+----------------------------------------------------------+
|  EXTENDED RESPONSE — 0–3 points                          |
|                                                          |
|  Multi-part problem (Parts A, B, sometimes C)            |
|  Requires show work AND written explanation              |
|  Higher DOK — strategic thinking, justify reasoning      |
|  Human scored using ER rubric                            |
|  Session 3 only (1 per test)                             |
+----------------------------------------------------------+
```

**ER Example (Grade 8, DOK 3, 8.EE.7 + 8.F.2):**

*"The MTA tracks subway ridership over two months. In January, daily ridership followed the equation y = 1,200x + 85,000, where x is the day of the month. In February, daily ridership followed y = 950x + 90,000.*
*Part A: On which day of January did ridership first exceed 100,000? Show your work.*
*Part B: Which month had greater ridership growth per day? Explain how you know using mathematical evidence.*
*Part C: Interpret the meaning of the y-intercepts for each equation in context."*

## 6. DEPTH OF KNOWLEDGE (DOK)

| DOK | Label                  | Math Application Examples                                             |
|-----|------------------------|-----------------------------------------------------------------------|
| 1   | Recall & Reproduction  | Compute 3/4 × 8; Identify a property; Convert units                  |
| 2   | Skills & Concepts      | Solve a two-step word problem; Explain why a solution works           |
| 3   | Strategic Thinking     | Design a plan; Justify; Analyze error; Compare solution methods       |
| 4   | Extended Thinking       | (Not typically on NYS Math test) Multi-day investigations             |

> **ER items are always DOK 3.** SR items target DOK 2 primarily. All Session 1 MCQ are DOK 1–2.

## 7. MATHEMATICAL PRACTICES

The NY NGMS incorporates the **CCSS Standards for Mathematical Practice (SMP)** as the process standards. These practices should be embedded across all item types.

| SMP | Practice                              | Assessment Application                                         |
|-----|---------------------------------------|----------------------------------------------------------------|
| 1   | Make sense of problems; persevere     | Multi-step ER items; complex word problems                     |
| 2   | Reason abstractly and quantitatively  | Contextual problems requiring decontextualization              |
| 3   | Construct viable arguments; critique  | SR/ER items requiring explanation or error analysis            |
| 4   | Model with mathematics                | Real-world contexts (NYC transportation, population, etc.)     |
| 5   | Use appropriate tools strategically   | Calculator use decisions; reference sheet use                  |
| 6   | Attend to precision                   | Labeling units; exact vs. approximate answers                  |
| 7   | Look for and make use of structure    | Pattern recognition; algebraic reasoning items                 |
| 8   | Look for and express regularity       | Generalization items; repeated reasoning                       |

## 8. SCORING RUBRICS

### Short Response (SR) Rubric

| Score | Criteria                                                                                                                             |
|-------|--------------------------------------------------------------------------------------------------------------------------------------|
| 2     | Response shows correct mathematical work AND arrives at the correct answer. Units and labels are included where required. Work is clear and organized. |
| 1     | Response shows a correct mathematical approach or setup but contains a computational error OR shows correct answer without sufficient work shown. Partial understanding is demonstrated. |
| 0     | Response shows no correct mathematical approach; answer is incorrect with no supporting work; response is blank or completely off-task. |

---

### Extended Response (ER) Rubric

| Score | Criteria                                                                                                                                                                                       |
|-------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 3     | All parts of the problem are correctly addressed. Mathematical work is complete, clearly shown, and leads to correct answers. Written explanations (if required) are mathematically sound and use accurate vocabulary. Units/labels are correct. |
| 2     | Most parts of the problem are correctly addressed. Mathematical work is mostly correct with minor computational errors. Written explanations demonstrate adequate understanding. One part may be incomplete or contain an error. |
| 1     | Some correct mathematical work is shown; student demonstrates partial understanding of the concepts involved. Multiple errors are present, or only one of multiple parts is correct. Written explanations are weak or missing. |
| 0     | No correct mathematical work is shown; response demonstrates no understanding of the mathematical task; response is blank or completely off-task.                                              |

## 11. QUALITY CHECKLIST

- [ ] Standard code uses NY-Next Gen. format (not raw CCSS)
- [ ] Calculator policy matches session (no calculator in Session 1; four-function Gr6+ in Sessions 2–3)
- [ ] Reference sheet availability noted for Gr5+ items with formulas
- [ ] SR and ER items include "Show your work" directive
- [ ] ER items have at least two parts (A and B minimum)
- [ ] Real-world context is authentic and grade-appropriate
- [ ] All numerical values produce clean, non-ambiguous computations
- [ ] Distractors for MCQ reflect specific, identifiable student error types
- [ ] DOK level is verified against item cognitive demand
- [ ] Formulas used are consistent with NY reference sheet (if applicable)
- [ ] Units are clearly specified; labels required where appropriate
- [ ] No grade-inappropriate content (e.g., no algebra in Gr3)

### Common Pitfalls

| Pitfall                               | Problem                                     | Fix                                              |
|---------------------------------------|---------------------------------------------|--------------------------------------------------|
| Calculator allowed in Session 1       | Session 1 is no-calculator for all grades   | Remove calculator-dependent numbers in Session 1 |
| ER with only one part                 | NY ER requires multi-part structure         | Ensure Part A + Part B minimum                   |
| Answers requiring rounding in SR      | Creates ambiguity for partial credit        | Design problems with clean answers               |
| Using CCSS codes without NY prefix    | NY uses NGMS, not raw CCSS                  | Always use NY-Next Gen. prefix                   |
| Generic "store" context               | NY test values authentic NY settings        | Anchor in NYC boroughs, upstate NY, etc.         |
| ER explanation prompt missing         | DOK 3 requires justification component      | Add "Explain how you know" to Part B             |

## 12. PROMPT PATTERNS

The following five prompt patterns reflect the most common NYS Mathematics item structures.

### Pattern 1: Contextual Computation (MC, DOK 2)
> "[NY context]. [Student] needs to find [quantity]. What is [quantity]?"
> (Options: correct answer + three error-type distractors)

### Pattern 2: Show Work — One Step Up (SR, DOK 2)
> "A [NY setting] has [given information]. [Question requiring multi-step math]. Show your work."

### Pattern 3: Multi-Part ER with Explanation (ER, DOK 3)
> "[NY data scenario with table or graph].
> Part A: [Computational or procedural task]. Show your work.
> Part B: [Reasoning or justification task]. Use mathematical evidence to support your answer."

### Pattern 4: Error Analysis (SR or MC, DOK 3)
> "[Student name] solved the following problem and got [incorrect answer]. [Student's work shown]. Explain the error [student] made and find the correct answer."

### Pattern 5: Comparison and Generalization (ER, DOK 3)
> "Two [NY contexts] are described. [Data for each]. Which [option] is [better/greater/more efficient]? Use mathematical evidence to justify your answer."
