## 3. TEST STRUCTURE

Forward Exam Mathematics is administered in **2 sessions** over one or two days.

```
+-------------------------------------------------------------------+
|       FORWARD EXAM MATH STRUCTURE (Grades 3–8, 10)                |
+---------------------------------+---------------------------------+
|   SESSION 1                     |   SESSION 2                     |
|   ~60–75 minutes                |   ~60–75 minutes                |
|                                 |                                 |
|  MULTIPLE CHOICE                |  MULTIPLE CHOICE                |
|  TECHNOLOGY-ENHANCED ITEMS      |  TECHNOLOGY-ENHANCED ITEMS      |
|  NO calculator (all grades)     |  CONSTRUCTED RESPONSE           |
|                                 |  Calculator allowed (Gr 6–8,10) |
+---------------------------------+---------------------------------+
```

### Session Item Counts by Grade Band

| Session       | Grades 3–5                       | Grades 6–8                       | Grade 10                         |
|---------------|----------------------------------|----------------------------------|----------------------------------|
| Session 1     | 18–24 MC/TEI items (no calc)     | 18–24 MC/TEI items (no calc)     | 18–24 MC/TEI items (no calc)     |
| Session 2     | 14–20 MC/TEI + 2–3 CR items     | 14–20 MC/TEI + 2–3 CR (calc)    | 14–20 MC/TEI + 2–3 CR (calc)    |

> **Calculator Policy:** No calculators for any portion of Grades 3–5. For Grades 6–8 and 10, a calculator is available during Session 2 only.

## 5. ITEM TYPES

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Single correct answer                                   |
|  Machine scored                                          |
|  DOK 1–2                                                 |
|  Both sessions                                           |
+----------------------------------------------------------+
```

**MC Example (Grade 6, DOK 2, 6.RP — Ratios):**

A Wisconsin dairy farm produces 5 gallons of milk for every 2 cows milked. If the farm milks 30 cows in one day, how many gallons of milk are produced?

- A. 12
- B. 60
- C. 75
- D. 150

*Correct Answer: C (30 / 2 = 15 groups; 15 x 5 = 75)*

---

### Technology-Enhanced Item (TEI)

```
+----------------------------------------------------------+
|  TECHNOLOGY-ENHANCED ITEM — 1–2 points                   |
|                                                          |
|  Drag-and-drop, multi-select, drop-down menus,           |
|  equation entry, graphing, matching, number line          |
|  Machine scored                                          |
|  DOK 2–3                                                 |
|  Both sessions                                           |
+----------------------------------------------------------+
```

**TEI Example (Grade 8, DOK 2, 8.SP — Statistics, Multi-Select):**

*A student collected data on the number of visitors to Door County over 12 months and created a scatter plot.*

Select TWO conclusions that are supported by the scatter plot data.

- A. Visitor numbers are highest during June, July, and August
- B. Visitor numbers are the same every month
- C. There is a positive correlation between temperature and number of visitors
- D. Door County receives no visitors during winter months
- E. The total number of visitors decreased each year

*Correct Answers: A and C*

### Constructed Response (CR)

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE — 0–2 points                       |
|                                                          |
|  Multi-step problem requiring shown work                 |
|  May include Parts A, B                                  |
|  DOK 2–3                                                 |
|  Human scored using CR rubric                            |
|  Session 2 only (2–3 per test)                           |
+----------------------------------------------------------+
```

**CR Example (Grade 7, DOK 3, 7.RP — Proportional Relationships):**

*"Two Wisconsin dairy farms report their milk production. Farm A produces 1,200 gallons from 80 cows. Farm B produces 900 gallons from 55 cows.*

*Part A: Find the gallons per cow for each farm. Show your work.*
*Part B: Which farm is more productive per cow? Explain your reasoning."*

## 8. SCORING RUBRICS

### Constructed Response (CR) Rubric — 0–2 Points

| Score | Criteria                                                                                                    |
|-------|-------------------------------------------------------------------------------------------------------------|
| 2     | Correct answer with complete, clearly shown work; mathematical reasoning is sound and organized              |
| 1     | Partially correct; work shown is incomplete or contains a minor error; some mathematical understanding       |
| 0     | Incorrect or no work shown; blank; off-task; no mathematical understanding demonstrated                     |

### TEI Scoring

| Item Type            | Scoring                                                              |
|----------------------|----------------------------------------------------------------------|
| TEI (1-point)        | All-or-nothing: full credit for fully correct response               |
| TEI (2-point)        | Partial credit: 2 pts for fully correct; 1 pt for partially correct  |

## 10. CONTEXTUALIZATION — WISCONSIN MATH

When generating real-world math contexts, prioritize authentic Wisconsin settings:

### Recommended Math Contexts

| Context                                   | Grade Band | Math Domains                                    |
|-------------------------------------------|------------|-------------------------------------------------|
| Dairy production data (milk, cheese)      | 3–10       | Ratios, multiplication, fractions, data analysis |
| Lake Michigan dimensions and data         | 5–10       | Measurement, geometry, proportional reasoning    |
| Door County tourism statistics            | 4–10       | Data analysis, statistics, percent, functions    |
| Wisconsin Dells rock formation data       | 4–8        | Measurement, geometry, data analysis             |
| Apostle Islands distances and areas       | 5–10       | Geometry, measurement, proportional reasoning    |
| Wisconsin cranberry harvest data          | 3–7        | Multiplication, fractions, ratios                |
| Green Bay Packers stadium statistics      | 5–8        | Data analysis, geometry, large numbers           |
| Wisconsin lumber production history       | 5–8        | Large numbers, ratios, percent change            |
| Lake Superior shipping distances          | 6–10       | Rates, proportional reasoning, functions         |

- "The table shows the number of tourists visiting Door County each month over [time period]..."
- "A cranberry farm in central Wisconsin harvested [X] barrels from [Y] acres..."
- "Students measured the distances between the Apostle Islands and recorded..."

## 11. QUALITY CHECKLIST AND COMMON PITFALLS

### Quality Checklist

- [ ] Standard code uses Wisconsin Standards format ([Grade].[Domain].[Standard])
- [ ] Practice standard alignment identified for CR items
- [ ] Calculator policy matches session and grade level
- [ ] CR items require shown work and may include multi-part structure
- [ ] All numerical values produce clean, non-ambiguous answers
- [ ] Wisconsin-specific real-world context used where appropriate
- [ ] Distractors reflect specific, identifiable student error types
- [ ] DOK level verified against actual cognitive demand
- [ ] Units and labels are correct throughout
- [ ] Grade 10 items include age-appropriate algebraic and functional content
- [ ] TEI format clearly specified (equation entry, graphing, multi-select, etc.)
- [ ] Data tables and graphs are clearly labeled

### Common Pitfalls

| Pitfall                                  | Problem                                           | Fix                                                      |
|------------------------------------------|---------------------------------------------------|----------------------------------------------------------|
| Calculator in Session 1 (Gr 3–5)        | No calculator allowed for any Grades 3–5 portion  | Design items without calculator dependence for Gr 3–5    |
| CR rubric exceeds 0–2 range             | Forward Exam Math CR items are scored 0–2          | Use only the 0–2 rubric scale                            |
| Generic context (no WI specificity)      | Forward Exam values authentic Wisconsin contexts   | Use dairy farms, Great Lakes, Door County, Dells         |
| CR without "show your work" directive   | DOK 3 requires demonstrated reasoning              | Include "Show your work" or "Explain your reasoning"     |
| Missing Grade 10 content                | Forward Exam tests Grade 10 with advanced math     | Include algebra, functions, and geometry for Grade 10    |
| TEI format unspecified                   | TEI has many possible formats                      | Always specify equation entry, graphing, drag-drop, etc. |
| Distractor without a clear error type    | Each wrong answer should target a specific mistake | Map each distractor to a computation or conceptual error |

## 12. PROMPT PATTERNS

The following patterns reflect the most common Forward Exam Mathematics item structures.

### Pattern 1: Contextual Computation (MC, DOK 2)
> "[Wisconsin setting]. [Given information]. [Mathematical question requiring multi-step application]."
> (Options: correct answer + three specific error-type distractors)

### Pattern 2: Multi-Step Application (CR Part A, DOK 2)
> "A [Wisconsin context] has [given data]. [Part A: computation requiring setup + solve]. Show your work."

### Pattern 3: Rate or Ratio in Context (MC or CR, DOK 2)
> "[Wisconsin scenario] involves [quantity A] for every [quantity B]. [Question about scaling, unit rate, or comparison]."

### Pattern 4: Explain in Context (CR Part B, DOK 3)
> "Explain what your answer to Part A means in the context of [Wisconsin scenario]."

### Pattern 5: Comparison with Justification (CR, DOK 3)
> "Two [Wisconsin scenarios] are described: [Scenario A] and [Scenario B]. Which is [more efficient / greater / better value]? Use mathematical evidence to justify your answer."

### Pattern 6: Error Analysis (MC or TEI, DOK 3)
> "[Student name] solved the problem and got [incorrect answer]. What error did [student] make?"

### Pattern 7: Data Interpretation (MC or TEI, DOK 2)
> "The [table / graph] below shows [Wisconsin data]. Based on the data, which statement is BEST supported?"
