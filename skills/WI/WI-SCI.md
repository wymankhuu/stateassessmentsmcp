## 2. STANDARDS FRAMEWORK

### Wisconsin Standards for Science (NGSS-aligned)

Wisconsin adopted science standards based on the NGSS framework. Standards are organized around three dimensions: Disciplinary Core Ideas (DCI), Science and Engineering Practices (SEP), and Crosscutting Concepts (CCC).

### Content Domains

| Code | Domain                         |
|------|--------------------------------|
| ESS  | Earth and Space Science        |
| LS   | Life Science                   |
| PS   | Physical Science               |
| ETS  | Engineering, Technology, Society|

### Grade 4 Priority Standards

| Standard Code | Description                                                                                      |
|---------------|--------------------------------------------------------------------------------------------------|
| 4-PS3         | Energy: define energy and relate speed to energy of motion                                        |
| 4-PS4         | Waves: develop models of waves, describe patterns in terms of amplitude and wavelength            |
| 4-LS1         | Organisms: construct arguments that organisms have internal and external structures for survival  |
| 4-ESS1        | Earth's place in Universe: identify evidence from patterns in rock formations and fossils         |
| 4-ESS2        | Earth's systems: analyze and interpret data from maps to describe patterns of Earth's features    |
| 4-ESS3        | Earth and human activity: generate solutions to reduce impacts of natural Earth processes         |

### Grade 8 Priority Standards

| Standard Code | Description                                                                                      |
|---------------|--------------------------------------------------------------------------------------------------|

| MS-ESS1       | Earth's place in the universe: develop models of Earth-Sun-Moon system                           |
| MS-ESS2       | Earth's systems: construct explanations based on evidence for geoscience processes                |

| Standard Code | Description                                                                                      |

| HS-PS1        | Matter and its interactions: use the periodic table and model atomic structure                    |

| HS-LS2        | Ecosystems: use mathematical representations for ecosystem dynamics                              |

## 5. ITEM TYPES

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Single correct answer                                   |
|  Machine scored                                          |
|  DOK 1–2                                                 |
+----------------------------------------------------------+
```

**MC Example (Grade 4, DOK 2, 4-LS1 — Organisms):**

White-tailed deer in Wisconsin grow thicker fur coats in autumn before winter arrives. How does this change BEST help the deer survive?

- A. It helps the deer run faster to escape predators
- B. It keeps the deer warm during cold Wisconsin winters
- C. It helps the deer find food under the snow
- D. It makes the deer more visible to other deer in the herd

*Correct Answer: B*

---

### Technology-Enhanced Item (TEI)

```
+----------------------------------------------------------+
|  TECHNOLOGY-ENHANCED ITEM — 1–2 points                   |
|                                                          |
|  Drag-and-drop, multi-select, matching,                  |
|  labeling diagrams, ordering, graphing                   |
|  Machine scored                                          |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**TEI Example (Grade 8, DOK 2, MS-ESS2 — Earth's Systems, Multi-Select):**

*Wisconsin's landscape was shaped by glaciers during the last Ice Age.*

Select TWO features that were formed by glacial activity in Wisconsin.

- A. The Wisconsin Dells rock formations carved by meltwater
- B. Volcanic mountains along the western border
- C. Kettle Moraine ridges and drumlins deposited by glaciers
- D. Deep ocean trenches along the Lake Michigan shore
- E. Sand dunes formed by desert winds

*Correct Answers: A and C*

### Constructed Response (CR)

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE — 0–2 points                       |
|                                                          |
|  Written response explaining scientific phenomena        |
|  Must reference data or scenario information             |
|  Human scored using CR rubric                            |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**CR Example (Grade 10, DOK 3, HS-ESS3 — Earth and Human Activity):**

*"Using the data provided about phosphorus levels in Lake Michigan over the past 30 years, explain how agricultural runoff from Wisconsin dairy farms affects the lake ecosystem. Include at least one specific pattern from the data and describe the relationship between phosphorus levels and algal blooms."*

## 7. NGSS THREE-DIMENSIONAL ASSESSMENT

Wisconsin's Forward Exam Science items reflect NGSS three-dimensional design where appropriate:

### Three Dimensions in Assessment

| Dimension                        | Description                                                              | Item Application                              |
|----------------------------------|--------------------------------------------------------------------------|-----------------------------------------------|
| Disciplinary Core Ideas (DCI)    | The core science content knowledge                                       | Content focus of the item                     |
| Science and Engineering Practices (SEP) | How scientists investigate and build models                      | Item requires analysis, modeling, or argument |
| Crosscutting Concepts (CCC)      | Concepts that bridge disciplines (patterns, cause/effect, systems)       | Conceptual lens for the item                  |

### Key SEPs Assessed

| SEP | Description                                             | Typical Item Type |
|-----|---------------------------------------------------------|-------------------|
| 1   | Asking questions and defining problems                  | CR               |
| 2   | Developing and using models                             | TEI, CR          |
| 3   | Planning and carrying out investigations                | MC, TEI          |
| 4   | Analyzing and interpreting data                         | MC, TEI, CR      |
| 6   | Constructing explanations                               | CR               |
| 7   | Engaging in argument from evidence                      | CR               |

### Key CCCs Assessed

| CCC | Concept           | Example Application                                        |
|-----|-------------------|------------------------------------------------------------|
| 1   | Patterns          | Identifying weather patterns in Great Lakes data           |
| 2   | Cause and Effect  | Explaining how glaciers caused Wisconsin's landforms       |
| 4   | Systems           | Analyzing Great Lakes ecosystem interactions               |

## 8. SCORING RUBRICS

### Constructed Response (CR) Rubric — 0–2 Points

| Score | Criteria                                                                                                    |
|-------|-------------------------------------------------------------------------------------------------------------|
| 2     | Accurate, complete explanation of the scientific phenomenon; references specific data or evidence; demonstrates clear understanding |
| 1     | Partially accurate explanation; some reference to data or evidence; demonstrates partial understanding       |
| 0     | Inaccurate, irrelevant, insufficient, or blank                                                              |

### TEI Scoring

| Item Type            | Scoring                                                              |
|----------------------|----------------------------------------------------------------------|
| TEI (1-point)        | All-or-nothing: full credit for fully correct response               |
| TEI (2-point)        | Partial credit: 2 pts for fully correct; 1 pt for partially correct  |

### MC Scoring

| Item Type    | Scoring Method  | Points |
|--------------|-----------------|--------|
| MC           | Machine scored  | 1 pt   |

## 10. CONTEXTUALIZATION — WISCONSIN SCIENCE

Wisconsin's unique ecology, geology, and geography provide rich phenomena for science assessment items.

### WI Science Context Guide by Grade

| Context / Phenomenon                        | Grade  | Domain              | Standards              |
|---------------------------------------------|--------|---------------------|------------------------|
| Great Lakes ecology and water quality       | 4, 8, 10 | Life/Earth Science | 4-ESS2, MS-LS2, HS-LS2 |
| Wisconsin glacial geology (Kettle Moraine)  | 4, 8   | Earth Science (ESS) | 4-ESS1, MS-ESS2        |
| Dairy farm science (nutrition, ecology)     | 4, 8   | Life Science (LS)   | 4-LS1, MS-LS2          |
| Apostle Islands sea caves and erosion       | 4, 8   | Earth Science (ESS) | 4-ESS2, MS-ESS2        |
| Lake Michigan water temperature patterns    | 8, 10  | Earth Science (ESS) | MS-ESS2, HS-ESS2       |
| Wisconsin forest ecology and succession     | 4, 8   | Life Science (LS)   | 4-LS1, MS-LS2          |
| Wisconsin Dells sandstone geology           | 4, 8   | Earth Science (ESS) | 4-ESS1, MS-ESS2        |
| Lake Superior ice formation patterns        | 8, 10  | Physical/Earth Sci   | MS-PS1, HS-ESS2        |
| Wisconsin agricultural runoff and water quality | 8, 10 | Life/Earth Science | MS-LS2, HS-ESS3       |
| Door County cherry blossom phenology        | 4, 8   | Life Science (LS)   | 4-LS1, MS-LS1          |

### Suggested Anchoring Phenomena by Grade

**Grade 4 Phenomena:**
- "White-tailed deer in Wisconsin forests change their behavior and fur thickness with the seasons — what adaptations help them survive cold winters?"
- "Students found different types of rocks near the Apostle Islands shoreline — what processes created these different rock types?"
- "A student noticed that trees near Lake Michigan have leaves that change color later in fall than trees farther inland — what causes this difference?"

**Grade 8 Phenomena:**
- "The Kettle Moraine in southeastern Wisconsin contains ridges, hills, and lakes that differ from the surrounding flat landscape — what geoscience processes formed these features?"
- "Scientists measuring phosphorus levels in Green Bay found that levels spike after heavy rainstorms — what relationship exists between agricultural practices and water quality?"
- "The Apostle Islands sea caves on Lake Superior continue to change shape each year — what processes drive this ongoing erosion?"

**Grade 10 Phenomena:**
- "Lake Michigan experiences large algal blooms in late summer that are visible from space — what chemical and biological processes contribute to this phenomenon?"
- "Wisconsin dairy farms produce methane as a byproduct of cattle digestion — how does this connect to greenhouse gas emissions and climate change?"
- "Scientists studying glacial deposits in Wisconsin can reconstruct climate conditions from thousands of years ago — what evidence in the rocks and soil supports these claims?"

## 11. QUALITY CHECKLIST AND COMMON PITFALLS

### Quality Checklist

- [ ] Grade verified as 4, 8, or 10 (Forward Exam Science grades)
- [ ] Standard code uses NGSS-aligned Wisconsin format
- [ ] Three-dimensional alignment noted where applicable (DCI, SEP, CCC)
- [ ] Wisconsin-specific phenomenon used in scenario items
- [ ] All MC distractors reflect identifiable student misconceptions
- [ ] Data tables and graphs are clearly labeled with units
- [ ] Science content is accurate and grade-appropriate
- [ ] DOK level matches cognitive demand of item
- [ ] Item avoids vocabulary beyond grade-level expectations
- [ ] Environmental contexts are authentic to Wisconsin
- [ ] CR items include evidence directive referencing scenario data
- [ ] TEI format clearly specified (drag-drop, multi-select, labeling, etc.)
- [ ] Grade 10 items reflect high-school-level science content

### Common Pitfalls

| Pitfall                                   | Problem                                           | Fix                                                      |
|-------------------------------------------|---------------------------------------------------|----------------------------------------------------------|
| Items for wrong grades                    | Forward Exam Science tests Grades 4, 8, and 10    | Restrict items to Grades 4, 8, and 10                    |
| Generic phenomena (not WI-specific)       | Items should anchor in real Wisconsin contexts     | Use Great Lakes, Kettle Moraine, dairy farms, Apostle Islands |
| Ignoring three-dimensional design         | NGSS items should integrate DCI, SEP, and CCC     | Note three-dimensional alignment in item design          |
| CR rubric exceeds 0–2 range              | Forward Exam Science CR items are scored 0–2       | Use the 0–2 rubric scale                                |
| Vocabulary too advanced for grade level   | Forward Exam targets grade-appropriate terminology | Review standards for expected vocabulary                  |
| Data items without clear labels/units     | Students need labeled data to interpret correctly  | Always include units and clear column/axis labels        |
| Missing Grade 10 content                  | Forward Exam tests Grade 10 with HS-level science  | Include HS-level standards for Grade 10                  |

## 12. PROMPT PATTERNS

The following patterns reflect the most common Forward Exam Science item structures.

### Pattern 1: Adaptation and Survival (MC, DOK 2, Life Science)
> "[Wisconsin organism] has [specific physical or behavioral trait]. How does this [adaptation / feature] BEST help the organism survive in its environment?"

### Pattern 2: Data Table Interpretation (MC or TEI, DOK 2)
> "The table below shows [Wisconsin science data]. Based on the data, which [conclusion / statement / pattern] is BEST supported?"

### Pattern 3: Glacial and Geological Processes (MC or TEI, DOK 1–2, Earth Science)
> "A student observed [geological feature] at [Wisconsin location]. Which process BEST explains how this feature formed?"

### Pattern 4: Ecosystem Interactions (MC or CR, DOK 2–3, Life Science)
> "In the [Great Lakes / Wisconsin forest / dairy farm] ecosystem, [change in one variable] occurred. What would MOST LIKELY be the effect on [another organism or part of the system]?"

### Pattern 5: Environmental Impact Analysis (CR, DOK 3, Earth Science)
> "Using the data provided about [Wisconsin environmental issue], explain how [human activity] affects [ecosystem or Earth system]. Include at least one specific pattern from the data."

### Pattern 6: Experimental Design and Variables (MC or CR, DOK 2–3)
> "A student designed an experiment to test whether [variable] affects [outcome] in a [Wisconsin context]. What is the [independent variable / controlled variable / best improvement]?"

### Pattern 7: Weather and Climate Patterns (MC or TEI, DOK 2, Earth Science)
> "The [graph / data table] shows [climate / weather data] recorded near [Wisconsin location]. Based on the data, what pattern is MOST LIKELY occurring?"
