## 1. Overview

| Field | Detail |
|---|---|
| **Assessment Name** | Nebraska Student-Centered Assessment System (NSCAS) — Mathematics |
| **Administering Agency** | Nebraska Department of Education (NDE) |
| **Vendor** | NE State DOE |
| **Grades Tested** | 3, 4, 5, 6, 7, 8, 11 |
| **Testing Window** | March – April |
| **Delivery** | Computer-based |
| **Standards** | Nebraska College and Career Ready Standards for Mathematics |
| **Score Scale** | 4 performance levels; scaled score varies by grade |
| **Reporting** | Individual Student Report; School, District, State aggregates |

> **NSCAS Mathematics:** The Nebraska Student-Centered Assessment System measures student mastery of the Nebraska College and Career Ready Standards for Mathematics. Items assess conceptual understanding, procedural fluency, and application in real-world and mathematical contexts.

### Performance Levels

| Level | Label | Description |
|---|---|---|
| 4 | **Level 4 — Exceeds** | Thorough understanding; applies mathematics in novel and complex situations; constructs valid mathematical arguments |
| 3 | **Level 3 — Meets** | Adequate understanding; solves grade-level problems accurately; applies mathematics to real-world contexts |
| 2 | **Level 2 — Approaching** | Partial understanding; applies procedures in familiar contexts but struggles with novel problems |
| 1 | **Level 1 — Beginning** | Minimal understanding; significant conceptual and procedural gaps |

## 5. Item Types & Formats

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Real-world or mathematical context                      |
|  Machine scored                                          |
|  DOK 1–3                                                 |
+----------------------------------------------------------+
```

**MC Example (Grade 6, DOK 2, 6.RP.A.3):**

A Nebraska farmer harvests 7,200 bushels of corn from 48 acres. At this rate, how many bushels would the farmer expect to harvest from 60 acres?

A. 7,500 bushels
B. 8,400 bushels
C. 9,000 bushels
D. 10,800 bushels

*Correct Answer: C (7200/48 = 150 bushels per acre; 150 x 60 = 9,000)*
*Alignment: 6.RP.A.3 | Ratios & Proportional Relationships | DOK 2*

---

**MC Example (Grade 4, DOK 2, 4.MD.A.3):**

A rectangular section of the Platte River near Grand Island is being measured for a conservation study. The section is 240 feet long and 95 feet wide. What is the area of this river section?

A. 335 square feet
B. 670 square feet
C. 22,800 square feet
D. 22,800 feet

*Correct Answer: C*
*Alignment: 4.MD.A.3 | Measurement & Data | DOK 2*

---

### Multi-Select (MS)

```
+----------------------------------------------------------+
|  MULTI-SELECT RESPONSE — 1 point                         |
|                                                          |
|  5–6 options; select exactly 2 or 3 correct answers      |
|  Full credit only; partial credit not awarded            |
|  Machine scored                                          |
+----------------------------------------------------------+
```

**MS Example (Grade 7, DOK 2, 7.RP.A.2):**

A Nebraska feedlot receives beef cattle at a constant rate. After 4 days, the lot has received 520 cattle. Select ALL equations that correctly represent the relationship between the number of days (d) and the number of cattle received (c).

A. c = 130d
B. d = 130c
C. c/d = 130
D. d/c = 130
E. c = 520 + 130d

*Correct Answers: A, C*
*Alignment: 7.RP.A.2 | Ratios & Proportional Relationships | DOK 2*

---

### Constructed Response (CR)

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE — 0–2 points                       |
|                                                          |
|  Show work and explain reasoning                         |
|  Real-world or mathematical context                      |
|  Human scored                                            |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**CR Example (Grade 7, DOK 3, 7.RP.A.2):**

The Sandhills region of Nebraska covers approximately 19,600 square miles and contains roughly 720,000 head of cattle. The eastern Nebraska farmland region covers approximately 12,400 square miles and contains roughly 310,000 head of cattle.

Which region has a higher density of cattle per square mile? Show your work and explain how you determined your answer.

*Scoring:*
- *2 pts: Correctly computes cattle density for both regions (Sandhills: ~36.7 per sq mi; Eastern: ~25.0 per sq mi), identifies Sandhills as higher, and provides clear explanation*
- *1 pt: Correct approach with minor computational error, OR correct answer without work/explanation*
- *0 pts: Incorrect approach or blank*

## 8. Scoring Rubrics

### Constructed Response (CR) Rubric — 0–2 Points

| Score | Criteria |
|---|---|
| 2 | Correct solution with clear mathematical reasoning. Work shown systematically. Explanation demonstrates conceptual understanding. Appropriate mathematical vocabulary used. |
| 1 | Partial understanding with minor errors. Correct approach demonstrated but final answer contains an error. OR Correct answer given without sufficient work or explanation. |
| 0 | Incorrect approach, no understanding shown, or blank. |

### CR Scoring Notes

- **Work must be shown** for full credit on all CR items.
- **Explanations** should reference mathematical concepts, not just describe steps.
- **Computational errors** with correct reasoning earn partial credit (1 point).

## 10. Contextualization — Nebraska Mathematics

When generating problem contexts, use authentic Nebraska settings:

### Nebraska Math Context Guide

| Context | Domain | Grade Band |
|---|---|---|
| Nebraska corn production (bushels per acre, yield data) | Ratios, Operations, Data | 3–8 |
| Nebraska beef production and feedlot operations | Proportionality, Measurement, Statistics | 5–11 |
| Platte River dimensions and flow rates | Measurement, Ratios, Geometry | 4–8 |
| Sandhills area and ranching statistics | Geometry, Measurement, Statistics | 5–11 |
| Oregon Trail distances and pioneer travel rates | Ratios, Proportionality, Operations | 4–8 |
| Nebraska wind energy production data | Functions, Data Analysis, Statistics | 6–11 |
| Chimney Rock / Scotts Bluff elevation data | Operations, Geometry, Measurement | 3–7 |
| Nebraska soybean farming and crop data | Ratios, Fractions, Data Analysis | 3–8 |
| Omaha and Lincoln population data | Statistics, Proportionality, Data | 5–11 |
| Sandhill crane migration counts | Data Analysis, Operations, Statistics | 3–8 |

### Suggested Problem Contexts by Grade

**Grades 3–5:**
- Counting sandhill cranes during the spring migration along the Platte River
- Measuring the dimensions of a corn field near Grand Island
- Sharing bushels of soybeans equally among Nebraska grain elevators

**Grades 6–8:**
- Comparing corn production rates across Nebraska counties
- Analyzing Platte River water flow data to determine average rates
- Calculating the area of Sandhills ranches and comparing cattle density

**Grade 11:**
- Modeling Nebraska wind farm energy output as a function of wind speed
- Analyzing scatter plots of corn yield vs. rainfall across Nebraska counties
- Using statistical inference with Nebraska population growth data for Omaha and Lincoln

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] Nebraska College and Career Ready Standards code is accurate and grade-appropriate
- [ ] MC items have exactly 4 options with one correct answer
- [ ] MS items specify exact number of answers to select (ALL/TWO/THREE)
- [ ] CR items require work to be shown and reasoning explained
- [ ] CR scored on 0–2 point scale
- [ ] Calculator policy appropriate for grade level
- [ ] Nebraska real-world context used where appropriate
- [ ] Distractors represent actual student computational or conceptual errors
- [ ] All computations verified before item is finalized
- [ ] DOK level matches actual cognitive demand
- [ ] Grade 11 items reflect high school mathematics complexity

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| CR asking only for a final answer | CR must require explanation | Add "Show your work and explain" |
| Using non-Nebraska contexts | Misses state contextualization | Use Nebraska farms, Platte River, Sandhills, and Omaha/Lincoln contexts |
| Items testing only rote computation | NSCAS targets DOK 2 primarily | Add real-world context to elevate cognitive demand |
| Grade 11 items at middle school level | Underestimates high school expectations | Use algebra, functions, and statistics at HS level |
| Distractors that are obviously wrong | Does not assess real misconceptions | Base distractors on common student errors |

## 12. Prompt Patterns

### Pattern 1: Real-World Application (MC, DOK 2)
> "[Nebraska context]. [Multi-step problem]. What is [answer]?"

### Pattern 2: Justify and Explain (CR, DOK 3)
> "[Nebraska scenario]. [Problem]. Show your work and explain how you found your answer."

### Pattern 3: Proportional Reasoning (MC, DOK 2)
> "A [Nebraska entity] produces/uses [quantity] in [time/unit]. At this rate, how much [quantity] in [different time/unit]?"

### Pattern 4: Data Interpretation (MC or MS, DOK 2)
> "The [table / graph] shows [Nebraska data context]. Based on the data, which statement is correct?"

### Pattern 5: Multi-Step Problem Solving (CR, DOK 3)
> "[Nebraska scenario with multiple constraints]. Determine [answer]. Show your work and explain whether your answer is reasonable."

### Pattern 6: Comparison and Reasoning (CR, DOK 3)
> "Two students solved this problem differently. [Method A] and [Method B]. Who is correct? Use mathematics to justify your answer."
