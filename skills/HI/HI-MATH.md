## 1. Overview

| Field | Detail |
|---|---|
| **Assessment Name** | Hawaii Statewide Assessment (HSA) — Mathematics |
| **Consortium** | Smarter Balanced Assessment Consortium (SBAC) |
| **Vendor** | Hawaii Department of Education (HIDOE) / Educational Testing Service (ETS) |
| **Grades Tested** | 3, 4, 5, 6, 7, 8, 11 |
| **Testing Window** | March – May (operational window; schools schedule within this range) |
| **Delivery** | Computer-adaptive (CAT) for Part 1 (non-calculator + calculator); fixed-form Performance Task for Part 2 |
| **Standards** | Common Core State Standards for Mathematics (CCSS-M) |
| **Score Scale** | 2000–3000 scale score (varies by grade) |
| **Reporting** | Individual Student Report (ISR); School, Complex Area, State aggregate reports |

### Achievement Level Descriptors (ALDs)

| Level | Label | Description |
|---|---|---|
| 4 | **Standard Exceeded** | Student demonstrates sophisticated understanding of mathematical concepts and procedures; applies mathematics fluently in novel situations; constructs valid mathematical arguments; evaluates and critiques the reasoning of others |
| 3 | **Standard Met** | Student demonstrates adequate understanding of grade-level concepts and procedures; applies mathematics to real-world and mathematical problems with reasonable accuracy; can explain mathematical reasoning |
| 2 | **Standard Nearly Met** | Student demonstrates partial understanding; can apply procedures in familiar contexts but struggles with novel problems; mathematical explanations are incomplete or sometimes inaccurate |
| 1 | **Standard Not Met** | Student demonstrates minimal understanding of grade-level concepts and procedures; significant gaps in foundational knowledge; cannot apply mathematics to solve real-world problems |

> **Cut scores** are set by the Smarter Balanced Assessment Consortium and adopted by the Hawaii Board of Education. For item-writing purposes, target ALDs 3 and 4.

## 5. Item Types & Formats

### SR — Selected Response (1 point)

Standard four-option multiple-choice.

```
+-----------------------------------------------------------------+
|  [Context sentence(s) establishing the math scenario]             |
|                                                                   |
|  [Question stem requiring mathematical reasoning]                 |
|                                                                   |
|  O  A. [Distractor — common computational error]                  |
|  O  B. [Distractor — wrong operation applied]                     |
|  O  C. [Correct answer]                                           |
|  O  D. [Distractor — partial solution or misread]                 |
+-----------------------------------------------------------------+
Points: 1 (correct) / 0 (incorrect)
```

---

### MS — Multi-Select (1 point)

Student selects ALL correct answers from a set of five or six options.

```
+-----------------------------------------------------------------+
|  [Question stem — "Select ALL the expressions that..."]           |
|                                                                   |
|  [ ]  A. [Option]                                                 |
|  [ ]  B. [Option — CORRECT]                                       |
|  [ ]  C. [Option]                                                 |
|  [ ]  D. [Option — CORRECT]                                       |
|  [ ]  E. [Option]                                                 |
|  [ ]  F. [Option — CORRECT]                                       |
+-----------------------------------------------------------------+
Points: 1 (all correct, none incorrect) / 0 (any other)
```

---

### EQ — Equation / Numeric Entry (1 point)

Student types a numerical answer or expression into an input field.

```
+-----------------------------------------------------------------+
|  [Word problem or mathematical context]                           |
|                                                                   |
|  What is the value of [quantity]?                                 |
|                                                                   |
|  Answer: [____________]                                           |
+-----------------------------------------------------------------+
Points: 1 (exact match or equivalent form) / 0 (incorrect)
```

---

### TE — Technology-Enhanced (1–2 points)

Includes graphing items (plot points, draw lines), drag-and-drop (sorting, matching, ordering), and hot-spot items.

```
+-----------------------------------------------------------------+
|  [Graph / coordinate plane / number line / sorting area]          |
|                                                                   |
|  [Directive: "Plot the point..." / "Drag each expression..." /   |
|   "Click the region that..."]                                     |
+-----------------------------------------------------------------+
Points: 1–2 depending on complexity
```

---

### SCR — Short Constructed Response (0–2 points)

Student solves a problem and provides a written explanation of their reasoning.

```
+-----------------------------------------------------------------+
|  [Multi-step word problem with real-world context]                |
|                                                                   |
|  Part A: [Solve the problem. Show your work.]                     |
|  [Student response area]                                          |
|                                                                   |
|  Part B: [Explain how you know your answer is correct/reasonable.]|
|  [Student response area]                                          |
+-----------------------------------------------------------------+
Scoring: 0–2 points (see Section 8 rubric)
```

---

### PT-ER — Performance Task Extended Response (0–6 points)

A multi-part task embedded in a real-world scenario. Three parts (A, B, C), each scored 0–2.

```
+-----------------------------------------------------------------+
|  PERFORMANCE TASK                                                 |
|                                                                   |
|  [5–7 sentence real-world scenario with data table/diagram]       |
|                                                                   |
|  Part A: [Setup calculation — DOK 2]                              |
|  Part B: [Application/comparison — DOK 2–3]                       |
|  Part C: [Modeling/justification — DOK 3–4]                       |
+-----------------------------------------------------------------+
Scoring: 0–2 per part; Total: 0–6
```

## 6. DOK / Cognitive Complexity

### DOK Level Descriptions for Mathematics

| DOK | Label | Description | Example Tasks |
|---|---|---|---|
| **1** | Recall & Reproduction | Recall a fact; perform a routine, single-step procedure; identify a property; solve a one-step equation; read a value from a graph | *calculate, identify, recall, use, recognize, list, name, measure* |
| **2** | Skills & Concepts | Solve a multi-step problem using a known procedure; classify or organize information; make inferences from data; apply a concept in a new but straightforward context | *classify, organize, estimate, compare, interpret, solve [multi-step], graph, apply* |
| **3** | Strategic Thinking | Solve non-routine problems requiring planning; justify or prove a mathematical claim; analyze errors in reasoning; design a mathematical model; evaluate the reasonableness of results | *justify, prove, analyze, evaluate, formulate, critique, explain reasoning, construct* |
| **4** | Extended Thinking | Conduct multi-stage investigations; synthesize mathematical ideas across domains; design and evaluate complex models; present and defend solutions | *synthesize, design, evaluate [complex], connect, present, create* |

> DOK 4 appears primarily in PT Extended Response Part C items, not in individual CAT items.

### DOK Distribution Targets for Item Generation

| Item Type | Target DOK | Rationale |
|---|---|---|
| SR — single computation | 1 | Routine procedure, one step |
| SR — two-step word problem | 2 | Application; concept + computation |
| MS — identify equivalent forms | 1–2 | Depends on conceptual demand |
| EQ — numeric entry | 1–2 | Usually procedural; contextual use raises to DOK 2 |
| TE — graphing | 2 | Requires connecting representations |
| SCR — explain reasoning | 3 | Justification required; non-routine |
| PT-ER Part A | 2 | Setup computation within context |
| PT-ER Part B | 2–3 | Application or partial modeling |
| PT-ER Part C | 3–4 | Full modeling, justify, evaluate |

## 7. Mathematical Practices

The Standards for Mathematical Practice (SMP) describe the mathematical habits of mind that proficient students develop.

### The 8 Standards for Mathematical Practice

| SMP | Title | Description | Primary Claim(s) |
|---|---|---|---|
| **SMP 1** | Make sense of problems and persevere in solving them | Students understand what a problem is asking, plan a pathway, monitor progress, and adjust strategy if needed | Claims 2, 4 |
| **SMP 2** | Reason abstractly and quantitatively | Students decontextualize (represent symbolically) and recontextualize (interpret symbols back in context) | Claims 1, 3 |
| **SMP 3** | Construct viable arguments and critique the reasoning of others | Students justify conclusions using mathematical reasoning; they identify flawed arguments and explain the flaw | Claim 3 |
| **SMP 4** | Model with mathematics | Students use mathematics to describe real-world situations; they identify important quantities, map relationships, and evaluate whether a model is appropriate | Claim 4 |
| **SMP 5** | Use appropriate tools strategically | Students choose and use tools — calculators, rulers, protractors, graphs, spreadsheets — knowing their limitations | Claims 1, 2 |
| **SMP 6** | Attend to precision | Students use precise language and symbols; they specify units of measure; they calculate accurately and efficiently | Claim 1 |
| **SMP 7** | Look for and make use of structure | Students see patterns and structure in mathematical objects; they recognize equivalent forms | Claim 1 |
| **SMP 8** | Look for and express regularity in repeated reasoning | Students notice repeated calculations and general methods; they articulate general rules | Claims 1, 3 |

### SMP — Claim Alignment Matrix

| Claim | Primary SMPs | Secondary SMPs |
|---|---|---|
| Claim 1 — Concepts & Procedures | SMP 6, 7, 8 | SMP 2, 5 |
| Claim 2 — Problem Solving | SMP 1, 5 | SMP 2, 4, 6 |
| Claim 3 — Communicating Reasoning | SMP 3, 6 | SMP 1, 2, 7 |
| Claim 4 — Modeling & Data Analysis | SMP 4, 1 | SMP 2, 3, 5, 6 |

## 8. Scoring Rubrics

### SCR — Short Constructed Response (0–2 Points)

| Score | Descriptor |
|---|---|
| **2** | The response demonstrates a thorough understanding of the mathematical concepts and procedures required by the task. The student provides a correct solution with a clear, accurate explanation or justification. Work shown is logical and complete. Minor arithmetic errors do not affect the score if reasoning is sound. |
| **1** | The response demonstrates a partial understanding of the mathematical concepts and procedures. The student provides a partially correct solution or a correct solution with an incomplete or unclear explanation. OR the student provides the correct answer with no explanation. |
| **0** | The response is incorrect, irrelevant, or demonstrates no mathematical understanding. A blank response receives a score of 0. |

---

### PT-ER — Performance Task Extended Response (0–6 Points)

#### Part A Rubric (0–2 points)

| Score | Descriptor |
|---|---|
| **2** | The response correctly sets up and solves the introductory problem within the scenario. All calculations are correct and clearly shown. Units are correctly identified and used. |
| **1** | The response demonstrates correct approach or setup but contains a computational error, an incomplete solution, or a missing unit. |
| **0** | The response is incorrect, missing, or demonstrates no understanding of the mathematical task. |

#### Part B Rubric (0–2 points)

| Score | Descriptor |
|---|---|
| **2** | The response correctly applies the mathematical results from Part A to solve the intermediate problem. Reasoning is clear; any comparison, evaluation, or interpretation is accurate and well-supported. |
| **1** | The response shows partial understanding. The student may use an incorrect value from Part A but apply correct reasoning from that point. |
| **0** | The response is incorrect, missing, or shows no mathematical understanding relative to the Part B task. |

#### Part C Rubric (0–2 points)

| Score | Descriptor |
|---|---|
| **2** | The response demonstrates sophisticated mathematical reasoning applied to the complex extension. The student accurately uses mathematical results to justify a decision, evaluate a model, or explain a pattern. |
| **1** | The response shows some correct reasoning or a partially valid justification. The student may identify the correct conclusion but provide insufficient mathematical support. |
| **0** | The response is incorrect, off-task, or provides only unsupported assertions. |

#### Error-Carried-Forward (ECF) Policy

When a student carries an incorrect value from Part A into Parts B and C, use ECF scoring:
- If the student's Part B or Part C work is mathematically correct based on their Part A answer, award full credit for that part despite the error from Part A
- ECF applies only when the error is a simple computational mistake, not a conceptual misunderstanding

## 10. Contextualization

### Hawaii-Specific Mathematics Context Bank

Item writers should anchor scenarios in authentic Hawaii contexts to maximize student engagement and ecological validity.

#### Island Distances & Geography

| Topic | Mathematical Applications |
|---|---|
| **Inter-island distances** | Distance-rate-time problems (e.g., Honolulu to Maui ~100 miles by air); unit conversion (miles, nautical miles, kilometers); proportional reasoning |
| **Island elevations** | Mauna Kea summit 13,796 ft; Mauna Loa 13,681 ft; comparing elevations; sea level vs. sea floor measurements; integers and absolute value |
| **Archipelago measurements** | Total chain length ~1,500 miles; area of individual islands; perimeter of coastlines; fractions and decimals in measurement |
| **Volcanic elevation data** | Height comparisons between volcanic peaks; elevation gain calculations for hiking trails; data tables of eruption data over time |

#### Ocean & Marine Data

| Topic | Mathematical Applications |
|---|---|
| **Ocean temperature data** | Seasonal temperature changes; data analysis with mean, median, range; graphing temperature over months |
| **Tide data** | High and low tide differences; time intervals between tides; patterns and periodic data; graphing tidal cycles |
| **Whale migration distances** | Humpback whale travel from Alaska (~3,500 miles); rate problems; unit rate; proportional relationships |
| **Coral reef area measurements** | Area calculations; percent of reef damaged vs. healthy; data interpretation; ratio and proportion |

#### Tourism & Economy

| Topic | Mathematical Applications |
|---|---|
| **Tourism statistics** | Approximately 10 million visitors per year; percent change year-over-year; per-capita spending; graphing trends |
| **Hotel occupancy rates** | Percent; ratio; comparing rates across islands; multi-step computations |
| **Agriculture data** | Coffee production (Kona); macadamia nut harvest data; unit rates (pounds per acre); proportional reasoning |
| **Cost of living** | Comparing prices (groceries, fuel) to mainland averages; percent difference; ratio and proportion |

#### Community & Everyday Contexts

| Topic | Mathematical Applications |
|---|---|
| **School lu'au planning** | Multi-step problems with food quantities, budgets, and serving sizes; multiplication, division, fractions |
| **Canoe paddling distances** | Rate problems; distance-time relationships; unit conversion; data collection and graphing |
| **Farmer's market pricing** | Unit price comparisons; fractions and decimals; multi-step computation; percent discount |
| **Public transit (TheBus) schedules** | Elapsed time; distance and rate; proportional reasoning; reading schedules and tables |

### Grade-Band Contextualization Notes

#### Grades 3–5

| Principle | Guidance |
|---|---|
| **Concreteness** | Contexts should involve tangible, observable quantities (shells counted, distances measured, areas calculated) |
| **Accessibility** | Avoid highly specialized vocabulary or cultural knowledge that disadvantages newcomer students |
| **Scale of numbers** | Match the number magnitude to grade-level standards (Gr 3: within 1,000; Gr 5: multi-digit, decimals, fractions) |
| **Authenticity** | School garden (kalo/taro patch), beach cleanup, island field trip, farmer's market — familiar community settings |

#### Grades 6–8

| Principle | Guidance |
|---|---|
| **Real data** | Use approximate real data (Hawaii population ~1.4 million; tourism figures; volcanic eruption data) to ground tasks |
| **Multiple representations** | Include tables, graphs, or diagrams alongside word problem contexts |
| **Social relevance** | Topics like sustainability, ocean health, and cost of living resonate with middle-school students |

#### Grade 11

| Principle | Guidance |
|---|---|
| **Workforce readiness** | Career-relevant contexts (marine biology, tourism management, sustainable agriculture, renewable energy) |
| **Complex data** | Multi-variable data sets; scatter plots; regression; probability in real decision-making |
| **Equity lens** | Include data that represents Hawaii's diversity; avoid contexts that systematically advantage students from higher socioeconomic backgrounds |

### English Learner (EL) Considerations for Math

| Consideration | Guidance |
|---|---|
| **Mathematical vocabulary** | Pre-teach or define Tier 3 math vocabulary in a glossary; avoid confusing mathematical terms with everyday meanings |
| **Word problem language** | Use simple, direct sentence structure in word problem stems; avoid unnecessarily complex syntax |
| **Bilingual glossary** | EL designated support; mathematical terms available in multiple languages; items should not be invalidated by glossary use |
| **Hawaiian terms** | Common Hawaiian words used in everyday Hawaii English (e.g., mauka/makai for directional context) may appear with sufficient context |
| **Diagrams and visuals** | Use clear, labeled diagrams to reduce linguistic load |

## 11. Quality Checklist

Use this checklist before finalizing any generated item or item set.

### Standards Alignment

- [ ] Item is tagged to one primary CCSS Math standard (e.g., 7.RP.A.2)
- [ ] Standard matches the claim and subclaim
- [ ] DOK level is consistent with the cognitive demand of the task
- [ ] Grade-level standard is appropriate for the intended grade band
- [ ] Item does not require knowledge of standards above or below grade level

### Calculator Policy

- [ ] Item is flagged as calculator or non-calculator consistent with grade-level policy (Section 3)
- [ ] Computational complexity is appropriate for the calculator policy
- [ ] Calculator-active items use numbers that would realistically benefit from a calculator

### Reference Sheet

- [ ] For Grades 8 and 11: item does not embed formulas that are on the reference sheet
- [ ] For Grades 3–7: item does not require formulas not taught at grade level
- [ ] Formula reference is given in the item when required

### Item Quality (All Types)

- [ ] Stem is a clear, unambiguous question or directive
- [ ] All numerical values in the problem are internally consistent
- [ ] Units are clearly specified and used correctly throughout
- [ ] No "trick" questions
- [ ] Diagrams are clearly labeled, drawn to reasonable scale, and described in alt text
- [ ] Answer options for SR are plausible and each represents a specific student error
- [ ] Correct answer is verified independently (calculation checked)
- [ ] Word problem context is realistic and meaningful

### SCR and PT-ER Checks

- [ ] Constructed-response prompt requires both a numerical answer AND explanation/justification
- [ ] Rubric is included with the item
- [ ] PT-ER parts are interdependent and logically sequenced (A -> B -> C)
- [ ] Error-carried-forward (ECF) policy is noted in the rubric
- [ ] Scoring guide anticipates common student errors

### EL and Accessibility

- [ ] Word problem language is clear and concise
- [ ] Mathematical vocabulary is appropriate for the grade; specialized terms are defined
- [ ] Diagrams are usable by students using zoom or screen magnification
- [ ] Item does not require cultural knowledge that disadvantages EL students

## 12. Prompt Patterns

The following patterns map common user requests to generation strategies for the AI.

---

### Pattern 1: "Generate a math problem for Grade [X]"

**Interpretation:** Default to an SR item (1 point) for Claim 1 (Concepts & Procedures) at DOK 2. Use a real-world context from Section 10.

**Generation Recipe:**
1. Identify the primary content domain for the grade
2. Select a Hawaii context from Section 10
3. Generate SR using Template 1, ensuring two mathematical steps
4. Construct four options where each distractor represents a distinct common error
5. Tag: state=HI, subject=MATH, grade=[X], claim=2, standard=[DOMAIN].[GRADE].[STANDARD], dok=2, calculator=[per policy]

---

### Pattern 2: "Generate a word problem that requires explanation"
