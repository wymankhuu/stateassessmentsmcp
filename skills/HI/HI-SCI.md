## 1. Overview

| Field | Detail |
|---|---|
| **Assessment Name** | Hawaii Statewide Assessment (HSA) — Science |
| **Administering Agency** | Hawaii Department of Education (HIDOE) |
| **Vendor** | Hawaii DOE / Educational Testing Service (ETS) |
| **Grades Tested** | 5, 8, 11 |
| **Testing Window** | March – May |
| **Delivery** | Computer-based; fixed-form |
| **Standards** | Next Generation Science Standards (NGSS) as adopted by Hawaii |
| **Score Scale** | Standard score (varies by grade); 4 performance levels |
| **Reporting** | Individual Student Report; School, Complex Area, State aggregate reports |

> **CRITICAL NOTE:** HSA Science is administered **only at Grades 5, 8, and 11**. Do not generate items for Grades 3, 4, 6, or 7. Grade 5 covers elementary NGSS; Grade 8 covers middle school NGSS; Grade 11 covers high school science (Biology, Chemistry, Physics, Earth Science).

### Performance Level Descriptors

| Level | Label | Description |
|---|---|---|
| 4 | **Standard Exceeded** | Student demonstrates thorough understanding of three-dimensional science; expertly integrates DCI, SEP, and CCC; constructs sophisticated, evidence-based explanations |
| 3 | **Standard Met** | Student demonstrates adequate understanding of three-dimensional science; appropriately applies practices and crosscutting concepts in grade-level contexts |
| 2 | **Standard Nearly Met** | Student demonstrates partial understanding; can recall disciplinary core ideas but struggles to integrate science practices or crosscutting concepts |
| 1 | **Standard Not Met** | Student demonstrates minimal science understanding; cannot apply practices or crosscutting concepts; limited to recall of isolated facts |

> **Item-writing target:** Level 3 (Standard Met) performance. Items should assess all three NGSS dimensions simultaneously.

## 3. Test Structure

HSA Science is a single-session, computer-based test. There is **no lab practical component** — all items are stimulus-based (scenarios, data tables, diagrams, models, and graphs).

```
+------------------------------------------------------------------+
|                   HSA SCIENCE STRUCTURE (Grades 5, 8, 11)         |
+------------------------------------------------------------------+
|  SINGLE SESSION                                                    |
|  Computer-Based, Fixed-Form                                        |
|  Approximately 90–120 minutes                                      |
|                                                                    |
|  ~40 items per grade                                               |
|                                                                    |
|  Item types:                                                       |
|    * Selected Response (SR) — ~60–65% of items                     |
|    * Multi-Select Response (MS) — ~15–20% of items                 |
|    * Constructed Response (CR) — ~15–20% of items (3 pts each)     |
+------------------------------------------------------------------+
```

### Grade-Level Test Specifications

| Specification | Grade 5 | Grade 8 | Grade 11 |
|---|---|---|---|
| Approximate Item Count | ~38–42 | ~38–42 | ~38–42 |
| Selected Response | ~25–28 | ~25–28 | ~25–28 |
| Multi-Select | ~6–8 | ~6–8 | ~6–8 |
| Constructed Response | ~4–6 | ~4–6 | ~4–6 |
| Approx. Testing Time | 90–120 min | 90–120 min | 90–120 min |
| Calculator | No | No | No |
| Reference Sheet | No | No | No |

> **Three-Dimensional Requirement:** Every HSA Science item must integrate at least one **Disciplinary Core Idea (DCI)**, one **Science and Engineering Practice (SEP)**, and one **Crosscutting Concept (CCC)**. Items that test only factual recall of DCIs are not NGSS-aligned and should not be used.

## 5. Item Types & Formats

### Selected Response (SR)

```
+----------------------------------------------------------+
|  SELECTED RESPONSE — 1 point                             |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Scenario, diagram, data table, or model stimulus        |
|  Must integrate DCI + SEP + CCC                          |
|  Machine scored                                          |
+----------------------------------------------------------+
```

**SR Example (Grade 8, DOK 2, MS-ESS2-2 — Geoscience Processes):**

Scientists studying the Hawaiian Islands found that the islands become progressively older as you move from southeast to northwest. Kauai, the northwesternmost major island, is approximately 5.1 million years old, while the Big Island (Hawaii) is less than 0.7 million years old. Which statement BEST explains this pattern?

A. Ocean currents pushed the islands farther apart over time
B. The Pacific Plate moved over a stationary volcanic hot spot, creating a chain of islands
C. Each island was formed by a different volcano erupting at the same time
D. Erosion caused the northwestern islands to appear older

*Correct Answer: B*
*Alignment: MS-ESS2-2 | SEP: Constructing Explanations | CCC: Patterns | DOK 2*

---

**SR Example (Grade 5, DOK 2, 5-LS2-1 — Food Webs):**

A student draws a model showing algae -> sea urchins -> Hawaiian monk seals. Which statement BEST describes the role of the algae in this model?

A. The algae receives energy from the sea urchins
B. The algae provides energy that originally came from the sun
C. The algae is a decomposer that recycles nutrients in the ocean
D. The algae stores energy that it receives from the monk seals

*Correct Answer: B*
*Alignment: 5-LS2-1 | SEP: Developing and Using Models | CCC: Energy and Matter | DOK 2*

---

### Multi-Select Response (MS)

```
+----------------------------------------------------------+
|  MULTI-SELECT RESPONSE — 1 point                         |
|                                                          |
|  5–6 options; select exactly 2 or 3 correct answers      |
|  Full credit only; partial credit not awarded            |
|  Machine scored                                          |
+----------------------------------------------------------+
```

**MS Example (Grade 8, DOK 2, MS-ESS3-3 — Human Impact):**

A coral reef ecosystem near Maui is showing signs of bleaching. Select the TWO statements that describe evidence-based strategies scientists could use to monitor and help protect the reef.

A. Remove all fish from the reef to reduce competition
B. Collect water temperature and pH data monthly to track environmental changes
C. Add chemicals to the water to make it cooler
D. Establish marine protected areas to limit fishing and boat anchoring near the reef
E. Increase the amount of sunscreen-wearing tourists swimming near the reef

*Correct Answers: B, D*
*Alignment: MS-ESS3-3 | SEP: Constructing Explanations | CCC: Cause and Effect | DOK 2*

### Constructed Response (CR)

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE — 0–3 points                       |
|                                                          |
|  Written explanation using evidence from stimulus        |
|  Stimulus always provided (data, diagram, scenario)      |
|  Must demonstrate three-dimensional reasoning            |
|  Human scored                                            |
+----------------------------------------------------------+
```

**CR Example (Grade 8, DOK 3, MS-LS2-2 — Ecosystem Interactions):**

*Stimulus: A data table showing the population changes of Hawaiian monk seals, sea urchins, and coral reef health in a Hawaiian marine ecosystem over 20 years. Data shows that when monk seal populations declined, sea urchin populations increased, and coral reef health indicators dropped.*

*"Using data from the table, construct an explanation for how the decline in Hawaiian monk seal population may have affected the coral reef ecosystem. Include evidence from the data and explain the cause-and-effect relationship."*

## 7. Three-Dimensional Design

Every HSA Science item must reflect all three NGSS dimensions simultaneously.

### Three-Dimensions Alignment Guide

| Dimension | What It Is | Example in Items |
|---|---|---|
| **DCI** (What students know) | Disciplinary science content | Photosynthesis; volcanic formation; plate tectonics; natural selection; ecosystem interactions |
| **SEP** (What students do) | How scientists work | Analyze data from a table; construct an explanation using evidence; use a model to predict |
| **CCC** (Lens of thinking) | Cross-domain thinking tools | Cause and effect; patterns; energy and matter; structure and function; systems and system models |

### Sample Three-Dimensional Item Design (Grade 8)

```
+------------------------------------------------------------------+
|  3D ITEM STRUCTURE                                                |
|                                                                    |
|  PHENOMENON: Hawaiian coral reefs show bleaching patterns that     |
|  correlate with rising ocean temperatures over the past decade     |
|  (Authentic HI phenomenon grounds the item)                       |
|                                                                    |
|  DCI: MS-LS2 — Ecosystems; MS-LS2-2 interdependence              |
|  SEP: Analyzing and Interpreting Data                              |
|  CCC: Cause and Effect                                             |
|                                                                    |
|  STIMULUS: Time-series graph of ocean temperature, coral           |
|  bleaching percentage, and fish species diversity; 15-year span    |
|  near Kaneohe Bay, Oahu                                            |
|                                                                    |
|  PROMPT: "Using data from the graph, construct an explanation     |
|  for the relationship between ocean temperature and coral reef     |
|  health. Identify the cause-and-effect relationship."             |
+------------------------------------------------------------------+
```

### Crosscutting Concepts by Grade Band

| CCC | Grade 5 Emphasis | Grade 8 Emphasis | Grade 11 Emphasis |
|---|---|---|---|
| Patterns | Rock formations; seasonal changes | Island chain age patterns; evolutionary patterns | Inheritance patterns; population trends |
| Cause and Effect | Food web changes; erosion | Volcanic eruptions; population dynamics | Mutations -> traits; environmental -> evolution |
| Energy and Matter | Food chains; weather | Chemical reactions; thermal transfer | Cellular respiration; photosynthesis |
| Structure and Function | Plant/animal adaptations | Cell structures; molecular bonds | DNA -> protein -> trait |
| Systems and System Models | Ecosystems; water cycle | Earth systems; marine ecosystems | Ecosystems; genetic systems |
| Scale, Proportion, Quantity | Particle size; distances | Atomic scale; geological time | Chromosome/gene scale |
| Stability and Change | Habitat change; erosion | Climate; ecosystem stability | Evolution; homeostasis |

## 8. Scoring Rubrics

### Constructed Response (CR) Rubric — 0–3 Points

| Score | Criteria |
|---|---|
| 3 | Response accurately addresses the science concept; demonstrates clear three-dimensional understanding (DCI + SEP or CCC evident); includes specific, relevant evidence from the stimulus; explanation is complete, accurate, and logically connected |
| 2 | Response addresses the science concept with partial accuracy; shows understanding of the DCI but may only partially integrate a practice or crosscutting concept; evidence from stimulus is present but may be incomplete |
| 1 | Response minimally addresses the science concept; shows limited understanding; little or no evidence from stimulus; explanation may be vague or contain minor science inaccuracies |
| 0 | Response does not address the science concept; blank; off-topic; restates the stimulus without explanation; demonstrates no science understanding |

### CR Scoring Notes

- **Evidence must come from the stimulus.** Responses that rely solely on prior knowledge without referencing the provided data/diagram receive a maximum of 1 point.
- **Three-dimensional reasoning earns full credit.** A Score 3 response integrates content knowledge (DCI) with at least one SEP or CCC.
- **Misconceptions lower the score.** A significant science misconception drops the response by one score point.

```

         [construct an explanation for / argue whether / analyze why]

SCORING GUIDE:

Score 1: Vague or partially correct; little/no stimulus evidence used;
         or contains a minor misconception.
Score 0: Blank, off-task, or major misconception with no science content.

[2–4 sentence model response integrating evidence + DCI + CCC]
```

### Suggested Anchoring Phenomena by Grade

**Grade 5 Phenomena:**
- "The Hawaiian Islands are home to the nene goose, a bird found nowhere else on Earth. Scientists believe the nene evolved from Canadian geese that arrived in Hawaii thousands of years ago. How could a bird change so much over time?"
- "Kilauea volcano on the Big Island has been erupting for decades, adding new land to the island. Where does the energy come from that keeps the volcano active?"
- "Mauna Kea, a mountain on the Big Island, is 13,796 feet above sea level but measures over 33,000 feet from its base on the ocean floor. Why is Mauna Kea so much taller below the water than above it?"

**Grade 8 Phenomena:**
- "The Hawaiian Islands form a chain stretching 1,500 miles across the Pacific. Scientists found that Kauai (northwest) is 5.1 million years old, while the Big Island (southeast) is less than 0.7 million years old. What explains this age pattern?"

- "After the introduction of mongooses to Hawaii in the 1880s to control rats in sugarcane fields, populations of ground-nesting native birds declined sharply. What ecological relationship explains this pattern?"

**Grade 11 Phenomena:**
- "Hawaiian honeycreepers are a group of over 50 species of birds, all descended from a single finch-like ancestor that arrived in Hawaii millions of years ago. Some have long curved beaks for nectar, while others have thick beaks for seeds. What process explains this diversity?"
- "Scientists found that Hawaiian monk seals in the Northwestern Hawaiian Islands have lower genetic diversity than most mainland seal populations. What factors could explain this, and why might it be a concern for the species' survival?"

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] Grade verified as 5, 8, or 11 ONLY (not other grades)
- [ ] PE code is a valid NGSS Performance Expectation
- [ ] Item is three-dimensional: DCI + SEP + CCC all identified
- [ ] Anchoring phenomenon is authentic and Hawaii-relevant where possible
- [ ] Stimulus (data table/graph/diagram) has clear labels, units, and realistic data
- [ ] CR prompt directs students to use evidence from the stimulus
- [ ] All distractors represent real misconceptions (not obviously wrong)
- [ ] MS items specify how many answers to select (TWO/THREE)
- [ ] Score 3 anchor response written before finalizing CR item
- [ ] Science content is accurate and reflects current scientific understanding
- [ ] Vocabulary is grade-appropriate (avoid jargon not in NGSS glossary)

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Writing items for Grades 3, 4, 6, or 7 | HSA Science is only at Grades 5, 8, 11 | Restrict to tested grades |
| DCI-only items (no SEP or CCC) | HSA requires three-dimensional items | Always embed a practice and a crosscutting concept |
| CR prompts without evidence directive | Students may respond without citing data | Include "Use evidence from the [data/graph/diagram]" |
| Generic stimulus data not tied to HI | HSA favors Hawaii phenomena | Anchor stimulus to Hawaii-specific context |
| Multi-select with only 2 correct in 4 options | Too easy to guess | Use 5–6 options with exactly 2–3 correct |
| Recall-only SR items | DOK 1 items are under-represented on HSA | Elevate most items to DOK 2 with a scenario |
| Using mainland-only examples | Misses opportunity for authentic Hawaii context | Prioritize island, ocean, and volcanic contexts |

## 12. Prompt Patterns

The following patterns reflect the most common HSA Science item archetypes.

### Pattern 1: Data-to-Conclusion (SR, DOK 2)
> "The [graph / table / diagram] below shows [Hawaii science scenario]. Based on the data, which [conclusion / explanation / pattern] is BEST supported?"

### Pattern 2: Phenomenon Explanation (CR, DOK 3)
> "Scientists observed [Hawaii-anchored phenomenon]. Using evidence from the [data / model / diagram], construct an explanation for [specific science focus]. Explain the [cause-and-effect / energy flow / pattern] relationship."

### Pattern 3: Model Evaluation (SR or MS, DOK 2–3)
> "A student made a model showing [science concept]. Which statement BEST describes what the model shows about [DCI focus]? / Select the TWO statements that correctly describe what the model represents."

### Pattern 4: Investigation Design (CR, DOK 3)
> "A scientist wants to investigate whether [variable] affects [outcome] in [Hawaii ecosystem/context]. Describe a procedure the scientist could follow. Include what the scientist would measure and how they would know if the variable made a difference."

### Pattern 5: Evidence-Based Argument (CR, DOK 3)
> "Two students disagree about [science claim]. Student A says [claim based on misconception]. Student B says [scientifically accurate claim]. Using evidence from the [data / diagram], explain which student is correct and why."

### Pattern 6: Multi-Select Evidence (MS, DOK 2)
> "A student is investigating [Hawaii science scenario]. Select the TWO [pieces of evidence / strategies / explanations] that BEST support the conclusion that [DCI-based claim]."
