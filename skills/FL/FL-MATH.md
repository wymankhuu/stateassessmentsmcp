## 2. STANDARDS FRAMEWORK

### Florida B.E.S.T. Mathematics Standards

Florida's B.E.S.T. Mathematics Standards were adopted in 2020 and are **distinct from CCSS**. They have a unique domain structure and standard codes that reflect Florida's approach to mathematical progressions.

Standard code format: **MA.[Grade].[Domain].[Standard].[Benchmark]**

### B.E.S.T. Math Domains

| Domain Code | Domain Name                              | Grades     |
|-------------|------------------------------------------|------------|
| NSO         | Number Sense and Operations              | K–8        |
| FR          | Fractions                                | K–5        |
| AR          | Algebraic Reasoning                      | K–8        |
| M           | Measurement                              | K–5        |
| GR          | Geometric Reasoning (and Measurement)   | K–8        |
| DP          | Data Analysis and Probability            | K–8        |

> **Domain Naming Note:** FL B.E.S.T. uses different domain names than CCSS. There is no "Operations and Algebraic Thinking (OA)" domain — instead FL separates Number Sense and Operations (NSO) and Algebraic Reasoning (AR). Do NOT use CCSS domain names.

### Key Standards by Grade

| Grade | Priority Standards                                                                                               |
|-------|------------------------------------------------------------------------------------------------------------------|
| 3     | MA.3.NSO.1 (place value), MA.3.FR.1 (fractions as numbers), MA.3.AR.1 (multiplication), MA.3.M.1 (time/measurement) |
| 4     | MA.4.NSO.2 (multi-digit mult/div), MA.4.FR.1 (fraction equivalence), MA.4.GR.1 (angles), MA.4.DP.1 (data) |
| 5     | MA.5.NSO.2 (decimal operations), MA.5.FR.2 (fraction operations), MA.5.GR.2 (volume), MA.5.AR.2 (patterns) |
| 6     | MA.6.NSO.3 (rational numbers), MA.6.AR.1 (expressions), MA.6.AR.2 (equations), MA.6.GR.1 (area/surface area) |
| 7     | MA.7.NSO.1 (proportional reasoning), MA.7.AR.2 (proportional equations), MA.7.GR.1 (2D geometry), MA.7.DP.2 (probability) |
| 8     | MA.8.AR.1 (equations), MA.8.AR.3 (functions), MA.8.GR.1 (Pythagorean theorem), MA.8.DP.1 (scatter plots) |

## 3. TEST STRUCTURE

FAST Mathematics is administered in **2 sessions**.

```
+------------------------------------------------------------------+
|            FAST MATHEMATICS TEST STRUCTURE (Grades 3–8)         |
+----------------------------------+-------------------------------+
|   SESSION 1                      |   SESSION 2                   |
|   ~45 minutes                    |   ~45 minutes                 |
|                                  |                               |
|  MCQ + Fill-in Response          |  MCQ + Fill-in + Multi-Select |
|  + Multi-Select                  |  + Open Response              |
|                                  |                               |
|  NO calculator (Gr 3–5)          |  NO calculator (Gr 3–5)       |
|  Calculator restricted (Gr 6–8)  |  Calculator allowed (Gr 6–8) |
+----------------------------------+-------------------------------+
```

### Session Item Counts by Grade Band

| Session       | Grades 3–5                      | Grades 6–8                      |
|---------------|--------------------------------|--------------------------------|
| Session 1     | 18–22 MCQ/FR/MS (no calculator)| 18–22 MCQ/FR/MS (restricted calc)|
| Session 2     | 12–16 MCQ/FR/MS + 2–3 OR       | 12–16 MCQ/FR/MS + 2–3 OR (calc allowed)|

> **Calculator Policy Detail (Gr 6–8):** Session 1 has a no-calculator portion for all grades. In Grades 6–8, a handheld or online four-function calculator is available for Session 2.

## 5. ITEM TYPES

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Single correct answer                                   |
|  Machine scored                                          |
|  Both sessions                                           |
|  DOK 1–2                                                 |
+----------------------------------------------------------+
```

**MC Example (Grade 7, DOK 2, MA.7.AR.2.1 — Proportional Reasoning):**

A citrus grove in Florida produces 240 oranges per tree each season. At this rate, how many oranges will 15 trees produce?

- A. 255
- B. 1,600
- C. 3,500
- D. 3,600

*Correct Answer: D (240 × 15 = 3,600)*

---

### Fill-in Response (FR)

```
+----------------------------------------------------------+
|  FILL-IN RESPONSE — 1 point                              |
|                                                          |
|  Student types a numeric answer                          |
|  No partial credit                                       |
|  Machine scored                                          |
|  Accepts equivalent forms (e.g., 1/2 = 0.5)             |
|  Both sessions                                           |
+----------------------------------------------------------+
```

**FR Example (Grade 5, DOK 2, MA.5.FR.2.1 — Fraction Addition):**

*"A Florida orange weighs 3/8 pound. A grapefruit weighs 5/8 pound. What is the combined weight of the orange and grapefruit in pounds?"*

*Answer: 1 (or 8/8 or equivalent)*

---

### Multi-Select (MS)

```
+----------------------------------------------------------+
|  MULTI-SELECT — 1 point (all-or-nothing)                 |
|                                                          |
|  5–6 options                                             |
|  Student selects ALL correct answers (typically 2)       |
|  Machine scored; no partial credit                       |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**MS Example (Grade 6, DOK 2, MA.6.AR.1.2 — Expressions):**

Which TWO expressions are equivalent to 3(x + 4)?

- A. 3x + 4
- B. 3x + 12
- C. x + 12
- D. 12 + 3x
- E. 7x

*Correct Answers: B and D*

---

### Open Response (OR)

```
+----------------------------------------------------------+
|  OPEN RESPONSE — 0–4 points                              |
|                                                          |
|  Multi-part problem (Parts A and B minimum)              |
|  Requires showing work AND written explanation           |
|  DOK 2–3                                                 |
|  Human scored using OR rubric                            |
|  Session 2 only (2–3 per test)                           |
+----------------------------------------------------------+
```

**OR Example (Grade 8, DOK 3, MA.8.AR.3.2 + MA.8.DP.1.2 — Functions and Data):**

*"The table below shows the daily attendance at a Florida theme park during spring break week.*

| Day | Attendance |
|-----|-----------|
| 1   | 42,000    |
| 2   | 45,500    |
| 3   | 49,000    |
| 4   | 52,500    |

*Part A: Write a linear equation to represent the relationship between the day (x) and attendance (y). Show your work.*
*Part B: Using your equation, predict the attendance on Day 7. Show your work.*
*Part C: Explain what the rate of change in your equation means in the context of the problem."*

## 7. B.E.S.T. MATHEMATICAL THINKING AND REASONING STANDARDS (MTRs)

Florida's B.E.S.T. Standards include **Mathematical Thinking and Reasoning Standards (MTRs)**, the Florida-specific equivalent of CCSS Standards for Mathematical Practice.

| MTR # | MTR Name                                               | Assessment Application                                               |
|-------|--------------------------------------------------------|----------------------------------------------------------------------|
| MTR 1 | Mathematicians think about numbers and their properties| Number sense; mental math; estimation items                          |
| MTR 2 | Demonstrate understanding using representations        | Graph, table, model connections in OR items                          |
| MTR 3 | Complete tasks with mathematical fluency               | Efficient computation; session 1 fluency-focused MC items            |
| MTR 4 | Engage in discussions about math; explain reasoning    | OR items requiring written explanation of process                    |
| MTR 5 | Use patterns and structure to help understand math     | Pattern items; algebraic generalization in Gr 6–8                   |
| MTR 6 | Assess the reasonableness of solutions                 | Estimation; error analysis; check-your-work prompts                  |
| MTR 7 | Apply mathematics to real-world contexts               | Florida-specific contextual problems (citrus, tourism, hurricanes)   |

> **MTR vs. SMP:** The MTRs serve the same function as CCSS Standards for Mathematical Practice but are numbered and named differently. When designing FAST items, reference MTRs rather than SMPs. MTR 7 (real-world application) is the most visible in test items.

## 8. SCORING RUBRICS

### Open Response (OR) Rubric — 0–4 Points

| Score | Criteria                                                                                                                                                                                              |
|-------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 4     | All parts of the problem are correctly and completely addressed. Mathematical work is fully shown, clearly organized, and leads to correct answers. Written explanations are mathematically precise, use accurate vocabulary, and fully address the context. Units and labels are correct throughout. |
| 3     | Most parts of the problem are correctly addressed. Mathematical work is mostly complete and leads to mostly correct answers. A minor computational error may be present but the approach is sound. Written explanations demonstrate adequate mathematical understanding. |
| 2     | Some parts of the problem are correctly addressed. Mathematical work is partially complete or contains procedural errors. Student demonstrates partial understanding of the mathematical concepts. Written explanations are present but may be incomplete or imprecise. |
| 1     | Little correct mathematical work is shown. Student demonstrates minimal understanding of the mathematical task. Significant errors are present across most parts. Written explanations are absent or demonstrate confusion about the concept. |
| 0     | No correct mathematical work is shown. Response is blank, off-task, or demonstrates no understanding of the mathematical task.                                                                        |

## 10. CONTEXTUALIZATION — FLORIDA MATH

When generating real-world math contexts, prioritize authentic Florida settings:

### Recommended Math Contexts

| Context                             | Grade Band | Math Domains                                    |
|-------------------------------------|------------|-------------------------------------------------|
| Hurricane wind speed and track data | 6–8        | Statistics, proportional reasoning, functions   |
| Florida citrus harvest quantities   | 3–6        | Multiplication, fractions, ratios               |
| Theme park attendance statistics    | 5–8        | Large numbers, ratios, linear functions         |
| Florida population growth           | 6–8        | Percents, ratios, data analysis                 |
| Beach geometry (coastline, areas)   | 4–7        | Area, perimeter, measurement                    |
| Coral reef depth measurements       | 5–8        | Negative numbers, measurement, data             |
| Florida Turnpike tolls and distance | 5–8        | Unit rates, proportional relationships          |
| Manatee population data             | 5–8        | Data analysis, scatter plots, statistics        |
| Florida aquifer water levels        | 6–8        | Data analysis, functions, rates of change       |
| Everglades water flow measurements  | 5–8        | Fractions, measurement, rates                   |

### Sample Context Sentence Starters

- "During hurricane season, meteorologists tracked wind speeds at [X] miles per hour..."
- "A citrus farmer in Polk County harvested [X] pounds of oranges from [Y] trees..."
- "The table below shows daily attendance at a theme park in Orlando during..."
- "Florida's population grew from [X] million to [Y] million between [years]..."
- "A scientist measuring water depth at a coral reef found..."

## 11. QUALITY CHECKLIST

- [ ] Standard code uses B.E.S.T. format: MA.[Grade].[Domain].[Standard].[Benchmark]
- [ ] MTR alignment identified for OR items
- [ ] No CCSS standard codes or domain names used
- [ ] Calculator policy matches session (no calculator Gr 3–5; calc allowed Session 2 for Gr 6–8)
- [ ] OR items have at least two parts (Part A and Part B minimum)
- [ ] Part C of OR includes explanation/justification component
- [ ] Fill-in response accepts all equivalent forms
- [ ] Multi-Select exactly 2 correct answers from 5–6 options
- [ ] Real-world context is Florida-specific and grade-appropriate
- [ ] All numerical values produce clean, non-ambiguous answers
- [ ] Distractors reflect specific, identifiable student error types
- [ ] DOK level verified against actual cognitive demand

### Common Pitfalls

| Pitfall                               | Problem                                          | Fix                                                 |
|---------------------------------------|--------------------------------------------------|-----------------------------------------------------|
| Using CCSS domain names (OA, NBT)     | FL B.E.S.T. uses NSO, AR, GR, DP, FR            | Use B.E.S.T. domain codes only                      |
| Calculator in Session 1 (Gr 3–5)      | No calculator allowed at all for Grades 3–5      | Design all items to not require calculator Gr 3–5   |
| OR with only one part                 | FAST OR requires multi-part structure             | Minimum Part A and Part B                           |
| FR with ambiguous decimal/fraction    | System may not accept all equivalent forms        | Pre-test FR answer in test platform; list all forms |
| Generic context (no FL specificity)   | FL test values authentic FL contexts              | Use hurricanes, citrus, beaches, theme parks        |
| OR explanation prompt missing         | DOK 3 requires written justification              | Include "Explain what this means in context"        |
| B.E.S.T. standards confused with NGSSS| NGSSS was the previous FL standard set            | B.E.S.T. replaced NGSSS for math in 2020           |

## 12. PROMPT PATTERNS

The following five patterns reflect the most common FAST Mathematics item structures.

### Pattern 1: Contextual Computation (MC, DOK 2)
> "[Florida setting]. [Given information]. [Mathematical question requiring multi-step application]."
> (Options: correct answer + three specific error-type distractors)

### Pattern 2: Multi-Step Context (OR Part A, DOK 2)
> "A [Florida context] has [given data]. [Part A: computational task requiring setup + solve]. Show your work."

### Pattern 3: Rate of Change in Context (OR Part C, DOK 3)
> "Your equation has a [slope/rate/coefficient] of [value]. Explain what this number means in the context of [Florida scenario]."

### Pattern 4: Error Analysis (MC or OR, DOK 3)
> "[Student name] solved the problem and wrote [incorrect answer/work]. What error did [student] make? Find and show the correct answer."

### Pattern 5: Comparison with Justification (OR, DOK 3)
> "Two [Florida scenarios] are described: [Scenario A data] and [Scenario B data]. Which [option] is [more efficient/greater/better value]? Use mathematical evidence to justify your answer."
