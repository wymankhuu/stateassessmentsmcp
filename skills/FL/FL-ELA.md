## 1. OVERVIEW

| Field                | Details                                                                         |
|----------------------|---------------------------------------------------------------------------------|
| Assessment Name      | FAST ELA Reading (Florida Assessment of Student Thinking)                       |
| Administering Agency | Florida Department of Education (FLDOE) / AIR (American Institutes for Research)|
| Grades Covered       | 3, 4, 5, 6, 7, 8, 9, 10                                                        |
| Testing Windows      | Progress Monitoring 1 (PM1): October–November                                   |
|                      | Progress Monitoring 2 (PM2): February                                           |
|                      | Progress Monitoring 3 (PM3/Summative): April–May                               |
| Format               | Computer-based testing (CBT); adaptive in upper grades                          |
| Standards Framework  | Florida B.E.S.T. ELA Standards (Benchmarks for Excellent Student Thinking), 2020|
| Performance Levels   | 5 levels (1–5); Level 3 = proficient                                            |
| Replaces             | FSA (Florida Standards Assessment), replaced starting 2022–23                  |

> **CRITICAL NOTE:** FAST replaced FSA in the 2022–23 school year. FAST uses **B.E.S.T. Standards**, which are Florida-specific and NOT based on CCSS. Do NOT use CCSS codes for FAST items. Always use B.E.S.T. standard codes (e.g., ELA.5.R.1.1).

### Performance Levels

| Level | Label                      | Description                                                      |
|-------|----------------------------|------------------------------------------------------------------|
| 1     | Below Level 2              | Does not demonstrate foundational reading skills                 |
| 2     | Below Satisfactory         | Partially meets grade-level reading expectations                 |
| 3     | Satisfactory               | Meets grade-level reading expectations (proficient)             |
| 4     | Proficient                 | Reads above grade level with strong comprehension               |
| 5     | Mastery                    | Demonstrates advanced mastery of reading and analysis           |

### FAST vs. FSA Key Differences

| Feature                     | FAST ELA Reading      | FSA ELA Reading (former) |
|-----------------------------|----------------------|--------------------------|
| Standards                   | B.E.S.T.             | NGSSS / CCSS-influenced  |
| Number of items             | Fewer (~30–40)       | More (~50–60)            |
| Performance Task            | None                 | Writing PT component     |
| Testing frequency           | 3 windows/year       | 1 annual window          |
| Administration              | CBT adaptive         | CBT linear               |

## 2. STANDARDS FRAMEWORK

### Florida B.E.S.T. ELA Standards

Florida's B.E.S.T. ELA Standards were adopted in 2020 and are unique to Florida. Standard codes follow the format: **ELA.[Grade].[Strand].[Standard].[Benchmark]**

**Strand Overview:**

| Strand Code | Strand Name                                 |
|-------------|---------------------------------------------|
| R           | Reading                                     |
| W           | Writing                                     |
| C           | Communication                               |
| V           | Vocabulary                                  |
| F           | Foundational Skills (K–5)                   |

### Key B.E.S.T. Reading Standards — Literary Text (R.1)

| Standard     | Description                                                                                         |
|--------------|-----------------------------------------------------------------------------------------------------|
| ELA.X.R.1.1  | Analyze the elements of plot including exposition, rising action, climax, falling action, resolution |
| ELA.X.R.1.2  | Compare and contrast first and third-person narrators and how POV affects story                     |
| ELA.X.R.1.3  | Describe the development of theme in literary text through character, setting, and events            |
| ELA.X.R.1.4  | Analyze how author's use of figurative language, including connotation, creates meaning             |

### Key B.E.S.T. Reading Standards — Informational Text (R.2)

| Standard     | Description                                                                                         |
|--------------|-----------------------------------------------------------------------------------------------------|
| ELA.X.R.2.1  | Explain how text structure and features contribute to author's purpose                              |
| ELA.X.R.2.2  | Explain how an author's perspective influences the details in a text                                |
| ELA.X.R.2.3  | Explain how an author uses evidence to support central idea(s)                                      |
| ELA.X.R.2.4  | Track the development of an argument, identifying claims and supporting evidence                    |

### Key B.E.S.T. Vocabulary Standards (V)

| Standard     | Description                                                                                         |
|--------------|-----------------------------------------------------------------------------------------------------|
| ELA.X.V.1.1  | Use context clues, figurative language, and academic vocabulary to determine word meaning           |
| ELA.X.V.1.2  | Apply knowledge of Greek and Latin roots and affixes to determine word meaning                      |
| ELA.X.V.1.3  | Identify and explain idioms, adages, and proverbs                                                   |

> **B.E.S.T. Coding Note:** Replace X with the actual grade number. For example, the Grade 5 central idea standard is **ELA.5.R.2.3**. Never use generic CCSS codes like RI.5.2 — the FAST test is assessed using B.E.S.T. codes exclusively.

## 3. TEST STRUCTURE

FAST ELA Reading is administered in **2 sessions** across one or two days.

```
+-------------------------------------------------------------------+
|            FAST ELA READING TEST STRUCTURE (Grades 3–10)         |
+---------------------------------+---------------------------------+
|   SESSION 1                     |   SESSION 2                     |
|   ~45 minutes                   |   ~45 minutes                   |
|                                 |                                 |
|  LITERARY TEXT                  |  INFORMATIONAL TEXT             |
|  - 1–2 literary passages        |  - 1–2 informational passages   |
|  - Multiple Choice (MCQ)        |  - Multiple Choice (MCQ)        |
|  - Multi-Select (MS)            |  - Multi-Select (MS)           |
|  - Open Response (OR)           |  - Open Response (OR)          |
+---------------------------------+---------------------------------+
```

### Session Item Counts by Grade Band

| Session       | Grades 3–5              | Grades 6–8              | Grades 9–10             |
|---------------|------------------------|------------------------|------------------------|
| Session 1 (Literary) | 12–15 MCQ/MS + 1 OR | 14–17 MCQ/MS + 1 OR | 16–19 MCQ/MS + 1 OR |
| Session 2 (Info)     | 12–15 MCQ/MS + 1 OR | 14–17 MCQ/MS + 1 OR | 16–19 MCQ/MS + 1 OR |

> FAST is intentionally **shorter than FSA**. Fewer items reflect a more focused, higher-quality item set aligned to B.E.S.T. priority benchmarks.

## 5. ITEM TYPES

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Single correct answer                                   |
|  Machine scored                                          |
|  DOK 1–2                                                 |
|  Both sessions                                           |
+----------------------------------------------------------+
```

**MC Example (Grade 5, DOK 2, ELA.5.R.1.3 — Theme):**

*Passage excerpt: A young girl in Miami helps her grandmother preserve traditional Haitian recipes, even as her friends prefer American fast food.*

Which theme is BEST supported by the events in the passage?

- A. Hard work always leads to success
- B. Technology makes life easier for everyone
- C. Cultural traditions are worth preserving across generations
- D. People should always follow the advice of their elders

*Correct Answer: C*

---

### Multi-Select (MS)

```
+----------------------------------------------------------+
|  MULTI-SELECT — 1 point (all-or-nothing)                 |
|                                                          |
|  5–7 options                                             |
|  Student selects 2 or more correct answers               |
|  Partial credit NOT awarded — must get ALL correct       |
|  Machine scored                                          |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**MS Example (Grade 7, DOK 2, ELA.7.R.2.3 — Central Idea Evidence):**

*"Which TWO pieces of evidence from the article BEST support the central idea that Florida's coral reefs are endangered by rising ocean temperatures? Select two answers."*

- A. Florida has more than 700 miles of coastline
- B. Coral bleaching events have increased 400% since 1980
- C. Scuba diving is a popular tourist activity near the Keys
- D. Water temperatures in the Florida Straits rose 2°C in 30 years
- E. The Keys were established as a marine sanctuary in 1990

*Correct Answers: B and D*

---

### Open Response (OR)

```
+----------------------------------------------------------+
|  OPEN RESPONSE — 0–3 points                              |
|                                                          |
|  Written response (1–3 paragraphs typical)               |
|  Must cite textual evidence with elaboration             |
|  Human scored using OR rubric                            |
|  DOK 3                                                   |
|  1 per session (2 total per test)                        |
|  NO Performance Task component (unlike Smarter Balanced) |
+----------------------------------------------------------+
```

**OR Example (Grade 8, DOK 3, ELA.8.R.2.2 + ELA.8.R.2.3):**

*"The article 'The Everglades: America's Wetland' describes the challenges facing Florida's Everglades ecosystem. How does the author use evidence to support the argument that human intervention is both the cause of and solution to the Everglades' decline? Use evidence from the text to support your response."*

## 8. SCORING RUBRICS

### Open Response (OR) Rubric — 0–3 Points

The FAST OR rubric evaluates three traits: **Response**, **Evidence**, and **Elaboration**.

| Score | Response                                              | Evidence                                                | Elaboration                                              |
|-------|-------------------------------------------------------|----------------------------------------------------------|----------------------------------------------------------|
| 3     | Clearly and accurately addresses the prompt; demonstrates strong understanding of the text | Cites specific, accurate, and relevant textual evidence; evidence directly supports the response | Fully elaborates how evidence supports the response; demonstrates sophisticated analysis |
| 2     | Adequately addresses the prompt; demonstrates acceptable understanding of the text | Cites mostly accurate evidence; evidence is generally relevant but may be vague | Partially elaborates connection between evidence and response; some analysis present |
| 1     | Minimally addresses the prompt; demonstrates limited understanding of the text | Little or no textual evidence cited; evidence may be inaccurate or irrelevant | Little or no elaboration; response is largely a summary or simple retelling |
| 0     | Does not address the prompt; blank; off-topic; copied from passage; or incomprehensible | No evidence cited | No elaboration |

> **FAST OR Scoring Reminder:** All three traits (Response, Evidence, Elaboration) are scored holistically as a single score of 0–3. There is no separate trait scoring — the rubric describes what a 0, 1, 2, or 3 response looks like across all three dimensions simultaneously.

  - Include relevant evidence (may be paraphrased)

  - Include little or vague evidence
  - Lack elaboration or connection to prompt

## 11. QUALITY CHECKLIST AND COMMON PITFALLS

### Quality Checklist

- [ ] Standard code uses B.E.S.T. format: ELA.[Grade].[Strand].[Standard].[Benchmark]
- [ ] No CCSS codes used anywhere in item
- [ ] Passage Lexile is within grade-band range (see Section 7)
- [ ] MC options are plausible; no "trick" or obviously wrong choices
- [ ] Multi-Select requires exactly 2 correct answers from 5–7 options
- [ ] OR prompt includes clear analytical focus (not "summarize")
- [ ] OR prompt ends with evidence directive
- [ ] OR rubric anchor responses written before item is finalized
- [ ] Florida-specific context used where appropriate
- [ ] No Performance Task component (FAST does not have PT)
- [ ] Item does not reference FSA or former assessment structures
- [ ] DOK level verified against item cognitive demand

### Common Pitfalls

| Pitfall                                   | Problem                                              | Fix                                                       |
|-------------------------------------------|------------------------------------------------------|-----------------------------------------------------------|
| Using CCSS standard codes                 | FAST uses B.E.S.T., not CCSS                         | Always use ELA.[Grade].[Strand] format                    |
| Building a Performance Task component     | FAST has NO PT (unlike Smarter Balanced)             | Use OR items only; max 3 points per written response      |
| Treating FAST like FSA                    | FAST has fewer items, different standards             | Reference FAST specifications; do not copy FSA structure  |
| OR prompt that asks students to summarize | Summarizing is not DOK 3 analytical thinking         | Frame prompt around analysis, argument, or author purpose |
| Ignoring Florida's cultural diversity     | Test fairness requires representation                | Rotate across FL communities (Cuban, Haitian, Seminole, etc.) |
| Using generic "national" contexts         | Florida test values FL-specific authenticity          | Anchor passages in real FL places and FL communities      |
| MS item with 3+ correct answers from 5   | Students cannot reliably identify all-or-nothing      | Keep MS to exactly 2 correct answers from 5–7 options     |

## 12. PROMPT PATTERNS

The following five patterns reflect the most commonly tested item structures on FAST ELA Reading.

### Pattern 1: Theme Development (OR, DOK 3, R.1.3)
> "In '[passage title],' the author develops the theme that [theme]. How do the characters' [actions/decisions/experiences] throughout the story support this theme? Use evidence from the text to support your response."

### Pattern 2: Author's Purpose and Evidence (OR, DOK 3, R.2.3)
> "In the article '[title],' the author argues that [central claim]. How does the author use evidence to support this argument? Use specific details from the text to support your response."

### Pattern 3: Figurative Language and Meaning (MC, DOK 2, V.1.1)
> "Read this sentence from the passage: '[sentence with figurative language].' What does this [metaphor/simile/idiom] most likely mean?"

### Pattern 4: Point of View and Effect (MC/MS, DOK 2, R.1.2 or R.2.2)
> "How does the author's [first-person/third-person] point of view affect the reader's understanding of [event/character/idea]? Select [one/two] answer(s) that BEST explain this effect."

### Pattern 5: Text Structure and Author's Purpose (MC, DOK 2, R.2.1)
> "Why does the author include [specific section, paragraph, or feature] in the article? What is the author's purpose for organizing the text this way?"
