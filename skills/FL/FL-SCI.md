## 1. OVERVIEW

| Field                | Details                                                                           |
|----------------------|-----------------------------------------------------------------------------------|
| Assessment Name      | Florida Science Assessment (FAST Science)                                         |
| Administering Agency | Florida Department of Education (FLDOE) / AIR                                    |
| Grades Covered       | **Grade 5 and Grade 8 ONLY** (not all grades)                                    |
| Testing Window       | May (annual summative only; no PM windows for Science)                           |
| Format               | Computer-based testing (CBT), single session                                     |
| Duration             | Approximately 60–80 minutes                                                      |
| Standards Framework  | NGSSS — Next Generation Sunshine State Standards (Florida-specific, NOT NGSS)    |
| Performance Levels   | 5 levels (1–5); Level 3 = satisfactory/proficient                                |

> **CRITICAL NOTE:** Florida Science Assessment uses the **NGSSS (Next Generation Sunshine State Standards)**, which are Florida's own standards and are **NOT the same as NGSS (Next Generation Science Standards)**. Despite the similar name, these are completely different frameworks. Do NOT confuse NGSSS with NGSS or NY P-12 Science Standards.

> **GRADE NOTE:** Like NY Science, Florida Science Assessment tests only **Grade 5** and **Grade 8**. Do not generate items for Grades 3, 4, 6, or 7 for this assessment.

### Performance Levels

| Level | Label                | Description                                                           |
|-------|----------------------|-----------------------------------------------------------------------|

| 2     | Below Satisfactory   | Partially meets grade-level science expectations                      |
| 3     | Satisfactory         | Meets grade-level science expectations (proficient)                  |
| 4     | Proficient           | Performs above grade level; strong application of science concepts   |
| 5     | Mastery              | Demonstrates advanced mastery of grade-level science standards        |

## 2. STANDARDS FRAMEWORK

### NGSSS — Next Generation Sunshine State Standards (Science)

Florida's NGSSS were adopted in 2008 and are organized differently from both the old Sunshine State Standards and the newer NGSS. NGSSS standard codes follow the format: **SC.[Grade].[Body of Knowledge].[Big Idea].[Benchmark]**

**Example:** SC.5.L.17.1 = Science, Grade 5, Life Science, Big Idea 17, Benchmark 1

### Bodies of Knowledge

| Code | Body of Knowledge           |
|------|-----------------------------|
| N    | Nature of Science           |
| E    | Earth and Space Science     |
| P    | Physical Science             |
| L    | Life Science                |

### NGSSS vs. NGSS Comparison

| Feature                         | NGSSS (Florida)                           | NGSS (not used in FL)                        |
|---------------------------------|-------------------------------------------|----------------------------------------------|
| Adopted                         | 2008, Florida-specific                    | 2013, national framework                     |
| Structure                       | Bodies of Knowledge + Big Ideas           | Three Dimensions (DCI + SEP + CCC)           |
| Standard Code Format            | SC.[Grade].[N/E/P/L].[Big Idea].[Benchmark]| [Grade]-[Domain]-[Number]                  |
| Science Practices               | Nature of Science (Body N)                | Science and Engineering Practices (SEPs)     |
| Focus                           | Knowledge-based + inquiry                 | Phenomena-based + three-dimensional          |

## 3. TEST STRUCTURE

FAST Science is a **single session** assessment, unlike the multi-session NY and other FAST assessments.

```
+------------------------------------------------------------------+
|          FLORIDA SCIENCE ASSESSMENT STRUCTURE (Gr 5 & 8)         |
+------------------------------------------------------------------+
|   SINGLE SESSION — approximately 60–80 minutes                   |
|   Computer-based testing (CBT)                                   |
|                                                                  |
|   ~55–60 items total:                                            |
|   - Multiple Choice (MC): approximately 45–50 items             |
|   - Multi-Select (MS): approximately 8–12 items                 |
|                                                                  |
|   NO Constructed Response (CR)                                   |
|   NO Lab Practical component (unlike NY Science)                 |
|   ALL items are machine-scored                                   |
+------------------------------------------------------------------+
```

| Physical Science (Body P)             | 10–14         | 14–18         |
| Life Science (Body L)                 | 14–18         | 10–14         |
| **Total Items**                       | **~55**       | **~55**       |

## 5. ITEM TYPES

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Single correct answer                                   |
|  Machine scored                                          |
|  Scenario-based items include data tables, diagrams,     |
|  graphs, and Florida-specific phenomena                  |
|  Both Grade 5 and Grade 8                                |
+----------------------------------------------------------+
```

**MC Example (Grade 5, DOK 2, SC.5.L.17.1 — Florida Adaptations):**

Manatees are large marine mammals that live in Florida's warm coastal waters and rivers. During winter months, manatees gather near power plant warm water discharges to stay warm. What does this behavior BEST show about manatee adaptations?

- A. Manatees have adapted to eat aquatic plants only
- B. Manatees require warm water to maintain body temperature
- C. Manatees migrate to colder water in winter
- D. Manatees can survive in both freshwater and saltwater equally

*Correct Answer: B*

---

**MC Example (Grade 8, DOK 2, SC.8.P.9.2 — Physical vs. Chemical Change):**

A student placed a piece of iron outdoors in Florida's humid climate for two weeks. The student observed that the iron turned reddish-brown and its surface became rough and flaky. Which statement BEST explains the type of change that occurred?

- A. A physical change occurred because the shape of the iron changed
- B. A physical change occurred because the mass of the iron increased
- C. A chemical change occurred because a new substance (rust) was formed
- D. A chemical change occurred because the iron was broken into smaller pieces

*Correct Answer: C*

### Multi-Select (MS)

```
+----------------------------------------------------------+
|  MULTI-SELECT — 1 point (all-or-nothing)                 |
|                                                          |
|  5–6 options                                             |
|  Student selects ALL correct answers (typically 2)       |
|  Machine scored; no partial credit                       |
|  Scenario-based; often includes data                     |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**MS Example (Grade 8, DOK 2, SC.8.L.18.1 — Photosynthesis):**

Which TWO items are REQUIRED for photosynthesis to occur in plants?

- A. Oxygen
- B. Carbon dioxide
- C. Nitrogen
- D. Sunlight (light energy)
- E. Soil nutrients

*Correct Answers: B and D*

### Scenario-Based Items with Data

```
+------------------------------------------------------------------+
|  SCENARIO-BASED ITEM STRUCTURE                                   |
|                                                                  |
|  STIMULUS: 2–4 sentence scenario describing a Florida phenomenon |
|            OR a data table/graph/diagram                         |
|                                                                  |

|            scenario or data                                      |
|                                                                  |
|  COMMON DATA TYPES:                                              |

+------------------------------------------------------------------+
```

**Scenario-Based Example (Grade 5, DOK 2, SC.5.E.7.3 — Weather):**

*A student in Tampa recorded the following weather data over 5 days:*

| Day | Temperature (°F) | Precipitation | Barometric Pressure |
|-----|-----------------|---------------|---------------------|
| 1   | 85              | None          | 30.1 (High)         |
| 2   | 83              | None          | 29.8 (Falling)      |
| 3   | 78              | Heavy rain    | 29.2 (Low)          |
| 4   | 80              | Light rain    | 29.5 (Rising)       |
| 5   | 84              | None          | 30.0 (High)         |

*Based on the data table, what is the relationship between barometric pressure and precipitation?*

- A. High barometric pressure is associated with heavy rain
- B. Low barometric pressure is associated with clear weather
- C. Low barometric pressure is associated with precipitation
- D. There is no relationship between pressure and precipitation

*Correct Answer: C*

## 7. NGSSS vs. NGSS: A COMPARISON FOR ITEM WRITERS

This comparison is essential for avoiding the most common error in FL Science item development — treating NGSSS as if it were NGSS.

### Side-by-Side Comparison

| Feature                     | NGSSS (Florida — USE THIS)              | NGSS (NOT used in Florida)               |
|-----------------------------|------------------------------------------|------------------------------------------|
| Adopted by Florida           | YES — 2008                              | NO — Florida chose NOT to adopt NGSS     |
| Standard Code Example        | SC.5.L.17.1                             | 5-LS2-1                                  |
| Structure                    | Body of Knowledge > Big Idea > Benchmark| Performance Expectation with 3 dimensions|
| Science Practices            | Embedded in Nature of Science (Body N)  | Explicit SEPs (8 practices)              |
| Crosscutting Concepts        | Not explicitly labeled                  | Explicit CCCs (7 concepts)               |
| Assessment implications      | Content-focused; knowledge application  | Practice-focused; three-dimensional      |
| Used by NY?                  | NO — NY uses its own P-12 SLS (NGSS-aligned) | NY uses NGSS-aligned framework       |

> **KEY RULE:** When writing FL Science items, code standards as **SC.[Grade].[N/E/P/L].[BigIdea].[Benchmark]** — never use NGSS PE codes like "5-LS2-1."

## 8. SCORING

### Machine-Scored Only

Because the Florida Science Assessment uses only MC and Multi-Select items, **there are no rubrics** — all items are machine scored.

| Item Type    | Scoring Method  | Points |
|--------------|-----------------|--------|
| MC           | Machine scored  | 1 pt   |
| Multi-Select | Machine scored  | 1 pt (all-or-nothing) |
| CR           | N/A — none used | —      |

> **MS Scoring Note:** Multi-Select items award **1 point only when ALL correct answers are selected and NO incorrect answers are selected**. There is no partial credit. This differs from some other state assessments. Inform item reviewers that MS items can effectively "miss" a student who selects one of two correct answers.

### Suggested Anchoring Phenomena by Grade

**Grade 5 Phenomena:**
- "Every year, sea turtles return to the same Florida beaches to lay eggs at night — what adaptations allow them to navigate back to their birth beach?"
- "After Hurricane season, scientists noticed that algae blooms appeared in Tampa Bay — what caused this change in the ecosystem?"
- "Florida orange groves have been devastated by a bacterial disease spread by a tiny insect — how does one organism affect an entire ecosystem?"

- "When iron from a shipwreck off Key West was analyzed, it showed different forms of iron compounds than original samples — what changes occurred?"

## 11. QUALITY CHECKLIST AND COMMON PITFALLS

### Quality Checklist

- [ ] Grade verified as 5 or 8 ONLY (not other FL grades)
- [ ] Standard code uses NGSSS format: SC.[Grade].[N/E/P/L].[BigIdea].[Benchmark]
- [ ] No NGSS codes used anywhere in item
- [ ] No Constructed Response items (FAST Science is all machine-scored)
- [ ] No Lab Practical component (unlike NY Science)
- [ ] Florida-specific phenomenon used in scenario items
- [ ] Multi-Select has exactly 2 correct answers from 5–6 options
- [ ] All MC distractors reflect identifiable student misconceptions
- [ ] Data tables and graphs are clearly labeled with units
- [ ] Science content is accurate and reviewed by subject-matter expert
- [ ] DOK level matches cognitive demand of item
- [ ] Item avoids vocabulary beyond grade-level expectations

### Common Pitfalls

| Pitfall                                   | Problem                                           | Fix                                                  |
|-------------------------------------------|---------------------------------------------------|------------------------------------------------------|
| Using NGSS PE codes                       | Florida uses NGSSS, NOT NGSS                      | Use SC.[Grade].[N/E/P/L] format only                 |
| Writing CR items for FL Science           | FAST Science is 100% machine-scored               | Convert all CR to MC or MS format                    |
| Grades 3, 4, 6, 7 items                   | FL Science tests only Gr 5 and Gr 8               | Restrict items to Grades 5 and 8                     |
| Generic phenomena (not Florida-specific)  | FL items anchor in real Florida contexts          | Use manatees, Everglades, hurricanes, coral, etc.    |
| NGSSS confused with "old" Sunshine Standards| NGSSS is the CURRENT FL standard (not old)       | NGSSS adopted 2008; still in use for Science         |
| Lab Practical component added             | FL Science has no Lab Practical (unlike NY)       | Remove Lab Practical; all assessment is CBT          |
| MS with 3+ correct answers               | FL MS items use exactly 2 correct answers         | Redesign MS to have exactly 2 correct options        |
| Assuming FL uses NGSS three-dimensions   | NGSSS is not three-dimensional like NGSS          | Focus on knowledge + inquiry, not DCI/SEP/CCC model  |

## 12. PROMPT PATTERNS

The following five patterns reflect the most common FAST Science item structures at Grades 5 and 8.

### Pattern 1: Observation to Explanation (MC, DOK 2)
> "Scientists observed [Florida organism/phenomenon] doing [specific behavior/change]. Which explanation BEST describes why this occurred?"

### Pattern 2: Data Table Interpretation (MC or MS, DOK 2)
> "The table/graph below shows [Florida science data collected over time / in an experiment]. Based on the data, which [conclusion/statement/pattern] is BEST supported?"

### Pattern 3: Cause and Effect — Ecosystem (MC, DOK 2)
> "In the Everglades/Florida ecosystem, [change in one variable] occurred. What would MOST LIKELY be the effect on [another organism or part of the system]?"

### Pattern 4: Experimental Design and Inquiry (MC, DOK 2–3, Body N)
> "A student designed an experiment to test whether [variable] affects [outcome] in a Florida [context]. Which change would make the experiment MORE valid / What is the INDEPENDENT VARIABLE in this experiment?"

### Pattern 5: Physical/Chemical Change Application (MC, DOK 2, Body P)
> "A student in Florida observed [physical change or chemical change scenario]. Which statement BEST explains whether a physical or chemical change occurred, and WHY?"
