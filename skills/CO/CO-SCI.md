## 1. Overview

| Field | Detail |
|---|---|
| **Assessment Name** | Colorado Measures of Academic Success (CMAS) — Science |
| **Administering Agency** | Colorado Department of Education (CDE) |
| **Vendor** | Pearson |
| **Grades Tested** | **Grade 5**, **Grade 8**, **Grade 11** |
| **Testing Window** | March – April |
| **Delivery** | Computer-based; single session |
| **Standards** | Colorado Academic Standards for Science (incorporating NGSS) |
| **Score Scale** | 5 performance levels; scaled score varies by grade |
| **Reporting** | Individual Student Report; School, District, State aggregates |

> **CRITICAL NOTE:** CMAS Science is administered **only at Grades 5, 8, and 11**. Do not generate CMAS Science items for Grades 3, 4, 6, or 7.

> **CMAS and NGSS:** Colorado Academic Standards for Science fully incorporate the **Next Generation Science Standards (NGSS)** framework. All items must be three-dimensional: integrating **Disciplinary Core Ideas (DCI)**, **Science and Engineering Practices (SEP)**, and **Crosscutting Concepts (CCC)**.

### Performance Levels

| Level | Label | Description |
|---|---|---|
| 5 | **Exceeded Expectations** | Distinguished three-dimensional science understanding; expertly integrates DCI, SEP, and CCC |
| 4 | **Met Expectations** | Strong three-dimensional understanding; appropriately applies practices and crosscutting concepts |
| 3 | **Approached Expectations** | Moderate understanding; applies DCI content but inconsistently integrates SEP or CCC |
| 2 | **Partially Met Expectations** | Partial understanding; limited to surface-level application of science concepts |
| 1 | **Did Not Yet Meet Expectations** | Minimal understanding; limited to recall of isolated facts |

## 3. Test Structure

CMAS Science is a single-session, computer-based assessment. All items are scenario-based with data tables, diagrams, graphs, and models as stimuli.

```
+------------------------------------------------------------------+
|           CMAS SCIENCE STRUCTURE (Grades 5, 8, 11)               |
+------------------------------------------------------------------+
|  SINGLE SESSION                                                  |
|  Computer-Based, Fixed-Form                                      |
|  Approximately 90–120 minutes                                    |
|                                                                  |
|  ~40 items per grade                                             |
|                                                                  |
|  Item types:                                                     |
|    Selected Response (SR) — ~55–60% (~24 items)                 |
|    Constructed Response (CR) — ~20–25% (~8–10 items; 0–3 pts)   |
|    Technology Enhanced / Multi-Select — ~15–20% (~6–8 items)     |
+------------------------------------------------------------------+
```

### Grade-Level Test Specifications

| Specification | Grade 5 | Grade 8 | Grade 11 |
|---|---|---|---|
| Total Items (approx.) | ~38–42 | ~38–42 | ~38–42 |
| Selected Response | ~22–26 | ~22–26 | ~22–26 |
| Multi-Select / TE | ~6–8 | ~6–8 | ~6–8 |
| Constructed Response | ~6–10 | ~6–10 | ~6–10 |
| Testing Time | 90–120 min | 90–120 min | 90–120 min |

> **Three-Dimensional Requirement:** Every CMAS Science item must integrate at least one **DCI**, one **SEP**, and one **CCC**. Items that test DCI content in isolation are not aligned to the Colorado Academic Standards for Science.

## 5. Item Types & Formats

### Selected Response (SR)

```
+----------------------------------------------------------+
|  SELECTED RESPONSE — 1 point                             |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Scenario, diagram, data table, or model stimulus        |
|  Must integrate DCI + SEP + CCC                          |
|  Machine scored                                          |
+----------------------------------------------------------+
```

**SR Example (Grade 8, DOK 2, MS-ESS2-2 — Geoscience Processes):**

Scientists studying the Rocky Mountains in Colorado found that the same type of limestone found on mountain peaks at 12,000 feet also appears at the bottom of valleys at 5,000 feet. Which explanation BEST accounts for this observation?

A. Wind carried limestone particles from the peaks to the valleys over millions of years
B. Tectonic forces uplifted ancient seafloor sedimentary rock to different elevations
C. Glaciers deposited identical limestone at both locations during the last ice age
D. Volcanic eruptions distributed limestone evenly across all elevations

*Correct Answer: B*
*Alignment: MS-ESS2-2 | SEP: Constructing Explanations | CCC: Stability and Change | DOK 2*

---

**SR Example (Grade 5, DOK 2, 5-LS2-1 — Ecosystem Matter Flow):**

A diagram shows: Sunlight -> Alpine wildflowers -> Pikas -> Red-tailed Hawks

Which statement BEST explains the role of alpine wildflowers in this Rocky Mountain ecosystem model?

A. Alpine wildflowers receive energy from pikas through a food chain
B. Alpine wildflowers capture energy from the sun and store it in their cells
C. Alpine wildflowers are decomposers that break down dead organisms in the tundra
D. Alpine wildflowers get energy from the rocky soil through their root system

*Correct Answer: B*
*Alignment: 5-LS2-1 | SEP: Developing and Using Models | CCC: Energy and Matter | DOK 2*

---

### Constructed Response (CR)

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE — 0–3 points                       |
|                                                          |
|  Written explanation using evidence from the stimulus    |
|  Stimulus always provided (data, diagram, scenario)      |
|  Must demonstrate three-dimensional reasoning            |
|  Human scored                                            |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**CR Example (Grade 8, DOK 3, MS-ESS3-3 — Human Impact):**

*Stimulus: A data table showing nitrogen and phosphorus levels, dissolved oxygen, and fish population counts in the Colorado River at three locations: upstream of Denver, near Denver, and 50 miles downstream. Near Denver, nutrient levels are highest and dissolved oxygen and fish counts are lowest.*

*"Using data from the table, construct an explanation for the relationship between nutrient levels and fish populations at different points along the Colorado River. Include specific evidence from the data and explain the cause-and-effect relationships involved."*

---

**CR Example (Grade 11, DOK 3, HS-ESS2-2 — Earth Systems Feedbacks):**

*Stimulus: Graph showing average annual temperature and snowpack depth in the Colorado Rockies from 1960–2020, with temperature rising and snowpack declining.*

*"Using evidence from the graph, analyze how changes in temperature have affected snowpack in the Colorado Rockies. Explain how reduced snowpack could create feedback effects on other Earth systems, including water availability and vegetation patterns downstream."*

## 7. Three-Dimensional Design

Every CMAS Science item must reflect all three NGSS dimensions simultaneously.

### Three-Dimensions Alignment Guide

| Dimension | What It Is | Example in CMAS Items |
|---|---|---|
| **DCI** (What students know) | Disciplinary science content | Rocky Mountain geology; alpine tundra ecology; Colorado River watershed; chemical reactions; energy transfer |
| **SEP** (What students do) | How scientists work | Analyze population data; construct explanations from evidence; use models to predict ecosystem changes |
| **CCC** (Lens of thinking) | Cross-domain thinking tools | Cause and effect; patterns; energy and matter; structure and function; systems and system models |

### Crosscutting Concepts by Grade Band

| CCC | Grade 5 Emphasis | Grade 8 Emphasis | Grade 11 Emphasis |
|---|---|---|---|
| Patterns | Seasonal cycles in Rocky Mountain ecosystems; rock layer patterns | Weather patterns; population trend data | Periodic table patterns; evolutionary change |
| Cause and Effect | Food chain removal; erosion processes | Mining environmental impacts; chemical reactions | Climate feedbacks; homeostasis disruption |
| Energy and Matter | Food webs; water cycle in mountain systems | Chemical reactions; thermal transfer in geothermal areas | Metabolic pathways; Earth energy systems |
| Structure and Function | Plant adaptations to alpine conditions | Mineral properties; cell structures | DNA and protein structure; organ systems |
| Systems and System Models | Mountain ecosystems; water cycle | Colorado River watershed; Earth systems | Climate systems; biological feedback loops |

## 8. Scoring Rubrics

### Constructed Response (CR) Rubric — 0–3 Points

| Score | Criteria |
|---|---|
| 3 | Response accurately addresses the science concept; demonstrates clear three-dimensional understanding (DCI + SEP or CCC evident); includes specific, relevant evidence from the stimulus; explanation is complete, accurate, and logically connected |
| 2 | Response addresses the science concept with partial accuracy; shows understanding of the DCI but only partially integrates a practice or crosscutting concept; evidence present but may be incomplete |
| 1 | Response minimally addresses the science concept; shows limited understanding; little or no evidence from stimulus; explanation vague or contains science inaccuracies |
| 0 | Response does not address the concept; blank; off-topic; restates stimulus without explanation |

### CR Scoring Notes

- **Evidence from the stimulus is required.** Responses relying solely on prior knowledge without referencing the provided data earn a maximum of 1 point.
- **Three-dimensional reasoning earns full credit.** A Score 3 integrates content knowledge (DCI) with at least one SEP or CCC.
- **Misconceptions reduce the score.** A significant scientific misconception drops the response by one score point.

## 10. Contextualization — Colorado Science

When generating CMAS Science items, prioritize authentic Colorado natural settings:

### Colorado Science Context Guide

| Setting / Phenomenon | Grade | Science Domain | PE Alignment |
|---|---|---|---|
| Rocky Mountain geology and plate tectonics | 5, 8, 11 | Earth Science | 5-ESS2, MS-ESS2, HS-ESS2 |
| Colorado River watershed and water cycle | 5, 8 | Earth/Life Science | 5-ESS2, MS-ESS3 |
| Alpine tundra ecology above treeline | 5, 8 | Life Science | 5-LS2, MS-LS2 |
| Colorado mining environmental impacts (acid mine drainage) | 8, 11 | Earth/Physical Science | MS-ESS3, MS-PS1 |
| Denver air quality and urban atmosphere | 8, 11 | Earth/Physical Science | MS-ESS3, HS-ESS2 |
| Great Sand Dunes formation and geology | 5, 8 | Earth Science | 5-ESS2, MS-ESS2 |
| Rocky Mountain snowpack and climate change | 8, 11 | Earth Science | MS-ESS3, HS-ESS2 |
| Colorado wildlife adaptations (pika, ptarmigan, elk) | 5, 8 | Life Science | 5-LS2, MS-LS2 |
| Geothermal features (hot springs) | 8, 11 | Physical/Earth Science | MS-PS3, HS-PS3 |
| Colorado wildfire ecology and forest recovery | 5, 8, 11 | Life/Earth Science | 5-LS2, MS-LS2, HS-LS2 |
| Mesa Verde archaeological preservation (chemical weathering) | 8 | Physical/Earth Science | MS-PS1, MS-ESS2 |
| Colorado solar energy and renewable resources | 8, 11 | Physical Science | MS-PS3, HS-PS3 |

### Suggested Anchoring Phenomena by Grade

**Grade 5 Phenomena:**
- "Every spring, wildflowers bloom on the alpine tundra above 11,000 feet in Rocky Mountain National Park, even though the growing season is only six weeks long. How do these plants survive in such harsh conditions?"
- "The Great Sand Dunes in southern Colorado are the tallest sand dunes in North America, yet they are surrounded by mountains. What processes created and maintain these dunes?"
- "Students visiting a Colorado mountain stream noticed that water was orange near an old mine entrance. What could explain this color change?"

**Grade 8 Phenomena:**
- "Scientists have recorded that the American pika, a small mammal living above treeline in the Colorado Rockies, has disappeared from many lower-elevation sites over the past 30 years. What ecological factors explain this pattern?"
- "Water quality data from the Colorado River shows that dissolved mineral concentrations increase significantly as the river flows from the mountains through agricultural regions. What mechanisms cause this change?"
- "Denver's average summer temperature is 3–5 degrees warmer than surrounding rural areas. What factors contribute to this urban heat island effect?"

**Grade 11 Phenomena:**
- "Acid mine drainage from abandoned gold mines in the Colorado mountains has turned some streams bright orange for over a century. What chemical processes are responsible, and how do they affect downstream ecosystems?"
- "Colorado's snowpack has declined by approximately 20% over the past 50 years, while average winter temperatures have increased. Analyze how this creates feedback effects across multiple Earth systems."

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] Grade verified as 5, 8, or 11 ONLY
- [ ] PE code is a valid NGSS Performance Expectation
- [ ] Item is three-dimensional: DCI + SEP + CCC all identified
- [ ] Anchoring phenomenon is authentic and Colorado-relevant where possible
- [ ] Stimulus (data table/graph/diagram) has clear labels, units, and realistic data
- [ ] CR prompt directs students to use evidence from the stimulus
- [ ] All distractors represent real misconceptions (not obviously wrong)
- [ ] MS items specify how many answers to select (TWO/THREE)
- [ ] Score 3 anchor response written before finalizing CR item
- [ ] Science content is accurate and reflects current scientific understanding
- [ ] Vocabulary is grade-appropriate

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Writing items for Grades 3, 4, 6, or 7 | CMAS Science only at Grades 5, 8, 11 | Restrict to tested grades |
| DCI-only items (no SEP or CCC) | CMAS requires three-dimensional items | Always embed a practice and crosscutting concept |
| CR prompts without evidence directive | Students may respond without citing data | Include "Use evidence from the [data/graph/diagram]" |
| Generic science phenomena not anchored to Colorado | CMAS benefits from Colorado contexts | Use Rocky Mountain, Colorado River, Denver contexts |
| MS items with only 2 options in 4 total | Too easy to guess | Use 5–6 options with exactly 2–3 correct |

## 12. Prompt Patterns

### Pattern 1: Data-to-Conclusion (SR, DOK 2)
> "The [graph / table / diagram] below shows [Colorado science scenario]. Based on the data, which [conclusion / explanation / pattern] is BEST supported?"

### Pattern 2: Phenomenon Explanation (CR, DOK 3)
> "Scientists observed [Colorado-anchored phenomenon]. Using evidence from the [data / model / diagram], construct an explanation for [specific science focus]. Explain the [cause-and-effect / energy flow / pattern] relationship."

### Pattern 3: Model Evaluation (SR or MS, DOK 2–3)
> "A student made a model showing [Colorado science concept]. Which statement BEST describes what the model shows about [DCI focus]?"

### Pattern 4: Investigation Design (CR, DOK 3)
> "A scientist in Colorado wants to investigate whether [variable] affects [outcome] in [Colorado ecosystem]. Describe a procedure the scientist could follow. Include what would be measured and how the scientist would know if the variable made a difference."

### Pattern 5: Evidence-Based Argument (CR, DOK 3)
> "Two students disagree about [Colorado science claim]. Student A says [misconception]. Student B says [accurate claim]. Using evidence from the [data / diagram], explain which student is correct and why."

### Pattern 6: Human Impact and Solutions (MS or CR, DOK 2–3)
> "Human activities have [impacted Colorado environment]. Select the TWO strategies that BEST [monitor / reduce / address] this impact."
