| Field | Detail |

| **Administering Agency** | Colorado Department of Education (CDE) |

| **Score Scale** | 650–850 scale score (varies by grade); 5 performance levels |
| **Reporting** | Individual Student Report; School, District, State aggregates |

> **CMAS and PARCC:** CMAS ELA is derived from the **Partnership for Assessment of Readiness for College and Careers (PARCC)** design. Item types, task models, and rubrics reflect the PARCC architecture: Literary Analysis Task (LAT), Research Simulation Task (RST), and Narrative Writing Task (NWT). Colorado uses **Colorado Academic Standards** (CAS), which are aligned to CCSS ELA, with passages reflecting Colorado geography, culture, and history.

### Performance Levels

| Level | Label | Description |
|---|---|---|
| 5 | **Exceeded Expectations** | Student demonstrates distinguished command of the knowledge and skills in the Colorado Academic Standards; advanced analysis and evidence use |
| 4 | **Met Expectations** | Student demonstrates strong command of the knowledge and skills; thorough analysis with relevant evidence |
| 3 | **Approached Expectations** | Student demonstrates moderate command; partial analysis with some evidence use |
| 2 | **Partially Met Expectations** | Student demonstrates partial command; limited analysis and inconsistent evidence |
| 1 | **Did Not Yet Meet Expectations** | Student demonstrates minimal command; significant gaps in grade-level expectations |

## 2. Standards Framework

> **Reference:** See `_shared/ccss_ela_framework.md` for full CCR Anchor Standards and grade-by-grade progressions. Colorado uses the **Colorado Academic Standards (CAS)**, which incorporate Common Core ELA standards. Standards are referenced using CAS codes (e.g., CAS.ELA.RL.3.1).

### Reading Literature (RL) — Key Standards by Grade Band

| Standard | Gr 3–5 Focus | Gr 6–8 Focus | Gr 11 Focus |
|---|---|---|---|
| **CAS.RL.1** — Key details & inference | Explicit details; simple inference from text | Cite textual evidence; analyze what text says explicitly vs. inferentially | Cite strong and thorough textual evidence to support analysis |
| **CAS.RL.2** — Theme / central idea | Determine message or lesson; summarize | Analyze theme development; how it emerges through characters and plot | Analyze how themes develop and interact over the course of a text |
| **CAS.RL.3** — Character, setting, events | Describe characters' traits and responses | Analyze how dialogue and incidents reveal character and advance plot | Analyze impact of author's choices regarding story elements |
| **CAS.RL.4** — Word meaning | Determine meaning of words; recognize figurative language | Analyze figurative and connotative meanings; word choice and tone | Determine multiple meanings; analyze how word choice shapes meaning and tone |
| **CAS.RL.6** — Point of view | Identify narrator's point of view | Analyze how differences in POV create effects like suspense or humor | Analyze a case in which grasping point of view requires distinguishing the author's from the characters' |

### Reading Informational Text (RI) — Key Standards by Grade Band

| Standard | Gr 3–5 Focus | Gr 6–8 Focus | Gr 11 Focus |
|---|---|---|---|
| **CAS.RI.1** — Key details & inference | Quote accurately; draw inferences | Cite textual evidence supporting analysis | Cite strong and thorough textual evidence; determine where text leaves matters uncertain |
| **CAS.RI.3** — Connections & relationships | Explain relationships between events, ideas, or concepts | Analyze how a text makes connections between ideas | Analyze a complex set of ideas or sequence of events |
| **CAS.RI.6** — Author's purpose & point of view | Identify author's purpose | Determine author's point of view; analyze how purpose shapes content | Determine an author's point of view or purpose; analyze rhetoric |
| **CAS.RI.8** — Argument & evidence | Explain how reasons support points | Trace and evaluate argument; assess whether reasoning is sound | Delineate and evaluate reasoning in seminal U.S. texts |
| **CAS.RI.9** — Compare/integrate information | Compare multiple texts on same topic | Analyze how two texts treat similar topics differently | Analyze foundational U.S. documents of historical and literary significance |

### Writing Standards

| Standard | Focus | DOK |
|---|---|---|
| **CAS.W.1** — Argument/Opinion | Write arguments with clear claims, evidence, and reasoning | 3–4 |
| **CAS.W.2** — Informative/Explanatory | Develop topics with facts, details, definitions, examples | 3 |
| **CAS.W.3** — Narrative | Establish situation; develop narrator/characters; use narrative techniques | 3–4 |
| **CAS.W.7** — Research | Conduct short research projects; gather relevant information | 3 |

## 3. Test Structure

CMAS ELA uses the PARCC task model architecture with three distinct task types administered across multiple sessions.

```
+------------------------------------------------------------------+
|              CMAS ELA STRUCTURE (Grades 3–8, 11)                 |
+------------------------------------------------------------------+
|  LITERARY ANALYSIS TASK (LAT)                                    |
|  ~75–90 minutes                                                   |
|                                                                  |
|  1–2 literary passages                                            |
|  Items: SR, MS, EBSR, TE                                         |
|  Prose Constructed Response (PCR) — literary analysis essay       |
|                                                                  |
+------------------------------------------------------------------+
|  RESEARCH SIMULATION TASK (RST)                                  |
|  ~75–90 minutes                                                   |
|                                                                  |
|  2–3 informational source texts (articles, data, excerpts)       |
|  Items: SR, MS, EBSR, TE                                         |
|  Prose Constructed Response (PCR) — research-based essay          |
|                                                                  |
+------------------------------------------------------------------+
|  NARRATIVE WRITING TASK (NWT)                                    |
|  ~75–90 minutes                                                   |
|                                                                  |
|  1 literary or informational stimulus passage                     |
|  Items: SR, MS, EBSR, TE                                         |
|  Prose Constructed Response (PCR) — narrative essay               |
|                                                                  |
+------------------------------------------------------------------+
```

## 5. Item Types & Formats

### Selected Response (SR)

```
+----------------------------------------------------------+
|  SELECTED RESPONSE — 1 point                             |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Passage-dependent; always tied to a stimulus            |
|  Machine scored                                          |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**SR Example (Grade 6 Informational, DOK 3, CAS.RI.6.6):**

*[After reading an article about the history of mining in Colorado's mountain towns]*

What is the author's MAIN purpose in writing this article?

A. To persuade readers that mining should resume in Colorado's mountain communities
B. To entertain readers with exciting stories about gold rush adventurers
C. To inform readers about how the mining industry shaped the development and culture of Colorado's mountain towns
D. To warn readers about the environmental dangers of living near abandoned mines

*Correct Answer: C*
*Alignment: CAS.ELA.RI.6.6 | Reading Informational Text | DOK 2*

---

### Multi-Select Response (MS)

```
+----------------------------------------------------------+
|  MULTI-SELECT RESPONSE — 1 point                         |
|                                                          |
|  5–8 options; select exactly 2 or 3 correct answers      |
|  Full credit only; partial credit not awarded            |
|  Machine scored                                          |
+----------------------------------------------------------+
```

**MS Example (Grade 5 Literary, DOK 2, CAS.RL.5.3):**

*[After reading a short story about a family hiking to the summit of Pikes Peak]*

Select the TWO details from the story that BEST show how the narrator's feelings about the hike change from the beginning to the end of the story.

A. "The parking lot at the trailhead was already crowded when we arrived before dawn."
B. "My legs felt like they were filled with concrete, and I told Dad I wanted to turn back at the halfway point."
C. "Standing at the summit, watching the sunrise paint the plains below us, I understood why they call it America's Mountain."
D. "Dad packed extra water bottles and energy bars in his backpack."
E. "The trail wound through groves of bristlecone pines that had been growing for centuries."

*Correct Answers: B, C*
*Alignment: CAS.ELA.RL.5.3 | Reading Literary Text | DOK 2*

---

### Evidence-Based Selected Response (EBSR)

```
+----------------------------------------------------------+
|  EVIDENCE-BASED SELECTED RESPONSE — 2 points            |
|                                                          |
|  Part A: Inference or analysis (1 pt)                   |
|  Part B: Text evidence supporting Part A (1 pt)          |
|  Machine scored                                          |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**EBSR Example (Grade 8 Informational, DOK 3, CAS.RI.8.8):**

*[After reading an argumentative essay about whether Colorado should restrict water use from the Colorado River]*

**Part A:** Which statement BEST describes the author's central argument in this essay?

A. The Colorado River provides enough water for all communities if managed properly
B. Colorado must implement stricter water-use regulations because increasing drought and population growth threaten the river's long-term sustainability
C. The Colorado River Compact should be abolished because it is outdated
D. Water shortages are primarily caused by agricultural irrigation and can be solved by reducing farming

**Part B:** Which sentence from the essay BEST supports your answer to Part A?

A. "The river's headwaters begin high in the Rocky Mountains, fed by snowmelt each spring."
B. "Several communities have voluntarily reduced their lawn watering schedules during summer months."
C. "With snowpack levels declining by 20% over the past two decades and Colorado's population projected to grow by another million residents, the gap between water supply and demand will only widen without enforceable conservation measures."
D. "The Colorado River Compact of 1922 divided water rights among seven states."

*Correct Answers: Part A: B | Part B: C*
*Alignment: CAS.ELA.RI.8.8 | Reading Informational Text | DOK 3*

+----------------------------------------------------------+

|                                                          |

### Prose Constructed Response (PCR)

```
+----------------------------------------------------------+
|  PROSE CONSTRUCTED RESPONSE — 0–4 points                 |
|                                                          |
|  Multi-paragraph written response to passage(s)         |
|  LAT: Literary analysis essay                            |
|  RST: Research-based argumentative/informational essay   |
|  NWT: Narrative continuation or original narrative       |
|  Scored on a single 0–4 holistic rubric                  |
|  Human scored by trained raters                          |
+----------------------------------------------------------+
```

**PCR Prompt Example — RST (Grade 7, CAS.W.7.1):**

*[Sources provided: Article 1 on the history of Mesa Verde cliff dwellings; Article 2 on current preservation challenges; Data table on visitor impact at Mesa Verde National Park]*

You have read three sources about Mesa Verde National Park and the challenges of preserving its ancient cliff dwellings. Write an essay that argues whether the park should limit the number of visitors allowed each year to protect these irreplaceable structures. Use evidence from at least two of the three sources to support your argument. Be sure to acknowledge a counterclaim.

**PCR Prompt Example — NWT (Grade 5, CAS.W.5.3):**

*[After reading a story about a young prospector during the Colorado gold rush]*

The story ends with the narrator arriving at a mining camp in the mountains. Write a continuation of the story that describes what happens next. Use details from the passage to develop the characters and setting, and include descriptive details that help the reader picture the scene.

## 8. Scoring Rubrics

### Prose Constructed Response (PCR) Rubric — 0–4 Points (Holistic)

| Score | Criteria |
|---|---|
| 4 | **Thorough understanding** of the text(s). Response is well-organized and includes specific, relevant evidence. Analysis is accurate, insightful, and fully developed. For narrative: effective use of narrative techniques, sensory details, and clear event sequence. Conventions errors minimal and do not interfere. |
| 3 | **Adequate understanding** of the text(s). Response is organized and includes relevant evidence, though analysis may not be fully developed. For narrative: adequate narrative techniques with generally clear sequence. Some conventions errors but meaning is clear. |
| 2 | **Partial understanding** of the text(s). Response includes some evidence but analysis is superficial or uneven. Organization may be inconsistent. For narrative: limited narrative techniques; sequence may be unclear. Conventions errors may occasionally interfere with meaning. |
| 1 | **Minimal understanding** of the text(s). Response includes little or no relevant evidence. Analysis is vague or inaccurate. For narrative: minimal narrative development. Frequent conventions errors interfere with meaning. |
| 0 | Blank, copied text, off-topic, or entirely in a language other than English. |

### PCR Scoring Notes

- **Evidence from text is required.** Responses relying solely on prior knowledge without referencing provided passages earn a maximum of 1 point.
- **RST PCR** must integrate evidence from at least two sources for a score of 3 or 4.
- **NWT PCR** must use details from the stimulus passage and demonstrate narrative techniques (dialogue, description, pacing).

- "Should more students have the chance to visit Colorado's national parks?" (Opinion)

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] Colorado Academic Standards (CAS) code verified
- [ ] PARCC task type correctly identified (LAT, RST, or NWT)
- [ ] EBSR Part B is a quote that directly supports Part A (not just same topic)
- [ ] MS items specify exact number of answers to select (TWO/THREE)
- [ ] PCR prompt is open-ended enough for student voice
- [ ] PCR scored on 0–4 holistic rubric (not trait-based)
- [ ] Passage Lexile matches grade-band range
- [ ] RST sources include at least one non-prose source (graph, data table, image)
- [ ] Colorado context incorporated where appropriate (geography, ecology, culture)
- [ ] Distractors represent authentic student misconceptions (not trivially wrong)
- [ ] DOK level matches the actual cognitive demand of the question
- [ ] Grade 11 items reflect appropriate text complexity and analytical depth

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| EBSR Part B that supports a different answer | Part B must directly support Part A's correct answer | Cross-check: does Part B quote only make sense given Part A answer? |
| PCR prompts with only one correct interpretation | Essay needs room for student perspective | Keep prompts debatable or open-ended |
| Using 12-point trait-based FW rubric instead of 4-point holistic PCR | CMAS uses PARCC-style 0–4 holistic PCR rubric | Always use 0–4 holistic scale |
| RST sources all the same format (three articles) | PARCC RST includes varied source types | Include data tables, graphs, or images as at least one RST source |
| Forgetting Grade 11 | CMAS tests Grade 11 unlike some states | Include Grade 11 in test specifications |
| Generic Midwest context | Colorado has distinct geography and culture | Use Rocky Mountains, Denver, Mesa Verde, Colorado River contexts |

## 12. Prompt Patterns

### Pattern 1: Central Idea / Theme (SR or EBSR, DOK 2–3)
> "What [central idea / theme] does the [passage / author] develop? Which detail from the text BEST supports this [idea / theme]?"

### Pattern 2: Author's Craft (SR, DOK 3)
> "How does the author's use of [figurative language / structure / word choice / point of view] in [this section / paragraph #] affect the [meaning / tone / reader's understanding of ____]?"

### Pattern 3: Evidence Selection (EBSR Part B)
> "Which [sentence / detail] from the [passage] BEST supports your answer to Part A?"

### Pattern 4: Research Simulation — Multi-Source Argument (PCR, DOK 4)
> "Using evidence from at least two of the three sources, write an argumentative essay about [Colorado-relevant debatable issue]. Be sure to acknowledge a counterclaim."

### Pattern 5: Narrative Writing Task (PCR, DOK 3–4)
> "Write a [continuation / narrative] based on the passage. Use details from the text to develop [characters / setting / plot]. Include narrative techniques such as dialogue, description, and pacing."

### Pattern 6: Literary Analysis Task (PCR, DOK 3–4)
> "Write an essay analyzing how the author uses [literary device / structure / characterization] to develop [theme / central idea] in the passage. Use specific evidence from the text to support your analysis."

### Pattern 7: Multi-Select Evidence (MS, DOK 2)
> "Select the TWO [details / sentences / examples] from the text that BEST [support / show / explain] [specific focus]."

### Pattern 8: Compare Texts (SR or EBSR, DOK 3)
> "Both sources discuss [common topic]. How does [Source 1] treat this topic differently from [Source 2]?"
