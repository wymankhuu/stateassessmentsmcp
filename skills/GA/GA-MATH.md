> **Georgia Milestones Mathematics** assesses the Georgia Standards of Excellence (GSE) for Mathematics. The test includes Multiple Choice (MC), Multi-Select (MS), Constructed Response (CR), and Extended Response (ER) items. Items emphasize conceptual understanding, procedural fluency, and application of mathematical reasoning.

### Performance Levels

| Level | Label | Description |
|---|---|---|
| 1 | **Beginning Learner** | Student does not yet demonstrate proficiency in grade-level mathematics standards |
| 2 | **Developing Learner** | Student demonstrates partial proficiency; needs additional support |
| 3 | **Proficient Learner** | Student demonstrates grade-level proficiency in the mathematics standards |
| 4 | **Distinguished Learner** | Student demonstrates advanced proficiency beyond grade-level expectations |

> **Item-writing target:** "Proficient Learner" performance. Items should require genuine application of GSE at the expected DOK level.

## 5. Item Types & Formats

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Single correct answer                                   |
|  Machine scored                                          |
|  Sections 1 and 2                                        |
+----------------------------------------------------------+
```

**MC Example (Grade 5, DOK 2, MGSE5.NF.4 — Multiply Fractions):**

A Georgia peach orchard covers 3/4 of an acre. A farmer plants peach trees on 2/3 of the orchard. What fraction of an acre has peach trees?

A. 5/7
B. 6/12
C. 1/2
D. 2/4

*Correct Answer: C (3/4 × 2/3 = 6/12 = 1/2)*
*Alignment: MGSE5.NF.4 | DOK 2*

---

**MC Example (Grade 7, DOK 2, MGSE7.RP.2 — Proportional Relationships):**

The MARTA train in Atlanta travels 45 miles in 1.5 hours during a morning route. At this constant rate, how far will the train travel in 2.5 hours?

A. 67.5 miles
B. 75 miles
C. 90 miles
D. 112.5 miles

*Correct Answer: B (Rate = 45/1.5 = 30 mph; 30 × 2.5 = 75)*
*Alignment: MGSE7.RP.2 | DOK 2*

---

### Multi-Select (MS)

```
+----------------------------------------------------------+
|  MULTI-SELECT (MS) — 1 point                             |
|                                                          |
|  5–6 options                                             |
|  Student selects ALL correct answers (typically 2)       |
|  Machine scored; all-or-nothing                          |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**MS Example (Grade 6, DOK 2, MGSE6.EE.1):**

Which TWO expressions are equivalent to 4³?

A. 4 × 3
B. 4 × 4 × 4
C. 3 × 3 × 3 × 3
D. 64
E. 12

*Correct Answers: B and D*

### Constructed Response (CR)

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE (CR) — 0–2 points                  |
|                                                          |
|  Student must show work and/or provide a brief           |
|  written explanation                                     |
|  Human scored using CR rubric                            |
|  DOK 2–3                                                 |
|  Section 2 only                                          |
+----------------------------------------------------------+
```

**CR Example (Grade 6, DOK 2, MGSE6.RP.3 — Percentages):**

A store in Atlanta is having a sale where all items are 25% off the original price. A pair of shoes originally costs $68. What is the sale price of the shoes? Show your work.

---

### Extended Response (ER)

```
+----------------------------------------------------------+
|  EXTENDED RESPONSE (ER) — 0–4 points                    |
|                                                          |
|  Multi-part problem or rich application                  |
|  Requires show work AND written explanation              |
|  Higher DOK — strategic thinking, justify reasoning      |
|  Human scored using ER rubric                            |
|  Section 2 only                                          |
+----------------------------------------------------------+
```

**ER Example (Grade 8, DOK 3, MGSE8.F.2 + MGSE8.EE.7):**

*The MARTA transit authority tracks daily ridership on two bus routes. Route A follows the equation y = 150x + 2,400, where x is the number of weeks since January 1 and y is the weekly ridership. Route B data is shown in the table:*

| Weeks (x) | Route B Ridership (y) |
|---|---|
| 0 | 3,000 |
| 2 | 3,240 |
| 4 | 3,480 |
| 6 | 3,720 |

*Part A: Write an equation to represent Route B's ridership. Show your work.*

*Part B: Which route has a greater rate of ridership increase per week? Explain how you determined your answer using mathematical evidence.*

*Part C: After how many weeks will both routes have the same ridership? Show your work and explain what this means in context.*

## 6. Depth of Knowledge (DOK)

| DOK | Label | Math Application Examples |
|---|---|---|
| 1 | Recall & Reproduction | Compute 3/4 × 8; identify a geometric shape; convert units; recall a formula |
| 2 | Skills & Concepts | Solve a two-step word problem; explain why a solution method works; apply a ratio to a real-world context |
| 3 | Strategic Thinking | Design a solution plan; justify reasoning; analyze a student error; compare two solution methods; generalize a pattern |
| 4 | Extended Thinking | (Not typically assessed on Georgia Milestones Math; reserved for extended projects) |

### DOK Alignment by Item Type

| Item Type | Typical DOK | Notes |
|---|---|---|
| MC | 1–2 | Most MC items are DOK 1–2; Section 1 emphasizes DOK 1 |
| MS | 2 | Requires identifying multiple correct elements |
| CR | 2–3 | Requires showing work and brief explanation |
| ER | 3 | Multi-part; requires justification and mathematical reasoning |

## 7. Mathematical Practices

The GSE Mathematics incorporates the **Standards for Mathematical Practice (SMP)**, which should be embedded across all item types.

| SMP | Practice | Assessment Application |
|---|---|---|
| 1 | Make sense of problems; persevere in solving | Multi-step ER items; complex word problems |
| 2 | Reason abstractly and quantitatively | Contextual problems requiring decontextualization (e.g., MARTA ridership to equations) |
| 3 | Construct viable arguments; critique reasoning | CR/ER items requiring explanation or error analysis |
| 4 | Model with mathematics | Real-world Georgia contexts (peach production, transit data, geographic dimensions) |
| 5 | Use appropriate tools strategically | Calculator use decisions; reference sheet use |
| 6 | Attend to precision | Labeling units; exact vs. approximate answers |
| 7 | Look for and make use of structure | Pattern recognition; algebraic reasoning items |
| 8 | Look for and express regularity in repeated reasoning | Generalization items; function tables |

## 8. Scoring Rubrics

### Constructed Response (CR) Rubric — 0–2 Points

| Score | Criteria |
|---|---|
| 2 | Response shows correct mathematical work AND arrives at the correct answer. Units and labels are included where required. Work is clear and organized. |
| 1 | Response shows a correct mathematical approach or setup but contains a computational error OR shows the correct answer without sufficient work shown. Partial understanding is demonstrated. |
| 0 | Response shows no correct mathematical approach; answer is incorrect with no supporting work; response is blank or completely off-task. |

### Extended Response (ER) Rubric — 0–4 Points

| Score | Criteria |
|---|---|
| 4 | All parts of the problem are correctly and completely addressed. Mathematical work is thorough, clearly shown, and leads to correct answers. Written explanations are mathematically sound, use accurate vocabulary, and demonstrate deep understanding. Units/labels are correct throughout. |
| 3 | Most parts of the problem are correctly addressed. Mathematical work is mostly correct with minor computational errors. Written explanations demonstrate solid understanding. One part may have a minor error or be slightly incomplete. |
| 2 | Some parts of the problem are correctly addressed. Mathematical work shows a generally correct approach but contains errors. Written explanations demonstrate partial understanding. At least one part is correct. |
| 1 | Minimal correct mathematical work is shown. Student demonstrates limited understanding of the concepts involved. Multiple significant errors are present, or only a small portion of the task is addressed. Explanations are weak or missing. |
| 0 | No correct mathematical work is shown; response demonstrates no understanding of the mathematical task; response is blank or completely off-task. |

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] Standard code uses MGSE format (not raw CCSS codes)
- [ ] Calculator policy matches section (no calculator in Section 1; permitted in Section 2 for Gr 5–8)
- [ ] CR and ER items include "Show your work" directive
- [ ] ER items have at least two parts (Part A and Part B minimum)
- [ ] Real-world context is authentic and Georgia-specific where appropriate
- [ ] All numerical values produce clean, non-ambiguous computations
- [ ] Distractors for MC reflect specific, identifiable student error types
- [ ] DOK level is verified against item cognitive demand
- [ ] Units are clearly specified; labels required where appropriate
- [ ] No grade-inappropriate content (e.g., no algebra in Gr 3)
- [ ] Item type matches the correct point value (MC=1, MS=1, CR=0–2, ER=0–4)
- [ ] Formulas used are consistent with any provided reference materials

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Calculator allowed in Section 1 | Section 1 is no-calculator for all grades | Design Section 1 items with manageable computation |
| Using CCSS codes without MGSE prefix | Georgia uses GSE, not raw CCSS | Always use MGSE prefix codes |
| ER with only one part | Georgia Milestones ER requires multi-part structure | Ensure Part A + Part B minimum |
| Answers requiring complex rounding | Creates ambiguity for partial credit in CR | Design problems with clean answers |
| Generic context (not Georgia-specific) | Georgia Milestones values authentic state settings | Anchor in MARTA data, peach farms, Stone Mountain, etc. |
| CR/ER explanation prompt missing | DOK 3 requires justification component | Add "Explain how you determined your answer" to CR/ER |
| MS with 3+ correct answers | Georgia Milestones MS items use exactly 2 correct | Design MS with exactly 2 correct from 5–6 options |

## 12. Prompt Patterns

### Pattern 1: Contextual Computation (MC, DOK 2)
> "[Georgia context]. [Student/person] needs to find [quantity]. What is [quantity]?"
> (Options: correct answer + three error-type distractors)

### Pattern 2: Show Work — Application (CR, DOK 2)
> "A [Georgia setting] has [given information]. [Question requiring multi-step math]. Show your work."

### Pattern 3: Multi-Part ER with Explanation (ER, DOK 3)
> "[Georgia data scenario with table or graph].
> Part A: [Computational or procedural task]. Show your work.
> Part B: [Reasoning or justification task]. Use mathematical evidence to support your answer."

### Pattern 4: Error Analysis (CR or MC, DOK 3)
> "[Student name] solved the following problem and got [incorrect answer]. [Student's work shown]. Explain the error [student] made and find the correct answer."

### Pattern 5: Comparison and Generalization (ER, DOK 3)
> "Two [Georgia contexts] are described. [Data for each]. Which [option] is [better/greater/more efficient]? Use mathematical evidence to justify your answer."

### Pattern 6: Data Interpretation (MC or MS, DOK 2)
> "[Data table or graph from Georgia context]. Based on the data, which [statement / conclusion / value] is correct?"
