## 1. Overview

| Field | Detail |
|---|---|
| **Assessment Name** | Georgia Milestones — Science |
| **Administering Agency** | Georgia Department of Education (GaDOE) |
| **Vendor** | AIR (American Institutes for Research) |

| **Testing Window** | April–May (summative) |
| **Delivery** | Computer-based (online); paper accommodations available |
| **Standards** | Georgia Standards of Excellence (GSE) for Science |
| **Score Scale** | Scale score; 4 performance levels |
| **Item Types** | Multiple Choice (MC, 1 pt) and Constructed Response (CR, 0–2 pts) |
| **Reporting** | Individual Student Report; School, District, State aggregates |

> **GRADE NOTE:** Georgia Milestones Science is administered at **Grade 5, Grade 8, and EOC Biology** only. Do not generate items for Grades 3, 4, 6, or 7 for this assessment.

> **STANDARDS NOTE:** Georgia uses the **Georgia Standards of Excellence (GSE) for Science**, which are Georgia-specific standards. These are NOT the same as NGSS (Next Generation Science Standards). GSE Science standards use the format S[Grade][Domain][#] (e.g., S5L1, S8P1).

### Performance Levels

| Level | Label | Description |
|---|---|---|
| 1 | **Beginning Learner** | Student does not yet demonstrate proficiency in grade-level science standards |
| 2 | **Developing Learner** | Student demonstrates partial proficiency; needs additional support |
| 3 | **Proficient Learner** | Student demonstrates grade-level proficiency in science standards |
| 4 | **Distinguished Learner** | Student demonstrates advanced proficiency beyond grade-level expectations |

## 2. Standards Framework

### Georgia Standards of Excellence (GSE) for Science

Georgia's GSE for Science are organized by content domains with standards and elements. Standard codes follow the format: **S[Grade][Domain abbreviation][Standard number]** with sub-elements lettered (a, b, c, etc.).

**Example:** S5L1a = Science, Grade 5, Life Science, Standard 1, Element a

### Content Domains

| Code | Domain | Grades |
|---|---|---|
| E | Earth Science | 5, 8 |
| P | Physical Science | 5, 8 |
| L | Life Science | 5, 8, Biology EOC |

### Grade 5 Priority GSE Science Standards

| Standard Code | Description |
|---|---|
| S5P1 | Explain the difference between a physical change and a chemical change |
| S5P2 | Explain the difference between a mixture and a solution |
| S5P3 | Investigate the electricity, magnetism, and their relationship |
| S5L1 | Classify organisms into groups and relate how they determined the groups with how and why scientists use classification |
| S5L2 | Recognize that offspring can resemble parents in inherited traits and learned behaviors |
| S5L3 | Diagram and label parts of various cells (plant, animal, single-celled organisms) |
| S5L4 | Relate how microorganisms benefit or harm larger organisms |
| S5E1 | Identify surface features of the Earth caused by constructive and destructive processes |
| S5E2 | Recognize the physical attributes of stars in the night sky |

### Grade 8 Priority GSE Science Standards

| Standard Code | Description |
|---|---|
| S8P1 | Examine the scientific view of the nature of matter |
| S8P2 | Be familiar with the concept of force and motion |
| S8P3 | Investigate relationship between force, mass, and the motion of objects |
| S8P4 | Explore the wave nature of sound and electromagnetic radiation |
| S8P5 | Recognize characteristics of gravity, electricity, and magnetism as major kinds of forces |
| S8L1 | Distinguish between cells, tissues, organs, organ systems, and organisms |
| S8L2 | Relate how organisms reproduce to the survival of the species |
| S8L3 | Analyze how biological traits are passed on to successive generations |
| S8L4 | Relate changes in organisms over time to changes in the environment |
| S8E1 | Understand the geologic processes that shape the Earth |
| S8E2 | Investigate weather systems and climate |

### GSE vs. NGSS Comparison

| Feature | GSE (Georgia — USE THIS) | NGSS (NOT used in Georgia) |
|---|---|---|
| Adopted by Georgia | YES — Georgia-specific | NO — Georgia did NOT adopt NGSS |
| Standard Code Example | S5L1a | 5-LS2-1 |
| Structure | Domain > Standard > Element | Performance Expectation with 3 dimensions |
| Science Practices | Embedded in standards/inquiry expectations | Explicit SEPs (8 practices) |
| Crosscutting Concepts | Not explicitly labeled | Explicit CCCs (7 concepts) |
| Assessment focus | Knowledge-based + inquiry | Practice-based + three-dimensional |

> **KEY RULE:** When writing GA Science items, code standards as **S[Grade][Domain][Standard#]** — never use NGSS PE codes like "5-LS2-1."

## 3. Test Structure

Georgia Milestones Science is a **single session** assessment administered on one day.

```
+------------------------------------------------------------------+
|       GEORGIA MILESTONES SCIENCE STRUCTURE (Gr 5, 8, Bio EOC)    |
+------------------------------------------------------------------+
|   SINGLE SESSION — approximately 90–120 minutes                  |
|   Computer-based testing (CBT)                                   |
|                                                                  |
|   ~55–65 items total:                                            |

|   - Constructed Response (CR): approximately 2–4 items           |
|                                                                  |

+------------------------------------------------------------------+
```

## 5. Item Types & Formats

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Single correct answer                                   |
|  Machine scored                                          |
|  Scenario-based items include data tables, diagrams,     |
|  graphs, and Georgia-specific phenomena                  |
|  Both Grade 5 and Grade 8                                |
+----------------------------------------------------------+
```

**MC Example (Grade 5, DOK 2, S5L4 — Microorganisms):**

In the Okefenokee Swamp, scientists study bacteria that break down dead plant material in the water. How do these bacteria MOST benefit the swamp ecosystem?

A. They provide food for fish to eat directly
B. They release nutrients back into the water and soil for living plants to use
C. They clean the water by removing all organisms
D. They prevent new plants from growing in the swamp

*Correct Answer: B*
*Alignment: S5L4 | DOK 2*

---

**MC Example (Grade 8, DOK 2, S8E1 — Geologic Processes):**

The Georgia Piedmont region is known for its red clay soil and rolling hills. Which geologic process is MOST responsible for shaping the current landscape of the Piedmont?

A. Volcanic eruptions depositing new rock layers
B. Weathering and erosion wearing down ancient mountains over millions of years
C. Glaciers carving valleys through the region
D. Earthquakes lifting the land to form new mountains

*Correct Answer: B*
*Alignment: S8E1 | DOK 2*

### Constructed Response (CR)

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE (CR) — 0–2 points                  |
|                                                          |
|  Short written response (2–4 sentences)                  |
|  Must reference data, evidence, or scientific concepts   |
|  Human scored using CR rubric                            |
|  DOK 2–3                                                 |
|  2–4 CR items per test                                   |
+----------------------------------------------------------+
```

**CR Example (Grade 5, DOK 3, S5E1 — Earth's Surface Features):**

*A student studies photos of Georgia's barrier islands taken 20 years apart. The photos show that the shoreline has moved significantly inland on the eastern side of the island.*

Using your knowledge of constructive and destructive processes, explain what most likely caused the change in the island's shoreline. Include at least one specific process in your answer.

---

**CR Example (Grade 8, DOK 3, S8L4 — Organisms and Environment):**

*Scientists studying wildlife in the Okefenokee Swamp observed that a particular species of frog has developed a slightly different coloring than the same species found in the Georgia Piedmont region.*

Using your knowledge of how organisms change over time, explain how the environment of the Okefenokee Swamp could have contributed to this difference in coloring. Use scientific reasoning in your response.

**Scenario-Based Example (Grade 8, DOK 2, S8E2 — Weather):**

*A student in Atlanta recorded weather data for one week in April:*

| Day | Temperature (°F) | Humidity (%) | Wind Direction | Precipitation |
|---|---|---|---|---|
| Monday | 72 | 45 | NW | None |
| Tuesday | 68 | 55 | S | None |
| Wednesday | 65 | 78 | SE | Light rain |
| Thursday | 58 | 92 | SE | Heavy rain |
| Friday | 70 | 50 | NW | None |

Based on the data, which statement BEST explains the weather pattern observed during the week?

A. A warm front moved through the area on Wednesday and Thursday
B. A cold front passed through the area, bringing rain followed by clearing
C. Atlanta experienced a hurricane during the middle of the week
D. The changing wind direction had no effect on the weather

*Correct Answer: B*

## 7. GSE vs. NGSS: A Comparison for Item Writers

This comparison is essential for avoiding the most common error in GA Science item development — treating GSE as if it were NGSS.

### Side-by-Side Comparison

| Feature | GSE (Georgia — USE THIS) | NGSS (NOT used in Georgia) |
|---|---|---|
| Adopted by Georgia | YES — Georgia-specific | NO — Georgia chose NOT to adopt NGSS |
| Standard Code Example | S5L1a | 5-LS2-1 |
| Structure | Domain > Standard > Elements | Performance Expectation with 3 dimensions |
| Science Practices | Embedded in inquiry expectations | Explicit SEPs (8 practices) |
| Crosscutting Concepts | Not explicitly labeled | Explicit CCCs (7 concepts) |
| Assessment implications | Content-focused; knowledge + inquiry | Practice-focused; three-dimensional |

> **KEY RULE:** When writing GA Science items, code standards as **S[Grade][Domain][Standard#]** — never use NGSS PE codes.

### Common Standard Code Errors

| Incorrect | Correct | Why |
|---|---|---|
| 5-LS2-1 | S5L2 | NGSS code used instead of GSE |
| SC.5.L.17.1 | S5L1 | Florida NGSSS code used instead of GSE |
| 5-ESS2-1 | S5E1 | NGSS code used instead of GSE |

## 8. Scoring

### Multiple Choice (MC) Scoring

| Item Type | Scoring Method | Points |
|---|---|---|
| MC | Machine scored | 1 pt |

### Constructed Response (CR) Rubric — 0–2 Points

| Score | Criteria |
|---|---|
| 2 | Response demonstrates a thorough understanding of the scientific concept. The explanation is accurate and complete, using relevant scientific vocabulary. Evidence or reasoning directly supports the answer. |
| 1 | Response demonstrates a partial understanding of the scientific concept. The explanation is partially accurate but may be incomplete or contain minor errors. Some scientific reasoning is present but may not fully support the answer. |
| 0 | Response demonstrates no understanding of the scientific concept. The explanation is inaccurate, irrelevant, or missing. No scientific reasoning is provided. Response may be blank or off-topic. |

## 10. Contextualization — Georgia Science

Georgia's unique ecology, geology, and environment provide rich, authentic phenomena for science assessment items.

### GA Science Context Guide by Grade

| Context / Phenomenon | Grade | Domain | GSE Standards |
|---|---|---|---|
| Okefenokee Swamp ecology (food webs, decomposition, biodiversity) | 5, 8 | Life Science (L) | S5L1, S5L4, S8L4 |
| Georgia Piedmont geology (red clay, erosion, weathering) | 5, 8 | Earth Science (E) | S5E1, S8E1 |
| Barrier island ecosystems (Cumberland, Jekyll, Sapelo Island) | 5, 8 | Life/Earth (L/E) | S5L1, S5E1, S8L4, S8E1 |
| Georgia wildlife (black bears, loggerhead turtles, gopher tortoises) | 5, 8 | Life Science (L) | S5L1, S5L2, S8L4 |
| Savannah River watershed (water quality, flow, ecosystems) | 5, 8 | Earth/Life (E/L) | S5E1, S8E1, S8L4 |
| Georgia climate and weather patterns (severe storms, humidity, seasons) | 5, 8 | Earth Science (E) | S5E1, S8E2 |
| Georgia forests (longleaf pine ecosystem, controlled burns) | 5, 8 | Life Science (L) | S5L1, S5L4, S8L4 |
| Chattahoochee River and Atlanta water supply | 8 | Earth Science (E) | S8E1 |
| Georgia coastal erosion and sea level change | 8 | Earth Science (E) | S8E1 |
| Physical/chemical changes in Georgia industries (kaolin mining, paper mills) | 5, 8 | Physical Science (P) | S5P1, S8P1 |

### Suggested Anchoring Phenomena by Grade

**Grade 5 Phenomena:**
- "Scientists studying the Okefenokee Swamp noticed that certain bacteria turn dead plant material into nutrients that help other organisms grow — how do microorganisms benefit this ecosystem?"
- "A student on a field trip to Jekyll Island collected rocks from two different locations: one from the beach and one from a wooded trail. The rocks looked very different — what processes caused these differences?"
- "A farmer in south Georgia noticed that offspring of her chickens had slightly different feather patterns than the parent birds — how can offspring differ from their parents?"
- "During a science investigation, a student mixed sand and iron filings together. Another student dissolved salt in water. Which student created a mixture and which created a solution?"

**Grade 8 Phenomena:**
- "The Georgia Piedmont region has deep red clay soil, while the coastal plain has sandy soil — what geologic processes created these different soil types?"
- "Scientists studying loggerhead sea turtles on Georgia's barrier islands noticed that the turtles' nesting behavior has shifted northward over the past 30 years — what environmental changes could explain this shift?"
- "Water quality tests on the Savannah River showed different chemical compositions upstream vs. downstream of a factory — what evidence would help determine if a physical or chemical change occurred?"
- "During a thunderstorm in Atlanta, a student observed lightning and then heard thunder several seconds later — what explains the delay between seeing and hearing the storm?"

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] Grade verified as 5, 8, or Biology EOC ONLY (not other GA grades)
- [ ] Standard code uses GSE format: S[Grade][Domain][Standard#]
- [ ] No NGSS codes used anywhere in item
- [ ] Georgia-specific phenomenon used in scenario items
- [ ] MC has exactly 4 options with 1 correct answer
- [ ] CR prompt requires scientific explanation with reasoning
- [ ] All MC distractors reflect identifiable student misconceptions
- [ ] Data tables and graphs are clearly labeled with units
- [ ] Science content is accurate and grade-appropriate
- [ ] DOK level matches cognitive demand of item
- [ ] Item avoids vocabulary beyond grade-level expectations
- [ ] CR scoring uses 0–2 rubric (not 0–4 or other scales)

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Using NGSS PE codes | Georgia uses GSE, NOT NGSS | Use S[Grade][Domain][Standard#] format only |
| Grades 3, 4, 6, 7 items | GA Science tests only Gr 5, 8, and Bio EOC | Restrict items to tested grades |
| Generic phenomena (not Georgia-specific) | GA items should anchor in real Georgia contexts | Use Okefenokee, Piedmont, barrier islands, Savannah River, etc. |
| CR scored on 0–4 scale | GA Milestones Science CR uses 0–2 rubric | Use 0–2 scoring only |
| Confusing GSE with NGSS three-dimensions | GSE is not three-dimensional like NGSS | Focus on knowledge + inquiry, not DCI/SEP/CCC model |
| Lab Practical component added | GA Milestones Science has no Lab Practical | All assessment is CBT; no hands-on lab component |
| Items requiring outside knowledge | Items should be answerable from scenario + grade-level science | Ensure all needed information is in the stimulus or within GSE expectations |

## 12. Prompt Patterns

### Pattern 1: Observation to Explanation (MC, DOK 2)
> "Scientists observed [Georgia organism/phenomenon] doing [specific behavior/change]. Which explanation BEST describes why this occurred?"

### Pattern 2: Data Table Interpretation (MC, DOK 2)
> "The table/graph below shows [Georgia science data collected over time / in an experiment]. Based on the data, which [conclusion/statement/pattern] is BEST supported?"

### Pattern 3: Cause and Effect — Ecosystem (MC, DOK 2)
> "In the [Okefenokee Swamp / Georgia Piedmont / barrier island ecosystem], [change in one variable] occurred. What would MOST LIKELY be the effect on [another organism or part of the system]?"

### Pattern 4: Scientific Explanation — CR (DOK 2–3)
> "Using your knowledge of [scientific concept], explain [how / why] [Georgia phenomenon or observation]. Use scientific reasoning in your response."

### Pattern 5: Experimental Design and Inquiry (MC, DOK 2–3)
> "A student designed an experiment to test whether [variable] affects [outcome] in a Georgia [context]. Which change would make the experiment MORE valid? / What is the INDEPENDENT VARIABLE in this experiment?"

### Pattern 6: Classification and Comparison (MC, DOK 1–2)
> "A student collected samples from [Georgia location]. Which characteristic would BEST be used to classify [organisms / materials / processes] into groups?"
