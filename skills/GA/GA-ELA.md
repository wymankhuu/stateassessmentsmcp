> **Georgia Milestones** replaced the CRCT in 2014–2015. The assessment includes both End-of-Grade (EOG) tests for Grades 3–8 and End-of-Course (EOC) tests for high school. ELA is structured with two distinct sections: Reading/Evidence-Based Analysis and Writing/Language Conventions.

### Performance Levels

| Level | Label | Description |
|---|---|---|
| 1 | **Beginning Learner** | Student does not yet demonstrate proficiency in the grade-level standards; significant support needed |
| 2 | **Developing Learner** | Student demonstrates partial proficiency; additional instruction and support needed |
| 3 | **Proficient Learner** | Student demonstrates grade-level proficiency in the standards |
| 4 | **Distinguished Learner** | Student demonstrates advanced proficiency beyond grade-level expectations |

> **Item-writing target:** "Proficient Learner" performance. Items should require genuine application of GSE at the expected DOK level — not mere recall.

## 2. Standards Framework

> Georgia Milestones ELA is aligned to the **Georgia Standards of Excellence (GSE) for English Language Arts**, adopted in 2015. GSE are Georgia's own standards, developed from the state's review of national frameworks and tailored for Georgia students.

### GSE ELA Strands

| Strand | Focus | Grade Emphasis |
|---|---|---|
| **Reading Literary (RL)** | Fiction, poetry, drama; character, theme, structure, craft | All grades |
| **Reading Informational (RI)** | Nonfiction comprehension; central idea, evidence, argument, text structure | All grades |
| **Writing (W)** | Narrative, informational, argumentative composition; writing process | All grades; explicit in Extended Writing |
| **Language (L)** | Grammar, conventions, vocabulary acquisition, standard English usage | All grades; assessed in Section 2 |

### Key GSE Standards by Grade Band

| Standard Code | Description | Grade Band | DOK |
|---|---|---|---|
| ELAGSE3RL1 | Ask and answer questions to demonstrate understanding; refer explicitly to text | 3 | 1–2 |
| ELAGSE4RL2 | Determine a theme of a story, drama, or poem from details in the text | 4 | 2–3 |
| ELAGSE5RI6 | Analyze multiple accounts of the same event or topic, noting similarities and differences | 5 | 3 |
| ELAGSE6RL3 | Describe how a story's or drama's plot unfolds and how characters respond | 6 | 2–3 |
| ELAGSE7RI8 | Trace and evaluate the argument and specific claims in a text; assess reasoning and evidence | 7 | 3 |
| ELAGSE8RL4 | Determine the meaning of words and phrases including figurative and connotative meanings; analyze impact of word choices | 8 | 2–3 |
| ELAGSE6-8W1 | Write arguments to support claims with clear reasons and relevant evidence | 6–8 | 3–4 |

### Key Writing / Language GSE

| Standard Code | Description | DOK |
|---|---|---|
| ELAGSE3-8W3 | Write narratives to develop real or imagined experiences | 3–4 |
| ELAGSE3-8W2 | Write informative/explanatory texts to examine a topic and convey ideas | 3–4 |
| ELAGSE3-8L1 | Demonstrate command of the conventions of standard English grammar and usage | 1–2 |
| ELAGSE3-8L2 | Demonstrate command of the conventions of standard English capitalization, punctuation, and spelling | 1–2 |

## 3. Test Structure

Georgia Milestones ELA is divided into **two sections** within a single administration. Section 1 focuses on Reading and Evidence-Based Analysis; Section 2 focuses on Writing and Language Conventions.

```
+------------------------------------------------------------------+
|       GEORGIA MILESTONES ELA STRUCTURE (Grades 3–8)              |
+------------------------------------------------------------------+
|  SECTION 1: READING / EVIDENCE-BASED ANALYSIS                   |
|  ┌────────────────────────────────────────────┐                  |
|  │ Passage Set 1 (Literary) → MC, SRE, CR    │                  |
|  │ Passage Set 2 (Informational) → MC, SRE   │                  |
|  │ Passage Set 3 (Literary or Paired) → MC, CR│                 |
|  │ Passage Set 4 (Informational) → MC, MS    │                  |
|  └────────────────────────────────────────────┘                  |
|                                                                  |
|  SECTION 2: WRITING / LANGUAGE CONVENTIONS                       |
|  ┌────────────────────────────────────────────┐                  |
|  │ Language items: MC, MS (grammar, usage,    │                  |
|  │ punctuation, vocabulary)                    │                  |
|  │ Extended Writing (EW): 1 composition prompt │                 |
|  │ (narrative, informational, or argumentative)│                 |
|  └────────────────────────────────────────────┘                  |
+------------------------------------------------------------------+
```

## 5. Item Types & Formats

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE (MC) — 1 point                          |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Single correct answer                                   |
|  Passage-based (tied to stimulus text)                   |
|  Machine scored                                          |
|  DOK 1–3                                                 |
+----------------------------------------------------------+
```

**MC Example (Grade 5 Literary, DOK 2, ELAGSE5RL2):**

*[After reading a story about a child helping on a Georgia peach farm]*

Which statement BEST describes the theme of this story?

A. Working on a farm is difficult but teaches valuable lessons
B. Georgia peaches are the best in the country
C. Children should always listen to their grandparents
D. Summer is the most enjoyable season of the year

*Correct Answer: A*
*Alignment: ELAGSE5RL2 | DOK 2*

---

**MC Example (Grade 7 Informational, DOK 2, ELAGSE7RI6):**

*[After reading an article about the history of the Atlanta civil rights movement]*

How does the author MAINLY develop their point of view in this article?

A. By describing personal experiences of growing up in Atlanta
B. By presenting a timeline of events alongside quotes from leaders
C. By comparing Atlanta to other Southern cities
D. By arguing that Atlanta was the most important city in the movement

*Correct Answer: B*
*Alignment: ELAGSE7RI6 | DOK 2*

---

### Multi-Select (MS)

```
+----------------------------------------------------------+
|  MULTI-SELECT (MS) — 1 point                             |
|                                                          |
|  5–6 options                                             |
|  Student selects ALL correct answers (typically 2)       |
|  Machine scored; all-or-nothing                          |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**MS Example (Grade 6, DOK 2, ELAGSE6RI5):**

*[After reading an article about Savannah's historic architecture]*

Select TWO ways the author organizes information in this article.

A. By listing arguments for and against historic preservation
B. By describing buildings in chronological order of construction
C. By comparing Savannah's squares to those in other cities
D. By grouping examples by architectural style and period
E. By presenting a fictional story set in Savannah

*Correct Answers: B and D*

---

### Selected-Response with Evidence (SRE)

```
+----------------------------------------------------------+
|  SELECTED-RESPONSE WITH EVIDENCE (SRE) — 2 points       |
|                                                          |
|  TWO-PART item:                                          |
|  Part A: Analytical question (inference, theme, craft)   |
|  Part B: Select the BEST evidence that supports Part A   |
|  Both parts must be correct for full credit              |
|  Machine scored                                          |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**SRE Example (Grade 8 Literary, DOK 3, ELAGSE8RL4):**

*[After reading a short story set near the Okefenokee Swamp]*

**Part A:** What does the phrase "the swamp held its breath" in paragraph 6 MOST LIKELY suggest about the setting?

A. The swamp is dangerous and unpredictable
B. A moment of stillness and anticipation surrounds the character
C. The narrator is afraid of the water
D. The animals in the swamp have gone silent permanently

**Part B:** Which sentence from the story BEST supports the answer to Part A?

F. "The cypress trees stood like dark sentinels along the water's edge."
G. "Maria paused on the boardwalk, feeling the silence wrap around her like a blanket before the storm."
H. "The boat had been tied to the dock since morning."
J. "Her brother called from across the clearing, breaking the spell."

*Correct Answers: Part A — B; Part B — G*
*Alignment: ELAGSE8RL4 | DOK 3*

### Constructed Response (CR)

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE (CR) — 0–2 points                  |
|                                                          |
|  2–4 sentence written response                           |
|  Must reference the text                                 |
|  Human scored using CR rubric                            |
|  DOK 2–3                                                 |
|  Section 1 only                                          |
+----------------------------------------------------------+
```

**CR Example (Grade 6 Informational, DOK 3, ELAGSE6RI8):**

*[After reading an article about the Georgia coast and its barrier islands]*

Using evidence from the article, explain how the author supports the claim that Georgia's barrier islands are important to both wildlife and local communities.

---

### Extended Writing (EW)

```
+----------------------------------------------------------+
|  EXTENDED WRITING (EW) — 0–7 points                     |
|                                                          |
|  Multi-paragraph composition                             |
|  Scored on a rubric: 0–7 scale                           |
|  Types: Narrative, Informational/Explanatory,            |
|         Argumentative (varies by grade)                   |
|  Human scored                                            |
|  Section 2                                               |
+----------------------------------------------------------+
```

**EW Prompt Example (Grade 4 — Narrative):**

Think about a time when you explored a new place. Write a story about a character who discovers something unexpected while exploring. Use descriptive details to develop the setting, characters, and events.

**EW Prompt Example (Grade 7 — Argumentative):**

Some people believe that students should be required to participate in community service projects. Others believe community service should be voluntary. Write an argument in which you take a position on this issue. Support your claim with clear reasons and evidence.

## 6. Depth of Knowledge (DOK)

| DOK | Label | ELA Application Examples |
|---|---|---|
| 1 | Recall | Identify a vocabulary word meaning using context; locate an explicit fact; name a text structure |
| 2 | Skills & Concepts | Infer a character's motivation from text evidence; identify the author's purpose; explain how a detail supports the central idea |
| 3 | Strategic Thinking | Analyze how the author's use of figurative language contributes to mood; evaluate the effectiveness of an argument; compare themes across two passages; synthesize evidence from multiple sources |
| 4 | Extended Thinking | Extended Writing prompt — full essay, narrative, or argument integrating ideas, craft, evidence, and voice |

### DOK Alignment by Item Type

| Item Type | Typical DOK | Notes |
|---|---|---|
| MC | 1–3 | Most MC items are DOK 2; some DOK 1 for vocabulary/recall; DOK 3 for craft analysis |
| MS | 2–3 | Requires identifying multiple correct elements |
| SRE | 2–3 | Two-part evidence-based reasoning |
| CR | 2–3 | Requires written explanation with text evidence |
| EW | 3–4 | Extended composition integrating multiple skills |

| Knowledge Demand | Everyday experience | Disciplinary or cultural knowledge |

## 8. Scoring Rubrics

### Constructed Response (CR) Rubric — 0–2 Points

| Score | Criteria |
|---|---|
| 2 | Response provides an accurate, specific answer that addresses the question. Includes relevant textual evidence (quoted or paraphrased) that directly supports the answer. Demonstrates clear understanding of the text. |
| 1 | Response provides a partially accurate answer. OR Response provides an accurate answer without sufficient or directly relevant textual evidence. Demonstrates partial understanding. |
| 0 | Response is inaccurate, irrelevant, insufficient in length to evaluate, or blank. |

### Selected-Response with Evidence (SRE) Scoring — 0–2 Points

| Score | Criteria |
|---|---|
| 2 | Both Part A and Part B are answered correctly. The evidence selected in Part B directly supports the analytical response in Part A. |
| 1 | Part A is correct but Part B is incorrect. OR Part A is incorrect but Part B is consistent with the incorrect Part A response and reflects valid reasoning. |
| 0 | Both parts are incorrect. OR only Part B is correct with no logical connection to Part A. |

### Extended Writing (EW) Rubric — 0–7 Points

The Extended Writing is scored holistically on a 0–7 scale assessing the quality of the student's composition across multiple dimensions.

| Score | Criteria |
|---|---|
| 7 | Fully developed composition with a commanding controlling idea. Precise, engaging language throughout. Sophisticated organization with purposeful transitions. Thorough development with compelling evidence/details. Consistent control of conventions with only minor errors. |
| 6 | Well-developed composition with a clear controlling idea. Effective language and varied sentence structure. Strong organization and transitions. Detailed development with relevant evidence/details. Strong control of conventions. |
| 5 | Developed composition with a clear controlling idea. Appropriate language with some variety. Logical organization with transitions. Adequate development with supporting evidence/details. General control of conventions with occasional errors. |
| 4 | Adequately developed composition with an identifiable controlling idea. Basic but functional language. Organization present but may be formulaic. Development present but may be uneven. Adequate control of conventions. |
| 3 | Partially developed composition with a vague or inconsistent controlling idea. Simple language with limited variety. Weak organization; transitions absent or unclear. Limited development; evidence/details may be insufficient. Partial control of conventions with errors that may interfere. |
| 2 | Minimally developed composition with an unclear controlling idea. Repetitive or imprecise language. Little discernible organization. Minimal development with few or no supporting details. Limited control of conventions with frequent errors. |
| 1 | Composition is largely undeveloped. Controlling idea absent or unrecognizable. Incoherent organization. Negligible development. Pervasive errors that severely impede reading. |
| 0 | Blank, off-topic, or insufficient text to evaluate. |

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] GSE code verified as correct for the targeted grade (ELAGSE format)
- [ ] MC items directly tied to the passage (not general knowledge questions)
- [ ] SRE Part B evidence directly supports the Part A analytical response
- [ ] CR prompt requires textual evidence (not just prior knowledge)
- [ ] Distractors represent authentic misconceptions, not obviously wrong answers
- [ ] EW prompt is open-ended enough for student voice and elaboration
- [ ] Lexile of passage matches the grade-level range
- [ ] Passage length appropriate (400–1,000 words for comprehension passages)
- [ ] Georgia context incorporated where appropriate (geography, history, culture)
- [ ] Extended Writing scored using the 0–7 holistic rubric
- [ ] Item type matches the correct point value (MC=1, MS=1, SRE=2, CR=0–2, EW=0–7)
- [ ] Two-section test structure maintained (Section 1: Reading; Section 2: Writing/Language)

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| SRE Part B evidence not matching Part A | Both parts must logically connect | Ensure Part B options include direct textual support for the correct Part A answer |
| EW scored on trait-by-trait rubric | Georgia Milestones EW uses a holistic 0–7 rubric | Use the 0–7 holistic scale, not a multi-trait model |
| Using CCSS codes instead of GSE | Georgia uses GSE, not CCSS | Reference ELAGSE codes exclusively |
| CR prompt that only tests recall | CR should require DOK 2–3 analysis with textual evidence | Include "using evidence from the text" in CR prompts |
| Items not passage-dependent | All Section 1 items must reference a stimulus text | Tie every MC, SRE, and CR to a specific passage |
| EW prompt too narrow | Limits student voice and range of response | Ensure prompts allow for multiple valid approaches |
| Ignoring Section 2 language items | Language conventions are tested separately | Include MC/MS items for grammar, usage, punctuation |

## 12. Prompt Patterns

### Pattern 1: Theme / Central Idea (MC or SRE, DOK 2–3)
> "What [theme / central idea] does this [passage / story / article] develop? How does the author use [specific details / events / language] to develop this [theme / idea]?"

### Pattern 2: Craft & Language Analysis (MC, DOK 3)
> "Read [line reference / paragraph reference]. What effect does the author's use of [figurative language / imagery / word choice / structure] create in this [sentence / paragraph / passage]?"

### Pattern 3: Author's Purpose / Argument (MC or CR, DOK 2–3)
> "What is the author's [main purpose / central argument] in this [article / essay]? How does the author [support / develop] this [purpose / argument]? Use evidence from the text."

### Pattern 4: Evidence-Based Analysis — SRE (DOK 2–3)
> "Part A: What does [detail / phrase / event] reveal about [character / theme / central idea]?
> Part B: Which [sentence / detail] from the passage BEST supports the answer to Part A?"

### Pattern 5: Constructed Response — Text Evidence (DOK 3)
> "Using evidence from [passage title], explain how the author [develops / supports / conveys] [specific aspect of the text]."

### Pattern 6: Extended Writing — Narrative (DOK 4)
> "Write a story about [topic / scenario]. Use descriptive details to develop your setting, characters, and events."

### Pattern 7: Extended Writing — Argumentative (DOK 4)
> "[Issue statement presenting two sides]. Write an argument in which you take a position. Support your claim with clear reasons and evidence."
