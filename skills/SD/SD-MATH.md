| Level | Label | Description |
|---|---|---|
| 4 | **Standard Exceeded** | Student demonstrates sophisticated understanding of mathematical concepts and procedures; applies mathematics fluently in novel situations; constructs valid mathematical arguments; evaluates and critiques the reasoning of others |

## 5. Item Types & Formats

### SR — Selected Response (1 point)

Standard four-option multiple-choice. Student selects one best answer.

```
+-----------------------------------------------------------------+
|  [Stimulus: problem context, diagram, table, or equation]        |
|                                                                  |
|  Question stem targeting a specific standard and claim.          |
|                                                                  |
|  O  A. [Numerical / expression answer -- plausible distractor]   |
|  O  B. [Numerical / expression answer -- common error]           |
|  O  C. [Numerical / expression answer -- CORRECT]                |
|  O  D. [Numerical / expression answer -- off-track distractor]   |
+-----------------------------------------------------------------+
Points: 1 (correct) / 0 (incorrect)
```

**Construction Rules:**
- Distractors must reflect real student errors (e.g., computational errors, conceptual mistakes, operation errors)
- Numerical answers should not reveal the correct answer through magnitude ordering
- Avoid answer options that are obviously not in the ballpark
- Diagrams and tables must be clearly labeled and drawn to reasonable scale

---

### MS — Multi-Select (1 point)

Student selects ALL correct answers from a set of five or six options. Full credit only when all correct options are selected and no incorrect options are selected.

```
+-----------------------------------------------------------------+
|  [Problem context or mathematical statement]                     |
|                                                                  |
|  Select the TWO [equations / values / expressions] that...       |
|                                                                  |
|  [ ]  A. [Option]                                                |
|  [ ]  B. [Option -- CORRECT]                                     |
|  [ ]  C. [Option]                                                |
|  [ ]  D. [Option -- CORRECT]                                     |
|  [ ]  E. [Option]                                                |
|  [ ]  F. [Option]                                                |
+-----------------------------------------------------------------+
Points: 1 (all correct, none incorrect) / 0 (any error)
```

**Construction Rules:**
- Specify the count in the stem when it is fixed ("Select the TWO...")
- Use "Select ALL that apply" when count is variable
- Typically 2–3 correct answers from 5–6 options
- Common use cases: identify all equivalent fractions, select all true equations, identify all figures with a given property

---

### EQ — Equation / Numeric Entry (1 point)

Student types a number, expression, or short equation into a response box. No choices are provided.

```
+-----------------------------------------------------------------+
|  [Problem context: real-world scenario or pure math]             |
|                                                                  |
|  What is the value of [EXPRESSION / VARIABLE / QUANTITY]?        |
|                                                                  |
|  Enter your answer in the box.                                   |
|  +---------------+                                               |
|  |               |  [numeric / expression entry field]           |
|  +---------------+                                               |
|                                                                  |
|  [Unit label if applicable: "bushels", "acres", etc.]            |
+-----------------------------------------------------------------+
Points: 1 (exact correct value or equivalent expression) / 0
```

**Construction Rules:**
- Clearly state the expected form of the answer (whole number, decimal, fraction, simplified expression)
- Specify units in the item when applicable
- For fraction entries, provide the fraction entry tool (numerator/denominator boxes)
- Answers should be unique; specify rounding rules when relevant

---

### SCR — Short Constructed Response (0–2 points)

Student writes a brief explanation or solution — usually 1–4 sentences plus work shown.

```
+-----------------------------------------------------------------+
|  [Problem context -- multi-step real-world scenario]             |
|                                                                  |
|  [PART A -- Computational or procedural question]                |
|  [PART B -- "Explain how you know" or "Show your work"]          |
|                                                                  |
|  +-------------------------------------------------------------+|
|  |  [Student response area -- text input + scratchpad]          ||
|  +-------------------------------------------------------------+|
+-----------------------------------------------------------------+
Points: 0-2 (see rubric, Section 8)
```

**Construction Rules:**
- Prompt must clearly ask for both an answer AND an explanation/justification
- Identify the claim: SCR is most appropriate for Claim 3 (Communicating Reasoning) or Claim 2 (Problem Solving)
- The problem context should be accessible but require non-trivial mathematical reasoning

---

### PT-ER — Performance Task Extended Response (0–6 points, multi-part)

The PT Extended Response presents a complex real-world scenario and asks students to complete 3–5 interdependent sub-parts.

```
+-----------------------------------------------------------------+
|  PERFORMANCE TASK -- EXTENDED RESPONSE                           |
|                                                                  |
|  SCENARIO:                                                       |
|  [3-5 sentence real-world context establishing the situation]    |
|  [Data tables, diagrams, or charts may be provided here]         |
|                                                                  |
|  Part A: [Introductory computation or setup question]            |
|  Part B: [Intermediate reasoning or application question]        |
|  Part C: [Complex extension -- explain, justify, model, or      |
|           evaluate a decision based on mathematical results]     |
+-----------------------------------------------------------------+
Points: 0-2 per part x 3 parts = 0-6 total
```

## 6. DOK / Cognitive Complexity

### DOK Level Descriptions for Mathematics

| DOK | Label | Description | Example Tasks |
|---|---|---|---|
| **1** | Recall & Reproduction | Recall a fact; perform a routine, single-step procedure; identify a property; solve a one-step equation; read a value from a graph | *calculate, identify, recall, use, recognize, list, name, measure* |
| **2** | Skills & Concepts | Solve a multi-step problem using a known procedure; classify or organize information; make inferences from data; apply a concept in a new but straightforward context | *classify, organize, estimate, compare, interpret, solve [multi-step], graph, apply* |
| **3** | Strategic Thinking | Solve non-routine problems requiring planning; justify or prove a mathematical claim; analyze errors in reasoning; design a mathematical model | *justify, prove, analyze, evaluate, formulate, critique, explain reasoning, construct* |
| **4** | Extended Thinking | Conduct multi-stage investigations; synthesize mathematical ideas across domains; design and evaluate complex models | *synthesize, design, evaluate [complex], connect, present, create* |

> DOK 4 appears primarily in PT Extended Response Part C items, not in individual CAT items.

### DOK Distribution Targets for Item Generation

| Item Type | Target DOK | Rationale |
|---|---|---|
| SR — single computation | 1 | Routine procedure, one step |
| SR — two-step word problem | 2 | Application; concept + computation |
| MS — identify equivalent forms | 1–2 | Depends on conceptual demand |
| EQ — numeric entry | 1–2 | Usually procedural; contextual use raises to DOK 2 |
| TE — graphing | 2 | Requires connecting representations |
| SCR — explain reasoning | 3 | Justification required; non-routine |
| PT-ER Part A | 2 | Setup computation within context |
| PT-ER Part B | 2–3 | Application or partial modeling |
| PT-ER Part C | 3–4 | Full modeling, justify, evaluate |

## 8. Scoring Rubrics

### SCR — Short Constructed Response (0–2 Points)

| Score | Descriptor |
|---|---|
| **2** | The response demonstrates thorough understanding. Correct solution with clear, accurate explanation or justification. Work shown is logical and complete. Minor arithmetic errors do not affect the score if reasoning is sound. |
| **1** | The response demonstrates partial understanding. Partially correct solution or correct solution with incomplete explanation. A computational error with otherwise sound reasoning may earn 1 point. OR correct answer with no explanation. |
| **0** | The response is incorrect, irrelevant, or demonstrates no mathematical understanding. Blank response receives 0. |

---

### PT-ER — Performance Task Extended Response (0–6 Points)

#### Part A Rubric (0–2 points)

| Score | Descriptor |
|---|---|
| **2** | Correctly sets up and solves the introductory problem. All calculations correct and clearly shown. Units correctly identified. |
| **1** | Correct approach or setup but contains a computational error, incomplete solution, or missing unit. |
| **0** | Incorrect, missing, or demonstrates no understanding. |

#### Part B Rubric (0–2 points)

| Score | Descriptor |
|---|---|
| **2** | Correctly applies mathematical results from Part A to solve the intermediate problem. Reasoning is clear; comparison, evaluation, or interpretation is accurate. |
| **1** | Partial understanding. May use incorrect value from Part A but apply correct reasoning, or arrive at correct conclusion through partially correct work. |
| **0** | Incorrect, missing, or shows no mathematical understanding. |

#### Part C Rubric (0–2 points)

| Score | Descriptor |
|---|---|
| **2** | Demonstrates sophisticated mathematical reasoning. Accurately uses mathematical results to justify a decision, evaluate a model, or explain a pattern. Explanation is clear and mathematically sound. |
| **1** | Some correct reasoning or partially valid justification. Correct conclusion with insufficient mathematical support, or correct calculations without connection to explanation. |
| **0** | Incorrect, off-task, or only unsupported assertions. |

#### Error-Carried-Forward (ECF) Policy

When a student carries an incorrect value from Part A into Parts B and C, award full credit for subsequent parts if the student's work is mathematically correct based on their Part A answer. ECF applies only to simple computational mistakes, not conceptual misunderstandings.

## 10. Contextualization

### South Dakota-Specific Mathematics Context Bank

Item writers should anchor scenarios in authentic South Dakota contexts to maximize student engagement and ecological validity.

#### Mount Rushmore Dimensions & Black Hills Elevation

| Topic | Mathematical Applications |
|---|---|
| **Mount Rushmore face dimensions** | Each presidential face is approximately 60 feet tall (nose ~20 ft, mouth ~18 ft wide, eyes ~11 ft across); proportional reasoning comparing sculpture to actual human proportions; scale factor calculations (sculpture face is ~20x life size); area and perimeter of carved surfaces; unit conversion (feet to meters: 60 ft ~ 18.3 m) |
| **Mount Rushmore to scale models** | A gift-shop model is 1:150 scale; calculate model dimensions from actual; set up and solve proportions; use ratios to find missing measurements; compare multiple scale factors |
| **Black Hills elevation** | Black Elk Peak (formerly Harney Peak) at 7,242 ft is the highest point east of the Rockies; elevation change from Rapid City (3,202 ft) to summit = 4,040 ft; slope calculations for trail grade (~1,700 ft gain over 3.5 miles); integer operations with elevation gain/loss; graphing elevation profiles |
| **Crazy Horse Memorial progress** | When complete: 563 ft high by 641 ft long; currently the face is 87 ft 6 in tall; percent completion; volume of rock removed (~8.4 million tons so far); rate of progress over decades |

#### Badlands Area & Geology

| Topic | Mathematical Applications |
|---|---|
| **Badlands National Park area** | 244,000 acres total; conversion to square miles (~381 sq mi); fraction of South Dakota's total area (~77,116 sq mi); compare to other national parks using ratios; perimeter estimation from park boundary maps |
| **Badlands erosion rates** | The Badlands erode approximately 1 inch per year; rate of change calculations; how much erosion in 50 years, 100 years; unit conversion (inches to feet, cm); linear modeling of erosion over time |
| **Badlands fossil site measurements** | Fossil bone dimensions; scale diagrams; proportional reasoning comparing ancient animal sizes to modern relatives; area of excavation sites |

#### SD Farming Data & Livestock Statistics

| Topic | Mathematical Applications |
|---|---|
| **Corn production** | SD harvested ~6.0 million acres of corn; average yield ~155 bushels per acre; total production calculations; percent change from previous year; revenue at ~$4.50/bushel; multi-step word problems |
| **Soybean acreage** | ~5.5 million acres; yield ~47 bushels per acre; compare corn vs. soybean revenue per acre; ratio and proportion; data displays of production by county |
| **Wheat production** | ~2.0 million acres; spring wheat vs. winter wheat ratios; yield per acre calculations; comparing SD wheat to ND wheat production |
| **Livestock statistics** | SD has ~3.9 million cattle and ~900,000 people — ratio of ~4.3 cattle per person; unit rate problems; proportional reasoning; compare to other states; data analysis of cattle counts by county; feed consumption rates (25–30 lbs/day per head) |
| **Sunflower production** | SD is a top-5 sunflower state; acreage and yield data; oil extraction ratios (~40% oil by weight); multi-step unit rate calculations |

#### Missouri River Flow & Water Data

| Topic | Mathematical Applications |
|---|---|
| **Missouri River flow rate** | Average flow at Pierre: ~25,000 cubic feet per second; unit conversion to gallons per second (~187,000 gal/sec); distance-rate-time problems along the river; volume calculations for time intervals |
| **Oahe Dam and reservoir** | Lake Oahe stretches 231 miles; surface area ~374,000 acres; volume of stored water; compare to other SD reservoirs (Sharpe, Francis Case); percent of SD water supply from Missouri River system |
| **Seasonal flow variation** | Spring peak flow vs. winter low flow data; range and mean calculations; graphing flow data over 12 months; percent change between seasons |
| **Flood stage data** | Historical river levels at Pierre and Sioux Falls; integer operations (feet above/below flood stage); rate of rise during flood events; data interpretation from hydrograph displays |

#### Community and Everyday Contexts

| Topic | Mathematical Applications |
|---|---|
| **Sioux Falls population** | Metro area ~280,000; city proper ~200,000; percent growth (~2% annually); population density (area ~89 sq mi); compare to Rapid City (~78,000) using ratios |
| **Rural distance calculations** | Pierre to Rapid City: ~175 miles; Sioux Falls to Pierre: ~225 miles; Sioux Falls to Rapid City: ~350 miles; distance-rate-time at various speeds; fuel consumption calculations |
| **Sturgis Motorcycle Rally** | ~500,000 annual visitors over 10 days; ratio of visitors to SD population; economic impact (~$800 million); daily average attendance; percent of annual tourism revenue |
| **SD school data** | Per-pupil spending; rural school enrollment trends; student-teacher ratios (~13:1 statewide); transportation distances for consolidated districts; budget calculations |

### Grade-Band Contextualization Notes

#### Grades 3–5 Contextualization

| Principle | Guidance |
|---|---|
| **Concreteness** | Contexts should involve tangible, observable quantities (bushels of corn, miles between towns, bison in Custer State Park herd, feet of a monument) |
| **Accessibility** | Avoid highly specialized vocabulary; ensure both rural and urban SD students can relate |
| **Scale of numbers** | Match number magnitude to grade-level standards (Gr 3: within 1,000; Gr 5: multi-digit, decimals, fractions) |
| **Authenticity** | South Dakota farm, Custer State Park visit, school fundraiser in Rapid City, community garden in Sioux Falls — familiar community settings |

#### Grades 6–8 Contextualization

| Principle | Guidance |
|---|---|
| **Real data** | Use approximate real data (SD population ~900,000; Mount Rushmore dimensions; crop production figures; temperature records) |
| **Multiple representations** | Include tables, graphs, or diagrams alongside word problem contexts |
| **Social relevance** | Topics like farming economics, Missouri River management, Black Hills tourism, and weather patterns resonate with middle-school students |

#### Grade 11 Contextualization

| Principle | Guidance |
|---|---|
| **Workforce readiness** | Career-relevant contexts (agriculture, tourism, engineering, wind energy, healthcare) |
| **Complex data** | Multi-variable data sets; scatter plots; regression; probability in real decision-making |
| **Equity lens** | Include data representing South Dakota's diversity; include Lakota, Dakota, and Nakota tribal community contexts; reflect refugee and immigrant community experiences in Sioux Falls |

### English Learner (EL) Considerations for Math

| Consideration | Guidance |
|---|---|
| **Mathematical vocabulary** | Pre-teach or define Tier 3 math vocabulary in a glossary; avoid confusing mathematical terms with everyday meanings |
| **Word problem language** | Use simple, direct sentence structure in word problem stems |
| **Bilingual glossary** | EL designated support — mathematical terms in home languages; items should not be invalidated by glossary use |
| **Diagrams and visuals** | Use clear, labeled diagrams to reduce linguistic load |

## 11. Quality Checklist

Use this checklist before finalizing any generated item or item set.

### Standards Alignment

- [ ] Item is tagged to one primary CCSS Math standard (e.g., 7.RP.A.2)
- [ ] Standard matches the claim and subclaim
- [ ] DOK level is consistent with the cognitive demand of the task
- [ ] Grade-level standard is appropriate for the intended grade band
- [ ] Item does not require knowledge of standards above or below grade level

### Calculator Policy

- [ ] Item is flagged as calculator or non-calculator consistent with grade-level policy (Section 3)
- [ ] Computational complexity is appropriate for the calculator policy
- [ ] Calculator-active items use numbers that would realistically benefit from a calculator

### Reference Sheet

- [ ] For Grades 8 and 11: item does not embed formulas that are on the reference sheet
- [ ] For Grades 3–7: item does not require formulas not taught at grade level
- [ ] Formula reference is given in the item when required

### Item Quality (All Types)

- [ ] Stem is a clear, unambiguous question or directive
- [ ] All numerical values in the problem are internally consistent
- [ ] Units are clearly specified and used correctly throughout
- [ ] No "trick" questions
- [ ] Diagrams are clearly labeled, drawn to reasonable scale, and described in alt text
- [ ] Answer options for SR are plausible and each represents a specific student error
- [ ] Correct answer is verified independently (calculation checked)
- [ ] Word problem context is realistic and meaningful

### SCR and PT-ER Checks

- [ ] Constructed-response prompt requires both a numerical answer AND explanation/justification
- [ ] Rubric is included with the item
- [ ] PT-ER parts are interdependent and logically sequenced (A -> B -> C)
- [ ] Error-carried-forward (ECF) policy is noted in the rubric
- [ ] Scoring guide anticipates common student errors

### EL and Accessibility

- [ ] Word problem language is clear and concise
- [ ] Mathematical vocabulary is appropriate for the grade; specialized terms are defined
- [ ] Diagrams are usable by students using zoom or screen magnification
- [ ] Item does not require cultural knowledge that disadvantages EL students
- [ ] Item contexts reflect South Dakota's diversity, including Lakota/Dakota/Nakota and immigrant community perspectives

## 12. Prompt Patterns

The following patterns map common user requests to generation strategies for the AI.

---

### Pattern 1: "Generate a math problem for Grade [X]"

**Interpretation:** Default to an SR item (1 point) for Claim 1 (Concepts & Procedures) at DOK 2. Use a real-world context from Section 10.

**Generation Recipe:**
1. Identify the primary content domain for the grade
2. Select a South Dakota context from Section 10
3. Generate SR using Template 1, ensuring two mathematical steps
4. Construct four options where each distractor represents a distinct common error
5. Tag: state=SD, subject=MATH, grade=[X], claim=2, standard=[STANDARD], dok=2

---

### Pattern 2: "Generate a word problem that requires explanation"

**Interpretation:** Generate an SCR (0–2 points) for Claim 3 (Communicating Reasoning) at DOK 3. Use Template 2.

**Generation Recipe:**
1. Select a multi-step context appropriate for the grade (see Section 10)
2. Build Part A as the computational component (DOK 2)
3. Build Part B as the justification requirement (DOK 3)
4. Include a scoring guide (Section 8 rubric)
5. Tag: state=SD, subject=MATH, grade=[X], claim=3, dok=3

---

### Pattern 3: "Generate a Performance Task math problem for Grade [X]"

**Interpretation:** Generate a full PT-ER package using Template 3.

**Generation Recipe:**
1. Choose a multi-faceted South Dakota context (Mount Rushmore dimensions, farming data, Missouri River flow, Badlands area calculations, livestock statistics)
2. Create a realistic data set with 3–5 rows/entries
3. Scaffold Parts A (DOK 2), B (DOK 2–3), and C (DOK 3–4)
4. Include the 0–2 rubric for each part and ECF note
5. Tag: state=SD, subject=MATH, grade=[X], claim=4, dok=3-4, calculator=yes

---

### Pattern 4: "Generate a set of math items covering multiple domains"

**Interpretation:** Generate a mini-assessment covering 3–4 different mathematical domains with a mix of item types.

**Generation Recipe:**
1. Identify 3–4 primary domains for the grade
2. Generate one item per domain: 1–2 SR, 1 MS, 1 EQ
3. Distribute calculator vs. non-calculator per policy (Section 3)
4. Include a standards and DOK summary table
5. Tag each item with claim, standard, DOK, and calculator policy

---

### Pattern 5: "Generate a math item about [South Dakota topic]"

**Interpretation:** Identify the closest match in Section 10, select grade-appropriate standards, and generate an item using the corresponding mathematical applications.

**Generation Recipe:**
1. Match the requested topic to Section 10 context bank
2. Determine grade-appropriate standards and number complexity
3. Select the best item type (SR for DOK 1–2, SCR for DOK 3, PT-ER for DOK 3–4)
4. Generate the item with authentic SD data and context
5. Tag: state=SD, subject=MATH, grade=[X], claim=[CLAIM], standard=[STANDARD], dok=[DOK]
