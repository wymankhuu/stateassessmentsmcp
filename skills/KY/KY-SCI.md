| 3 | **Proficient** | Student demonstrates sufficient understanding of science standards; applies scientific knowledge and practices at grade level |

## 2. STANDARDS FRAMEWORK

### Kentucky Science Standards (NGSS-Aligned)

Kentucky adopted the NGSS framework with state-specific adaptations. The standards are organized around three dimensions that work together in assessment:

**Three Dimensions of Kentucky Science Standards:**

| Dimension | Description |
|---|---|
| Disciplinary Core Ideas (DCIs) | Content knowledge organized by domain |
| Science and Engineering Practices (SEPs) | What students DO with science knowledge |
| Crosscutting Concepts (CCCs) | Themes that bridge science domains |

## 3. TEST STRUCTURE

KSA Science is administered in **2 sessions** with scenario-based item clusters.

```
+------------------------------------------------------------------+
|         KSA SCIENCE TEST STRUCTURE (Grades 5, 8, 10)             |
+----------------------------------+-------------------------------+
|   SESSION 1                      |   SESSION 2                   |
|   ~60 minutes                    |   ~60 minutes                 |
|                                  |                               |
|  Scenario-based item clusters    |  Scenario-based item clusters |
|  - Multiple Choice (MC)          |  - Multiple Choice (MC)       |
|  - Multi-Select (MS)             |  - Multi-Select (MS)          |
|  - Constructed Response (CR)     |  - Constructed Response (CR)  |
|                                  |                               |
|  Items tied to science phenomena |  Items tied to science phenomena|
|  with data, models, and diagrams |  with data, models, and diagrams|
+----------------------------------+-------------------------------+
```

### Item Counts by Grade

| Component | Grade 5 | Grade 8 | Grade 10 |
|---|---|---|---|
| MC items | 25–30 | 28–32 | 28–32 |
| MS items | 6–10 | 8–12 | 8–12 |
| CR items | 2–3 | 2–3 | 2–3 |
| **Total items** | **~38–42** | **~40–45** | **~40–45** |

> **Three-Dimensional Items:** KSA Science items are designed to assess all three dimensions simultaneously. A single item or item cluster may integrate a DCI, an SEP, and a CCC. This is different from assessments that test content knowledge in isolation.

## 5. ITEM TYPES

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Single correct answer                                   |
|  Machine scored                                          |
|  Often scenario-based with data/models                   |
|  DOK 1–2                                                 |
+----------------------------------------------------------+
```

**MC Example (Grade 5, DOK 2, 5-ESS2-1 — Earth Systems):**

Mammoth Cave in Kentucky was formed over millions of years by water dissolving limestone rock underground. Which statement BEST describes the interaction between Earth's systems that created the cave?

- A. The atmosphere heated the rock until it melted to form the cave
- B. Water from the hydrosphere chemically dissolved rock in the geosphere
- C. Wind from the atmosphere physically eroded the rock underground
- D. Plants from the biosphere pushed the rock apart with their roots

*Correct Answer: B*

---

### Multi-Select (MS)

```
+----------------------------------------------------------+
|  MULTI-SELECT — 1 point (all-or-nothing)                 |
|                                                          |
|  5–6 options                                             |
|  Student selects ALL correct answers (typically 2)       |
|  Machine scored; no partial credit                       |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**MS Example (Grade 8, DOK 2, MS-LS2-4 — Ecosystem Changes):**

*A section of forest in eastern Kentucky was cleared for coal mining. After mining ended, the land was left bare. Which TWO changes would MOST LIKELY occur in the ecosystem over time?*

- A. The total amount of matter in the ecosystem would decrease permanently
- B. Pioneer species such as grasses and small plants would begin to grow first
- C. The original forest community would return within one year
- D. New soil would gradually develop as organisms decompose
- E. The area would remain permanently barren with no plant growth

*Correct Answers: B and D*

**CR Example (Grade 10, DOK 3, HS-LS2-2 + HS-ESS3-4):**

*"Scientists studying biodiversity in the Kentucky River watershed found that areas downstream from agricultural operations had fewer species of aquatic organisms than areas upstream. The data table below shows species counts at four locations along the river.*

| Location | Distance from Farm (km) | Number of Species |
|---|---|---|
| A | 0.5 | 8 |
| B | 2.0 | 14 |
| C | 5.0 | 22 |
| D | 10.0 | 31 |

*Using the data, construct an explanation for the pattern in biodiversity at different distances from the agricultural operation. In your response, identify a possible cause, describe the evidence that supports your explanation, and propose one solution that could reduce the impact on biodiversity."*

## 7. THREE-DIMENSIONAL ASSESSMENT GUIDANCE

### How Three Dimensions Integrate in KSA Science Items

KSA Science items assess students' ability to use science practices (SEPs) with content knowledge (DCIs) while applying crosscutting concepts (CCCs). Item writers must identify all three dimensions when creating items.

### Crosscutting Concepts (CCCs)

| CCC # | Concept | Kentucky Context Example |
|---|---|---|
| 1 | Patterns | Patterns in Mammoth Cave stalactite growth over time |
| 2 | Cause and Effect | How coal mining runoff affects downstream water quality |
| 3 | Scale, Proportion, and Quantity | Scale of geological processes that formed Cumberland Gap |
| 4 | Systems and System Models | Kentucky River watershed as a system |
| 5 | Energy and Matter | Energy flow through Appalachian forest ecosystems |
| 6 | Structure and Function | Adaptations of Kentucky cave-dwelling organisms |
| 7 | Stability and Change | Changes in Kentucky ecosystems due to mining and reclamation |

### Three-Dimensional Item Design Template

```
DIMENSION CHECK:
[ ] DCI: [Specific disciplinary core idea being assessed]
[ ] SEP: [Specific science practice students must demonstrate]
[ ] CCC: [Crosscutting concept that connects the item]

Example:
DCI: MS-ESS2-2 (geoscience processes change Earth's surface)
SEP: SEP 6 (Constructing explanations)
CCC: CCC 2 (Cause and effect)
Phenomenon: Formation of Mammoth Cave through water erosion
```

## 8. SCORING RUBRICS

### Constructed Response (CR) Rubric — 0–2 Points (Short CR)

| Score | Criteria |
|---|---|
| 2 | Response provides a complete scientific explanation with accurate evidence from the scenario; identifies relevant cause-and-effect relationships; uses appropriate scientific vocabulary |
| 1 | Response provides a partial explanation; some evidence cited but incomplete; scientific reasoning is present but underdeveloped |
| 0 | Response does not address the prompt; blank; off-topic; or contains significant scientific inaccuracies |

### Constructed Response (CR) Rubric — 0–4 Points (Extended CR)

| Score | Criteria |
|---|---|
| 4 | Complete, accurate scientific explanation citing specific evidence from data/scenario; clear identification of cause-and-effect or pattern; appropriate use of scientific vocabulary; addresses all parts of the prompt thoroughly |
| 3 | Mostly complete explanation with relevant evidence; minor inaccuracy or omission; adequate scientific vocabulary; most parts of the prompt addressed |
| 2 | Partial explanation with some relevant evidence; demonstrates basic scientific understanding but reasoning is incomplete; some parts of prompt unaddressed |
| 1 | Minimal explanation with little evidence; demonstrates limited scientific understanding; significant gaps in reasoning |
| 0 | No relevant scientific content; blank; off-topic; or demonstrates fundamental misunderstanding |

### Machine-Scored Items

| Item Type | Scoring Method | Points |
|---|---|---|
| MC | Machine scored | 1 pt |
| Multi-Select | Machine scored | 1 pt (all-or-nothing) |

## 10. CONTEXTUALIZATION — KENTUCKY SCIENCE

Kentucky's unique geology, ecology, and industries provide rich phenomena for science assessment items.

### KY Science Context Guide by Grade

| Context / Phenomenon | Grade | Domain | Standards Connection |
|---|---|---|---|
| Mammoth Cave formation and ecosystem | 5, 8 | ESS, LS | Earth systems, ecosystems, adaptations |
| Kentucky horse breeding and genetics | 8, 10 | LS | Heredity, variation, natural selection |
| Appalachian forest ecosystems | 5, 8, 10 | LS, ESS | Ecosystems, biodiversity, human impact |
| Coal formation and mining processes | 8, 10 | ESS, PS | Rock strata, chemical/physical changes, energy |
| Cumberland Gap geological history | 5, 8 | ESS | Geoscience processes, rock formation |
| Kentucky River watershed | 5, 8, 10 | ESS, LS | Water cycle, ecosystems, human impact |
| Bourbon distillation (chemistry) | 10 | PS | Chemical reactions, conservation of matter |
| Kentucky cave-dwelling organisms | 5, 8 | LS | Adaptations, ecosystems, structure/function |
| Appalachian coal seam geology | 8, 10 | ESS | Rock strata, fossil evidence, Earth's history |
| Kentucky weather and climate patterns | 5 | ESS | Weather, climate, Earth systems |

### Suggested Anchoring Phenomena by Grade

**Grade 5 Phenomena:**
- "Scientists exploring Mammoth Cave discovered eyeless fish and crayfish that live in total darkness — what adaptations allow these organisms to survive?"
- "A student in Kentucky noticed that the limestone rocks near a creek had small holes and channels carved into them — what caused these changes to the rock?"
- "After a severe rainstorm in the Bluegrass region, the Kentucky River turned muddy brown — what interactions between Earth's systems caused this change?"

**Grade 8 Phenomena:**
- "Coal found in eastern Kentucky contains fossil imprints of tropical plants, even though Kentucky currently has a temperate climate — what does this evidence suggest about Kentucky's geological past?"
- "After a coal mine in Appalachian Kentucky was closed and the land reclaimed, scientists tracked the return of plant and animal species over 20 years — what patterns did they observe?"
- "A farmer near the Cumberland Gap noticed that crops grew differently on opposite sides of the mountain — what factors explain this difference?"

**Grade 10 Phenomena:**
- "Kentucky bourbon distillers use a specific chemical process involving yeast, grain, and water to produce ethanol — what evidence shows that this is a chemical change rather than a physical change?"
- "Scientists studying the Kentucky River found that dissolved oxygen levels decreased significantly downstream from urban areas — construct an explanation for this pattern and its effect on aquatic biodiversity."
- "The process of mountaintop removal mining in eastern Kentucky permanently alters the landscape — evaluate the short-term and long-term effects on both the geosphere and local ecosystems."

## 11. QUALITY CHECKLIST AND COMMON PITFALLS

### Quality Checklist

- [ ] Grade verified as 5, 8, or 10 ONLY (not other grades)
- [ ] Standard uses NGSS-aligned PE code format
- [ ] All three dimensions identified (DCI + SEP + CCC)
- [ ] Kentucky-specific phenomenon used in scenario items
- [ ] Multi-Select has exactly 2 correct answers from 5–6 options
- [ ] CR items require evidence-based scientific explanation
- [ ] All MC distractors reflect identifiable student misconceptions
- [ ] Data tables and graphs are clearly labeled with units
- [ ] Science content is accurate and reviewed by subject-matter expert
- [ ] DOK level matches cognitive demand of item
- [ ] Items assess practices (SEPs) and not just recall of content
- [ ] Crosscutting concept is authentically embedded, not forced

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Testing content only (no SEP) | NGSS-aligned items must be three-dimensional | Integrate a science practice into every item |
| Using non-NGSS standard codes | Kentucky adopted NGSS-aligned framework | Use NGSS PE codes with Kentucky adaptations |
| Items for non-tested grades | KSA Science is Gr 5, 8, 10 only | Restrict items to tested grades |
| Generic phenomena (not KY-specific) | Kentucky items should anchor in local contexts | Use Mammoth Cave, Appalachia, coal, horse farms |
| Stereotyping coal mining negatively | Cultural sensitivity is essential | Present mining in full context — economic, environmental, community |
| CR without evidence requirement | NGSS emphasizes evidence-based reasoning | Always require students to cite data or observations |
| Ignoring CCC dimension | Three-dimensional assessment requires all three | Explicitly identify and embed the CCC |
| Treating KSA Science like a recall test | NGSS prioritizes application and reasoning | Ensure most items are DOK 2–3 with practice integration |

## 12. PROMPT PATTERNS

The following five patterns reflect the most common KSA Science item structures.

### Pattern 1: Phenomenon Explanation (MC, DOK 2)
> "Scientists observed [Kentucky phenomenon]. Which explanation BEST describes why [observed event] occurred?"

### Pattern 2: Data Interpretation (MC or MS, DOK 2)
> "The table/graph below shows [Kentucky science data]. Based on the data, which [conclusion/statement/pattern] is BEST supported?"

### Pattern 3: Cause and Effect — Ecosystem (MC, DOK 2)
> "In [Kentucky ecosystem], [change in one variable] occurred. What would MOST LIKELY be the effect on [another organism or part of the system]?"

### Pattern 4: Construct an Explanation (CR, DOK 3)
> "Using the data provided, construct a scientific explanation for [Kentucky phenomenon]. Identify the [cause/pattern], cite specific evidence from the data, and explain the scientific reasoning that connects the evidence to your explanation."

### Pattern 5: Evaluate a Solution (MC or CR, DOK 3)
> "A community in [Kentucky location] wants to reduce [environmental impact]. Which solution would MOST EFFECTIVELY address the problem while considering [tradeoffs]? Use evidence to support your evaluation."
