## 3. TEST STRUCTURE

KSA Mathematics is administered in **2 sessions**.

```
+------------------------------------------------------------------+
|          KSA MATHEMATICS TEST STRUCTURE (Grades 3–8, 10)         |
+----------------------------------+-------------------------------+
|   SESSION 1                      |   SESSION 2                   |
|   ~60 minutes                    |   ~60 minutes                 |
|                                  |                               |
|  MCQ + Multi-Select              |  MCQ + Multi-Select           |
|  + Equation Editor (EQ)          |  + Equation Editor (EQ)       |
|                                  |  + Constructed Response (CR)  |
|                                  |                               |
|  NO calculator (Gr 3–5)          |  NO calculator (Gr 3–5)       |
|  No-calc section (Gr 6–8, 10)   |  Calculator allowed (Gr 6–8, 10) |
+----------------------------------+-------------------------------+
```

### Session Item Counts by Grade Band

| Session | Grades 3–5 | Grades 6–8 | Grade 10 |
|---|---|---|---|
| Session 1 | 18–22 MC/MS/EQ (no calculator) | 18–22 MC/MS/EQ (no-calc section) | 18–22 MC/MS/EQ (no-calc section) |
| Session 2 | 14–18 MC/MS/EQ + 1–2 CR | 14–18 MC/MS/EQ + 1–2 CR (calc) | 14–18 MC/MS/EQ + 1–2 CR (calc) |

> **Calculator Policy:** No calculator is permitted at any point for Grades 3–5. For Grades 6–8 and 10, Session 1 is a no-calculator section; Session 2 permits an online or handheld four-function/scientific calculator.

## 5. ITEM TYPES

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Single correct answer                                   |
|  Machine scored                                          |
|  Both sessions                                           |
|  DOK 1–2                                                 |
+----------------------------------------------------------+
```

**MC Example (Grade 6, DOK 2, 6.RP.3 — Unit Rates):**

A horse farm in Lexington feeds each thoroughbred 18 pounds of hay per day. If the farm has 24 horses, how many pounds of hay does the farm need for one week?

- A. 432
- B. 3,024
- C. 2,520
- D. 168

*Correct Answer: B (18 × 24 × 7 = 3,024)*

---

### Multi-Select (MS)

```
+----------------------------------------------------------+
|  MULTI-SELECT — 1 point (all-or-nothing)                 |
|                                                          |
|  5–6 options                                             |
|  Student selects ALL correct answers (typically 2)       |
|  Machine scored; no partial credit                       |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**MS Example (Grade 8, DOK 2, 8.EE.7 — Linear Equations):**

Which TWO equations have exactly one solution?

- A. 3x + 5 = 3x + 5
- B. 2x − 4 = 10
- C. 4x + 1 = 4x + 7
- D. 5(x − 2) = 3x + 6
- E. x + x = 2x

*Correct Answers: B and D*

---

### Equation Editor (EQ)

```
+----------------------------------------------------------+
|  EQUATION EDITOR — 1 point                               |
|                                                          |
|  Student enters numeric or algebraic response            |
|  Accepts equivalent forms (e.g., 3/4 = 0.75)            |
|  Machine scored                                          |
|  Both sessions                                           |
|  DOK 1–2                                                 |
+----------------------------------------------------------+
```

**EQ Example (Grade 5, DOK 2, 5.NF.2 — Fraction Addition):**

*"Daniel Boone hiked 3/4 of a mile in the morning and 5/8 of a mile in the afternoon. How many total miles did he hike? Enter your answer as a fraction or mixed number."*

*Answer: 1 3/8 (or 11/8)*

---

### Constructed Response (CR)

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE — 0–2 or 0–4 points                |
|                                                          |
|  Multi-part problem (Parts A and B minimum)              |
|  Requires showing work AND written explanation           |
|  DOK 2–3                                                 |
|  Human scored using CR rubric                            |
|  Session 2 only (1–2 per test)                           |
+----------------------------------------------------------+
```

**CR Example (Grade 7, DOK 3, 7.RP.2 + 7.RP.3 — Proportional Relationships):**

*"A Kentucky bourbon distillery produces barrels at a constant rate. The table shows the number of barrels produced over several days:*

| Days | Barrels |
|---|---|
| 2 | 36 |
| 5 | 90 |
| 8 | 144 |

*Part A: Write an equation relating the number of days (d) to the number of barrels (b). Show your work.*
*Part B: How many barrels will the distillery produce in 30 days? Show your work.*
*Part C: Explain what the rate of change means in the context of this problem."*

## 7. MATHEMATICAL PRACTICE STANDARDS

Kentucky Academic Standards include **Standards for Mathematical Practice (SMP)**, which describe the habits of mind that mathematically proficient students demonstrate.

| SMP # | Practice Name | KSA Assessment Application |
|---|---|---|
| SMP 1 | Make sense of problems and persevere in solving them | Multi-step CR items requiring problem setup |
| SMP 2 | Reason abstractly and quantitatively | Items connecting abstract math to Kentucky contexts |
| SMP 3 | Construct viable arguments and critique reasoning | CR items requiring written justification |
| SMP 4 | Model with mathematics | Real-world Kentucky context problems |
| SMP 5 | Use appropriate tools strategically | Calculator-permitted sections; choosing representations |
| SMP 6 | Attend to precision | Items requiring exact answers with correct units/labels |
| SMP 7 | Look for and make use of structure | Pattern recognition and algebraic structure items |
| SMP 8 | Look for and express regularity in repeated reasoning | Generalization items in Grades 6–10 |

> **SMP in CR Items:** Constructed Response items on the KSA frequently target SMP 3 (construct arguments) and SMP 4 (model with mathematics). The Part C explanation component of CR items directly assesses SMP 3.

## 8. SCORING RUBRICS

### Constructed Response (CR) Rubric — 0–2 Points (Short CR)

| Score | Criteria |
|---|---|
| 2 | Correct answer with complete and clear mathematical work shown; demonstrates solid understanding of the concept |
| 1 | Partially correct; demonstrates some understanding but contains errors or incomplete work |
| 0 | Incorrect or no response; no understanding demonstrated; blank or off-task |

### Constructed Response (CR) Rubric — 0–4 Points (Extended CR)

| Score | Criteria |
|---|---|
| 4 | All parts correctly and completely addressed; mathematical work is fully shown, clearly organized, and leads to correct answers; written explanations are mathematically precise with accurate vocabulary and context |
| 3 | Most parts correctly addressed; mathematical work is mostly complete with a minor computational error; approach is sound; written explanations demonstrate adequate understanding |
| 2 | Some parts correctly addressed; mathematical work is partially complete or contains procedural errors; demonstrates partial understanding; explanations present but incomplete |
| 1 | Little correct mathematical work shown; demonstrates minimal understanding; significant errors across most parts; explanations absent or confused |
| 0 | No correct mathematical work shown; response is blank, off-task, or demonstrates no understanding |

## 11. QUALITY CHECKLIST AND COMMON PITFALLS

### Quality Checklist

- [ ] Standard code uses KAS format: [Grade].[Domain].[Standard]
- [ ] SMP alignment identified for CR items
- [ ] Calculator policy matches session (no calc Gr 3–5; calc allowed Session 2 for Gr 6–8, 10)
- [ ] CR items have at least two parts (Part A and Part B minimum)
- [ ] Part C of CR includes explanation/justification component
- [ ] Equation Editor accepts all equivalent forms
- [ ] Multi-Select has exactly 2 correct answers from 5–6 options
- [ ] Real-world context is Kentucky-specific and grade-appropriate
- [ ] All numerical values produce clean, non-ambiguous answers
- [ ] Distractors reflect specific, identifiable student error types
- [ ] DOK level verified against actual cognitive demand
- [ ] Grade 10 items use high school standard notation (HS.A, HS.F, etc.)

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Calculator in Session 1 (Gr 3–5) | No calculator allowed at all for Grades 3–5 | Design all items to not require calculator Gr 3–5 |
| CR with only one part | KSA CR requires multi-part structure | Minimum Part A and Part B |
| EQ with ambiguous decimal/fraction | System may not accept all equivalent forms | List all accepted forms; test in platform |
| Generic context (no KY specificity) | KY assessment values authentic local contexts | Use horse farms, Mammoth Cave, bourbon, coal mining |
| CR explanation prompt missing | DOK 3 requires written justification | Include "Explain what this means in context" |
| Missing Grade 10 | KSA Math tests Grade 10 in addition to 3–8 | Include HS-level items using high school standards |
| Stereotyping Appalachian communities | Cultural sensitivity is essential | Portray communities with economic and cultural complexity |

## 12. PROMPT PATTERNS

The following five patterns reflect the most common KSA Mathematics item structures.

### Pattern 1: Contextual Computation (MC, DOK 2)
> "[Kentucky setting]. [Given information]. [Mathematical question requiring multi-step application]."
> (Options: correct answer + three specific error-type distractors)

### Pattern 2: Multi-Step Context (CR Part A, DOK 2)
> "A [Kentucky context] has [given data]. [Part A: computational task requiring setup + solve]. Show your work."

### Pattern 3: Rate of Change in Context (CR Part C, DOK 3)
> "Your equation has a [slope/rate/coefficient] of [value]. Explain what this number means in the context of [Kentucky scenario]."

### Pattern 4: Error Analysis (MC or CR, DOK 3)
> "[Student name] solved the problem and wrote [incorrect answer/work]. What error did [student] make? Find and show the correct answer."

### Pattern 5: Comparison with Justification (CR, DOK 3)
> "Two [Kentucky scenarios] are described: [Scenario A data] and [Scenario B data]. Which [option] is [more efficient/greater/better value]? Use mathematical evidence to justify your answer."
