## 1. OVERVIEW

| Field | Detail |
|---|---|

| **Administering Agency** | Kentucky Department of Education (KDE) |
| **Vendor** | Cognia |

| **Performance Levels** | 4 levels: Novice, Apprentice, Proficient, Distinguished |
| **Reporting** | Individual Student Reports; School, District, State aggregates |

> **CRITICAL NOTE:** The KSA replaced Kentucky's previous K-PREP assessment. KSA items align exclusively to the **Kentucky Academic Standards (KAS)**, which are Kentucky's own adoption and adaptation of standards. Always use KAS standard references when designing items. The KSA is developed and administered through Cognia.

### Performance Levels

| Level | Label | Description |
|---|---|---|
| 1 | **Novice** | Student demonstrates minimal understanding of grade-level ELA standards; significant gaps in reading and writing skills |
| 2 | **Apprentice** | Student demonstrates partial understanding of grade-level ELA standards; inconsistent application of skills |
| 3 | **Proficient** | Student demonstrates sufficient understanding of grade-level ELA standards; meets expectations for college/career readiness progression |
| 4 | **Distinguished** | Student demonstrates exceptional understanding of grade-level ELA standards; exceeds expectations with advanced analysis and application |

> **Proficiency Target:** Level 3 (Proficient) is the state target. Students scoring Proficient or Distinguished are considered on track for college and career readiness.

## 2. STANDARDS FRAMEWORK

### Kentucky Academic Standards (KAS) for ELA

Kentucky Academic Standards for ELA are organized by strand with grade-level specificity. Standards are referenced using the format: **RL.[Grade].[Standard]** for Reading Literature, **RI.[Grade].[Standard]** for Reading Informational Text, **W.[Grade].[Standard]** for Writing, and **L.[Grade].[Standard]** for Language.

**Strand Overview:**

| Strand Code | Strand Name |
|---|---|
| RL | Reading Literature |
| RI | Reading Informational Text |
| W | Writing |
| SL | Speaking and Listening |
| L | Language |

### Key KAS Reading Standards — Literary Text (RL)

| Standard | Description |
|---|---|
| RL.X.1 | Read closely to determine what the text says explicitly and make logical inferences; cite textual evidence to support conclusions |
| RL.X.2 | Determine a theme or central idea of a text and analyze its development; provide an objective summary |
| RL.X.3 | Analyze how particular elements of a story or drama interact (e.g., setting shapes characters or plot) |
| RL.X.4 | Determine the meaning of words and phrases as used in text, including figurative and connotative meanings |
| RL.X.5 | Analyze how an author's choices concerning text structure create effects such as mystery, tension, or surprise |
| RL.X.6 | Assess how point of view or purpose shapes the content and style of a text |

### Key KAS Reading Standards — Informational Text (RI)

| Standard | Description |
|---|---|
| RI.X.1 | Read closely to determine what the text says explicitly and make logical inferences; cite textual evidence |
| RI.X.2 | Determine a central idea of a text and analyze its development; provide an objective summary |
| RI.X.3 | Analyze how individuals, events, and ideas develop and interact over the course of a text |
| RI.X.4 | Determine the meaning of words and phrases as used in text, including technical meanings |
| RI.X.5 | Analyze the structure an author uses to organize a text, including how sections contribute to the whole |
| RI.X.6 | Determine an author's point of view or purpose and analyze how it is conveyed |
| RI.X.8 | Delineate and evaluate the argument and specific claims in a text, assessing reasoning and evidence |

> **KAS Coding Note:** Replace X with the actual grade number. For example, the Grade 5 theme standard is **RL.5.2**. Grade 10 standards may use the 9–10 band notation (e.g., RL.9-10.2).

## 3. TEST STRUCTURE

KSA ELA is administered in **2 sessions** across one or two days.

```
+-------------------------------------------------------------------+
|              KSA ELA TEST STRUCTURE (Grades 3–8, 10)              |
+---------------------------------+---------------------------------+
|   SESSION 1                     |   SESSION 2                     |
|   ~60 minutes                   |   ~60 minutes                   |
|                                 |                                 |
|  READING PASSAGES               |  READING PASSAGES               |
|  - Literary + Informational     |  - Literary + Informational     |
|  - Multiple Choice (MC)         |  - Multiple Choice (MC)         |
|  - Multi-Select (MS)            |  - Multi-Select (MS)            |
|  - EBSR (Evidence-Based         |  - EBSR (Evidence-Based         |
|    Selected Response)           |    Selected Response)           |
|  - Constructed Response (CR)    |  - Constructed Response (CR)    |
+---------------------------------+---------------------------------+
```

### Session Item Counts by Grade Band

| Session | Grades 3–5 | Grades 6–8 | Grade 10 |
|---|---|---|---|
| Session 1 | 12–16 MC/MS/EBSR + 1 CR | 14–18 MC/MS/EBSR + 1 CR | 16–20 MC/MS/EBSR + 1 CR |
| Session 2 | 12–16 MC/MS/EBSR + 1 CR | 14–18 MC/MS/EBSR + 1 CR | 16–20 MC/MS/EBSR + 1 CR |

> KSA ELA includes a mix of literary and informational passages in each session. Passages may be paired for cross-text analysis at higher grades.

## 5. ITEM TYPES

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Single correct answer                                   |
|  Machine scored                                          |
|  DOK 1–2                                                 |
|  Both sessions                                           |
+----------------------------------------------------------+
```

**MC Example (Grade 5, DOK 2, RL.5.2 — Theme):**

*Passage excerpt: A young boy living near Mammoth Cave discovers that his grandfather's stories about the cave's history connect to his own sense of belonging in the Appalachian community.*

Which statement BEST expresses a theme of this passage?

- A. Caves are dangerous places that should be avoided
- B. Family stories help people understand who they are
- C. Older generations always know more than younger ones
- D. Living in rural areas is better than living in cities

*Correct Answer: B*

---

### Multi-Select (MS)

```
+----------------------------------------------------------+
|  MULTI-SELECT — 1 point (all-or-nothing)                 |
|                                                          |
|  5–7 options                                             |
|  Student selects 2 or more correct answers               |
|  No partial credit                                       |
|  Machine scored                                          |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**MS Example (Grade 7, DOK 2, RI.7.1 — Textual Evidence):**

*"Which TWO details from the article BEST support the idea that the Kentucky horse industry has a significant economic impact on the state? Select two answers."*

- A. Kentucky has a long tradition of raising thoroughbred horses
- B. The horse industry contributes over four billion dollars annually to Kentucky's economy
- C. The Kentucky Derby is held on the first Saturday in May
- D. Horse farms employ more than 40,000 workers across the state
- E. Horses were first brought to Kentucky by early settlers

*Correct Answers: B and D*

---

### Evidence-Based Selected Response (EBSR)

```
+----------------------------------------------------------+
|  EVIDENCE-BASED SELECTED RESPONSE (EBSR) — 2 points     |
|                                                          |
|  Two-part item                                           |
|  Part A: Analytical question (MC format)                 |
|  Part B: Select evidence that supports Part A answer     |
|  1 point per part (2 points total)                       |
|  Machine scored                                          |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**EBSR Example (Grade 8, DOK 2, RL.8.4 — Word Meaning):**

*Part A: In paragraph 3, what does the phrase "a seam of light" MOST LIKELY mean in the context of the passage about a coal miner's journey through Cumberland Gap?*

- A. A crack in the rock that allows light to enter
- B. A narrow opportunity or moment of hope
- C. A type of mineral found in coal mines
- D. A sewing technique used by miners' families

*Correct Answer: B*

*Part B: Which sentence from the passage BEST supports your answer to Part A?*

- A. "The miners descended into the darkness each morning before dawn."
- B. "Jonas saw the gap ahead and felt, for the first time, that escape was possible."
- C. "Coal dust covered every surface in the small mountain town."
- D. "The tools they carried were heavy and worn from years of use."

*Correct Answer: B*

---

### Constructed Response (CR)

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE — 0–2 or 0–4 points                |
|                                                          |
|  Written response (1–3 paragraphs typical)               |
|  Must cite textual evidence with elaboration             |
|  Human scored using CR rubric                            |
|  DOK 3                                                   |
|  1–2 per test                                            |
+----------------------------------------------------------+
```

**CR Example (Grade 10, DOK 3, RI.9-10.6 + RI.9-10.8):**

*"The article 'Bourbon and the Bluegrass' describes how Kentucky's bourbon industry has shaped the state's identity and economy. How does the author use evidence to argue that bourbon production is both a cultural tradition and an economic driver? Use details from the text to support your response."*

## 6. DEPTH OF KNOWLEDGE (DOK)

| DOK | Label | KSA ELA Application Examples |
|---|---|---|
| 1 | Recall & Reproduction | Identify the setting; define a word using direct context clues |
| 2 | Skills & Concepts | Explain how a character's perspective affects plot; analyze text structure; determine theme |
| 3 | Strategic Thinking | Evaluate effectiveness of author's argument; synthesize across two texts; analyze rhetorical choices |

> **CR items target DOK 3.** EBSR items often target DOK 2–3. Standard MC items are predominantly DOK 2.

## 8. SCORING RUBRICS

### Constructed Response (CR) Rubric — 0–2 Points (Short CR)

| Score | Criteria |
|---|---|
| 2 | Response clearly addresses the prompt with accurate textual evidence and thorough elaboration; demonstrates strong understanding of the text |
| 1 | Response partially addresses the prompt; evidence may be present but vague or incomplete; limited elaboration |
| 0 | Response does not address the prompt; blank; off-topic; copied from passage; or incomprehensible |

### Constructed Response (CR) Rubric — 0–4 Points (Extended CR)

| Score | Criteria |
|---|---|
| 4 | Response demonstrates thorough understanding; cites specific, well-chosen textual evidence; provides detailed elaboration that clearly connects evidence to the analytical focus; sophisticated analysis |
| 3 | Response demonstrates adequate understanding; cites relevant textual evidence; provides sufficient elaboration connecting evidence to the prompt |
| 2 | Response demonstrates partial understanding; some evidence cited but may be imprecise; elaboration is limited or underdeveloped |
| 1 | Response demonstrates minimal understanding; little or no relevant evidence; elaboration absent or confused |
| 0 | Response is blank, off-topic, copied from the passage, or incomprehensible |

> **EBSR Scoring:** Each part of an EBSR is worth 1 point, for a total of 2 points. Part A and Part B are scored independently — a student can earn credit for Part B even if Part A is incorrect, provided the Part B answer is internally consistent.

## 11. QUALITY CHECKLIST AND COMMON PITFALLS

### Quality Checklist

- [ ] Standard code uses KAS format: RL.[Grade].[Standard] or RI.[Grade].[Standard]
- [ ] Passage Lexile is within grade-band range (see Section 7)
- [ ] MC options are plausible; no "trick" or obviously wrong choices
- [ ] Multi-Select requires exactly 2 correct answers from 5–7 options
- [ ] EBSR Part A and Part B are logically connected
- [ ] EBSR Part B options are actual text excerpts from the passage
- [ ] CR prompt includes clear analytical focus (not "summarize")
- [ ] CR prompt ends with evidence directive ("Use evidence from the text...")
- [ ] CR rubric anchor responses written before item is finalized
- [ ] Kentucky-specific context used where appropriate
- [ ] Grade 10 items use 9–10 band standard notation
- [ ] DOK level verified against item cognitive demand
- [ ] No reference to former K-PREP assessment structures

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Using generic national contexts | KSA values Kentucky-specific authenticity | Anchor passages in real KY places and communities |
| EBSR Part B with non-text options | Part B must reference actual passage text | Ensure all Part B options are direct excerpts |
| CR prompt that asks to summarize | Summarizing is not DOK 3 analytical thinking | Frame prompt around analysis, argument, or author purpose |
| Ignoring Appalachian cultural sensitivity | Stereotyping coal mining or rural communities | Portray Appalachian culture with dignity and complexity |
| MS item with 3+ correct answers | Students cannot reliably identify all-or-nothing | Keep MS to exactly 2 correct answers from 5–7 options |
| Confusing KAS with other state standards | Kentucky has its own standards framework | Always reference Kentucky Academic Standards |
| Missing Grade 10 in test design | KSA ELA tests Grade 10 (not just 3–8) | Include Grade 10 items using 9–10 band standards |

## 12. PROMPT PATTERNS

The following five patterns reflect the most commonly tested item structures on KSA ELA.

### Pattern 1: Theme Development (CR, DOK 3, RL.X.2)
> "In '[passage title],' the author develops the theme that [theme]. How do the characters' [actions/decisions/experiences] throughout the story support this theme? Use evidence from the text to support your response."

### Pattern 2: Author's Purpose and Evidence (CR, DOK 3, RI.X.6 + RI.X.8)
> "In the article '[title],' the author argues that [central claim]. How does the author use evidence and rhetorical strategies to support this argument? Use specific details from the text to support your response."

### Pattern 3: Figurative Language and Meaning (EBSR, DOK 2, RL.X.4 or L.X.5)
> Part A: "Read this sentence from the passage: '[sentence with figurative language].' What does this [metaphor/simile/idiom] MOST LIKELY mean?"
> Part B: "Which sentence from the passage BEST supports your answer to Part A?"

### Pattern 4: Point of View and Effect (MC/MS, DOK 2, RL.X.6 or RI.X.6)
> "How does the [narrator's/author's] point of view affect the reader's understanding of [event/character/idea]? Select [one/two] answer(s) that BEST explain this effect."

### Pattern 5: Text Structure and Central Idea (MC, DOK 2, RI.X.5)
> "How does the structure of the article help the reader understand the central idea about [topic]? Which organizational pattern does the author use, and why is it effective?"
