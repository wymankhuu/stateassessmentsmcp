## 1. OVERVIEW

| Field | Detail |
|---|---|
| **Assessment Name** | MAAP — Mississippi Academic Assessment Program, Mathematics |
| **Administering Agency** | Mississippi Department of Education (MDE) |
| **Vendor** | Questar (ETS successor) |
| **Grades Tested** | 3, 4, 5, 6, 7, 8, 10 (Algebra I) |
| **Testing Window** | April–May (annual summative) |
| **Delivery** | Computer-based testing (CBT); paper accommodations available |
| **Standards** | Mississippi College- and Career-Readiness Standards (MS CCRS) for Mathematics — CCSS-aligned |
| **Performance Levels** | 4 levels: Level 1 (Minimal), Level 2 (Basic), Level 3 (Pass/Proficient), Level 4 (Advanced) |
| **Calculator Policy** | No calculator Grades 3–5; Calculator allowed on designated sections Grades 6–8, 10 |
| **Grade 10** | Algebra I end-of-course assessment |

> **CRITICAL NOTE:** MAAP Mathematics aligns to the **Mississippi College- and Career-Readiness Standards (MS CCRS)** for Mathematics, which are aligned to CCSS Mathematics. Standard codes follow the CCSS format (e.g., 5.NBT.5, 8.EE.7). Grade 10 tests Algebra I standards (A-SSE, A-CED, A-REI, F-IF, F-BF, F-LE, S-ID).

### Performance Levels

| Level | Label | Description |
|---|---|---|
| 1 | **Minimal** | Student demonstrates minimal understanding of grade-level math standards; significant computational and conceptual gaps |
| 2 | **Basic** | Student demonstrates partial understanding; inconsistent procedural and reasoning skills |
| 3 | **Pass (Proficient)** | Student demonstrates sufficient understanding; meets college/career readiness progression expectations |
| 4 | **Advanced** | Student demonstrates thorough mathematical understanding; extends reasoning beyond grade-level expectations |

> **Proficiency Target:** Level 3 (Pass) is the state proficiency target.

## 3. TEST STRUCTURE

MAAP Mathematics is administered in **2 sessions** across one or two days.

```
+------------------------------------------------------------------+
|          MAAP MATHEMATICS STRUCTURE (Grades 3–8, 10)              |
+----------------------------------+-------------------------------+
|   SESSION 1                      |   SESSION 2                   |
|   ~60 minutes                    |   ~60 minutes                 |
|                                  |                               |
|  MC items (1 pt)                 |  MC items (1 pt)              |
|  Multi-Select items (1 pt)       |  Multi-Select items (1 pt)    |
|                                  |  Constructed Response (0–2 pt)|
|                                  |                               |
|  NO calculator (Gr 3–5)         |  NO calculator (Gr 3–5)       |
|  No-calc section (Gr 6–8, 10)  |  Calculator allowed (Gr 6–8, 10) |
+----------------------------------+-------------------------------+
```

### Session Item Counts by Grade Band

| Session | Grades 3–5 | Grades 6–8 | Grade 10 |
|---|---|---|---|
| Session 1 | 20–24 MC/MS (no calculator) | 18–22 MC/MS (no-calc section) | 18–22 MC/MS (no-calc section) |
| Session 2 | 16–20 MC/MS + 1–2 CR | 16–20 MC/MS + 1–2 CR (calc) | 16–20 MC/MS + 1–2 CR (calc) |

> **Calculator Policy:** Grades 3–5 have no calculator for any session. Grades 6–8 and 10 have a no-calculator session (Session 1) and a calculator-permitted session (Session 2).

## 5. ITEM TYPES

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Single correct answer                                   |
|  Machine scored                                          |
|  Both sessions                                           |
|  DOK 1–2                                                 |
+----------------------------------------------------------+
```

**MC Example (Grade 6, DOK 2, 6.RP.3 — Unit Rates):**

The Mississippi River is approximately 2,340 miles long. A boat travels from Memphis, Tennessee, to Vicksburg, Mississippi, a distance of 234 miles, in 18 hours. What is the boat's average speed in miles per hour?

- A. 11 miles per hour
- B. 13 miles per hour
- C. 15 miles per hour
- D. 18 miles per hour

*Correct Answer: B (234 / 18 = 13)*
*Alignment: 6.RP.3b | DOK 2*

---

### Multi-Select (MS)

```
+----------------------------------------------------------+
|  MULTI-SELECT — 1 point (all-or-nothing)                 |
|                                                          |
|  5–6 options                                             |
|  Student selects ALL correct answers (typically 2)       |
|  Machine scored; no partial credit                       |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**MS Example (Grade 7, DOK 2, 7.RP.2 — Proportional Relationships):**

A Mississippi Delta cotton farm produces 1,200 pounds of cotton per acre. Which TWO statements describe a proportional relationship between acres planted (a) and pounds of cotton produced (p)?

- A. p = 1,200a
- B. p = 1,200 + a
- C. The ratio of pounds to acres is constant at 1,200
- D. As acres double, the pounds of cotton increase by 1,200
- E. When 0 acres are planted, 0 pounds of cotton are produced

*Correct Answers: A and C*

---

### Constructed Response (CR)

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE — 0–2 points                       |
|                                                          |
|  Brief response with work shown                          |
|  1–3 step solution                                       |
|  Human scored                                            |
|  Session 2 only                                          |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**CR Example (Grade 8, DOK 3, 8.F.4 + 8.SP.1):**

*A farmer in the Mississippi Delta tracked the number of acres of cotton planted and the total harvest in bales for each year.*

| Year | Acres | Bales |
|---|---|---|
| 2021 | 200 | 340 |
| 2022 | 350 | 595 |
| 2023 | 500 | 850 |

*Part A: Determine the rate of bales produced per acre. Show your work.*

*Part B: Explain how you know the relationship between acres and bales is proportional, and predict how many bales would be produced from 700 acres.*

## 7. MATHEMATICAL PRACTICES AND REASONING

### Standards for Mathematical Practice (SMP) on MAAP

MAAP Mathematics assesses the CCSS Standards for Mathematical Practice through item design, particularly in constructed response items.

| SMP | Practice | How It Appears on MAAP |
|---|---|---|
| MP.1 | Make sense of problems; persevere | Multi-step CR items requiring entry point identification |
| MP.2 | Reason abstractly and quantitatively | Items requiring translation between context and math |
| MP.3 | Construct arguments; critique reasoning | CR items asking "Explain" or "Justify your answer" |
| MP.4 | Model with mathematics | Mississippi-context word problems; data interpretation |
| MP.5 | Use appropriate tools strategically | Calculator/no-calculator section design |
| MP.6 | Attend to precision | Exact answers; appropriate units; precise vocabulary |
| MP.7 | Look for and make use of structure | Pattern items; equivalent expression identification |
| MP.8 | Express regularity in repeated reasoning | Function rule items; generalization in context |

> **MP.3 and MP.4 are the most visible on MAAP Mathematics.** CR items frequently require justification (MP.3) and real-world Mississippi contexts (MP.4).

## 8. SCORING RUBRICS

### Constructed Response (CR) Rubric — 0–2 Points

| Score | Criteria |
|---|---|
| 2 | Correct answer with complete work shown; solution process is clear, logical, and demonstrates solid understanding of the concept |
| 1 | Partially correct answer or correct approach with computational error; some work shown; demonstrates partial understanding |
| 0 | Incorrect answer with no valid work; blank; or demonstrates no understanding of the mathematical task |

## 10. CONTEXTUALIZATION — MISSISSIPPI MATH

When generating real-world math contexts, prioritize authentic Mississippi settings:

### Recommended Math Contexts

| Context | Grade Band | Math Domains |
|---|---|---|
| Mississippi River dimensions and flow data | 5–10 | Ratios, unit rates, proportional reasoning, functions |
| Delta cotton production statistics | 4–8 | Multiplication, fractions, ratios, proportions |
| Mississippi Delta farmland acreage | 3–7 | Area, perimeter, multiplication, measurement |
| Catfish farming production data | 4–8 | Ratios, percents, data analysis, multiplication |
| Mississippi population data by county | 6–10 | Statistics, percents, data analysis, functions |
| Gulf Coast shrimp harvest quantities | 5–8 | Ratios, data analysis, statistics |
| Natchez Trace Parkway distances | 4–7 | Measurement, fractions, unit conversion |
| Vicksburg bridge engineering dimensions | 6–10 | Geometry, Pythagorean theorem, ratios |
| Mississippi timber industry production | 5–8 | Ratios, measurement, data analysis |
| Mississippi school enrollment data | 6–10 | Statistics, percents, functions |

### Sample Context Sentence Starters

- "The Mississippi River is approximately 2,340 miles long. A section near Vicksburg..."
- "A cotton farm in the Mississippi Delta planted [X] acres and harvested [Y] bales..."
- "The Natchez Trace Parkway stretches 444 miles from Natchez, Mississippi, to Nashville, Tennessee..."
- "A catfish farm in Belzoni, Mississippi, produces [X] pounds of catfish per pond each year..."
- "The distance from Jackson, Mississippi, to Biloxi on the Gulf Coast is approximately [X] miles..."

## 11. QUALITY CHECKLIST AND COMMON PITFALLS

### Quality Checklist

- [ ] Standard code uses CCSS format (e.g., 6.RP.3, 8.F.4)
- [ ] SMP alignment identified for CR items
- [ ] Calculator policy matches session (no calculator Session 1; calc allowed Session 2 for Gr 6–8, 10)
- [ ] CR items have at least Part A and Part B
- [ ] CR includes explanation or justification component
- [ ] Multi-Select has exactly 2 correct answers from 5–6 options
- [ ] Real-world context is Mississippi-specific and grade-appropriate
- [ ] All numerical values produce clean, non-ambiguous answers
- [ ] Distractors reflect specific, identifiable student error types
- [ ] DOK level verified against actual cognitive demand
- [ ] Grade 10 items specify Algebra I standards (A-SSE, A-CED, A-REI, F-IF, etc.)
- [ ] Performance levels use Mississippi terminology (Minimal through Advanced)

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Calculator on Session 1 | Session 1 is no-calculator for all grades | Design Session 1 items to not require calculator |
| No calculator for Grades 3–5 | No calculator allowed at all for Grades 3–5 | All Gr 3–5 items must be solvable without calculator |
| CR without explanation | DOK 3 requires written justification | Include "Explain" or "Justify" in Part B |
| Generic context (no MS specificity) | Mississippi test values authentic MS contexts | Use Mississippi River, Delta farmland, catfish, cotton |
| Confusing Level 3 (Pass) with Level 2 (Basic) | Level 3 is proficiency target | Target item difficulty to Level 3 performance |
| Grade 10 items without Algebra I scope | Grade 10 tests Algebra I specifically | Restrict to Algebra I standards |
| EQ-type items on MAAP | MAAP Math uses MC, MS, and CR only | Do not include Equation Entry items |

## 12. PROMPT PATTERNS

The following patterns reflect the most common MAAP Mathematics item structures.

### Pattern 1: Contextual Computation (MC, DOK 2)
> "[Mississippi setting]. [Given information]. [Mathematical question requiring multi-step application]."
> (Options: correct answer + three specific error-type distractors)

### Pattern 2: Proportional Reasoning (MC or MS, DOK 2)
> "A [Mississippi context] has [given rate or ratio]. [Find missing quantity / identify proportional relationship]."

### Pattern 3: Data Interpretation (MC or CR, DOK 2–3)
> "The table/graph below shows [Mississippi data set]. Based on the data, [find the value / describe the pattern / make a prediction]."

### Pattern 4: Explain and Justify (CR Part B, DOK 3)
> "Explain how you determined your answer. Use mathematical reasoning to justify why your approach is correct."

### Pattern 5: Error Analysis (MC, DOK 3)
> "[Student name] solved the problem and wrote [incorrect answer]. What error did [student] make?"

### Pattern 6: Algebraic Modeling (MC or CR, DOK 2–3, Grade 10)
> "[Mississippi scenario with variable relationship]. Write an equation to represent [situation]. Use the equation to [predict / solve / interpret]."
