## 1. Overview

| Field | Detail |
|---|---|
| **Assessment Name** | Rhode Island Comprehensive Assessment System (RICAS) — Science |
| **Administering Agency** | Rhode Island Department of Education (RIDE) |
| **Vendor** | Pearson |
| **Grades Tested** | **Grade 5**, **Grade 8**, **Grade 11** |
| **Testing Window** | March – May |
| **Delivery** | Computer-based; single session |
| **Standards** | Rhode Island Science Standards (incorporating NGSS) |
| **Score Scale** | 4 performance levels; scaled score varies by grade |
| **Reporting** | Individual Student Report; School, District, State aggregates |

> **CRITICAL NOTE:** RICAS Science is administered **only at Grades 5, 8, and 11**. Do not generate RICAS Science items for Grades 3, 4, 6, or 7.

> **RICAS and NGSS:** Rhode Island Science Standards fully incorporate the **Next Generation Science Standards (NGSS)** framework. All items must be three-dimensional: integrating **Disciplinary Core Ideas (DCI)**, **Science and Engineering Practices (SEP)**, and **Crosscutting Concepts (CCC)**.

### Performance Levels

| Level | Label | Description |
|---|---|---|
| 4 | **Exceeding Expectations** | Distinguished three-dimensional science understanding; expertly integrates DCI, SEP, and CCC |
| 3 | **Meeting Expectations** | Strong three-dimensional understanding; appropriately applies practices and crosscutting concepts |
| 2 | **Partially Meeting Expectations** | Partial understanding; limited to surface-level application of science concepts |
| 1 | **Not Meeting Expectations** | Minimal understanding; limited to recall of isolated facts |

## 3. Test Structure

RICAS Science is a single-session, computer-based assessment. All items are scenario-based with data tables, diagrams, graphs, and models as stimuli.

```
+------------------------------------------------------------------+
|           RICAS SCIENCE STRUCTURE (Grades 5, 8, 11)               |
+------------------------------------------------------------------+
|  SINGLE SESSION                                                  |
|  Computer-Based, Fixed-Form                                      |
|  Approximately 90–120 minutes                                    |
|                                                                  |
|  ~40 items per grade                                             |
|                                                                  |
|  Item types:                                                     |
|    Selected Response (SR) — ~55–60% (~24 items)                 |
|    Constructed Response (CR) — ~20–25% (~8–10 items; 0–3 pts)   |
|    Technology Enhanced / Multi-Select — ~15–20% (~6–8 items)     |
+------------------------------------------------------------------+
```

### Grade-Level Test Specifications

| Specification | Grade 5 | Grade 8 | Grade 11 |
|---|---|---|---|
| Total Items (approx.) | ~38–42 | ~38–42 | ~38–42 |
| Selected Response | ~22–26 | ~22–26 | ~22–26 |
| Multi-Select / TE | ~6–8 | ~6–8 | ~6–8 |
| Constructed Response | ~6–10 | ~6–10 | ~6–10 |
| Testing Time | 90–120 min | 90–120 min | 90–120 min |

> **Three-Dimensional Requirement:** Every RICAS Science item must integrate at least one **DCI**, one **SEP**, and one **CCC**. Items that test DCI content in isolation are not aligned to the Rhode Island Science Standards.

## 5. Item Types & Formats

### Selected Response (SR)

```
+----------------------------------------------------------+
|  SELECTED RESPONSE — 1 point                             |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Scenario, diagram, data table, or model stimulus        |
|  Must integrate DCI + SEP + CCC                          |
|  Machine scored                                          |
+----------------------------------------------------------+
```

**SR Example (Grade 8, DOK 2, MS-ESS2-2 — Geoscience Processes):**

Scientists studying the Rhode Island coastline found that the same type of glacial till (a mixture of rocks and sediment left by glaciers) appears along beaches in Narragansett and on Block Island, 12 miles offshore. Which explanation BEST accounts for this observation?

A. Ocean currents carried the glacial material from Narragansett to Block Island over centuries
B. A continental glacier deposited the material across the entire region, and rising sea levels later separated Block Island from the mainland
C. Volcanic activity beneath the ocean floor pushed glacial till to the surface at both locations
D. Wind erosion transported rock fragments from inland areas to both coastal locations simultaneously

*Correct Answer: B*
*Alignment: MS-ESS2-2 | SEP: Constructing Explanations | CCC: Stability and Change | DOK 2*

---

**SR Example (Grade 5, DOK 2, 5-LS2-1 — Ecosystem Matter Flow):**

A diagram shows: Sunlight -> Eelgrass -> Blue crabs -> Striped bass

Which statement BEST explains the role of eelgrass in this Narragansett Bay ecosystem model?

A. Eelgrass receives energy from blue crabs through a food chain
B. Eelgrass captures energy from the sun and stores it in its cells
C. Eelgrass is a decomposer that breaks down dead organisms on the bay floor
D. Eelgrass gets energy from the sandy bay bottom through its root system

*Correct Answer: B*
*Alignment: 5-LS2-1 | SEP: Developing and Using Models | CCC: Energy and Matter | DOK 2*

### Constructed Response (CR)

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE — 0–3 points                       |
|                                                          |
|  Written explanation using evidence from the stimulus    |
|  Stimulus always provided (data, diagram, scenario)      |
|  Must demonstrate three-dimensional reasoning            |
|  Human scored                                            |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**CR Example (Grade 8, DOK 3, MS-ESS3-3 — Human Impact):**

*Stimulus: A data table showing nitrogen levels, dissolved oxygen, water clarity, and shellfish population counts in Narragansett Bay at three locations: upper bay near Providence, mid-bay near Warwick, and lower bay near Newport. Near Providence, nutrient levels are highest and dissolved oxygen and shellfish counts are lowest.*

*"Using data from the table, construct an explanation for the relationship between nutrient levels and shellfish populations at different points along Narragansett Bay. Include specific evidence from the data and explain the cause-and-effect relationships involved."*

---

**CR Example (Grade 11, DOK 3, HS-ESS2-2 — Earth Systems Feedbacks):**

*Stimulus: Graph showing shoreline retreat rates (in feet per year) at five Rhode Island coastal locations from 1950–2020, with retreat rates accelerating in recent decades alongside rising sea levels.*

*"Using evidence from the graph, analyze how rising sea levels have affected coastal erosion rates along the Rhode Island shoreline. Explain how accelerating erosion could create feedback effects on other systems, including coastal ecosystems, freshwater resources, and human infrastructure."*

## 7. Three-Dimensional Design

Every RICAS Science item must reflect all three NGSS dimensions simultaneously.

### Three-Dimensions Alignment Guide

| Dimension | What It Is | Example in RICAS Items |
|---|---|---|
| **DCI** (What students know) | Disciplinary science content | Narragansett Bay marine ecology; Rhode Island coastal geology; glacial landforms; chemical reactions; energy transfer |
| **SEP** (What students do) | How scientists work | Analyze water quality data; construct explanations from evidence; use models to predict ecosystem changes |
| **CCC** (Lens of thinking) | Cross-domain thinking tools | Cause and effect; patterns; energy and matter; structure and function; systems and system models |

### Crosscutting Concepts by Grade Band

| CCC | Grade 5 Emphasis | Grade 8 Emphasis | Grade 11 Emphasis |
|---|---|---|---|
| Patterns | Seasonal cycles in Narragansett Bay ecosystems; tidal patterns | Weather patterns; population trend data in coastal species | Periodic table patterns; evolutionary change |
| Cause and Effect | Food chain disruption; coastal erosion processes | Pollution impacts on bay water quality; chemical reactions | Climate feedbacks; homeostasis disruption |
| Energy and Matter | Food webs in bay ecosystems; water cycle | Chemical reactions; thermal transfer in ocean currents | Metabolic pathways; Earth energy systems |
| Structure and Function | Marine organism adaptations to bay environments | Shellfish anatomy; cell structures | DNA and protein structure; organ systems |
| Systems and System Models | Bay ecosystems; water cycle | Narragansett Bay watershed; Earth systems | Climate systems; biological feedback loops |

## 8. Scoring Rubrics

### Constructed Response (CR) Rubric — 0–3 Points

| Score | Criteria |
|---|---|
| 3 | Response accurately addresses the science concept; demonstrates clear three-dimensional understanding (DCI + SEP or CCC evident); includes specific, relevant evidence from the stimulus; explanation is complete, accurate, and logically connected |
| 2 | Response addresses the science concept with partial accuracy; shows understanding of the DCI but only partially integrates a practice or crosscutting concept; evidence present but may be incomplete |
| 1 | Response minimally addresses the science concept; shows limited understanding; little or no evidence from stimulus; explanation vague or contains science inaccuracies |
| 0 | Response does not address the concept; blank; off-topic; restates stimulus without explanation |

### CR Scoring Notes

- **Evidence from the stimulus is required.** Responses relying solely on prior knowledge without referencing the provided data earn a maximum of 1 point.
- **Three-dimensional reasoning earns full credit.** A Score 3 integrates content knowledge (DCI) with at least one SEP or CCC.
- **Misconceptions reduce the score.** A significant scientific misconception drops the response by one score point.

## 10. Contextualization — Rhode Island Science

When generating RICAS Science items, prioritize authentic Rhode Island natural settings:

### Rhode Island Science Context Guide

| Setting / Phenomenon | Grade | Science Domain | PE Alignment |
|---|---|---|---|
| Narragansett Bay marine ecology (eelgrass, quahogs, fish) | 5, 8, 11 | Life Science | 5-LS2, MS-LS2, HS-LS2 |
| Rhode Island coastal erosion and sea level rise | 5, 8, 11 | Earth Science | 5-ESS2, MS-ESS2, HS-ESS2 |
| Block Island glacial geology and landforms | 5, 8 | Earth Science | 5-ESS2, MS-ESS2 |
| Narragansett Bay water quality and pollution | 8, 11 | Earth/Life Science | MS-ESS3, HS-ESS3 |
| Rhode Island salt marsh ecosystems | 5, 8 | Life Science | 5-LS2, MS-LS2 |
| Providence urban heat island effect | 8, 11 | Earth/Physical Science | MS-ESS3, HS-ESS2 |
| Rhode Island wind farm (Block Island Wind Farm) | 8, 11 | Physical Science | MS-PS3, HS-PS3 |
| Tidal patterns in Narragansett Bay | 5, 8 | Earth Science | 5-ESS2, MS-ESS2 |
| Shellfish aquaculture and water chemistry | 8, 11 | Physical/Life Science | MS-PS1, HS-PS1 |
| Rhode Island forest recovery after colonial clearing | 5, 8, 11 | Life/Earth Science | 5-LS2, MS-LS2, HS-LS4 |
| Barrier beach formation and coastal dynamics | 8, 11 | Earth Science | MS-ESS2, HS-ESS2 |
| Rhode Island invasive species (e.g., green crabs) | 5, 8 | Life Science | 5-LS2, MS-LS2 |

### Suggested Anchoring Phenomena by Grade

**Grade 5 Phenomena:**
- "Every spring, millions of menhaden fish swim into Narragansett Bay to spawn, attracting seabirds, seals, and striped bass. How does matter and energy move through this bay ecosystem?"
- "Rhode Island's salt marshes are slowly shrinking, even though new grass grows every year. What processes cause salt marshes to change over time?"
- "Students visiting a Rhode Island beach found smooth, round rocks next to jagged, sharp rocks on the same stretch of shore. What could explain these different shapes?"

**Grade 8 Phenomena:**
- "Water quality data shows that Narragansett Bay has significantly less dissolved oxygen in summer than in winter, especially in the upper bay near Providence. What factors explain this seasonal pattern?"
- "Block Island is slowly getting smaller — scientists estimate the island loses about 2 feet of shoreline each year along its southeastern bluffs. What geoscience processes cause this erosion, and how might rising sea levels accelerate it?"
- "The Block Island Wind Farm generates electricity from ocean winds. How does the design of the turbine convert the kinetic energy of wind into electrical energy for Rhode Island homes?"

**Grade 11 Phenomena:**
- "Narragansett Bay's average water temperature has risen by 3 degrees Fahrenheit over the past 50 years, and species that were once rare, like black sea bass, are now common, while cold-water species like winter flounder have declined. Analyze how temperature change creates feedback effects across the bay's ecological systems."
- "Rhode Island's coastal groundwater aquifers are showing increased salinity in areas where sea levels have risen. Explain how rising sea levels affect freshwater systems and the feedback mechanisms involved."

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] Grade verified as 5, 8, or 11 ONLY
- [ ] PE code is a valid NGSS Performance Expectation
- [ ] Item is three-dimensional: DCI + SEP + CCC all identified
- [ ] Anchoring phenomenon is authentic and Rhode Island-relevant where possible
- [ ] Stimulus (data table/graph/diagram) has clear labels, units, and realistic data
- [ ] CR prompt directs students to use evidence from the stimulus
- [ ] All distractors represent real misconceptions (not obviously wrong)
- [ ] MS items specify how many answers to select (TWO/THREE)
- [ ] Score 3 anchor response written before finalizing CR item
- [ ] Science content is accurate and reflects current scientific understanding
- [ ] Vocabulary is grade-appropriate

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Writing items for Grades 3, 4, 6, or 7 | RICAS Science only at Grades 5, 8, 11 | Restrict to tested grades |
| DCI-only items (no SEP or CCC) | RICAS requires three-dimensional items | Always embed a practice and crosscutting concept |
| CR prompts without evidence directive | Students may respond without citing data | Include "Use evidence from the [data/graph/diagram]" |
| Generic science phenomena not anchored to Rhode Island | RICAS benefits from Rhode Island contexts | Use Narragansett Bay, Block Island, coastal erosion contexts |
| MS items with only 2 options in 4 total | Too easy to guess | Use 5–6 options with exactly 2–3 correct |

## 12. Prompt Patterns

### Pattern 1: Data-to-Conclusion (SR, DOK 2)
> "The [graph / table / diagram] below shows [Rhode Island science scenario]. Based on the data, which [conclusion / explanation / pattern] is BEST supported?"

### Pattern 2: Phenomenon Explanation (CR, DOK 3)
> "Scientists observed [Rhode Island-anchored phenomenon]. Using evidence from the [data / model / diagram], construct an explanation for [specific science focus]. Explain the [cause-and-effect / energy flow / pattern] relationship."

### Pattern 3: Model Evaluation (SR or MS, DOK 2–3)
> "A student made a model showing [Rhode Island science concept]. Which statement BEST describes what the model shows about [DCI focus]?"

### Pattern 4: Investigation Design (CR, DOK 3)
> "A scientist in Rhode Island wants to investigate whether [variable] affects [outcome] in [Narragansett Bay / coastal ecosystem]. Describe a procedure the scientist could follow. Include what would be measured and how the scientist would know if the variable made a difference."

### Pattern 5: Evidence-Based Argument (CR, DOK 3)
> "Two students disagree about [Rhode Island science claim]. Student A says [misconception]. Student B says [accurate claim]. Using evidence from the [data / diagram], explain which student is correct and why."

### Pattern 6: Human Impact and Solutions (MS or CR, DOK 2–3)
> "Human activities have [impacted Rhode Island's coastal environment]. Select the TWO strategies that BEST [monitor / reduce / address] this impact."
