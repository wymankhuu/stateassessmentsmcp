| **Administering Agency** | Rhode Island Department of Education (RIDE) |

| **Score Scale** | 440–560 scale score (varies by grade); 4 performance levels |
| **Reporting** | Individual Student Report; School, District, State aggregates |

> **RICAS and PARCC:** RICAS ELA is derived from the **Partnership for Assessment of Readiness for College and Careers (PARCC)** design. Item types, task models, and rubrics reflect the PARCC architecture: Literary Analysis Task (LAT), Research Simulation Task (RST), and Narrative Writing Task (NWT). Rhode Island uses **Rhode Island Core Standards (RICS)**, which are aligned to CCSS ELA, with passages reflecting Rhode Island geography, history, and culture.

### Performance Levels

| Level | Label | Description |
|---|---|---|
| 4 | **Exceeding Expectations** | Student demonstrates distinguished command of the knowledge and skills in the Rhode Island Core Standards; advanced analysis and evidence use |
| 3 | **Meeting Expectations** | Student demonstrates strong command of the knowledge and skills; thorough analysis with relevant evidence |
| 2 | **Partially Meeting Expectations** | Student demonstrates partial command; limited analysis and inconsistent evidence use |
| 1 | **Not Meeting Expectations** | Student demonstrates minimal command; significant gaps in grade-level expectations |

## 2. Standards Framework

> **Reference:** See `_shared/ccss_ela_framework.md` for full CCR Anchor Standards and grade-by-grade progressions. Rhode Island uses the **Rhode Island Core Standards (RICS)**, which incorporate Common Core ELA standards. Standards are referenced using RICS codes (e.g., RICS.ELA.RL.3.1).

### Reading Literature (RL) — Key Standards by Grade Band

| Standard | Gr 3–5 Focus | Gr 6–8 Focus | Gr 11 Focus |
|---|---|---|---|
| **RICS.RL.1** — Key details & inference | Explicit details; simple inference from text | Cite textual evidence; analyze what text says explicitly vs. inferentially | Cite strong and thorough textual evidence to support analysis |
| **RICS.RL.2** — Theme / central idea | Determine message or lesson; summarize | Analyze theme development; how it emerges through characters and plot | Analyze how themes develop and interact over the course of a text |
| **RICS.RL.3** — Character, setting, events | Describe characters' traits and responses | Analyze how dialogue and incidents reveal character and advance plot | Analyze impact of author's choices regarding story elements |
| **RICS.RL.4** — Word meaning | Determine meaning of words; recognize figurative language | Analyze figurative and connotative meanings; word choice and tone | Determine multiple meanings; analyze how word choice shapes meaning and tone |
| **RICS.RL.6** — Point of view | Identify narrator's point of view | Analyze how differences in POV create effects like suspense or humor | Analyze a case in which grasping point of view requires distinguishing the author's from the characters' |

### Reading Informational Text (RI) — Key Standards by Grade Band

| Standard | Gr 3–5 Focus | Gr 6–8 Focus | Gr 11 Focus |
|---|---|---|---|
| **RICS.RI.1** — Key details & inference | Quote accurately; draw inferences | Cite textual evidence supporting analysis | Cite strong and thorough textual evidence; determine where text leaves matters uncertain |
| **RICS.RI.3** — Connections & relationships | Explain relationships between events, ideas, or concepts | Analyze how a text makes connections between ideas | Analyze a complex set of ideas or sequence of events |
| **RICS.RI.6** — Author's purpose & point of view | Identify author's purpose | Determine author's point of view; analyze how purpose shapes content | Determine an author's point of view or purpose; analyze rhetoric |
| **RICS.RI.8** — Argument & evidence | Explain how reasons support points | Trace and evaluate argument; assess whether reasoning is sound | Delineate and evaluate reasoning in seminal U.S. texts |
| **RICS.RI.9** — Compare/integrate information | Compare multiple texts on same topic | Analyze how two texts treat similar topics differently | Analyze foundational U.S. documents of historical and literary significance |

### Writing Standards

| Standard | Focus | DOK |
|---|---|---|
| **RICS.W.1** — Argument/Opinion | Write arguments with clear claims, evidence, and reasoning | 3–4 |
| **RICS.W.2** — Informative/Explanatory | Develop topics with facts, details, definitions, examples | 3 |
| **RICS.W.3** — Narrative | Establish situation; develop narrator/characters; use narrative techniques | 3–4 |
| **RICS.W.7** — Research | Conduct short research projects; gather relevant information | 3 |

## 3. Test Structure

RICAS ELA uses the PARCC task model architecture with three distinct task types administered across multiple sessions.

```
+------------------------------------------------------------------+
|              RICAS ELA STRUCTURE (Grades 3–8, 11)                 |
+------------------------------------------------------------------+
|  LITERARY ANALYSIS TASK (LAT)                                    |
|  ~75–90 minutes                                                   |
|                                                                  |
|  1–2 literary passages                                            |
|  Items: SR, MS, EBSR, TE                                         |
|  Prose Constructed Response (PCR) — literary analysis essay       |
|                                                                  |
+------------------------------------------------------------------+
|  RESEARCH SIMULATION TASK (RST)                                  |
|  ~75–90 minutes                                                   |
|                                                                  |
|  2–3 informational source texts (articles, data, excerpts)       |
|  Items: SR, MS, EBSR, TE                                         |
|  Prose Constructed Response (PCR) — research-based essay          |
|                                                                  |
+------------------------------------------------------------------+
|  NARRATIVE WRITING TASK (NWT)                                    |
|  ~75–90 minutes                                                   |
|                                                                  |
|  1 literary or informational stimulus passage                     |
|  Items: SR, MS, EBSR, TE                                         |
|  Prose Constructed Response (PCR) — narrative essay               |
|                                                                  |
+------------------------------------------------------------------+
```

## 5. Item Types & Formats

### Selected Response (SR)

```
+----------------------------------------------------------+
|  SELECTED RESPONSE — 1 point                             |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Passage-dependent; always tied to a stimulus            |
|  Machine scored                                          |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**SR Example (Grade 6 Informational, DOK 2, RICS.RI.6.6):**

*[After reading an article about the history of Narragansett Bay and its role in Rhode Island's maritime economy]*

What is the author's MAIN purpose in writing this article?

A. To persuade readers that commercial fishing should be expanded in Narragansett Bay
B. To entertain readers with dramatic stories of colonial-era shipwrecks
C. To inform readers about how Narragansett Bay has shaped Rhode Island's economy and identity over centuries
D. To warn readers about the environmental dangers of pollution in the bay

*Correct Answer: C*
*Alignment: RICS.ELA.RI.6.6 | Reading Informational Text | DOK 2*

---

### Multi-Select Response (MS)

```
+----------------------------------------------------------+
|  MULTI-SELECT RESPONSE — 1 point                         |
|                                                          |
|  5–8 options; select exactly 2 or 3 correct answers      |
|  Full credit only; partial credit not awarded            |
|  Machine scored                                          |
+----------------------------------------------------------+
```

**MS Example (Grade 5 Literary, DOK 2, RICS.RL.5.3):**

*[After reading a short story about a family visiting the Newport mansions for the first time]*

Select the TWO details from the story that BEST show how the narrator's feelings about the mansions change from the beginning to the end of the visit.

A. "Mom said the drive from Providence would take about forty-five minutes."
B. "I thought visiting a bunch of old houses sounded like the most boring Saturday imaginable."
C. "Standing in the Breakers ballroom, staring up at the painted ceiling that seemed to go on forever, I finally understood why people called these places palaces."
D. "Dad pointed out where he could park near the Cliff Walk entrance."
E. "The guide told us that seventy rooms had been built for just one family."

*Correct Answers: B, C*
*Alignment: RICS.ELA.RL.5.3 | Reading Literary Text | DOK 2*

---

### Evidence-Based Selected Response (EBSR)

```
+----------------------------------------------------------+
|  EVIDENCE-BASED SELECTED RESPONSE — 2 points            |
|                                                          |
|  Part A: Inference or analysis (1 pt)                   |
|  Part B: Text evidence supporting Part A (1 pt)          |
|  Machine scored                                          |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**EBSR Example (Grade 8 Informational, DOK 3, RICS.RI.8.8):**

*[After reading an argumentative essay about whether Rhode Island should invest more in protecting Narragansett Bay from pollution]*

**Part A:** Which statement BEST describes the author's central argument in this essay?

A. Narragansett Bay's water quality has improved enough that no further action is needed
B. Rhode Island must strengthen pollution controls for Narragansett Bay because rising water temperatures and stormwater runoff threaten the bay's marine ecosystems and the state's fishing economy
C. The federal government should take full responsibility for cleaning Narragansett Bay
D. Pollution in Narragansett Bay is primarily caused by recreational boating and can be solved by limiting marina access

**Part B:** Which sentence from the essay BEST supports your answer to Part A?

A. "Narragansett Bay stretches over 147 square miles and touches nearly every community in the state."
B. "Several towns along the bay have organized volunteer beach cleanup days each summer."
C. "With stormwater carrying fertilizers and chemicals into the bay after every heavy rain, and water temperatures rising steadily over the past two decades, the shellfish beds and fish populations that support a $100 million fishing industry face increasing stress without stronger regulatory action."
D. "The bay's name comes from the Narragansett people, who have lived along its shores for thousands of years."

*Correct Answers: Part A: B | Part B: C*
*Alignment: RICS.ELA.RI.8.8 | Reading Informational Text | DOK 3*

### Prose Constructed Response (PCR)

```
+----------------------------------------------------------+
|  PROSE CONSTRUCTED RESPONSE — 0–4 points                 |
|                                                          |
|  Multi-paragraph written response to passage(s)         |
|  LAT: Literary analysis essay                            |
|  RST: Research-based argumentative/informational essay   |
|  NWT: Narrative continuation or original narrative       |
|  Scored on a single 0–4 holistic rubric                  |
|  Human scored by trained raters                          |
+----------------------------------------------------------+
```

**PCR Prompt Example — RST (Grade 7, RICS.W.7.1):**

*[Sources provided: Article 1 on the history of Rhode Island's textile mills during the Industrial Revolution; Article 2 on the modern-day preservation of Slater Mill; Data table on tourism revenue from historic mill sites in Rhode Island]*

You have read three sources about Rhode Island's textile mill history and the debate over preserving these sites. Write an essay that argues whether the state should invest more funding in restoring and maintaining historic textile mills as educational landmarks. Use evidence from at least two of the three sources to support your argument. Be sure to acknowledge a counterclaim.

**PCR Prompt Example — NWT (Grade 5, RICS.W.5.3):**

*[After reading a story about a young sailor during Rhode Island's colonial era]*

The story ends with the narrator arriving at the docks in Newport Harbor. Write a continuation of the story that describes what happens next. Use details from the passage to develop the characters and setting, and include descriptive details that help the reader picture the scene.

## 8. Scoring Rubrics

### Prose Constructed Response (PCR) Rubric — 0–4 Points (Holistic)

| Score | Criteria |
|---|---|
| 4 | **Thorough understanding** of the text(s). Response is well-organized and includes specific, relevant evidence. Analysis is accurate, insightful, and fully developed. For narrative: effective use of narrative techniques, sensory details, and clear event sequence. Conventions errors minimal and do not interfere. |
| 3 | **Adequate understanding** of the text(s). Response is organized and includes relevant evidence, though analysis may not be fully developed. For narrative: adequate narrative techniques with generally clear sequence. Some conventions errors but meaning is clear. |
| 2 | **Partial understanding** of the text(s). Response includes some evidence but analysis is superficial or uneven. Organization may be inconsistent. For narrative: limited narrative techniques; sequence may be unclear. Conventions errors may occasionally interfere with meaning. |
| 1 | **Minimal understanding** of the text(s). Response includes little or no relevant evidence. Analysis is vague or inaccurate. For narrative: minimal narrative development. Frequent conventions errors interfere with meaning. |
| 0 | Blank, copied text, off-topic, or entirely in a language other than English. |

### PCR Scoring Notes

- **Evidence from text is required.** Responses relying solely on prior knowledge without referencing provided passages earn a maximum of 1 point.
- **RST PCR** must integrate evidence from at least two sources for a score of 3 or 4.
- **NWT PCR** must use details from the stimulus passage and demonstrate narrative techniques (dialogue, description, pacing).

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] Rhode Island Core Standards (RICS) code verified
- [ ] PARCC task type correctly identified (LAT, RST, or NWT)
- [ ] EBSR Part B is a quote that directly supports Part A (not just same topic)
- [ ] MS items specify exact number of answers to select (TWO/THREE)
- [ ] PCR prompt is open-ended enough for student voice
- [ ] PCR scored on 0–4 holistic rubric (not trait-based)
- [ ] Passage Lexile matches grade-band range
- [ ] RST sources include at least one non-prose source (graph, data table, image)
- [ ] Rhode Island context incorporated where appropriate (bay, history, culture)
- [ ] Distractors represent authentic student misconceptions (not trivially wrong)
- [ ] DOK level matches the actual cognitive demand of the question
- [ ] Grade 11 items reflect appropriate text complexity and analytical depth

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| EBSR Part B that supports a different answer | Part B must directly support Part A's correct answer | Cross-check: does Part B quote only make sense given Part A answer? |
| PCR prompts with only one correct interpretation | Essay needs room for student perspective | Keep prompts debatable or open-ended |
| Using 12-point trait-based FW rubric instead of 4-point holistic PCR | RICAS uses PARCC-style 0–4 holistic PCR rubric | Always use 0–4 holistic scale |
| RST sources all the same format (three articles) | PARCC RST includes varied source types | Include data tables, graphs, or images as at least one RST source |
| Forgetting Grade 11 | RICAS tests Grade 11 unlike some states | Include Grade 11 in test specifications |
| Generic New England context | Rhode Island has distinct maritime and colonial identity | Use Narragansett Bay, Newport, Providence, textile mill contexts |

## 12. Prompt Patterns

### Pattern 1: Central Idea / Theme (SR or EBSR, DOK 2–3)
> "What [central idea / theme] does the [passage / author] develop? Which detail from the text BEST supports this [idea / theme]?"

### Pattern 2: Author's Craft (SR, DOK 3)
> "How does the author's use of [figurative language / structure / word choice / point of view] in [this section / paragraph #] affect the [meaning / tone / reader's understanding of ____]?"

### Pattern 3: Evidence Selection (EBSR Part B)
> "Which [sentence / detail] from the [passage] BEST supports your answer to Part A?"

### Pattern 4: Research Simulation — Multi-Source Argument (PCR, DOK 4)
> "Using evidence from at least two of the three sources, write an argumentative essay about [Rhode Island-relevant debatable issue]. Be sure to acknowledge a counterclaim."

### Pattern 5: Narrative Writing Task (PCR, DOK 3–4)
> "Write a [continuation / narrative] based on the passage. Use details from the text to develop [characters / setting / plot]. Include narrative techniques such as dialogue, description, and pacing."

### Pattern 6: Literary Analysis Task (PCR, DOK 3–4)
> "Write an essay analyzing how the author uses [literary device / structure / characterization] to develop [theme / central idea] in the passage. Use specific evidence from the text to support your analysis."

### Pattern 7: Multi-Select Evidence (MS, DOK 2)
> "Select the TWO [details / sentences / examples] from the text that BEST [support / show / explain] [specific focus]."

### Pattern 8: Compare Texts (SR or EBSR, DOK 3)
> "Both sources discuss [common topic]. How does [Source 1] treat this topic differently from [Source 2]?"
