## 1. Overview

| Field | Detail |
|---|---|
| **Assessment Name** | Rhode Island Comprehensive Assessment System (RICAS) — Mathematics |
| **Administering Agency** | Rhode Island Department of Education (RIDE) |
| **Vendor** | Pearson |
| **Grades Tested** | 3, 4, 5, 6, 7, 8, 11 |
| **Testing Window** | March – May |
| **Delivery** | Computer-based; multi-session test |
| **Standards** | Rhode Island Core Standards (RICS) — aligned to Common Core State Standards Mathematics |
| **Score Scale** | 440–560 scale score (varies by grade); 4 performance levels |
| **Reporting** | Individual Student Report; School, District, State aggregates |

> **RICAS and PARCC:** RICAS Mathematics is derived from the **PARCC** design. Content is organized into Major, Supporting, and Additional clusters at each grade level. Item types include SR, EQ, SCR (0–2 pts), and ECR (0–6 pts). Rhode Island uses **Rhode Island Core Standards (RICS)** for Mathematics, which are aligned to CCSS-Math.

### Performance Levels

| Level | Label | Description |
|---|---|---|
| 4 | **Exceeding Expectations** | Distinguished command; applies mathematics in complex, novel situations; constructs sophisticated mathematical arguments |
| 3 | **Meeting Expectations** | Strong command; applies mathematics effectively to real-world and mathematical problems |
| 2 | **Partially Meeting Expectations** | Partial command; limited ability to apply mathematical concepts beyond routine procedures |
| 1 | **Not Meeting Expectations** | Minimal command; significant conceptual and procedural gaps |

## 5. Item Types & Formats

### Selected Response (SR)

```
+----------------------------------------------------------+
|  SELECTED RESPONSE — 1 point                             |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Real-world or mathematical context                      |
|  Machine scored                                          |
|  DOK 1–3                                                 |
+----------------------------------------------------------+
```

**SR Example (Grade 7, DOK 2, RICS.Math.7.RP.A.2):**

A ferry between Providence and Block Island charges $12.50 per person. A group of 8 students from a Providence school takes the ferry for a field trip. What is the total cost for the group?

A. $80.00
B. $96.00
C. $100.00
D. $112.50

*Correct Answer: C*
*Alignment: RICS.Math.7.RP.A.2 | Major Content | DOK 2*

---

### Equation/Numeric Entry (EQ)

```
+----------------------------------------------------------+
|  EQUATION / NUMERIC ENTRY — 1 point                      |
|                                                          |
|  Student types numeric answer or expression              |
|  No answer choices provided                              |
|  Machine scored                                          |
|  DOK 1–2                                                 |
+----------------------------------------------------------+
```

**EQ Example (Grade 5, DOK 2, RICS.Math.5.NF.A.1):**

A student walks 3/8 of a mile along the Cliff Walk in Newport on Saturday and 1/4 of a mile on Sunday. What is the total distance the student walked on both days?

Enter your answer as a fraction: **5/8**

*Alignment: RICS.Math.5.NF.A.1 | Major Content | DOK 2*

---

### Short Constructed Response (SCR)

```
+----------------------------------------------------------+
|  SHORT CONSTRUCTED RESPONSE — 0–2 points                 |
|                                                          |
|  Explain reasoning in 2–4 sentences                      |
|  Show work required for full credit                      |
|  Human scored                                            |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**SCR Example (Grade 6, DOK 3, RICS.Math.6.RP.A.3):**

Narragansett Bay has an area of approximately 147 square miles. A marine biologist estimates there are about 12 quahog clams per square foot in a healthy section of the bay. If one square mile equals 27,878,400 square feet, how many quahog clams would the biologist expect to find in 0.5 square miles of healthy bay bottom? Show your work and explain how you found your answer.

*Scoring:*
- *2 pts: Correct answer (167,270,400 clams) with clear work shown; explanation demonstrates understanding of rate reasoning and multi-step problem solving*
- *1 pt: Correct approach with minor arithmetic error, OR correct answer without process shown*
- *0 pts: Incorrect approach or blank*

### Extended Constructed Response (ECR)

```
+----------------------------------------------------------+
|  EXTENDED CONSTRUCTED RESPONSE — 0–6 points              |
|                                                          |
|  Multi-part problem with work and written justification  |
|  Assesses reasoning and modeling at DOK 3                |
|  Human scored                                            |
|  Session 2 (Calculator)                                  |
+----------------------------------------------------------+
```

**ECR Example (Grade 8 — Linear Modeling):**

*The table below shows the population density (people per square mile) for five Rhode Island cities.*

| City | Area (sq mi) | Population |
|---|---|---|
| Providence | 20.5 | 190,934 |
| Warwick | 49.1 | 82,823 |
| Cranston | 28.6 | 82,934 |
| Pawtucket | 8.9 | 75,604 |
| Newport | 11.5 | 25,163 |

**Part A:** Calculate the population density (people per square mile) for each city. Round to the nearest whole number. Show your work.

**Part B:** Create a scatter plot of area versus population density. Describe the relationship you observe between a city's area and its population density.

**Part C:** A city planner claims that smaller Rhode Island cities always have higher population densities. Using your calculations and graph, evaluate whether this claim is supported by the data. Explain your reasoning.

## 8. Scoring Rubrics

### Short Constructed Response (SCR) Rubric — 0–2 Points

| Score | Criteria |
|---|---|
| 2 | Correct solution with clear mathematical reasoning. Work shown systematically. Appropriate mathematical vocabulary used. Explanation demonstrates conceptual understanding. |
| 1 | Partial understanding with minor errors. Correct approach demonstrated even if the final answer contains a computational error. OR Correct answer given without sufficient explanation or work. |
| 0 | Response is incorrect, shows no understanding, or is blank. |

### Extended Constructed Response (ECR) Rubric — 0–6 Points

| Score | Criteria |
|---|---|
| 6 | All parts correct with clear, complete mathematical reasoning. Work shown systematically. All explanations accurate and complete. Justifications well-supported with evidence. |
| 5 | All parts essentially correct. Minor computational or notational error does not affect overall reasoning. |
| 4 | Correct approach throughout. One significant error or one part incorrect; reasoning otherwise sound. |
| 3 | Correct approach on majority of parts. Multiple minor errors or one major error; some reasoning present. |
| 2 | Partial understanding. Correct approach on at least one part; some valid mathematical work. |
| 1 | Minimal understanding shown. Some relevant mathematical work attempted. |
| 0 | Incorrect, irrelevant, or blank. |

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] RICS standard code is accurate and grade-appropriate
- [ ] Content cluster identified (Major, Supporting, or Additional)
- [ ] Session assignment is correct (calculator vs. non-calculator)
- [ ] SCR items require work to be shown (not just a final answer)
- [ ] ECR has exactly three parts of increasing complexity
- [ ] Rhode Island real-world context used where appropriate
- [ ] Distractors represent actual student computational or conceptual errors
- [ ] All computations verified before item is finalized
- [ ] DOK level matches the actual cognitive demand
- [ ] Grade 11 items reflect high school content standards

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Calculator items in Session 1 | Session 1 is non-calculator | Design Session 1 items for mental math or standard algorithms |
| SCR that only asks for an answer | SCR must require explanation/justification | Add "Show your work and explain how you found your answer" |
| ECR with only one part | ECR requires multi-part structure | Design 3 parts of increasing complexity |
| Ignoring cluster weights | Major content should dominate | Ensure ~65–70% of items target Major cluster standards |
| Generic context without Rhode Island flavor | RICAS items benefit from state context | Use Narragansett Bay, Newport, Providence contexts |
| Items testing only rote computation | RICAS targets DOK 2 primarily | Add real-world context to elevate to application level |

## 12. Prompt Patterns

### Pattern 1: Real-World Application (SR, DOK 2)
> "[Rhode Island context]. [Multi-step problem requiring application of concept]. What is [answer]?"

### Pattern 2: Justify and Explain (SCR, DOK 3)
> "[Rhode Island scenario requiring strategic thinking]. [Multi-step problem]. Show your work and explain how you found your answer."

### Pattern 3: Equivalent Representations (SR or EQ, DOK 2)
> "Select the [expression / equation / value] that is equivalent to [given value or expression]."

### Pattern 4: Linear Relationship (SR or SCR, DOK 2–3)
> "The [table / graph] shows [Rhode Island data context]. What is the [rate of change / slope / equation] that represents this relationship?"

### Pattern 5: Multi-Part Modeling (ECR, DOK 3)
> "Part A: [Direct calculation]. Part B: [Extension or comparison]. Part C: [Justify whether... / Evaluate if this is reasonable using mathematics]."

### Pattern 6: Comparison and Reasoning (SCR or SR, DOK 3)
> "Two students solved this problem differently. Student A says [method/answer]. Student B says [method/answer]. Who is correct? Use mathematics to justify your answer."
