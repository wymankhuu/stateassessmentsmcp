# Oregon — OSAS Science (Oregon Statewide Science Assessment)
## AssessmentForge Skill Guide | Grades 5, 8, 11

## 1. Overview

| Field | Detail |
|---|---|
| **Assessment Name** | Oregon Statewide Assessment System (OSAS) — Science |
| **Administering Agency** | Oregon Department of Education (ODE) |
| **Vendor** | Oregon Department of Education (ODE) |
| **Grades Tested** | 5, 8, and 11 |
| **Testing Window** | March – May |
| **Delivery** | Computer-based; fixed-form |
| **Standards** | Next Generation Science Standards (NGSS) as adopted by Oregon |
| **Score Scale** | Standard score (varies by grade); 4 performance levels |
| **Reporting** | Individual Student Report; School, District, State aggregate reports |

> **CRITICAL NOTE:** OSAS Science is administered **only at Grades 5, 8, and 11**. Do not generate items for Grades 3, 4, 6, or 7. Grade 11 covers high school science standards. Grade 5 covers elementary NGSS; Grade 8 covers middle school NGSS.

### Performance Level Descriptors

| Level | Label | Description |
|---|---|---|
| 4 | **Standard Exceeded** | Student demonstrates thorough understanding of three-dimensional science; expertly integrates DCI, SEP, and CCC; constructs sophisticated, evidence-based explanations |
| 3 | **Standard Met** | Student demonstrates adequate understanding of three-dimensional science; appropriately applies practices and crosscutting concepts in grade-level contexts |
| 2 | **Standard Nearly Met** | Student demonstrates partial understanding; can recall disciplinary core ideas but struggles to integrate science practices or crosscutting concepts |
| 1 | **Standard Not Met** | Student demonstrates minimal science understanding; cannot apply practices or crosscutting concepts; limited to recall of isolated facts |

> **Item-writing target:** Level 3 (Standard Met) performance. Items should assess all three NGSS dimensions simultaneously.

## 3. Test Structure

OSAS Science is a single-session, computer-based test. There is **no lab practical component** — all items are stimulus-based (scenarios, data tables, diagrams, models, and graphs).

```
+------------------------------------------------------------------+
|                   OSAS SCIENCE STRUCTURE (Grades 5, 8, 11)        |
+------------------------------------------------------------------+
|  SINGLE SESSION                                                   |
|  Computer-Based, Fixed-Form                                       |
|  Approximately 90–120 minutes                                     |
|                                                                   |
|  ~40 items per grade                                              |
|                                                                   |
|  Item types:                                                      |
|    - Selected Response (SR) — ~60–65% of items                    |
|    - Multi-Select Response (MS) — ~15–20% of items                |
|    - Constructed Response (CR) — ~15–20% of items (3 pts each)    |
+------------------------------------------------------------------+
```

### Grade-Level Test Specifications

| Specification | Grade 5 | Grade 8 | Grade 11 |
|---|---|---|---|
| Approximate Item Count | ~38–42 | ~38–42 | ~38–42 |
| Selected Response | ~25–28 | ~25–28 | ~25–28 |
| Multi-Select | ~6–8 | ~6–8 | ~6–8 |
| Constructed Response | ~4–6 | ~4–6 | ~4–6 |
| Approx. Testing Time | 90–120 min | 90–120 min | 90–120 min |
| Calculator | No | No | No |
| Reference Sheet | No | No | No |

> **Three-Dimensional Requirement:** Every OSAS Science item must integrate at least one **Disciplinary Core Idea (DCI)**, one **Science and Engineering Practice (SEP)**, and one **Crosscutting Concept (CCC)**. Items that test only factual recall of DCIs are not NGSS-aligned and should not be used.

## 5. Item Types & Formats

### Selected Response (SR)

```
+----------------------------------------------------------+
|  SELECTED RESPONSE — 1 point                             |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Scenario, diagram, data table, or model stimulus        |
|  Must integrate DCI + SEP + CCC                          |
|  Machine scored                                          |
+----------------------------------------------------------+
```

**SR Example (Grade 8, DOK 2, MS-PS1-2 — Chemical Reactions):**

A student combines two liquids in a beaker. After mixing, a white solid appears, the solution changes from clear to cloudy, and the temperature drops by 4 degrees C. Which statement BEST explains the evidence that a chemical reaction occurred?

A. The liquids were transparent before mixing
B. A new substance with different properties formed
C. The total volume of the mixture increased
D. The temperature change was too small to be significant

*Correct Answer: B*
*Alignment: MS-PS1-2 | SEP: Analyzing Data | CCC: Cause and Effect | DOK 2*

---

**SR Example (Grade 5, DOK 2, 5-LS2-1 — Food Webs):**

A student draws a model showing grass -> grasshoppers -> frogs -> hawks. Which statement BEST describes the role of the grass in this model?

A. The grass receives energy from the grasshoppers
B. The grass provides energy that originally came from the sun
C. The grass is a decomposer that recycles nutrients in the soil
D. The grass stores energy that it receives from the frogs

*Correct Answer: B*
*Alignment: 5-LS2-1 | SEP: Developing and Using Models | CCC: Energy and Matter | DOK 2*

---

### Multi-Select Response (MS)

```
+----------------------------------------------------------+
|  MULTI-SELECT RESPONSE — 1 point                         |
|                                                          |
|  5–6 options; select exactly 2 or 3 correct answers      |
|  Full credit only; partial credit not awarded            |
|  Machine scored                                          |
+----------------------------------------------------------+
```

**MS Example (Grade 8, DOK 2, MS-ESS3-3 — Human Impact):**

A river ecosystem in Oregon is being affected by agricultural runoff from Willamette Valley farms. Select the TWO statements that describe evidence-based strategies scientists could use to monitor and minimize the human impact on this ecosystem.

A. Build a dam upstream to stop all water flow
B. Collect water samples monthly to measure nutrient and chemical levels
C. Remove all vegetation along the riverbank
D. Establish buffer zones of native plants between farmland and the river
E. Increase the amount of fertilizer applied to reduce runoff concentration

*Correct Answers: B, D*
*Alignment: MS-ESS3-3 | SEP: Constructing Explanations | CCC: Cause and Effect | DOK 2*

---

### Constructed Response (CR)

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE — 0–3 points                       |
|                                                          |
|  Written explanation using evidence from stimulus        |
|  Stimulus always provided (data, diagram, scenario)      |
|  Must demonstrate three-dimensional reasoning            |
|  Human scored                                            |
+----------------------------------------------------------+
```

**CR Example (Grade 8, DOK 3, MS-LS2-2 — Ecosystem Interactions):**

*Stimulus: A data table showing population changes of Chinook salmon, sea lions, and plankton density in the Columbia River estuary over 20 years. Data shows that when salmon populations declined (due to dam construction), sea lion feeding patterns shifted, and plankton density increased in certain tributaries.*

*"Using data from the table, construct an explanation for how the decline in salmon population affected the Columbia River estuary ecosystem. Include evidence from the data and an explanation of the cause-and-effect relationship."*

## 7. Three-Dimensional Design

Every OSAS Science item must reflect all three NGSS dimensions simultaneously.

### Three-Dimensions Alignment Guide

| Dimension | What It Is | Example in Items |
|---|---|---|
| **DCI** (What students know) | Disciplinary science content | Photosynthesis; atomic structure; plate tectonics; natural selection |
| **SEP** (What students do) | How scientists work | Analyze data from a table; construct an explanation using evidence; use a model to predict |
| **CCC** (Lens of thinking) | Cross-domain thinking tools | Cause and effect; patterns; energy and matter; structure and function; systems and system models |

### Sample Three-Dimensional Item Design (Grade 8)

```
+------------------------------------------------------------------+
|  3D ITEM STRUCTURE                                                |
|                                                                   |
|  PHENOMENON: Salmon populations in the Columbia River decline     |
|  sharply when water temperatures rise above seasonal norms        |
|  (Authentic OR phenomenon grounds the item)                       |
|                                                                   |
|  DCI: MS-LS2 — Ecosystems; MS-LS2-2 interdependence              |
|  SEP: Constructing Explanations from Data                         |
|  CCC: Cause and Effect                                            |
|                                                                   |
|  STIMULUS: Time-series graph of water temperature, salmon count,  |
|  and dissolved oxygen levels; 20-year span in Columbia River      |
|                                                                   |
|  PROMPT: "Using data from the graph, construct an explanation    |
|  for the relationship between water temperature and salmon        |
|  population. Identify the cause-and-effect relationship."         |
+------------------------------------------------------------------+
```

### Crosscutting Concepts by Grade Band

| CCC | Grade 5 Emphasis | Grade 8 Emphasis | Grade 11 Emphasis |
|---|---|---|---|
| Patterns | Rock formations; seasonal changes | Periodic table patterns; evolutionary patterns | Inheritance patterns; population trends |
| Cause and Effect | Food web changes; erosion | Chemical reactions; population dynamics | Mutations -> traits; environmental -> evolution |
| Energy and Matter | Food chains; weather | Chemical reactions; thermal transfer | Cellular respiration; photosynthesis |
| Structure and Function | Plant/animal adaptations | Cell structures; molecular bonds | DNA -> protein -> trait |
| Systems and System Models | Ecosystems; water cycle | Earth systems; ecosystems | Ecosystems; genetic systems |
| Scale, Proportion, Quantity | Particle size; distances | Atomic scale; geological time | Chromosome/gene scale |
| Stability and Change | Habitat change; erosion | Climate; ecosystem stability | Evolution; homeostasis |

## 8. Scoring Rubrics

### Constructed Response (CR) Rubric — 0–3 Points

| Score | Criteria |
|---|---|
| 3 | Response accurately addresses the science concept; demonstrates clear three-dimensional understanding (DCI + SEP or CCC evident); includes specific, relevant evidence from the stimulus; explanation is complete, accurate, and logically connected |
| 2 | Response addresses the science concept with partial accuracy; shows understanding of the DCI but may only partially integrate a practice or crosscutting concept; evidence from stimulus is present but may be incomplete or imprecisely used |
| 1 | Response minimally addresses the science concept; shows limited understanding; little or no evidence from stimulus; explanation may be vague, overgeneralized, or contain minor science inaccuracies |
| 0 | Response does not address the science concept; blank; off-topic; restates the stimulus without explanation; demonstrates no science understanding |

### CR Scoring Notes

- **Evidence must come from the stimulus.** Responses that rely solely on prior knowledge without referencing the provided data/diagram receive a maximum of 1 point.
- **Three-dimensional reasoning earns full credit.** A Score 3 response integrates content knowledge (DCI) with at least one SEP or CCC.
- **Misconceptions lower the score.** A significant science misconception drops the response by one score point.

### Template A: SR — Data-Based Inference (DOK 2)

```

DCI: [Disciplinary Core Idea]
SEP: Analyzing and Interpreting Data
CCC: [Crosscutting Concept — typically Cause and Effect or Patterns]
DOK LEVEL: 2
POINT VALUE: 1 point

STIMULUS: [Data table OR graph with realistic, Oregon-relevant data]
          [Label all axes/columns clearly; include units]

      pattern] is BEST supported?

A. [Distractor — misreads the data or confuses variables]
B. [Distractor — partially correct; right domain, oversimplified]
C. [CORRECT — integrates DCI + data evidence at DOK 2]
D. [Distractor — common misconception about the science concept]

ANSWER KEY: C
ALIGNMENT: [PE Code] | SEP: Analyzing Data | CCC: [CCC] | DOK 2
```

```

SEP: Constructing Explanations / Arguing from Evidence
CCC: [Crosscutting Concept]

         [construct an explanation for / argue whether / analyze why]

         relationship."

SCORING GUIDE:

Score 1: Vague or partially correct; little/no stimulus evidence used;
         or contains a minor misconception.
Score 0: Blank, off-task, or major misconception with no science content.

[2–4 sentence model response integrating evidence + DCI + CCC]
```

### Suggested Anchoring Phenomena by Grade

**Grade 5 Phenomena:**
- "Crater Lake is one of the clearest lakes in the world, with visibility sometimes exceeding 100 feet. The lake has no rivers flowing in or out. Where does the water come from, and why is it so clear?"
- "After a wildfire swept through an Oregon forest near the Cascade Range, plants began growing back within weeks in some areas but not others. What provided the energy for this new growth, and why did some areas recover faster?"
- "Scientists studying the Oregon coast noticed that certain tide pool organisms can survive both underwater and exposed to air during low tide. What properties help these organisms survive in such a changing environment?"

**Grade 8 Phenomena:**
- "Chinook salmon travel hundreds of miles from the Pacific Ocean up the Columbia River to spawn in the same streams where they were born. Scientists have observed that salmon populations have declined significantly since dams were built along the river. What explains this pattern?"
- "Geologists discovered ancient marine fossils high in the Cascade Range, far from any ocean. What does this evidence suggest about Oregon's geological history?"
- "Water samples from the Willamette River show an increase in nitrogen and phosphorus levels near agricultural areas. What could be the ecological effects downstream in the Willamette Valley wetlands?"

**Grade 11 Phenomena:**
- "Two populations of Oregon red tree voles, separated by the Willamette Valley for thousands of years, now show significantly different physical characteristics. What process explains this difference?"
- "Scientists found that salmon populations in hatcheries show less genetic diversity than wild salmon populations in Oregon rivers. What factors could explain this difference, and why might it matter for the species' long-term survival?"
- "The Cascadia Subduction Zone off the Oregon coast has not produced a major earthquake since 1700. Geologists predict a magnitude 9.0+ earthquake is possible. What geologic processes make this region particularly vulnerable?"

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] Grade verified as 5, 8, or 11 ONLY (not other grades)
- [ ] PE code is a valid NGSS Performance Expectation
- [ ] Item is three-dimensional: DCI + SEP + CCC all identified
- [ ] Anchoring phenomenon is authentic and Oregon-relevant where possible
- [ ] Stimulus (data table/graph/diagram) has clear labels, units, and realistic data
- [ ] CR prompt directs students to use evidence from the stimulus
- [ ] All distractors represent real misconceptions (not obviously wrong)
- [ ] MS items specify how many answers to select (TWO/THREE)
- [ ] Score 3 anchor response written before finalizing CR item
- [ ] Science content is accurate and reflects current scientific understanding
- [ ] Vocabulary is grade-appropriate (avoid jargon not in NGSS glossary)

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Writing items for Grades 3, 4, 6, or 7 | OSAS Science is only at Grades 5, 8, 11 | Restrict to tested grades |
| DCI-only items (no SEP or CCC) | OSAS requires three-dimensional items | Always embed a practice and a crosscutting concept |
| CR prompts without evidence directive | Students may respond without citing data | Include "Use evidence from the [data/graph/diagram]" |
| Using NGSS codes as written (not OR-adopted) | Oregon adopted NGSS — codes are identical, but reference OR NGSS | Reference "OR NGSS" not just NGSS in guide headers |
| Generic stimulus data not tied to OR | OSAS favors Oregon phenomena | Anchor stimulus to OR-specific context |
| Multi-select with only 2 correct in 4 options | Too easy to guess; 1-in-6 chance | Use 5–6 options with exactly 2–3 correct |
| Recall-only SR items | DOK 1 items are under-represented on OSAS | Elevate most items to DOK 2 with a scenario |

## 12. Prompt Patterns

The following patterns reflect the most common OSAS Science item archetypes.

### Pattern 1: Data-to-Conclusion (SR, DOK 2)
> "The [graph / table / diagram] below shows [Oregon science scenario]. Based on the data, which [conclusion / explanation / pattern] is BEST supported?"

### Pattern 2: Phenomenon Explanation (CR, DOK 3)
> "Scientists observed [Oregon-anchored phenomenon]. Using evidence from the [data / model / diagram], construct an explanation for [specific science focus]. Explain the [cause-and-effect / energy flow / pattern] relationship."

### Pattern 3: Model Evaluation (SR or MS, DOK 2–3)
> "A student made a model showing [science concept]. Which statement BEST describes what the model shows about [DCI focus]? / Select the TWO statements that correctly describe what the model represents."

### Pattern 4: Investigation Design (CR, DOK 3)
> "A scientist wants to investigate whether [variable] affects [outcome] in [Oregon ecosystem/context]. Describe a procedure the scientist could follow. Include what the scientist would measure and how they would know if the variable made a difference."

### Pattern 5: Evidence-Based Argument (CR, DOK 3)
> "Two students disagree about [science claim]. Student A says [claim based on misconception]. Student B says [scientifically accurate claim]. Using evidence from the [data / diagram], explain which student is correct and why."

### Pattern 6: Multi-Select Evidence (MS, DOK 2)
> "A student is investigating [Oregon science scenario]. Select the TWO [pieces of evidence / strategies / explanations] that BEST support the conclusion that [DCI-based claim]."
