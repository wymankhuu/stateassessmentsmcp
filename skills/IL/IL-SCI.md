# Illinois — ISA Science (Illinois Science Assessment)
## AssessmentForge Skill Guide | Grades 5, 8, and 11

---

## 1. Overview

| Field | Detail |
|---|---|
| **Assessment Name** | Illinois Science Assessment (ISA) |
| **Administering Agency** | Illinois State Board of Education (ISBE) |
| **Vendor** | Measured Progress |
| **Grades Tested** | **Grade 5**, **Grade 8**, and **Grade 11** |
| **Testing Window** | March – April |
| **Delivery** | Computer-based; single session |
| **Standards** | Illinois Learning Standards for Science (incorporating NGSS) |
| **Score Scale** | 4 performance levels; scaled score varies by grade |
| **Reporting** | Individual Student Report; School, District, State aggregates |

> **CRITICAL NOTE:** ISA is administered **only at Grades 5, 8, and 11**. Do not generate ISA-aligned science items for Grades 3, 4, 6, or 7. Grade 11 covers high school physical and life science standards.

> **ISA and NGSS:** The ISA uses Illinois Learning Standards for Science, which fully incorporate the **Next Generation Science Standards (NGSS)** framework. All items must be three-dimensional: integrating **Disciplinary Core Ideas (DCI)**, **Science and Engineering Practices (SEP)**, and **Crosscutting Concepts (CCC)**.

### Performance Levels

| Level | Label | Description |
|---|---|---|
| 4 | **Exceeded Expectations** | Demonstrates thorough three-dimensional science understanding; expertly integrates DCI, SEP, and CCC; constructs sophisticated evidence-based explanations |
| 3 | **Met Expectations** | Demonstrates adequate three-dimensional science understanding; appropriately applies science practices and crosscutting concepts |
| 2 | **Approached Expectations** | Demonstrates partial understanding; can apply DCI content but struggles to integrate SEP or CCC meaningfully |
| 1 | **Did Not Meet Expectations** | Demonstrates minimal science understanding; limited to recall of isolated facts |

## 3. Test Structure

ISA Science is a single-session, computer-based assessment. All items are scenario-based (no lab practical). Items use data tables, diagrams, graphs, and models as stimuli.

```
+------------------------------------------------------------------+
|           ISA SCIENCE STRUCTURE (Grades 5, 8, 11)               |
+------------------------------------------------------------------+
|  SINGLE SESSION                                                  |
|  Computer-Based, Fixed-Form                                      |
|  Approximately 90–120 minutes                                    |
|                                                                  |
|  ~40 items per grade                                             |
|                                                                  |
|  Item types:                                                     |
|    • Selected Response (SR) — ~55–60% (~24 items)               |
|    • Multi-Select Response (MS) — ~15–20% (~6–8 items)          |
|    • Constructed Response (CR) — ~20–25% (~8–10 items; 0–3 pts) |
+------------------------------------------------------------------+
```

### Grade-Level Test Specifications

| Specification | Grade 5 | Grade 8 | Grade 11 |
|---|---|---|---|
| Total Items (approx.) | ~38–42 | ~38–42 | ~38–42 |
| Selected Response | ~22–26 | ~22–26 | ~22–26 |
| Multi-Select | ~6–8 | ~6–8 | ~6–8 |
| Constructed Response | ~6–10 | ~6–10 | ~6–10 |
| Testing Time | 90–120 min | 90–120 min | 90–120 min |

> **Three-Dimensional Requirement:** Every ISA item must integrate at least one **DCI**, one **SEP**, and one **CCC**. Items that test DCI content in isolation (pure recall) are not aligned to the Illinois Learning Standards for Science.

## 5. Item Types & Formats

### Selected Response (SR)

```
+----------------------------------------------------------+
|  SELECTED RESPONSE — 1 point                             |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Scenario, diagram, data table, or model stimulus        |
|  Must integrate DCI + SEP + CCC                          |
|  Machine scored                                          |
+----------------------------------------------------------+
```

**SR Example (Grade 8, DOK 2, IL.NGSS.MS-PS1-2 — Chemical Reactions):**

A student in a Chicago high school mixes two colorless solutions. After mixing, the solution turns bright orange, and the temperature drops by 6°C. Which observation provides the BEST evidence that a chemical reaction has occurred?

A. The temperature decreased during the mixing process
B. The original solutions were both colorless before mixing
C. A new substance with different properties (bright orange color) formed
D. The student noticed the mixture had a slightly different smell

*Correct Answer: C*
*Alignment: IL.NGSS.MS-PS1-2 | SEP: Analyzing and Interpreting Data | CCC: Cause and Effect | DOK 2*

---

**SR Example (Grade 5, DOK 2, IL.NGSS.5-LS2-1 — Ecosystem Energy Flow):**

A diagram shows: Sunlight → Prairie Grasses → Grasshoppers → Prairie Chickens → Red-tailed Hawks

Which statement BEST explains the role of prairie grasses in this Illinois ecosystem model?

A. Prairie grasses receive energy from grasshoppers through a food chain
B. Prairie grasses capture energy from the sun and store it in their cells
C. Prairie grasses are decomposers that break down dead organisms in the prairie
D. Prairie grasses get energy from the soil through their root system

*Correct Answer: B*
*Alignment: IL.NGSS.5-LS2-1 | SEP: Developing and Using Models | CCC: Energy and Matter | DOK 2*

---

### Multi-Select Response (MS)

```
+----------------------------------------------------------+
|  MULTI-SELECT RESPONSE — 1 point                         |
|                                                          |
|  5–6 options; select exactly 2 or 3 correct answers      |
|  All must be selected for credit                         |
|  Machine scored                                          |
+----------------------------------------------------------+
```

**MS Example (Grade 8, DOK 2, IL.NGSS.MS-ESS3-3 — Human Impact):**

Excess agricultural runoff from Illinois farms has been linked to the growth of algal blooms in the Illinois River. Select the TWO strategies that would BEST help scientists monitor and minimize this human impact on the river ecosystem.

A. Remove all vegetation along the riverbanks to reduce shade and algae growth
B. Collect monthly water samples to measure nitrogen and phosphorus levels
C. Introduce more fish species to the river to consume the algae
D. Establish vegetated buffer zones between farmland and the river to absorb excess nutrients
E. Increase the flow rate of the river by removing natural curves and bends

*Correct Answers: B, D*
*Alignment: IL.NGSS.MS-ESS3-3 | SEP: Constructing Explanations | CCC: Cause and Effect | DOK 2*

### Constructed Response (CR)

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE — 0–3 points                       |
|                                                          |
|  Written explanation using evidence from the stimulus    |
|  Stimulus always provided (data, diagram, scenario)      |
|  Must demonstrate three-dimensional reasoning            |
|  Human scored                                            |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**CR Example (Grade 8, DOK 3, IL.NGSS.MS-LS2-2 — Ecosystem Interactions):**

*Stimulus: A data table showing the population changes of gray wolves, white-tailed deer, and tree seedlings in a northern Illinois forest preserve over 20 years. When wolves were reintroduced (Year 10), deer populations decreased, and tree seedling populations increased significantly.*

*"Using data from the table, construct an explanation for how the reintroduction of gray wolves affected tree seedling populations in this Illinois forest preserve. Include evidence from the data and explain the cause-and-effect relationships."*

## 7. Three-Dimensional Design

Every ISA item must reflect all three NGSS dimensions simultaneously.

### Three-Dimensions Alignment Guide

| Dimension | What It Is | Example in ISA Items |
|---|---|---|
| **DCI** (What students know) | Disciplinary science content | Illinois prairie food webs; chemical reactions; Great Lakes geology; genetic inheritance |
| **SEP** (What students do) | How scientists work | Analyze population data; construct explanations from evidence; use a model to predict ecosystem changes |
| **CCC** (Lens of thinking) | Cross-domain thinking tools | Cause and effect; patterns; energy and matter; structure and function; systems and system models |

### Sample Three-Dimensional Item Design (Grade 8)

```
+------------------------------------------------------------------+
|  3D ITEM STRUCTURE                                               |
|                                                                  |
|  PHENOMENON: Algal blooms in Lake Michigan near Chicago          |
|  have increased significantly since 1990                         |
|  (Authentic Illinois phenomenon)                                 |
|                                                                  |
|  DCI: MS-LS2 — Ecosystems; MS-ESS3 — Human impacts              |
|  SEP: Constructing Explanations from Data                        |
|  CCC: Cause and Effect                                           |
|                                                                  |
|  STIMULUS: Time-series data table showing nitrogen levels and    |
|  algal bloom frequency in Lake Michigan, 1990–2020              |
|                                                                  |
|  PROMPT: "Using data from the table, construct an explanation    |
|  for the increase in algal blooms near Chicago's Lake Michigan   |
|  shoreline. Include specific evidence from the data and explain  |
|  the cause-and-effect relationships."                            |
+------------------------------------------------------------------+
```

### Crosscutting Concepts by Grade Band

| CCC | Grade 5 Emphasis | Grade 8 Emphasis | Grade 11 Emphasis |
|---|---|---|---|
| Patterns | Prairie seasonal cycles; rock formations | Chemical reaction patterns; population trends | Periodic table patterns; evolutionary change |
| Cause and Effect | Food chain removal; erosion | Human impacts; chemical reactions | Evolution mechanisms; homeostasis disruption |
| Energy and Matter | Food webs; water cycle | Chemical reactions; thermal transfer | Metabolic pathways; Earth system cycles |
| Structure and Function | Organism adaptations; plant structures | Cell structures; molecular properties | DNA → protein → trait; organ systems |
| Systems and System Models | Prairie ecosystems; water cycle | Ecosystems; Earth systems | Ecosystems; biological feedback systems |

## 8. Scoring Rubrics

### Constructed Response (CR) Rubric — 0–3 Points

| Score | Criteria |
|---|---|
| 3 | Response accurately addresses the science concept; demonstrates clear three-dimensional understanding (DCI + SEP or CCC evident); includes specific, relevant evidence from the stimulus; explanation is complete, accurate, and logically connected |
| 2 | Response addresses the science concept with partial accuracy; shows understanding of the DCI but only partially integrates a practice or crosscutting concept; evidence from stimulus is present but may be incomplete or imprecisely used |
| 1 | Response minimally addresses the science concept; shows limited understanding; little or no evidence from stimulus used; explanation vague, overgeneralized, or contains minor science inaccuracies |
| 0 | Response does not address the science concept; blank; off-topic; restates stimulus without explanation; demonstrates no science understanding |

### CR Scoring Notes

- **Evidence from the stimulus is required.** A response that relies solely on prior knowledge without referencing the provided data/diagram earns a maximum of 1 point.
- **Three-dimensional reasoning earns full credit.** A Score 3 response integrates content knowledge (DCI) with at least one SEP or CCC.
- **Misconceptions reduce the score.** A significant scientific misconception drops the response by one score point.

### Suggested Anchoring Phenomena by Grade

**Grade 5 Phenomena:**
- "Every spring, the tallgrass prairie at Midewin National Tallgrass Prairie burns. Instead of killing the prairie, the fires seem to help it thrive — why?"
- "Scientists counted the number of different bird species at an Illinois forest preserve before and after removing invasive buckthorn shrubs. After removal, the bird population diversity increased significantly. What explains this pattern?"
- "Students in Rockford noticed that a creek near their school had much clearer water after a beaver dam was removed. What does this tell us about how animals affect their ecosystems?"

**Grade 8 Phenomena:**
- "Since Asian carp were introduced to Illinois waterways in the 1970s, populations of native fish have declined dramatically. What ecological mechanisms explain this pattern?"
- "Scientists monitoring Lake Michigan water temperatures found that surface temperatures have increased by nearly 2°C since 1980. What effects might this have on the lake ecosystem?"
- "Geologists studying the Illinois landscape discovered that the flat terrain of central Illinois is the result of glaciers that covered the area 18,000 years ago. What evidence could scientists use to support this claim?"

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] Grade verified as 5, 8, or 11 ONLY (not other Illinois grades)
- [ ] PE code is a valid IL.NGSS Performance Expectation
- [ ] Item is three-dimensional: DCI + SEP + CCC all identified
- [ ] Anchoring phenomenon is authentic and Illinois-relevant where possible
- [ ] Stimulus (data table/graph/diagram) has clear labels, units, and realistic data
- [ ] CR prompt directs students to use evidence from the stimulus
- [ ] All distractors represent real misconceptions (not obviously wrong)
- [ ] MS items specify how many answers to select (TWO/THREE)
- [ ] Score 3 anchor response written before finalizing CR item
- [ ] Science content is accurate and reflects current scientific understanding
- [ ] Vocabulary is grade-appropriate for the targeted grade level

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Writing ISA items for Grades 3, 4, 6, or 7 | ISA is only at Grades 5, 8, 11 | Restrict to tested grades |
| DCI-only items (no SEP or CCC) | ISA requires three-dimensional items | Always embed a practice and crosscutting concept |
| CR prompts without evidence directive | Students may respond without citing data | Include "Use evidence from the [data/graph/diagram]" in all CR prompts |
| Using NGSS codes without IL. prefix | Illinois uses IL.NGSS prefix | Add IL.NGSS. to all PE codes |
| Generic Midwest phenomena not anchored to Illinois | ISA favors Illinois-specific contexts | Use Lake Michigan, Illinois River, prairie, Chicago contexts |
| MS items with only 2 options in 4 total | Too easy to guess | Use 5–6 options with exactly 2–3 correct |

## 12. Prompt Patterns

The following patterns reflect the most common ISA item archetypes.

### Pattern 1: Data-to-Conclusion (SR, DOK 2)
> "The [graph / table / diagram] below shows [Illinois science scenario]. Based on the data, which [conclusion / explanation / pattern] is BEST supported?"

### Pattern 2: Phenomenon Explanation (CR, DOK 3)
> "Scientists observed [Illinois-anchored phenomenon]. Using evidence from the [data / model / diagram], construct an explanation for [specific science focus]. Explain the [cause-and-effect / energy flow / pattern] relationship."

### Pattern 3: Model Evaluation (SR or MS, DOK 2–3)
> "A student made a model showing [Illinois science concept]. Which statement BEST describes what the model shows about [DCI focus]? / Select the TWO statements that correctly describe what the model represents."

### Pattern 4: Investigation Design (CR, DOK 3)
> "A scientist in Illinois wants to investigate whether [variable] affects [outcome] in [Illinois ecosystem]. Describe a procedure the scientist could follow. Include what would be measured and how the scientist would know if the variable made a difference."

### Pattern 5: Evidence-Based Argument (CR, DOK 3)
> "Two students disagree about [Illinois science claim]. Student A says [misconception]. Student B says [scientifically accurate claim]. Using evidence from the [data / diagram], explain which student is correct and why."

### Pattern 6: Human Impact and Solutions (MS or CR, DOK 2–3)
> "Human activities have [impacted Illinois environment]. Select the TWO strategies that BEST [monitor / reduce / address] this impact. / Describe TWO effects this has had on [ecosystem/organism]. Then explain ONE method scientists could use to reduce this impact."
