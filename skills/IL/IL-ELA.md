## 1. Overview

| Field | Detail |
|---|---|
| **Assessment Name** | Illinois Assessment of Readiness (IAR) — English Language Arts/Literacy |
| **Administering Agency** | Illinois State Board of Education (ISBE) |
| **Vendor** | Measured Progress |
| **Grades Tested** | 3, 4, 5, 6, 7, 8 |
| **Testing Window** | March – April |
| **Delivery** | Computer-based; two-session test |
| **Standards** | Illinois Learning Standards — Incorporating Common Core (CCSS ELA) |
| **Score Scale** | 650–850 scale score (varies by grade); 4 performance levels |
| **Reporting** | Individual Student Report; School, District, State aggregates |

> **IAR and Smarter Balanced:** The IAR ELA assessment is based on the **Smarter Balanced Assessment Consortium (SBAC) design**. Item types, blueprints, and rubrics closely parallel those used in California (CAASPP). Key differences: Illinois uses **Illinois Learning Standards** (CCSS-based) and passages may reflect Illinois/Midwest contexts.

### Performance Levels

| Level | Label | Description |
|---|---|---|
| 4 | **Exceeded Expectations** | Student demonstrates thorough understanding; sophisticated analysis; precise use of evidence from complex texts |
| 3 | **Met Expectations** | Student demonstrates adequate understanding; appropriate analysis; uses relevant evidence from grade-level texts |
| 2 | **Approached Expectations** | Student demonstrates partial understanding; limited analysis; inconsistent use of evidence |
| 1 | **Did Not Meet Expectations** | Student demonstrates minimal understanding; significant gaps relative to grade-level expectations |

## 2. Standards Framework

> **Reference:** See `_shared/ccss_ela_framework.md` for full CCR Anchor Standards and grade-by-grade progressions. Illinois uses the **Illinois Learning Standards** (ILS), which incorporate Common Core ELA standards. All CCSS codes are prefixed with "IL." in the Illinois system.

### Reading Literature (RL) — Key Standards by Grade Band

| Standard | Gr 3–5 Focus | Gr 6–8 Focus |
|---|---|---|
| **IL.RL.1** — Key details & inference | Explicit details; simple inference from text | Cite textual evidence; analyze what text says explicitly vs. inferentially |
| **IL.RL.2** — Theme / central idea | Determine message or lesson; summarize | Analyze theme development; how it emerges through characters and plot |
| **IL.RL.3** — Character, setting, events | Describe characters' traits and responses | Analyze how dialogue and incidents reveal character and advance plot |
| **IL.RL.4** — Word meaning | Determine meaning of words; recognize figurative language | Analyze figurative and connotative meanings; word choice and tone |
| **IL.RL.6** — Point of view | Identify narrator's point of view | Analyze how differences in POV create effects like suspense or humor |

### Reading Informational Text (RI) — Key Standards by Grade Band

| Standard | Gr 3–5 Focus | Gr 6–8 Focus |
|---|---|---|
| **IL.RI.1** — Key details & inference | Quote accurately; draw inferences | Cite textual evidence supporting analysis |
| **IL.RI.3** — Connections & relationships | Explain relationships between events, ideas, or concepts | Analyze how a text makes connections between ideas |
| **IL.RI.6** — Author's purpose & point of view | Identify author's purpose | Determine author's point of view; analyze how purpose shapes content |
| **IL.RI.8** — Argument & evidence | Explain how reasons support points | Trace and evaluate argument; assess whether reasoning is sound |
| **IL.RI.9** — Compare/integrate information | Compare multiple texts on same topic | Analyze how two texts treat similar topics differently |

### Writing Standards

| Standard | Focus | DOK |
|---|---|---|
| **IL.W.1** — Argument/Opinion | Write arguments with clear claims, evidence, and reasoning | 3–4 |
| **IL.W.2** — Informative/Explanatory | Develop topics with facts, details, definitions, examples | 3 |
| **IL.W.3** — Narrative | Establish situation; develop narrator/characters; use narrative techniques | 3–4 |
| **IL.W.7** — Research | Conduct short research projects; gather relevant information | 3 |

## 3. Test Structure

IAR ELA is a two-session assessment delivered in two sittings on consecutive days.

```
+------------------------------------------------------------------+
|              IAR ELA STRUCTURE (Grades 3–8)                      |
+------------------------------------------------------------------+
|  SESSION 1 — Computer-Adaptive Test (CAT)                       |
|  ~60–90 minutes                                                  |
|                                                                  |
|  Literary Passage + items (SR, MS, EBSR, TE)                    |
|  Informational Passage + items (SR, MS, EBSR, TE)               |
|                                                                  |
|  Total: ~28–35 items                                             |
|                                                                  |
+------------------------------------------------------------------+
|  SESSION 2 — Performance Task (PT)                              |
|  ~90–120 minutes                                                 |
|                                                                  |
|  Research Simulation Task:                                       |
|    • 2–3 source documents (articles, excerpts, data)            |
|    • Short Text items (PT-ST) about the sources                 |
|    • Full Write (FW) — extended essay (12 pts)                  |
+------------------------------------------------------------------+
```

### Session 1 — CAT Item Distribution

| Item Type | Points | Machine Scored | DOK |
|---|---|---|---|
| Selected Response (SR) | 1 | Yes | 2–3 |
| Multi-Select Response (MS) | 1 | Yes | 2–3 |
| Evidence-Based Selected Response (EBSR) | 2 | Yes | 2–3 |
| Technology Enhanced (TE) | 1–2 | Yes | 2 |

### Session 2 — Performance Task Structure

| Component | Description | Points |
|---|---|---|
| PT Short Text (PT-ST) | 1–2 short responses per source | 0–2 each (2–4 pts total) |
| Full Write (FW) | Multi-paragraph essay (argumentative, informational, or narrative) | 0–12 pts (3 traits × 0–4) |

### Grade-Level Test Specifications

| Grade | Session 1 Items | Session 2 Format | Total Approx. Points |
|---|---|---|---|
| 3–5 | ~28–32 | Narrative or Opinion FW | ~42–50 |
| 6–8 | ~32–36 | Argumentative or Informational FW | ~50–58 |

## 4. Claims & Blueprint

### Reporting Category Weightings

| Claim | Weight | Description |
|---|---|---|
| Claim 1 — Reading | ~45% | Students can read closely and analytically to comprehend literary and informational texts |
| Claim 2 — Writing | ~25% | Students can produce effective, well-grounded writing for a range of purposes |
| Claim 4 — Research | ~30% | Students can engage in research and inquiry; analyze, integrate, and present information |

> **Note:** IAR does not heavily weight Claim 3 (Speaking & Listening) as a scored component. Research (Claim 4) is assessed through the Performance Task.

### DOK Distribution

| DOK Level | Description | Approximate % |
|---|---|---|
| DOK 1 | Recall; identify; locate | ~5–10% |
| DOK 2 | Infer; explain; apply; analyze surface features | ~50–55% |
| DOK 3 | Analyze craft; evaluate argument; synthesize across texts | ~35–40% |

### Passage Requirements

|---|---|---|
| Literary | 420–820L | 925–1185L |
| Informational | 420–820L | 925–1185L |
| PT Sources (Session 2) | Grade-appropriate band | Grade-appropriate band |

## 5. Item Types & Formats

### Selected Response (SR)

```
+----------------------------------------------------------+
|  SELECTED RESPONSE — 1 point                             |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Passage-dependent; always tied to a stimulus            |
|  Machine scored                                          |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**SR Example (Grade 6 Informational, DOK 3, IL.RI.6.6):**

*[After reading an article about Chicago's use of green infrastructure to manage stormwater]*

What is the author's MAIN purpose in writing this article?

A. To persuade readers to donate money to environmental programs in Illinois
B. To entertain readers with stories about floods in Chicago neighborhoods
C. To inform readers about how Chicago has used green infrastructure to solve a complex urban problem
D. To warn readers about the dangers of flooding in large cities

*Correct Answer: C*
*Alignment: IL.CCSS.ELA-Literacy.RI.6.6 | Claim 1 | DOK 2*

---

### Multi-Select Response (MS)

```
+----------------------------------------------------------+
|  MULTI-SELECT RESPONSE — 1 point                         |
|                                                          |
|  5–8 options; select exactly 2 or 3 correct answers      |
|  Full credit only; partial credit not awarded            |
|  Machine scored                                          |
+----------------------------------------------------------+
```

**MS Example (Grade 5 Literary, DOK 2, IL.RL.5.3):**

*[After reading a short story about siblings navigating a tornado warning on an Illinois farm]*

Select the TWO details from the story that BEST show how the relationship between the siblings changes over the course of the story.

A. "The sky turned a sickly green above the cornfields."
B. "Marcus refused to look at his sister when she called his name from the barn doorway."
C. "Later, huddled in the storm shelter, Marcus reached for his sister's hand without being asked."
D. "Their mother had gone to town for supplies before the storm warnings began."
E. "The old farmhouse shuddered as the wind picked up across the flat Illinois plains."

*Correct Answers: B, C*
*Alignment: IL.CCSS.ELA-Literacy.RL.5.3 | Claim 1 | DOK 2*

---

### Evidence-Based Selected Response (EBSR)

```
+----------------------------------------------------------+
|  EVIDENCE-BASED SELECTED RESPONSE — 2 points            |
|                                                          |
|  Part A: Inference or analysis (1 pt)                   |
|  Part B: Text evidence supporting Part A (1 pt)          |
|  Machine scored                                          |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**EBSR Example (Grade 8 Informational, DOK 3, IL.RI.8.8):**

*[After reading an argumentative essay about whether Illinois should expand its high-speed rail network]*

**Part A:** Which statement BEST describes the author's central argument in this essay?

A. High-speed rail would only benefit residents of Chicago and should be limited to the metro area
B. Illinois should expand high-speed rail because it would improve economic connections, reduce traffic congestion, and benefit both urban and rural communities
C. The cost of high-speed rail makes it an impractical investment for Illinois at this time
D. High-speed rail systems have failed in other states, and Illinois should wait to observe the results elsewhere

**Part B:** Which sentence from the essay BEST supports your answer to Part A?

A. "The construction phase alone would create an estimated 15,000 jobs statewide."
B. "Critics have raised concerns about the initial capital investment required for infrastructure."
C. "By connecting Rockford, Peoria, and Springfield to Chicago with 90-minute service, Illinois could unlock regional economies that have been stagnating for decades — while reducing reliance on interstate highways clogged with freight trucks."
D. "Japan and France offer models of successful high-speed rail, though their populations differ from Illinois in important ways."

*Correct Answers: Part A: B | Part B: C*
*Alignment: IL.CCSS.ELA-Literacy.RI.8.8 | Claim 1 | DOK 3*

### Technology Enhanced (TE)

```
+----------------------------------------------------------+
|  TECHNOLOGY ENHANCED — 1–2 points                        |
|                                                          |
|  Selectable text, drag-and-drop, or matching             |
|  Interaction directly with passage or stimulus           |
|  Machine scored                                          |
|  DOK 2                                                   |
+----------------------------------------------------------+
```

**TE Example (Grade 5 — Selectable Text, DOK 2):**

*Click on the sentence in paragraph 3 that BEST shows the narrator's feelings about leaving her Chicago neighborhood.*

### Full Write (FW) — Performance Task

```
+----------------------------------------------------------+
|  FULL WRITE — 0–12 points                                |
|                                                          |
|  Multi-paragraph essay written in response to sources   |
|  Grades 3–5: Opinion or Narrative                       |
|  Grades 6–8: Argument or Informational/Explanatory      |
|  3 traits × 0–4 points = 12 total                       |
|  Traits: Organization/Purpose, Evidence/Elaboration,    |
|  and Conventions                                         |
|  Human scored by two readers                             |
+----------------------------------------------------------+
```

**FW Prompt Example (Grade 6 — Argumentative, Claim 2/4):**

*[Sources provided: Article 1 on urban farming in Chicago; Article 2 on food deserts in Illinois; Data table on community garden impact in Peoria]*

Write an argumentative essay about whether schools and communities in Illinois should invest in urban farming programs. Use evidence from at least two of the three sources to support your argument. Be sure to address a counterclaim.

## 6. Depth of Knowledge (DOK)

| DOK | Label | ELA Application Examples |
|---|---|---|
| 1 | Recall | Find an explicit fact from the text; identify the genre; locate a vocabulary word in context |
| 2 | Skills & Concepts | Infer a character's motivation from text evidence; identify the author's purpose; explain how one detail supports the main idea |
| 3 | Strategic Thinking | Analyze how the author's use of figurative language contributes to theme; evaluate the strength of an argument's evidence; compare how two texts treat the same theme |
| 4 | Extended Thinking | Full Write essay requiring synthesis of multiple sources, argument development, and evidence integration |

## 8. Scoring Rubrics

### Full Write (FW) Rubric — Per Trait (0–4 Points Each)

**Trait 1 — Organization/Purpose**

| Score | Criteria |
|---|---|
| 4 | Clear and effective organizational structure. Strong command of purpose throughout. Sophisticated transitions create coherence. Introduction and conclusion purposeful and well-crafted. |
| 3 | Adequate organizational structure. Clear introduction and conclusion. Logical idea development. Transitions present but may be formulaic. |
| 2 | Inconsistent organizational structure. Introduction or conclusion may be weak. Limited transitions. Some logical development. |
| 1 | Little or no discernible structure. No clear introduction or conclusion. Development absent, tangential, or illogical. |
| 0 | Blank, copied text, or entirely off-task. |

**Trait 2 — Evidence/Elaboration**

| Score | Criteria |
|---|---|
| 4 | Convincing and thorough elaboration. Precise use of relevant evidence from sources. Effective elaborative techniques (examples, quotation, explanation). Vocabulary precise and enhances response. |
| 3 | Adequate elaboration. Some use of relevant evidence from sources. Vocabulary generally appropriate. Elaboration present but may not be fully developed. |
| 2 | Weak or cursory elaboration. Evidence present but unelaborated or imprecise. General or imprecise vocabulary. |
| 1 | Minimal or no evidence from sources. Vocabulary vague or below grade level. Little to no elaboration. |
| 0 | Blank or entirely off-task. |

**Trait 3 — Conventions**

| Score | Criteria |
|---|---|
| 4 | Consistent application of conventions with few errors. Sentence variety enhances response. Errors do not interfere with understanding. |
| 3 | Adequate command of conventions. Some errors present but do not significantly interfere with meaning. Some sentence variety. |
| 2 | Partial command. Errors noticeable and occasionally interfere with meaning. Limited sentence variety. |
| 1 | Limited command. Frequent errors significantly interfere with meaning. Little sentence variety. |
| 0 | Blank or not enough writing to evaluate. |

## 10. Contextualization — Illinois ELA

When generating passages and prompts, prioritize authentic Illinois settings and culture:

### Illinois Context Guide

| Context | Passage Type | Grade Band |
|---|---|---|
| Chicago neighborhoods / urban community | Literary fiction or Informational | 5–8 |
| Illinois prairie ecology / tallgrass restoration | Informational or Literary | 4–8 |
| Great Lakes shoreline (Lake Michigan) | Informational | 4–8 |
| Illinois agricultural heritage (corn, soybeans) | Informational | 3–7 |
| Chicago Architecture / innovation | Informational | 5–8 |
| Route 66 / Illinois transportation history | Informational | 5–8 |
| Illinois River wetlands and ecology | Informational / Literary | 4–8 |
| Immigrant experience in Illinois (Chicago, Quad Cities) | Literary or Personal | 5–8 |
| Lincoln Heritage (Springfield) | Informational | 4–8 |
| Illinois weather extremes (blizzards, tornadoes, floods) | Literary or Informational | 3–8 |
| Cook County / stormwater and green infrastructure | Informational | 6–8 |
| Illinois authors (Gwendolyn Brooks, Carl Sandburg, Sandra Cisneros connections) | Literary text | 6–8 |

### Suggested PT Topics by Grade

**Grades 3–4 Opinion/Narrative:**
- "Should schools have more outdoor learning time?" (Opinion)
- "Write about a time when you helped someone in your community" (Narrative)

**Grades 5–6 Argumentative/Informational:**
- "Should Illinois communities invest in urban gardens and community farms?" (Argumentative)
- "Explain the impact of the Great Chicago Fire on how cities plan for disasters today" (Informational)

**Grades 7–8 Argumentative:**
- "Should Illinois expand its public transportation system to connect rural and urban communities?" (Argumentative)
- "Evaluate whether Illinois schools should implement year-round schooling schedules" (Argumentative)

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] Illinois Learning Standards code verified (IL.CCSS prefix)
- [ ] EBSR Part B is a quote that directly supports Part A (not just same topic)
- [ ] MS items specify exact number of answers to select (TWO/THREE)
- [ ] Full Write prompt is open-ended enough for student voice
- [ ] Full Write scored on all 3 traits (Organization/Purpose, Evidence/Elaboration, Conventions)
- [ ] Passage Lexile matches grade-band range
- [ ] PT sources include at least one non-print source (graph, data table, image)
- [ ] Illinois context incorporated where appropriate (geography, ecology, urban/rural)
- [ ] Distractors represent authentic student misconceptions (not trivially wrong)
- [ ] DOK level matches the actual cognitive demand of the question

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| EBSR Part B that supports a different answer | Part B must directly support Part A's correct answer | Cross-check: does Part B quote only make sense given Part A answer? |
| Full Write prompts with only one correct interpretation | Essay needs room for student perspective | Keep prompts debatable or open-ended |
| Scored on only 2 FW traits | IAR FW uses 3 traits | Always include Organization/Purpose, Evidence/Elaboration, Conventions |
| Using CCSS codes without IL. prefix | Illinois uses IL.CCSS prefix | Add IL. to all standard codes |
| PT sources all the same format (three articles) | IAR PT includes varied source types | Include data tables, graphs, or images as at least one PT source |
| CAT items that don't require textual evidence | IAR ELA items must be passage-dependent | Tie all reading items to a specific passage |

## 12. Prompt Patterns

### Pattern 1: Central Idea / Theme (SR or EBSR, DOK 2–3)
> "What [central idea / theme] does the [passage / author] develop? Which detail from the text BEST supports this [idea / theme]?"

### Pattern 2: Author's Craft (SR, DOK 3)
> "How does the author's use of [figurative language / structure / word choice / point of view] in [this section / paragraph #] affect the [meaning / tone / reader's understanding of ____]?"

### Pattern 3: Evidence Selection (EBSR Part B)
> "Which [sentence / detail] from the [passage] BEST supports your answer to Part A?"

### Pattern 4: Multi-Source Argument (FW, DOK 4)
> "Using evidence from at least two of the three sources, write an argumentative essay about [Illinois-relevant debatable issue]. Be sure to address a counterclaim."

### Pattern 5: Multi-Select Evidence (MS, DOK 2)
> "Select the TWO [details / sentences / examples] from the text that BEST [support / show / explain] [specific focus]."

### Pattern 6: Compare Texts (SR or EBSR, DOK 3)
> "Both sources discuss [common topic]. How does [Source 1] treat this topic differently from [Source 2]?"
