## 1. Overview

| Field | Detail |
|---|---|
| **Assessment Name** | Illinois Assessment of Readiness (IAR) — Mathematics |
| **Administering Agency** | Illinois State Board of Education (ISBE) |
| **Vendor** | Measured Progress |
| **Grades Tested** | 3, 4, 5, 6, 7, 8 |
| **Testing Window** | March – April |
| **Delivery** | Computer-based; two-session test |
| **Standards** | Illinois Learning Standards — Incorporating Common Core Mathematics (CCSS-Math) |
| **Score Scale** | 650–850 scale score (varies by grade); 4 performance levels |
| **Reporting** | Individual Student Report; School, District, State aggregates |

> **IAR and Smarter Balanced:** IAR Mathematics is based on the **Smarter Balanced Assessment Consortium (SBAC) design**. Item types, blueprints, and rubrics closely parallel those used in California (CAASPP). Session 1 is non-calculator; Session 2 permits a calculator (online tool provided).

### Performance Levels

| Level | Label | Description |
|---|---|---|
| 4 | **Exceeded Expectations** | Thorough understanding; applies mathematics in novel situations; constructs valid mathematical arguments |
| 3 | **Met Expectations** | Adequate understanding; applies mathematics to real-world and mathematical problems with reasonable accuracy |
| 2 | **Approached Expectations** | Partial understanding; applies procedures in familiar contexts but struggles with novel problems |
| 1 | **Did Not Meet Expectations** | Minimal understanding; significant conceptual and procedural gaps |

## 3. Test Structure

IAR Mathematics is a two-session assessment. Session 1 is non-calculator; Session 2 allows calculator use.

```
+------------------------------------------------------------------+
|              IAR MATHEMATICS STRUCTURE (Grades 3–8)              |
+------------------------------------------------------------------+
|  SESSION 1 — Non-Calculator                                      |
|  ~45–60 minutes                                                  |
|  Primarily Claim 1 (Concepts & Procedures)                       |
|  Item types: SR, EQ, SCR                                         |
|  ~18–22 items                                                    |
|                                                                  |
+------------------------------------------------------------------+
|  SESSION 2 — Calculator Allowed                                  |
|  ~45–60 minutes                                                  |
|  Claims 2, 3, 4 (Problem Solving, Reasoning, Modeling)          |
|  Item types: SR, EQ, MS, TE, SCR, PT-ER                         |
|  ~18–22 items                                                    |
+------------------------------------------------------------------+
```

### Item Type Summary

| Item Type | Abbreviation | Points | Scored | Session |

| Technology Enhanced | TE | 1–2 | Machine | 2 |

## 4. Claims & Blueprint

### Claim Weightings

| Claim | Weight | Description |
|---|---|---|
| Claim 1 — Concepts & Procedures | ~40% | Students can explain and apply mathematical concepts with precision and fluency |
| Claim 2 — Problem Solving | ~25% | Students can solve a range of complex, well-posed problems using appropriate tools |
| Claim 3 — Communicating Reasoning | ~20% | Students can clearly construct viable arguments to support their own reasoning |
| Claim 4 — Modeling & Data Analysis | ~15% | Students can analyze real-world scenarios and use mathematical models |

### DOK Distribution

| DOK Level | Description | Approximate % |
|---|---|---|
| DOK 1 | Recall; compute; identify | ~20% |
| DOK 2 | Apply; solve in context; connect representations | ~55–60% |
| DOK 3 | Analyze; multi-step reasoning; justify | ~20–25% |

### Session-to-Claim Mapping

| Session | Primary Claims |
|---|---|
| Session 1 (Non-Calculator) | Claim 1 (Concepts & Procedures) |
| Session 2 (Calculator) | Claims 2, 3, and 4 (Problem Solving, Reasoning, Modeling) |

## 5. Item Types & Formats

### Selected Response (SR)

```
+----------------------------------------------------------+
|  SELECTED RESPONSE — 1 point                             |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Real-world or mathematical context                      |
|  Machine scored                                          |
|  DOK 1–3                                                 |
+----------------------------------------------------------+
```

**SR Example (Grade 7, DOK 2, IL.CCSS.Math.7.RP.A.2):**

A Chicago bakery sells 3 loaves of rye bread for $7.50. At this rate, how much would 8 loaves cost?

A. $17.50
B. $18.00
C. $20.00
D. $22.50

*Correct Answer: C*
*Alignment: IL.CCSS.Math.7.RP.A.2 | Claim 1 | DOK 2*

---

### Equation/Numeric Entry (EQ)

```
+----------------------------------------------------------+
|  EQUATION / NUMERIC ENTRY — 1 point                      |
|                                                          |
|  Student types numeric answer or expression              |
|  No answer choices provided                              |
|  Machine scored                                          |
|  DOK 1–2                                                 |
+----------------------------------------------------------+
```

**EQ Example (Grade 5, DOK 2, IL.CCSS.Math.5.NF.A.1):**

A recipe requires 2/3 cup of flour and 1/4 cup of sugar. How many cups of dry ingredients are needed in total?

Enter your answer as a fraction: **11/12**

*Alignment: IL.CCSS.Math.5.NF.A.1 | Claim 1 | DOK 2*

---

### Multi-Select Response (MS)

```
+----------------------------------------------------------+
|  MULTI-SELECT RESPONSE — 1 point                         |
|                                                          |
|  5–6 options; select ALL correct answers (typically 2–3) |
|  Full credit only; partial credit not awarded            |
|  Machine scored                                          |
|  Session 2 (Calculator)                                  |
+----------------------------------------------------------+
```

**MS Example (Grade 8, DOK 2, IL.CCSS.Math.8.EE.C.8):**

Select ALL systems of equations that have the solution (2, 5).

A. y = 3x − 1; y = x + 3
B. y = 2x + 1; y = −x + 7
C. y = x + 3; y = 4x − 3
D. y = 5; y = x + 3
E. y = 3x − 1; y = −2x + 9

*Correct Answers: A, C*
*Alignment: IL.CCSS.Math.8.EE.C.8 | Claim 2 | DOK 2*

---

### Short Constructed Response (SCR)

```
+----------------------------------------------------------+
|  SHORT CONSTRUCTED RESPONSE — 0–2 points                 |
|                                                          |
|  Explain reasoning in 2–4 sentences                      |
|  Show work required for full credit                      |
|  Human scored                                            |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**SCR Example (Grade 6, DOK 3, IL.CCSS.Math.6.RP.A.3):**

A school in Springfield, Illinois is planning a field trip. The school has a budget of $600 for admission. The admission price is $8.50 per student. How many students can attend within the budget? Show your work and explain how you found your answer.

*Scoring:*
- *2 pts: Correct answer (70 students) with clear division work shown; explanation demonstrates understanding of rate reasoning*
- *1 pt: Correct approach with minor arithmetic error, OR correct answer without process shown*
- *0 pts: Incorrect approach or blank*

## 7. Mathematical Representations

IAR Mathematics frequently requires students to connect multiple representations.

### Representation Types

| Representation | Description | Common IAR Use |
|---|---|---|
| **Numeric** | Numbers, fractions, decimals, percents | Computation; comparison |
| **Algebraic** | Equations, expressions, inequalities | Solve; simplify; write |
| **Tabular** | Input/output tables; data tables | Identify patterns; find missing values |
| **Graphical** | Coordinate plane; graphs | Plot points; identify relationships |
| **Verbal** | Word problems; explanations | Apply to context; justify reasoning |

### Calculator Use by Session

| Session | Calculator Policy |
|---|---|
| Session 1 | **No calculator** — Items designed for mental math or standard algorithms |
| Session 2 | **Four-function calculator** available (online tool); scientific calculator for Grades 7–8 specific items |

## 8. Scoring Rubrics

### Short Constructed Response (SCR) Rubric — 0–2 Points

| Score | Criteria |
|---|---|
| 2 | Correct solution with clear mathematical reasoning. Work shown systematically. Appropriate mathematical vocabulary used. Explanation demonstrates conceptual understanding. |
| 1 | Partial understanding with minor errors. Correct approach demonstrated even if the final answer contains a computational error. OR Correct answer given without sufficient explanation or work. |
| 0 | Response is incorrect, shows no understanding, or is blank. |

### Performance Task Extended Response (PT-ER) Rubric — 0–6 Points

| Score | Criteria |
|---|---|
| 6 | All parts correct with clear, complete mathematical reasoning. Work shown systematically. All explanations accurate and complete. |
| 5 | All parts essentially correct. Minor computational or notational error does not affect overall reasoning. |
| 4 | Correct approach throughout. One significant error or one part incorrect; reasoning otherwise sound. |
| 3 | Correct approach on majority of parts. Multiple minor errors or one major error; some reasoning present. |
| 2 | Partial understanding. Correct approach on at least one part; some valid mathematical work. |
| 1 | Minimal understanding shown. Some relevant mathematical work attempted. |
| 0 | Incorrect, irrelevant, or blank. |

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] IL.CCSS standard code is accurate and grade-appropriate
- [ ] Session assignment is correct (calculator vs. non-calculator)
- [ ] Claim alignment matches the cognitive type (Claim 1 = fluency, Claim 3 = reasoning)
- [ ] SCR items require work to be shown (not just a final answer)
- [ ] PT-ER has exactly three parts of increasing complexity
- [ ] MS items specify "ALL" or number of correct answers
- [ ] Illinois real-world context used where appropriate
- [ ] Distractors represent actual student computational or conceptual errors
- [ ] All computations verified before item is finalized
- [ ] DOK level matches the actual cognitive demand

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Calculator items in Session 1 | Session 1 is non-calculator | Design Session 1 items for mental math or standard algorithms |
| SCR that only asks for an answer | SCR must require explanation/justification | Add "Show your work and explain how you found your answer" |
| PT-ER with only one part | PT-ER requires multi-part structure | Design 3 parts of increasing complexity and cognitive demand |
| Using CCSS codes without IL. prefix | Illinois uses IL.CCSS prefix | Add IL. to all standard codes |
| MS items with only 2 options total | Too few options make guessing easy | Use 5–6 options with exactly 2–3 correct |
| Items testing only rote computation | IAR targets DOK 2 primarily | Add real-world context to elevate to application level |

## 12. Prompt Patterns

### Pattern 1: Real-World Application (SR, DOK 2)
> "[Illinois context]. [Multi-step problem requiring application of concept]. What is [answer]?"

### Pattern 2: Justify and Explain (SCR, DOK 3)
> "[Illinois scenario requiring strategic thinking]. [Multi-step problem]. Show your work and explain how you found your answer."

### Pattern 3: Equivalent Representations (MS, DOK 2)
> "Select ALL [expressions / equations / graphs / representations] that are equivalent to [given value or expression]."

### Pattern 4: Linear Relationship (SR or SCR, DOK 2–3)
> "The [table / graph] shows [Illinois data context]. What is the [rate of change / slope / equation] that represents this relationship? / Is this relationship proportional or non-proportional? Justify your answer."

### Pattern 5: Multi-Part Modeling (PT-ER, DOK 3)
> "Part A: [Direct calculation]. Part B: [Extension or comparison]. Part C: [Justify whether... / Evaluate if this is reasonable using mathematics]."

### Pattern 6: Comparison and Reasoning (SCR or SR, DOK 3)
> "Two students solved this problem differently. Student A says [method/answer]. Student B says [method/answer]. Who is correct? Use mathematics to justify your answer."
