## 1. Overview

| Field | Detail |
|---|---|
| **Assessment Name** | ILEARN — English/Language Arts (ELA) |
| **Administering Agency** | Indiana Department of Education (IDOE) |
| **Vendor** | Pearson |
| **Grades Tested** | 3, 4, 5, 6, 7, 8, and 10 |
| **Testing Window** | April – May |
| **Delivery** | Computer-based; paper accommodations available |
| **Standards** | Indiana Academic Standards — English/Language Arts |
| **Score Scale** | Scaled score; 4 performance levels |
| **Reporting** | Individual Student Report; School, Corporation, State aggregates |

> **ILEARN ELA Structure:** ILEARN ELA uses a variety of item types including multiple choice, multi-select, evidence-based selected response (EBSR), technology-enhanced items, and constructed response. The assessment is passage-based and requires students to analyze literary and informational texts with increasing complexity across grade bands.

### Performance Levels

| Level | Label | Description |
|---|---|---|
| 4 | **Above Proficiency** | Demonstrates thorough understanding; applies Indiana Academic Standards in sophisticated and complex ways |
| 3 | **At Proficiency** | Demonstrates solid understanding of grade-level Indiana Academic Standards; meets expectations |
| 2 | **Approaching Proficiency** | Demonstrates partial understanding; developing but not yet meeting grade-level expectations |
| 1 | **Below Proficiency** | Demonstrates minimal understanding; significant gaps in mastery of grade-level standards |

> **Item-writing target:** "At Proficiency" performance. Items should require genuine application of Indiana Academic Standards — not mere recall.

## 2. Standards Framework

> ILEARN ELA is aligned to the **Indiana Academic Standards for English/Language Arts**. The standards are organized by reading literature, reading nonfiction, writing, and speaking/listening strands.

### Indiana Academic Standards ELA Strands

| Strand | Focus | Grade Emphasis |
|---|---|---|
| **Reading: Literature** | Literary text comprehension; theme; character; craft; structure | Primary focus throughout |
| **Reading: Nonfiction** | Informational text comprehension; argument; evidence; text features | Primary focus throughout |
| **Writing** | Narrative, argumentative, informational writing; conventions; editing | Assessed via CR and ER |
| **Speaking and Listening** | Not directly assessed on ILEARN | N/A |

### Key Reading Standards by Grade Band

| Standard Code | Description | Grade Band | DOK |
|---|---|---|---|
| IN.ELA3.RL.2.1 | Ask and answer questions about a text, referring explicitly to the text for answers | 3–4 | 1–2 |
| IN.ELA5.RL.2.3 | Describe how a narrator's or speaker's point of view influences how events are described | 5 | 2–3 |
| IN.ELA6.RL.2.2 | Analyze how the theme or central idea develops over the course of a text | 6 | 3 |
| IN.ELA7.RN.3.3 | Evaluate the argument and claims in a text, assessing whether reasoning is sound and evidence is relevant | 7 | 3 |
| IN.ELA8.RL.2.1 | Analyze how an author develops and contrasts points of view of characters or narrators | 8 | 3 |
| IN.ELA10.RL.2.3 | Analyze how complex characters develop over the course of a text and interact with other characters | 10 | 3 |

### Key Writing Standards

| Standard Code | Description | Grade Band | DOK |
|---|---|---|---|
| IN.ELA3-8.W.3.1 | Write arguments to support claims with clear reasons and relevant evidence | 3–8 | 3 |
| IN.ELA3-8.W.3.2 | Write informative/explanatory texts to examine a topic | 3–8 | 3 |
| IN.ELA3-8.W.3.3 | Write narratives to develop real or imagined experiences | 3–8 | 3–4 |

## 3. Test Structure

ILEARN ELA is administered in two sessions over one to two days. The test includes passage-based items across multiple formats.

```
+------------------------------------------------------------------+
|            ILEARN ELA STRUCTURE (Grades 3–8, 10)                  |
+------------------------------------------------------------------+
|  TWO SESSIONS — Approximately 2–3 hours total                    |
|  Computer-Based                                                   |
|                                                                   |
|  SESSION 1: READING & LANGUAGE                                    |
|  ┌────────────────────────────────────────┐                      |
|  │ Passage Set 1 (Literary) → MC, EBSR,  │                      |
|  │   MS, TEI items                       │                      |
|  │ Passage Set 2 (Informational) → MC,   │                      |
|  │   EBSR, MS, TEI items                │                      |
```

## 5. Item Types & Formats

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Passage-based                                           |
|  Machine scored                                          |
|  DOK 1–3                                                 |
+----------------------------------------------------------+
```

**MC Example (Grade 7 Literary, DOK 3, IN.ELA7.RL.2.2):**

*[After reading a short story about a young runner training for the Indianapolis 500 Festival Mini-Marathon]*

How does the author develop the theme of perseverance throughout the story?

A. By describing the history of the Indianapolis 500
B. By showing how the main character overcomes repeated setbacks through determination and support from her coach
C. By comparing the main character's experience to professional race car drivers
D. By listing the physical benefits of running long distances

*Correct Answer: B*
*Alignment: IN.ELA7.RL.2.2 | DOK 3*

---

### Evidence-Based Selected Response (EBSR)

```
+----------------------------------------------------------+
|  EVIDENCE-BASED SELECTED RESPONSE — 1–2 points          |
|                                                          |
|  Two-part item:                                          |
|  Part A: Make an inference or claim (4 options)          |
|  Part B: Select evidence that supports Part A            |
|  Machine scored                                          |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**EBSR Example (Grade 5 Informational, DOK 2, IN.ELA5.RN.2.1):**

*[After reading an article about Indiana limestone and its use in famous buildings]*

**Part A:** What is the MAIN idea of the article?

A. Indiana limestone is the most expensive building material in the United States
B. Indiana limestone has been used in many important American buildings because of its quality and durability
C. Mining limestone in Indiana is dangerous work
D. Indiana has more limestone quarries than any other natural resource

**Part B:** Which sentence from the article BEST supports the answer to Part A?

F. "The quarries near Bedford, Indiana, have produced stone for the Empire State Building, the Pentagon, and dozens of state capitols."
G. "Limestone mining has been an Indiana industry since the early 1800s."
H. "Workers use large saws to cut the limestone into blocks."
J. "Indiana's climate makes quarrying difficult during winter months."

*Correct Answers: Part A — B; Part B — F*
*Alignment: IN.ELA5.RN.2.1 | DOK 2*

### Constructed Response (CR)

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE — 0–2 or 0–4 points               |
|                                                          |
|  Short CR: 0–2 points (2–4 sentence response)           |
|  Extended CR: 0–4 points (multi-paragraph response)      |
|  Must reference textual evidence                         |
|  Human scored                                            |
|  DOK 3–4                                                 |
+----------------------------------------------------------+
```

**CR Example (Grade 8, DOK 3, IN.ELA8.RL.2.1 — 0–2 pts):**

*[After reading a story set near the Indiana Dunes about a family preserving a natural landscape]*

Using evidence from the story, explain how the author contrasts the perspectives of the father and daughter regarding the future of the dunes.

---

**Extended CR Example (Grade 10, DOK 4, IN.ELA10.W.3.1 — 0–4 pts):**

*[After reading two passages: one about Lincoln's boyhood in Indiana, one about his later leadership]*

Using evidence from both passages, write an essay explaining how Lincoln's experiences growing up in Indiana shaped the leadership qualities he displayed later in life. Use specific details from both texts to support your analysis.

## 8. Scoring Rubrics

### Constructed Response (CR) Rubric — 0–2 Points

| Score | Criteria |
|---|---|
| 2 | Response accurately addresses the question with a clear, specific answer. Includes relevant textual evidence (quoted or paraphrased) that directly supports the response. |
| 1 | Response partially addresses the question. Evidence may be present but not directly connected, or answer is accurate but lacks sufficient evidence. |
| 0 | Response is inaccurate, irrelevant, insufficient to evaluate, or blank. |

### Extended Constructed Response (CR) Rubric — 0–4 Points

| Score | Criteria |
|---|---|
| 4 | Thorough, insightful response with a clear controlling idea. Multiple pieces of relevant textual evidence integrated smoothly. Analysis is sophisticated and well-organized. Strong command of conventions. |
| 3 | Adequate response with a clear controlling idea. Relevant evidence included and generally well-integrated. Analysis is sound. Minor convention errors. |
| 2 | Partial response with an evident controlling idea. Some evidence present but may be insufficient or loosely connected. Analysis is basic. Some convention errors. |
| 1 | Minimal response with a weak or unclear controlling idea. Little or no evidence. Analysis superficial or largely inaccurate. Frequent convention errors. |
| 0 | Blank, off-topic, or insufficient writing to evaluate. |

## 10. Contextualization — Indiana ELA

When generating passages and prompts, prioritize authentic Indiana settings, history, and culture:

### Indiana Context Guide

| Context | Passage Type | Grade Band |
|---|---|---|
| Indianapolis 500 / racing heritage | Literary fiction or Informational | 4–8 |
| Indiana limestone quarries and architecture | Informational | 5–8 |
| Hoosier agriculture (corn, soybeans, farming life) | Literary or Informational | 3–7 |
| Lincoln's boyhood home (Spencer County) | Historical fiction or Informational | 4–8 |
| Indiana Dunes (ecology, recreation, preservation) | Informational or Literary | 4–8 |
| Covered bridges of Parke County | Literary or Informational | 3–6 |
| Indiana basketball traditions | Literary fiction or Informational | 4–8 |
| Conner Prairie / Indiana pioneer history | Historical fiction or Informational | 4–7 |
| Indiana authors (Kurt Vonnegut, Booth Tarkington, Gene Stratton-Porter) | Literary text or excerpt | 7–10 |
| Wabash River / Indiana waterways | Informational | 5–8 |

### Suggested Passage Topics by Grade Band

**Grades 3–4:**
- A student's first visit to a covered bridge in Parke County
- An informational article about Indiana's state symbols and agriculture
- A story about a family attending the Indianapolis 500 for the first time

**Grades 5–6:**
- Historical fiction set at Lincoln's boyhood home in Indiana
- An article about how Indiana limestone is quarried and used in famous buildings
- A narrative about growing up on an Indiana farm during harvest season

**Grades 7–10:**
- Paired passages about the history and ecology of the Indiana Dunes
- An argumentative essay about preserving Indiana's natural landscapes
- Literary fiction set in Indianapolis exploring themes of community and identity

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] Indiana Academic Standard code verified as correct for the targeted grade
- [ ] EBSR Part B evidence aligns with Part A correct answer
- [ ] MC items directly tied to the passage (not general knowledge)
- [ ] CR prompt requires textual evidence ("Using evidence from...")
- [ ] Distractors represent authentic misconceptions
- [ ] Lexile of passage matches the grade-level range
- [ ] Indiana context incorporated where appropriate
- [ ] Extended CR scored on 4-point scale with clear rubric criteria
- [ ] DOK level matches the cognitive demand
- [ ] All item types appropriate for the grade level

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| EBSR Part B doesn't align with Part A | Part B evidence must support the correct Part A answer | Verify alignment before finalizing |
| CR prompt without evidence requirement | Students may not cite text | Always include "using evidence from" language |
| Extended CR scored on only 2 points | ILEARN extended CR uses 0–4 scale | Use full 4-point rubric |
| Items not passage-dependent | ILEARN ELA is passage-based | Tie all reading items to a specific passage |
| Using CCSS codes | Indiana uses its own Academic Standards | Reference Indiana Academic Standard codes |
| Ignoring Grade 10 | ILEARN tests Grade 10 as well | Include Grade 10 in planning |

## 12. Prompt Patterns

### Pattern 1: Theme Development (MC or CR, DOK 3)
> "How does the author develop the theme of [theme] throughout the [story / passage]?"

### Pattern 2: Evidence-Based Inference (EBSR, DOK 2–3)
> "Part A: What can the reader infer about [character / idea]? Part B: Which sentence BEST supports the answer to Part A?"

### Pattern 3: Author's Craft (MC, DOK 3)
> "Read [line reference]. What effect does the author's use of [literary device] create in this [passage / paragraph]?"

### Pattern 4: Argument Evaluation (MC or CR, DOK 3)
> "How does the author support the claim that [claim]? / Evaluate the effectiveness of the author's argument using evidence from the text."

### Pattern 5: Cross-Text Synthesis (Extended CR, DOK 4)
> "Using evidence from both passages, write an essay [explaining / analyzing / arguing] [specific focus]. Include details from both texts."

### Pattern 6: Vocabulary in Context (MC, DOK 1–2)
> "As used in paragraph [#], what does the word [word] MOST LIKELY mean?"

### Pattern 7: Text Structure (MC or TEI, DOK 2)
> "How does the author organize the information in this [article / section]? / What is the purpose of [text feature]?"
