| **Grades Tested** | **Grade 5**, **Grade 8**, and **Grade 10** |

> **CRITICAL NOTE:** ILEARN Science is administered at **Grades 5, 8, and 10 only**. Do not generate ILEARN-aligned science items for other grades for state accountability purposes.

### Performance Levels

| Level | Label | Description |
|---|---|---|
| 4 | **Above Proficiency** | Demonstrates thorough understanding; applies Indiana science standards in complex, novel situations |
| 3 | **At Proficiency** | Demonstrates solid understanding of grade-level Indiana science standards; meets expectations |
| 2 | **Approaching Proficiency** | Demonstrates partial understanding; developing but not yet meeting grade-level expectations |
| 1 | **Below Proficiency** | Demonstrates minimal understanding; significant gaps in mastery of grade-level science standards |

> **Item-writing target:** "At Proficiency" performance. Items should require genuine application of science concepts — not mere recall of vocabulary.

## 2. Standards Framework

The standards emphasize scientific inquiry, engineering design, and content knowledge across physical, life, and earth/space science.

| SEPS.5 | Using mathematics and computational thinking |
| SEPS.6 | Constructing explanations and designing solutions |

| SEPS.8 | Obtaining, evaluating, and communicating information |

## 3. Test Structure

ILEARN Science is a single-session, computer-based assessment. Items include MC, MS, and TEI formats. Items are scenario-based with data tables, diagrams, and investigation contexts.

```
+------------------------------------------------------------------+
|          ILEARN SCIENCE STRUCTURE (Grades 5, 8, 10)               |
+------------------------------------------------------------------+
|  SINGLE SESSION — Approximately 1.5–2 hours                      |
|  Computer-Based                                                   |
|                                                                   |
|  ~40–50 items total                                               |
|                                                                   |
|  Item types:                                                      |
|    • Multiple Choice (MC) — ~70–75% of items                      |
|    • Multi-Select (MS) — ~10–15% of items                         |
|    • Technology Enhanced Items (TEI) — ~10–15% of items           |
|      (drag-and-drop, labeling, sequencing, matching)             |
+------------------------------------------------------------------+
```

## 5. Item Types & Formats

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Scenario-based or data-based stimulus                   |
|  May include diagrams, data tables, graphs               |
|  Machine scored                                          |
|  DOK 1–3                                                 |
+----------------------------------------------------------+
```

**MC Example (Grade 5, DOK 2, IN.Sci5.LS.2 — Indiana Dunes Ecology):**

*[Diagram shows a food web at Indiana Dunes National Park: Sunlight -> Marram Grass -> Grasshoppers -> Sand-colored Spiders -> Kestrels]*

Based on the food web, what would MOST LIKELY happen to the spider population if the grasshopper population decreased significantly?

A. The spider population would increase because there would be less competition for space
B. The spider population would decrease because they would have less food available
C. The spider population would not change because spiders can eat marram grass
D. The spider population would migrate to a different part of the dunes

*Correct Answer: B*
*Alignment: IN.Sci5.LS.2 | DOK 2*

---

**MC Example (Grade 8, DOK 2, IN.Sci8.ESS.1 — Indiana Limestone Geology):**

A geologist studying a quarry near Bedford, Indiana, discovers that the limestone contains abundant fossils of crinoids and brachiopods — organisms that lived in ancient seas. Which conclusion is BEST supported by this evidence?

A. The Bedford area was once the site of active volcanoes
B. The area where the fossils were found was once covered by a warm, shallow sea
C. The fossils were carried to Indiana by glaciers during the last ice age
D. Ancient marine organisms lived on land before evolving to live in water

*Correct Answer: B*
*Alignment: IN.Sci8.ESS.1 | DOK 2*

---

### Multi-Select (MS)

```
+----------------------------------------------------------+
|  MULTI-SELECT — 1 point                                  |
|                                                          |
|  5–6 options; select ALL correct (typically 2–3)         |
|  All correct must be selected for credit                 |
|  Machine scored                                          |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**MS Example (Grade 10, DOK 2, IN.Sci10.ESS.3):**

The Wabash River watershed drains approximately two-thirds of Indiana's land area. Select the TWO human activities that would MOST LIKELY increase the amount of sediment entering the Wabash River.

A. Planting cover crops along the river banks
B. Clearing forests along tributaries for new construction
C. Building a water treatment facility downstream
D. Converting wetlands into farmland
E. Installing rain gardens in residential areas

*Correct Answers: B, D*
*Alignment: IN.Sci10.ESS.3 | DOK 2*

## 7. Scientific Investigation Design

ILEARN Science emphasizes students' ability to design and evaluate scientific investigations through Indiana's Science and Engineering Process Standards (SEPS).

### Investigation Design Components

| Component | Description | SEPS Alignment |
|---|---|---|
| **Testable Question** | Question that can be answered through investigation | SEPS.1 |
| **Hypothesis** | Testable prediction about the relationship between variables | SEPS.1 |
| **Independent Variable** | The variable the investigator changes | SEPS.3 |
| **Dependent Variable** | The variable being measured or observed | SEPS.3 |
| **Control Group** | Condition held constant for comparison | SEPS.3 |
| **Data Collection** | Measurement using appropriate tools and techniques | SEPS.4 |
| **Evidence-Based Conclusion** | Inference drawn from data; connection back to hypothesis | SEPS.6, SEPS.7 |

### Investigation Item Structure

```
+------------------------------------------------------------------+
|  INVESTIGATION DESIGN ITEM (MC or TEI)                            |
|                                                                   |
|  SCENARIO: An Indiana student investigates whether [variable]     |
|  affects [outcome] in a [Indiana-relevant setting].               |
|                                                                   |
|  STEM (MC): Which experimental setup would BEST allow the         |
|  student to test this hypothesis?                                 |
|  — OR —                                                           |
|  STEM (TEI): Drag the labels to correctly identify the            |
|  independent, dependent, and controlled variables.                |
+------------------------------------------------------------------+
```

## 8. Scoring Rubrics

### Multiple Choice (MC) — 1 Point

| Score | Criteria |
|---|---|
| 1 | Student selects the correct answer |
| 0 | Student selects an incorrect answer or leaves blank |

### Multi-Select (MS) — 1 Point

| Score | Criteria |
|---|---|
| 1 | Student selects ALL correct answers and no incorrect answers |
| 0 | Any incorrect selection or missing correct selection |

### Technology Enhanced Item (TEI) Rubric — 1–2 Points

| Score | Criteria |
|---|---|
| 2 | All components of the response are correct (all labels, sequences, or matches accurate) |
| 1 | Response is partially correct; at least one component accurately completed |
| 0 | Response is incorrect or blank |

## 10. Contextualization — Indiana Science

When generating science items, prioritize authentic Indiana natural settings and phenomena:

### Indiana Science Context Guide

| Setting / Phenomenon | Grade | Science Domain | Standard Alignment |
|---|---|---|---|
| Indiana Dunes ecology (dune succession, food webs, native species) | 5, 8 | Life Science | IN.Sci5.LS.1, IN.Sci5.LS.2, IN.Sci8.LS.5 |
| Indiana limestone geology (Bedford quarries, fossils, sedimentary processes) | 5, 8, 10 | Earth Science | IN.Sci5.ESS.3, IN.Sci8.ESS.1 |
| Wabash River watershed (water quality, erosion, sediment transport, human impact) | 5, 8, 10 | Earth/Life Science | IN.Sci5.ESS.4, IN.Sci8.ESS.4, IN.Sci10.ESS.3 |
| Indiana glacial landscape (moraines, till plains, kettle lakes) | 8, 10 | Earth Science | IN.Sci8.ESS.1 |
| Indiana agriculture impact (soil erosion, nitrogen runoff, water quality) | 8, 10 | Earth Science | IN.Sci8.ESS.4, IN.Sci10.ESS.3 |
| Indiana cave systems (karst geology, groundwater) | 8 | Earth Science | IN.Sci8.ESS.1 |
| Indiana forest ecosystems (hardwood forests, seasonal changes) | 5, 8 | Life Science | IN.Sci5.LS.1, IN.Sci8.LS.5 |
| Indiana wetlands and restoration | 5, 8, 10 | Life/Earth Science | IN.Sci5.ESS.4, IN.Sci8.LS.5 |
| Indiana mineral and fossil resources | 5, 8 | Earth Science | IN.Sci5.ESS.3, IN.Sci8.ESS.1 |
| Lake Michigan shoreline processes | 5, 8 | Earth Science | IN.Sci5.ESS.3, IN.Sci8.ESS.4 |

### Suggested Anchoring Phenomena by Grade

**Grade 5 Phenomena:**
- "Students visiting Indiana Dunes National Park noticed that the vegetation changes from grasses near the beach to dense forests further inland. What might explain this pattern?"
- "After a heavy rainstorm, a student observed that the creek near their school in southern Indiana was cloudy and brown. What process caused this change?"
- "An Indiana farmer noticed that adding cover crops to fields reduced the amount of soil washed into nearby streams. What scientific question could the farmer investigate?"

**Grade 8 Phenomena:**
- "A geologist studying a quarry near Bedford, Indiana, discovered layers of limestone containing fossils of organisms that lived in warm, shallow seas. What geological history does this evidence reveal about Indiana?"
- "Scientists monitoring the Wabash River found that water quality decreases downstream from areas with intensive farming. What evidence connects agricultural practices to changes in water chemistry?"
- "Students noticed that northern Indiana has flat terrain with rich soil, while southern Indiana has hills and exposed limestone. What geological processes created these different landscapes?"

**Grade 10 Phenomena:**
- "The Wabash River watershed drains most of Indiana's land area, carrying nutrients and sediments from agricultural fields to the river. How do human activities affect the cycling of matter through this watershed?"
- "Indiana Dunes has undergone ecological succession from bare sand to mature forest over centuries. What factors drive changes in biodiversity during this process?"

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] Grade verified as 5, 8, or 10 ONLY (not other grades)
- [ ] Indiana Academic Standard code is accurate and grade-appropriate
- [ ] Stimulus (data table/graph/diagram) clearly labeled with units
- [ ] MS items have clearly correct answers with no ambiguity
- [ ] TEI items use technology meaningfully (drag-and-drop, sequencing, labeling)
- [ ] All distractors represent real student misconceptions
- [ ] Investigation design items clearly identify variables
- [ ] Science content is accurate and reflects current scientific understanding
- [ ] Indiana context incorporated where possible (Dunes, limestone, Wabash River)
- [ ] DOK level matches the cognitive demand

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Writing science items for non-tested grades | ILEARN Science only at Grades 5, 8, 10 | Restrict to tested grades |
| Using NGSS codes instead of Indiana codes | Indiana uses its own Academic Standards for Science | Reference Indiana standard codes exclusively |
| MS with ambiguous options | All-or-nothing scoring means each option must be clearly correct or incorrect | Verify each option independently |
| Items assessing factual recall only | ILEARN Science is ~55–60% DOK 2 | Elevate items with scenarios and data |
| Generic phenomena not anchored to Indiana | Assessment favors Indiana-specific contexts | Use Indiana Dunes, limestone, Wabash River, glacial features |
| MC with two clearly correct options | Creates ambiguity | Review all options carefully; only one clearly correct |

## 12. Prompt Patterns

### Pattern 1: Data-to-Conclusion (MC, DOK 2)
> "The [table / graph / diagram] shows [Indiana science scenario]. Based on the data, which [conclusion / explanation / prediction] is BEST supported?"

### Pattern 2: Cause and Effect (MC, DOK 2)
> "A student [observed / measured / recorded] that [Indiana phenomenon]. Which explanation BEST describes why this [occurred / changed]?"

### Pattern 3: Investigation Design (MC or TEI, DOK 2–3)
> "[Indiana student] wants to investigate whether [variable] affects [outcome] in [Indiana setting]. Which experimental design would BEST test this? / What is the [dependent / independent / controlled] variable?"

### Pattern 4: Food Web / Ecosystem Change (MC or MS, DOK 2–3)
> "[Indiana ecosystem — Dunes / forest / Wabash River] diagram shows [food web / community]. If [organism / factor] changed, what would MOST LIKELY happen to [other organism / population]?"

### Pattern 5: Geological Process (MC, DOK 2)
> "A geologist studying [Indiana region] discovered [geological feature / rock type / fossil]. Which [process / explanation] BEST accounts for this observation?"

### Pattern 6: Evidence-Based Multi-Select (MS, DOK 2–3)
> "Select the TWO [observations / activities / factors] that BEST [support / explain / describe] [Indiana science phenomenon]."
