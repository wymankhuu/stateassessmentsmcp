## 1. Overview

| Field | Detail |
|---|---|
| **Assessment Name** | ILEARN — Mathematics |
| **Administering Agency** | Indiana Department of Education (IDOE) |
| **Vendor** | Pearson |
| **Grades Tested** | 3, 4, 5, 6, 7, 8, and 10 |
| **Testing Window** | April – May |
| **Delivery** | Computer-based; paper accommodations available |
| **Standards** | Indiana Academic Standards — Mathematics |
| **Score Scale** | Scaled score; 4 performance levels |
| **Reporting** | Individual Student Report; School, Corporation, State aggregates |

> **ILEARN Math Structure:** ILEARN Mathematics uses multiple choice (MC), multi-select (MS), equation/numeric entry (EQ), and constructed response (CR) items scored 0–2 or 0–4. Items emphasize real-world application, multi-step reasoning, and conceptual understanding across Indiana Academic Standards.

### Performance Levels

| Level | Label | Description |
|---|---|---|
| 4 | **Above Proficiency** | Demonstrates thorough understanding; applies Indiana Academic Standards in complex, non-routine situations |
| 3 | **At Proficiency** | Demonstrates solid understanding of grade-level Indiana Academic Standards; meets expectations |
| 2 | **Approaching Proficiency** | Demonstrates partial understanding; developing but not yet meeting grade-level expectations |
| 1 | **Below Proficiency** | Demonstrates minimal understanding; significant gaps in mastery of grade-level standards |

> **Item-writing target:** "At Proficiency" performance. Items should require genuine application of Indiana Academic Standards — not mere recall of procedures.

## 2. Standards Framework

> ILEARN Mathematics is aligned to the **Indiana Academic Standards for Mathematics**, organized by process standards and content domains that build across grade bands.

### Indiana Academic Standards Mathematics Domains

| Domain | Focus | Grade Emphasis |
|---|---|---|
| **Number Sense** | Place value, fractions, decimals, integers, rational/irrational numbers | Primary focus Grades 3–6 |
| **Computation** | Operations, fluency, estimation, order of operations | Grades 3–7 |
| **Algebraic Thinking** | Expressions, equations, inequalities, functions | Grows Grades 4–10 |
| **Geometry** | Shapes, area, volume, transformations, coordinate geometry | All grades |
| **Measurement** | Units, conversions, applications | All grades |
| **Data Analysis, Statistics, and Probability** | Data displays, central tendency, probability, statistical reasoning | All grades; increases Grades 6–10 |

## 3. Test Structure

ILEARN Mathematics is administered in two sessions. Items include MC, MS, EQ (equation/numeric entry), and CR (constructed response scored 0–2 or 0–4).

```
+------------------------------------------------------------------+
|            ILEARN MATHEMATICS STRUCTURE (Grades 3–8, 10)          |
+------------------------------------------------------------------+
|  TWO SESSIONS — Approximately 2–3 hours total                    |
|  Computer-Based                                                   |
|                                                                   |
|  SESSION 1                                                        |
|  ┌────────────────────────────────────────┐                      |
|  │ MC items (4 options, 1 pt each)       │                      |
|  │ MS items (select all, 1 pt each)      │                      |

```

## 5. Item Types & Formats

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Real-world or mathematical context                      |
|  Machine scored                                          |
|  DOK 1–3                                                 |
+----------------------------------------------------------+
```

**MC Example (Grade 6, DOK 2, IN.Math6.C.6):**

An Indiana farmer produced 12,480 bushels of corn across 96 acres. If each acre produced the same number of bushels, how many bushels of corn did each acre produce?

A. 120
B. 125
C. 130
D. 135

*Correct Answer: C*
*Alignment: IN.Math6.C.6 | DOK 2*

---

### Multi-Select (MS)

```
+----------------------------------------------------------+
|  MULTI-SELECT — 1 point                                  |
|                                                          |
|  5–6 options; select ALL correct answers (typically 2–3) |
|  All correct must be selected for full credit            |
|  Machine scored                                          |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**MS Example (Grade 8, DOK 2, IN.Math8.AF.7):**

The table shows the distance a car travels on I-65 from Indianapolis heading south.

| Time (hours) | Distance (miles) |
|---|---|
| 1 | 62 |
| 2 | 124 |
| 3 | 186 |
| 4 | 248 |

Select ALL statements that are true about this relationship.

A. The relationship is proportional
B. The rate of change is 62 miles per hour
C. The equation d = 62t + 10 represents the relationship
D. The graph of this relationship passes through the origin
E. The rate of change increases over time

*Correct Answers: A, B, D*
*Alignment: IN.Math8.AF.7 | DOK 2*

---

### Equation / Numeric Entry (EQ)

```
+----------------------------------------------------------+
|  EQUATION / NUMERIC ENTRY — 1 point                      |
|                                                          |
|  Student types a numeric value or expression              |
|  Exact match or equivalent forms accepted                |
|  Machine scored                                          |
|  DOK 1–2                                                 |
+----------------------------------------------------------+
```

**EQ Example (Grade 5, DOK 2, IN.Math5.M.4):**

A storage container at an Indiana soybean processing plant is shaped like a rectangular prism. The container is 8 feet long, 5 feet wide, and 4 feet tall. What is the volume of the container, in cubic feet?

Enter your answer: _____ cubic feet

*Correct Answer: 160*
*Alignment: IN.Math5.M.4 | DOK 2*

---

### Constructed Response (CR)

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE — 0–2 or 0–4 points               |
|                                                          |
|  Short CR: 0–2 points (show work + answer)               |
|  Extended CR: 0–4 points (multi-step + explanation)      |
|  Must show mathematical reasoning                        |
|  Human scored                                            |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**CR Example (Grade 7, DOK 3, IN.Math7.C.6 — 0–2 pts):**

During the Indy 500, a race car completes 200 laps on a 2.5-mile oval track. The car's average speed for the first 100 laps was 220 miles per hour, and the average speed for the last 100 laps was 215 miles per hour. How much longer did it take the car to complete the last 100 laps compared to the first 100 laps? Show your work.

---

**Extended CR Example (Grade 10, DOK 3, IN.Math10.DSP.4 — 0–4 pts):**

The table shows the population of Indianapolis (in thousands) for selected years.

| Year | Population (thousands) |
|---|---|
| 1980 | 701 |
| 1990 | 742 |
| 2000 | 782 |
| 2010 | 820 |
| 2020 | 887 |

Part A: Create a scatterplot of the data and describe the trend.
Part B: Estimate the population of Indianapolis in 2030. Explain your reasoning and state any assumptions.
Part C: Explain why a linear model may or may not be appropriate for predicting the population in 2060.

## 7. Mathematical Representations

ILEARN Mathematics items frequently require students to move between multiple representations.

### Representation Types

| Representation | Description | Common Item Use |
|---|---|---|
| **Tabular** | Input/output table; data table | Identify patterns; find missing values; analyze trends |
| **Graphical** | Coordinate plane; bar/line graph; scatterplot; histogram | Identify slope; read data; compare distributions |
| **Algebraic** | Equations; inequalities; expressions | Solve; write; simplify; model real-world contexts |
| **Verbal** | Word problem; real-world scenario | Apply to Indiana context |
| **Visual/Geometric** | Diagrams; figures with measurements; number lines | Compute area/volume; apply transformations |

### Representation Connections by Grade Band

| Grade Band | Frequent Connections |
|---|---|
| 3–5 | Number line ↔ fraction; table ↔ pattern rule; model ↔ computation |
| 6–7 | Table ↔ equation ↔ graph; ratio ↔ percent ↔ proportion |
| 8–10 | Equation ↔ graph ↔ table; scatterplot ↔ linear/nonlinear model; function ↔ multiple representations |

## 8. Scoring Rubrics

### Multiple Choice (MC) — 1 Point

| Score | Criteria |
|---|---|
| 1 | Student selects the correct answer |
| 0 | Student selects an incorrect answer or leaves blank |

### Multi-Select (MS) — 1 Point

| Score | Criteria |
|---|---|
| 1 | Student selects ALL correct answers and no incorrect answers |
| 0 | Any incorrect selection or missing correct selection |

### Equation / Numeric Entry (EQ) — 1 Point

| Score | Criteria |
|---|---|
| 1 | Student enters the correct numeric value or equivalent expression |
| 0 | Incorrect value or blank |

### Constructed Response (CR) Rubric — 0–2 Points

| Score | Criteria |
|---|---|
| 2 | Correct answer with complete and accurate mathematical work shown; reasoning is clear |
| 1 | Partially correct; correct approach with computational error, OR correct answer without sufficient work |
| 0 | Incorrect, irrelevant, or blank |

### Extended Constructed Response (CR) Rubric — 0–4 Points

| Score | Criteria |
|---|---|
| 4 | All parts answered correctly with thorough mathematical reasoning; work is organized, accurate, and clearly explained |
| 3 | Most parts correct; reasoning is sound with minor errors or omissions in explanation |
| 2 | Partial response; demonstrates understanding of the concept but contains significant errors or incomplete reasoning |
| 1 | Minimal response; attempts the problem but demonstrates limited understanding; major errors |
| 0 | Blank, off-topic, or no mathematical reasoning demonstrated |

## 10. Contextualization — Indiana Mathematics

When generating math problem contexts, use authentic Indiana settings:

### Indiana Math Context Guide

| Context | Domain | Grade Band |
|---|---|---|
| Indy 500 data (speed, distance, laps, time, fuel consumption) | Rate, Proportionality, Operations | 5–10 |
| Indiana corn production (bushels per acre, total yield, seasonal data) | Operations, Ratio, Data Analysis | 3–8 |
| Indiana soybean production (yield data, comparison across counties) | Ratio, Proportionality, Data Analysis | 4–8 |
| Indianapolis population growth (census data, trends, projections) | Data Analysis, Functions, Modeling | 6–10 |
| Indiana highway distances (I-65, I-70, I-69 routes) | Rate, Proportionality, Operations | 4–8 |
| Indiana basketball court dimensions and statistics | Geometry, Measurement, Data Analysis | 4–8 |
| Indiana limestone quarry measurements | Geometry, Measurement, Volume | 5–8 |
| Indiana Dunes beach erosion data | Data Analysis, Rate of Change | 6–10 |
| Wabash River flow rate and watershed data | Rate, Proportionality, Data Analysis | 6–10 |
| Indiana state fair attendance and revenue | Data Analysis, Operations | 3–7 |

### Suggested Problem Contexts by Grade Band

**Grades 3–4:**
- A student counts ears of corn at an Indiana farm and groups them equally into baskets
- A class measures the dimensions of a basketball court for a geometry activity
- A table shows attendance at the Indiana State Fair over four days

**Grades 5–6:**
- Indiana corn and soybean yield data used to calculate mean, median, and range
- A proportional relationship between laps and distance at the Indy 500
- A student calculates the volume of a limestone block from an Indiana quarry

**Grades 7–10:**
- Scatterplot of Indianapolis population data with line of best fit and projection
- Indy 500 fuel consumption rates compared across different race conditions
- Indiana soybean production data analyzed for proportional and linear relationships

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] Indiana Academic Standard code is accurate and grade-appropriate
- [ ] Calculator policy followed for the target grade (no calculator Gr 3–5)
- [ ] Real-world context is relevant to Indiana students
- [ ] MC distractors represent actual student errors (not trivially wrong)
- [ ] MS items have clear correct answers with no ambiguity
- [ ] EQ items have a single correct numeric value or acceptable equivalents defined
- [ ] CR rubric matches the point value (0–2 or 0–4)
- [ ] DOK level matches the cognitive demand of the problem
- [ ] All computations verified before item is finalized
- [ ] Answer choices are in logical order (ascending/descending for numeric)

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Calculator use at Grade 3–5 | ILEARN Gr 3–5 has no calculator | Design problems solvable by hand |
| CR scored on wrong scale | Short CR = 0–2; Extended CR = 0–4 | Match rubric to CR type |
| MS with ambiguous options | All-or-nothing scoring means options must be clearly true or false | Verify each option is unambiguously correct or incorrect |
| EQ with rounding ambiguity | Student may enter equivalent values | Specify rounding requirements; accept equivalent forms |
| DOK 1 items that only require recall | ILEARN aims for mostly DOK 2–3 | Embed problems in real-world context |
| Using CCSS codes instead of Indiana codes | Indiana uses its own Academic Standards | Reference Indiana Academic Standard codes exclusively |

## 12. Prompt Patterns

### Pattern 1: Real-World Multi-Step (MC or CR, DOK 2–3)
> "[Indiana context — Indy 500, corn production, Indianapolis]. [Specific mathematical question]. What is [quantity]? Show your work."

### Pattern 2: Representation Connection (MC or MS, DOK 2)
> "A student created a [table / graph / equation] to represent [relationship]. Which [other representation / statement] represents the SAME relationship? / Select ALL true statements."

### Pattern 3: Data Interpretation (MC or CR, DOK 2–3)
> "The [table / graph / scatterplot] shows [Indiana data context]. Based on the data, [what is the rate of change / which conclusion / what prediction] is BEST supported?"

### Pattern 4: Geometry Application (MC or EQ, DOK 2)
> "[Indiana context — quarry, building, court]. What is the [area / volume / perimeter / surface area] of [figure]?"

### Pattern 5: Proportional Reasoning (MC or EQ, DOK 2)
> "[Indiana context — farming, distance, recipe]. If [proportional setup], then what is [unknown quantity]?"

### Pattern 6: Extended Analysis (CR 0–4, DOK 3)
> "The [data set] shows [Indiana context]. Part A: [Calculate]. Part B: [Explain]. Part C: [Evaluate or extend the model]."
