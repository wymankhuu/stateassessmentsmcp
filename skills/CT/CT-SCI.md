### Achievement Level Descriptors (ALDs)

| Level | Label | Description |
|---|---|---|
| 4 | **Exceeds Standard** | Student demonstrates sophisticated, integrated understanding of disciplinary core ideas, science and engineering practices, and crosscutting concepts; applies three-dimensional reasoning to novel phenomena |
| 3 | **Meets Standard** | Student demonstrates adequate understanding of three-dimensional science; can use practices and crosscutting concepts to explain grade-level phenomena and solve problems |
| 2 | **Approaching Standard** | Student demonstrates partial understanding; can identify relevant science ideas but struggles to integrate practices and crosscutting concepts in explanations |
| 1 | **Below Standard** | Student demonstrates minimal understanding of disciplinary core ideas; limited ability to engage in science practices or apply crosscutting concepts |

> **Cut scores** are set by the Connecticut State Board of Education. For item-writing purposes, focus on ALDs 3 and 4 as the target proficiency range.

## 2. Standards Framework

> **Reference:** See `_shared/ngss_framework.md` for full NGSS architecture including Disciplinary Core Ideas (DCIs), Science and Engineering Practices (SEPs), and Crosscutting Concepts (CCCs). This section highlights the key performance expectations most heavily assessed on the Connecticut NGSS assessment.

### Three-Dimensional Assessment Design

NGSS assessment items are designed to integrate all three dimensions simultaneously:

| Dimension | Description | Role in Assessment |
|---|---|---|
| **Disciplinary Core Ideas (DCIs)** | The key science content organized into Physical Science (PS), Life Science (LS), Earth and Space Science (ESS), and Engineering (ETS) | Provides the content knowledge assessed |
| **Science and Engineering Practices (SEPs)** | The behaviors scientists and engineers use to investigate and build models | Provides the cognitive action students perform |
| **Crosscutting Concepts (CCCs)** | Themes that bridge disciplinary boundaries (patterns, cause and effect, systems, etc.) | Provides the lens through which students reason |

## 4. Claims & Blueprint

### Assessment Targets

Connecticut NGSS science assessment is organized around the three dimensions rather than traditional claims. For blueprint purposes, the assessment uses the following reporting categories:

| Reporting Category | Description | Approximate Weight | Dimensions Assessed |
|---|---|---|---|
| **Physical Science** | Properties of matter; forces and motion; energy; waves | **25–30%** | PS DCIs + SEPs + CCCs |
| **Life Science** | Ecosystems; heredity; evolution; organisms | **25–30%** | LS DCIs + SEPs + CCCs |
| **Earth and Space Science** | Earth's systems; Earth's place in universe; human activity | **25–30%** | ESS DCIs + SEPs + CCCs |
| **Engineering Design** | Defining problems; designing solutions; optimizing | **10–15%** | ETS DCIs + SEPs + CCCs |

### Science and Engineering Practices (SEPs) — Assessment Emphasis

| SEP | Description | Item Frequency |
|---|---|---|
| **SEP 1** — Asking Questions / Defining Problems | Formulate testable questions; define engineering design constraints | Moderate |
| **SEP 2** — Developing and Using Models | Create, use, and revise models to explain phenomena | High |
| **SEP 3** — Planning and Carrying Out Investigations | Design investigations; identify variables | Moderate |
| **SEP 4** — Analyzing and Interpreting Data | Use data tables, graphs, and statistical reasoning | High |
| **SEP 5** — Using Mathematics and Computational Thinking | Apply mathematical concepts to science problems | Moderate |
| **SEP 6** — Constructing Explanations / Designing Solutions | Build evidence-based explanations; propose solutions | High |
| **SEP 7** — Engaging in Argument from Evidence | Support claims with evidence; evaluate competing arguments | Moderate |
| **SEP 8** — Obtaining, Evaluating, and Communicating Information | Read and synthesize scientific information | Moderate |

### Crosscutting Concepts (CCCs) — Assessment Emphasis

| CCC | Description | Item Frequency |
|---|---|---|
| **CCC 1** — Patterns | Observed patterns guide classification, prediction | High |
| **CCC 2** — Cause and Effect | Mechanism and prediction; testing causal claims | High |
| **CCC 3** — Scale, Proportion, and Quantity | Relative scales; proportional relationships | Moderate |
| **CCC 4** — Systems and System Models | Defining boundaries; inputs and outputs | Moderate |
| **CCC 5** — Energy and Matter | Flows, cycles, and conservation | High |
| **CCC 6** — Structure and Function | Shape determines function | Moderate |
| **CCC 7** — Stability and Change | Equilibrium; rates of change; feedback | Moderate |

### DOK Distribution

| DOK Level | Approximate Distribution | Typical Item Types |
|---|---|---|
| DOK 1 | ~10% | SR — recall definitions, identify structures |
| DOK 2 | ~45% | SR, MS — apply concepts, interpret data, classify |
| DOK 3 | ~40% | MS, CR — analyze phenomena, construct explanations, evaluate evidence |
| DOK 4 | ~5% | CR — extended investigation, multi-step modeling |

## 5. Item Types & Formats

### SR — Selected Response (1 point)

Standard four-option multiple-choice. Student selects one best answer. Items are anchored to a phenomenon or data set.

```
+-----------------------------------------------------------------+
|  PHENOMENON / STIMULUS:                                          |
|  [Description of a natural phenomenon, data table, diagram,     |
|   or experimental setup — 2–5 sentences or a labeled figure]    |
|                                                                  |
|  Question stem integrating a SEP and CCC with a DCI.            |
|                                                                  |
|  O  A. [Plausible distractor — common misconception]             |
|  O  B. [Correct answer — supported by evidence and reasoning]    |
|  O  C. [Plausible distractor — partially correct reasoning]      |
|  O  D. [Plausible distractor — incomplete understanding]         |
+-----------------------------------------------------------------+
Points: 1 (correct) / 0 (incorrect)
```

**Construction Rules:**
- Item must be anchored to an observable phenomenon or data set
- Stem must require application of at least one SEP (not just recall)
- All four options must be plausible; distractors should reflect documented student misconceptions
- Avoid "All of the above" / "None of the above"
- Correct answer must be defensible through three-dimensional reasoning

---

### MS — Multi-Select (1 point)

Student selects ALL correct answers from a set of typically five or six options. Full credit only when all correct options are selected and no incorrect options are selected.

```
+-----------------------------------------------------------------+
|  PHENOMENON / STIMULUS:                                          |
|  [Description, data, or diagram]                                 |
|                                                                  |
|  Question stem — "Select ALL that apply" or                      |
|  "Select the TWO [observations / claims / explanations] that..." |
|                                                                  |
|  [ ]  A. [Option]                                                |
|  [ ]  B. [Option — CORRECT]                                      |
|  [ ]  C. [Option]                                                |
|  [ ]  D. [Option — CORRECT]                                      |
|  [ ]  E. [Option]                                                |
|  [ ]  F. [Option]                                                |
+-----------------------------------------------------------------+
Points: 1 (all correct selected, none incorrect) / 0 (any other)
```

**Construction Rules:**
- Specify the number of correct answers in the stem when count is fixed ("Select the TWO...")
- When count is unspecified, use "Select ALL that apply"
- Typically 2–3 correct answers from a field of 5–6
- Each option should represent a distinct scientific claim or observation
- Distractors should reflect common student misconceptions about the phenomenon

---

### CR — Constructed Response (0–3 points)

Student writes a multi-sentence explanation, constructs an argument from evidence, or describes a model. Scored holistically on a 0–3 rubric.

```
+-----------------------------------------------------------------+
|  PHENOMENON / STIMULUS:                                          |
|  [Extended description of phenomenon — may include data table,   |
|   graph, diagram, experimental results, or scenario]             |
|                                                                  |
|  PROMPT:                                                         |
|  [Directive requiring students to construct an explanation,       |
|   develop a model, argue from evidence, or design a solution]    |
|                                                                  |
|  Be sure to:                                                     |
|    * [Specific guidance bullet 1 — e.g., "Identify the cause"]   |
|    * [Specific guidance bullet 2 — e.g., "Use data from the      |
|       table to support your explanation"]                         |
|    * [Specific guidance bullet 3 — e.g., "Describe what would    |
|       happen if..."]                                              |
|                                                                  |
|  +-----------------------------------------------------+        |
|  |                                                       |        |
|  |  [Student response area — text input]                 |        |
|  |                                                       |        |
|  +-----------------------------------------------------+        |
+-----------------------------------------------------------------+
Points: 0–3 (see rubric, Section 8)
```

**Construction Rules:**
- Must integrate all three NGSS dimensions (DCI + SEP + CCC)
- Prompt must reference a specific phenomenon or data set, not ask for generic definitions
- Include "Be sure to" guidance bullets (typically 2–3) to scaffold student response
- The phenomenon should be grade-appropriate and ideally connected to Connecticut contexts (Section 10)
- Response expectations: Grade 5 (3–5 sentences); Grade 8 (5–8 sentences); Grade 11 (6–10 sentences)

## 6. DOK / Cognitive Complexity

### DOK Level Descriptions for Science

| DOK | Label | Description | Example Tasks |
|---|---|---|---|
| **1** | Recall & Reproduction | Recall a scientific fact or definition; identify a structure from a diagram; recognize a pattern from a simple data display | *identify, define, recall, recognize, label, list, name* |
| **2** | Skills & Concepts | Classify organisms or materials; interpret a data table or graph; explain a cause-effect relationship; apply a science concept to a familiar context | *classify, interpret, explain, compare, organize, infer, predict, relate* |
| **3** | Strategic Thinking | Analyze experimental data to draw conclusions; construct an evidence-based explanation of a phenomenon; evaluate competing scientific claims; design an investigation | *analyze, construct, evaluate, justify, design, formulate, synthesize, argue* |
| **4** | Extended Thinking | Conduct multi-step investigations across multiple variables; synthesize information from multiple sources to build and revise a scientific model; evaluate complex real-world scenarios requiring integration of multiple DCIs | *synthesize, design [complex], evaluate [complex], connect, create, present* |

> DOK 4 appears primarily in CR items with extended phenomena, not in individual SR or MS items.

### DOK Distribution Targets for Item Generation

| Item Type | Target DOK | Rationale |
|---|---|---|
| SR — identify / recall | 1 | Simple recall of terms, structures, or classifications |
| SR — apply concept to phenomenon | 2 | Requires connecting concept to observable data |
| MS — evaluate multiple claims | 2–3 | Requires evaluating each option against evidence |
| CR — construct explanation | 3 | Requires integration of DCI, SEP, and CCC |
| CR — extended modeling | 3–4 | Requires multi-step reasoning and model construction |

## 7. Three-Dimensional Item Design

### Integrating the Three Dimensions

Every NGSS-aligned item must assess a student's ability to use a Science and Engineering Practice (SEP) to demonstrate understanding of a Disciplinary Core Idea (DCI), viewed through the lens of a Crosscutting Concept (CCC). The table below shows common three-dimensional combinations:

| Item Focus | SEP | CCC | DCI Example |
|---|---|---|---|
| Explain ecosystem energy flow | SEP 6 — Constructing Explanations | CCC 5 — Energy and Matter | LS2.B — Cycling of Matter and Energy |
| Analyze weather data patterns | SEP 4 — Analyzing Data | CCC 1 — Patterns | ESS2.D — Weather and Climate |
| Evaluate erosion prevention designs | SEP 7 — Argument from Evidence | CCC 7 — Stability and Change | ESS2.A — Earth Materials and Systems |
| Model chemical reaction | SEP 2 — Developing Models | CCC 5 — Energy and Matter | PS1.B — Chemical Reactions |
| Investigate inheritance patterns | SEP 3 — Planning Investigations | CCC 1 — Patterns | LS3.A — Inheritance of Traits |

### Phenomenon-Based Design Principles

| Principle | Guidance |
|---|---|
| **Anchoring phenomenon** | Every task set begins with an observable, engaging phenomenon that students must explain using three-dimensional reasoning |
| **Student sense-making** | Items should require students to figure out the phenomenon, not simply recall facts about it |
| **Multiple dimensions** | The phenomenon should naturally lend itself to at least one SEP and one CCC in addition to the target DCI |
| **Connecticut relevance** | Use Connecticut-specific phenomena when possible (see Section 10) to increase engagement and ecological validity |
| **Accessibility** | Phenomena should be described clearly enough that students without prior exposure can engage meaningfully |

### Model Types for Assessment

| Model Type | Description | Grade Band |
|---|---|---|
| **Diagrammatic** | Labeled diagrams showing relationships, flows, or structures | All grades |
| **Mathematical** | Equations, proportional relationships, quantitative predictions | Gr 8, 11 |
| **Conceptual** | Verbal or visual representations of cause-effect chains | All grades |
| **Computational** | Data-driven models; trend analysis; simulation interpretation | Gr 8, 11 |

## 8. Scoring Rubrics

### CR — Constructed Response (0–3 Points)

| Score | Descriptor |
|---|---|
| **3** | The response demonstrates thorough three-dimensional understanding. The student accurately applies the relevant DCI to explain the phenomenon, effectively uses the targeted SEP (e.g., constructs a complete explanation, develops a detailed model, argues convincingly from evidence), and explicitly connects reasoning to the relevant CCC. Scientific vocabulary is precise and used correctly. Evidence from the stimulus is cited accurately and integrated into the explanation. |
| **2** | The response demonstrates adequate three-dimensional understanding. The student applies the relevant DCI with minor inaccuracies, uses the targeted SEP with some effectiveness, and implicitly or partially connects to the relevant CCC. The explanation is mostly complete but may lack full elaboration or miss one component. Scientific vocabulary is generally appropriate. |
| **1** | The response demonstrates partial understanding. The student shows some knowledge of the DCI but may have significant misconceptions. The targeted SEP is used minimally or incompletely. The connection to the CCC is absent or incorrect. The explanation addresses the phenomenon but is substantially incomplete or contains notable errors. |
| **0** | The response is off topic, demonstrates no understanding of the science concepts, restates the prompt without analysis, is too brief to evaluate, or is left blank. |

**CR Scoring Notes:**
- Score based on scientific accuracy and quality of reasoning, not writing mechanics
- A response with minor spelling or grammar errors but sound scientific reasoning should not be penalized
- Students must reference the specific phenomenon or data in the stimulus; generic textbook-style answers should not receive full credit

## 10. Contextualization

### Connecticut-Specific Science Topic Bank

Item writers should anchor phenomena and scenarios in authentic Connecticut contexts when possible. This increases ecological validity and engagement for Connecticut students while providing rich, three-dimensional assessment opportunities.

#### Long Island Sound Ecology

| Topic | Scientific Applications |
|---|---|
| **Long Island Sound food webs** | Energy flow through marine ecosystems; trophic levels; producer-consumer relationships; impact of nitrogen loading on algal blooms; Sound-wide water quality monitoring data |
| **Osprey population recovery** | Population dynamics; predator-prey relationships; bioaccumulation of pesticides (DDT history); habitat restoration success indicators; data analysis with population counts over decades |
| **Harbor seal migration** | Animal behavior; seasonal patterns; thermoregulation; population survey data; cause and effect of habitat disturbance |
| **Shellfish restoration** | Ecosystem services; water filtration by oysters; Norwalk oyster beds; nutrient cycling; human impact and conservation efforts |
| **Invasive species in the Sound** | Competition; niche displacement; Asian shore crab populations; data on biodiversity changes; ecosystem stability |

#### Connecticut River Watershed

| Topic | Scientific Applications |
|---|---|

| **Floodplain ecology** | Nutrient deposition; soil formation; plant community succession; periodic disturbance and ecosystem resilience; Connecticut River Valley agriculture |
| **Watershed hydrology** | Water cycle; surface runoff; groundwater recharge; precipitation data analysis; modeling water flow through the 410-mile river system |

#### Connecticut Weather

| Topic | Scientific Applications |
|---|---|
| **Nor'easters and winter storms** | Atmospheric systems; energy transfer; air mass interactions; historical storm data for Connecticut; cause and effect of geographic position on weather severity |
| **Microclimate variation** | Temperature and precipitation differences between CT coastal and inland areas; data analysis comparing weather stations; cause and effect of proximity to Long Island Sound |
| **Seasonal temperature patterns** | Earth's axial tilt and solar angle; energy absorption; graphing annual temperature data; comparing CT to other latitudes; patterns in climate data |
| **Severe weather prediction** | Weather modeling; atmospheric variables; interpreting weather maps; evaluating forecast accuracy; engineering weather warning systems |

### English Learner (EL) Considerations

| Consideration | Guidance |
|---|---|
| **Scientific vocabulary** | Pre-teach or define Tier 3 science vocabulary in sidebars; avoid conflating everyday and scientific meanings of terms (e.g., "energy," "force," "theory") |
| **Sentence structure** | Use clear, direct sentences in stimulus descriptions and item stems; avoid unnecessarily complex syntax |
| **Visual supports** | Include diagrams, data tables, and labeled figures to reduce linguistic load; all visuals must include alt text |
| **Bilingual glossaries** | Designated support; science terms in Spanish, Portuguese, and other home languages |
| **Cultural familiarity** | Include phenomena that connect to students' lived experiences; avoid assuming prior outdoor recreation or field experience |

## 11. Quality Checklist

Use this checklist before finalizing any generated item or item set.

### Three-Dimensional Alignment

- [ ] Item is tagged to one primary performance expectation (e.g., MS-LS2-1)
- [ ] Item integrates at least one SEP (science practice) beyond simple recall
- [ ] Item connects to at least one CCC (crosscutting concept)
- [ ] The DCI assessed matches the target grade band
- [ ] The three dimensions work together coherently; none feels forced or tacked on

### Phenomenon / Stimulus

- [ ] Item is anchored to an observable phenomenon or data set (not a generic definition prompt)
- [ ] Phenomenon is engaging, age-appropriate, and culturally inclusive
- [ ] Data in tables or graphs is realistic and internally consistent
- [ ] Diagrams are clearly labeled, drawn to reasonable scale, and described in alt text
- [ ] Connecticut context is used when appropriate (Section 10)

### Item Quality (All Types)

- [ ] Stem requires application of a science practice, not just recall
- [ ] All options (SR/MS) are plausible and reflect documented student misconceptions
- [ ] Correct answer is unambiguously supported by three-dimensional reasoning
- [ ] No "All of the above" / "None of the above" options
- [ ] DOK level is consistent with the cognitive demand of the task
- [ ] Item can be answered from the provided stimulus; no external knowledge required beyond grade-level DCI

### CR-Specific Checks

- [ ] Prompt requires three-dimensional reasoning (DCI + SEP + CCC)
- [ ] "Be sure to" bullets provide clear scaffolding without giving away the answer
- [ ] Scoring rubric is included with the item
- [ ] Rubric distinguishes between levels of three-dimensional understanding
- [ ] Response length expectations are appropriate for the grade

### EL and Accessibility

- [ ] Scientific vocabulary is appropriate for the grade; specialized terms are defined
- [ ] Visual supports accompany text-heavy stimuli
- [ ] Item does not require cultural knowledge that disadvantages EL students
- [ ] Text-to-speech compatible (no items invalidated by audio)

## 12. Prompt Patterns

The following patterns map common user requests to generation strategies for the AI.

---

### Pattern 1: "Generate a science item for Grade [X]"

**Interpretation:** Default to an SR item (1 point) at DOK 2, anchored to a phenomenon. Select a DCI appropriate to the grade level. Use a Connecticut context from Section 10.

**Generation Recipe:**
1. Select a grade-appropriate performance expectation
2. Choose a Connecticut phenomenon from Section 10
3. Identify the target SEP and CCC
4. Generate SR using Template 1
5. Ensure all four options reflect distinct scientific reasoning paths
6. Tag: state=CT, subject=SCI, grade=[X], pe=[PE], sep=[SEP], ccc=[CCC], dok=2

---

### Pattern 2: "Generate a constructed response science item for Grade [X]"

**Interpretation:** Generate a CR item (0–3 points) at DOK 3, requiring three-dimensional reasoning. Use Template 3.

**Generation Recipe:**
1. Select a grade-appropriate performance expectation
2. Choose an engaging phenomenon (Connecticut context preferred)
3. Write an extended stimulus (4–8 sentences with data or diagram description)
4. Write the prompt with 2–3 "Be sure to" scaffolding bullets
5. Include the 0–3 scoring rubric
6. Tag: state=CT, subject=SCI, grade=[X], pe=[PE], sep=[SEP], ccc=[CCC], dok=3

---

### Pattern 3: "Generate an engineering design item"

**Interpretation:** Generate a CR item targeting ETS performance expectations. Use Template 4.

**Generation Recipe:**
1. Select a grade-appropriate ETS performance expectation
2. Define a design problem with clear criteria and constraints (Connecticut context preferred)
3. Write the stimulus describing the problem and any relevant data
4. Write the prompt requiring solution design, evaluation, or optimization
5. Include the 0–3 scoring rubric
6. Tag: state=CT, subject=SCI, grade=[X], pe=[ETS PE], sep=6 or 7, ccc=[CCC], dok=3-4

---

### Pattern 4: "Generate a complete science task set for Grade [X]"

**Interpretation:** Generate a phenomenon-based task set with 3–5 items (mix of SR, MS, CR) all anchored to a single phenomenon.

**Generation Recipe:**
1. Select a rich, multi-faceted phenomenon (Connecticut context strongly preferred)
2. Identify 2–3 performance expectations that connect to the phenomenon
3. Generate items in this sequence:
   - 1–2 SR items (DOK 1–2) — entry-level reasoning about the phenomenon
   - 1 MS item (DOK 2–3) — evaluate multiple claims or data patterns
   - 1 CR item (DOK 3) — construct explanation or argue from evidence
4. Ensure the task set integrates multiple SEPs and CCCs
5. Tag each item with PE, SEP, CCC, DOK
6. Include scoring rubric for the CR item

---

### Pattern 5: "Generate a data analysis science item"

**Interpretation:** Generate an MS or SR item targeting SEP 4 (Analyzing and Interpreting Data) at DOK 2–3. Include a data table or graph in the stimulus.

**Generation Recipe:**
1. Select a grade-appropriate DCI with quantitative data opportunities
2. Create a realistic data set (table or graph description) using Connecticut data when possible
3. Use Template 2 for MS or Template 1 for SR
4. Ensure the stem requires interpretation beyond simple reading of the data
5. Tag: state=CT, subject=SCI, grade=[X], pe=[PE], sep=4, ccc=[CCC], dok=2-3
