## 1. Overview

| Field | Detail |
|---|---|
| **Assessment Name** | Connecticut Smarter Balanced Mathematics / CT SAT School Day — Mathematics |
| **Consortium** | Smarter Balanced Assessment Consortium (SBAC) |
| **Vendor** | Smarter Balanced / College Board (Grade 11 via SAT School Day) |
| **Grades Tested** | 3, 4, 5, 6, 7, 8, 11 |
| **Testing Window** | March – May (operational window; schools schedule within this range) |
| **Delivery** | Computer-adaptive (CAT) for Part 1 (non-calculator + calculator); fixed-form Performance Task for Part 2 |
| **Standards** | Common Core State Standards for Mathematics (CCSS-M); Connecticut Core Standards |
| **Score Scale** | 2000–3000 scale score (varies by grade); SAT scale for Grade 11 |
| **Reporting** | Individual Student Report (ISR); School, District, State aggregate reports via Connecticut EdSight |

### Achievement Level Descriptors (ALDs)

| Level | Label | Description |
|---|---|---|
| 4 | **Standard Exceeded** | Student demonstrates sophisticated understanding of mathematical concepts and procedures; applies mathematics fluently in novel situations; constructs valid mathematical arguments; evaluates and critiques the reasoning of others |
| 3 | **Standard Met** | Student demonstrates adequate understanding of grade-level concepts and procedures; applies mathematics to real-world and mathematical problems with reasonable accuracy; can explain mathematical reasoning |
| 2 | **Standard Nearly Met** | Student demonstrates partial understanding; can apply procedures in familiar contexts but struggles with novel problems; mathematical explanations are incomplete or sometimes inaccurate |
| 1 | **Standard Not Met** | Student demonstrates minimal understanding; makes frequent errors in procedures; cannot explain mathematical reasoning; significant gaps in prerequisite skills |

> **Cut scores** are set by the Smarter Balanced Assessment Consortium and adopted by the Connecticut State Board of Education. For item-writing purposes, target ALDs 3 and 4 as the proficiency range.

## 2. Standards Framework

> **Reference:** See `_shared/ccss_math_framework.md` for full CCSS-M standards and grade-by-grade progressions. This section highlights the key domains and standards most heavily tested on the Connecticut Smarter Balanced assessment.

### Grades 3–5: Key Content Domains

| Domain | Gr 3 Focus | Gr 4 Focus | Gr 5 Focus |
|---|---|---|---|
| **OA — Operations & Algebraic Thinking** | Multiply/divide within 100; two-step word problems | Multi-step word problems; factor pairs; patterns | Write and interpret numerical expressions; analyze patterns |
| **NBT — Number & Operations Base Ten** | Place value to 1,000; fluently add/subtract within 1,000 | Multi-digit arithmetic; place value to 1,000,000 | Decimal operations; powers of 10 |
| **NF — Number & Operations Fractions** | Unit fractions; fractions on number line | Equivalent fractions; add/subtract fractions; multiply fraction by whole | All fraction operations; relate fractions to decimals |
| **MD — Measurement & Data** | Area; perimeter; time; mass; volume | Measurement conversion; angle measurement | Volume; measurement conversion |
| **G — Geometry** | Properties of shapes; area and perimeter | Lines, angles, symmetry | Coordinate plane; classify 2D figures |

### Grades 6–8: Key Content Domains

| Domain | Gr 6 Focus | Gr 7 Focus | Gr 8 Focus |
|---|---|---|---|
| **RP — Ratios & Proportional Relationships** | Ratio concepts; unit rates | Proportional relationships; percent problems | (integrated into functions and geometry) |
| **NS — The Number System** | Divide fractions; rational numbers; coordinate plane | Rational number operations; absolute value | Irrational numbers; rational approximations |
| **EE — Expressions & Equations** | Evaluate and write expressions; one-step equations | Two-step equations and inequalities; equivalent expressions | Linear equations; systems of equations; exponents |
| **G — Geometry** | Area, surface area, volume | Scale drawings; cross-sections; angle relationships | Pythagorean theorem; transformations; volume of cylinders/cones/spheres |
| **SP — Statistics & Probability** | Statistical variability; distributions | Probability; sampling; comparing populations | Scatter plots; linear association; two-way tables |
| **F — Functions** | — | — | Define and compare functions; linear functions |

### Grade 11: Key Content Domains

| Domain | Focus |
|---|---|
| **Algebra** | Interpret structure of expressions; create equations; reasoning with equations and inequalities; polynomial and rational expressions |
| **Functions** | Interpret functions (domain, range, graphs); build functions; linear, quadratic, and exponential models; trigonometric functions (intro) |
| **Number & Quantity** | Extend properties of exponents to rational exponents; reason quantitatively with units |
| **Geometry** | Prove geometric theorems; apply trigonometry; geometric measurement (modeling with geometry) |
| **Statistics & Probability** | Interpret data; make inferences; use probability to evaluate outcomes of decisions |

## 5. Item Types & Formats

### SR — Selected Response (1 point)

Standard four-option multiple-choice. Student selects one best answer.

```
+-----------------------------------------------------------------+
|  [Stimulus: problem context, diagram, table, or equation]        |
|                                                                  |
|  Question stem targeting a specific standard and claim.          |
|                                                                  |
|  O  A. [Numerical / expression answer — plausible distractor]    |
|  O  B. [Numerical / expression answer — common error]            |
|  O  C. [Numerical / expression answer — CORRECT]                 |
|  O  D. [Numerical / expression answer — off-track distractor]    |
+-----------------------------------------------------------------+
Points: 1 (correct) / 0 (incorrect)
```

**Construction Rules:**
- Distractors must reflect real student errors (e.g., computational errors, conceptual mistakes, operation errors)
- Numerical answers should not reveal the correct answer through magnitude ordering
- Avoid answer options that are obviously not in the ballpark
- Diagrams and tables must be clearly labeled and drawn to reasonable scale

---

### MS — Multi-Select (1 point)

Student selects ALL correct answers from a set of five or six options. Full credit only when all correct options are selected and no incorrect options are selected.

```
+-----------------------------------------------------------------+
|  [Problem context or mathematical statement]                     |
|                                                                  |
|  Select the TWO [equations / values / expressions] that...      |
|                                                                  |
|  [ ]  A. [Option]                                                |
|  [ ]  B. [Option — CORRECT]                                      |
|  [ ]  C. [Option]                                                |
|  [ ]  D. [Option — CORRECT]                                      |
|  [ ]  E. [Option]                                                |
|  [ ]  F. [Option]                                                |
+-----------------------------------------------------------------+
Points: 1 (all correct, none incorrect) / 0 (any error)
```

**Construction Rules:**
- Specify the count in the stem when it is fixed ("Select the TWO...")
- Use "Select ALL that apply" when count is variable
- Typically 2–3 correct answers from 5–6 options
- Common use cases: identify all equivalent fractions, select all true equations, identify all figures with a given property

---

### EQ — Equation / Numeric Entry (1 point)

Student types a number, expression, or short equation into a response box. No choices are provided.

```
+-----------------------------------------------------------------+
|  [Problem context: real-world scenario or pure math]             |
|                                                                  |
|  What is the value of [EXPRESSION / VARIABLE / QUANTITY]?       |
|                                                                  |
|  Enter your answer in the box.                                   |
|  +---------------+                                               |
|  |               |  [numeric / expression entry field]          |
|  +---------------+                                               |
|                                                                  |
|  [Unit label if applicable: "miles", "square feet", etc.]        |
+-----------------------------------------------------------------+
Points: 1 (exact correct value or equivalent expression) / 0
```

**Construction Rules:**
- Clearly state the expected form of the answer (whole number, decimal, fraction, simplified expression)
- Specify units in the item when applicable; include unit label adjacent to the entry box
- For fraction entries, provide the fraction entry tool (numerator/denominator boxes)
- Specify significant figures or rounding rules when relevant (e.g., "Round to the nearest tenth")

---

### TE — Technology-Enhanced (1 point, variable format)

A family of interactive item formats including number line placement, drag-and-drop matching, graphing/coordinate plane, and table completion.

#### TE: Number Line Placement
```
+-----------------------------------------------------------------+
|  Plot the point that represents [VALUE] on the number line.      |
|                                                                  |
|  <--+----+----+----+----+----+----+----+-->                      |
|     0   0.5   1   1.5   2   2.5   3   3.5   4                   |
|                                                                  |
|  [Student drags or clicks to place a dot on the number line]     |
+-----------------------------------------------------------------+
```

#### TE: Drag-and-Drop Matching
```
+-----------------------------------------------------------------+
|  Match each expression to its equivalent value.                  |
|                                                                  |
|  WORD BANK:  [3^2]   [sqrt(81)]   [2^3]   [4^2]                |
|                                                                  |
|  +----------+--------------+                                     |
|  |  Value   |  Expression  |                                     |
|  +----------+--------------+                                     |
|  |    8     |  [drop zone] |                                     |
|  |    9     |  [drop zone] |                                     |
|  |   16     |  [drop zone] |                                     |
|  +----------+--------------+                                     |
+-----------------------------------------------------------------+
Points: partial credit — 1 point per correctly matched pair
```

#### TE: Graphing / Coordinate Plane
```
+-----------------------------------------------------------------+
|  Graph the equation y = 2x + 1 on the coordinate plane below.   |
|                                                                  |
|  [Student clicks points or drags a line using two-point tool]    |
+-----------------------------------------------------------------+
Points: 1 (correct line or correct points)
```

---

### SCR — Short Constructed Response (0–2 points)

Student writes a brief explanation or solution in a text/scratchpad area. Scored holistically 0–2.

```
+-----------------------------------------------------------------+
|  [Problem context — multi-step real-world scenario]              |
|                                                                  |
|  [PART A — Computational or procedural question]                 |
|  [PART B — "Explain how you know" or "Show your work"]           |
|                                                                  |
|  +-----------------------------------------------------+        |
|  |                                                       |        |
|  |  [Student response area — text input + scratchpad]    |        |
|  |                                                       |        |
|  +-----------------------------------------------------+        |
+-----------------------------------------------------------------+
Points: 0–2 (see rubric, Section 8)
```

**Construction Rules:**
- Prompt must clearly ask for both an answer AND an explanation/justification
- Identify the claim: SCR is most appropriate for Claim 3 (Communicating Reasoning) or Claim 2 (Problem Solving)
- The problem context should be accessible but require non-trivial mathematical reasoning

---

### PT-ER — Performance Task Extended Response (0–6 points, multi-part)

The PT Extended Response presents a complex real-world scenario with 3–5 interdependent sub-parts constituting a full mathematical modeling experience.

```
+-----------------------------------------------------------------+
|  PERFORMANCE TASK — EXTENDED RESPONSE                            |
|                                                                  |
|  SCENARIO:                                                       |
|  [3–5 sentence real-world context establishing the situation]    |
|  [Data tables, diagrams, or charts may be provided here]         |
|                                                                  |
|  Part A: [Introductory computation or setup question]            |
|  [Student response area]                                         |
|                                                                  |
|  Part B: [Intermediate reasoning or application question]        |
|  [Student response area]                                         |
|                                                                  |
|  Part C: [Complex extension — explain, justify, model, or        |
|            evaluate a decision based on mathematical results]    |
|  [Student response area]                                         |
+-----------------------------------------------------------------+
Points: 0–2 per part x 3 parts = 0–6 total
```

## 6. DOK / Cognitive Complexity

### DOK Level Descriptions for Mathematics

| DOK | Label | Description | Example Tasks |
|---|---|---|---|
| **1** | Recall & Reproduction | Recall a fact; perform a routine, single-step procedure; identify a property; solve a one-step equation; read a value from a graph | *calculate, identify, recall, use, recognize, list, name, measure* |
| **2** | Skills & Concepts | Solve a multi-step problem using a known procedure; classify or organize information; make inferences from data; apply a concept in a new but straightforward context | *classify, organize, estimate, compare, interpret, solve [multi-step], graph, apply* |
| **3** | Strategic Thinking | Solve non-routine problems requiring planning; justify or prove a mathematical claim; analyze errors in reasoning; design a mathematical model | *justify, prove, analyze, evaluate, formulate, critique, explain reasoning, construct* |
| **4** | Extended Thinking | Conduct multi-stage investigations; synthesize mathematical ideas across domains; design and evaluate complex models | *synthesize, design, evaluate [complex], connect, present, create* |

> DOK 4 appears primarily in PT Extended Response Part C items, not in individual CAT items.

### DOK Distribution Targets for Item Generation

| Item Type | Target DOK | Rationale |
|---|---|---|
| SR — single computation | 1 | Routine procedure, one step |
| SR — two-step word problem | 2 | Application; concept + computation |
| MS — identify equivalent forms | 1–2 | Depends on conceptual demand |
| EQ — numeric entry | 1–2 | Usually procedural; contextual use raises to DOK 2 |
| TE — graphing | 2 | Requires connecting representations |
| SCR — explain reasoning | 3 | Justification required; non-routine |
| PT-ER Part A | 2 | Setup computation within context |
| PT-ER Part B | 2–3 | Application or partial modeling |
| PT-ER Part C | 3–4 | Full modeling, justify, evaluate |

## 7. Mathematical Practices

The Standards for Mathematical Practice (SMP) describe the mathematical habits of mind that proficient students develop. SBAC items are designed to elicit these practices, particularly within the Claims framework.

### The 8 Standards for Mathematical Practice

| SMP | Title | Description | Primary Claim(s) |
|---|---|---|---|
| **SMP 1** | Make sense of problems and persevere in solving them | Students understand what a problem is asking, plan a pathway, monitor progress, and adjust strategy | Claims 2, 4 |
| **SMP 2** | Reason abstractly and quantitatively | Students decontextualize (represent symbolically) and recontextualize (interpret symbols in context); attend to meaning of quantities and units | Claims 1, 3 |
| **SMP 3** | Construct viable arguments and critique the reasoning of others | Students justify conclusions using mathematical reasoning; identify flawed arguments and explain the flaw | Claim 3 |
| **SMP 4** | Model with mathematics | Students use mathematics to describe real-world situations; identify important quantities, map relationships | Claim 4 |
| **SMP 5** | Use appropriate tools strategically | Students choose and use tools — calculators, rulers, graphs, spreadsheets — knowing their limitations | Claims 1, 2 |
| **SMP 6** | Attend to precision | Students use precise language and symbols; specify units; calculate accurately and efficiently | Claim 1 |
| **SMP 7** | Look for and make use of structure | Students see patterns and structure in mathematical objects; recognize equivalent forms | Claim 1 |
| **SMP 8** | Look for and express regularity in repeated reasoning | Students notice repeated calculations and general methods; articulate general rules | Claims 1, 3 |

### SMP — Claim Alignment Matrix

| Claim | Primary SMPs | Secondary SMPs |
|---|---|---|
| Claim 1 — Concepts & Procedures | SMP 6, 7, 8 | SMP 2, 5 |
| Claim 2 — Problem Solving | SMP 1, 5 | SMP 2, 4, 6 |
| Claim 3 — Communicating Reasoning | SMP 3, 6 | SMP 1, 2, 7 |
| Claim 4 — Modeling & Data Analysis | SMP 4, 1 | SMP 2, 3, 5, 6 |

## 8. Scoring Rubrics

### SCR — Short Constructed Response (0–2 Points)

| Score | Descriptor |
|---|---|
| **2** | The response demonstrates a thorough understanding of the mathematical concepts and procedures required by the task. The student provides a correct solution with a clear, accurate explanation or justification. Work shown is logical and complete. Minor arithmetic errors do not affect the score if reasoning is sound. |
| **1** | The response demonstrates a partial understanding. The student provides a partially correct solution or a correct solution with an incomplete or unclear explanation. The student may have made a computational error that led to an incorrect answer, but the mathematical reasoning is otherwise sound. OR the student provides the correct answer with no explanation. |
| **0** | The response is incorrect, irrelevant, or demonstrates no mathematical understanding. Responses that show only memorized formulas without application, or that copy the problem without work, receive a score of 0. |

**SCR Scoring Notes:**
- Score based on the mathematical soundness of the reasoning, not writing quality
- Correct answer alone (without explanation when explanation is required) earns at most 1 point
- Correct process with arithmetic error earns 1 point if the method is clearly shown and correct

---

### PT-ER — Performance Task Extended Response (0–6 Points)

#### Part A Rubric (0–2 points)

| Score | Descriptor |
|---|---|
| **2** | The response correctly sets up and solves the introductory problem. All calculations are correct and clearly shown. Units are correctly identified. |
| **1** | The response demonstrates correct approach but contains a computational error, an incomplete solution, or a missing unit. The mathematical intent is clear. |
| **0** | The response is incorrect, missing, or demonstrates no understanding of the mathematical task. |

#### Part B Rubric (0–2 points)

| Score | Descriptor |
|---|---|
| **2** | The response correctly applies Part A results to solve the intermediate problem. Reasoning is clear; any comparison or interpretation is accurate. |
| **1** | The response shows partial understanding. The student may use an incorrect value from Part A but apply correct reasoning, OR arrive at the correct conclusion through partially correct work. |
| **0** | The response is incorrect, missing, or shows no mathematical understanding relative to Part B. |

#### Part C Rubric (0–2 points)

| Score | Descriptor |
|---|---|
| **2** | The response demonstrates sophisticated mathematical reasoning. The student accurately uses results to justify a decision, evaluate a model, or explain a pattern. The explanation is clear and mathematically sound. |
| **1** | The response shows some correct reasoning or a partially valid justification. The student may identify the correct conclusion but provide insufficient support. |
| **0** | The response is incorrect, off-task, or provides only unsupported assertions. |

#### Error-Carried-Forward (ECF) Policy
When a student carries an incorrect value from Part A into Parts B and C, if their work is mathematically correct based on their Part A answer, award full credit for that part despite the earlier error. ECF applies only when the error is computational, not conceptual.

## 10. Contextualization

### Connecticut-Specific Mathematics Context Bank

Item writers should anchor scenarios in authentic Connecticut contexts to maximize student engagement and ecological validity.

#### Population & Demographics

| Topic | Mathematical Applications |
|---|---|
| **CT population data** | Large number operations; percent change; data displays; proportional reasoning; Connecticut's population of ~3.6 million; town-by-town comparisons |
| **Hartford metro area growth** | Percent increase/decrease; ratio; population density calculations; comparing urban vs. suburban statistics |
| **CT school enrollment data** | Ratios; proportional reasoning; data analysis; bar and circle graphs |
| **CT demographic diversity** | Percent composition; circle graphs; proportional reasoning |

#### Geography & Environment

| Topic | Mathematical Applications |
|---|---|
| **Long Island Sound measurements** | Area and perimeter; measurement conversion; proportional reasoning; the Sound is approximately 110 miles long and 21 miles at its widest; depth data for rate calculations |
| **CT highway distances** | Distance-rate-time problems; elapsed time; unit conversion; I-95 from Greenwich to Stonington (~110 miles); I-91 from New Haven to Hartford (~40 miles) |
| **Connecticut River data** | Length (410 miles total, ~58 miles in CT); flow rate; watershed area; volume calculations |
| **CT state park acreage** | Area; comparison; percent; fractions; Sleeping Giant (1,660 acres); Hammonasset Beach (920 acres) |

#### Industry & Economy

| Topic | Mathematical Applications |
|---|---|
| **Insurance industry statistics** | Large number operations; percent; rates; Hartford as "Insurance Capital" — premium data, employment figures, economic impact |
| **CT manufacturing output** | Rate calculations; unit rate; proportional relationships; aerospace industry data (Pratt & Whitney) |
| **Tourism revenue** | Multi-step problems; percent of state revenue; comparison across seasons; Mystic Seaport and Foxwoods visitor data |
| **CT agriculture** | Unit rates (bushels per acre); area; shade-grown tobacco economics; dairy production data |

#### Community and Everyday Contexts

| Topic | Mathematical Applications |
|---|---|
| **CT school budgets and per-pupil spending** | Large numbers; percent; ratios; proportional reasoning; CT ranks among highest per-pupil spending nationally |
| **New Haven pizza restaurant data** | Unit price; rates; ratios; multi-step computation; tip and tax calculations |
| **CT weather data** | Mean, median, mode; data analysis; temperature ranges; snowfall comparisons between coastal and inland areas |
| **CT sports statistics** | Mean, median; percent; data analysis; Yale athletics; CT Sun (WNBA); Hartford Yard Goats (minor league baseball) |

### Grade-Band Contextualization Notes

#### Grades 3–5 Contextualization

| Principle | Guidance |
|---|---|
| **Concreteness** | Contexts should involve tangible, observable quantities (objects counted, distances measured, areas calculated) |
| **Accessibility** | Avoid highly specialized vocabulary or cultural knowledge that disadvantages EL students |
| **Scale of numbers** | Match the number magnitude to grade-level standards |
| **Authenticity** | Connecticut school garden, local farmer's market, state park visit, school fundraiser — familiar community settings |

#### Grades 6–8 Contextualization

| Principle | Guidance |
|---|---|
| **Real data** | Use approximate real data (CT population ~3.6 million; Long Island Sound dimensions; highway distances) |
| **Multiple representations** | Include tables, graphs, or diagrams alongside word problem contexts |
| **Social relevance** | Topics like transportation, environmental data, and school funding resonate with middle-school students |

#### Grade 11 Contextualization

| Principle | Guidance |
|---|---|
| **Workforce readiness** | Career-relevant contexts (insurance, aerospace, healthcare, technology) |
| **Complex data** | Multi-variable data sets; scatter plots; regression; probability in real decision-making |
| **Equity lens** | Include data that represents Connecticut's diversity; avoid contexts that systematically advantage students from higher socioeconomic backgrounds |

### English Learner (EL) Considerations for Math

| Consideration | Guidance |
|---|---|
| **Mathematical vocabulary** | Pre-teach or define Tier 3 math vocabulary in a glossary; avoid confusing mathematical terms with everyday meanings |
| **Word problem language** | Use simple, direct sentence structure in word problem stems; avoid unnecessarily complex syntax |
| **Bilingual glossary** | EL designated support — mathematical terms in Spanish, Portuguese, and other home languages |
| **Diagrams and visuals** | Use clear, labeled diagrams to reduce linguistic load |

## 11. Quality Checklist

Use this checklist before finalizing any generated item or item set.

### Standards Alignment

- [ ] Item is tagged to one primary CCSS Math standard (e.g., 7.RP.A.2)
- [ ] Standard matches the claim and subclaim
- [ ] DOK level is consistent with the cognitive demand of the task
- [ ] Grade-level standard is appropriate for the intended grade band
- [ ] Item does not require knowledge of standards above or below grade level

### Calculator Policy

- [ ] Item is flagged as calculator or non-calculator consistent with grade-level policy (Section 3)
- [ ] Computational complexity is appropriate for the calculator policy
- [ ] Calculator-active items use numbers that would realistically benefit from a calculator

### Reference Sheet

- [ ] For Grades 8 and 11: item does not embed formulas that are on the reference sheet
- [ ] For Grades 3–7: item does not require formulas not taught at grade level
- [ ] Formula reference is given in the item when required for grades without a reference sheet

### Item Quality (All Types)

- [ ] Stem is a clear, unambiguous question or directive
- [ ] All numerical values in the problem are internally consistent
- [ ] Units are clearly specified and used correctly throughout
- [ ] No "trick" questions — the correct answer is not based on misreading a minor detail
- [ ] Diagrams are clearly labeled, drawn to reasonable scale, and described in alt text
- [ ] Answer options for SR are plausible and each represents a specific student error
- [ ] Correct answer is verified independently (calculation checked)
- [ ] Word problem context is realistic and meaningful

### SCR and PT-ER Checks

- [ ] Constructed-response prompt requires both a numerical answer AND explanation/justification
- [ ] Rubric is included with the item
- [ ] PT-ER parts are interdependent and logically sequenced (A -> B -> C)
- [ ] Error-carried-forward (ECF) policy is noted in the rubric
- [ ] Scoring guide anticipates common student errors

### EL and Accessibility

- [ ] Word problem language is clear and concise
- [ ] Mathematical vocabulary is appropriate for the grade; specialized terms are defined
- [ ] Diagrams are usable by students using zoom or screen magnification
- [ ] Item does not require cultural knowledge that disadvantages EL students

## 12. Prompt Patterns

The following patterns map common user requests to generation strategies for the AI.

---

### Pattern 1: "Generate a math problem for Grade [X]"

**Interpretation:** Default to an SR item (1 point) for Claim 1 (Concepts & Procedures) at DOK 2. Use a real-world context from Section 10.

**Generation Recipe:**
1. Identify the primary content domain for the grade
2. Select a Connecticut context from Section 10
3. Generate SR using Template 1, ensuring two mathematical steps
4. Construct four options where each distractor represents a distinct common error
5. Tag: state=CT, subject=MATH, grade=[X], claim=2, dok=2

---

### Pattern 2: "Generate a word problem that requires explanation"

**Interpretation:** Generate an SCR (0–2 points) for Claim 3 (Communicating Reasoning) at DOK 3. Use Template 2.

**Generation Recipe:**
1. Select a multi-step context appropriate for the grade (see Section 10)
2. Build Part A as the computational/procedural component (DOK 2)
3. Build Part B as the justification/explanation requirement (DOK 3)
4. Include a scoring guide (Section 8 rubric)
5. Tag: state=CT, subject=MATH, grade=[X], claim=3, dok=3

---

### Pattern 3: "Generate a Performance Task math problem for Grade [X]"

**Interpretation:** Generate a full PT-ER package using Template 3: scenario + data table + Parts A, B, C + scoring rubric.

**Generation Recipe:**
1. Choose a multi-faceted Connecticut context (insurance data, Long Island Sound, highway distances, population)
2. Create a realistic data set with 3–5 rows/entries
3. Scaffold Parts A (DOK 2), B (DOK 2–3), and C (DOK 3–4)
4. Include the 0–2 rubric for each part and ECF note
5. Tag: state=CT, subject=MATH, grade=[X], claim=4, dok=3-4

---

### Pattern 4: "Generate a set of math items covering multiple domains"

**Interpretation:** Generate a mini-assessment covering 3–4 different mathematical domains for the specified grade, with a mix of SR, MS, and EQ item types.

**Generation Recipe:**
1. Identify 3–4 primary domains for the grade
2. Generate one item per domain:
   - 1–2 SR items (DOK 1–2)
   - 1 MS item (DOK 2)
   - 1 EQ item (DOK 1–2)
3. Distribute calculator vs. non-calculator per policy (Section 3)
4. Include a standards and DOK summary table for the full set
5. Tag each item with claim, standard, DOK, and calculator policy
