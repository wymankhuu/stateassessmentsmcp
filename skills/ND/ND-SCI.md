## 1. Overview

| Field | Detail |
|---|---|

| **Administering Agency** | North Dakota Department of Public Instruction (NDDPI) |
| **Vendor** | North Dakota Department of Public Instruction (NDDPI) |
| **Grades Tested** | 5, 8, 11 |
| **Testing Window** | March – May |

| **Standards** | North Dakota Science Standards (aligned to NGSS) |
| **Score Scale** | Standard score (varies by grade); 4 performance levels |

> **CRITICAL NOTE:** NDSA Science is administered **only at Grades 5, 8, and 11**. Do not generate items for Grades 3, 4, 6, or 7. Grade 5 covers elementary science; Grade 8 covers middle school science; Grade 11 covers high school science.

### Performance Level Descriptors

| Level | Label | Description |
|---|---|---|
| 4 | **Standard Exceeded** | Student demonstrates thorough understanding of three-dimensional science; expertly integrates DCI, SEP, and CCC; constructs sophisticated, evidence-based explanations |
| 3 | **Standard Met** | Student demonstrates adequate understanding of three-dimensional science; appropriately applies practices and crosscutting concepts in grade-level contexts |
| 2 | **Standard Nearly Met** | Student demonstrates partial understanding; can recall disciplinary core ideas but struggles to integrate science practices or crosscutting concepts |
| 1 | **Standard Not Met** | Student demonstrates minimal science understanding; cannot apply practices or crosscutting concepts; limited to recall of isolated facts |

> **Item-writing target:** Level 3 (Standard Met) performance. Items should assess all three dimensions simultaneously.

## 3. Test Structure

NDSA Science is a single-session, computer-based test. There is **no lab practical component** — all items are stimulus-based (scenarios, data tables, diagrams, models, and graphs).

```
+------------------------------------------------------------------+
|              NDSA SCIENCE STRUCTURE (Grades 5, 8, 11)              |
+------------------------------------------------------------------+
|  SINGLE SESSION                                                    |
|  Computer-Based, Fixed-Form                                        |
|  Approximately 90-120 minutes                                      |
|                                                                    |
|  ~40 items per grade                                               |
|                                                                    |
|  Item types:                                                       |
|    - Selected Response (SR) -- ~60-65% of items                    |
|    - Multi-Select Response (MS) -- ~15-20% of items                |
|    - Constructed Response (CR) -- ~15-20% of items (3 pts each)   |
+------------------------------------------------------------------+
```

### Grade-Level Test Specifications

| Specification | Grade 5 | Grade 8 | Grade 11 |
|---|---|---|---|
| Approximate Item Count | ~38–42 | ~38–42 | ~38–42 |
| Selected Response | ~25–28 | ~25–28 | ~25–28 |
| Multi-Select | ~6–8 | ~6–8 | ~6–8 |
| Constructed Response | ~4–6 | ~4–6 | ~4–6 |
| Approx. Testing Time | 90–120 min | 90–120 min | 90–120 min |
| Calculator | No | No | No |
| Reference Sheet | No | No | No |

> **Three-Dimensional Requirement:** Every NDSA Science item must integrate at least one **Disciplinary Core Idea (DCI)**, one **Science and Engineering Practice (SEP)**, and one **Crosscutting Concept (CCC)**. Items that test only factual recall of DCIs are not aligned and should not be used.

## 5. Item Types & Formats

### Selected Response (SR)

```
+----------------------------------------------------------+
|  SELECTED RESPONSE -- 1 point                             |
|                                                            |
|  4 options (A, B, C, D)                                    |
|  Scenario, diagram, data table, or model stimulus          |
|  Must integrate DCI + SEP + CCC                            |
|  Machine scored                                            |
+----------------------------------------------------------+
```

**SR Example (Grade 8, DOK 2, MS-ESS2-2 — Earth's Surface):**

Scientists studying the North Dakota Badlands observe alternating layers of dark and light sedimentary rock in butte formations. The dark layers contain lignite coal, while the lighter layers contain sandstone and clay. Which statement BEST explains what the pattern of alternating layers reveals about the area's geological history?

A. The layers formed at the same time from different types of rock mixing together
B. Each layer represents a different time period when the environment and types of materials being deposited changed
C. Wind erosion created the alternating pattern by removing some types of rock faster than others
D. The darker layers are older because they are always found at the bottom

*Correct Answer: B*
*Alignment: MS-ESS2-2 | SEP: Constructing Explanations | CCC: Patterns | DOK 2*

---

**SR Example (Grade 5, DOK 2, 5-LS2-1 — Ecosystems):**

A student creates a model of a North Dakota prairie food web showing grass -> grasshoppers -> meadowlarks -> hawks. If a disease suddenly killed most of the grasshoppers, which prediction is BEST supported by the model?

A. The hawks would immediately leave the prairie
B. The grass population would likely increase because fewer grasshoppers are eating it
C. The meadowlarks would begin eating grass instead
D. The disease would also spread to the hawks

*Correct Answer: B*
*Alignment: 5-LS2-1 | SEP: Developing and Using Models | CCC: Cause and Effect | DOK 2*

---

### Multi-Select Response (MS)

```
+----------------------------------------------------------+
|  MULTI-SELECT RESPONSE -- 1 point                         |
|                                                            |
|  5-6 options; select exactly 2 or 3 correct answers        |
|  Full credit only; partial credit not awarded              |
|  Machine scored                                            |
+----------------------------------------------------------+
```

**MS Example (Grade 8, DOK 2, MS-ESS3-3 — Human Impact):**

Agricultural runoff from North Dakota farms enters the Missouri River watershed and eventually contributes to downstream water quality problems. Select the TWO strategies that would BEST help scientists monitor and reduce the environmental impact of this runoff.

A. Increase the speed of water flow in irrigation channels to flush chemicals away faster
B. Install sensors at multiple points along tributaries to measure nitrogen and phosphorus levels over time
C. Remove all native vegetation along riverbanks to prevent plants from absorbing the chemicals
D. Plant strips of native grass and shrubs between crop fields and waterways to filter runoff before it reaches the river
E. Apply additional fertilizer in early spring so that crops absorb all nutrients before runoff occurs

*Correct Answers: B, D*
*Alignment: MS-ESS3-3 | SEP: Planning Investigations / Constructing Explanations | CCC: Cause and Effect | DOK 2*

### Constructed Response (CR)

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE -- 0-3 points                       |
|                                                            |
|  Written explanation using evidence from stimulus          |
|  Stimulus always provided (data, diagram, scenario)        |
|  Must demonstrate three-dimensional reasoning              |
|  Human scored                                              |
+----------------------------------------------------------+
```

**CR Example (Grade 8, DOK 3, MS-LS2-2 — Ecosystem Interactions):**

*Stimulus: A data table showing changes in bison, prairie dog, and swift fox populations in the Little Missouri National Grassland over 25 years. Data shows that prairie dog towns expanded when bison grazing increased (bison create short-grass areas prairie dogs prefer), and swift fox populations increased alongside prairie dog expansion (swift foxes use abandoned prairie dog burrows for shelter).*

*"Using data from the table, construct an explanation for how bison grazing patterns in the North Dakota grasslands affect interactions among prairie dogs and swift foxes. Include evidence from the data and identify the cause-and-effect relationships."*

## 7. Three-Dimensional Design

Every NDSA Science item must reflect all three NGSS dimensions simultaneously.

### Three-Dimensions Alignment Guide

| Dimension | What It Is | Example in Items |
|---|---|---|
| **DCI** (What students know) | Disciplinary science content | Photosynthesis; atomic structure; erosion and deposition; natural selection; weather systems |
| **SEP** (What students do) | How scientists work | Analyze data from a table; construct an explanation using evidence; use a model to predict |
| **CCC** (Lens of thinking) | Cross-domain thinking tools | Cause and effect; patterns; energy and matter; structure and function; systems and system models |

### Sample Three-Dimensional Item Design (Grade 8)

```
+------------------------------------------------------------------+
|  3D ITEM STRUCTURE                                                 |
|                                                                    |
|  PHENOMENON: Petrified tree stumps found in Theodore Roosevelt     |
|  National Park indicate that the area was once a subtropical       |
|  swamp forest, but today the landscape is dry, eroded badlands    |
|  with sparse prairie grass                                         |
|  (Authentic North Dakota phenomenon grounds the item)              |
|                                                                    |
|  DCI: MS-ESS2 -- Earth's Systems; MS-ESS2-2 geoscience processes |
|  SEP: Constructing Explanations                                    |
|  CCC: Stability and Change                                         |
|                                                                    |
|  STIMULUS: Cross-section diagram of Theodore Roosevelt NP rock     |
|  layers with labeled fossils at different depths; timeline of      |
|  geological periods; data table of fossil types per layer          |
|                                                                    |
|  PROMPT: "Using data from the diagram and table, construct an     |
|  explanation for how the presence of petrified subtropical trees   |
|  in the North Dakota Badlands provides evidence that Earth's      |
|  surface and climate have changed significantly over time."        |
+------------------------------------------------------------------+
```

### Crosscutting Concepts by Grade Band

| CCC | Grade 5 Emphasis | Grade 8 Emphasis | Grade 11 Emphasis |
|---|---|---|---|
| Patterns | Rock layers; seasonal prairie changes | Badlands fossil patterns; periodic table | Inheritance patterns; population genetics |
| Cause and Effect | Food web changes; erosion | Chemical reactions; ecosystem dynamics; weather | Mutations -> traits; environmental -> evolution |
| Energy and Matter | Food chains; weather systems | Chemical reactions; thermal transfer | Cellular respiration; photosynthesis |
| Structure and Function | Plant/animal prairie adaptations | Cell structures; molecular bonds | DNA -> protein -> trait |
| Systems and System Models | Prairie ecosystems; water cycle | Earth systems; Missouri River watershed | Ecosystems; genetic systems |
| Scale, Proportion, Quantity | Particle size; distances | Atomic scale; geological time (Badlands) | Chromosome/gene scale |
| Stability and Change | Habitat change; erosion | Climate change evidence; ecosystem stability | Evolution; homeostasis |

## 8. Scoring Rubrics

### Constructed Response (CR) Rubric — 0–3 Points

| Score | Criteria |
|---|---|
| 3 | Response accurately addresses the science concept; demonstrates clear three-dimensional understanding (DCI + SEP or CCC evident); includes specific, relevant evidence from the stimulus; explanation is complete, accurate, and logically connected |
| 2 | Response addresses the science concept with partial accuracy; shows understanding of the DCI but may only partially integrate a practice or crosscutting concept; evidence from stimulus is present but may be incomplete or imprecisely used |
| 1 | Response minimally addresses the science concept; shows limited understanding; little or no evidence from stimulus; explanation may be vague, overgeneralized, or contain minor science inaccuracies |
| 0 | Response does not address the science concept; blank; off-topic; restates the stimulus without explanation; demonstrates no science understanding |

### CR Scoring Notes

- **Evidence must come from the stimulus.** Responses that rely solely on prior knowledge without referencing the provided data/diagram receive a maximum of 1 point.
- **Three-dimensional reasoning earns full credit.** A Score 3 response integrates content knowledge (DCI) with at least one SEP or CCC.
- **Misconceptions lower the score.** A significant science misconception drops the response by one score point.

### Suggested Anchoring Phenomena by Grade

**Grade 5 Phenomena:**
- "In Theodore Roosevelt National Park, visitors can see petrified logs lying on the ground in dry, treeless badlands. These logs are the remains of trees that grew millions of years ago when North Dakota had a warm, swampy climate. What evidence do these fossils provide about how the environment has changed?"
- "North Dakota's prairie potholes — small wetlands scattered across the landscape — freeze solid in winter but teem with life in spring when millions of migrating ducks and geese arrive. What role do these wetlands play in the movement of matter and energy through the prairie ecosystem?"
- "During a January cold snap, temperatures in Fargo dropped to negative 35 degrees Fahrenheit, but the water under the ice in the Red River stayed at 32 degrees. What explains why the river water stays at a different temperature than the air above it?"

**Grade 8 Phenomena:**
- "Paleontologists have discovered fossils of crocodile-like reptiles and palm trees in the same rock layers where lignite coal is found in western North Dakota. Today, the average January temperature in this area is 10 degrees Fahrenheit. What geoscience processes and climate changes explain how tropical organisms once lived in what is now North Dakota?"
- "Data from water quality monitoring stations along the Missouri River in North Dakota show that nitrogen levels increase significantly downstream from large agricultural areas, especially after spring planting season. What causes this pattern, and what are the potential effects on aquatic ecosystems?"
- "North Dakota experiences some of the most extreme temperature swings in the United States, with temperatures ranging from negative 60 degrees Fahrenheit (recorded in 1936) to 121 degrees Fahrenheit (recorded in 1936 — the same year). What atmospheric and geographic factors cause such extreme temperature variations in North Dakota?"

**Grade 11 Phenomena:**
- "Wild horse populations in Theodore Roosevelt National Park have been managed through periodic roundups to maintain a herd of approximately 100–200 animals. Genetic studies show that after decades of small population size, the horses have significantly less genetic diversity than domestic horse breeds. How could reduced genetic diversity affect the population's ability to adapt to disease or environmental change?"
- "North Dakota farmers have observed that certain weed species have become resistant to the herbicide glyphosate after 20 years of repeated application. How does the process of natural selection explain the increase in herbicide-resistant weeds, and what evidence would scientists look for to support this explanation?"
- "Prairie pothole wetlands cover less than 10 percent of the Northern Great Plains but provide breeding habitat for more than 50 percent of North American migratory ducks. As agricultural expansion drains these wetlands, scientists predict significant effects on continental waterfowl populations. What factors affect carrying capacity in this system, and how could mathematical models predict the impact of habitat loss?"

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] Grade verified as 5, 8, or 11 ONLY (not other grades)
- [ ] PE code is a valid NGSS-aligned Performance Expectation from North Dakota Science Standards
- [ ] Item is three-dimensional: DCI + SEP + CCC all identified
- [ ] Anchoring phenomenon is authentic and North Dakota-relevant where possible
- [ ] Stimulus (data table/graph/diagram) has clear labels, units, and realistic data
- [ ] CR prompt directs students to use evidence from the stimulus
- [ ] All distractors represent real misconceptions (not obviously wrong)
- [ ] MS items specify how many answers to select (TWO/THREE)
- [ ] Score 3 anchor response written before finalizing CR item
- [ ] Science content is accurate and reflects current scientific understanding
- [ ] Vocabulary is grade-appropriate (avoid jargon not in NGSS glossary)

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Writing items for Grades 3, 4, 6, or 7 | NDSA Science is only at Grades 5, 8, 11 | Restrict to tested grades |
| DCI-only items (no SEP or CCC) | NDSA Science requires three-dimensional items | Always embed a practice and a crosscutting concept |
| CR prompts without evidence directive | Students may respond without citing data | Include "Use evidence from the [data/graph/diagram]" |
| Generic stimulus data not tied to ND | NDSA Science favors North Dakota-relevant phenomena | Anchor stimulus to ND-specific context |
| Multi-select with only 2 correct in 4 options | Too easy to guess; 1-in-6 chance | Use 5-6 options with exactly 2-3 correct |
| Recall-only SR items | DOK 1 items are under-represented | Elevate most items to DOK 2 with a scenario |

### Sensitivity and Inclusivity

| Consideration | Guidance |
|---|---|
| **Lakota/Dakota/Mandan/Hidatsa/Arikara perspectives** | Include Indigenous ecological knowledge when relevant; present tribal stewardship practices respectfully; acknowledge the historical and contemporary presence of the MHA Nation, Standing Rock Sioux, Spirit Lake Nation, Turtle Mountain Band of Chippewa, and Sisseton-Wahpeton Oyate |
| **Rural and urban balance** | Include contexts from both agricultural/rural settings and Fargo/Bismarck/Grand Forks urban settings |
| **English Learner accessibility** | Use clear, direct sentence structure; define domain-specific vocabulary; ensure diagrams reduce linguistic load; North Dakota has growing immigrant and refugee communities from East Africa, the Middle East, and Central America |
| **Bias review** | Avoid scenarios that assume familiarity with specific cultural practices, economic situations, or recreational activities |

## 12. Prompt Patterns

The following patterns reflect the most common NDSA Science item archetypes.

### Pattern 1: Data-to-Conclusion (SR, DOK 2)
> "The [graph / table / diagram] below shows [North Dakota science scenario]. Based on the data, which [conclusion / explanation / pattern] is BEST supported?"

### Pattern 2: Phenomenon Explanation (CR, DOK 3)
> "Scientists observed [North Dakota-anchored phenomenon]. Using evidence from the [data / model / diagram], construct an explanation for [specific science focus]. Explain the [cause-and-effect / energy flow / pattern] relationship."

### Pattern 3: Model Evaluation (SR or MS, DOK 2–3)
> "A student made a model showing [science concept]. Which statement BEST describes what the model shows about [DCI focus]? / Select the TWO statements that correctly describe what the model represents."

### Pattern 4: Investigation Design (CR, DOK 3)
> "A scientist wants to investigate whether [variable] affects [outcome] in [North Dakota ecosystem/context]. Describe a procedure the scientist could follow. Include what the scientist would measure and how they would know if the variable made a difference."

### Pattern 5: Evidence-Based Argument (CR, DOK 3)
> "Two students disagree about [science claim]. Student A says [claim based on misconception]. Student B says [scientifically accurate claim]. Using evidence from the [data / diagram], explain which student is correct and why."

### Pattern 6: Multi-Select Evidence (MS, DOK 2)
> "A student is investigating [North Dakota science scenario]. Select the TWO [pieces of evidence / strategies / explanations] that BEST support the conclusion that [DCI-based claim]."
