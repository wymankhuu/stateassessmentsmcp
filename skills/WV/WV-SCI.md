## AssessmentForge Skill Guide | Grades 5, 8, and 11

## 1. Overview

| Field | Detail |
|---|---|
| **Assessment Name** | West Virginia General Summative Assessment (WVGSA) — Science |
| **Administering Agency** | West Virginia Department of Education (WVDE) |
| **Grades Tested** | **Grade 5**, **Grade 8**, **Grade 11** |
| **Testing Window** | April – May |
| **Delivery** | Computer-based; single session |
| **Standards** | WV Science Standards (West Virginia College- and Career-Readiness Standards for Science) |
| **Score Scale** | 4 performance levels; scale score reported per grade |
| **Reporting** | Individual Student Report; School, District, State aggregates |

> **CRITICAL NOTE:** WVGSA Science is administered at Grades 5, 8, and 11 only. Do not generate WVGSA Science items for any other grade. Grade 11 is the high school accountability grade.

> **WV Science Standards:** West Virginia adopted its own College- and Career-Readiness Standards for Science, which incorporate elements of the Next Generation Science Standards (NGSS) framework but use West Virginia's own coding system and emphasis areas. Items must align to WV Science Standards, not raw NGSS Performance Expectations. WV standards emphasize disciplinary core ideas, science and engineering practices, and crosscutting concepts within a three-dimensional framework.

### Performance Levels

| Level | Label | Description |
|---|---|---|
| 4 | **Exceeds** | Distinguished command of science concepts; applies reasoning precisely across complex, multi-step problems; integrates practices, core ideas, and crosscutting concepts with depth |
| 3 | **Meets** | Proficient command of grade-level science; applies content knowledge and practices to explain phenomena and solve problems at expected rigor |
| 2 | **Partially Meets** | Partial understanding; demonstrates some content knowledge but struggles with multi-step reasoning, evidence-based explanation, or application |
| 1 | **Does Not Meet** | Minimal understanding; limited to isolated recall with little evidence of scientific reasoning or practice application |

## 3. Test Structure

WVGSA Science is a single-session, computer-based assessment. All items use stimuli (data tables, diagrams, graphs, models, scenarios). No separate lab or performance task component.

```
+------------------------------------------------------------------+
|         WVGSA SCIENCE STRUCTURE (Grades 5, 8, and 11)            |
+------------------------------------------------------------------+
|  SINGLE SESSION                                                  |
|  Computer-Based                                                  |
|  Approximately 90-120 minutes (untimed, with guidelines)         |
|                                                                  |
|  ~35-45 items per grade                                          |
|                                                                  |
|  Item types:                                                     |
|    * Multiple Choice (MC) — ~55-60% (~20-24 items; 1 pt each)   |
|    * Multi-Select (MS) — ~15-20% (~6-8 items; 1 pt each)        |
|    * Constructed Response (CR) — ~20-25% (~7-10 items; 0-3 pts) |
+------------------------------------------------------------------+
```

| Specification | Grade 5 | Grade 8 | Grade 11 |

## 5. Item Types & Formats

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |

```

**MC Example (Grade 8, DOK 2, WV.SCI.8.ESS.2 -- Geoscience Processes):**

A geologist studying the New River Gorge finds layers of sandstone and shale along the canyon walls. The sandstone contains fossilized ripple marks, and the shale contains fossilized fern impressions. Which conclusion is BEST supported by this evidence?

A. The New River Gorge was formed by a single volcanic eruption
B. The area was once covered by environments that changed between shallow water and swampy land over time
C. The sandstone and shale were deposited at the same time by glaciers
D. The fossils were carried to the gorge by the New River from another location

*Correct Answer: B*
*Alignment: WV.SCI.8.ESS.2 | Practice: Constructing Explanations | Crosscutting: Patterns | DOK 2*

### Multi-Select (MS)

```
+----------------------------------------------------------+
|  MULTI-SELECT — 1 point                                  |
|                                                          |
|  5-6 options; select exactly 2 or 3 correct answers      |
|  All must be selected for full credit                    |
|  Machine scored                                          |
+----------------------------------------------------------+
```

**MS Example (Grade 11, DOK 2, WV.SCI.11.LS.2 -- Human Impact on Biodiversity):**

Scientists studying the Monongahela National Forest found that biodiversity has changed in areas near mountaintop removal mining sites. Select the TWO effects that are MOST directly caused by mountaintop removal mining.

A. Increased forest canopy density in mined areas
B. Loss of headwater stream habitats that support hellbender salamanders and other aquatic species
C. Improved soil quality due to rock fragmentation
D. Destruction of mature forest ecosystems that provide habitat for black bears and migratory songbirds
E. Decreased atmospheric carbon dioxide levels near mining sites

*Correct Answers: B, D*
*Alignment: WV.SCI.11.LS.2 | Practice: Evaluating Evidence | Crosscutting: Cause and Effect | DOK 2*

### Constructed Response (CR)

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE — 0-3 points                       |
|                                                          |
|  Written explanation (3-8 sentences depending on prompt)  |
|  Stimulus always provided (data, diagram, scenario)      |
|  Must demonstrate scientific reasoning and evidence use  |
|  Human scored                                            |
|  DOK 2-3                                                 |
+----------------------------------------------------------+
```

**CR Example (Grade 5, DOK 2, WV.SCI.5.ESS.1 -- Earth Systems Interactions):**

*Stimulus: Diagram showing the water cycle in a West Virginia mountain valley. Arrows show precipitation falling on the Allegheny Mountains, water flowing into streams, streams feeding the Kanawha River, and evaporation from the river returning water to the atmosphere.*

*"Using the diagram, explain how TWO of Earth's systems (geosphere, hydrosphere, biosphere, atmosphere) interact in this West Virginia mountain valley. Use specific evidence from the diagram in your response."*

**CR Example (Grade 11, DOK 3, WV.SCI.11.ESS.1 -- Earth System Feedbacks):**

*Stimulus: Data table showing pH levels in streams near abandoned coal mines in southern West Virginia over 20 years. Graph shows declining pH (increasing acidity) correlated with increasing dissolved iron and aluminum concentrations.*

*"Part A: Using evidence from the data, explain the process of acid mine drainage and how it affects water chemistry in West Virginia streams. Part B: Describe how changes in water chemistry could create feedback effects in the surrounding ecosystem. Include at least one specific effect on organisms."*

## 7. Three-Dimensional Design

WV Science Standards integrate three dimensions of science learning. Items should reflect all three dimensions where possible.

### Three Dimensions

| Dimension | What It Is | Example in WVGSA Items |
|---|---|---|
| **Disciplinary Core Ideas** (What students know) | Content knowledge: Physical, Life, Earth/Space Science | Properties of matter; ecosystem dynamics; WV geological history; heredity and natural selection |
| **Science and Engineering Practices** (What students do) | Developing models, analyzing data, constructing explanations, arguing from evidence | Analyze acid mine drainage data; develop a model of karst cave formation; construct an explanation for fossil distribution in WV rock layers |
| **Crosscutting Concepts** (How students connect) | Patterns, cause/effect, systems, energy/matter, structure/function, stability/change, scale | Patterns in WV weather data; cause and effect of deforestation on stream health; energy flow in Appalachian forest ecosystems |

### Crosscutting Concepts Emphasized in WV Standards

| Crosscutting Concept | Grade 5 Emphasis | Grade 8 Emphasis | Grade 11 Emphasis |
|---|---|---|---|
| Patterns | Weather patterns; seasonal changes in Appalachian forests | Fossil record patterns; rock layer sequences in New River Gorge | Population trends; chemical reaction patterns |
| Cause and Effect | Erosion and weathering; food web disruptions | Acid mine drainage; tectonic and geoscience processes | Natural selection; human impact on Monongahela Forest biodiversity |
| Systems and System Models | Earth's spheres; WV river watersheds | Water cycle; geosphere processes in karst regions | Climate feedback loops; biogeochemical cycles |
| Energy and Matter | Food chains in Appalachian forests; water cycle | Energy transformations; chemical changes in mining contexts | Ecosystem energy flow; nuclear and chemical energy |
| Stability and Change | Ecosystem balance; rock weathering | Population dynamics; stream chemistry near mine sites | Biodiversity change over time; Earth system feedbacks |

## 8. Scoring Rubrics

### Constructed Response (CR) Rubric -- 0-3 Points

| Score | Criteria |
|---|---|
| 3 | Thorough and accurate; addresses all parts of the prompt; uses specific evidence from the stimulus; demonstrates clear scientific reasoning integrating practices and core ideas; vocabulary is precise and grade-appropriate |
| 2 | Adequate response; addresses most parts of the prompt; uses some evidence from the stimulus; demonstrates understanding with minor gaps in reasoning or accuracy |
| 1 | Minimal response; addresses the prompt partially; limited or vague evidence; shows basic recall but weak scientific reasoning; may contain misconceptions |
| 0 | Blank; off-topic; restates stimulus without explanation; no science understanding demonstrated |

### Multiple Choice / Multi-Select Scoring

| Item Type | Scoring Rule |
|---|---|
| MC (Multiple Choice) | 1 point for correct answer; 0 for incorrect |
| MS (Multi-Select) | 1 point only when ALL correct options selected and no incorrect options selected; 0 otherwise |

### CR Scoring Notes

- **Evidence from the stimulus is required.** Responses relying solely on prior knowledge cannot earn the highest score.
- **Multi-part prompts require multi-part responses.** Addressing only one part limits the score to a maximum of 2 points.
- **Misconceptions reduce the score** by at least one point even when other reasoning is sound.
- **West Virginia context is valued but not required.** Students who connect science concepts to WV-specific phenomena demonstrate deeper understanding, but generic correct responses still earn credit.

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] Grade verified as **5, 8, or 11 ONLY**
- [ ] Standard code uses WV.SCI prefix and is a valid WV Science Standard
- [ ] Item integrates at least two of three dimensions (core idea + practice or crosscutting concept)
- [ ] Anchoring phenomenon is authentic and WV-relevant where possible
- [ ] Stimulus has clear labels, units, and realistic data
- [ ] CR prompts direct students to use evidence from the stimulus
- [ ] All MC distractors represent real misconceptions or common errors (not obviously wrong)
- [ ] MS items specify how many answers to select (TWO or THREE)
- [ ] CR anchor response (Score 3) written before finalizing
- [ ] Science content is accurate; vocabulary is grade-appropriate
- [ ] Performance level descriptors use 4-level scale (Does Not Meet / Partially Meets / Meets / Exceeds)
- [ ] MC items offer exactly 4 answer choices (A-D); MS items offer 5-6 choices
- [ ] Point values are correct: MC = 1 pt, MS = 1 pt, CR = 0-3 pts

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Writing items for untested grades | WVGSA Science tests only Grades 5, 8, 11 | Restrict to tested grades |
| Using NGSS PE codes instead of WV codes | WV uses its own standards framework | Use WV.SCI prefix and WV performance expectations |
| Pure recall items (no practice dimension) | WV emphasizes three-dimensional assessment | Embed data analysis, modeling, explanation, or argumentation |
| CR prompts without evidence directive | Students may skip citing data | Include "Using evidence from the [stimulus]" in all CR prompts |
| Using 5 performance levels | WV uses 4 levels | Always reference the 4-level scale (Does Not Meet / Partially Meets / Meets / Exceeds) |
| Generic Appalachian phenomena | WVGSA favors WV-specific contexts | Use New River Gorge, Kanawha Valley, Monongahela NF contexts |
| MS items with only 4 options | Too easy to guess correctly | Use 5-6 options with 2-3 correct |
| CR scoring on wrong scale | WVGSA CR items use 0-3 scale | Apply 0-3 rubric consistently |
| Ignoring engineering/design practices | WV standards include engineering practices | Include "design a solution" or "propose a method" items |
| Grade 11 items at middle school complexity | High school items require more sophisticated reasoning | Ensure Grade 11 items include multi-system analysis, feedback loops, and evaluation of competing claims |

## 12. Prompt Patterns

### Pattern 1: Data-to-Conclusion (MC, DOK 2)
> "The [graph / table] shows [WV scenario -- e.g., stream pH levels near a coal mine]. Based on the data, which [conclusion / pattern] is BEST supported?"

### Pattern 2: Phenomenon Explanation (CR, DOK 3)
> "Scientists observed [WV phenomenon -- e.g., orange water flowing from an abandoned mine]. Part A: Using evidence from the [stimulus], explain [science focus] and the cause-and-effect relationship. Part B: Propose one solution to reduce the impact. Explain how it works using science concepts."

### Pattern 3: Model Evaluation (MC or MS, DOK 2-3)
> "A student made a model showing [WV concept -- e.g., water movement through a karst cave system]. Which statement BEST describes what the model shows? / Select the TWO statements that correctly describe what the model represents."

### Pattern 4: Investigation Design (CR, DOK 3)
> "A scientist wants to investigate whether [variable] affects [outcome] in [WV context -- e.g., whether reforestation reduces acid runoff in a mined watershed]. Describe a procedure including what to measure and what to keep constant. Predict results if the hypothesis is correct."

### Pattern 5: Evidence-Based Argument (CR, DOK 2-3)
> "Two students disagree about [WV science claim -- e.g., whether the New River carved its gorge or the mountains rose around it]. Student A says [claim 1]. Student B says [claim 2]. Using evidence from the [stimulus], explain which student's claim is better supported and why."

### Pattern 6: Human Impact and Solutions (MS or CR, DOK 2-3)
