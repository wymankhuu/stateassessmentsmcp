## 3. TEST STRUCTURE

WVGSA Mathematics is administered in **2 sessions** over one or two days.

```
+-------------------------------------------------------------------+
|          WVGSA MATH TEST STRUCTURE (Grades 3–8, 11)               |
+---------------------------------+---------------------------------+
|   SESSION 1                     |   SESSION 2                     |
|   ~60–75 minutes                |   ~60–75 minutes                |
|                                 |                                 |
|  MULTIPLE CHOICE                |  MULTIPLE CHOICE                |
|  MULTI-SELECT                   |  MULTI-SELECT                   |
|  EQUATION ENTRY (EQ)            |  EQUATION ENTRY (EQ)            |
|  NO calculator (all grades)     |  CONSTRUCTED RESPONSE           |
|                                 |  Calculator allowed (Gr 6–8,11) |
+---------------------------------+---------------------------------+
```

### Session Item Counts by Grade Band

| Session       | Grades 3–5                       | Grades 6–8                       | Grade 11                         |
|---------------|----------------------------------|----------------------------------|----------------------------------|
| Session 1     | 18–24 MC/MS/EQ items (no calc)   | 18–24 MC/MS/EQ items (no calc)   | 18–24 MC/MS/EQ items (no calc)   |
| Session 2     | 14–20 MC/MS/EQ + 2–3 CR items   | 14–20 MC/MS/EQ + 2–3 CR (calc)  | 14–20 MC/MS/EQ + 2–3 CR (calc)  |

> **Calculator Policy:** No calculators for any portion of Grades 3–5. For Grades 6–8 and 11, a calculator is available during Session 2 only.

## 5. ITEM TYPES

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Single correct answer                                   |
|  Machine scored                                          |
|  DOK 1–2                                                 |
|  Both sessions                                           |
+----------------------------------------------------------+
```

**MC Example (Grade 6, DOK 2, 6.RP — Ratios):**

A coal museum in WV reports that 3 out of every 5 visitors are from out of state. If 120 visitors came to the museum last weekend, how many were from out of state?

- A. 24
- B. 40
- C. 72
- D. 200

*Correct Answer: C (120 x 3/5 = 72)*

---

### Multi-Select (MS)

```
+----------------------------------------------------------+
|  MULTI-SELECT — 1 point                                  |
|                                                          |
|  5–6 options                                             |
|  Student selects ALL correct answers (typically 2)       |
|  Machine scored; all-or-nothing                          |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**MS Example (Grade 8, DOK 2, 8.EE — Expressions and Equations):**

*The New River Gorge Bridge is 876 feet above the river. A rock dropped from the bridge follows the equation h(t) = 876 - 16t^2, where h is height in feet and t is time in seconds.*

Select TWO true statements about this equation.

- A. The rock starts at a height of 876 feet
- B. The rock rises before it falls
- C. The coefficient -16 represents the effect of gravity
- D. The rock hits the water at exactly 7 seconds
- E. The height increases as time increases

*Correct Answers: A and C*

---

### Equation Entry (EQ)

```
+----------------------------------------------------------+
|  EQUATION ENTRY — 1 point                                |
|                                                          |
|  Student types a numerical answer or expression          |
|  Machine scored; exact match or equivalent               |
|  DOK 1–2                                                 |
|  Both sessions                                           |
+----------------------------------------------------------+
```

**EQ Example (Grade 7, DOK 2, 7.RP — Proportional Relationships):**

*The elevation at the top of Spruce Knob, West Virginia's highest point, is 4,863 feet. The elevation at the base of the mountain is 2,100 feet. What is the elevation gain in feet?*

*Enter your answer: ____*

*Correct Answer: 2763*

---

### Constructed Response (CR)

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE — 0–2 points                       |
|                                                          |
|  Multi-step problem requiring shown work                 |
|  May include Parts A, B                                  |
|  DOK 2–3                                                 |
|  Human scored using CR rubric                            |
|  Session 2 only (2–3 per test)                           |
+----------------------------------------------------------+
```

**CR Example (Grade 8, DOK 3, 8.G — Geometry):**

*"The New River Gorge Bridge has a main arch span of 1,700 feet and rises 876 feet above the river.*

*Part A: If a scale model of the bridge uses a scale of 1 inch = 50 feet, how long would the model's main span be? Show your work.*
*Part B: How tall would the arch be in the model? Explain how you determined your answer."*

## 8. SCORING RUBRICS

### Constructed Response (CR) Rubric — 0–2 Points

| Score | Criteria                                                                                                    |
|-------|-------------------------------------------------------------------------------------------------------------|
| 2     | Correct answer with complete, clearly shown work; mathematical reasoning is sound and organized              |
| 1     | Partially correct; work shown is incomplete or contains a minor error; some mathematical understanding       |
| 0     | Incorrect or no work shown; blank; off-task; no mathematical understanding demonstrated                     |

### Other Item Scoring

| Item Type            | Scoring                                                              |
|----------------------|----------------------------------------------------------------------|
| MC (1-point)         | Correct answer = 1 pt; incorrect = 0 pt                             |
| MS (1-point)         | All-or-nothing: all correct answers must be selected                 |
| EQ (1-point)         | Exact match or equivalent = 1 pt; incorrect = 0 pt                  |

## 11. QUALITY CHECKLIST AND COMMON PITFALLS

### Quality Checklist

- [ ] Standard code uses WV College- and Career-Readiness format ([Grade].[Domain].[Standard])
- [ ] Practice standard alignment identified for CR items
- [ ] Calculator policy matches session and grade level
- [ ] CR items require shown work and may include multi-part structure
- [ ] EQ items have clear, unambiguous numerical answers
- [ ] All numerical values produce clean, non-ambiguous answers
- [ ] WV-specific real-world context used where appropriate
- [ ] Distractors reflect specific, identifiable student error types
- [ ] DOK level verified against actual cognitive demand
- [ ] Units and labels are correct throughout
- [ ] Grade 11 items include advanced algebraic and functional content
- [ ] MS items specify how many options to select
- [ ] Data tables and graphs are clearly labeled

### Common Pitfalls

| Pitfall                                  | Problem                                           | Fix                                                      |
|------------------------------------------|---------------------------------------------------|----------------------------------------------------------|
| Calculator in Session 1 (Gr 3–5)        | No calculator allowed for any Grades 3–5 portion  | Design items without calculator dependence for Gr 3–5    |
| CR rubric exceeds 0–2 range             | WVGSA Math CR items are scored 0–2                 | Use only the 0–2 rubric scale                            |
| Generic context (no WV specificity)      | WVGSA values authentic WV contexts                 | Use New River Gorge, elevation data, coal production     |
| CR without "show your work" directive   | DOK 3 requires demonstrated reasoning              | Include "Show your work" or "Explain your reasoning"     |
| Grade 11 treated same as Grade 8         | Grade 11 requires more advanced math               | Include algebra, functions, and geometry for Grade 11    |
| EQ answer ambiguous                      | EQ requires exact machine-scored answers            | Verify answer has a single clean numerical form          |
| MS item not specifying selection count   | Students must know how many to select              | Always include "Select TWO" or similar directive         |

## 12. PROMPT PATTERNS

The following patterns reflect the most common WVGSA Mathematics item structures.

### Pattern 1: Contextual Computation (MC, DOK 2)
> "[WV setting]. [Given information]. [Mathematical question requiring multi-step application]."
> (Options: correct answer + three specific error-type distractors)

### Pattern 2: Multi-Step Application (CR Part A, DOK 2)
> "A [WV context] has [given data]. [Part A: computation requiring setup + solve]. Show your work."

### Pattern 3: Rate or Ratio in Context (MC or CR, DOK 2)
> "[WV scenario] involves [quantity A] for every [quantity B]. [Question about scaling, unit rate, or comparison]."

### Pattern 4: Explain in Context (CR Part B, DOK 3)
> "Explain what your answer to Part A means in the context of [WV scenario]."

### Pattern 5: Comparison with Justification (CR, DOK 3)
> "Two [WV scenarios] are described: [Scenario A] and [Scenario B]. Which is [more efficient / greater / better value]? Use mathematical evidence to justify your answer."

### Pattern 6: Equation Entry (EQ, DOK 1–2)
> "[WV context with given data]. [Direct computation question]. Enter your answer."

### Pattern 7: Data Interpretation (MC or MS, DOK 2)
> "The [table / graph] below shows [WV data]. Based on the data, which statement is BEST supported?"
