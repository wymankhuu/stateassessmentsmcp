## 5. Item Types & Formats

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                                |
|                                                           |
|  4 options (A, B, C, D)                                   |
|  May include real-world context or stimulus               |
|  Machine scored                                           |
|  DOK 1–3                                                  |
+----------------------------------------------------------+
```

**MC Example (Grade 6, DOK 2, WY.Math.6.RP.3):**

A family drives from Cheyenne to Yellowstone National Park, a distance of approximately 450 miles. If they average 60 miles per hour, how many hours will the drive take?

A. 6.5
B. 7.0
C. 7.5
D. 8.0

*Correct Answer: C*
*Alignment: WY.Math.6.RP.3 | DOK 2*

---

**MC Example (Grade 8, DOK 2, WY.Math.8.F.2):**

Two Wyoming ranches track their cattle herds over time. Ranch A's herd size is shown in the table, and Ranch B's herd is modeled by the equation y = 50x + 200, where x is the number of years and y is the herd size. Which statement correctly compares the two ranches?

A. Ranch A's herd is growing at a faster rate than Ranch B's
B. Ranch B starts with a larger herd than Ranch A
C. Both ranches have the same initial herd size
D. Ranch A's herd will always be larger than Ranch B's

*Correct Answer: B*
*Alignment: WY.Math.8.F.2 | DOK 2*

---

### Multi-Select (MS)

```
+----------------------------------------------------------+
|  MULTI-SELECT — 1 point                                   |
|                                                           |
|  5–7 options; select all correct answers                  |
|  Machine scored                                           |
|  DOK 2–3                                                  |
+----------------------------------------------------------+
```

**MS Example (Grade 7, DOK 2, WY.Math.7.EE.4):**

Select ALL equations that could represent the following situation: A Wyoming outfitter charges $75 per day plus a flat equipment rental fee of $150. A group paid a total of $600.

A. 75x + 150 = 600
B. 150x + 75 = 600
C. 600 = 75x + 150
D. 75(600) + 150 = x
E. 600 - 150 = 75x

*Correct Answers: A, C, E*
*Alignment: WY.Math.7.EE.4 | DOK 2*

### Constructed Response (CR)

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE — 0–2 points                        |
|                                                           |
|  Show work and/or explain reasoning                       |
|  Multi-step problem or justification                      |
|  Human scored using CR rubric                             |
|  DOK 3                                                    |
+----------------------------------------------------------+
```

**CR Example (Grade 11, DOK 3, WY.Math.11.S-ID.6):**

The table below shows the Grand Teton summit elevation (13,775 ft) and the elevations of five base camps along the climbing route, along with the average temperature at each elevation. Create a scatter plot of elevation vs. temperature. Describe the relationship and write an equation for the line of best fit. Use your model to predict the temperature at 11,000 feet. Explain whether your prediction is reasonable.

## 8. Scoring Rubrics

### Constructed Response (CR) Rubric — 0–2 Points

| Score | Criteria |
|---|---|
| 2 | Work clearly shows a correct mathematical process. Answer is correct. Explanation (if required) demonstrates understanding of the mathematical concept and uses appropriate mathematical vocabulary. |
| 1 | Work shows understanding of the mathematical concept but contains a minor computational error. OR Correct answer is given without a clear explanation of the process. |
| 0 | Work shows no understanding of the mathematical concept, or response is blank. |

## 10. Contextualization — Wyoming Mathematics

When generating items and contexts, prioritize authentic Wyoming settings:

### Wyoming Context Guide

| Context | Mathematical Application | Grade Band |
|---|---|---|
| Yellowstone dimensions and data (3,472 sq mi; 10,000+ thermal features; 2.2M acres) | Area, measurement, ratios, unit conversion, data analysis | 4–11 |
| Grand Teton elevation (13,775 ft summit; base at 6,237 ft; vertical rise 7,538 ft) | Measurement, subtraction, slope, rate of change, functions | 4–11 |
| Wyoming cattle statistics (1.3 million cattle; ranch sizes; carrying capacity) | Multiplication, ratios, unit rates, proportional reasoning, data analysis | 3–11 |
| Wyoming highway distances (Cheyenne to Yellowstone: 450 mi; vast distances between towns) | Rate, distance/time, unit conversion, proportional reasoning | 3–8 |
| Devils Tower dimensions (867 ft tall; 1,000 ft diameter base) | Measurement, geometry, volume, circumference | 4–8 |
| Wind River Range peaks and trail distances | Measurement, slope, rate of change, functions | 5–11 |
| Wyoming population data (smallest state population: ~577,000) | Statistics, ratios, per capita calculations, data analysis | 6–11 |
| Yellowstone wildlife census data (bison, wolves, elk counts) | Data analysis, mean/median, graphing, percent change | 4–8 |
| Wyoming energy production (coal, natural gas, wind energy output) | Unit rates, percent, data analysis, linear models | 6–11 |
| Oregon Trail distances and travel rates | Rate, distance/time, proportional reasoning | 4–7 |

### Suggested Problem Contexts by Grade

**Grades 3–4:**
- Counting bison in Yellowstone; grouping and multiplication
- Measuring distances along a trail in Grand Teton National Park

**Grades 5–6:**
- Calculating rates of travel on Wyoming highways between towns
- Ratio problems using Wyoming cattle ranch data

**Grades 7–8:**
- Proportional reasoning with Yellowstone geyser eruption data (intervals, duration)
- Analyzing elevation data for Grand Teton climbing routes

**Grade 11:**
- Modeling Wyoming wind energy production growth with linear or exponential functions
- Statistical analysis of Yellowstone visitor data across decades

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] Wyoming Content and Performance Standard code verified as correct for the targeted grade and domain
- [ ] Real-world context is mathematically accurate and grade-appropriate
- [ ] Computation is error-free; answer key verified
- [ ] Distractors reflect authentic student misconceptions or common computational errors
- [ ] MS items have exactly the specified number of correct answers
- [ ] CR prompt requires multi-step reasoning and/or explanation
- [ ] Calculator policy is correctly applied per grade level
- [ ] Wyoming context incorporated where appropriate
- [ ] DOK level matches the cognitive demand of the item
- [ ] Numerical values are realistic for Wyoming contexts

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Context-free computation | WY-TOPP emphasizes application and modeling | Embed problems in real-world Wyoming contexts |
| CR that only requires computation | CR should require explanation or justification at DOK 3 | Include "show your work and explain" in CR prompts |
| Unrealistic numerical values | Context must be mathematically plausible | Verify numbers match real Wyoming data (distances, elevations, populations) |
| Calculator-required item in non-calculator section | Calculator policy varies by grade and section | Clearly designate calculator availability per item |
| MS items with only one correct answer | MS items must have 2+ correct answers | Ensure multiple valid responses exist |
| Urban-centric contexts | Wyoming is predominantly rural | Use ranch, wildlife, park, and small-town contexts |

## 12. Prompt Patterns

### Pattern 1: Real-World Computation (MC, DOK 2)
> "[Wyoming context with quantities]. [Question requiring computation]. What is the [result / total / difference]?"

### Pattern 2: Multiple Representations (MC, DOK 2)
> "A [table / graph / equation] shows [relationship]. Which [other representation / statement] represents the SAME relationship?"

### Pattern 3: Justify and Explain (CR, DOK 3)
> "[Multi-step Wyoming context problem]. Show your work and explain how you found your answer."

### Pattern 4: Equivalent Expressions / Select All (MS, DOK 2)
> "Select ALL [expressions / equations / values] that are equivalent to [given expression or scenario]."

### Pattern 5: Data Interpretation (MC or CR, DOK 2–3)
> "The [table / graph / chart] shows [Wyoming data context]. Based on the data, [what is the rate of change / which conclusion / what prediction] is BEST supported?"

### Pattern 6: Geometric Reasoning (MC, DOK 2–3)
> "[Wyoming context involving measurement or shape]. What is the [area / volume / perimeter / angle measure]? [Show your work / explain your reasoning]."
