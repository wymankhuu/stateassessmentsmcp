## 1. Overview

| Field | Detail |
|---|---|
| **Assessment Name** | WY-TOPP — Science |
| **Administering Agency** | Wyoming Department of Education (WDE) |
| **Vendor** | Wyoming Department of Education |
| **Grades Tested** | **Grade 5**, **Grade 8**, **Grade 11** |
| **Testing Window** | Spring (March–April) |
| **Delivery** | Computer-based (online); paper accommodations available |
| **Standards** | Wyoming Science Content and Performance Standards (NGSS-aligned) |
| **Score Scale** | Scale score with 4 performance levels |
| **Reporting** | Individual Student Report; School, District, State aggregates |

> **CRITICAL NOTE:** WY-TOPP Science is administered **only at Grades 5, 8, and 11**. It is **NOT** given at Grades 3, 4, 6, or 7 for state accountability. Do not generate WY-TOPP Science-aligned items for non-tested grades. Wyoming's science standards are aligned with the **Next Generation Science Standards (NGSS)**, emphasizing three-dimensional learning.

### Performance Levels

| Level | Label | Description |
|---|---|---|
| 4 | **Highly Proficient** | Thorough understanding of science concepts; applies knowledge in novel and complex situations |
| 3 | **Proficient** | Adequate understanding of grade-level science standards; applies concepts appropriately |
| 2 | **Partially Proficient** | Partial understanding; inconsistent application of science concepts |
| 1 | **Minimally Proficient** | Minimal understanding; significant gaps in science knowledge and practices |

## 2. Standards Framework

> WY-TOPP Science is aligned to **Wyoming Science Content and Performance Standards**, which adopt the NGSS framework integrating science and engineering practices, crosscutting concepts, and disciplinary core ideas — following a three-dimensional learning model.

### Science and Engineering Practices

| Practice | Description |
|---|---|
| Asking Questions / Defining Problems | Formulate testable questions and define engineering problems |
| Developing and Using Models | Create, use, and revise models to represent phenomena |
| Planning and Carrying Out Investigations | Design and conduct investigations to collect data |
| Analyzing and Interpreting Data | Use mathematical and computational thinking to analyze data |
| Using Mathematics and Computational Thinking | Apply mathematical tools to analyze and represent data |
| Constructing Explanations / Designing Solutions | Construct evidence-based explanations; design solutions |
| Engaging in Argument from Evidence | Support or refute claims using evidence and reasoning |
| Obtaining, Evaluating, and Communicating Information | Read, synthesize, and communicate scientific information |

### Crosscutting Concepts

| Concept | Description |
|---|---|
| Patterns | Observed patterns guide organization and classification |
| Cause and Effect | Events have causes; investigate and explain causal relationships |
| Scale, Proportion, and Quantity | Relative scales of time, size, and energy matter |
| Systems and System Models | Define system boundaries; model component interactions |
| Energy and Matter | Track flows of energy and cycles of matter |
| Structure and Function | Form and function are complementary |
| Stability and Change | Conditions of stability and change; feedback mechanisms |

## 3. Test Structure

WY-TOPP Science is administered in a single session. Items are organized around science phenomena or scenarios, with clusters of items tied to a shared stimulus.

```
+------------------------------------------------------------------+
|            WY-TOPP SCIENCE STRUCTURE (Grades 5, 8, 11)            |
+------------------------------------------------------------------+
|  SINGLE SESSION — Approximately 2–3 hours (untimed)              |
|  Computer-Based                                                   |
|                                                                   |
|  STIMULUS-BASED CLUSTERS                                          |
|  +----------------------------------------+                      |
|  | Cluster 1: Science Phenomenon/Scenario |                       |
|  |   -> 3–5 MC + MS items                |                       |
|  +----------------------------------------+                      |
|  | Cluster 2: Investigation/Data Scenario |                       |
|  |   -> 3–5 MC + MS items                |                       |
|  +----------------------------------------+                      |
|  | Cluster 3: Phenomenon/Model Scenario   |                       |
|  |   -> 3–5 MC + MS + CR items           |                       |
|  +----------------------------------------+                      |
|  | Cluster 4–6: Additional clusters       |                       |

|  +----------------------------------------+                      |
+------------------------------------------------------------------+
```

## 5. Item Types & Formats

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                                |
|                                                           |
|  4 options (A, B, C, D)                                   |
|  Always stimulus-dependent (data, scenario, model)        |
|  Machine scored                                           |
|  DOK 1–3                                                  |
+----------------------------------------------------------+
```

**MC Example (Grade 5, DOK 2, WY.5-LS2-1):**

*[Stimulus: Diagram showing a sagebrush steppe food web with sagebrush, grasshoppers, sage grouse, pronghorn, golden eagles, and coyotes]*

If the population of grasshoppers in this ecosystem suddenly decreased, which organism would MOST LIKELY be directly affected first?

A. Golden eagles
B. Sage grouse
C. Pronghorn
D. Sagebrush

*Correct Answer: B*
*Alignment: WY.5-LS2-1 | DOK 2*

---

**MC Example (Grade 8, DOK 2, WY.MS-ESS2-2):**

*[Stimulus: Diagram showing the glacial features of the Teton Range, including moraines, U-shaped valleys, and glacial lakes]*

Which process BEST explains the formation of the U-shaped valleys in the Grand Teton Range?

A. River erosion cutting through sedimentary rock over millions of years
B. Glacial ice carving and widening existing stream valleys during ice ages
C. Tectonic plate collision pushing rock layers upward
D. Wind erosion wearing down the mountain peaks over time

*Correct Answer: B*
*Alignment: WY.MS-ESS2-2 | DOK 2*

---

**MC Example (Grade 11, DOK 2, WY.HS-ESS2-1):**

*[Stimulus: Cross-section diagram showing the Yellowstone hotspot, magma chamber, and overlying caldera with data on past eruptions]*

Based on the diagram and data, which statement BEST explains the relationship between the Yellowstone hotspot and the geothermal features observed at the surface?

A. The geothermal features are caused by radioactive decay of surface rocks
B. Heat from the magma chamber below the caldera heats groundwater, creating geysers and hot springs
C. Solar radiation absorbed by dark rock surfaces creates the hot springs
D. Chemical reactions between mineral deposits and rainwater generate the heat

*Correct Answer: B*
*Alignment: WY.HS-ESS2-1 | DOK 2*

### Multi-Select (MS)

```
+----------------------------------------------------------+
|  MULTI-SELECT — 1 point                                   |
|                                                           |
|  5–7 options; select 2 or more correct answers            |
|  Stimulus-dependent                                       |
|  Machine scored                                           |
|  DOK 2–3                                                  |
+----------------------------------------------------------+
```

**MS Example (Grade 11, DOK 2, WY.HS-LS4-3):**

*[Stimulus: Data table showing bison population counts in Yellowstone from 1900–2020, along with average winter severity index and available grazing area]*

Select TWO conclusions that are supported by the data in the table.

A. Bison population has remained constant throughout the entire period
B. Severe winters are correlated with temporary decreases in bison population
C. Bison populations increased after conservation measures expanded available habitat
D. The bison population will reach 10,000 by 2030
E. Bison prefer to live near geothermal features in winter

*Correct Answers: B, C*
*Alignment: WY.HS-LS4-3 | DOK 2*

### Constructed Response (CR)

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE — 0–2 points                        |
|                                                           |
|  Evidence-based written explanation                       |
|  Must reference data, diagrams, or investigation results  |
|  Human scored using CR rubric                             |
|  DOK 3                                                    |
+----------------------------------------------------------+
```

**CR Example (Grade 8, DOK 3, WY.MS-ESS3-5):**

*[Stimulus: Data table showing Wyoming's annual energy production by source (coal, natural gas, wind) from 2005–2023, along with corresponding carbon dioxide emissions data]*

Using the data from the table, explain how Wyoming's energy production has changed over the past two decades and how these changes have affected carbon dioxide emissions. Reference specific data values to support your explanation.

---

**CR Example (Grade 11, DOK 3, WY.HS-ESS3-2):**

*[Stimulus: Comparative data showing Wyoming wind energy output, coal production, employment figures, and environmental impact metrics over the last decade]*

Using the data provided, evaluate the trade-offs between expanding wind energy production and maintaining coal production in Wyoming. Reference specific values from the data to support your argument, and explain how this relates to the management of natural resources.

## 7. Scientific Investigation Design

### Investigation Components Assessed

| Component | Description | Example |
|---|---|---|
| **Testable Question** | Identify or formulate a question that can be investigated | "How does water temperature affect the eruption interval of a model geyser?" |
| **Variables** | Identify independent, dependent, and controlled variables | IV: water temperature; DV: eruption interval; CV: water volume, apparatus design |
| **Procedure** | Evaluate or design a step-by-step investigation plan | Multiple trials, single variable changed, appropriate tools |
| **Data Collection** | Select appropriate tools and methods for gathering data | Thermometer for temperature; stopwatch for time; multiple trials |
| **Data Analysis** | Interpret tables, graphs, and charts to identify patterns | "The graph shows that as water temperature increased, eruption frequency increased" |
| **Conclusions** | Draw evidence-based conclusions; identify limitations | "The data supports the hypothesis because..." |

### Stimulus Types

| Stimulus | Description | Use |
|---|---|---|
| **Data table** | Organized numerical data from an investigation | Data interpretation, pattern identification, prediction |
| **Graph** | Bar graph, line graph, scatter plot | Trend analysis, comparison, correlation |
| **Diagram** | System model, food web, geological cross-section, anatomical structure | Model interpretation, process identification |
| **Investigation scenario** | Description of a student conducting an experiment | Variable identification, procedure evaluation, conclusion drawing |
| **Phenomenon description** | Real-world Wyoming phenomenon requiring scientific explanation | Explanation construction, evidence-based reasoning |

## 8. Scoring Rubrics

### Constructed Response (CR) Rubric — 0–2 Points

| Score | Criteria |
|---|---|
| 2 | Response accurately interprets or applies the science concept. References specific data, evidence, or values from the provided stimulus. Explanation is clear, logically connected, and demonstrates understanding of the underlying scientific principle. |
| 1 | Response shows partial understanding. Data referenced but not precisely used, OR explanation is accurate but lacks reference to stimulus data. |
| 0 | Response is incorrect, does not address the science concept, is insufficient in length, or is blank. |

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] Wyoming Science Standard code verified as correct for the targeted grade (5, 8, or 11 only)
- [ ] Item is stimulus-dependent (tied to data, diagram, model, or investigation scenario)
- [ ] Three-dimensional: item integrates a practice, crosscutting concept, and core idea
- [ ] CR prompt requires evidence-based explanation referencing specific data or observations
- [ ] MC distractors reflect authentic science misconceptions
- [ ] MS items have exactly the specified number of correct answers
- [ ] Stimulus data is scientifically accurate and grade-appropriate
- [ ] Wyoming context incorporated where appropriate (geology, ecology, wildlife, energy)
- [ ] DOK level matches the cognitive demand of the item and standard
- [ ] NGSS alignment verified (Wyoming adopts NGSS framework)

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Items at non-tested grades | WY-TOPP Science is only at Grades 5, 8, and 11 | Verify grade before generating items |
| Standalone recall items | WY-TOPP Science emphasizes three-dimensional assessment | Embed items in phenomenon-based or data-based stimuli |
| CR without data reference | CR should require specific evidence from stimulus | Include "use specific data/evidence" in every CR prompt |
| Scientifically inaccurate stimuli | Data and scenarios must be realistic | Verify all scientific claims and data values against Wyoming sources |
| Missing crosscutting concepts | NGSS requires three-dimensional alignment | Identify the crosscutting concept addressed by each item |
| Using non-NGSS standard codes | Wyoming uses NGSS-aligned codes | Reference WY NGSS standard codes exclusively |

## 12. Prompt Patterns

### Pattern 1: Data Interpretation (MC, DOK 2)
> "Based on the data in the [table / graph], which [conclusion / pattern / trend] is BEST supported?"

### Pattern 2: Investigation Design (MC, DOK 2–3)
> "A student wants to investigate [Wyoming-relevant question]. Which experimental setup would BEST allow the student to test this hypothesis?"

### Pattern 3: Cause and Effect (MC, DOK 2)
> "If [variable or condition changes] in this [ecosystem / system / investigation], what would MOST LIKELY happen to [outcome]?"

### Pattern 4: Ecosystem / Trophic Cascade Analysis (MC or CR, DOK 2–3)
> "[Yellowstone / Wyoming ecosystem] diagram shows [food web / interactions]. If [organism / factor] were removed or changed, what would MOST LIKELY happen to [other organism / population]? Use evidence from the [diagram / data] to explain."

### Pattern 5: Geological Process (MC, DOK 2)
> "The [diagram / model] shows [geological feature in Wyoming]. Which process BEST explains the formation of [feature]?"

### Pattern 6: Evidence-Based Explanation (CR, DOK 3)
> "Using the data in the [table / graph], explain [science pattern or relationship]. Use specific [values / evidence] from the [data / graph] in your explanation."
