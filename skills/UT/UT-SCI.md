## 1. Overview

| Field | Detail |
|---|---|
| **Assessment Name** | RISE — Science |
| **Administering Agency** | Utah State Board of Education (USBE) |
| **Vendor** | Cambium Assessment / USBE |
| **Grades Tested** | **Grade 5**, **Grade 8**, **Grade 11** |
| **Testing Window** | Spring (March–May) |
| **Delivery** | Computer-based (online); paper accommodations available |
| **Standards** | Utah SEEd Standards (Science with Engineering Education) |
| **Score Scale** | Scale score with 4 performance levels |
| **Reporting** | Individual Student Report; School, District, State aggregates |

> **CRITICAL NOTE:** RISE Science is administered **only at Grades 5, 8, and 11**. It is **NOT** given at Grades 3, 4, 6, or 7 for state accountability. Do not generate RISE Science-aligned items for non-tested grades. Utah uses the **SEEd Standards** (Science with Engineering Education), which are Utah's unique adaptation incorporating three-dimensional learning.

### Performance Levels

| Level | Label | Description |
|---|---|---|

| 3 | **Proficient** | Adequate understanding of grade-level science standards; applies concepts appropriately |
| 2 | **Partially Proficient** | Partial understanding; inconsistent application of science concepts |
| 1 | **Minimally Proficient** | Minimal understanding; significant gaps in science knowledge and practices |

## 2. Standards Framework

> RISE Science is aligned to the **Utah SEEd Standards (Science with Engineering Education)**, which integrate science and engineering practices, crosscutting concepts, and disciplinary core ideas — following a three-dimensional learning model unique to Utah.

### Science and Engineering Practices

| Practice | Description |
|---|---|
| Asking Questions / Defining Problems | Formulate testable questions and define engineering problems |
| Developing and Using Models | Create, use, and revise models to represent phenomena |
| Planning and Carrying Out Investigations | Design and conduct investigations to collect data |
| Analyzing and Interpreting Data | Use mathematical and computational thinking to analyze data |
| Using Mathematics and Computational Thinking | Apply mathematical tools to analyze and represent data |
| Constructing Explanations / Designing Solutions | Construct evidence-based explanations; design solutions |
| Engaging in Argument from Evidence | Support or refute claims using evidence and reasoning |
| Obtaining, Evaluating, and Communicating Information | Read, synthesize, and communicate scientific information |

### Crosscutting Concepts

| Concept | Description |
|---|---|
| Patterns | Observed patterns guide organization and classification |
| Cause and Effect | Events have causes; investigate and explain causal relationships |
| Scale, Proportion, and Quantity | Relative scales of time, size, and energy matter |
| Systems and System Models | Define system boundaries; model component interactions |
| Energy and Matter | Track flows of energy and cycles of matter |
| Structure and Function | Form and function are complementary |
| Stability and Change | Conditions of stability and change; feedback mechanisms |

## 3. Test Structure

RISE Science is administered in a single session. Items are organized around science phenomena or scenarios, with clusters of items tied to a shared stimulus.

```
+------------------------------------------------------------------+
|            RISE SCIENCE STRUCTURE (Grades 5, 8, 11)               |
+------------------------------------------------------------------+
|  SINGLE SESSION — Approximately 2–3 hours (untimed)              |
|  Computer-Based                                                   |
|                                                                   |
|  STIMULUS-BASED CLUSTERS                                          |
|  +----------------------------------------+                      |
|  | Cluster 1: Science Phenomenon/Scenario |                       |
|  |   -> 3–5 SR + MS + TE items           |                       |
|  +----------------------------------------+                      |
|  | Cluster 2: Investigation/Data Scenario |                       |
|  |   -> 3–5 SR + MS + TE items           |                       |
|  +----------------------------------------+                      |
|  | Cluster 3: Phenomenon/Model Scenario   |                       |
|  |   -> 3–5 SR + MS + TE + CR items      |                       |
|  +----------------------------------------+                      |
|  | Cluster 4–6: Additional clusters       |                       |
|  |   (varies by grade)                    |                       |
|  +----------------------------------------+                      |
+------------------------------------------------------------------+
```

## 5. Item Types & Formats

### Selected Response (SR)

```
+----------------------------------------------------------+
|  SELECTED RESPONSE — 1 point                              |
|                                                           |
|  4 options (A, B, C, D)                                   |
|  Always stimulus-dependent (data, scenario, model)        |
|  Machine scored                                           |
|  DOK 1–3                                                  |
+----------------------------------------------------------+
```

**SR Example (Grade 5, DOK 2, UT.5.3.1):**

*[Stimulus: Diagram showing the internal structure of a brine shrimp from Great Salt Lake, with labeled body parts]*

Which internal structure MOST helps the brine shrimp survive in the highly saline water of Great Salt Lake?

A. Its compound eyes that detect light
B. Its specialized gills that regulate salt concentration in its body
C. Its segmented body that allows it to swim
D. Its antennae that help it sense food

*Correct Answer: B*
*Alignment: UT.5.3.1 | DOK 2*

---

**SR Example (Grade 11, DOK 2, UT.HS.2.2):**

*[Stimulus: Photograph and cross-section diagram of sandstone layers at Arches National Park showing the Entrada Sandstone formation]*

Which geological process BEST explains the formation of the natural arches at Arches National Park?

A. Volcanic activity pushing molten rock through sandstone layers
B. Differential erosion of softer rock layers beneath harder caprock, combined with frost wedging
C. Tectonic plate collision folding the sandstone into arch shapes
D. Ancient rivers carving tunnels through solid rock

*Correct Answer: B*
*Alignment: UT.HS.2.2 | DOK 2*

### Multi-Select (MS)

```
+----------------------------------------------------------+
|  MULTI-SELECT — 1 point                                   |
|                                                           |
|  5–7 options; select 2 or more correct answers            |
|  Stimulus-dependent                                       |
|  Machine scored                                           |
|  DOK 2–3                                                  |
+----------------------------------------------------------+
```

**MS Example (Grade 8, DOK 2, UT.8.2.7):**

*[Stimulus: Data table showing Great Salt Lake water levels, surface area, and average air temperature from 1985–2023]*

Select TWO conclusions that are supported by the data in the table.

A. Great Salt Lake's surface area has remained stable over the past 40 years
B. As average air temperature has increased, Great Salt Lake water levels have generally decreased
C. The lake's water level is primarily controlled by tectonic activity
D. There is a correlation between declining water levels and reduced surface area
E. Great Salt Lake will disappear entirely within 10 years

*Correct Answers: B, D*
*Alignment: UT.8.2.7 | DOK 2*

### Constructed Response (CR)

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE — 0–2 points                        |
|                                                           |
|  Evidence-based written explanation                       |
|  Must reference data, diagrams, or investigation results  |
|  Human scored using CR rubric                             |
|  DOK 3                                                    |
+----------------------------------------------------------+
```

**CR Example (Grade 11, DOK 3, UT.HS.2.5):**

Using the data provided, explain how mining activity in Utah has affected local water systems. Reference specific data values from the table to support your explanation, and suggest one engineering solution that could reduce the environmental impact.

## 7. Scientific Investigation Design

### Investigation Components Assessed

| Component | Description | Example |
|---|---|---|
| **Testable Question** | Identify or formulate a question that can be investigated | "How does salinity affect the buoyancy of objects in Great Salt Lake?" |
| **Variables** | Identify independent, dependent, and controlled variables | IV: salinity level; DV: buoyancy force; CV: object mass, water temperature |
| **Procedure** | Evaluate or design a step-by-step investigation plan | Multiple trials, single variable changed, appropriate tools |
| **Data Collection** | Select appropriate tools and methods for gathering data | Graduated cylinder for volume; scale for mass; salinity meter |
| **Data Analysis** | Interpret tables, graphs, and charts to identify patterns | "The graph shows that as salinity increased, buoyancy force increased" |
| **Conclusions** | Draw evidence-based conclusions; identify limitations | "The data supports the hypothesis because..." |

### Stimulus Types

| Stimulus | Description | Use |
|---|---|---|
| **Data table** | Organized numerical data from an investigation | Data interpretation, pattern identification, prediction |
| **Graph** | Bar graph, line graph, scatter plot | Trend analysis, comparison, correlation |
| **Diagram** | System model, food web, geological cross-section, anatomical structure | Model interpretation, process identification |
| **Investigation scenario** | Description of a student conducting an experiment | Variable identification, procedure evaluation, conclusion drawing |
| **Phenomenon description** | Real-world Utah phenomenon requiring scientific explanation | Explanation construction, evidence-based reasoning |

## 8. Scoring Rubrics

### Constructed Response (CR) Rubric — 0–2 Points

| Score | Criteria |
|---|---|
| 2 | Response accurately interprets or applies the science concept. References specific data, evidence, or values from the provided stimulus. Explanation is clear, logically connected, and demonstrates understanding of the underlying scientific principle. |
| 1 | Response shows partial understanding. Data referenced but not precisely used, OR explanation is accurate but lacks reference to stimulus data. |
| 0 | Response is incorrect, does not address the science concept, is insufficient in length, or is blank. |

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] Utah SEEd Standard code verified as correct for the targeted grade (5, 8, or 11 only)
- [ ] Item is stimulus-dependent (tied to data, diagram, model, or investigation scenario)
- [ ] Three-dimensional: item integrates a practice, crosscutting concept, and core idea
- [ ] CR prompt requires evidence-based explanation referencing specific data or observations
- [ ] SR distractors reflect authentic science misconceptions
- [ ] MS items have exactly the specified number of correct answers
- [ ] TE items have clear interaction instructions and unambiguous correct responses
- [ ] Stimulus data is scientifically accurate and grade-appropriate
- [ ] Utah context incorporated where appropriate (ecology, geology, climate)
- [ ] DOK level matches the cognitive demand of the item and standard

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Items at non-tested grades | RISE Science is only at Grades 5, 8, and 11 | Verify grade before generating items |
| Standalone recall items | RISE Science emphasizes three-dimensional assessment | Embed items in phenomenon-based or data-based stimuli |
| CR without data reference | CR should require specific evidence from stimulus | Include "use specific data/evidence" in every CR prompt |
| Scientifically inaccurate stimuli | Data and scenarios must be realistic | Verify all scientific claims and data values |
| Missing crosscutting concepts | Utah SEEd standards require three-dimensional alignment | Identify the crosscutting concept addressed by each item |
| Using NGSS codes instead of Utah SEEd codes | RISE Science uses Utah SEEd Standards | Reference UT science standard codes exclusively |

## 12. Prompt Patterns

### Pattern 1: Data Interpretation (SR, DOK 2)
> "Based on the data in the [table / graph], which [conclusion / pattern / trend] is BEST supported?"

### Pattern 2: Investigation Design (SR, DOK 2–3)
> "A student wants to investigate [Utah-relevant question]. Which experimental setup would BEST allow the student to test this hypothesis?"

### Pattern 3: Cause and Effect (SR, DOK 2)
> "If [variable or condition changes] in this [ecosystem / system / investigation], what would MOST LIKELY happen to [outcome]?"

### Pattern 4: Ecosystem Analysis (SR or CR, DOK 2–3)
> "[Great Salt Lake / Utah ecosystem] diagram shows [food web / interactions]. If [organism / factor] were removed or changed, what would MOST LIKELY happen to [other organism / population]? Use evidence from the [diagram / data] to explain."

### Pattern 5: Model Interpretation (SR or TE, DOK 2)
> "The model shows [process / system / cycle]. Which [label / arrow / component] BEST represents [specific process or interaction]?"

### Pattern 6: Evidence-Based Explanation (CR, DOK 3)
> "Using the data in the [table / graph], explain [science pattern or relationship]. Use specific [values / evidence] from the [data / graph] in your explanation."
