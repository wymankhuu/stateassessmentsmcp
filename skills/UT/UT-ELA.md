> **KEY NOTE:** RISE ELA is Utah's adaptation of the Smarter Balanced Assessment (SBAC) framework. It assesses Utah Core Standards for ELA across Grades 3–8 and Grade 11. Grade 11 serves as the high school accountability grade. The assessment uses computer-adaptive technology for selected-response sections.

### Performance Levels

| Level | Label | Description |
|---|---|---|
| 4 | **Highly Proficient** | Demonstrates thorough understanding; applies advanced ELA skills to complex texts and tasks |
| 3 | **Proficient** | Demonstrates adequate understanding of grade-level ELA standards |
| 2 | **Partially Proficient** | Demonstrates partial understanding; needs additional support to meet grade-level expectations |
| 1 | **Minimally Proficient** | Demonstrates minimal understanding; significant gaps in ELA knowledge and skills |

> **Item-writing target:** "Proficient" performance. Items should require genuine application of Utah Core Standards at the expected DOK level — not mere recall.

## 2. Standards Framework

> RISE ELA is aligned to the **Utah Core Standards for English Language Arts**, which are closely aligned with the Common Core State Standards (CCSS) for ELA. The standards emphasize close reading, text-based evidence, and analytical writing.

### Utah ELA Standards Strands

| Strand | Focus | Grade Emphasis |
|---|---|---|
| **Reading — Literature** | Comprehension of literary texts; analysis of craft, structure, theme | All grades |
| **Reading — Informational Text** | Comprehension of informational texts; argument analysis; text structure | All grades |
| **Writing** | Narrative, informational, and argumentative writing; writing process | All grades; assessed via CR |
| **Language** | Grammar, conventions, vocabulary acquisition and use | All grades |

## 3. Test Structure

RISE ELA uses a computer-adaptive format for selected-response items, with fixed-form constructed-response components. Items are passage-based, with students reading passages and answering associated items.

```
+------------------------------------------------------------------+
|            RISE ELA STRUCTURE (Grades 3–8, 11)                    |
+------------------------------------------------------------------+
|  COMPUTER-ADAPTIVE TEST — Approximately 3–4 hours (untimed)      |
|  Computer-Based                                                   |
|                                                                   |
|  SECTION 1: READING COMPREHENSION (CAT)                           |
|  +----------------------------------------+                      |
|  | Passage Set 1 (Literary) -> SR + MS + EBSR items |             |
|  | Passage Set 2 (Informational) -> SR + MS + EBSR  |             |
|  | Passage Set 3 (Literary or Paired) -> SR + MS + EBSR |         |
|  | Passage Set 4 (Informational) -> SR + MS + EBSR  |             |
|  +----------------------------------------+                      |
|                                                                   |
|  SECTION 2: WRITING / CONSTRUCTED RESPONSE                        |
|  +----------------------------------------+                      |
|  | CR items tied to passages (0–2 or 0–4 pts) |                   |
|  | (Text-dependent analysis prompts)           |                   |
|  +----------------------------------------+                      |
+------------------------------------------------------------------+
```

## 5. Item Types & Formats

### Selected Response (SR)

```
+----------------------------------------------------------+
|  SELECTED RESPONSE — 1 point                              |
|                                                           |
|  4 options (A, B, C, D)                                   |
|  Always passage-dependent                                 |
|  Machine scored                                           |
|  DOK 1–3                                                  |
+----------------------------------------------------------+
```

**SR Example (Grade 7 Literary, DOK 3, UT.ELA.7.RL.4):**

*[After reading a short story set near Great Salt Lake]*

Read this sentence from paragraph 4: *"The lake stretched out like a mirror made of salt, reflecting nothing but the emptiness of the sky and the weight of her own longing."*

What effect does the author's use of figurative language create in this sentence?

A. It shows that the character enjoys visiting the lake
B. It emphasizes the character's isolation and emotional heaviness through the barren landscape
C. It suggests the lake is polluted and unappealing
D. It implies the character is lost and cannot find her way home

*Correct Answer: B*
*Alignment: UT.ELA.7.RL.4 | DOK 3*

---

**SR Example (Grade 5 Informational, DOK 2, UT.ELA.5.RI.2):**

*[After reading an article about Arches National Park]*

What is the central idea of this article?

A. Arches National Park is the most popular park in Utah
B. The unique sandstone arches were formed over millions of years through natural processes of erosion and weathering
C. Delicate Arch is the largest natural stone arch in the world
D. Visitors should be careful not to touch the arches because they are fragile

*Correct Answer: B*
*Alignment: UT.ELA.5.RI.2 | DOK 2*

---

### Multi-Select (MS)

```
+----------------------------------------------------------+
|  MULTI-SELECT — 1 point                                   |
|                                                           |
|  5–7 options; select 2 or more correct answers            |
|  Passage-dependent                                        |
|  Machine scored                                           |
|  DOK 2–3                                                  |
+----------------------------------------------------------+
```

**MS Example (Grade 8 Informational, DOK 2, UT.ELA.8.RI.1):**

*[After reading an article about the history of Mormon pioneers settling in Utah]*

Select TWO details from the article that support the author's claim that the pioneers demonstrated remarkable determination.

A. The pioneers traveled more than 1,300 miles from Illinois to the Salt Lake Valley
B. Brigham Young was the leader of the Church of Jesus Christ of Latter-day Saints
C. The pioneers built an extensive irrigation system in the arid Salt Lake Valley within their first year
D. Utah became a U.S. territory in 1850
E. The first transcontinental railroad was completed at Promontory Summit in 1869

*Correct Answers: A, C*
*Alignment: UT.ELA.8.RI.1 | DOK 2*

---

### Evidence-Based Selected Response (EBSR)

```
+----------------------------------------------------------+
|  EVIDENCE-BASED SELECTED RESPONSE — 2 points              |
|                                                           |
|  Two-part item: Part A (inference/conclusion) +           |
|  Part B (select evidence that supports Part A)            |
|  Passage-dependent                                        |
|  Machine scored                                           |
|  DOK 2–3                                                  |
+----------------------------------------------------------+
```

**EBSR Example (Grade 6 Literary, DOK 3, UT.ELA.6.RL.3):**

*[After reading a story about a family visiting the Wasatch Mountains]*

**Part A:** How does the main character's attitude toward hiking change over the course of the story?

A. She becomes more frightened as the trail gets steeper
B. She starts reluctantly but gains confidence and appreciation for the mountains
C. She remains enthusiastic throughout the entire hike
D. She becomes angry at her family for making her go

**Part B:** Which sentence from the story BEST supports your answer to Part A?

A. "'I don't see why we can't just stay at the hotel,' Maya muttered as they started up the trail."
B. "The trail marker said 'Summit: 2.5 miles,' and Maya picked up her pace."
C. "Her brother had been hiking these trails since he was five years old."
D. "The parking lot was already full when they arrived at the trailhead."

*Correct Answers: Part A: B; Part B: A*
*Alignment: UT.ELA.6.RL.3 | DOK 3*

### Constructed Response (CR)

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE — 0–2 points or 0–4 points          |
|                                                           |
|  Text-dependent analysis response                         |
|  Short CR: 2–5 sentences (0–2 pts)                        |
|  Extended CR: multi-paragraph (0–4 pts)                   |
|  Must reference textual evidence                          |
|  Human scored using CR rubric                             |
|  DOK 3–4                                                  |
+----------------------------------------------------------+
```

**CR Example (Grade 11 Literary, DOK 3, UT.ELA.11.RL.2 — 0–4 point extended):**

*[After reading a short story set in a Utah mining town]*

Analyze how the author develops the theme of perseverance in this story. In your response, identify at least two literary devices or narrative techniques the author uses and explain how each contributes to the development of the theme. Support your analysis with specific evidence from the text.

## 6. Depth of Knowledge (DOK)

| DOK | Label | ELA Application Examples |
|---|---|---|
| 1 | Recall | Identify explicit information stated in the text; define a vocabulary word using context clues; name the narrator's point of view |
| 2 | Skills & Concepts | Infer a character's motivation from textual evidence; identify the author's purpose; explain how a detail supports the main idea; determine word meaning using context |
| 3 | Strategic Thinking | Analyze how the author uses figurative language to develop tone or theme; evaluate the strength of an argument; compare perspectives across two texts; synthesize ideas from multiple sections |
| 4 | Extended Thinking | (Assessed through extended CR tasks requiring multi-paragraph analysis with evidence integration across multiple texts or sections) |

## 8. Scoring Rubrics

### Constructed Response (CR) Rubric — 0–2 Points (Short)

| Score | Criteria |
|---|---|
| 2 | Response provides an accurate, thorough analysis that addresses all parts of the question. Includes relevant, correctly-used textual evidence (quoted or paraphrased) that directly supports the analysis. Demonstrates clear understanding of the standard being assessed. |
| 1 | Response provides a partially accurate analysis. OR Response is accurate but lacks sufficient or directly relevant textual evidence. OR Response addresses only part of the question. |
| 0 | Response is inaccurate, irrelevant, too brief to evaluate, or blank. |

### Constructed Response (CR) Rubric — 0–4 Points (Extended)

| Score | Criteria |
|---|---|
| 4 | Response provides a thorough, insightful analysis that fully addresses all parts of the prompt. Integrates well-chosen, specific textual evidence throughout. Demonstrates sophisticated understanding of craft, structure, or argument. Writing is clear, organized, and uses precise academic language. |
| 3 | Response provides an adequate analysis that addresses the prompt. Includes relevant textual evidence that supports the analysis. Demonstrates solid understanding. Writing is clear and organized. |
| 2 | Response provides a partial analysis. Textual evidence is present but may be general or imprecise. Demonstrates basic understanding but may miss key elements. Writing may lack clarity or organization. |
| 1 | Response attempts the task but demonstrates minimal analysis. Textual evidence is absent or incorrectly used. Writing is unclear or disorganized. |
| 0 | Response is inaccurate, irrelevant, too brief to evaluate, or blank. |

### EBSR Rubric — 2 Points

| Score | Criteria |
|---|---|
| 2 | Both Part A and Part B are correct. |
| 1 | Part A is correct but Part B is incorrect, OR Part A is incorrect but Part B correctly identifies evidence for Part A's correct answer. |
| 0 | Both parts are incorrect or blank. |

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] Utah Core Standard code verified as correct for the targeted grade
- [ ] All items are passage-dependent (no standalone general knowledge questions)
- [ ] CR prompts require textual evidence (not just prior knowledge)
- [ ] SR distractors represent authentic misconceptions, not obviously wrong answers
- [ ] MS items have exactly the specified number of correct answers
- [ ] EBSR Part B evidence directly supports the correct Part A answer
- [ ] Lexile of passage matches the grade-level range
- [ ] Passage length appropriate (400–1,000 words for comprehension passages)
- [ ] Utah context incorporated where appropriate (geography, history, culture)
- [ ] DOK level matches the cognitive demand specified in the standard

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Items not tied to a passage | RISE ELA items must be passage-dependent | Always tie SR, MS, EBSR, and CR to a specific stimulus |
| CR prompt that only tests recall | CR should require DOK 3+ analysis with evidence | Include "using evidence from the text" in every CR prompt |
| EBSR Part B evidence misaligned | Part B must support the CORRECT answer to Part A | Pre-validate that Part B evidence maps to Part A key |
| Extended CR scored on 0–2 scale | Extended CR uses 0–4 rubric | Verify rubric matches item type |
| MS items with ambiguous correct answers | All correct and incorrect answers must be clearly defensible | Pre-validate each option against the passage |
| Using CCSS codes instead of Utah codes | RISE uses Utah Core Standards | Reference UT.ELA codes exclusively |

## 12. Prompt Patterns

### Pattern 1: Craft & Language Analysis (SR, DOK 3)
> "Read [line reference / paragraph reference]. What effect does the author's use of [figurative language / imagery / word choice / structure] create in this [sentence / paragraph / passage]?"

### Pattern 2: Central Idea and Evidence (SR or CR, DOK 2–3)
> "What is the [central idea / theme] of this [passage / article]? [How does the author develop this idea using specific details?]"

### Pattern 3: Author's Purpose / Argument (SR or CR, DOK 2–3)
> "What is the author's [main purpose / central argument] in this [article / essay]? How does the author [support / develop] this [purpose / argument]? Use evidence from the text."

### Pattern 4: Evidence Selection (MS, DOK 2)
> "Select [TWO / THREE] details from the [passage / article] that BEST support [claim / central idea / inference]."

### Pattern 5: Evidence-Based Two-Part (EBSR, DOK 2–3)
> "Part A: [Inference / conclusion question]. Part B: Which [sentence / detail] from the [passage] BEST supports your answer to Part A?"

### Pattern 6: Vocabulary in Context (SR, DOK 2)
> "As used in paragraph [#], what does the word [WORD] most likely mean?"

### Pattern 7: Extended Analysis (CR 0–4, DOK 3–4)
> "Analyze how [the author develops / the text explores] [theme / argument / character]. In your response, [identify techniques / compare perspectives / evaluate effectiveness]. Support your analysis with specific evidence from the text."
