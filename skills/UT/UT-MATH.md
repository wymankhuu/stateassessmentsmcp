## 2. Standards Framework

> RISE Mathematics is aligned to the **Utah Core Standards for Mathematics**, which are closely aligned with the Common Core State Standards (CCSS) for Mathematics. The standards emphasize conceptual understanding, procedural fluency, and application.

### Utah Mathematics Standards — Key Domains by Grade

| Domain | Description | Grade Band |
|---|---|---|
| **Operations & Algebraic Thinking** | Represent and solve problems; understand properties of operations | 3–5 |
| **Number & Operations — Base Ten** | Place value understanding; multi-digit arithmetic | 3–5 |
| **Number & Operations — Fractions** | Fraction concepts; fraction arithmetic | 3–5 |
| **Ratios & Proportional Relationships** | Understand ratios; use proportional reasoning | 6–7 |
| **The Number System** | Rational numbers; integer operations | 6–8 |
| **Expressions & Equations** | Algebraic expressions; linear equations and inequalities | 6–8 |
| **Geometry** | Shape properties; area; volume; coordinate geometry; transformations | 3–8, 11 |
| **Statistics & Probability** | Data analysis; probability; statistical inference | 6–8, 11 |
| **Functions** | Define, evaluate, and compare functions; model relationships | 8, 11 |
| **Number & Quantity** | Extend properties of exponents; rational and irrational numbers | 11 |
| **Algebra** | Seeing structure in expressions; creating equations; reasoning | 11 |

## 5. Item Types & Formats

### Selected Response (SR)

```
+----------------------------------------------------------+
|  SELECTED RESPONSE — 1 point                              |
|                                                           |
|  4 options (A, B, C, D)                                   |
|  May include real-world context or stimulus               |
|  Machine scored                                           |
|  DOK 1–3                                                  |
+----------------------------------------------------------+
```

**SR Example (Grade 6, DOK 2, UT.Math.6.RP.3):**

Great Salt Lake's salinity is approximately 12% in its southern arm. If a researcher collects a 500-gram water sample, how many grams of salt are in the sample?

A. 12
B. 42
C. 60
D. 120

*Correct Answer: C*
*Alignment: UT.Math.6.RP.3 | DOK 2*

---

**SR Example (Grade 11, DOK 2, UT.Math.11.A-REI.4):**

A ski resort in the Wasatch Mountains models its daily revenue R (in thousands of dollars) based on the temperature t (in degrees Fahrenheit) using the equation R = -0.5t^2 + 20t - 150. At what temperatures does the resort break even (R = 0)?

A. t = 10 and t = 30
B. t = 15 and t = 20
C. t = 5 and t = 35
D. t = 10 and t = 20

*Correct Answer: A*
*Alignment: UT.Math.11.A-REI.4 | DOK 2*

### Performance Task — Extended Response (PT-ER)

```
+----------------------------------------------------------+
|  PERFORMANCE TASK EXTENDED RESPONSE — 0–6 points          |
|                                                           |
|  Multi-step, real-world application                       |
|  Requires modeling, computation, and explanation           |
|  Human scored using PT-ER rubric                          |
|  DOK 3–4                                                  |
+----------------------------------------------------------+
```

**PT-ER Example (Grade 11, DOK 3, UT.Math.11.S-ID.6):**

A researcher is studying the relationship between Great Salt Lake's water level (in feet above sea level) and salinity (in percent) over a 30-year period. The data is provided in the table.

Part A: Create a scatter plot of the data and describe the correlation.
Part B: Write an equation for the line of best fit.
Part C: Using your model, predict the salinity if the water level drops to 4,190 feet. Explain whether your prediction is reasonable and identify any limitations of your model.

## 8. Scoring Rubrics

### Short Constructed Response (SCR) Rubric — 0–2 Points

| Score | Criteria |
|---|---|
| 2 | Work clearly shows a correct mathematical process. Answer is correct. Explanation (if required) demonstrates understanding of the mathematical concept and uses appropriate mathematical vocabulary. |
| 1 | Work shows understanding of the mathematical concept but contains a minor computational error. OR Correct answer is given without a clear explanation of the process. |
| 0 | Work shows no understanding of the mathematical concept, or response is blank. |

### Performance Task Extended Response (PT-ER) Rubric — 0–6 Points

| Score | Criteria |
|---|---|
| 6 | All parts answered correctly with thorough explanations. Mathematical modeling is accurate and clearly communicated. Justification demonstrates deep conceptual understanding. |
| 5 | Nearly all parts correct with clear explanations. Minor error in one part that does not affect overall reasoning. |
| 4 | Most parts answered correctly. Explanations are adequate but may lack precision. Modeling approach is sound with minor errors. |
| 3 | Some parts correct. Shows understanding of the general approach but contains errors in execution or explanation. |
| 2 | Limited correct work. Shows partial understanding of the problem but significant errors in process or reasoning. |
| 1 | Minimal relevant work shown. Demonstrates limited understanding of the mathematical concepts required. |
| 0 | No relevant mathematical work, or response is blank. |

## 10. Contextualization — Utah Mathematics

When generating items and contexts, prioritize authentic Utah settings:

### Utah Context Guide

| Context | Mathematical Application | Grade Band |
|---|---|---|
| Great Salt Lake salinity data (12–27% depending on arm; declining water levels) | Percent, ratios, data analysis, linear models, scatter plots | 5–11 |
| Arches National Park measurements (2,000+ arches; spans from 3 ft to 306 ft) | Measurement, ratios, data analysis, statistics | 3–8 |
| Utah ski resort elevation data (base/summit elevations; vertical drops of 2,000–3,000 ft) | Measurement, slope, linear functions, data comparison | 5–11 |
| Bonneville Salt Flats speed records (land speed record: 763 mph; race distances) | Rate, unit conversion, distance/time, linear and non-linear models | 6–11 |
| Wasatch Mountains elevation profiles (peaks 10,000–12,000 ft) | Slope, rate of change, functions, data analysis | 6–11 |
| Great Salt Lake brine shrimp harvest (millions of pounds annually) | Multiplication, ratios, unit rates | 3–7 |
| Utah population growth (Salt Lake City metro area) | Percent change, exponential growth, statistics | 6–11 |
| Zion National Park canyon dimensions (2,000 ft deep; 15 mi long) | Measurement, ratios, scale, proportional reasoning | 4–8 |
| Utah solar and wind energy production | Linear and exponential models, statistics | 8–11 |
| Utah highway distances (Salt Lake City to various destinations) | Addition, multiplication, rate, distance/time | 3–6 |

### Suggested Problem Contexts by Grade

**Grades 3–4:**
- Counting arches at Arches National Park; grouping and multiplication
- Measuring trail distances at Zion National Park

**Grades 5–6:**
- Calculating salinity percentages in Great Salt Lake water samples
- Ratio and proportion problems using Utah ski resort data

**Grades 7–8:**
- Analyzing the relationship between elevation and snowfall at Utah resorts
- Proportional reasoning with Bonneville Salt Flats speed and distance data

**Grade 11:**
- Modeling Great Salt Lake water level decline with linear regression
- Statistical analysis of Utah ski resort visitor data across seasons

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] Utah Core Standard code verified as correct for the targeted grade and domain
- [ ] Real-world context is mathematically accurate and grade-appropriate
- [ ] Computation is error-free; answer key verified
- [ ] Distractors reflect authentic student misconceptions or common computational errors
- [ ] EQ response format is clearly specified (numeric entry, equation, fraction)
- [ ] SCR prompt requires multi-step reasoning and/or explanation
- [ ] PT-ER includes multiple parts with increasing complexity
- [ ] Calculator policy is correctly applied per grade level
- [ ] Utah context incorporated where appropriate
- [ ] DOK level matches the cognitive demand of the item

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Context-free computation | RISE emphasizes application and modeling | Embed problems in real-world Utah contexts |
| SCR that only requires computation | SCR should require explanation or justification at DOK 3 | Include "show your work and explain" in SCR prompts |
| PT-ER with only one step | PT-ER items must be multi-part with increasing complexity | Ensure Part A/B/C structure with scaffolded difficulty |
| Unrealistic numerical values | Context must be mathematically plausible | Verify that numbers make sense in the given scenario |
| Calculator-required item in non-calculator section | Calculator policy varies by grade and section | Clearly designate calculator availability per item |
| Using CCSS codes instead of Utah codes | RISE uses Utah Core Standards | Reference UT.Math codes exclusively |

## 12. Prompt Patterns

### Pattern 1: Real-World Computation (SR, DOK 2)
> "[Utah context with quantities]. [Question requiring computation]. What is the [result / total / difference]?"

### Pattern 2: Multiple Representations (SR or EQ, DOK 2)
> "A [table / graph / equation] shows [relationship]. Which [other representation / statement] represents the SAME relationship?"

### Pattern 3: Justify and Explain (SCR, DOK 3)
> "[Multi-step Utah context problem]. Show your work and explain how you found your answer."

### Pattern 4: Data Interpretation (SR or SCR, DOK 2–3)
> "The [table / graph / chart] shows [Utah data context]. Based on the data, [what is the rate of change / which conclusion / what prediction] is BEST supported?"

### Pattern 5: Performance Task — Multi-Part Modeling (PT-ER, DOK 3–4)
> "Part A: [Analyze data / compute]. Part B: [Write equation / create model]. Part C: [Predict / justify / evaluate limitations]."

### Pattern 6: Geometric Reasoning (SR or EQ, DOK 2–3)
> "[Utah context involving measurement or shape]. What is the [area / volume / perimeter / angle measure]?"
