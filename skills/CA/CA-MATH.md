## 1. Overview

| Field | Detail |
|---|---|
| **Assessment Name** | California Assessment of Student Performance and Progress (CAASPP) — Mathematics |
| **Consortium** | Smarter Balanced Assessment Consortium (SBAC) |
| **Vendor** | Educational Testing Service (ETS) |
| **Grades Tested** | 3, 4, 5, 6, 7, 8, 11 |
| **Testing Window** | April – June (operational window; schools schedule within this range) |
| **Delivery** | Computer-adaptive (CAT) for Part 1 (non-calculator + calculator); fixed-form Performance Task for Part 2 |
| **Standards** | Common Core State Standards for Mathematics (CCSS-M); California additions appended |
| **Score Scale** | 2000–3000 scale score (varies by grade) |
| **Reporting** | Individual Student Report (ISR); School, District, County, State aggregate reports |

### Achievement Level Descriptors (ALDs)

| Level | Label | Description |
|---|---|---|
| 4 | **Standard Exceeded** | Student demonstrates sophisticated understanding of mathematical concepts and procedures; applies mathematics fluently in novel situations; constructs valid mathematical arguments; evaluates and critiques the reasoning of others |
| 3 | **Standard Met** | Student demonstrates adequate understanding of grade-level concepts and procedures; applies mathematics to real-world and mathematical problems with reasonable accuracy; can explain mathematical reasoning |
| 2 | **Standard Nearly Met** | Student demonstrates partial understanding; can apply procedures in familiar contexts but struggles with novel problems; mathematical explanations are incomplete or sometimes inaccurate |
| 1 | **Standard Not Met** | Student demonstrates minimal understanding; significant conceptual and procedural gaps; unable to apply mathematics beyond the most basic recall tasks |

> **Cut scores** are set by the Smarter Balanced Assessment Consortium and adopted by the California State Board of Education. Items should target the transition zone between Level 2 and Level 3 (approaching proficiency) and between Level 3 and Level 4 (exceeding proficiency) to maximize diagnostic value.

## 2. Standards Framework

> CAASPP Mathematics is built on CCSS Mathematics. California adopted CCSS Math with minor additions (California-specific standards designated with a (+) or (CA) suffix in official documents). For item writing, default to standard CCSS Math progressions.

### Elementary Grades (3–5) — Domain Overview

| Domain | Code | Grade 3 | Grade 4 | Grade 5 |
|---|---|---|---|---|
| **Operations & Algebraic Thinking** | OA | Multiplication/division up to 100; properties; solve problems | Factors, multiples, patterns | Write/interpret expressions; analyze patterns |
| **Number & Operations in Base Ten** | NBT | Round, add, subtract multi-digit; multiply 1-digit × multi-digit | Multi-digit multiplication; division with remainders | Decimals to thousandths; multi-digit × and ÷ |
| **Number & Operations — Fractions** | NF | Fractions as numbers; compare fractions | Fraction equivalence; add/subtract fractions; multiply fraction × whole | Add/subtract fractions; multiply fractions; divide unit fractions |
| **Measurement & Data** | MD | Time, volume, mass; bar graphs, pictographs; area, perimeter | Units of measure; area/perimeter; line plots; angles | Convert units; volume; line plots |
| **Geometry** | G | Shapes and their attributes; partition shapes | Lines, angles, symmetry; classify shapes | Coordinate plane; classify shapes by properties |

### Middle Grades (6–8) — Domain Overview

| Domain | Code | Grade 6 | Grade 7 | Grade 8 |
|---|---|---|---|---|
| **Ratios & Proportional Relationships** | RP | Ratios; rates; unit rates; percent | Proportional relationships; percent problems | — (transitions to functions) |
| **The Number System** | NS | Division of fractions; rational numbers on number line | Add/subtract/multiply/divide rational numbers | Irrational numbers; approximating square roots |
| **Expressions & Equations** | EE | Algebraic expressions; one-variable equations and inequalities | Equivalent expressions; linear equations; solve problems | Linear equations; simultaneous equations; slope |
| **Functions** | F | — | — | Define and compare functions; linear vs. non-linear |
| **Geometry** | G | Area, surface area, volume; nets | Scale drawings; circles; area/circumference; 3D shapes | Pythagorean Theorem; volume of cylinders, cones, spheres; transformations; congruence and similarity |
| **Statistics & Probability** | SP | Statistical variability; distributions; summarize data | Random sampling; comparative inferences; probability | Scatter plots; bivariate data; two-way tables; linear models |

### High School (Grade 11) — Domain Overview

Grade 11 on CAASPP draws from the Integrated Pathway (Integrated Math I–III) or Traditional Pathway (Algebra I, Geometry, Algebra II) per the California Mathematics Framework. Items are drawn from these conceptual clusters:

| Conceptual Category | Key Topics |
|---|---|
| **Number & Quantity** | Extending number systems; complex numbers; vector and matrix quantities |
| **Algebra** | Seeing structure in expressions; arithmetic with polynomials; creating and reasoning with equations; function notation |
| **Functions** | Interpreting, building, and modeling with functions; linear, quadratic, exponential, trigonometric |
| **Geometry** | Congruence; similarity; right triangles; trigonometry; circles; modeling with geometry |
| **Statistics & Probability** | Interpreting data; making inferences; probability and randomness; using probability to make decisions |

### Key California-Specific Additions

| Addition | Grade | Description |
|---|---|---|
| **3.OA.D.9 (CA)** | 3 | Identify arithmetic patterns including patterns in addition/multiplication tables |
| **6.NS.7c (CA)** | 6 | Understand the absolute value of a rational number as its distance from 0 |
| **Algebra I course standards** | 8/9 | California offers Algebra I at Grade 8; CAASPP Gr 8 can include Algebra I-level items for students enrolled in that course |

## 4. Claims & Blueprint

### Claim Structure

| Claim | Description | Point Weight | Primary Focus |
|---|---|---|---|
| **Claim 1 — Concepts & Procedures** | Students can explain and apply mathematical concepts and carry out mathematical procedures with precision and fluency | **40%** | Procedural fluency; conceptual understanding of grade-level math |
| **Claim 2 — Problem Solving** | Students can solve a range of complex well-posed problems in pure and applied mathematics, making productive use of knowledge and problem-solving strategies | **25%** | Multi-step problems; strategy selection; real-world contexts |
| **Claim 3 — Communicating Reasoning** | Students can clearly and precisely construct viable arguments to support their own reasoning and to critique the reasoning of others | **20%** | Explanation; justification; error analysis; proof |
| **Claim 4 — Modeling & Data Analysis** | Students can analyze complex, real-world scenarios and can construct and use mathematical models to interpret and solve problems | **15%** | Mathematical modeling; data interpretation; multi-step real-world scenarios |

## 5. Item Types & Formats

### SR — Selected Response (1 point)

Standard four-option multiple-choice. Student selects one best answer.

```
┌─────────────────────────────────────────────────────────────────┐
│  [Stimulus: problem context, diagram, table, or equation]       │
│                                                                 │
│  Question stem targeting a specific standard and claim.         │
│                                                                 │
│  ○  A. [Numerical / expression answer — plausible distractor]   │
│  ○  B. [Numerical / expression answer — common error]           │
│  ○  C. [Numerical / expression answer — CORRECT]                │
│  ○  D. [Numerical / expression answer — off-track distractor]   │
└─────────────────────────────────────────────────────────────────┘
Points: 1 (correct) / 0 (incorrect)
```

**Construction Rules:**
- Distractors must reflect real student errors (e.g., computational errors, conceptual mistakes, operation errors)
- Numerical answers should not reveal the correct answer through magnitude ordering
- Avoid answer options that are obviously not in the ballpark
- Diagrams and tables must be clearly labeled and drawn to reasonable scale

---

### MS — Multi-Select (1 point)

Student selects ALL correct answers from a set of five or six options. Full credit only when all correct options are selected and no incorrect options are selected.

```
┌─────────────────────────────────────────────────────────────────┐
│  [Problem context or mathematical statement]                    │
│                                                                 │
│  Select the TWO [equations / values / expressions] that...     │
│                                                                 │
│  ☐  A. [Option]                                                 │
│  ☐  B. [Option — CORRECT]                                       │
│  ☐  C. [Option]                                                 │
│  ☐  D. [Option — CORRECT]                                       │
│  ☐  E. [Option]                                                 │
│  ☐  F. [Option]                                                 │
└─────────────────────────────────────────────────────────────────┘
Points: 1 (all correct, none incorrect) / 0 (any error)
```

**Construction Rules:**
- Specify the count in the stem when it is fixed ("Select the TWO...")
- Use "Select ALL that apply" when count is variable
- Typically 2–3 correct answers from 5–6 options
- Common use cases: identify all equivalent fractions, select all true equations, identify all figures with a given property

---

### EQ — Equation / Numeric Entry (1 point)

Student types a number, expression, or short equation into a response box. No choices are provided. May include a fraction template, exponent entry, or simple expression builder.

```
┌─────────────────────────────────────────────────────────────────┐
│  [Problem context: real-world scenario or pure math]            │
│                                                                 │
│  What is the value of [EXPRESSION / VARIABLE / QUANTITY]?      │
│                                                                 │
│  Enter your answer in the box.                                  │
│  ┌───────────────┐                                              │
│  │               │  [numeric / expression entry field]         │
│  └───────────────┘                                              │
│                                                                 │
│  [Unit label if applicable: "miles", "square feet", etc.]       │
└─────────────────────────────────────────────────────────────────┘
Points: 1 (exact correct value or equivalent expression) / 0
```

**Construction Rules:**
- Clearly state the expected form of the answer (whole number, decimal, fraction, simplified expression)
- Specify units in the item when applicable; include unit label adjacent to the entry box
- For fraction entries, provide the fraction entry tool (numerator/denominator boxes)
- Answers should be unique (no ambiguous correct answers); avoid prompts where multiple equivalent forms might cause scoring issues unless the system accepts all equivalents
- Specify significant figures or rounding rules when relevant (e.g., "Round to the nearest tenth")

### SCR — Short Constructed Response (0–2 points)

Student writes a brief explanation or solution — usually 1–4 sentences plus work shown — in a text/scratchpad area. Scored holistically 0–2.

```
┌─────────────────────────────────────────────────────────────────┐
│  [Problem context — multi-step real-world scenario]             │
│                                                                 │
│  [PART A — Computational or procedural question]                │
│  [PART B — "Explain how you know" or "Show your work"]          │
│                                                                 │
│  ┌─────────────────────────────────────────────────────────┐    │
│  │                                                         │    │
│  │  [Student response area — text input + scratchpad]      │    │
│  │                                                         │    │
│  └─────────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────────┘
Points: 0–2 (see rubric, Section 8)
```

**Construction Rules:**
- Prompt must clearly ask for both an answer AND an explanation/justification
- Avoid prompts with a single correct numerical answer unless explanation is the primary target
- Identify the claim: SCR is most appropriate for Claim 3 (Communicating Reasoning) or Claim 2 (Problem Solving)
- The problem context should be accessible but require non-trivial mathematical reasoning

### PT-ER — Performance Task Extended Response (0–6 points, multi-part)

The PT Extended Response is the primary item in the Performance Task. It presents a complex real-world scenario and asks students to complete 3–5 interdependent sub-parts that together constitute a full mathematical modeling or problem-solving experience.

```
┌─────────────────────────────────────────────────────────────────┐
│  PERFORMANCE TASK — EXTENDED RESPONSE                           │
│                                                                 │
│  SCENARIO:                                                      │
│  [3–5 sentence real-world context establishing the situation]   │
│  [Data tables, diagrams, or charts may be provided here]        │
│                                                                 │
│  Part A: [Introductory computation or setup question]           │
│  ┌───────────────────────────────────────────────────────┐      │
│  │ [Student response area]                               │      │
│  └───────────────────────────────────────────────────────┘      │
│                                                                 │
│  Part B: [Intermediate reasoning or application question]       │
│  ┌───────────────────────────────────────────────────────┐      │
│  │ [Student response area]                               │      │
│  └───────────────────────────────────────────────────────┘      │
│                                                                 │
│  Part C: [Complex extension — explain, justify, model, or       │
│            evaluate a decision based on mathematical results]   │
│  ┌───────────────────────────────────────────────────────┐      │
│  │ [Student response area]                               │      │
│  └───────────────────────────────────────────────────────┘      │
└─────────────────────────────────────────────────────────────────┘
Points: 0–2 per part × 3 parts = 0–6 total
Alternatively: 0–3 for Parts A+B combined, 0–3 for Part C
(see rubric, Section 8)
```

## 6. DOK / Cognitive Complexity

### DOK Level Descriptions for Mathematics

| DOK | Label | Description | Example Tasks |
|---|---|---|---|
| **1** | Recall & Reproduction | Recall a fact; perform a routine, single-step procedure; identify a property; solve a one-step equation; read a value from a graph | *calculate, identify, recall, use, recognize, list, name, measure* |
| **2** | Skills & Concepts | Solve a multi-step problem using a known procedure; classify or organize information; make inferences from data; apply a concept in a new but straightforward context; construct a simple graph or diagram | *classify, organize, estimate, compare, interpret, solve [multi-step], graph, apply* |

## 7. Mathematical Practices

The Standards for Mathematical Practice (SMP) describe the mathematical habits of mind that proficient students develop. CAASPP items are designed to elicit these practices, particularly within the Claims framework.

### The 8 Standards for Mathematical Practice

| SMP | Title | Description | Primary Claim(s) |
|---|---|---|---|
| **SMP 1** | Make sense of problems and persevere in solving them | Students understand what a problem is asking, plan a pathway, monitor progress, and adjust strategy if needed. They check answers for reasonableness | Claims 2, 4 |
| **SMP 2** | Reason abstractly and quantitatively | Students decontextualize (represent symbolically) and recontextualize (interpret symbols back in context); they attend to the meaning of quantities and units | Claims 1, 3 |
| **SMP 3** | Construct viable arguments and critique the reasoning of others | Students justify conclusions using mathematical reasoning; they identify flawed arguments and explain the flaw | Claim 3 |
| **SMP 4** | Model with mathematics | Students use mathematics to describe real-world situations; they identify important quantities, map relationships, and evaluate whether a model is appropriate | Claim 4 |
| **SMP 5** | Use appropriate tools strategically | Students choose and use tools — calculators, rulers, protractors, graphs, spreadsheets — knowing their limitations | Claims 1, 2 |
| **SMP 6** | Attend to precision | Students use precise language and symbols; they specify units of measure; they calculate accurately and efficiently | Claim 1 |
| **SMP 7** | Look for and make use of structure | Students see patterns and structure in mathematical objects; they recognize equivalent forms; they see complicated problems as single objects | Claim 1 |
| **SMP 8** | Look for and express regularity in repeated reasoning | Students notice repeated calculations and general methods; they recognize when processes are repeating and articulate general rules | Claims 1, 3 |

### SMP — Claim Alignment Matrix

| Claim | Primary SMPs | Secondary SMPs |
|---|---|---|
| Claim 1 — Concepts & Procedures | SMP 6, 7, 8 | SMP 2, 5 |
| Claim 2 — Problem Solving | SMP 1, 5 | SMP 2, 4, 6 |
| Claim 3 — Communicating Reasoning | SMP 3, 6 | SMP 1, 2, 7 |
| Claim 4 — Modeling & Data Analysis | SMP 4, 1 | SMP 2, 3, 5, 6 |

> Item tags should include the primary SMP whenever possible. When generating PT items, note which SMP the task most prominently elicits.

## 8. Scoring Rubrics

### SCR — Short Constructed Response (0–2 Points)

| Score | Descriptor |
|---|---|
| **2** | The response demonstrates a thorough understanding of the mathematical concepts and procedures required by the task. The student provides a correct solution with a clear, accurate explanation or justification. Work shown is logical and complete. Minor arithmetic errors do not affect the score if reasoning is sound. |
| **1** | The response demonstrates a partial understanding of the mathematical concepts and procedures. The student provides a partially correct solution or a correct solution with an incomplete or unclear explanation. The student may have made a computational error that led to an incorrect answer, but the mathematical reasoning is otherwise sound. OR the student provides the correct answer with no explanation. |
| **0** | The response is incorrect, irrelevant, or demonstrates no mathematical understanding of the concepts required. Responses that show only memorized formulas without application, or that copy the problem without work, receive a score of 0. A blank response receives a score of 0. |

**SCR Scoring Notes:**
- Score based on the mathematical soundness of the reasoning, not writing quality
- Correct answer alone (without explanation when explanation is required) earns at most 1 point
- Correct process with arithmetic error earns 1 point if the method is clearly shown and correct
- Do not penalize for minor notation errors (e.g., missing units) unless units are the central focus of the problem

---

### PT-ER — Performance Task Extended Response (0–6 Points)

The PT-ER is scored across the full multi-part task. Partial credit is awarded per part. The following rubric applies to a standard 3-part task (Parts A, B, C), scored 0–2 each.

#### Part A Rubric (0–2 points)

| Score | Descriptor |
|---|---|
| **2** | The response correctly sets up and solves the introductory problem within the scenario. All calculations are correct and clearly shown. Units are correctly identified and used. The response demonstrates understanding of the mathematical context. |
| **1** | The response demonstrates correct approach or setup but contains a computational error, an incomplete solution, or a missing unit. The mathematical intent is clear and the process is mostly correct. |
| **0** | The response is incorrect, missing, or demonstrates no understanding of the mathematical task. |

#### Part B Rubric (0–2 points)

| Score | Descriptor |
|---|---|
| **2** | The response correctly applies the mathematical results from Part A (or independently arrives at correct values) to solve the intermediate problem. Reasoning is clear; any comparison, evaluation, or interpretation is accurate and well-supported. |
| **1** | The response shows partial understanding. The student may use an incorrect value from Part A but apply correct reasoning from that point, OR arrive at the correct conclusion through partially correct work. |
| **0** | The response is incorrect, missing, or shows no mathematical understanding relative to the Part B task. |

#### Part C Rubric (0–2 points)

| Score | Descriptor |
|---|---|
| **2** | The response demonstrates sophisticated mathematical reasoning applied to the complex extension. The student accurately uses mathematical results to justify a decision, evaluate a model, or explain a pattern. The explanation is clear, precise, and mathematically sound. If multiple correct approaches exist, any valid approach earns full credit. |
| **1** | The response shows some correct reasoning or a partially valid justification. The student may identify the correct conclusion but provide insufficient or partially flawed mathematical support. OR the student provides correct calculations without connecting them to the required explanation or decision. |
| **0** | The response is incorrect, off-task, or provides only unsupported assertions. A blank response receives 0. |

#### Holistic Scoring Note for PT-ER

When a student carries an incorrect value from Part A into Parts B and C, use "error carried forward" (ECF) scoring:
- If the student's Part B or Part C work is mathematically correct based on their Part A answer, award full credit for that part despite the error from Part A
- ECF applies only when the error is a simple computational mistake, not a conceptual misunderstanding

## 10. Contextualization

### California-Specific Mathematics Context Bank

Item writers should anchor scenarios in authentic California contexts to maximize student engagement and ecological validity.

#### Agriculture & Water (Central Valley Focus)

| Topic | Mathematical Applications |
|---|---|
| **Central Valley crop production** | Unit rates (bushels per acre); ratio and proportion; area calculations; multi-step problems |
| **Water usage and drought** | Percent change; data analysis; rates (gallons per day); comparing and interpreting data sets |
| **Farmworker wages and scheduling** | Multiplication, division; unit rate; proportional relationships; inequalities |
| **Irrigation systems** | Area and perimeter; volume; fractions (portions of fields irrigated) |

#### Technology & Innovation (Bay Area / Silicon Valley Focus)

| Topic | Mathematical Applications |
|---|---|
| **App downloads and usage data** | Percentages; ratios; statistical analysis; exponential growth |
| **Tech salaries and cost of living** | Percent change; ratios; income vs. expense calculations |
| **Screen time and data usage** | Rates; unit rate; proportional relationships; data interpretation |

#### Environment & Natural Features

| Topic | Mathematical Applications |
|---|---|
| **Earthquake data** | Number line (negative/positive); absolute value; measurement; statistical analysis of frequency |
| **California population statistics** | Large number operations; percent; data displays; proportional reasoning |
| **State park areas and trails** | Area, perimeter; fractions; unit conversion; distance-rate-time |
| **Coastal erosion rates** | Rate of change; proportional relationships; graphing; slope (Gr 7–8) |
| **Solar panel installations** | Area; proportional reasoning; rates; percent; cost-benefit analysis |

#### Community and Everyday Contexts

| Topic | Mathematical Applications |
|---|---|
| **California school budgets** | Large numbers; percent; ratios; proportional reasoning |
| **Farmer's market pricing** | Unit price; discount; percent; multi-step computation |
| **Public transit schedules** | Time; distance; rate; elapsed time; proportional reasoning |
| **Sports statistics (Dodgers, Warriors, 49ers)** | Mean, median, mode; percent; data analysis; ratios |

### Grade-Band Contextualization Notes

#### Grades 3–5 Contextualization

| Principle | Guidance |
|---|---|
| **Concreteness** | Contexts should involve tangible, observable quantities (objects counted, distances measured, areas calculated) |
| **Accessibility** | Avoid highly specialized vocabulary or cultural knowledge that disadvantages EL students or newcomer families |
| **Scale of numbers** | Match the number magnitude to grade-level standards (Gr 3: within 1,000; Gr 5: multi-digit, decimals, fractions) |
| **Authenticity** | California school garden, local farmer's market, state park visit, school fundraiser — familiar community settings |

#### Grades 6–8 Contextualization

| Principle | Guidance |
|---|---|
| **Real data** | Use approximate real data (California population ~39 million; average water use; earthquake magnitudes) to ground tasks in reality |
| **Multiple representations** | Include tables, graphs, or diagrams alongside word problem contexts |
| **Social relevance** | Topics like water usage, housing costs, and environmental data resonate with middle-school students and connect to social studies/science |

#### Grade 11 Contextualization

| Principle | Guidance |
|---|---|
| **Workforce readiness** | Career-relevant contexts (engineering, agriculture, medicine, business) — appropriate for students approaching graduation |
| **Complex data** | Multi-variable data sets; scatter plots; regression; probability in real decision-making |
| **Equity lens** | Include data that represents California's diversity; avoid contexts that systematically advantage students from higher socioeconomic backgrounds |

### English Learner (EL) Considerations for Math

| Consideration | Guidance |
|---|---|
| **Mathematical vocabulary** | Pre-teach or define Tier 3 math vocabulary in a glossary; avoid confusing mathematical terms with everyday meanings (e.g., "table," "root," "product") |
| **Word problem language** | Use simple, direct sentence structure in word problem stems; avoid unnecessarily complex syntax |
| **Bilingual glossary** | EL designated support — mathematical terms in Spanish, Chinese, Vietnamese, and other home languages; items should not be invalidated by glossary use |
| **Diagrams and visuals** | Use clear, labeled diagrams to reduce linguistic load; diagrams should never be the only path to a correct answer (accessibility) |

## 11. Quality Checklist

Use this checklist before finalizing any generated item or item set.

### Standards Alignment

- [ ] Item is tagged to one primary CCSS Math standard (e.g., 7.RP.A.2)
- [ ] Standard matches the claim and subclaim
- [ ] DOK level is consistent with the cognitive demand of the task
- [ ] Grade-level standard is appropriate for the intended grade band
- [ ] Item does not require knowledge of standards above or below grade level (unless explicitly noted as a bridge item)

### Calculator Policy

- [ ] Item is flagged as calculator or non-calculator consistent with grade-level policy (Section 3)
- [ ] Computational complexity is appropriate for the calculator policy (non-calc items should not require excessive multi-digit computation at upper grades)
- [ ] Calculator-active items use numbers that would realistically benefit from a calculator

### Reference Sheet

- [ ] For Grades 8 and 11: item does not embed formulas that are on the reference sheet
- [ ] For Grades 3–7: item does not require formulas not taught at grade level
- [ ] Formula reference is given in the item when required for grades that do not receive a reference sheet

### Item Quality (All Types)

- [ ] Stem is a clear, unambiguous question or directive
- [ ] All numerical values in the problem are internally consistent
- [ ] Units are clearly specified and used correctly throughout
- [ ] No "trick" questions — the correct answer is not based on misreading a minor detail
- [ ] Diagrams are clearly labeled, drawn to reasonable scale, and described in alt text
- [ ] Answer options for SR are plausible and each represents a specific student error
- [ ] Correct answer is verified independently (calculation checked)
- [ ] Word problem context is realistic and meaningful — not artificial or confusing

### SCR and PT-ER Checks

- [ ] Constructed-response prompt requires both a numerical answer AND explanation/justification
- [ ] Rubric is included with the item
- [ ] PT-ER parts are interdependent and logically sequenced (A → B → C)
- [ ] Error-carried-forward (ECF) policy is noted in the rubric
- [ ] Scoring guide anticipates common student errors and specifies how they should be scored

### EL and Accessibility

- [ ] Word problem language is clear and concise; no unnecessarily complex syntax
- [ ] Mathematical vocabulary is appropriate for the grade; specialized terms are defined
- [ ] Diagrams are usable by students using zoom or screen magnification
- [ ] Item does not require cultural knowledge that disadvantages EL students or students new to California

## 12. Prompt Patterns

The following patterns map common user requests to generation strategies for the AI.

---

### Pattern 1: "Generate a math problem for Grade [X]"

**Interpretation:** Default to an SR item (1 point) for Claim 1 (Concepts & Procedures) at DOK 2. Use a real-world context from Section 10.

**Generation Recipe:**
1. Identify the primary content domain for the grade (e.g., Gr 5 → NF fractions or NBT decimals; Gr 7 → RP proportional relationships)
2. Select a California context from Section 10
3. Generate SR using Template 1, ensuring two mathematical steps
4. Construct four options where each distractor represents a distinct common error
5. Tag: state=CA, subject=MATH, grade=[X], claim=2, standard=[DOMAIN].[GRADE].[STANDARD], dok=2, calculator=no (Gr 3–5) or yes (Gr 6–8)

---

### Pattern 2: "Generate a word problem that requires explanation"

**Interpretation:** Generate an SCR (0–2 points) for Claim 3 (Communicating Reasoning) at DOK 3. Use Template 2.

**Generation Recipe:**
1. Select a multi-step context appropriate for the grade (see Section 10)
2. Build Part A as the computational/procedural component (DOK 2)
3. Build Part B as the justification/explanation requirement (DOK 3)
4. Include a scoring guide (Section 8 rubric)
5. Tag: state=CA, subject=MATH, grade=[X], claim=3, standard=[PRIMARY_STANDARD], dok=3

---

### Pattern 3: "Generate a Performance Task math problem for Grade [X]"

**Interpretation:** Generate a full PT-ER package using Template 3: scenario + data table + Parts A, B, C + scoring rubric.

**Generation Recipe:**
1. Choose a multi-faceted California context (water usage, agriculture, state park, population data)
2. Create a realistic data set with 3–5 rows/entries
3. Scaffold Parts A (DOK 2), B (DOK 2–3), and C (DOK 3–4)
4. Include the 0–2 rubric for each part and ECF note
5. List the primary standards and claims addressed by each part
6. Tag: state=CA, subject=MATH, grade=[X], claim=4, dok=3-4, calculator=yes

---

### Pattern 4: "Generate a set of math items covering multiple domains"

**Interpretation:** Generate a mini-assessment covering 3–4 different mathematical domains for the specified grade, with a mix of SR, MS, and EQ item types.

**Generation Recipe:**
1. Identify 3–4 primary domains for the grade (e.g., Gr 6: NS, RP, EE, G)
2. Generate one item per domain:
   - 1–2 SR items (DOK 1–2)
   - 1 MS item (DOK 2)
   - 1 EQ item (DOK 1–2)
3. Distribute calculator vs. non-calculator per policy (Section 3)
4. Include a standards and DOK summary table for the full set
5. Tag each item with claim, standard, DOK, and calculator policy
