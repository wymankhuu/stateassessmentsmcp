## 1. Overview

| Field | Detail |
|---|---|

| **Consortium** | Smarter Balanced Assessment Consortium (SBAC) |
| **Vendor** | Educational Testing Service (ETS) |
| **Grades Tested** | 3, 4, 5, 6, 7, 8, 11 |

| **Delivery** | Computer-adaptive (CAT) for Part 1; fixed-form Performance Task for Part 2 |

| **Reporting** | Individual Student Report (ISR); School, District, County, State aggregate reports |

### Achievement Level Descriptors (ALDs)

| Level | Label | Description |
|---|---|---|
| 4 | **Standard Exceeded** | Student demonstrates thorough understanding of concepts and procedures; sophisticated analysis; precise use of evidence from complex texts |
| 3 | **Standard Met** | Student demonstrates adequate understanding; appropriate analysis; uses relevant evidence from grade-level texts |
| 2 | **Standard Nearly Met** | Student demonstrates partial understanding; limited analysis; inconsistent use of evidence; needs support to access grade-level text |
| 1 | **Standard Not Met** | Student demonstrates minimal understanding; little to no evidence use; significant gaps relative to grade-level expectations |

> **Cut scores** are set by the Smarter Balanced Assessment Consortium and adopted annually by the California State Board of Education. For item-writing purposes, focus on ALDs 3 and 4 as the target proficiency range.

## 2. Standards Framework

> **Reference:** See `_shared/ccss_ela_framework.md` for full CCR Anchor Standards and grade-by-grade progressions. This section highlights the key standards most heavily tested on CAASPP.

### Reading Literature (RL) — Key Standards by Grade Band

| Standard | Gr 3–5 Focus | Gr 6–8 Focus | Gr 11 Focus |
|---|---|---|---|
| **RL.1** — Key details & inference | Explicit details; simple inference | Textual evidence for inference | Cite strong and thorough textual evidence |
| **RL.2** — Central idea / theme | Determine main message or lesson | Theme + how it is conveyed | Two or more themes; complex analysis |
| **RL.3** — Character, setting, events | Describe characters' traits and motivations | Analyze character development | Analyze impact of author's choices |
| **RL.4** — Word meaning | Determine meaning of words and phrases | Figurative language, connotations | Nuanced meanings, tone |
| **RL.6** — Point of view | Identify narrator's point of view | Analyze how POV shapes content | Evaluate unreliable narrators |
| **RL.9** — Compare / contrast texts | Compare similar themes across texts | Analyze how modern works draw on earlier | Demonstrate knowledge of 18th–20th century works |

### Reading Informational Text (RI) — Key Standards by Grade Band

| Standard | Gr 3–5 Focus | Gr 6–8 Focus | Gr 11 Focus |
|---|---|---|---|
| **RI.1** — Cite evidence | Refer explicitly to text | Cite textual evidence | Cite strong and thorough evidence |
| **RI.2** — Central idea | Main idea + key details | Analyze development of central idea | Determine two or more central ideas |
| **RI.3** — Connections | Describe relationships (compare/contrast, cause/effect) | Analyze how text makes connections and distinctions | Analyze sequence of events or ideas |
| **RI.6** — Author's purpose | Distinguish own point of view from author's | Determine author's point of view/purpose | Evaluate author's point of view and rhetoric |
| **RI.8** — Argument & evidence | Describe how reasons support points | Trace and evaluate argument | Evaluate effectiveness of evidence |
| **RI.9** — Integrate information | Compare texts on same topic | Analyze how texts address similar topics differently | Synthesize information from multiple sources |

### Writing (W) — Key Standards

| Standard | Description | CAASPP Claim |
|---|---|---|
| **W.1** | Write arguments with claims, reasons, and evidence | Claim 2 — Full Write; PT-FW argumentative |
| **W.2** | Write informative/explanatory texts | Claim 2 — Full Write; PT-FW informational |
| **W.3** | Write narratives | Claim 2 — occasionally, lower grades |
| **W.4** | Produce clear and coherent writing | Claim 2 — all writing tasks |
| **W.7** | Conduct short research projects | Claim 4 — Research |
| **W.8** | Gather relevant information from sources | Claim 4 — Research |
| **W.9** | Draw evidence from texts | Claims 2 and 4 |

### Language (L) — Key Standards

| Standard | Description |
|---|---|
| **L.1** | Grammar and usage conventions |
| **L.2** | Capitalization, punctuation, spelling |
| **L.4** | Determine word meanings (context clues, affixes, reference materials) |
| **L.5** | Figurative language, word relationships |
| **L.6** | Academic and domain-specific vocabulary |

## 5. Item Types & Formats

### SR — Selected Response (1 point)

Standard four-option multiple-choice. Student selects one best answer.

```
┌─────────────────────────────────────────────────────────────────┐
│  Read the following passage. Then answer the question.          │
│                                                                 │
│  [PASSAGE TEXT — 200–800 words depending on grade]              │
│                                                                 │
│  Question stem that targets a specific standard (RL/RI/L).      │
│                                                                 │
│  ○  A. [Plausible distractor — partially correct]               │
│  ○  B. [Correct answer — directly supported by text]            │
│  ○  C. [Plausible distractor — common misconception]            │
│  ○  D. [Plausible distractor — out of scope]                    │
└─────────────────────────────────────────────────────────────────┘
Points: 1 (correct) / 0 (incorrect)
```

**Construction Rules:**
- All four options must be plausible; no obviously wrong answers
- Correct answer must be unambiguously supported by passage text
- Distractors should represent real student errors (misreading, overgeneralization)
- Avoid "All of the above" / "None of the above"
- Stem must be a complete question or clear directive

---

### MS — Multi-Select (1 point)

Student selects ALL correct answers from a set of typically five or six options. Full credit only when all correct options are selected and no incorrect options are selected.

```
┌─────────────────────────────────────────────────────────────────┐
│  Read the passage. Then answer the question.                    │
│                                                                 │
│  Question stem — note: "Select ALL that apply" or              │
│  "Select the TWO answers that..."                               │
│                                                                 │
│  ☐  A. [Option]                                                 │
│  ☐  B. [Option — CORRECT]                                       │
│  ☐  C. [Option]                                                 │
│  ☐  D. [Option — CORRECT]                                       │
│  ☐  E. [Option]                                                 │
│  ☐  F. [Option]                                                 │
└─────────────────────────────────────────────────────────────────┘
Points: 1 (all correct selected, none incorrect) / 0 (any other)
```

**Construction Rules:**
- Specify the number of correct answers in the stem when count is fixed ("Select the TWO...")
- When count is unspecified, use "Select ALL that apply"
- Typically 2–3 correct answers from a field of 5–6
- Each option should be independently evaluable against the text

---

### TE-Selectable Text — Technology-Enhanced: Highlight/Select

Student clicks directly on words, sentences, or paragraphs within the passage to answer the question. The interface highlights selected text.

```
┌─────────────────────────────────────────────────────────────────┐
│  Read the paragraph below. Then answer the question.            │
│                                                                 │
│  ┌───────────────────────────────────────────────────────────┐  │
│  │ [Paragraph text — individual sentences are clickable]     │  │
│  │ The author develops the central idea across three main    │  │
│  │ points. [SENTENCE 1 — selectable]. [SENTENCE 2].          │  │
│  │ [SENTENCE 3 — selectable]. [SENTENCE 4].                  │  │
│  └───────────────────────────────────────────────────────────┘  │
│                                                                 │
│  Click the sentence that BEST supports the claim that...        │
│  (Select 1 sentence)                                            │
└─────────────────────────────────────────────────────────────────┘
Points: 1 (correct sentence/phrase) / 0 (incorrect)
```

---

### TE-Drag Drop — Technology-Enhanced: Drag and Drop

Student drags response options into a target area — typically a graphic organizer, table, or sequencing frame.

```
┌─────────────────────────────────────────────────────────────────┐
│  Read the passage. Then complete the activity.                  │
│                                                                 │
│  Drag the evidence from the word bank into the box that         │
│  describes whether it supports or contradicts the author's      │
│  central claim.                                                 │
│                                                                 │
│  WORD BANK: [Quote A]  [Quote B]  [Quote C]  [Quote D]         │
│                                                                 │
│  ┌─────────────────────┐    ┌─────────────────────┐            │
│  │  Supports Claim     │    │ Contradicts Claim   │            │
│  │                     │    │                     │            │
│  │  [drop zone]        │    │  [drop zone]        │            │
│  └─────────────────────┘    └─────────────────────┘            │
└──────────────────────────────────────────────────────────────��──┘
Points: 1 per correctly placed item (partial credit possible)
```

### EBSR — Evidence-Based Selected Response (2 points, two-part)

Part A is a standard SR question. Part B asks students to select the evidence from the text that best supports their Part A answer. Each part is scored separately.

```
┌─────────────────────────────────────────────────────────────────┐
│  PART A                                                         │
│                                                                 │
│  What is the central idea of the passage?                       │
│                                                                 │
│  ○  A. [Distractor]                                             │
│  ○  B. [CORRECT — central idea statement]                       │
│  ○  C. [Distractor]                                             │
│  ○  D. [Distractor]                                             │
│                                                                 │
├─────────────────────────────────────────────────────────────────┤
│  PART B                                                         │
│                                                                 │
│  Which detail from the passage BEST supports the answer to      │
│  Part A?                                                        │
│                                                                 │
│  ○  A. "[Direct quote — supports distractor A]"                 │
│  ○  B. "[Direct quote — CORRECT; supports central idea]"        │
│  ○  C. "[Direct quote — tangentially related]"                  │
│  ○  D. "[Direct quote — supports distractor C]"                 │
└─────────────────────────────────────────────────────────────────┘
Scoring: Part A correct = 1 pt; Part B correct = 1 pt
Note: Part B correct without Part A correct = 0 pts for Part B
Total possible: 2 points
```

**Construction Rules:**
- Part B options must be direct quotes or very close paraphrases from the passage
- Each Part B distractor should be a plausible piece of evidence for one of the Part A distractors
- The correct Part B quote must unambiguously support the correct Part A answer
- Assign standard codes to both parts (e.g., RI.5.2 and RI.5.1)

### PT-FW — Performance Task Full Write (12 points, three traits)

The centerpiece of the Performance Task. Students read a set of 2–3 source texts on a shared topic, then write a full multi-paragraph essay (argumentative or informational/explanatory). Scored on three traits: Organization/Purpose, Evidence/Elaboration, and Conventions.

```
┌─────────────────────────────────────────────────────────────────┐
│  PERFORMANCE TASK — FULL WRITE                                  │
│                                                                 │
│  You have read the following sources:                           │
│    Source 1: "[Title 1]" — [type: article, speech, excerpt]     │
│    Source 2: "[Title 2]" — [type]                               │
│    Source 3: "[Title 3]" — [type, Gr 6+ only]                   │
│                                                                 │
│  PROMPT:                                                        │
│  [Argumentative or Informational framing sentence]              │
│  Write a well-developed [essay/article/letter] in which you     │
│  [argue a position / explain / analyze].                        │
│                                                                 │
│  Use evidence from at least TWO of the sources to support       │
│  your [argument / explanation]. Be sure to:                     │
│    • Introduce your topic and state your [claim/thesis]         │
│    • Develop your ideas with relevant evidence and elaboration  │
│    • Use transitions to organize your ideas                     │
│    • Maintain a formal style and appropriate tone               │
│    • Provide a concluding section                               │
│                                                                 │
│  [Text input box — full word processor with spell check]        │
└─────────────────────────────────────────────────────────────────┘
Scoring: 0–4 Organization/Purpose + 0–4 Evidence/Elaboration
         + 0–4 Conventions = 0–12 raw points
```

---

### PT-ST — Performance Task Short Text (2 points)

A brief constructed-response item within the Performance Task. Students write a paragraph-length response using evidence from the source set.

```
┌─────────────────────────────────────────────────────────────────┐
│  PERFORMANCE TASK — SHORT TEXT                                  │
│                                                                 │
│  You have read the sources listed above.                        │
│                                                                 │
│  Question: What does [Source 1] say about [topic]? How does    │
│  [Source 2] support or challenge this idea? Use evidence        │
│  from BOTH sources in your response.                            │
│                                                                 │
│  [Text input box — 3–5 sentence response expected]              │
└─────────────────────────────────────────────────────────────────┘
Scoring: 0–2 points
  2 — Adequate evidence from both sources; clear connection
  1 — Evidence from only one source OR connection is vague
  0 — Off task, no evidence, or copied text only
```

## 6. DOK / Cognitive Complexity

### DOK Level Descriptions for ELA

| DOK | Label | Description | Example Verbs |
|---|---|---|---|
| **1** | Recall & Reproduction | Locate explicitly stated information; identify a defined term; recall a plot event | *identify, recall, locate, define, recognize, list* |
| **2** | Skills & Concepts | Make inferences; determine author's purpose; compare two ideas within a text; explain cause-effect; determine word meaning from context | *infer, explain, compare, classify, organize, summarize, interpret* |
| **3** | Strategic Thinking | Analyze how structural choices affect meaning; evaluate strength of evidence; synthesize across multiple texts; justify an interpretation with multiple pieces of evidence | *analyze, evaluate, justify, synthesize, critique, construct, formulate* |

> CAASPP ELA does not formally use DOK 4 on the summative assessment. Extended inquiry occurs in the PT but is scored through the three traits rather than a DOK 4 designation.

### DOK Distribution Targets for Item Generation

| Item Type | Target DOK | Rationale |
|---|---|---|
| SR — vocabulary in context | 1–2 | Primarily definitional; some inferential |
| SR — key details | 1–2 | Locate and explain; may require inference |
| SR — central idea / theme | 2–3 | Requires synthesis beyond literal reading |
| MS — evidence | 2–3 | Evaluate multiple pieces of evidence |
| EBSR | 2–3 | Part A often DOK 2; Part B requires justification (DOK 3) |
| TE — selectable text | 2–3 | Must identify evidence; not merely locate |
| PT-ST | 2–3 | Integrate evidence from two sources |
| PT-FW | 3 | Full argumentation with multi-source evidence |

## 7. Text Complexity

### Lexile Ranges by Grade (CAASPP Targets)

| Grade | Literary Text Lexile | Informational Text Lexile | Avg Passage Length |
|---|---|---|---|
| 3 | 520L – 820L | 520L – 820L | 200–400 words |
| 4 | 740L – 1010L | 740L – 1010L | 250–450 words |
| 5 | 830L – 1100L | 830L – 1100L | 300–500 words |
| 6 | 925L – 1185L | 925L – 1185L | 400–700 words |
| 7 | 970L – 1220L | 970L – 1220L | 500–800 words |
| 8 | 1010L – 1250L | 1010L – 1250L | 600–900 words |
| 11 | 1185L – 1385L | 1185L – 1385L | 700–1200 words |

> Lexile ranges are targets, not absolute cutoffs. Qualitative factors (purpose, knowledge demands, text structure, language clarity) are weighted alongside quantitative Lexile scores. A text slightly below Lexile range with high knowledge demands may be appropriate.

### Passage Requirements

| Requirement | Specification |
|---|---|
| **Genre balance** | Literary and informational in roughly equal proportion across a test form |
| **Source authenticity** | Passages must be authentic published works OR high-quality original passages that simulate authentic style and purpose |
| **Cultural representation** | Passages should reflect diverse authors, subjects, and cultural perspectives; no group should be systematically over- or underrepresented |
| **Bias and sensitivity** | No depictions of violence, overtly partisan political content, religious advocacy, or brand names; avoid content that advantages students from specific demographic groups |
| **Artwork/Graphics** | Informational passages may include charts, diagrams, photographs (described in alt text) |
| **PT source sets** | 2 sources at Grades 3–5; 3 sources at Grades 6–8 and 11; sources should have complementary and contrasting information on the shared topic |

## 8. Scoring Rubrics

### PT-FW Full Write — Three-Trait Rubric (0–4 each)

#### Trait 1: Organization / Purpose

| Score | Descriptor |
|---|---|
| **4** | The response has a clear and effective organizational structure, creating a sense of unity and completeness. The controlling idea or main claim is compelling and fully elaborated. The response consistently and purposefully addresses the appropriate form, audience, and purpose. Transitions are varied and consistently aid the reader's comprehension. |
| **3** | The response has an evident organizational structure. The controlling idea or claim is adequately elaborated. The response mostly addresses the appropriate form, audience, and purpose. Transitions are generally used appropriately, with minor lapses. |
| **2** | The response demonstrates some evidence of an organizational structure, but it may be formulaic, inconsistent, or only partially sustained. The controlling idea or claim may be vague or insufficiently developed. Some transitions are used, but they may be inappropriate or repetitive. |
| **1** | The response demonstrates little or no organizational structure. The controlling idea or claim, if present, is underdeveloped or hard to identify. There is minimal or no use of transitions. The response may seem random or incoherent in structure. |
| **0** | The response is completely irrelevant to the prompt, is a copy of the source text(s), is too brief to assess, or is written in a language other than English. |

#### Trait 2: Evidence / Elaboration

| Score | Descriptor |
|---|---|
| **4** | The response provides thorough and convincing support for the controlling idea or claim. Evidence is integrated effectively from at least two sources. Elaboration is well developed and demonstrates a clear understanding of the topic. Vocabulary is precise, domain-specific, and varied; academic language is used purposefully. |
| **3** | The response provides adequate support for the controlling idea or claim. Evidence is drawn from sources and is relevant, though elaboration may be somewhat formulaic. Vocabulary is generally appropriate for the audience; some academic language is used. |
| **2** | The response provides partial or uneven support for the controlling idea or claim. Evidence may be vague, repetitive, or only from one source. Elaboration is limited. Vocabulary is basic or inconsistently appropriate. |
| **1** | The response provides minimal support. Evidence is largely absent, incorrect, or taken directly from the source without elaboration. Vocabulary is predominantly basic; little or no academic language. |
| **0** | See Trait 1 score-point 0 conditions. |

#### Trait 3: Conventions

| Score | Descriptor |
|---|---|
| **4** | The response demonstrates consistent command of grammar, usage, capitalization, punctuation, and spelling. Errors, if present, are minor and do not interfere with meaning. Sentences are varied in structure and length. |
| **3** | The response demonstrates adequate command of conventions. Some errors are present but do not substantially impede meaning. Sentence structure is mostly varied. |
| **2** | The response demonstrates partial command of conventions. Errors in grammar, spelling, or punctuation are noticeable and may occasionally impede meaning. Sentence structure is repetitive or limited. |
| **1** | The response demonstrates limited command of conventions. Frequent errors significantly impede meaning. Sentence structure is simple and largely unvaried. |
| **0** | See Trait 1 score-point 0 conditions. |

> **Machine scoring:** CAASPP uses a combination of human scoring and automated scoring (AI/NLP models) for PT-FW. Human scoring is applied to all operational responses; automated scoring is used for quality checks and flagging. Item generators should design prompts that require genuine multi-source integration, which is harder for automated scoring to fake.

---

### PT-ST Short Text — 2-Point Rubric

| Score | Descriptor |
|---|---|
| **2** | The response clearly addresses the question and provides relevant and specific evidence from both (or all required) sources. The connection between sources and the response is explicit and logical. Minor errors in conventions do not impede meaning. |
| **1** | The response partially addresses the question. Evidence may be drawn from only one source, or the evidence from multiple sources is present but loosely connected. The response may be vague in places. |
| **0** | The response is off topic, does not use source evidence, copies directly from the text without analysis, is too brief to evaluate, or is in a language other than English. |

```
ITEM TYPE: EBSR

STANDARD: RI.[GRADE].[TARGET_STANDARD]
DOK: 2

PASSAGE CONTEXT:

PART A
What is the main idea of [the passage / paragraph [X] / [PASSAGE_TITLE]]?

○ A. [DISTRACTOR — broad overgeneralization or out-of-scope idea]
○ B. [CORRECT — accurate, specific statement of main idea]
○ C. [DISTRACTOR — detail masquerading as main idea]
○ D. [DISTRACTOR — related but incorrect interpretation]

PART B
Which detail from [the passage / the article] BEST supports your answer
in Part A?

○ A. "[QUOTE — supports distractor A]"
○ B. "[QUOTE — CORRECT; directly supports main idea in Part B]"
○ C. "[QUOTE — tangentially related or supports distractor C]"
○ D. "[QUOTE — supports distractor D]"

SCORING:
- Part A: 1 point (B correct)
- Part B: 1 point (B correct), conditioned on Part A correct
- Total: 0–2 points
```

```
  Topic angle: [POSITION_OR_PERSPECTIVE_1]
  Key claim: [MAIN_ARGUMENT_OF_SOURCE_1]
  Lexile: [APPROPRIATE_LEXILE]

Source 2: "[SOURCE_2_TITLE]" — [Type: article / chart + text / interview]
  Topic angle: [POSITION_OR_PERSPECTIVE_2]
  Key claim: [MAIN_ARGUMENT_OF_SOURCE_2]
  Lexile: [APPROPRIATE_LEXILE]

Source 3 (Grades 6–11 only):
  "[SOURCE_3_TITLE]" — [Type]
  Key claim: [MAIN_ARGUMENT_OF_SOURCE_3]

PROMPT:
You have read [two/three] sources about [SHARED_TOPIC].

[Connector sentence establishing the debate or issue]

Write a well-developed argument in which you take a clear position on
[DEBATABLE_QUESTION_OR_ISSUE]. Use evidence from at least TWO of the
sources to support your argument.

Be sure to:
  • Introduce your claim clearly
  • Support your claim with relevant evidence and reasoning from the sources
  • Address an opposing viewpoint
  • Organize your ideas logically with transitions between sections
  • Maintain a formal style and objective tone
  • Provide a conclusion that supports your argument

SCORING: 0–12 points total
Trait 1 — Organization/Purpose: 0–4
Trait 2 — Evidence/Elaboration: 0–4
Trait 3 — Conventions: 0–4
```

## 10. Contextualization

### California-Specific Topic Bank

Item writers should anchor passages and scenarios in authentic California contexts when possible. This increases ecological validity and engagement for California students.

#### Geography & Environment

| Topic | Details for Item Use |
|---|---|
| **Coastal Ecosystems** | Pacific coast, kelp forests, tide pools; Channel Islands National Park; sea otter conservation |
| **Sierra Nevada** | John Muir's writings; watershed and water supply; giant sequoias; wildfire ecology |
| **Central Valley** | Agricultural breadbasket; irrigation and water rights; air quality challenges; farming communities |
| **Mojave / Sonoran Desert** | Joshua Tree National Park; desert adaptations; renewable energy development |
| **Bay Area & Wetlands** | San Francisco Bay tidal marshes; habitat restoration; urban-nature interface |

#### History & Social Studies Contexts

| Topic | Suggested Use |
|---|---|
| **Cesar Chavez & the UFW** | Informational passages on labor rights; persuasive speeches; primary sources |
| **California Gold Rush (1848–1855)** | Historical narratives; multiple perspectives (immigrants, Indigenous peoples, miners) |
| **California Missions** | Informational / historical analysis; perspective-taking with Indigenous perspectives |
| **Japanese American Internment** | Historical informational text; memoir excerpts; primary documents |
| **Tech Industry & Silicon Valley** | Informational articles on innovation, entrepreneurship, equity in STEM |

#### Science & Current Events Contexts

| Topic | Suggested Use |
|---|---|
| **Drought and Water Policy** | Argumentative / informational; data-driven sources; multiple stakeholder perspectives |
| **Wildfire Science and Management** | Informational articles; cause/effect structure; science + policy intersection |
| **Earthquake Preparedness** | Science informational; procedural and explanatory writing |
| **Renewable Energy** | Argumentative or informational; solar, wind, and geothermal contexts |
| **Biodiversity Conservation** | Literary or informational; endangered species; habitat restoration |

### English Learner (EL) Considerations

California has one of the largest English Learner populations in the nation — approximately 25–30% of K–12 students are classified as English Learners, predominantly Spanish-speaking. Item writers and passage selectors should:

| Consideration | Guidance |
|---|---|
| **Vocabulary** | Avoid idioms that rely on cultural knowledge not shared by EL students; define unavoidable domain-specific terms in a sidebar or glossary |
| **Sentence structure** | Use clear, well-formed sentences in stems and options; avoid overly complex syntactic inversions in item stems |
| **Bilingual glossaries** | Designated support; passages should not be written to make glossaries ineffective |
| **Cultural familiarity** | Include contexts reflecting Latin American, East Asian, South Asian, and Southeast Asian cultures alongside mainstream American contexts |
| **Stimulus art/photography** | When used, images should be inclusive and contextually supportive |

## 11. Quality Checklist

Use this checklist before finalizing any generated item or item set.

### Standards Alignment

- [ ] Item is tagged to one primary CCSS ELA standard (e.g., RI.6.2)
- [ ] Standard matches the claim and target subclaim (e.g., RI.6.2 → Claim 1B)
- [ ] DOK level is consistent with the cognitive demand of the task
- [ ] Grade-level standard is appropriate for the intended grade band

### Passage Requirements

- [ ] Passage Lexile falls within the target range for the grade (see Section 7)
- [ ] Passage is authentic or high-quality original writing; no "textbook-style" passages
- [ ] Passage topic is appropriate (no bias, violence, religion, or brand names)
- [ ] Passage length is appropriate for the item type and grade
- [ ] Passage source is credited (author, title, date if applicable)
- [ ] Informational passages cite data accurately; no invented statistics

### Item Quality (All Types)

- [ ] Stem is a clear, complete question or directive
- [ ] All options are plausible (no obviously wrong distractors)
- [ ] Correct answer is unambiguously supported by the passage
- [ ] No grammatical clues in options (all options parallel in form and length)
- [ ] No "All of the above" or "None of the above" options
- [ ] Correct answer position rotated across an item set (avoid always B or C)
- [ ] Item can be answered from the passage alone; no prior knowledge required

### EBSR-Specific Checks

- [ ] Part B options are direct quotes or near-quotes from the passage
- [ ] Each Part B distractor logically corresponds to a Part A distractor
- [ ] Correct Part B quote unambiguously supports correct Part A answer
- [ ] Both parts are tagged to appropriate (related) standards

### PT-FW Checks

- [ ] Source set includes 2 sources (Gr 3–5) or 3 sources (Gr 6–11)
- [ ] Sources represent at least two different perspectives or angles on the topic
- [ ] Prompt clearly specifies the writing type (argumentative or informational)
- [ ] Prompt includes the "be sure to" checklist for student guidance
- [ ] Prompt is debatable (argumentative) or clearly focused (informational)
- [ ] Rubric dimensions align to the three CAASPP ELA FW traits

### EL and Accessibility

- [ ] No idioms or culturally exclusive references in item stems
- [ ] Text-to-speech compatible (no items that would be invalidated by audio)
- [ ] Item is appropriate for California's diverse student population

## 12. Prompt Patterns

The following patterns map common user requests to generation strategies for the AI.

---

### Pattern 1: "Generate a reading comprehension item for Grade [X]"

**Interpretation:** Default to an EBSR (2-point, two-part) item for Claim 1 (Reading). Use DOK 2 for Grades 3–5, DOK 3 for Grades 6–11.

**Generation Recipe:**
1. Select or generate a passage at the appropriate Lexile (Section 7)
2. Identify the primary target standard (RL or RI based on genre)
3. Generate EBSR using Template 1 (Gr 3–5) or Template 2 (Gr 6–8)
4. Ensure Part B options are direct quotes from the passage
5. Tag item: state=CA, subject=ELA, grade=[X], claim=1A or 1B, dok=[2 or 3]

---

### Pattern 2: "Generate a Performance Task writing prompt for Grade [X]"

**Interpretation:** Generate a full PT package: source set description + PT-ST question + PT-FW argumentative or informational prompt. Use Template 3 for PT-FW.

**Generation Recipe:**
1. Choose a grade-appropriate debatable or explanatory topic (Section 10 California topics strongly preferred)
2. Draft 2–3 source descriptions with Lexile and angle noted
3. Write PT-ST question requiring evidence from both sources
4. Write PT-FW prompt following Template 3 format, including "be sure to" list
5. Include scoring rubric (Section 8) in the output
6. Tag: state=CA, subject=ELA, grade=[X], claim=2B+2C, dok=3

---

### Pattern 3: "Generate a vocabulary item"

**Interpretation:** Generate an SR item targeting L.[GRADE].4.a (context clues) using Template 4.

**Generation Recipe:**
1. Select a passage excerpt that contains a Tier 2 or Tier 3 target word with adequate context
2. Use Template 4 exactly — cite the sentence with the target word
3. Construct four options: one clearly correct, three plausible but wrong
4. Ensure no option uses the root of the target word
5. Tag: state=CA, subject=ELA, grade=[X], claim=1A or 1B, standard=L.[X].4.a, dok=2

---

### Pattern 4: "Generate a multi-select item about author's purpose"

**Interpretation:** Generate an MS item for Claim 1, targeting RI.[GRADE].6 or RL.[GRADE].6 (point of view / purpose). Select 2–3 correct answers from a 5–6 option field.

**Generation Recipe:**
1. Provide or reference a passage with clear authorial purpose and craft choices
2. Stem: "Select the TWO [or THREE] [reasons / examples / details] that show how the author develops [purpose/point of view]."
3. Generate 5–6 options: 2–3 correct, 2–3 distractors (plausible but unsupported)
4. Verify all correct options are independently supported by distinct passages or techniques
5. Tag: state=CA, subject=ELA, grade=[X], claim=1A or 1B, standard=RI/RL.[X].6, dok=2–3

---

### Pattern 5: "Generate a complete practice set for Grade [X]"

**Interpretation:** Generate a mini-assessment package with one passage set and items across all major CAASPP item types.

**Generation Recipe:**
1. Select or generate one literary passage and one informational passage (or a paired set) at the appropriate Lexile
2. Generate items in this sequence:
   - 2–3 SR items (Claim 1, DOK 1–2)
   - 1 MS item (Claim 1, DOK 2–3)
   - 1–2 EBSR items (Claim 1, DOK 2–3)
   - 1 TE-Selectable item (Claim 2 or 4)
   - 1 PT-ST item (Claim 2B)
   - 1 PT-FW prompt (Claim 2C) — optional, note it requires a source set
3. Tag each item with claim, subclaim, standard, DOK
4. Include scoring rubrics for PT-ST and PT-FW
