| Field | Detail |
|---|---|
| **Assessment Name** | Iowa Statewide Assessment of Student Progress (ISASP) — Mathematics |
| **Administering Agency** | Iowa Department of Education |
| **Vendor** | IA State DOE |

| **Score Scale** | 4 performance levels; scaled score varies by grade |
| **Reporting** | Individual Student Report; School, District, State aggregates |

> **ISASP Mathematics:** The Iowa Statewide Assessment of Student Progress measures student mastery of the Iowa Core Standards for Mathematics. Items assess conceptual understanding, procedural fluency, and application in real-world and mathematical contexts.

### Performance Levels

| Level | Label | Description |
|---|---|---|
| 4 | **Advanced** | Thorough understanding; applies mathematics in novel and complex situations; constructs valid mathematical arguments |
| 3 | **Proficient** | Adequate understanding; solves grade-level problems accurately; applies mathematics to real-world contexts |
| 2 | **Progressing** | Partial understanding; applies procedures in familiar contexts but struggles with novel problems |
| 1 | **Beginning** | Minimal understanding; significant conceptual and procedural gaps |

## 5. Item Types & Formats

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Real-world or mathematical context                      |
|  Machine scored                                          |
|  DOK 1–3                                                 |
+----------------------------------------------------------+
```

**MC Example (Grade 6, DOK 2, 6.RP.A.3):**

An Iowa corn farmer harvests 9,600 bushels of corn from 60 acres. At this rate, how many bushels would the farmer expect to harvest from 85 acres?

A. 10,200 bushels
B. 13,600 bushels
C. 14,400 bushels
D. 16,000 bushels

*Correct Answer: B (9600/60 = 160 bushels per acre; 160 x 85 = 13,600)*
*Alignment: 6.RP.A.3 | Ratios & Proportional Relationships | DOK 2*

---

**MC Example (Grade 5, DOK 2, 5.NBT.B.7):**

The Des Moines metro area population grew by 23,456 people in one decade and 31,278 people in the next decade. What was the total population growth over both decades?

A. 7,822 people
B. 44,734 people
C. 54,734 people
D. 547,340 people

*Correct Answer: C (23,456 + 31,278 = 54,734)*
*Alignment: 5.NBT.B.7 | Number & Operations in Base Ten | DOK 1*

---

### Constructed Response (CR)

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE — 0–2 points                       |
|                                                          |
|  Show work and explain reasoning                         |
|  Real-world or mathematical context                      |
|  Human scored                                            |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**CR Example (Grade 8, DOK 3, 8.F.B.4):**

Iowa has been expanding its wind energy capacity. The table below shows the number of wind turbines installed in Iowa over time:

| Year | Wind Turbines |
|---|---|
| 2015 | 3,200 |
| 2017 | 3,680 |
| 2019 | 4,160 |
| 2021 | 4,640 |

Is this a linear relationship? Write a function that models the number of wind turbines based on years after 2015. Then predict how many turbines Iowa will have in 2027 if this trend continues. Show your work and explain your reasoning.

*Scoring:*
- *2 pts: Correctly identifies linear relationship; writes correct function (T = 240y + 3200 where y = years after 2015); correct prediction for 2027 (6,080 turbines); clear explanation*
- *1 pt: Correct function or prediction with incomplete explanation, OR correct approach with computational error*
- *0 pts: Incorrect approach or blank*

## 8. Scoring Rubrics

### Constructed Response (CR) Rubric — 0–2 Points

| Score | Criteria |
|---|---|
| 2 | Correct solution with clear mathematical reasoning. Work shown systematically. Explanation demonstrates conceptual understanding. Appropriate mathematical vocabulary used. |
| 1 | Partial understanding with minor errors. Correct approach demonstrated but final answer contains an error. OR Correct answer given without sufficient work or explanation. |
| 0 | Incorrect approach, no understanding shown, or blank. |

### CR Scoring Notes

- **Work must be shown** for full credit on all CR items.
- **Explanations** should reference mathematical concepts, not just describe steps.
- **Computational errors** with correct reasoning earn partial credit (1 point).

## 10. Contextualization — Iowa Mathematics

When generating problem contexts, use authentic Iowa settings:

### Iowa Math Context Guide

| Context | Domain | Grade Band |
|---|---|---|
| Iowa corn production (bushels per acre, yield data) | Ratios, Operations, Data | 3–8 |
| Iowa wind energy statistics (turbines, megawatts) | Functions, Data Analysis, Statistics | 5–11 |
| Des Moines population and metro growth data | Statistics, Proportionality, Functions | 5–11 |
| Iowa soybean farming and crop rotation data | Ratios, Fractions, Data Analysis | 3–8 |
| Iowa state fair attendance and economics | Operations, Data Analysis | 3–7 |
| Loess Hills elevation and geographic dimensions | Geometry, Measurement | 4–8 |
| Des Moines River flow rates and flood data | Ratios, Measurement, Data | 5–11 |
| Iowa highway distances (I-80, I-35) | Ratios, Proportionality | 4–8 |
| Iowa hog and cattle production data | Statistics, Ratios, Operations | 4–8 |
| Iowa renewable energy and ethanol production | Functions, Data Analysis | 6–11 |

### Suggested Problem Contexts by Grade

**Grades 3–5:**
- Counting bushels of corn at an Iowa grain elevator
- Measuring the dimensions of a rectangular farm field near Ames
- Calculating costs of food items at the Iowa State Fair

**Grades 6–8:**
- Comparing corn yields across Iowa counties using unit rates
- Analyzing Iowa wind turbine installation data to identify trends
- Calculating flow rates along the Des Moines River during spring flooding

**Grade 11:**
- Modeling Iowa wind energy capacity growth as a function of time
- Analyzing scatter plots of Iowa corn yield vs. growing season temperature
- Statistical analysis of Des Moines metropolitan population growth trends

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] Iowa Core Standards code is accurate and grade-appropriate
- [ ] MC items have exactly 4 options with one correct answer
- [ ] CR items require work to be shown and reasoning explained
- [ ] CR scored on 0–2 point scale
- [ ] Calculator policy appropriate for grade level
- [ ] Iowa real-world context used where appropriate
- [ ] Distractors represent actual student computational or conceptual errors
- [ ] All computations verified before item is finalized
- [ ] DOK level matches actual cognitive demand
- [ ] Grade 11 items reflect high school mathematics complexity

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| CR asking only for a final answer | CR must require explanation | Add "Show your work and explain" |
| Using non-Iowa contexts | Misses state contextualization | Use Iowa corn, wind energy, Des Moines, and Loess Hills contexts |
| Items testing only rote computation | ISASP targets DOK 2 primarily | Add real-world context to elevate cognitive demand |
| Grade 11 items at middle school level | Underestimates high school expectations | Use algebra, functions, and statistics at HS level |
| Distractors that are obviously wrong | Does not assess real misconceptions | Base distractors on common student errors |

## 12. Prompt Patterns

### Pattern 1: Real-World Application (MC, DOK 2)
> "[Iowa context]. [Multi-step problem]. What is [answer]?"

### Pattern 2: Justify and Explain (CR, DOK 3)
> "[Iowa scenario]. [Problem]. Show your work and explain how you found your answer."

### Pattern 3: Proportional Reasoning (MC, DOK 2)
> "An Iowa [entity] produces/uses [quantity] in [time/unit]. At this rate, how much [quantity] in [different time/unit]?"

### Pattern 4: Data Interpretation (MC, DOK 2)
> "The [table / graph] shows [Iowa data context]. Based on the data, which statement is correct?"

### Pattern 5: Multi-Step Problem Solving (CR, DOK 3)
> "[Iowa scenario with multiple constraints]. Determine [answer]. Show your work and explain whether your answer is reasonable."

### Pattern 6: Comparison and Reasoning (CR, DOK 3)
> "Two students solved this problem differently. [Method A] and [Method B]. Who is correct? Use mathematics to justify your answer."
