## 3. TEST STRUCTURE

ATLAS Mathematics is administered in **2 sessions** over one or two days.

```
+-------------------------------------------------------------------+
|          ATLAS MATH TEST STRUCTURE (Grades 3–8, 10)               |
+---------------------------------+---------------------------------+
|   SESSION 1                     |   SESSION 2                     |
|   ~60–75 minutes                |   ~60–75 minutes                |
|                                 |                                 |
|  MULTIPLE CHOICE                |  MULTIPLE CHOICE                |
|  MULTI-SELECT                   |  MULTI-SELECT                   |
|  NO calculator (all grades)     |  CONSTRUCTED RESPONSE           |
|                                 |  Calculator allowed (Gr 6–8,10) |
+---------------------------------+---------------------------------+
```

### Session Item Counts by Grade Band

| Session       | Grades 3–5                       | Grades 6–8                       | Grade 10                         |
|---------------|----------------------------------|----------------------------------|----------------------------------|
| Session 1     | 18–24 MC/MS items (no calc)      | 18–24 MC/MS items (no calc)      | 18–24 MC/MS items (no calc)      |
| Session 2     | 14–20 MC/MS + 2–3 CR items      | 14–20 MC/MS + 2–3 CR (calc)     | 14–20 MC/MS + 2–3 CR (calc)     |

> **Calculator Policy:** No calculators for any portion of Grades 3–5. For Grades 6–8 and 10, a calculator is available during Session 2 only.

## 5. ITEM TYPES

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Single correct answer                                   |
|  Machine scored                                          |
|  DOK 1–2                                                 |
|  Both sessions                                           |
+----------------------------------------------------------+
```

**MC Example (Grade 6, DOK 2, 6.RP — Ratios):**

An Arkansas rice farmer plants 5 rows of rice for every 3 rows of soybeans. If the farmer plants 40 rows of rice, how many rows of soybeans does the farmer plant?

- A. 15
- B. 24
- C. 30
- D. 67

*Correct Answer: B (40 / 5 = 8 groups; 8 x 3 = 24)*

---

### Multi-Select (MS)

```
+----------------------------------------------------------+
|  MULTI-SELECT — 1 point                                  |
|                                                          |
|  5–6 options                                             |
|  Student selects ALL correct answers (typically 2)       |
|  Machine scored; all-or-nothing                          |
|  DOK 2–3                                                 |
|  Both sessions                                           |
+----------------------------------------------------------+
```

**MS Example (Grade 8, DOK 2, 8.SP — Statistics):**

*A student recorded the daily high temperature at Hot Springs National Park for 10 days and calculated a mean of 78 degrees F and a median of 76 degrees F.*

Select TWO statements that are supported by this data.

- A. Every day the temperature was exactly 78 degrees F
- B. Half of the days had a high temperature at or below 76 degrees F
- C. The total of all 10 temperatures divided by 10 equals 78 degrees F
- D. The temperature never went above 80 degrees F
- E. The range of temperatures was exactly 2 degrees F

*Correct Answers: B and C*

---

### Constructed Response (CR)

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE — 0–2 points                       |
|                                                          |
|  Multi-step problem requiring shown work                 |
|  May include Parts A, B                                  |
|  DOK 2–3                                                 |
|  Human scored using CR rubric                            |
|  Session 2 only (2–3 per test)                           |
+----------------------------------------------------------+
```

**CR Example (Grade 7, DOK 3, 7.RP — Proportional Relationships):**

*"Two hiking trails in the Ozark Mountains have different difficulty ratings. Trail A covers 6 miles with an elevation gain of 1,200 feet. Trail B covers 4.5 miles with an elevation gain of 1,050 feet.*

*Part A: Find the elevation gain per mile for each trail. Show your work.*
*Part B: Which trail has a steeper average grade? Explain your reasoning."*

## 8. SCORING RUBRICS

### Constructed Response (CR) Rubric — 0–2 Points

| Score | Criteria                                                                                                    |
|-------|-------------------------------------------------------------------------------------------------------------|
| 2     | Correct answer with complete, clearly shown work; mathematical reasoning is sound and organized              |
| 1     | Partially correct; work shown is incomplete or contains a minor error; some mathematical understanding       |
| 0     | Incorrect or no work shown; blank; off-task; no mathematical understanding demonstrated                     |

### Multi-Select Scoring

| Item Type            | Scoring                                                              |
|----------------------|----------------------------------------------------------------------|
| MS (1-point)         | All-or-nothing: all correct answers must be selected                 |

## 10. CONTEXTUALIZATION — ARKANSAS MATH

When generating real-world math contexts, prioritize authentic Arkansas settings:

### Recommended Math Contexts

| Context                                   | Grade Band | Math Domains                                    |
|-------------------------------------------|------------|-------------------------------------------------|
| Hot Springs temperature data              | 3–8        | Data analysis, statistics, integers, graphing    |
| Ozark Mountain elevation data             | 5–10       | Measurement, ratios, proportional reasoning      |
| Arkansas rice production statistics       | 4–10       | Multiplication, ratios, percent, data analysis   |
| Buffalo River distance and flow data      | 5–8        | Measurement, rates, proportional reasoning       |
| Crater of Diamonds park statistics        | 3–7        | Data analysis, probability, fractions            |
| Arkansas River navigation distances       | 4–8        | Measurement, geometry, fractions                 |
| Ozark trail hiking statistics             | 5–10       | Ratios, rates, proportional reasoning            |
| Arkansas poultry and agriculture data     | 4–8        | Multiplication, large numbers, ratios            |
| Little Rock population data              | 6–10       | Percent change, data analysis, linear functions  |
| Arkansas state park visitor counts        | 3–8        | Data analysis, graphing, statistics              |

### Sample Context Sentence Starters

- "A rice farmer in the Arkansas Delta harvested [X] bushels from [Y] acres..."
- "The temperature of the thermal springs at Hot Springs NP averages [X] degrees F..."
- "A hiker on the Ozark Highlands Trail traveled [X] miles over [Y] hours..."
- "The table shows the number of diamonds found at Crater of Diamonds State Park over [years]..."
- "Students measured the water flow rate of the Buffalo National River and recorded..."

## 11. QUALITY CHECKLIST AND COMMON PITFALLS

### Quality Checklist

- [ ] Standard code uses Arkansas Mathematics format ([Grade].[Domain].[Standard])
- [ ] Practice standard alignment identified for CR items
- [ ] Calculator policy matches session and grade level
- [ ] CR items require shown work and may include multi-part structure
- [ ] All numerical values produce clean, non-ambiguous answers
- [ ] Arkansas-specific real-world context used where appropriate
- [ ] Distractors reflect specific, identifiable student error types
- [ ] DOK level verified against actual cognitive demand
- [ ] Units and labels are correct throughout
- [ ] Grade 10 items include age-appropriate algebraic and functional content
- [ ] MS items specify how many options to select
- [ ] Performance level names match Arkansas labels

### Common Pitfalls

| Pitfall                                  | Problem                                           | Fix                                                      |
|------------------------------------------|---------------------------------------------------|----------------------------------------------------------|
| Calculator in Session 1 (Gr 3–5)        | No calculator allowed for any Grades 3–5 portion  | Design items without calculator dependence for Gr 3–5    |
| CR rubric exceeds 0–2 range             | ATLAS Math CR items are scored 0–2                 | Use only the 0–2 rubric scale                            |
| Generic context (no AR specificity)      | ATLAS values authentic Arkansas contexts           | Use Hot Springs, Ozarks, Delta rice farms, Arkansas River|
| CR without "show your work" directive   | DOK 3 requires demonstrated reasoning              | Include "Show your work" or "Explain your reasoning"     |
| Missing Grade 10 content                | ATLAS tests Grade 10 with advanced math            | Include algebra, functions, and geometry for Grade 10    |
| MS item not specifying selection count   | Students must know how many to select              | Always include "Select TWO" or similar directive         |
| Wrong performance level labels           | Arkansas uses specific level names                 | Use In Need of Support / Close / Ready / Exceeding      |

## 12. PROMPT PATTERNS

The following patterns reflect the most common ATLAS Mathematics item structures.

### Pattern 1: Contextual Computation (MC, DOK 2)
> "[Arkansas setting]. [Given information]. [Mathematical question requiring multi-step application]."
> (Options: correct answer + three specific error-type distractors)

### Pattern 2: Multi-Step Application (CR Part A, DOK 2)
> "A [Arkansas context] has [given data]. [Part A: computation requiring setup + solve]. Show your work."

### Pattern 3: Rate or Ratio in Context (MC or CR, DOK 2)
> "[Arkansas scenario] involves [quantity A] for every [quantity B]. [Question about scaling, unit rate, or comparison]."

### Pattern 4: Explain in Context (CR Part B, DOK 3)
> "Explain what your answer to Part A means in the context of [Arkansas scenario]."

### Pattern 5: Comparison with Justification (CR, DOK 3)
> "Two [Arkansas scenarios] are described: [Scenario A] and [Scenario B]. Which is [more efficient / greater / better value]? Use mathematical evidence to justify your answer."

### Pattern 6: Data Interpretation (MC or MS, DOK 2)
> "The [table / graph] below shows [Arkansas data]. Based on the data, which statement is BEST supported?"

### Pattern 7: Statistical Reasoning (MS, DOK 2–3)
> "[Arkansas data scenario]. Select TWO statements that are supported by this data."
