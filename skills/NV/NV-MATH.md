### Achievement Level Descriptors (ALDs)

| Level | Label | Description |
|---|---|---|
| 4 | **Standard Exceeded** | Student demonstrates thorough understanding of and ability to apply mathematical concepts and procedures; solves complex problems with precision and justifies reasoning |
| 3 | **Standard Met** | Student demonstrates adequate understanding of mathematical concepts and procedures; solves grade-level problems and provides sufficient explanations |
| 2 | **Standard Nearly Met** | Student demonstrates partial understanding of mathematical concepts and procedures; solves routine problems but struggles with multi-step or non-routine tasks |
| 1 | **Standard Not Met** | Student demonstrates minimal understanding of mathematical concepts and procedures; significant gaps in foundational skills |

> **Cut scores** are set by the Smarter Balanced Assessment Consortium and adopted by the Nevada State Board of Education. For item-writing purposes, focus on ALDs 3 and 4 as the target proficiency range.

## 5. Item Types & Formats

### SR — Selected Response (1 point)

Standard four-option multiple-choice. Student selects one best answer.

```
+-----------------------------------------------------------------+
|  [Context or setup — may include a diagram, table, or scenario] |
|                                                                   |
|  Question stem targeting a specific standard.                     |
|                                                                   |
|  O  A. [Distractor — common computational error]                  |
|  O  B. [Correct answer]                                           |
|  O  C. [Distractor — conceptual misunderstanding]                 |
|  O  D. [Distractor — partial solution or wrong operation]         |
+-----------------------------------------------------------------+
Points: 1 (correct) / 0 (incorrect)
```

**Construction Rules:**
- All four options must be plausible; distractors should reflect common student errors
- Numerical distractors should result from identifiable mistakes (wrong operation, sign error, place value error)
- Avoid "All of the above" / "None of the above"
- Stem must be a complete question or clear directive
- Include units in options when applicable

---

### MS — Multi-Select (1 point)

Student selects ALL correct answers from a set of typically five or six options.

```
+-----------------------------------------------------------------+
|  [Context or setup]                                               |
|                                                                   |
|  Question stem — "Select ALL that apply" or                       |
|  "Select the TWO expressions that..."                             |
|                                                                   |
|  [ ]  A. [Option]                                                 |
|  [ ]  B. [Option — CORRECT]                                       |
|  [ ]  C. [Option]                                                 |
|  [ ]  D. [Option — CORRECT]                                       |
|  [ ]  E. [Option]                                                 |
+-----------------------------------------------------------------+
Points: 1 (all correct selected, none incorrect) / 0 (any other)
```

**Construction Rules:**
- Specify the number of correct answers in the stem when count is fixed
- When count is unspecified, use "Select ALL that apply"
- Typically 2–3 correct answers from a field of 5–6
- Each option should be independently evaluable

---

### EQ — Equation / Numeric Entry (1–2 points)

Student enters a numeric value, expression, or equation into a response field. May include fraction entry, coordinate entry, or expression editor.

```
+-----------------------------------------------------------------+
|  [Context or setup — may include a diagram or data table]        |
|                                                                   |
|  What is the area, in square feet, of the rectangle?              |
|                                                                   |
|  +---------------------------+                                    |
|  |  [Numeric entry field]    |  square feet                      |
|  +---------------------------+                                    |
+-----------------------------------------------------------------+
Points: 1 (exact match or equivalent form) / 0 (incorrect)
```

**Variations:**
- **Fraction entry:** Two-field input (numerator/denominator)
- **Coordinate entry:** (x, y) field pair
- **Expression entry:** Equation editor for simplified expressions
- **Multiple blanks:** Fill in two or more values (2 points possible)

**Construction Rules:**
- Specify acceptable equivalent forms (e.g., 0.5 = 1/2 = 50%)
- State required units in the stem or adjacent to the entry field
- Avoid ambiguous rounding situations; specify "Round to the nearest tenth" when needed
- For multi-blank items, each blank scores independently

---

### SCR — Short Constructed Response (0–2 points)

Student provides a brief written explanation, shows work, or justifies a solution. Scored with a rubric.

```
+-----------------------------------------------------------------+
|  [Context or setup]                                               |
|                                                                   |
|  Part A: Solve the equation 3x + 7 = 22. Show your work.         |
|                                                                   |
|  [Open response field with equation editor]                       |
|                                                                   |
|  Part B: Explain how you know your answer is correct.             |
|                                                                   |
|  [Text response field]                                            |
+-----------------------------------------------------------------+
Scoring: 0–2 points
  2 — Correct solution with clear, complete explanation or work shown
  1 — Correct solution with incomplete explanation, OR incorrect solution
      with substantially correct process
  0 — Incorrect solution with no valid work or explanation
```

**Construction Rules:**
- Clearly state what the student must show (work, explanation, or both)
- Part A / Part B structure is common; Part A is computational, Part B is reasoning
- Rubric must define what constitutes partial credit
- Avoid prompts that can be answered with a single number (use EQ instead)

---

### PT-ER — Performance Task Extended Response (0–4 points)

Multi-part real-world scenario requiring extended mathematical reasoning and modeling. Part of the fixed-form Performance Task session.

```
+-----------------------------------------------------------------+
|  PERFORMANCE TASK                                                 |
|                                                                   |
|  [Rich scenario: 100–300 words describing a real-world context]   |
|  [May include data tables, graphs, diagrams, maps]                |
|                                                                   |
|  Part A: [Computation or setup question — 1 point]                |
|  Part B: [Application or extension — 1 point]                     |
|  Part C: [Reasoning, justification, or modeling — 2 points]       |
|                                                                   |
|  [Response fields: numeric entry + open text]                     |
+-----------------------------------------------------------------+
Scoring: 0–4 points total across parts
```

**Construction Rules:**
- Scenario must be authentic and grade-appropriate
- Parts should scaffold: Part A provides a foundation for Parts B and C
- Part C must require explanation or justification, not just computation
- Calculator is available for PT items at Grades 6+
- Nevada contexts strongly preferred (see Section 10)

## 6. DOK / Cognitive Complexity

### DOK Level Descriptions for Mathematics

| DOK | Label | Description | Example Tasks |
|---|---|---|---|
| **1** | Recall & Reproduction | Recall a fact, definition, or formula; perform a routine one-step calculation | Compute 3/4 + 1/2; identify a shape by name; evaluate an expression given a value |
| **2** | Skills & Concepts | Apply a concept in a familiar context; make a decision about approach; solve a multi-step routine problem | Solve a two-step word problem; determine the area of a composite figure; interpret a line graph |
| **3** | Strategic Thinking | Develop a plan to solve a non-routine problem; justify a solution; analyze and compare approaches; synthesize information from multiple representations | Explain why a solution method works; model a real-world scenario with an equation; critique a student's incorrect reasoning |

> Nevada SBA Mathematics does not formally use DOK 4 on the summative assessment. Extended modeling occurs in the PT but is scored through the rubric rather than a DOK 4 designation.

### DOK Distribution Targets for Item Generation

| Item Type | Target DOK | Rationale |
|---|---|---|
| SR — computation | 1 | Single-step procedure or recall |
| SR — application | 2 | Apply concept to solve a problem |
| MS — identify properties/equivalences | 2 | Evaluate multiple statements or expressions |
| EQ — single computation | 1–2 | Produce a numeric or algebraic answer |
| EQ — multi-step | 2–3 | Requires planning and multiple operations |
| SCR — explain/justify | 2–3 | Part A often DOK 2; Part B reasoning is DOK 3 |
| PT-ER | 3 | Multi-part modeling with justification |

## 7. Text Complexity

### Quantitative Guidelines for Mathematical Contexts

| Grade | Word Problem Length | Data Table Size | Graph Complexity |
|---|---|---|---|
| 3 | 30–60 words | 2–3 rows, 2–3 columns | Bar graphs, picture graphs |
| 4 | 40–80 words | 3–4 rows, 2–4 columns | Bar graphs, line plots |
| 5 | 50–100 words | 3–5 rows, 2–4 columns | Line graphs, coordinate grids |
| 6 | 60–120 words | 4–6 rows, 3–5 columns | Line graphs, histograms, dot plots |
| 7 | 70–140 words | 4–7 rows, 3–5 columns | Scatter plots, box plots |
| 8 | 80–160 words | 5–8 rows, 3–6 columns | Scatter plots with trend lines, two-way tables |
| 11 | 100–200 words | 5–10 rows, 3–6 columns | Functions, regression plots, normal distributions |

### Linguistic Complexity Guidelines

| Requirement | Specification |
|---|---|
| **Vocabulary** | Use standard mathematical terminology appropriate to the grade; define non-standard terms in the stem |
| **Sentence structure** | Minimize syntactic complexity; avoid nested clauses in word problems |
| **Reading load** | Math items should assess mathematical reasoning, not reading ability; keep language accessible |
| **EL considerations** | Avoid idioms, cultural references, and unnecessary contextual detail that increases linguistic demand without mathematical purpose |
| **Units and notation** | Use standard notation (e.g., $, %, ft, m); spell out units in lower grades (Gr 3–5) |
| **Diagrams and visuals** | Provide clear labels, appropriate scale, and alt text descriptions for all graphics |

## 8. Scoring Rubrics

### SCR — Short Constructed Response (0–2 points)

| Score | Descriptor |
|---|---|
| **2** | The response demonstrates a thorough understanding of the mathematical concept. The solution is correct, and the work or explanation is complete, clear, and mathematically sound. |
| **1** | The response demonstrates partial understanding. The solution may be correct with an incomplete explanation, OR the process/reasoning is substantially correct but leads to an incorrect answer due to a minor computational error. |
| **0** | The response demonstrates insufficient understanding. The solution is incorrect with no valid mathematical reasoning, OR the response is blank, off-topic, or irrelevant. |

### PT-ER — Performance Task Extended Response (0–4 points)

| Score | Descriptor |
|---|---|
| **4** | The response demonstrates a thorough understanding of all parts of the task. All computations are correct. The explanation or justification is clear, complete, and mathematically precise. The model or approach is appropriate and well-supported. |
| **3** | The response demonstrates adequate understanding. Most computations are correct. The explanation is mostly clear and logical, with minor gaps in reasoning or precision. |
| **2** | The response demonstrates partial understanding. Some computations are correct, but significant errors or omissions appear. The explanation is incomplete or partially flawed. |
| **1** | The response demonstrates minimal understanding. Few computations are correct. The explanation is largely absent or incorrect. Only one part of the task is meaningfully addressed. |
| **0** | The response is completely incorrect, blank, off-topic, or a copy of the stimulus without any mathematical work. |

> **Machine scoring:** Nevada SBA uses automated scoring for SR, MS, and EQ items. SCR and PT-ER items are scored by trained human raters with AI-assisted scoring as a second read.

| Consideration | Guidance |
|---|---|

| **Sentence structure** | Keep word problems concise; use simple sentence structures; avoid passive voice and embedded clauses |
| **Bilingual glossaries** | Designated support providing math term translations; items should not rely on nuanced English phrasing |
| **Cultural familiarity** | Nevada-specific contexts should include brief clarifying details so all students can access the scenario |
| **Visual supports** | Provide diagrams, tables, and graphs to reduce linguistic load when possible |

## 11. Quality Checklist

Use this checklist before finalizing any generated item or item set.

### Standards Alignment

- [ ] Item is tagged to one primary CCSS-M standard (e.g., 6.RP.3)
- [ ] Standard matches the claim and target subclaim
- [ ] DOK level is consistent with the cognitive demand of the task
- [ ] Grade-level standard is appropriate for the intended grade band

### Mathematical Accuracy

- [ ] The correct answer is mathematically sound and unambiguous
- [ ] All numerical values, units, and labels are accurate
- [ ] Diagrams and graphs are drawn to appropriate scale with clear labels
- [ ] Distractors result from identifiable, common student errors
- [ ] Multiple solution paths, if they exist, all yield the same correct answer

### Item Quality (All Types)

- [ ] Stem is a clear, complete question or directive
- [ ] All options are plausible (no obviously wrong distractors)
- [ ] No grammatical clues in options (all options parallel in form)
- [ ] No "All of the above" or "None of the above" options
- [ ] Correct answer position rotated across an item set
- [ ] Calculator policy is respected (non-calculator items are hand-solvable)

### Word Problem Checks

- [ ] Context is authentic and grade-appropriate
- [ ] Reading load is minimized; language does not obscure the math
- [ ] Unnecessary contextual information is avoided (unless intentionally assessing information extraction)
- [ ] Units are clearly stated in the stem and answer options
- [ ] Numbers are realistic for the context (e.g., reasonable prices, distances, measurements)

### SCR / PT-ER Checks

- [ ] Rubric clearly defines each score point
- [ ] Multiple valid solution paths are anticipated and credited
- [ ] Partial credit criteria are specific and actionable for scoring
- [ ] Part scaffolding is logical (earlier parts support later parts)
- [ ] Explanation prompts require genuine mathematical reasoning, not just restating answers

### EL and Accessibility

- [ ] No idioms or culturally exclusive references in item stems
- [ ] Text-to-speech compatible for non-math text
- [ ] Diagrams include alt text descriptions
- [ ] Item is appropriate for Nevada's diverse student population
- [ ] Bilingual glossary terms are standard mathematical vocabulary

### Pattern 1: "Generate a math item for Grade [X]"

**Interpretation:** Default to an SR (1-point) item for Claim 1 (Concepts & Procedures). Use DOK 1 for basic computation, DOK 2 for application.

**Generation Recipe:**
1. Identify the target domain and standard for the grade
2. Generate SR using Template 1 (Gr 3–5) or adapt for Gr 6–11
3. Construct four options with identifiable error patterns as distractors
4. Verify calculator policy compliance
5. Tag item: state=NV, subject=MATH, grade=[X], claim=1, dok=[1 or 2]

### Pattern 2: "Generate a word problem for Grade [X]"

**Interpretation:** Generate an EQ or SCR item for Claim 2 (Problem Solving) with a real-world context. Prefer Nevada contexts from Section 10.

**Generation Recipe:**
1. Select a grade-appropriate Nevada context (Section 10)
2. Write a word problem at appropriate linguistic complexity (Section 7)
3. Use Template 2 (EQ) for numeric answer or Template 3 (SCR) if explanation is needed
4. Verify numbers are realistic and computation is grade-appropriate
5. Tag: state=NV, subject=MATH, grade=[X], claim=2, dok=2

### Pattern 3: "Generate an item where students explain their reasoning"

**Interpretation:** Generate an SCR (2-point) item for Claim 3 (Communicating Reasoning) using Template 3.

**Generation Recipe:**
1. Choose a concept where common misconceptions exist at the target grade
2. Optionally present student work with an error to critique
3. Part A: Identify or solve; Part B: Explain or justify
4. Write rubric with clear partial credit criteria
5. Tag: state=NV, subject=MATH, grade=[X], claim=3, dok=3

---

### Pattern 4: "Generate a Performance Task for Grade [X]"

**Interpretation:** Generate a PT-ER (4-point) multi-part item for Claim 4 (Modeling) using Template 4.

**Generation Recipe:**
1. Select a rich Nevada context (Section 10 — strongly preferred)
2. Build a three-part scaffolded problem (Part A computation, Part B application, Part C modeling/justification)
3. Include relevant data tables, graphs, or diagrams
4. Write a 4-point rubric following Section 8 guidelines
5. Verify calculator is available (Grades 6+)
6. Tag: state=NV, subject=MATH, grade=[X], claim=4, dok=3

---

### Pattern 5: "Generate a complete practice set for Grade [X]"

**Interpretation:** Generate a mini-assessment package covering all four claims.

**Generation Recipe:**
1. Select 1–2 Nevada contexts as unifying themes
2. Generate items in this sequence:
   - 2–3 SR items (Claim 1, DOK 1–2)
   - 1 MS item (Claim 1 or 3, DOK 2)
   - 1–2 EQ items (Claim 2, DOK 2)
   - 1 SCR item (Claim 3, DOK 3)
   - 1 PT-ER item (Claim 4, DOK 3) — optional, note it requires a rich context
3. Tag each item with claim, subclaim, standard, DOK
4. Include scoring rubrics for SCR and PT-ER
5. Verify calculator policy across the set
