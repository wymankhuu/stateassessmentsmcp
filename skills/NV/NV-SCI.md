### Achievement Level Descriptors (ALDs)

| Level | Label | Description |
|---|---|---|
| 4 | **Exceeds the Standard** | Student demonstrates thorough three-dimensional understanding; applies science and engineering practices to novel and complex phenomena; constructs and critiques sophisticated explanations and models |
| 3 | **Meets the Standard** | Student demonstrates adequate three-dimensional understanding; applies science and engineering practices to grade-level phenomena; constructs explanations supported by evidence |
| 2 | **Approaches the Standard** | Student demonstrates partial three-dimensional understanding; applies some science and engineering practices with support; explanations are incomplete or weakly supported |

## 2. Standards Framework

> **Reference:** See `_shared/ngss_framework.md` for full NGSS architecture including Disciplinary Core Ideas, Science and Engineering Practices, and Crosscutting Concepts. This section highlights the key performance expectations tested at each grade.

### Three-Dimensional Assessment Design

All items must integrate all three NGSS dimensions:

| Dimension | Description | Role in Assessment |
|---|---|---|
| **Disciplinary Core Ideas (DCIs)** | Content knowledge organized by domain (Physical Science, Life Science, Earth & Space Science, Engineering) | Defines the content context of the item |
| **Science and Engineering Practices (SEPs)** | What scientists and engineers do (e.g., developing models, analyzing data, constructing explanations) | Defines the cognitive task the student performs |
| **Crosscutting Concepts (CCCs)** | Themes that bridge disciplines (e.g., patterns, cause/effect, systems, energy/matter) | Provides the conceptual lens for reasoning |

## 4. Claims & Blueprint

### Assessment Targets

The Nevada Science Assessment does not use a formal "claims" structure like Smarter Balanced. Instead, items are organized by NGSS performance expectations and assessed through three-dimensional item design. For item generation purposes, the following framework organizes assessment targets:

| Target Area | Description | Weight |
|---|---|---|
| **Science and Engineering Practices (SEPs)** | Assess students' ability to engage in the practices scientists and engineers use | Integrated into every item |
| **Disciplinary Core Ideas (DCIs)** | Assess content knowledge across Physical, Life, and Earth & Space Science | Defines item content |
| **Crosscutting Concepts (CCCs)** | Assess students' ability to apply cross-disciplinary themes | Integrated into every item |

### Science and Engineering Practices — Assessment Focus

| SEP | Description | Frequency |
|---|---|---|
| **SEP 1** — Asking Questions / Defining Problems | Formulate testable questions; define engineering design problems | Low–Moderate |
| **SEP 2** — Developing and Using Models | Create, use, and revise models to explain phenomena or test solutions | High |
| **SEP 3** — Planning and Carrying Out Investigations | Design and evaluate investigations; identify variables | Moderate |
| **SEP 4** — Analyzing and Interpreting Data | Use data to identify patterns, support claims, or evaluate solutions | High |
| **SEP 5** — Using Mathematics and Computational Thinking | Apply math to analyze data, support explanations, and solve problems | Moderate |
| **SEP 6** — Constructing Explanations / Designing Solutions | Build evidence-based explanations; propose design solutions | High |
| **SEP 7** — Engaging in Argument from Evidence | Construct and defend arguments; evaluate competing claims | Moderate–High |
| **SEP 8** — Obtaining, Evaluating, and Communicating Information | Read, synthesize, and communicate scientific information | Low–Moderate |

### Crosscutting Concepts — Assessment Focus

| CCC | Description | Frequency |
|---|---|---|
| **CCC 1** — Patterns | Identify and explain patterns in data, observations, or phenomena | High |
| **CCC 2** — Cause and Effect | Identify causal mechanisms; use evidence to explain why phenomena occur | High |
| **CCC 3** — Scale, Proportion, and Quantity | Apply mathematical relationships; understand effects of scale | Moderate |
| **CCC 4** — Systems and System Models | Define system boundaries; trace flows of matter and energy | Moderate–High |
| **CCC 5** — Energy and Matter | Track flows, cycles, and conservation within systems | Moderate |
| **CCC 6** — Structure and Function | Relate structure of natural and designed objects to their function | Moderate |
| **CCC 7** — Stability and Change | Explain conditions for stability and what drives change in systems | Moderate |

### DOK Distribution

| DOK Level | Approximate Distribution |
|---|---|
| DOK 1 — Recall | ~10–15% |
| DOK 2 — Skills & Concepts | ~45–55% |
| DOK 3 — Strategic Thinking | ~30–40% |

## 5. Item Types & Formats

### SR — Selected Response (1 point)

Standard four-option multiple-choice. Student selects one best answer.

```
+-----------------------------------------------------------------+
|  STIMULUS: [Phenomenon description, data table, or diagram]      |
|                                                                   |
|  Question stem targeting a specific PE (DCI + SEP + CCC).         |
|                                                                   |
|  O  A. [Distractor — common misconception]                        |
|  O  B. [Correct answer — scientifically accurate]                 |
|  O  C. [Distractor — partially correct reasoning]                 |
|  O  D. [Distractor — wrong causal mechanism or process]           |
+-----------------------------------------------------------------+
Points: 1 (correct) / 0 (incorrect)
```

**Construction Rules:**
- All four options must be plausible; distractors should reflect documented student misconceptions
- Correct answer must be scientifically accurate and supported by the stimulus
- Stem should assess a practice (SEP) applied to content (DCI) through a conceptual lens (CCC)
- Avoid "All of the above" / "None of the above"
- Stem must reference the stimulus explicitly

---

### MS — Multi-Select (1 point)

Student selects ALL correct answers from a set of options. Full credit requires all correct options selected and no incorrect options selected.

```
+-----------------------------------------------------------------+
|  STIMULUS: [Continued from cluster stimulus]                      |
|                                                                   |
|  Question stem — "Select the TWO [observations / claims /         |
|  pieces of evidence] that..."                                     |
|                                                                   |
|  [ ]  A. [Option]                                                 |
|  [ ]  B. [Option — CORRECT]                                       |
|  [ ]  C. [Option]                                                 |
|  [ ]  D. [Option — CORRECT]                                       |
|  [ ]  E. [Option]                                                 |
+-----------------------------------------------------------------+
Points: 1 (all correct selected, none incorrect) / 0 (any other)
```

**Construction Rules:**
- Specify the number of correct answers in the stem when count is fixed
- Typically 2–3 correct answers from a field of 4–6
- Each option should represent a distinct scientific claim, observation, or piece of evidence
- Options should be evaluable using the stimulus and scientific reasoning

---

### CR — Constructed Response (0–3 points)

Student writes an explanation, constructs an argument, describes a model, or analyzes data. Scored with a rubric.

```
+-----------------------------------------------------------------+
|  STIMULUS: [Continued from cluster stimulus — may include         |
|  additional data, diagram, or model for this item]                |
|                                                                   |
|  [Prompt requiring explanation, argument, or analysis]            |
|                                                                   |
|  Use evidence from the [data / investigation / model] to          |
|  support your response.                                           |
|                                                                   |
|  [Open text response field — 3–8 sentences expected]              |
+-----------------------------------------------------------------+
Scoring: 0–3 points
```

**Construction Rules:**
- Prompt must require three-dimensional reasoning (practice + content + crosscutting concept)
- Clearly state what form the response should take (explanation, argument, model description)
- Include the directive "Use evidence from..." to cue evidence-based reasoning
- Rubric must define each score point with specific scientific criteria
- Accept multiple valid scientific explanations or approaches

## 6. DOK / Cognitive Complexity

### DOK Level Descriptions for Science

| DOK | Label | Description | Example Tasks |
|---|---|---|---|
| **1** | Recall & Reproduction | Recall a fact, term, definition, or simple procedure; identify a component from a diagram; recognize a basic scientific relationship | Name the layers of the atmosphere; identify a mineral from a chart; label parts of a cell |
| **2** | Skills & Concepts | Apply a scientific concept to a familiar context; classify or compare observations; interpret a data display; design a simple investigation step | Interpret a data table to identify a trend; compare two organisms' adaptations; predict the outcome of a simple experiment |
| **3** | Strategic Thinking | Develop a model to explain a phenomenon; construct an argument from multiple pieces of evidence; evaluate competing explanations; synthesize data across representations | Explain why a population declined using food web data; construct an argument for one geological model over another; evaluate an experimental design for flaws |

> Nevada Science Assessment does not formally use DOK 4 on the summative assessment. Extended investigation and research occur in classroom-based science tasks.

### DOK Distribution Targets for Item Generation

| Item Type | Target DOK | Rationale |
|---|---|---|
| SR — identify/recall | 1 | Recognize a concept, term, or component |
| SR — apply/interpret | 2 | Apply a concept to a stimulus or interpret data |
| MS — evaluate evidence | 2–3 | Select multiple pieces of evidence supporting a claim |
| CR — explain phenomenon | 2–3 | Construct a multi-sentence explanation using evidence |
| CR — argue/evaluate | 3 | Build or critique a scientific argument using multiple data sources |

## 7. Text Complexity

### Stimulus Design Guidelines

| Grade | Stimulus Length | Data Complexity | Vocabulary Level |
|---|---|---|---|
| 5 | 80–200 words | Simple tables (2–3 variables); labeled diagrams; bar/line graphs | Grade-level science terms with context support |
| 8 | 120–300 words | Moderate tables (3–5 variables); multi-panel diagrams; scatter plots | Domain-specific vocabulary (defined or context-inferable) |
| 11 | 150–350 words | Complex tables; multi-variable graphs; experimental data sets; models with multiple components | Technical vocabulary expected at grade level |

### Stimulus Requirements

| Requirement | Specification |
|---|---|
| **Phenomenon-based** | Every cluster must be anchored to an observable phenomenon or engineering design problem |
| **Authenticity** | Stimuli should reflect real scientific data, scenarios, or investigations; no contrived or impossible situations |
| **Three-dimensional** | Stimulus must create opportunities for assessing SEPs and CCCs, not just factual recall of DCIs |
| **Visual supports** | Include diagrams, data tables, graphs, photographs (described in alt text), or models whenever possible |
| **Cultural representation** | Include phenomena and contexts relevant to Nevada's diverse communities including Native American, Hispanic/Latino, and rural perspectives |
| **Bias and sensitivity** | Avoid content involving animal cruelty, graphic natural disasters, or politically charged environmental debates; present science objectively |
| **Data accuracy** | All data presented in stimuli must be scientifically accurate or clearly labeled as simulated; no invented statistics presented as real |

## 8. Scoring Rubrics

### CR — Constructed Response (0–3 points)

| Score | Descriptor |
|---|---|
| **3** | The response demonstrates thorough three-dimensional understanding. The explanation or argument is scientifically accurate, complete, and well-supported by evidence from the stimulus. The response clearly connects the relevant DCI, SEP, and CCC. Scientific reasoning is precise and logically coherent. |
| **2** | The response demonstrates adequate three-dimensional understanding. The explanation or argument is mostly accurate and supported by evidence, but may contain minor gaps in reasoning, incomplete connections between dimensions, or limited elaboration. |
| **1** | The response demonstrates partial understanding. The explanation or argument addresses some relevant science content but is incomplete, contains significant inaccuracies, or relies on evidence that is weak or tangentially connected. Only one or two dimensions are meaningfully addressed. |
| **0** | The response demonstrates insufficient understanding. The explanation is scientifically inaccurate, does not address the prompt, provides no evidence, is too brief to evaluate, or is blank. |

### Scoring Guidance for Specific SEPs

#### SEP 2 — Developing and Using Models

| Score | What to Look For |
|---|---|
| **3** | Model accurately represents the phenomenon; includes relevant components and interactions; explains how the model accounts for observations |
| **2** | Model is mostly accurate but missing a key component or interaction; explanation is present but incomplete |
| **1** | Model is partially relevant but contains significant inaccuracies or missing critical elements |
| **0** | Model is absent, irrelevant, or scientifically inaccurate |

#### SEP 6 — Constructing Explanations

| Score | What to Look For |
|---|---|
| **3** | Explanation identifies the correct causal mechanism; uses specific evidence from the stimulus; connects cause to effect clearly; applies relevant scientific principles |
| **2** | Explanation identifies a relevant mechanism and uses some evidence, but the causal chain is incomplete or partially inaccurate |
| **1** | Explanation is vague or general; references a relevant concept but does not build a coherent causal chain |
| **0** | No valid explanation or mechanism is provided |

#### SEP 7 — Engaging in Argument from Evidence

| Score | What to Look For |
|---|---|
| **3** | Argument states a clear claim; provides multiple pieces of relevant evidence; reasoning connects evidence to claim; may address counterarguments |
| **2** | Argument states a claim with some supporting evidence, but reasoning is incomplete or evidence is limited |
| **1** | Argument states a claim but provides minimal or weakly connected evidence |
| **0** | No clear claim, or claim is unsupported by evidence |

## 10. Contextualization

### Nevada-Specific Topic Bank

Item writers should anchor phenomena and scenarios in authentic Nevada contexts when possible. This increases ecological validity and engagement for Nevada students.

#### Earth & Space Science Contexts

| Topic | Details for Item Use |
|---|---|
| **Nevada Geology & Minerals** | Comstock Lode silver/gold deposits; turquoise mining; mineral formation in volcanic and hydrothermal settings; Nevada is the most mountainous state in the lower 48; over 300 named mountain ranges. Use for mineral identification, rock cycle, geological processes, and resource extraction phenomena |
| **Basin and Range Tectonics** | Nevada's characteristic landscape formed by extensional tectonics; normal faulting creates parallel mountain ranges and valleys; Great Basin is an endorheic watershed (no outlet to the ocean); active seismic zone. Use for plate tectonics, earthquake phenomena, landform development, and geological time scale |
| **Lake Tahoe Water Clarity** | Secchi disk readings historically ~100 ft, declining due to fine sediment and algal growth; ongoing conservation efforts; oligotrophic lake in a granite basin; watershed science. Use for water quality, ecosystems, human impact, light transmission, and data analysis |
| **Hoover Dam Engineering** | Arch-gravity dam design; 726 ft height; hydroelectric power generation (2,080 MW capacity); Colorado River flow management; Lake Mead water levels and climate change impacts. Use for energy transformation, engineering design, water systems, and human impact on Earth systems |

#### Life Science Contexts

| Topic | Details for Item Use |
|---|---|
| **Great Basin Desert Ecology** | Sagebrush steppe ecosystem; dominant plant: big sagebrush (Artemisia tridentata); keystone species: greater sage-grouse; food web includes pronghorn, jackrabbits, coyotes, raptors; fire ecology and invasive cheatgrass. Use for ecosystems, food webs, population dynamics, biodiversity, and human impact |
| **Desert Wildlife Adaptations** | Desert tortoise: behavioral and physiological adaptations (burrowing, water storage in bladder, dormancy); desert bighorn sheep: adapted to arid mountains; kit fox: large ears for thermoregulation; kangaroo rat: metabolic water production. |---|---|

### English Learner (EL) Considerations

Nevada has a significant English Learner population. Item writers should:

| Consideration | Guidance |
|---|---|
| **Vocabulary** | Use standard scientific terminology; define domain-specific terms in the stimulus or provide context clues |
| **Sentence structure** | Keep stimulus and stem language clear; avoid complex syntactic structures that increase linguistic demand without scientific purpose |
| **Bilingual glossaries** | Designated support providing science term translations; items should not rely on nuanced English phrasing for scientific reasoning |
| **Visual supports** | Provide diagrams, data tables, and labeled models to reduce reliance on text comprehension |
| **Cultural familiarity** | Nevada-specific contexts should include brief clarifying details so all students can access the scenario |

## 11. Quality Checklist

Use this checklist before finalizing any generated item or item set.

### Three-Dimensional Alignment

- [ ] Item is tagged to a specific NGSS Performance Expectation (PE)
- [ ] Item assesses a clearly identified SEP (Science and Engineering Practice)
- [ ] Item incorporates a specific CCC (Crosscutting Concept)
- [ ] Item addresses the relevant DCI (Disciplinary Core Idea) at the appropriate grade level
- [ ] All three dimensions are integrated, not assessed in isolation

### Stimulus Quality

- [ ] Stimulus is anchored to an observable phenomenon or engineering problem
- [ ] Stimulus is scientifically accurate; data is real or clearly labeled as simulated
- [ ] Stimulus length is appropriate for the grade (see Section 7)
- [ ] Visuals (diagrams, graphs, tables) are clearly labeled with appropriate scale and units
- [ ] Alt text is provided for all images and diagrams
- [ ] Stimulus supports multiple items within the cluster

### Item Quality (All Types)

- [ ] Stem is a clear, complete question or directive
- [ ] All options are plausible; distractors reflect common student misconceptions
- [ ] Correct answer is scientifically accurate and unambiguous
- [ ] No grammatical clues in options (all options parallel in form and length)
- [ ] No "All of the above" or "None of the above" options
- [ ] Correct answer position rotated across items in a cluster
- [ ] Item requires reasoning beyond simple recall (unless DOK 1 is intended)

### CR-Specific Checks

- [ ] Prompt clearly states what form the response should take (explanation, argument, model description)
- [ ] "Use evidence" directive is included
- [ ] Rubric defines each score point (0–3) with specific scientific criteria
- [ ] Multiple valid scientific explanations or approaches are anticipated
- [ ] Rubric explicitly addresses the three dimensions (DCI, SEP, CCC)

### Cluster Coherence

- [ ] All items in a cluster connect meaningfully to the shared stimulus
- [ ] Items within a cluster progress in cognitive demand (DOK 1/2 before DOK 3)
- [ ] No item reveals the answer to another item in the same cluster
- [ ] Cluster covers at least one SEP and one CCC in addition to the DCI

### EL and Accessibility

- [ ] No idioms or culturally exclusive references in item stems
- [ ] Text-to-speech compatible
- [ ] Scientific vocabulary is grade-appropriate or defined in context
- [ ] Diagrams and visuals support comprehension for all students
- [ ] Item is appropriate for Nevada's diverse student population

## 12. Prompt Patterns

The following patterns map common user requests to generation strategies for the AI.

---

### Pattern 1: "Generate a science item for Grade [X]"

**Interpretation:** Default to an SR (1-point) item within a phenomenon-based cluster. Select a PE appropriate for the grade. Target DOK 2.

**Generation Recipe:**
1. Select a grade-appropriate PE and identify the DCI, SEP, and CCC
2. Design a phenomenon-based stimulus (Section 7 guidelines)
3. Generate SR item using Template 1 — ensure three-dimensional integration
4. Construct four options with identifiable misconceptions as distractors
5. Tag item: state=NV, subject=SCI, grade=[X], pe=[PE], sep=[SEP], ccc=[CCC], dok=2

---

### Pattern 2: "Generate a constructed response item for Grade [X]"

**Interpretation:** Generate a CR (0–3 point) item for the specified grade using Template 3 (explanation) or Template 4 (model-based reasoning).

**Generation Recipe:**
1. Select a PE and identify all three dimensions
2. Design or extend a phenomenon-based stimulus
3. Write a prompt requiring explanation or model-based reasoning
4. Include "Use evidence from..." directive
5. Write a 0–3 rubric with specific scientific criteria at each score point
6. Tag: state=NV, subject=SCI, grade=[X], pe=[PE], sep=[SEP], ccc=[CCC], dok=3

---

### Pattern 3: "Generate items about [Nevada topic]"

**Interpretation:** Use Section 10 Nevada contexts to design a phenomenon-based cluster. Generate 3–5 items of mixed types anchored to the Nevada phenomenon.

**Generation Recipe:**
1. Select the Nevada context from Section 10; identify relevant PEs
2. Write a stimulus describing the Nevada phenomenon (80–300 words depending on grade)
3. Generate a cluster of 3–5 items:
   - 1–2 SR items (DOK 1–2)
   - 1 MS item (DOK 2)
   - 1 CR item (DOK 3)
4. Ensure items progress in cognitive demand within the cluster
5. Verify no item reveals the answer to another
6. Tag each item: state=NV, subject=SCI, grade=[X], pe=[PE], sep=[SEP], ccc=[CCC]

---

### Pattern 4: "Generate a full stimulus cluster for Grade [X]"

**Interpretation:** Generate a complete phenomenon-based cluster with stimulus and 4–7 items of mixed types.

**Generation Recipe:**
1. Select a phenomenon appropriate for the grade (Nevada contexts preferred)
2. Identify the primary PE, DCI, SEP, and CCC
3. Write a rich stimulus (Section 7 length guidelines) including data, diagrams, or scenario descriptions
4. Generate 4–7 items:
   - 2–3 SR items (DOK 1–2)
   - 1–2 MS items (DOK 2)
   - 1–2 CR items (DOK 2–3)
5. Ensure three-dimensional integration across the cluster
6. Verify cluster coherence (see Quality Checklist, Section 11)
7. Include scoring rubrics for all CR items
8. Tag each item with PE, DCI, SEP, CCC, DOK

---

### Pattern 5: "Generate a complete practice test for Grade [X]"

**Interpretation:** Generate a mini-assessment with 3–4 stimulus clusters covering different domains.

**Generation Recipe:**
1. Select 3–4 phenomena spanning Physical Science, Life Science, and Earth & Space Science
2. At least one cluster should use a Nevada context (Section 10)
3. For each cluster, follow Pattern 4 recipe
4. Ensure domain distribution roughly matches: PS ~30%, LS ~30%, ESS ~30%, Engineering ~10%
5. Verify SEP and CCC coverage across the full set
6. Total item count target: 15–25 items across all clusters
7. Include scoring rubrics for all CR items
8. Tag all items appropriately
