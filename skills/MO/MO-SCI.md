## AssessmentForge Skill Guide | Grades 5, 8, and 11

## 1. Overview

| Field | Detail |
|---|---|
| **Assessment Name** | Missouri Assessment Program (MAP) — Science |
| **Administering Agency** | Missouri Department of Elementary and Secondary Education (DESE) |
| **Vendor** | MO State DOE |
| **Grades Tested** | **Grade 5**, **Grade 8**, and **Grade 11** |
| **Testing Window** | April – May |
| **Delivery** | Computer-based; single session |
| **Standards** | Missouri Learning Standards for Science |
| **Score Scale** | 4 performance levels; scaled score varies by grade |
| **Reporting** | Individual Student Report; School, District, State aggregates |

> **CRITICAL NOTE:** MAP Science is administered **only at Grades 5, 8, and 11**. Do not generate science items for Grades 3, 4, 6, or 7.

> **MAP Science Standards:** Missouri Learning Standards for Science integrate disciplinary core ideas with scientific and engineering practices and crosscutting concepts. Items should assess content knowledge alongside inquiry skills.

### Performance Levels

| Level | Label | Description |
|---|---|---|
| 4 | **Advanced** | Demonstrates thorough science understanding; expertly integrates scientific knowledge with practices; constructs sophisticated evidence-based explanations |
| 3 | **Proficient** | Demonstrates adequate science understanding; appropriately applies scientific practices and concepts |
| 2 | **Basic** | Demonstrates partial understanding; applies content knowledge but struggles to integrate practices meaningfully |
| 1 | **Below Basic** | Demonstrates minimal science understanding; limited to recall of isolated facts |

## 5. Item Types & Formats

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Scenario, diagram, data table, or model stimulus        |
|  Machine scored                                          |
+----------------------------------------------------------+
```

**MC Example (Grade 5, DOK 2 — Earth Systems):**

A diagram shows the water cycle in the Missouri River watershed, including precipitation, runoff, groundwater, and evaporation.

Which statement BEST explains how the Missouri River watershed demonstrates the interaction between the hydrosphere and geosphere?

A. The river only flows underground through rock layers
B. Precipitation falls on the land surface, flows across rock and soil as runoff, and shapes the river channel through erosion
C. The Missouri River evaporates completely during summer months
D. Groundwater in the watershed never interacts with surface water

*Correct Answer: B*
*Alignment: Earth Science — Earth Systems | Practice: Developing and Using Models | CCC: Systems and System Models | DOK 2*

---

**MC Example (Grade 8, DOK 2 — Seismology / New Madrid):**

The New Madrid Seismic Zone in southeastern Missouri produced some of the strongest earthquakes in U.S. history during 1811–1812. Scientists today use seismographs to monitor this region. Which statement BEST explains why the New Madrid Seismic Zone is still considered a hazard?

A. The zone is located on the boundary between two tectonic plates that are actively colliding
B. The zone contains ancient faults that remain under stress from deep tectonic forces, making future earthquakes possible
C. The earthquakes in 1811–1812 weakened the Earth's crust so much that it will eventually collapse
D. The Mississippi River erodes the rock beneath the zone, creating instability

*Correct Answer: B*
*Alignment: Earth Science — Seismology | Practice: Constructing Explanations | CCC: Stability and Change | DOK 2*

### Multi-Select (MS)

```
+----------------------------------------------------------+
|  MULTI-SELECT RESPONSE — 1 point                         |
|                                                          |
|  5–6 options; select exactly 2 or 3 correct answers      |
|  All must be selected for credit                         |
|  Machine scored                                          |
+----------------------------------------------------------+
```

**MS Example (Grade 8, DOK 2 — Ozark Ecology):**

Ecologists studying the Ozark Mountains of Missouri have observed declining populations of several native fish species in spring-fed streams. Select the TWO factors that would MOST LIKELY contribute to this decline.

A. Increased development near springs reducing groundwater recharge
B. Higher fish populations migrating from the Mississippi River
C. Agricultural runoff introducing excess nutrients and reducing dissolved oxygen in streams
D. Increased elevation of the Ozark Mountains blocking stream flow
E. Colder winter temperatures causing more snowfall in the region

*Correct Answers: A, C*
*Alignment: Life Science — Ecosystems | Practice: Analyzing Data | CCC: Cause and Effect | DOK 2*

### Constructed Response (CR)

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE — 0–2 points                       |
|                                                          |
|  Written explanation using evidence from the stimulus    |
|  Stimulus always provided (data, diagram, scenario)      |
|  Human scored                                            |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**CR Example (Grade 11, DOK 3 — Earth Systems / Missouri River Watershed):**

*Stimulus: A map showing the Missouri River watershed and a data table displaying annual sediment load, precipitation, and land use changes over 50 years. The data shows increasing sediment loads correlated with conversion of prairie to cropland.*

Using evidence from the data, explain how changes in land use within the Missouri River watershed have affected sediment transport. Describe TWO cause-and-effect relationships supported by the data.

*Scoring:*
- *2 pts: Accurately explains how land use change (prairie to cropland) increases erosion and sediment; identifies two specific cause-and-effect relationships from data; references specific data values*
- *1 pt: Partially correct explanation with one cause-and-effect relationship, OR two relationships without data references*
- *0 pts: Off-topic, blank, or major scientific misconception*

## 7. Three-Dimensional Design

Every MAP Science item should integrate scientific practices, content knowledge, and crosscutting concepts.

### Three-Dimensions Alignment Guide

| Dimension | What It Is | Example in MAP Items |
|---|---|---|
| **Content Knowledge** (What students know) | Disciplinary science content | Missouri cave systems; Ozark ecology; Missouri River watershed; New Madrid seismology |
| **Scientific Practices** (What students do) | How scientists work | Analyze seismic data; construct explanations from evidence; use watershed models |
| **Crosscutting Concepts** (Lens of thinking) | Cross-domain thinking tools | Cause and effect; patterns; energy and matter; stability and change; systems |

### Sample Three-Dimensional Item Design (Grade 8)

```
+------------------------------------------------------------------+
|  3D ITEM STRUCTURE                                               |
|                                                                  |
|  PHENOMENON: The New Madrid Seismic Zone in southeastern         |
|  Missouri still produces small earthquakes, even though it is    |
|  far from a plate boundary                                       |
|  (Authentic Missouri phenomenon)                                 |
|                                                                  |
|  CONTENT: Earth Science — Seismology; Geologic processes         |
|  PRACTICE: Analyzing and Interpreting Data                       |
|  CROSSCUTTING: Stability and Change                              |
|                                                                  |
|  STIMULUS: Map of the New Madrid Seismic Zone with earthquake    |
|  epicenter data over 30 years; magnitude and frequency table     |
|                                                                  |
|  PROMPT: "Using the data provided, describe the pattern of       |
|  earthquake activity in the New Madrid Seismic Zone. Explain     |
|  what geologic conditions make this area prone to earthquakes    |
|  despite being located far from a plate boundary."               |
+------------------------------------------------------------------+
```

## 8. Scoring Rubrics

### Constructed Response (CR) Rubric — 0–2 Points

| Score | Criteria |
|---|---|
| 2 | Response accurately addresses the science concept; demonstrates understanding of practices and crosscutting concepts; includes specific, relevant evidence from the stimulus; explanation is complete, accurate, and logically connected |
| 1 | Response addresses the science concept with partial accuracy; evidence present but may be incomplete; reasoning partially developed |
| 0 | Response does not address the science concept; blank; off-topic; restates stimulus without explanation; no science understanding demonstrated |

### CR Scoring Notes

- **Evidence from the stimulus is required.** Responses relying solely on prior knowledge earn a maximum of 1 point.
- **Scientific reasoning** integrating content with practices or crosscutting concepts is needed for full credit.
- **Scientific misconceptions** reduce the score by at least one point.

## 10. Contextualization — Missouri Science

When generating MAP Science items, prioritize authentic Missouri natural settings:

### Missouri Science Context Guide

| Setting / Phenomenon | Grade | Science Domain | Standard Focus |
|---|---|---|---|
| Missouri cave systems (karst geology, speleothem formation) | 5, 8 | Earth Science | Rock formation; water cycle; erosion |
| Ozark Mountain ecology (spring-fed streams, forest habitats) | 5, 8, 11 | Life Science | Ecosystems; biodiversity; water quality |
| Missouri River watershed and sediment transport | 5, 8, 11 | Earth Science | Erosion; water cycle; human impact |
| New Madrid Seismic Zone (intraplate earthquakes) | 8, 11 | Earth Science | Seismology; geologic hazards |
| Missouri Ozark Riverways (water chemistry) | 8, 11 | Physical/Earth Science | Chemical properties; water quality |
| Mark Twain National Forest ecology | 5, 8 | Life Science | Ecosystems; biodiversity |
| Missouri lead mining districts (geology and environmental impact) | 8, 11 | Earth/Physical Science | Mineral resources; human impact |
| Missouri tornado and severe storm patterns | 5, 8 | Earth Science | Weather systems; atmospheric dynamics |
| Missouri prairie and savanna restoration | 5, 8 | Life Science | Ecosystems; biodiversity |
| Missouri River flooding and levee systems | 8, 11 | Earth Science | Hydrology; engineering; human impact |
| Missouri bat populations in cave systems | 5, 8 | Life Science | Ecosystems; disease ecology |

### Suggested Anchoring Phenomena by Grade

**Grade 5 Phenomena:**
- "Missouri has over 6,000 known caves, more than almost any other state. Scientists found that many caves have formations called stalactites and stalagmites made of minerals deposited by dripping water. How do these formations grow?"
- "After heavy rain in the Ozarks, a stream turned muddy brown while a nearby spring-fed stream stayed clear. What explains the difference?"

**Grade 8 Phenomena:**
- "The New Madrid Seismic Zone in southeastern Missouri is far from any tectonic plate boundary, yet it produced magnitude 7+ earthquakes in 1811–1812 and still has small tremors today. What geologic conditions cause earthquakes in this location?"
- "Missouri cave biologists discovered that white-nose syndrome has killed millions of bats in Missouri caves since 2010. What effect might this have on the cave and forest ecosystems?"

**Grade 11 Phenomena:**
- "Scientists studying the Missouri River watershed found that sediment loads increased dramatically after large areas of native prairie were converted to row-crop agriculture. What explains this pattern, and what engineering solutions could reduce the impact?"
- "Ozark spring-fed streams maintain a nearly constant water temperature year-round, while surface streams vary widely with the seasons. What explains this difference, and how does it affect the organisms living in each type of stream?"

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] Grade verified as 5, 8, or 11 ONLY
- [ ] Missouri Learning Standard is accurate for grade level
- [ ] Item integrates content knowledge with a scientific practice
- [ ] Anchoring phenomenon is authentic and Missouri-relevant where possible
- [ ] Stimulus has clear labels, units, and realistic data
- [ ] CR prompt directs students to use evidence from the stimulus
- [ ] All distractors represent real misconceptions
- [ ] MS items specify how many answers to select (TWO/THREE)
- [ ] Science content is accurate and reflects current scientific understanding
- [ ] Vocabulary is grade-appropriate

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Writing science items for Grades 3, 4, 6, or 7 | MAP Science is only at Grades 5, 8, 11 | Restrict to tested grades |
| Content-only items with no scientific practice | MAP values practice integration | Embed a scientific practice into item design |
| CR prompts without evidence directive | Students may respond without citing data | Include "Use evidence from the [data/graph/diagram]" |
| Generic Midwest phenomena | MAP favors Missouri-specific contexts | Use caves, Ozarks, Missouri River, New Madrid contexts |
| MS items with only 2 options in 4 total | Too easy to guess | Use 5–6 options with exactly 2–3 correct |

## 12. Prompt Patterns

### Pattern 1: Data-to-Conclusion (MC, DOK 2)
> "The [graph / table / diagram] below shows [Missouri science scenario]. Based on the data, which [conclusion / explanation / pattern] is BEST supported?"

### Pattern 2: Phenomenon Explanation (CR, DOK 3)
> "Scientists observed [Missouri-anchored phenomenon]. Using evidence from the [data / model / diagram], construct an explanation for [specific science focus]. Explain the [cause-and-effect / energy flow / pattern] relationship."

### Pattern 3: Model Evaluation (MC or MS, DOK 2–3)
> "A student made a model showing [Missouri science concept]. Which statement BEST describes what the model shows about [content focus]?"

### Pattern 4: Investigation Design (CR, DOK 3)
> "A scientist in Missouri wants to investigate whether [variable] affects [outcome] in [Missouri ecosystem/setting]. Describe a procedure including what would be measured and how results would be interpreted."

### Pattern 5: Evidence-Based Argument (CR, DOK 3)
> "Two students disagree about [Missouri science claim]. Student A says [misconception]. Student B says [correct claim]. Using evidence from the [data / diagram], explain which student is correct and why."

### Pattern 6: Human Impact and Solutions (MS or CR, DOK 2–3)
> "Human activities have [impacted Missouri environment]. Select the TWO strategies that BEST [monitor / reduce / address] this impact."
