| Field | Detail |
|---|---|
| **Assessment Name** | Missouri Assessment Program (MAP) — Mathematics |
| **Administering Agency** | Missouri Department of Elementary and Secondary Education (DESE) |
| **Vendor** | MO State DOE |

| **Testing Window** | April – May |

| **Standards** | Missouri Learning Standards for Mathematics |
| **Score Scale** | 4 performance levels; scaled score varies by grade |
| **Reporting** | Individual Student Report; School, District, State aggregates |

> **MAP Mathematics:** The Missouri Assessment Program measures student mastery of the Missouri Learning Standards for Mathematics. Items assess conceptual understanding, procedural fluency, and application using real-world and mathematical contexts. MAP Math includes Technology-Enhanced Items (TEI).

### Performance Levels

| Level | Label | Description |
|---|---|---|
| 4 | **Advanced** | Thorough understanding; applies mathematics in novel and complex situations; constructs valid mathematical arguments |
| 3 | **Proficient** | Adequate understanding; solves grade-level problems accurately; applies mathematics to real-world contexts |
| 2 | **Basic** | Partial understanding; applies procedures in familiar contexts but struggles with novel problems |
| 1 | **Below Basic** | Minimal understanding; significant conceptual and procedural gaps |

## 5. Item Types & Formats

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Real-world or mathematical context                      |
|  Machine scored                                          |
|  DOK 1–3                                                 |
+----------------------------------------------------------+
```

**MC Example (Grade 6, DOK 2, 6.RP.A.3):**

The Missouri River flows approximately 2,341 miles from its source in Montana to its confluence with the Mississippi River near St. Louis. A boat travels 390 miles in 3 days. At this rate, how many miles would the boat travel in 7 days?

A. 780 miles
B. 910 miles
C. 1,170 miles
D. 2,730 miles

*Correct Answer: B (390/3 = 130 miles per day; 130 x 7 = 910)*
*Alignment: 6.RP.A.3 | Ratios & Proportional Relationships | DOK 2*

---

**MC Example (Grade 5, DOK 2, 4.GM.C.9):**

The Gateway Arch in St. Louis is approximately 630 feet tall and 630 feet wide at its base. A model of the Arch uses a scale where 1 inch represents 30 feet. How tall would the model be?

A. 18 inches
B. 21 inches
C. 31.5 inches
D. 210 inches

*Correct Answer: B (630 / 30 = 21)*
*Alignment: 5.NBT / Measurement & Data | DOK 2*

### Technology-Enhanced Item (TEI)

```
+----------------------------------------------------------+
|  TECHNOLOGY-ENHANCED ITEM — 1–2 points                   |
|                                                          |
|  Formats: multi-select, drag-and-drop, equation entry    |
|  Machine scored                                          |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**TEI Example — Multi-Select (Grade 7, DOK 2, 7.RP.A.2):**

A Kansas City BBQ restaurant sells brisket for $18.50 per pound. Select ALL equations that correctly represent the relationship between pounds of brisket (p) and total cost (c).

A. c = 18.50p
B. p = 18.50c
C. c/p = 18.50
D. p/c = 18.50
E. c = p + 18.50

*Correct Answers: A, C*
*Alignment: 7.RP.A.2 | Ratios & Proportional Relationships | DOK 2*

### Constructed Response (CR)

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE — 0–2 points                       |
|                                                          |
|  Show work and explain reasoning                         |
|  Real-world or mathematical context                      |
|  Human scored                                            |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**CR Example (Grade 8, DOK 3, 8.F.B.4):**

The St. Louis metropolitan area had a population of approximately 2,800,000 in 2010. The population has been decreasing by approximately 5,000 people per year since then.

Write a linear function that models this population change over time. Then determine the estimated population in 2025. Show your work and explain what the slope of your function represents in this context.

*Scoring:*
- *2 pts: Correct function (P = 2,800,000 - 5,000t or equivalent); correct population for 2025 (2,725,000); clear explanation that slope represents annual population decrease of 5,000*
- *1 pt: Correct function or answer with incomplete explanation, OR correct approach with computational error*
- *0 pts: Incorrect approach or blank*

## 8. Scoring Rubrics

### Constructed Response (CR) Rubric — 0–2 Points

| Score | Criteria |
|---|---|
| 2 | Correct solution with clear mathematical reasoning. Work shown systematically. Explanation demonstrates conceptual understanding. Appropriate mathematical vocabulary used. |
| 1 | Partial understanding with minor errors. Correct approach demonstrated but final answer contains an error. OR Correct answer given without sufficient work or explanation. |
| 0 | Incorrect approach, no understanding shown, or blank. |

### CR Scoring Notes

- **Work must be shown** for full credit on all CR items.
- **Explanations** should reference mathematical concepts, not just describe steps.
- **Computational errors** with correct reasoning earn partial credit (1 point).

## 10. Contextualization — Missouri Mathematics

When generating problem contexts, use authentic Missouri settings:

### Missouri Math Context Guide

| Context | Domain | Grade Band |
|---|---|---|
| Gateway Arch dimensions (630 ft tall/wide, catenary curve) | Measurement, Geometry, Functions | 4–11 |
| Missouri River data (length, flow rates, flooding) | Ratios, Measurement, Data | 4–11 |
| St. Louis population and demographic data | Statistics, Functions, Proportionality | 5–11 |
| Kansas City BBQ economics (pricing, portions, revenue) | Operations, Ratios, Proportionality | 3–8 |
| Ozark Mountain elevation and trail distances | Geometry, Measurement, Operations | 3–8 |
| Missouri agriculture (soybeans, corn, cattle) | Ratios, Fractions, Data | 3–8 |
| Missouri cave system measurements | Measurement, Geometry, Statistics | 4–8 |
| Kansas City and St. Louis highway distances (I-70) | Ratios, Proportionality | 4–8 |
| Mark Twain Lake / reservoir volume data | Geometry, Measurement | 5–11 |
| Missouri wind and solar energy production | Functions, Data Analysis | 6–11 |

### Suggested Problem Contexts by Grade

**Grades 3–5:**
- Measuring the dimensions of a model Gateway Arch using scale factors
- Calculating distances along I-70 between Missouri cities
- Comparing prices of BBQ items at a Kansas City restaurant

**Grades 6–8:**
- Analyzing Missouri River flow rate data to calculate unit rates
- Using proportional reasoning with St. Louis population data
- Calculating the area and dimensions of Ozark Mountain trail segments

**Grade 11:**
- Modeling the catenary curve of the Gateway Arch using quadratic or exponential functions
- Analyzing scatter plots of Missouri agricultural yield vs. rainfall
- Statistical analysis of Kansas City and St. Louis metropolitan growth trends

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] Missouri Learning Standards code is accurate and grade-appropriate
- [ ] MC items have exactly 4 options with one correct answer
- [ ] TEI items use appropriate technology-enhanced format
- [ ] CR items require work to be shown and reasoning explained
- [ ] CR scored on 0–2 point scale
- [ ] Calculator policy appropriate for grade level
- [ ] Missouri real-world context used where appropriate
- [ ] Distractors represent actual student computational or conceptual errors
- [ ] All computations verified before item is finalized
- [ ] DOK level matches actual cognitive demand

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| CR asking only for a final answer | CR must require explanation | Add "Show your work and explain" |
| Using non-Missouri contexts | Misses state contextualization | Use Gateway Arch, Missouri River, Kansas City, Ozarks contexts |
| Ignoring TEI format | MAP includes technology-enhanced items | Include multi-select, matching, and equation-entry items |
| Grade 11 items at middle school level | Underestimates high school expectations | Use algebra, functions, and statistics at HS level |
| Distractors that are obviously wrong | Does not assess real misconceptions | Base distractors on common student errors |

## 12. Prompt Patterns

### Pattern 1: Real-World Application (MC, DOK 2)
> "[Missouri context]. [Multi-step problem]. What is [answer]?"

### Pattern 2: Justify and Explain (CR, DOK 3)
> "[Missouri scenario]. [Problem]. Show your work and explain how you found your answer."

### Pattern 3: Proportional Reasoning (MC or TEI, DOK 2)
> "A [Missouri entity] produces/uses [quantity] in [time/unit]. At this rate, how much [quantity] in [different time/unit]?"

### Pattern 4: Data Interpretation (MC or TEI, DOK 2)
> "The [table / graph] shows [Missouri data context]. Based on the data, which statement is correct?"

### Pattern 5: Multi-Step Problem Solving (CR, DOK 3)
> "[Missouri scenario with multiple constraints]. Determine [answer]. Show your work and explain whether your answer is reasonable."

### Pattern 6: Comparison and Reasoning (CR, DOK 3)
> "Two students solved this problem differently. [Method A] and [Method B]. Who is correct? Use mathematics to justify your answer."
