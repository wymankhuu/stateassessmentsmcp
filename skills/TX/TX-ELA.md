## 1. Overview

| Field | Detail |
|---|---|
| **Assessment Name** | STAAR — English Language Arts and Reading (ELAR) |
| **Administering Agency** | Texas Education Agency (TEA) |
| **Vendor** | Cambium Assessment |
| **Grades Tested** | 3, 4, 5, 6, 7, 8 (Reading + Writing integrated); English I EOC; English II EOC |
| **Testing Window** | April (primary); additional windows available |
| **Delivery** | Computer-based (online); paper accommodations available |
| **Standards** | Texas Essential Knowledge and Skills (TEKS) — ELA, 2019 revised |
| **Score Scale** | Raw score converted to scaled performance score; 4 performance levels |
| **Reporting** | Individual Student Report; Campus, District, State aggregates |

> **STAAR 2023 Redesign:** Beginning in 2023, STAAR ELA underwent a major redesign. Reading and writing are now **fully integrated** into a single test. Items use a **stacked passages model** — students read a passage once, then answer all items associated with that passage (MCQ and Short Answer interleaved). The Extended Response (composition) prompt appears at the end of the test.

### Performance Levels

| Level | Label | Score Range | Description |
|---|---|---|---|
| Masters Grade Level | **Masters** | Highest range | Student demonstrates thorough understanding and strong command of grade-level TEKS |
| Meets Grade Level | **Meets** | Proficient | Student demonstrates sufficient understanding of grade-level TEKS |
| Approaches Grade Level | **Approaches** | Near-proficient | Student demonstrates some understanding but needs continued support |
| Did Not Meet Grade Level | **Did Not Meet** | Lowest range | Student demonstrates minimal understanding; significant gaps in TEKS mastery |

> **Item-writing target:** "Meets Grade Level" performance. Items should require genuine application of TEKS at the expected DOK level — not mere recall.

## 2. Standards Framework

> STAAR ELA is aligned to the **Texas Essential Knowledge and Skills (TEKS) for English Language Arts and Reading**, revised 2019 and fully implemented 2022–2023. TEKS are organized by four strands.

### TEKS ELA Strands

| Strand | Focus | Grade Emphasis |
|---|---|---|
| **Reading** | Literary and informational text comprehension; author's craft; genre study | Primary focus throughout Grades 3–8 |
| **Writing** | Composition; genre; writing process; voice | Integrated throughout; explicit in composition prompts |
| **Research** | Inquiry; source evaluation; synthesis | Grades 6–8 especially |
| **Oral & Written Conventions** | Grammar; punctuation; usage; sentence construction | Assessed in Revising & Editing section |

### Key Reading TEKS by Grade Band

| TEKS Code | Description | Grade Band | DOK |
|---|---|---|---|

| TEKS.ELA6.6A | Analyze how the use of language creates imagery, mood, or theme in literary text | 6 | 3 |
| TEKS.ELA6.8A | Explain the author's purpose (including implicit and explicit) and determine whether the author achieved it | 6 | 2–3 |
| TEKS.ELA7.6A | Analyze how the author's use of language creates imagery, mood, theme, and tone; include figurative language | 7 | 3 |
| TEKS.ELA8.6A | Analyze the effect of literary devices (including irony, paradox, and extended metaphor) | 8 | 3 |
| TEKS.ELA8.8A | Analyze how rhetorical and argumentative techniques are used in informational text | 8 | 3 |

## 3. Test Structure

STAAR ELA is a single-session test administered in one day. The **stacked passages model** means all comprehension items for a passage are presented together, immediately after reading.

```
+------------------------------------------------------------------+
|            STAAR ELA STRUCTURE (Grades 3–8)                      |
+------------------------------------------------------------------+
|  SINGLE SESSION — Approximately 4–5 hours (untimed)             |
|  Computer-Based                                                  |
|                                                                  |
|  SECTION 1: READING (Stacked Passages)                          |
|  ┌────────────────────────────────────────┐                     |
|  │ Passage 1 (Literary) → 4–8 MCQ + 1 SA │                     |
|  │ Passage 2 (Literary) → 4–8 MCQ + 1 SA │                     |
|  │ Passage 3 (Informational) → 4–8 MCQ + 1 SA │                |
|  │ Passage 4 (Informational) → 4–8 MCQ + 1 SA │                |
|  └────────────────────────────────────────┘                     |
|                                                                  |
|  SECTION 2: REVISING & EDITING                                  |
|  ┌────────────────────────────────────────┐                     |
|  │ Student-written draft → 4–8 RE items  │                     |
|  └────────────────────────────────────────┘                     |
|                                                                  |
|  SECTION 3: COMPOSITION (Extended Response)                     |
|  ┌────────────────────────────────────────┐                     |
|  │ ONE composition prompt                 │                     |
|  │ (Personal Narrative OR Expository)     │                     |
|  │ 4 traits × 4 points = 16 points        │                     |
|  └────────────────────────────────────────┘                     |
+------------------------------------------------------------------+
```

### Test Component Summary

| Section | Item Types | Points | Scoring |
|---|---|---|---|
| Reading — Stacked Passages | MCQ (1 pt each), SA (0–2 pts each) | ~30–36 pts | Machine + Human |
| Revising & Editing | RE (1 pt each) | ~4–8 pts | Machine |
| Composition | ER-PN or ER-EX (4 traits × 4 pts) | 16 pts | Human |
| **Total** | | **~50–60 pts** | |

## 5. Item Types & Formats

### Multiple Choice (MCQ) — Stacked

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE (STACKED) — 1 point                     |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Always tied to a passage/stimulus presented above       |
|  May include line-number references                      |
|  Machine scored                                          |
|  DOK 2–3 for most reading items                          |
+----------------------------------------------------------+
```

**MCQ Example (Grade 7 Literary, DOK 3, TEKS.ELA7.6A):**

*[After reading a short story about a Texas ranch during drought]*

Read this sentence from paragraph 4: *"The creek had become a rumor, a ghost of water etched only in the cracked mud."*

What effect does the author's use of figurative language in this sentence create?

A. It suggests that the creek was once a popular location
B. It shows that the narrator is confused about the creek's location
C. It emphasizes the extreme dryness of the land by comparing the creek to something that no longer exists
D. It implies that the story takes place long ago when creeks were common

*Correct Answer: C*
*Alignment: TEKS.ELA7.6A | DOK 3*

---

**MCQ Example (Grade 6 Informational, DOK 2, TEKS.ELA6.8A):**

*[After reading an article about wind energy in Texas]*

What is the author's MAIN purpose in writing this article?

A. To persuade readers to install wind turbines on their property
B. To entertain readers with stories about wind energy workers
C. To inform readers about how Texas became a national leader in wind energy production
D. To compare wind energy costs in Texas with other states

*Correct Answer: C*
*Alignment: TEKS.ELA6.8A | DOK 2*

### Short Answer (SA)

```
+----------------------------------------------------------+
|  SHORT ANSWER — 0–2 points                               |
|                                                          |
|  2–4 sentence written response                           |
|  Must include textual evidence (quoted or paraphrased)   |
|  Human scored using SA rubric                            |
|  One SA item typically follows each passage              |
|  DOK 3                                                   |
+----------------------------------------------------------+
```

**SA Example (Grade 8 Informational, DOK 3, TEKS.ELA8.8A):**

*[After reading an argumentative essay about Texas water conservation]*

Using evidence from the article, explain how the author develops the argument that water conservation is urgent for Texas communities.

```

|                                                          |

|  Editing: correct grammar, punctuation, usage            |

+----------------------------------------------------------+
```

**RE Example (Grade 5 — Revising):**

*[Student draft with underlined sentence in paragraph 2]*

A. [Version that adds a sentence fragment]
B. [Version that is vague and repetitive]
C. [Correct — improves clarity, word choice, or sentence flow]

## 8. Scoring Rubrics

### Short Answer (SA) Rubric — 0–2 Points

| Score | Criteria |
|---|---|
| 2 | Response provides an accurate, specific answer that addresses the question. Includes relevant, correctly-used textual evidence (quoted or paraphrased) that directly supports the answer. |
| 1 | Response provides a partially accurate answer. OR Response provides an accurate answer without sufficient or directly relevant textual evidence. |
| 0 | Response is inaccurate, irrelevant, insufficient in length to evaluate, or blank. |

### Extended Response (ER) Rubric — Per Trait (0–4 Points Each)

**Trait 1 — Organization**

| Score | Criteria |
|---|---|
| 4 | Single controlling idea clearly stated and maintained throughout. Strong, meaningful progression of ideas. Effective opening and closing. Purposeful, varied transitions. |
| 3 | Single controlling idea stated and generally maintained. Adequate progression. Opening and closing present. Transitions used but may be formulaic. |
| 2 | Controlling idea evident but may not be maintained. Some progression of ideas. Opening or closing may be weak. Limited transitions. |
| 1 | Controlling idea unclear or absent. Weak or random progression. No clear opening or closing. Few or no transitions. |
| 0 | Blank, insufficient writing, or no evidence of attempt. |

**Trait 2 — Development**

| Score | Criteria |
|---|---|
| 4 | Thorough, specific development using relevant details, examples, or evidence. Compelling and varied elaboration. Vivid and purposeful word choice. |
| 3 | Adequate development with some specific details. Elaboration present but may not be fully developed. Appropriate word choice. |
| 2 | General or inconsistent development. Limited elaboration. Word choice adequate but generic. |
| 1 | Minimal development. Little or no elaboration. Vague or repetitive word choice. |
| 0 | Blank or insufficient. |

**Trait 3 — Voice**

| Score | Criteria |
|---|---|
| 4 | Authentic, distinctive voice that engages the reader and fits the purpose/audience. Strong sense of the writer's perspective. |
| 3 | Clear voice that is generally appropriate for purpose and audience. Some personality evident. |
| 2 | Voice inconsistent or generic. Some sense of writer present but muted. |
| 1 | Little to no discernible voice or personality. Flat, lifeless writing. |
| 0 | Blank or insufficient. |

**Trait 4 — Conventions**

| Score | Criteria |
|---|---|
| 4 | Consistent control of sentence variety and length. Minimal errors in grammar, usage, punctuation, and spelling. Errors do not interfere with meaning. |
| 3 | Adequate control. Some errors present but do not significantly interfere with meaning. Some sentence variety. |
| 2 | Partial control. Errors noticeable and may occasionally interfere. Limited sentence variety. |
| 1 | Limited control. Frequent errors that interfere with meaning. Little sentence variety. |
| 0 | Blank or insufficient writing to evaluate. |

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] TEKS code verified as correct for the targeted grade
- [ ] MCQ items directly tied to the passage (not general knowledge questions)
- [ ] SA prompt requires textual evidence (not just prior knowledge)
- [ ] Distractors represent authentic misconceptions, not obviously wrong answers
- [ ] Composition prompt is open-ended enough for student voice and elaboration
- [ ] RE items reference a specific sentence or paragraph in a student-written draft
- [ ] Lexile of passage matches the grade-level range
- [ ] Passage length appropriate (400–1,000 words for comprehension passages)
- [ ] Texas context incorporated where appropriate (geography, history, culture)
- [ ] Extended Response scored using all 4 traits (Organization, Development, Voice, Conventions)

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| MCQ items not tied to a passage | STAAR ELA uses stacked passages — all items must be passage-dependent | Always tie MCQ and SA to a specific stimulus |
| SA prompt that only tests recall | SA should require DOK 3 analysis with textual evidence | Include "using evidence from the text" in every SA prompt |
| ER prompt with a single correct answer | Composition needs open-ended space for student voice | Ensure prompt invites personal perspective or multiple valid angles |
| Composition scored on only 2–3 traits | STAAR ER uses 4 traits | Always include all 4: Organization, Development, Voice, Conventions |
| RE items not in a student-draft context | RE items must be embedded in a draft | Provide student-written draft text with errors |
| Using non-TEKS standards (CCSS codes) | STAAR uses TEKS, not CCSS | Reference TEKS codes exclusively |

## 12. Prompt Patterns

### Pattern 1: Craft & Language Analysis (MCQ, DOK 3)
> "Read [line reference / paragraph reference]. What effect does the author's use of [figurative language / imagery / word choice / structure] create in this [sentence / paragraph]?"

### Pattern 2: Inference and Evidence (MCQ, DOK 2)
> "Based on [paragraph # / the passage], what can the reader infer about [character / author's purpose / main idea]?"

### Pattern 3: Author's Purpose / Argument (MCQ or SA, DOK 2–3)
> "What is the author's [main purpose / central argument] in this [article / essay]? How does the author [support / develop] this [purpose / argument]? Use evidence from the text."

### Pattern 4: Theme / Central Idea (MCQ or SA, DOK 2–3)
> "What [theme / central idea] does this [passage / story] develop? How does the author [use specific details / events / language] to develop this [theme / idea]?"

### Pattern 5: Composition — Personal Narrative (ER-PN, DOK 4)
> "Think about a time when [experience related to effort, challenge, relationship, or change]. Write a personal narrative about that experience. Use specific details and vivid language to develop your story."

### Pattern 6: Composition — Expository (ER-EX, DOK 4)
> "Think about [topic or concept]. Write an essay explaining [why / how / what]. Use specific examples and details to support your explanation."

### Pattern 7: Revising & Editing (RE, DOK 1–2)
> "Which revision BEST improves the underlined sentence [in paragraph #]?"
> "What change, if any, should be made to [sentence #]?"
