## 1. Overview

| Field | Detail |
|---|---|
| **Assessment Name** | STAAR — Science |
| **Administering Agency** | Texas Education Agency (TEA) |
| **Vendor** | Cambium Assessment |
| **Grades Tested** | **Grade 5**, **Grade 8**, and **Biology EOC** (End-of-Course) |
| **Testing Window** | April (primary window) |
| **Delivery** | Computer-based; paper accommodations available |
| **Standards** | Texas Essential Knowledge and Skills (TEKS) — Science |
| **Score Scale** | Raw score converted to scaled performance score; 4 performance levels |
| **Reporting** | Individual Student Report; Campus, District, State aggregates |

> **CRITICAL NOTE:** STAAR Science is administered **only at Grades 5, 8, and Biology EOC**. It is **NOT** given at Grades 3, 4, 6, or 7 for state accountability. Do not generate STAAR-aligned science items for non-tested grades.

### Performance Levels

| Level | Label | Description |
|---|---|---|
| Masters Grade Level | **Masters** | Thorough understanding of science TEKS; applies concepts in novel situations |
| Meets Grade Level | **Meets** | Sufficient science understanding to succeed at the next level |
| Approaches Grade Level | **Approaches** | Some understanding; inconsistent application of science concepts |
| Did Not Meet Grade Level | **Did Not Meet** | Significant science knowledge gaps; requires intervention |

## 3. Test Structure

STAAR Science is a single-session test. Items are scenario-based, integrating data analysis, diagrams, and real-world science applications.

```
+------------------------------------------------------------------+
|          STAAR SCIENCE STRUCTURE (Grades 5, 8, Biology EOC)      |
+------------------------------------------------------------------+
|  SINGLE SESSION — Approximately 3–4 hours (untimed)             |
|  Computer-Based                                                  |
|                                                                  |
|  ~44 items total                                                 |
|                                                                  |
|  Item types:                                                     |
|    • Multiple Choice (MCQ) — ~70–75% of items (~30–32 items)     |
|    • Multi-Select (MS) — ~10–15% of items (~4–6 items)           |
|    • Short Answer — Science (SA) — ~15% of items (~6 items)      |
+------------------------------------------------------------------+
```

## 5. Item Types & Formats

### Multiple Choice (MCQ)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Scenario-based or data-based stimulus                   |
|  May include diagrams, data tables, graphs               |
|  Machine scored                                          |
|  DOK 1–3                                                 |
+----------------------------------------------------------+
```

**MCQ Example (Grade 5, DOK 2, TEKS.Sci5.9B — Food Webs):**

*[Diagram shows: Sunlight → Grass → Grasshopper → Lizard → Roadrunner → Hawk]*

Based on the food web, which organism is a PRIMARY producer?

A. Grasshopper
B. Lizard
C. Grass
D. Hawk

*Correct Answer: C*
*Alignment: TEKS.Sci5.9B | DOK 1*

---

**MCQ Example (Grade 8, DOK 2, TEKS.Sci8.5F — Chemical Changes):**

A student mixes vinegar with baking soda. The mixture fizzes and produces bubbles. The temperature of the mixture drops. Which of the following BEST indicates that a chemical change has occurred?

A. The temperature decreased during the reaction
B. The original vinegar and baking soda can be recovered by evaporation
C. A new substance (carbon dioxide gas) with different properties was produced
D. The mixture changed from solid to liquid when the substances were combined

*Correct Answer: C*
*Alignment: TEKS.Sci8.5F | DOK 2*

---

**MCQ Example (Grade 8, DOK 3, TEKS.Sci8.14A — Evolution):**

*[Data table showing beak length and seed size in a population of finches over 50 years; seeds got harder and larger; birds with longer beaks survived better]*

Based on the data, which conclusion is BEST supported about the finch population?

A. Individual finches changed their beak length during their lifetime to eat the larger seeds
B. Natural selection favored finches with longer beaks, increasing the frequency of that trait in the population
C. All finches evolved longer beaks at the same rate because they all experienced the same environment
D. The finches migrated to a new location to find smaller seeds more suitable for their beaks

*Correct Answer: B*
*Alignment: TEKS.Sci8.14A | DOK 3*

---

### Multi-Select (MS)

```
+----------------------------------------------------------+
|  MULTI-SELECT — 1 point                                  |
|                                                          |
|  5–6 options; select ALL correct answers (typically 2)   |
|  All must be selected for credit                         |
|  Machine scored                                          |
+----------------------------------------------------------+
```

**MS Example (Grade 5, DOK 2, TEKS.Sci5.9C — Ecosystem Changes):**

A drought reduces rainfall in a Texas grassland ecosystem. Select the TWO statements that describe likely effects of the drought on the ecosystem.

A. The grassland plant population will increase because less water creates better growing conditions
B. Herbivore populations that depend on grasses for food will decrease
C. The water cycle will speed up and deliver more rain to the area within a week
D. Predator populations may decline as prey populations decrease
E. The soil will immediately become more fertile to compensate for the lack of rain

*Correct Answers: B, D*
*Alignment: TEKS.Sci5.9C | DOK 2*

---

### Short Answer — Science (SA)

```
+----------------------------------------------------------+
|  SHORT ANSWER — SCIENCE — 0–2 points                     |
|                                                          |
|  Written response requiring data-based explanation       |
|  Must reference provided data, diagram, or scenario      |
|  Human scored                                            |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**SA Example (Grade 8, DOK 3, TEKS.Sci8.6A — Motion):**

*Stimulus: A distance-time graph showing a cyclist riding in Texas. The line is flat for the first 5 minutes, then rises steeply for 10 minutes, then rises gradually for another 10 minutes.*

Using the data in the graph, explain what happened to the cyclist's speed during each part of the ride. Use specific values from the graph in your explanation.

*Scoring:*
- *2 pts: Identifies all three phases (stopped, fast, slow); uses specific data values from graph; explains speed correctly for each phase*
- *1 pt: Identifies two of three phases correctly with data, OR describes all phases without specific data values*
- *0 pts: Incorrect interpretation or blank*

## 7. Scientific Investigation Design

STAAR Science frequently includes items that assess students' ability to design and evaluate scientific investigations.

### Investigation Design Components

| Component | Description | TEKS Alignment |
|---|---|---|
| **Hypothesis** | Testable prediction about the relationship between variables | TEKS.Sci.Process.2A |
| **Independent Variable** | The variable the scientist changes | TEKS.Sci.Process.2A |
| **Dependent Variable** | The variable being measured/observed | TEKS.Sci.Process.2B |
| **Control Group** | Condition held constant for comparison | TEKS.Sci.Process.2A |
| **Controlled Variables** | All other factors kept the same | TEKS.Sci.Process.2A |
| **Data Collection** | Measurement using SI units; use of appropriate tools | TEKS.Sci.Process.2B |
| **Conclusion** | Inference drawn from data; relation back to hypothesis | TEKS.Sci.Process.2C |

### Investigation Item Types

```
+------------------------------------------------------------------+
|  INVESTIGATION DESIGN ITEM STRUCTURE (MCQ or SA)                 |
|                                                                  |
|  SCENARIO: A Texas student is investigating whether [variable]   |
|  affects [outcome].                                              |
|                                                                  |
|  STEM (MCQ): Which experimental setup would BEST allow the       |
|  student to test this hypothesis?                                |
|  — OR —                                                          |
|  STEM (SA): Describe one way the student could change the        |
|  experimental design to make the results more reliable.          |
+------------------------------------------------------------------+
```

## 8. Scoring Rubrics

### Short Answer (SA) Rubric — 0–2 Points

| Score | Criteria |
|---|---|
| 2 | Response accurately interprets or applies the science concept. References specific data, evidence, or values from the provided stimulus. Explanation is clear and logically connected. |
| 1 | Response shows partial understanding. Data referenced but not precisely used, OR explanation is accurate but lacks reference to stimulus data. |
| 0 | Response is incorrect, does not address the science concept, is insufficient in length, or is blank. |

```

---------------------------------------------------

DOK LEVEL: 2–3
POINT VALUE: 1 point

SCENARIO: [Texas student or scientist] wants to investigate
          whether [independent variable] affects [dependent variable].

      would BEST allow [the student / scientist] to test this?
      OR
      What is the DEPENDENT variable in this experiment?

A [Distractor — confuses independent and dependent variable]
B [Distractor — missing control group]
C [CORRECT — proper experimental design or correct variable ID]

```

```

-------------------------------------------------------
TARGET TEKS: [TEKS Code]
DOK LEVEL: 3
POINT VALUE: 0–2 points

         explain [science question about the data].

[2–3 sentence model response citing specific data]
```

### Suggested Anchoring Phenomena by Grade

- "During a severe Texas drought, ranchers noticed that grasslands turned brown and cattle populations declined. What caused this change in the ecosystem?"

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] Grade verified as 5, 8, or Biology EOC (not other grades)
- [ ] TEKS code is accurate and grade-appropriate
- [ ] Stimulus (data table/graph/diagram) clearly labeled with units
- [ ] SA prompts require reference to specific stimulus data
- [ ] MCQ distractors represent authentic student misconceptions
- [ ] Investigation design items clearly identify variables
- [ ] Science content is accurate and current
- [ ] Texas context incorporated where possible
- [ ] DOK level matches the cognitive demand
- [ ] MS items specify how many answers to select (TWO/ALL)

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Writing STAAR science items for Grades 3, 4, 6, or 7 | STAAR Science only at Grades 5, 8, Biology | Restrict to tested grades |
| SA prompts without "use data from the graph/table" | Students may rely on prior knowledge only | Always direct students to use provided stimulus data |
| MCQ with two clearly correct options | Creates ambiguity | Review all distractors carefully; only one should be clearly correct |
| Items assessing factual recall only | STAAR science is ~55–60% DOK 2 | Elevate items with real-world scenarios or data |
| Generic phenomena not anchored to Texas | STAAR uses Texas-relevant contexts | Use Texas settings (Big Bend, Gulf Coast, Hill Country, etc.) |
| Using NGSS codes instead of TEKS | STAAR uses TEKS, not NGSS | Reference TEKS Science codes exclusively |

## 12. Prompt Patterns

### Pattern 1: Data-to-Conclusion (MCQ, DOK 2)
> "The [table / graph / diagram] below shows [Texas science scenario]. Based on the data, which [conclusion / explanation / prediction] is BEST supported?"

### Pattern 2: Cause and Effect (MCQ, DOK 2)
> "A student [observed / measured / recorded] that [Texas phenomenon]. Which explanation BEST describes why this [occurred / changed / happened]?"

### Pattern 3: Investigation Design (MCQ or SA, DOK 2–3)
> "[Texas student] wants to investigate whether [independent variable] affects [dependent variable]. Which experimental design would BEST test this question? What is the [dependent / independent / controlled] variable in this experiment?"

### Pattern 4: Food Web / Ecosystem Change (MCQ or SA, DOK 2–3)
> "[Texas ecosystem] diagram shows [food web]. If [organism / factor] were removed or changed, what would MOST LIKELY happen to [other organism / population]? Use evidence from the [diagram / data] to explain."

### Pattern 5: Physical or Chemical Change (MCQ, DOK 2)
> "A student [mixes / heats / combines] two [substances / materials] in a Texas lab. Which observation provides the BEST evidence that a [physical / chemical] change occurred?"

### Pattern 6: Evidence-Based SA (DOK 3)
> "Using the data in the [table / graph], explain [science pattern or relationship]. Use specific [values / evidence] from the [data / graph] in your explanation."
