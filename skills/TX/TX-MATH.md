## 2. Standards Framework

> STAAR Mathematics is aligned to the **Texas Essential Knowledge and Skills (TEKS) for Mathematics**. TEKS are organized by mathematical process standards and content strands.

### TEKS Mathematical Process Standards (Apply at All Grades)

| Process Standard | Description |
|---|---|
| (A) Apply mathematics | Solve problems in real-world and mathematical contexts |
| (B) Use a problem-solving model | Select tools; create plans; evaluate reasonableness |
| (C) Select tools and techniques | Calculators, concrete objects, pictorial models, algorithms |
| (D) Communicate mathematical ideas | Explain reasoning using mathematical language |
| (E) Create and use representations | Use tables, graphs, equations, physical models |
| (F) Analyze relationships | Connect mathematical ideas; recognize structure |
| (G) Display social dispositions | Perseverance, precision, and efficiency in problem solving |

## 3. Test Structure

STAAR Mathematics is a single-session test. Most items are computer-based with an embedded calculator when permitted by grade level.

```
+------------------------------------------------------------------+
|            STAAR MATHEMATICS STRUCTURE (Grades 3–8)             |
+------------------------------------------------------------------+
|  SINGLE SESSION — Approximately 3–4 hours (untimed)             |
|  Computer-Based                                                  |
|                                                                  |
|  ~32–40 items total per grade                                    |
|                                                                  |
|  Item types:                                                     |
|    • Multiple Choice (MCQ) — ~45–50% of items                    |
|    • Multi-Select (MS) — ~15–20% of items                        |
|    • Griddable / Numeric Entry (GRID) — ~15–20% of items         |
|    • Short Answer — Math (SA) — ~10–15% of items                 |
+------------------------------------------------------------------+
```

## 4. Claims & Blueprint

### Reporting Category Weightings

| Reporting Category | Grade 3–4 | Grade 5–6 | Grade 7–8 |

| Computations and Algebraic Relationships | ~30% | ~35% | ~40% |

| Data Analysis and Financial Literacy | ~20% | ~20% | ~20% |

### DOK Distribution

| DOK Level | Description | Approximate % |
|---|---|---|
| DOK 1 | Recall; compute; identify | ~20% |
| DOK 2 | Apply; solve in context; connect representations | ~55–60% |
| DOK 3 | Analyze; multi-step reasoning; justify | ~20–25% |

### Real-World Context Requirement

At least **60–70% of STAAR Mathematics items** are presented in a real-world context. Items should be grounded in situations relevant to Texas students (agriculture, construction, sports, business, etc.).

## 5. Item Types & Formats

### Multiple Choice (MCQ)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Real-world or mathematical context                      |
|  Machine scored                                          |
|  DOK 1–3                                                 |
+----------------------------------------------------------+
```

**MCQ Example (Grade 6, DOK 2, TEKS.Math6.6A):**

A local farmer in West Texas tracks how many gallons of water he uses each week to irrigate different crops. The table shows the relationship between the number of acres planted and the gallons of water used.

| Acres Planted | Gallons Used |
|---|---|
| 2 | 1,400 |
| 5 | 3,500 |
| 8 | 5,600 |
| 11 | 7,700 |

Which statement BEST describes the relationship shown in the table?

A. The gallons of water used is the independent quantity
B. The number of acres planted increases as the gallons of water decreases
C. The number of acres planted is the independent quantity
D. For every gallon of water used, the farmer plants 700 more acres

*Correct Answer: C*
*Alignment: TEKS.Math6.6A | DOK 2*

---

### Multi-Select (MS)

```
+----------------------------------------------------------+
|  MULTI-SELECT — 1 point                                  |
|                                                          |
|  5–6 options; select ALL correct answers (typically 2)   |
|  Full credit only; partial credit not awarded            |
|  Machine scored                                          |
+----------------------------------------------------------+
```

**MS Example (Grade 8, DOK 2, TEKS.Math8.4C):**

A line passes through the points (0, 3) and (4, 11). Select ALL equations that represent this line.

A. y = 2x + 3
B. y = 2x − 3
C. y − 3 = 2(x − 0)
D. y = 3x + 2
E. 2x − y = −3

*Correct Answers: A, C, E*
*Alignment: TEKS.Math8.4C | DOK 2*

---

### Griddable / Numeric Entry (GRID)

```
+----------------------------------------------------------+
|  GRIDDABLE — 1 point                                     |
|                                                          |
|  Student enters a numeric answer                         |
|  No answer choices provided                              |
|  Online: student types in entry box                      |
|  Paper: student fills in answer grid                     |
|  Machine scored                                          |
|  DOK 1–2                                                 |
+----------------------------------------------------------+
```

**GRID Example (Grade 5, DOK 2, TEKS.Math5.4H):**

A rectangular garden in a Texas school has a length of 12.5 feet and a width of 8 feet. What is the area of the garden in square feet?

Record your answer: **100**

*Alignment: TEKS.Math5.4H | DOK 2*

---

### Short Answer — Math (SA)

```
+----------------------------------------------------------+
|  SHORT ANSWER — MATH — 0–2 points                        |
|                                                          |
|  Show work and/or explain reasoning                      |
|  Full credit requires correct answer + valid process     |
|  Human scored                                            |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**SA Example (Grade 7, DOK 3, TEKS.Math7.4A):**

A Texas middle school is ordering jerseys for its basketball team. The regular price of each jersey is $28.50. The school receives a 15% discount.

What is the total cost for 12 jerseys after the discount? Show your work and explain how you found the answer.

*Scoring:*
- *2 pts: Correct answer ($290.70) with clear work showing the 15% discount applied correctly*
- *1 pt: Correct method with minor arithmetic error, OR correct answer without process shown*
- *0 pts: Incorrect method or blank*

## 7. Mathematical Representations

STAAR Mathematics items frequently require students to move between multiple representations.

### Representation Types

| Representation | Description | Common Item Use |
|---|---|---|
| **Tabular** | Input/output table; data table | Identify relationships; find missing values |
| **Graphical** | Coordinate plane; line graph; bar/dot plot | Identify slope; read data; compare quantities |
| **Algebraic** | Equations; inequalities; expressions | Solve; write; simplify |
| **Verbal** | Word problem; real-world scenario | Apply to context |
| **Visual/Geometric** | Diagrams; figures with measurements | Compute area/volume; apply transformations |

### Representation Connections by Grade Band

| Grade Band | Frequent Connections |
|---|---|
| 3–5 | Number line ↔ fraction; table ↔ equation; model ↔ computation |
| 6–7 | Table ↔ equation ↔ graph; ratio ↔ percent ↔ fraction |
| 8/EOC | Equation ↔ graph ↔ table; scatterplot ↔ linear equation; geometric diagram ↔ algebraic equation |

## 8. Scoring Rubrics

### Short Answer (SA) Rubric — 0–2 Points

| Score | Criteria |
|---|---|
| 2 | Work clearly shows a correct mathematical process. Answer is correct. Explanation (if required) demonstrates understanding of the mathematical concept. |
| 1 | Work shows understanding of the mathematical concept but contains a minor computational error. OR Correct answer is given without a clear explanation of the process. |
| 0 | Work shows no understanding of the mathematical concept, or response is blank. |

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] TEKS code is accurate and grade-appropriate
- [ ] Calculator policy followed for the target grade (no calculator Gr 3–5)
- [ ] Real-world context is relevant to Texas students
- [ ] MCQ distractors represent actual student errors (not trivially wrong)
- [ ] MS item specifies "ALL" or number of answers to select
- [ ] GRID answer fits within the STAAR grid format (≤4 digits + decimal)
- [ ] SA items require process/work shown, not just an answer
- [ ] DOK level matches the cognitive demand of the problem
- [ ] All computations verified before item is finalized
- [ ] Problems do not rely on specialized knowledge beyond TEKS

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Calculator use at Grade 3–5 | STAAR Gr 3–5 has no calculator | Design problems solvable by hand |
| MCQ distractors that are obviously wrong | Distractors must represent real student errors | Use common computation or conceptual errors as distractors |
| GRID answers that don't fit the grid | STAAR grid has limited space | Keep numeric answers to ≤4 digits or simple decimals |
| DOK 1 items that only require recall | STAAR aims for mostly DOK 2 | Embed problems in real-world context |
| Over-complex word problems at Grades 3–4 | Reading demand should not exceed grade-level ELA | Keep problem setup brief at lower grades |
| Non-TEKS standards | STAAR uses TEKS, not CCSS | Reference TEKS codes exclusively |

## 12. Prompt Patterns

### Pattern 1: Real-World Multi-Step (MCQ or GRID, DOK 2)
> "[Texas context — farm, construction, sports, etc.]. [Specific mathematical question]. What is [quantity]?"

### Pattern 2: Representation Connection (MCQ, DOK 2)
> "A student created a [table / graph / equation] to represent [relationship]. Which [other representation / statement] represents the SAME relationship?"

### Pattern 3: Justify and Explain (SA, DOK 3)
> "[Multi-step Texas context]. [Multi-step problem]. Show your work and explain how you found your answer."

### Pattern 4: Equivalent Expressions / Select All (MS, DOK 2)
> "Select ALL [expressions / equations / values] that are equivalent to [given expression or scenario]."

### Pattern 5: Financial Literacy (MCQ or GRID, DOK 2)
> "[Texas student / family / business context involving money]. [Problem involving percent, discount, tax, or interest]. What is the [total cost / final amount / saving]?"

### Pattern 6: Data Interpretation (MCQ or SA, DOK 2–3)
> "The [table / graph / dot plot] shows [Texas data context]. Based on the data, [what is the rate of change / which conclusion / what prediction] is BEST supported?"
