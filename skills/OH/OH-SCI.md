## 1. Overview

| Field | Detail |
|---|---|
| **Assessment Name** | Ohio State Tests (OST) — Science |
| **Administering Agency** | Ohio Department of Education and Workforce |
| **Vendor** | American Institutes for Research (AIR) |
| **Grades Tested** | **Grade 5** and **Grade 8** |
| **Testing Window** | April – May |
| **Delivery** | Computer-based; single session |
| **Standards** | Ohio's Learning Standards for Science (revised 2018) |
| **Score Scale** | 5 performance levels; scale score reported per grade |
| **Reporting** | Individual Student Report; School, District, State aggregates |

> **CRITICAL NOTE:** Ohio State Tests for Science are administered **only at Grades 5 and 8**. Do not generate OST Science items for any other grade. There is no high school OST Science assessment.

> **Ohio's Learning Standards vs. NGSS:** Ohio adopted its own standards (revised 2018), incorporating NGSS elements but **not identical to NGSS**. Ohio uses its own coding system (OLS.SCI prefix). Items must align to Ohio's standards — not raw NGSS PEs. Ohio emphasizes inquiry, application, and "Designing Technological/Engineering Solutions Using Science Concepts" as a distinct strand.

### Performance Levels

| Level | Label | Description |
|---|---|---|
| 5 | **Advanced** | Comprehensive understanding; applies reasoning with precision; integrates inquiry, application, and crosscutting concepts |
| 4 | **Accelerated** | Strong understanding; effectively uses inquiry and applies concepts across contexts with minor gaps |
| 3 | **Proficient** | Adequate understanding; applies inquiry and content knowledge at grade level |
| 2 | **Basic** | Partial understanding; recalls some content but struggles with inquiry and application |
| 1 | **Limited** | Minimal understanding; limited to isolated recall with little inquiry or application |

## 3. Test Structure

OST Science is a single-session, computer-based assessment on the AIR platform. All items use stimuli (data tables, diagrams, graphs, models, scenarios). No lab or performance task component.

```
+------------------------------------------------------------------+
|           OST SCIENCE STRUCTURE (Grades 5 and 8)                 |
+------------------------------------------------------------------+
|  SINGLE SESSION                                                  |
|  Computer-Based, AIR Platform                                    |
|  Approximately 90–120 minutes (untimed, with guidelines)         |
|                                                                  |
|  ~40 items per grade                                             |
|                                                                  |
|  Item types:                                                     |
|    • Selected Response (SR) — ~50–55% (~20–22 items; 1 pt each) |
|    • Multi-Select (MS) — ~15–20% (~6–8 items; 1 pt each)        |
|    • Constructed Response — Short CR (~15%; 0–2 pts each)        |
|    • Constructed Response — Extended CR (~10–15%; 0–4 pts each)  |
+------------------------------------------------------------------+
```

### Grade-Level Test Specifications

| Specification | Grade 5 | Grade 8 |
|---|---|---|
| Total Items (approx.) | ~38–42 | ~38–42 |
| Selected Response (SR) | ~20–22 | ~20–22 |
| Multi-Select (MS) | ~6–8 | ~6–8 |

> **Inquiry and Application Requirement:** Items should assess inquiry (investigating, analyzing data) and application (designing solutions, real-world connections). Pure recall items should be minimal.

## 5. Item Types & Formats

### Selected Response (SR)

```
+----------------------------------------------------------+
|  SELECTED RESPONSE — 1 point                             |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Scenario, diagram, data table, or model stimulus        |
|  Aligns to Ohio's Learning Standards (OLS.SCI)           |
|  Machine scored                                          |
+----------------------------------------------------------+
```

**SR Example (Grade 8, DOK 2, OLS.SCI.8.PS.3 — Properties of Matter):**

A student heats a white powder in a beaker. The powder turns black, a gas with a strong odor is released, and the remaining solid has less mass than the original. Which observation provides the BEST evidence that a chemical change occurred?

A. The mass of the solid decreased after heating
B. The powder changed from white to black and a gas was released
C. The student used heat energy to change the substance
D. The remaining solid was still in the same beaker after heating

*Correct Answer: B*
*Alignment: OLS.SCI.8.PS.3 | Inquiry: Analyzing and Interpreting Data | Crosscutting: Cause and Effect | DOK 2*

### Multi-Select Response (MS)

```
+----------------------------------------------------------+
|  MULTI-SELECT RESPONSE — 1 point                         |
|                                                          |
|  5–6 options; select exactly 2 or 3 correct answers      |
|  All must be selected for full credit                    |
|  Machine scored                                          |
+----------------------------------------------------------+
```

**MS Example (Grade 8, DOK 2, OLS.SCI.8.ESS.3 — Hydrological Cycle):**

A scientist finds that Ohio River water quality worsened after heavy spring rains. Select the TWO factors that BEST explain how the hydrological cycle contributes to this pattern.

A. Evaporation from the Ohio River removes pollutants from the water
B. Runoff carries fertilizers and sediment from farmland into tributaries that feed the river
C. Groundwater always flows in the opposite direction of surface water
D. Precipitation increases the volume of surface runoff, which transports pollutants into waterways
E. Water molecules change their chemical composition during the water cycle

*Correct Answers: B, D*
*Alignment: OLS.SCI.8.ESS.3 | Inquiry: Analyzing Data | Crosscutting: Cause and Effect | DOK 2*

### Constructed Response — Short (CR-Short)

```
+----------------------------------------------------------+
|  SHORT CONSTRUCTED RESPONSE — 0–2 points                 |
|                                                          |
|  Brief written explanation (3–5 sentences)               |
|  Stimulus always provided (data, diagram, scenario)      |
|  Must demonstrate inquiry or application reasoning       |
|  Human scored                                            |
|  DOK 2                                                   |
+----------------------------------------------------------+
```

**CR-Short Example (Grade 5, DOK 2, OLS.SCI.5.ESS.2 — Earth's Changing Surface):**

*Stimulus: Two photographs of the same Ohio riverbank — one from 2015 showing a wide bank with grass, one from 2025 showing the bank narrowed with exposed tree roots and fallen trees.*

*"Using evidence from the photographs, explain what process is changing the riverbank. Describe TWO observations that support your explanation."*

### Constructed Response — Extended (CR-Extended)

```
+----------------------------------------------------------+
|  EXTENDED CONSTRUCTED RESPONSE — 0–4 points              |
|                                                          |
|  Detailed written explanation (5–10 sentences)           |
|  Multi-part prompt; requires evidence + reasoning        |
|  Stimulus always provided (data table, graph, diagram)   |
|  Must integrate content knowledge with inquiry/applic.   |
|  Human scored                                            |
|  DOK 3                                                   |
+----------------------------------------------------------+
```

**CR-Extended Example (Grade 8, DOK 3, OLS.SCI.8.LS.3 — Ecosystem Interactions):**

*Stimulus: Data table showing populations of white-tailed deer, coyotes, and native wildflowers in an Ohio state park over 15 years. After a hunting restriction (Year 5), deer increased sharply, coyotes increased moderately, wildflowers declined.*

*"Part A: Using data from the table, explain how the change in deer populations affected wildflower species. Include specific evidence. Part B: Predict what would happen to coyote populations if deer continued to increase. Explain your reasoning using the data."*

## 7. Three-Dimensional Design

Ohio's Learning Standards integrate three strands of scientific literacy. Items should reflect all three strands where possible.

### Ohio's Three Strands of Scientific Literacy

| Strand | What It Is | Example in OST Items |
|---|---|---|
| **Content Knowledge** (What students know) | Disciplinary content: Physical, Life, Earth/Space Science | Properties of matter; ecosystem energy flow; Ohio glacial geology; heredity |
| **Scientific Inquiry** (How students investigate) | Observing, questioning, designing investigations, analyzing data | Analyze Lake Erie water quality data; interpret a population graph from an Ohio wildlife survey |
| **Scientific Application** (How students apply) | Designing solutions; connecting science to real-world problems | Propose a solution to reduce algal blooms; design a structure to withstand tornado-force winds |

### Crosscutting Concepts Emphasized in Ohio Standards

| Crosscutting Concept | Grade 5 Emphasis | Grade 8 Emphasis |
|---|---|---|
| Patterns | Seasonal weather; orbital patterns | Population trends; chemical property patterns |
| Cause and Effect | Forces and motion; species removal in food webs | Tectonic events; pollution and algal blooms |
| Energy and Matter | Food web energy flow; water cycle | Energy transformations; nutrient cycling |
| Systems and System Models | Watersheds; solar system | Earth's interior; hydrological cycle |
| Structure and Function | Plant/animal adaptations | Cellular structures; rock layers |

### Sample Three-Dimensional Item Design (Grade 8)

```
+------------------------------------------------------------------+
|  THREE-STRAND ITEM STRUCTURE                                     |
|                                                                  |
|  PHENOMENON: Harmful algal blooms in Lake Erie have increased    |
|  dramatically since 2010 (Authentic Ohio phenomenon)             |
|                                                                  |
|  CONTENT: OLS.SCI.8.LS.3; OLS.SCI.8.ESS.3                      |
|  INQUIRY: Analyzing and Interpreting Data                        |
|  APPLICATION: Designing Solutions to Environmental Problems      |
|  CROSSCUTTING: Cause and Effect                                  |
|                                                                  |
|  STIMULUS: Data table — phosphorus levels, water temperature,    |
|  and algal bloom coverage in western Lake Erie, 2010–2024        |
|                                                                  |
|  PROMPT: "Part A: Explain the relationship between phosphorus   |
|  levels and algal bloom coverage. Include evidence from data.    |
|  Part B: Propose one solution. Explain how it addresses the     |
|  cause using evidence from the data."                            |
+------------------------------------------------------------------+
```

## 8. Scoring Rubrics

### Short Constructed Response (CR-Short) Rubric — 0–2 Points

| Score | Criteria |
|---|---|
| 2 | Accurately addresses the science concept; uses specific stimulus evidence; complete explanation with clear inquiry or application reasoning |
| 1 | Partially addresses the concept; evidence present but incomplete; basic understanding with minor gaps or inaccuracy |
| 0 | Blank; off-topic; restates stimulus without explanation; no science understanding |

### Extended Constructed Response (CR-Extended) Rubric — 0–4 Points

| Score | Criteria |
|---|---|
| 4 | Fully addresses all parts; thorough content understanding; specific stimulus evidence with clear reasoning; strong inquiry + application |
| 3 | Addresses all parts with mostly accurate content; evidence present but slightly incomplete; solid reasoning with minor gaps |
| 2 | Addresses some parts; partial understanding; evidence vague or loosely connected; inquiry/application reasoning underdeveloped |
| 1 | Minimal response; limited understanding; little/no stimulus evidence; vague or contains significant inaccuracies |
| 0 | Blank; off-topic; restates stimulus without explanation; no science understanding demonstrated |

### CR Scoring Notes

- **Evidence from the stimulus is required.** Responses relying solely on prior knowledge cannot earn the highest score.
- **Multi-part prompts require multi-part responses.** A complete response to only Part A earns a maximum of 2 points on extended CR.
- **Misconceptions reduce the score** by at least one point.
- **Application reasoning is valued.** Connecting science to real-world Ohio contexts demonstrates higher-level understanding.

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] Grade verified as **5 or 8 ONLY**
- [ ] Standard code uses OLS.SCI prefix and is a valid Ohio Learning Standard
- [ ] Item integrates content knowledge with inquiry or application (not pure recall)
- [ ] Anchoring phenomenon is authentic and Ohio-relevant where possible
- [ ] Stimulus has clear labels, units, and realistic data
- [ ] CR prompts direct students to use evidence from the stimulus
- [ ] All SR/MS distractors represent real misconceptions (not obviously wrong)
- [ ] MS items specify how many answers to select (TWO or THREE)
- [ ] CR-Extended items use Part A / Part B multi-part structure
- [ ] Extended CR anchor response (Score 4) written before finalizing
- [ ] Science content is accurate; vocabulary is grade-appropriate

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Writing items for grades other than 5 or 8 | Ohio tests science only at Grades 5 and 8 | Restrict to tested grades |
| Using NGSS PE codes instead of Ohio codes | Ohio uses its own standards, not raw NGSS | Use OLS.SCI prefix and Ohio Content Statements |
| Pure recall items (no inquiry/application) | Ohio emphasizes inquiry and application | Embed data analysis, investigation design, or application |
| CR prompts without evidence directive | Students may skip citing data | Include "Using evidence from the [stimulus]" in all CR prompts |
| Using only 4 performance levels | Ohio uses 5 levels | Always reference the 5-level scale |
| Generic Midwest phenomena | OST favors Ohio-specific contexts | Use Lake Erie, Ohio River, Cuyahoga Valley contexts |
| MS items with only 4 options | Too easy to guess | Use 5–6 options with 2–3 correct |
| CR-Extended with single-part prompts | Should require multi-step reasoning | Use Part A / Part B structure |
| Ignoring the application strand | Ohio emphasizes designing solutions | Include engineering/solution items |

## 12. Prompt Patterns

### Pattern 1: Data-to-Conclusion (SR, DOK 2)
> "The [graph / table] shows [Ohio scenario]. Based on the data, which [conclusion / pattern] is BEST supported?"

### Pattern 2: Phenomenon Explanation (CR-Extended, DOK 3)
> "Scientists observed [Ohio phenomenon]. Part A: Using evidence from the [stimulus], explain [science focus] and the cause-and-effect relationship. Part B: Propose one solution. Explain how it works using science concepts."

### Pattern 3: Model Evaluation (SR or MS, DOK 2–3)
> "A student made a model showing [Ohio concept]. Which statement BEST describes what the model shows? / Select the TWO statements that correctly describe what the model represents."

### Pattern 4: Investigation Design (CR-Extended, DOK 3)
> "A scientist wants to investigate whether [variable] affects [outcome] in [Ohio context]. Part A: Describe a procedure including what to measure and control. Part B: Predict results if the hypothesis is correct."

### Pattern 5: Evidence-Based Argument (CR-Short or CR-Extended, DOK 2–3)
> "Two students disagree about [Ohio science claim]. Student A says [misconception]. Student B says [accurate claim]. Using evidence, explain which student is correct and why."

### Pattern 6: Real-World Application and Engineering Design (MS or CR, DOK 2–3)
> "Ohio communities need to [address environmental challenge]. Select TWO strategies that would BEST help. / Describe ONE solution and explain how it uses science concepts."
