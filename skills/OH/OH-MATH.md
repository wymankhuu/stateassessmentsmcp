## AssessmentForge Skill Guide | Grades 3–8

## 1. Overview

| Field | Detail |
|---|---|
| **Assessment Name** | Ohio State Tests (OST) — Mathematics |
| **Administering Agency** | Ohio Department of Education and Workforce |
| **Vendor** | American Institutes for Research (AIR) |
| **Grades Tested** | 3, 4, 5, 6, 7, 8 |
| **Testing Window** | April – May |
| **Delivery** | Computer-based; two-unit test administered over 2 days |
| **Standards** | Ohio Learning Standards for Mathematics (aligned to CCSS-Math) |
| **Score Scale** | Scale score; 5 performance levels |
| **Reporting** | Individual Student Report; School, District, State aggregates |

> **OST and AIR:** OST Mathematics is developed by **American Institutes for Research (AIR)**. The test is administered in 2 units over 2 days. Unlike SBAC-based assessments, Ohio does not use an explicit calculator/non-calculator session split; calculator availability is governed by grade-level policy and accommodation guidelines.

### Performance Levels

| Level | Label | Description |
|---|---|---|
| 5 | **Advanced** | Superior command of grade-level mathematics; applies concepts flexibly in novel and complex situations; constructs rigorous mathematical arguments |
| 4 | **Accelerated** | Strong understanding of grade-level mathematics; applies concepts and procedures accurately across a variety of contexts with minimal errors |
| 3 | **Proficient** | Adequate understanding of grade-level mathematics; applies concepts and procedures to solve real-world and mathematical problems with reasonable accuracy |
| 2 | **Basic** | Partial understanding of grade-level mathematics; applies procedures in familiar contexts but struggles with multi-step or novel problems |
| 1 | **Limited** | Minimal understanding of grade-level mathematics; significant conceptual and procedural gaps that impede problem solving |

## 3. Test Structure

OST Mathematics is a two-unit assessment administered over two days. There is no explicit calculator/non-calculator session split as in SBAC-based tests; calculator availability follows Ohio grade-level policy.

```
+------------------------------------------------------------------+
|              OST MATHEMATICS STRUCTURE (Grades 3–8)               |
+------------------------------------------------------------------+
|  UNIT 1 — Day 1                                                   |
|  ~60–75 minutes                                                   |
|  Mix of reporting categories                                      |
|  Item types: SR, MS, EQ, SA                                       |
|  ~20–25 items                                                     |
|                                                                   |
+------------------------------------------------------------------+
|  UNIT 2 — Day 2                                                   |
|  ~60–75 minutes                                                   |
|  Mix of reporting categories                                      |
|  Item types: SR, MS, EQ, SA, ER                                   |
|  ~20–25 items (includes Extended Response)                        |
+------------------------------------------------------------------+
```

### Item Type Summary

| Item Type | Abbreviation | Points | Scored | Unit |
|---|---|---|---|---|
| Selected Response | SR | 1 | Machine | 1 and 2 |
| Multi-Select Response | MS | 1 | Machine | 1 and 2 |
| Equation/Numeric Entry | EQ | 1 | Machine | 1 and 2 |
| Short Answer | SA | 0–2 | Human | 1 and 2 |
| Extended Response | ER | 0–4 | Human | 2 |

## 5. Item Types & Formats

### Selected Response (SR)

```
+----------------------------------------------------------+
|  SELECTED RESPONSE — 1 point                             |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Real-world or mathematical context                      |
|  Machine scored                                          |
|  DOK 1–3                                                 |
+----------------------------------------------------------+
```

**SR Example (Grade 7, DOK 2, OH.CCSS.Math.7.RP.A.2):**

A Columbus bakery sells 5 loaves of sourdough bread for $12.50. At this rate, how much would 8 loaves cost?

A. $18.00
B. $20.00
C. $22.50
D. $25.00

*Correct Answer: B*
*Alignment: OH.CCSS.Math.7.RP.A.2 | Number & Operations | DOK 2*

```
+----------------------------------------------------------+
|  MULTI-SELECT RESPONSE — 1 point                         |
|                                                          |
|  5–6 options; select ALL correct answers (typically 2–3) |
|  Full credit only; partial credit not awarded            |
|  Machine scored                                          |

+----------------------------------------------------------+
```

**MS Example (Grade 8, DOK 2, OH.CCSS.Math.8.EE.C.8):**

Select ALL systems of equations that have the solution (3, 7).

B. y = 3x − 2; y = −x + 10
C. y = x + 4; y = 5x − 8
D. y = 7; y = 2x + 1
E. y = 2x + 1; y = −x + 10

*Correct Answers: A, C, E*
*Alignment: OH.CCSS.Math.8.EE.C.8 | Algebra & Algebraic Thinking | DOK 2*

```
+----------------------------------------------------------+
|  SHORT ANSWER — 0–2 points                               |
|                                                          |
|  Explain reasoning in 2–4 sentences                      |
|  Show work required for full credit                      |
|  Human scored                                            |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**SA Example (Grade 6, DOK 3, OH.CCSS.Math.6.RP.A.3):**

A school in Cincinnati is planning a field trip to the Cincinnati Zoo. The school has a budget of $750 for admission. The admission price is $9.50 per student. How many students can attend within the budget? Show your work and explain how you found your answer.

*Scoring:*
- *2 pts: Correct answer (78 students) with clear division work shown; explanation demonstrates understanding of rate reasoning*

- *0 pts: Incorrect approach or blank*

## 7. Mathematical Representations

OST Mathematics frequently requires students to connect multiple representations.

### Representation Types

| Representation | Description | Common OST Use |
|---|---|---|
| **Numeric** | Numbers, fractions, decimals, percents | Computation; comparison |
| **Algebraic** | Equations, expressions, inequalities | Solve; simplify; write |
| **Tabular** | Input/output tables; data tables | Identify patterns; find missing values |
| **Graphical** | Coordinate plane; graphs | Plot points; identify relationships |
| **Verbal** | Word problems; explanations | Apply to context; justify reasoning |

### Calculator Policy

| Grade Band | Calculator Policy |
|---|---|
| Grades 3–5 | **No calculator** — Items designed for mental math or standard algorithms |
| Grades 6–8 | **Scientific calculator** available as an online tool within the testing platform; use permitted across both units |

> **Note:** Unlike SBAC-based assessments, Ohio does not split sessions into calculator and non-calculator. Calculator access is determined by grade level, not by unit. Items at all grade levels are designed so that calculator access does not reduce the cognitive demand of the task.

## 8. Scoring Rubrics

### Short Answer (SA) Rubric — 0–2 Points

| Score | Criteria |
|---|---|
| 2 | Correct solution with clear mathematical reasoning. Work shown systematically. Appropriate mathematical vocabulary used. Explanation demonstrates conceptual understanding. |
| 1 | Partial understanding with minor errors. Correct approach demonstrated even if the final answer contains a computational error. OR Correct answer given without sufficient explanation or work. |
| 0 | Response is incorrect, shows no understanding, or is blank. |

### Extended Response (ER) Rubric — 0–4 Points

| Score | Criteria |
|---|---|
| 4 | All parts correct with clear, complete mathematical reasoning. Work shown systematically. Explanations accurate, thorough, and demonstrate strong conceptual understanding. |
| 3 | Correct approach throughout with mostly accurate results. One minor computational or notational error that does not undermine overall reasoning. Explanations are present and generally sound. |
| 2 | Correct approach on the majority of parts. One significant error or one part incomplete; some valid reasoning present. Partial explanations provided. |
| 1 | Minimal understanding shown. Correct approach on at least one element; some relevant mathematical work attempted but reasoning is largely incomplete or flawed. |
| 0 | Incorrect, irrelevant, or blank. No valid mathematical reasoning demonstrated. |

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] OH.CCSS standard code is accurate and grade-appropriate
- [ ] Unit assignment is correct (ER items must be in Unit 2)
- [ ] Reporting category alignment matches the content domain tested
- [ ] SA items require work to be shown (not just a final answer)
- [ ] ER has 2–3 parts of increasing complexity
- [ ] MS items specify "ALL" or number of correct answers
- [ ] Ohio real-world context used where appropriate
- [ ] Distractors represent actual student computational or conceptual errors
- [ ] All computations verified before item is finalized
- [ ] DOK level matches the actual cognitive demand
- [ ] Calculator assumptions are appropriate for the target grade band
- [ ] Performance level (5-level scale) is referenced correctly if applicable

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| ER items placed in Unit 1 | Extended Response items belong in Unit 2 | Move ER items to Unit 2 only |
| SA that only asks for an answer | SA must require explanation/justification | Add "Show your work and explain how you found your answer" |
| ER with only one part | ER requires multi-part structure | Design 2–3 parts of increasing complexity and cognitive demand |
| Using CCSS codes without OH. prefix | Ohio uses OH.CCSS prefix | Add OH. to all standard codes |
| MS items with only 2 options total | Too few options make guessing easy | Use 5–6 options with exactly 2–3 correct |
| Items testing only rote computation | OST targets DOK 2 at ~55% | Add real-world context to elevate to application level |
| Assuming calculator/non-calculator split | Ohio does not split units by calculator | Design items per grade-band calculator policy, not per unit |
| Using only 4 performance levels | Ohio uses 5 performance levels | Reference all 5 levels: Limited, Basic, Proficient, Accelerated, Advanced |

## 12. Prompt Patterns

### Pattern 1: Real-World Application (SR, DOK 2)
> "[Ohio context — e.g., farm yield, Lake Erie data]. [Multi-step problem requiring application of concept]. What is [answer]?"

### Pattern 2: Justify and Explain (SA, DOK 3)
> "[Ohio scenario requiring strategic thinking — e.g., Ohio Turnpike trip planning]. [Multi-step problem]. Show your work and explain how you found your answer."

### Pattern 3: Equivalent Representations (MS, DOK 2)
> "Select ALL [expressions / equations / graphs / representations] that are equivalent to [given value or expression]."

### Pattern 4: Data Interpretation (SR or SA, DOK 2–3)
> "The [table / graph] shows [Ohio data context — e.g., Lake Erie fish population, Cleveland monthly snowfall]. What is the [mean / rate of change / trend] shown by the data? / Is this relationship proportional or non-proportional? Justify your answer."

### Pattern 5: Multi-Part Modeling (ER, DOK 3)
> "Part A: [Direct calculation using Ohio context]. Part B: [Extension or comparison]. Part C: [Justify whether... / Evaluate if this is reasonable using mathematics]."

### Pattern 6: Comparison and Reasoning (SA or SR, DOK 3)
> "Two students solved this problem differently. Student A says [method/answer]. Student B says [method/answer]. Who is correct? Use mathematics to justify your answer."

### Pattern 7: Geometric Application (SR or EQ, DOK 2)
> "[Ohio landmark or location context — e.g., a rectangular plot near the Scioto River, the dimensions of a Columbus park]. [Area, perimeter, volume, or coordinate geometry problem]. Find the [measurement]."
