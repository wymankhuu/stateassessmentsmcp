# Ohio State Tests ELA — AssessmentForge Skill Guide

## 1. Overview

| Field | Details |
|---|---|
| **State** | Ohio |
| **Assessment Name** | Ohio State Tests (OST) — English Language Arts |
| **Grades Tested** | 3, 4, 5, 6, 7, 8 |
| **Standards** | Ohio Learning Standards for English Language Arts (OLS-ELA, aligned to CCSS) |
| **Vendor** | American Institutes for Research (AIR) |
| **Administration** | Spring; computer-based |
| **Score Reporting** | Scale score; 5 performance levels |
| **High Stakes** | Ohio Third Grade Reading Guarantee (Grade 3 promotion); school accountability |

### Performance Levels

| Level | Name | Description |
|---|---|---|
| 5 | Advanced | Exceeds grade-level proficiency; sophisticated analytical skills |
| 4 | Accelerated | Above proficiency; strong performance |
| 3 | Proficient | Meets grade-level expectations |
| 2 | Basic | Approaching proficiency |
| 1 | Limited | Below minimum proficiency |

> **Ohio Third Grade Reading Guarantee:** Students scoring below proficient on Grade 3 ELA OST may be subject to retention unless qualifying for an exemption.

## 3. Test Structure

Ohio OST ELA is administered in two units over two days.

```
+------------------------------------------------------------------+
|        OHIO STATE TESTS ELA STRUCTURE (Grades 3–8)               |
+------------------------------------------------------------------+
|  UNIT 1 — Day 1 (~60–75 minutes)                                 |
|  ┌────────────────────────────────────────┐                      |
|  │ READING SECTION                        │                      |
|  │ • 2–3 literary passages                │                      |
|  │ • Selected Response (SR) items         │                      |
|  │ • Multi-Select (MS) items              │                      |
|  │ • Short-Answer (SA) items              │                      |
|  └────────────────────────────────────────┘                      |
|                                                                   |
|  UNIT 2 — Day 2 (~60–75 minutes)                                 |
|  ┌────────────────────────────────────────┐                      |
|  │ READING + WRITING SECTION              │                      |
|  │ • 2–3 informational passages           │                      |
|  │ • SR, MS, SA items                     │                      |
|  │ • Extended-response writing prompt     │                      |
|  └────────────────────────────────────────┘                      |
+------------------------------------------------------------------+
```

### Test Component Summary

| Component | Item Types | Points |
|---|---|---|
| Selected Response (SR) | MC (1 pt each) | ~20–25 pts |
| Multi-Select (MS) | Select 2–3 of 5–6 options (1 pt each) | ~6–10 pts |
| Short Answer (SA) | Written response (0–2 pts) | ~6–10 pts |
| Extended Response (ER) | Written essay (0–4 pts) | 4 pts |
| **Total** | | **~36–49 pts** |

## 5. Item Types & Formats

### Selected Response (SR) — 1 Point

```
+----------------------------------------------------------+
|  SELECTED RESPONSE — 1 point                             |
|  4 options (A, B, C, D)                                  |
|  Passage-dependent                                       |
|  Machine scored                                          |
|  DOK 1–3                                                 |
+----------------------------------------------------------+
```

**SR Example (Grade 6, Literary, DOK 3, RL.6.6):**

*[After reading a short story narrated by a teenager in Cleveland]*

How does the author's use of first-person narration affect the reader's understanding of events in the story?

A. It provides an objective view of all characters' thoughts
B. It creates distance between the narrator and the conflict
C. It limits the reader to one perspective and makes the narrator's biases clear
D. It ensures the reader has complete information about the plot

*Correct Answer: C*
*Alignment: RL.6.6 | DOK 3*

---

### Multi-Select (MS) — 1 Point Per Correct Selection

```
+----------------------------------------------------------+
|  MULTI-SELECT — 1 point per correct selection            |
|  Select ALL correct answers (2–3) from 5–6 options       |
|  Passage-dependent                                       |
|  Machine scored                                          |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**MS Example (Grade 7, Informational, DOK 3, RI.7.8):**

*[After reading an editorial about school technology policies]*

Select TWO details from the article that BEST support the author's argument that school technology policies should prioritize student privacy.

---

### Short Answer (SA) — 0–2 Points

```
+----------------------------------------------------------+
|  SHORT ANSWER — 0–2 points                               |
|  2–4 sentence written response                           |
|  Must cite textual evidence                              |
|  Human scored                                            |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**SA Example (Grade 5, Informational, DOK 3, RI.5.2):**

What are two main ideas the author develops in this article? Use details from the text to support your answer.

---

### Extended Response (ER) — 0–4 Points

```
+----------------------------------------------------------+
|  EXTENDED RESPONSE — 0–4 points                         |
|                                                          |
|  Multi-paragraph informational or argumentative essay    |
|  Based on 2–3 provided passages                         |
|  Must synthesize evidence from passages                 |
|  Human scored                                           |
|  DOK 3–4                                                |
+----------------------------------------------------------+
```

**ER Prompt Example (Grade 8):**

*[After reading two informational texts about Ohio's manufacturing history]*

Write a well-developed essay explaining how Ohio's manufacturing industry has shaped its economy and identity. Use evidence from BOTH texts to support your response.

## 8. Scoring Rubrics

### Short Answer (SA) Rubric — 0–2 Points

| Score | Criteria |
|---|---|
| 2 | Accurate, specific response. Includes relevant textual evidence (quoted or paraphrased) that directly supports the answer. |
| 1 | Partially accurate response. OR Accurate response without sufficient textual evidence. |
| 0 | Inaccurate, irrelevant, too brief, or blank. |

### Extended Response (ER) Rubric — 0–4 Points

| Score | Criteria |
|---|---|
| 4 | Clear, focused essay that fully addresses the prompt. Synthesizes evidence from both/all sources with clear elaboration. Well organized with effective transitions. Strong command of language and conventions. |
| 3 | Essay addresses the prompt adequately. Uses evidence from sources, though synthesis may be uneven. Organization is evident. Minor errors. |
| 2 | Partial response. Essay shows some understanding of the prompt but uses limited evidence. Organization is inconsistent. Errors present. |
| 1 | Minimal response. Little evidence used, weak organization, frequent errors. |
| 0 | Blank, off-task, or copied from sources. |

## 9. Item Generation Templates

### Template A: SR — Literary Point of View (DOK 3)

```
ITEM TEMPLATE: SR — Literary Point of View (DOK 3)
---------------------------------------------------
TARGET STANDARD: RL.[GRADE].6
PASSAGE TYPE: Literary fiction or narrative nonfiction
DOK LEVEL: 3
POINT VALUE: 1 point

STEM:
"How does the author's use of [POINT OF VIEW / NARRATION]
 affect the reader's understanding of [EVENT / CHARACTER / THEME]?"

OPTIONS:
A [Distractor — misstates the effect; incorrect about limitation]
B [Distractor — correct about narration type, wrong about effect]
C [CORRECT — accurately describes effect on reader understanding]
D [Distractor — describes opposite effect]

ALIGNMENT: RL.[GRADE].6 | DOK 3
```

---

### Template B: MS — Argument Evidence (DOK 3)

```
ITEM TEMPLATE: MS — Argument Evidence (DOK 3)
----------------------------------------------
TARGET STANDARD: RI.[GRADE].8
PASSAGE TYPE: Informational (editorial, argument, speech)
DOK LEVEL: 3
POINT VALUE: 1 pt per correct (2–3 correct of 5–6 options)

STEM:
"Select the TWO [or THREE] details from the article that BEST
 support the author's argument that [CLAIM]."

OPTIONS (5–6 total):
[Option 1 — CORRECT: directly supports author's stated claim]
[Option 2 — CORRECT: second piece of supporting evidence]
[Option 3 — Distractor: related but does not directly support claim]
[Option 4 — Distractor: from passage but supports a different point]
[Option 5 — Distractor: partially relevant but misrepresents author's argument]

ALIGNMENT: RI.[GRADE].8 | DOK 3
```

---

### Template C: ER — Multi-Source Essay (DOK 4)

```
ITEM TEMPLATE: Extended Response (DOK 3–4)
-------------------------------------------
TARGET STANDARD: W.[GRADE].2 (informational) or W.[GRADE].1 (argument)
DOK LEVEL: 3–4
POINT VALUE: 0–4 points

SOURCE SET: 2–3 passages on a shared topic (informational or mixed)

PROMPT:
"Write a well-developed [informational essay / argument] [explaining /
 arguing] [FOCUSED TOPIC]. Use evidence from [BOTH / ALL] texts
 to support your response."

SCORING: 0–4 holistic ER rubric (see Section 8)
ALIGNMENT: W.[GRADE].1 or W.[GRADE].2 | DOK 3–4
```

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] OLS-ELA standard code verified for grade level
- [ ] SR/MS items are passage-dependent
- [ ] SA prompts require textual evidence explicitly
- [ ] ER prompt specifies source set (2–3 passages)
- [ ] ER scored using 0–4 holistic rubric
- [ ] Passage Lexile within grade-level range
- [ ] Multi-select items have 2–3 correct answers from 5–6 options
- [ ] Ohio context incorporated where appropriate

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| ER without multi-source requirement | Ohio OST ER uses a source set | Always reference 2+ passages in ER prompt |
| MS with only 1 correct answer | Multi-select requires 2–3 correct | Verify correct answer count before finalizing |
| Using CCSS codes directly | Ohio uses OLS-ELA codes | Use Ohio standard codes |

## 12. Prompt Patterns

### Pattern 1: Literary Analysis — Point of View (SR, DOK 3)
> "How does the author's use of [first-person / third-person limited / omniscient] narration affect the reader's understanding of [CHARACTER / EVENTS / THEME]?"

### Pattern 2: Informational — Argument Evaluation (MS, DOK 3)
> "Select the TWO details from the article that BEST support the author's argument that [CLAIM]."

### Pattern 3: Vocabulary in Context (SR, DOK 2)
> "As used in paragraph [#], what does the word [TARGET_WORD] most nearly mean?"

### Pattern 4: Extended Response — Explanatory (DOK 4)
> "Write a well-developed essay explaining [TOPIC]. Use evidence from BOTH texts to support your response."

### Pattern 5: Theme Development (SR or SA, DOK 3)
> "How does the author develop the theme that [THEME STATEMENT] through [CHARACTER / EVENTS / LANGUAGE CHOICES]?"

### Pattern 6: Cross-Text Synthesis (ER, DOK 4)
> "Both texts address [SHARED TOPIC]. Write an essay that synthesizes information from both texts to [explain / argue] [FOCUSED CLAIM]."
