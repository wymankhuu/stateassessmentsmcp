## 1. Overview

| Field | Detail |
|---|---|
| **Assessment Name** | DC Comprehensive Assessment Program (DC CAPE) — Science |
| **Administering Agency** | Office of the State Superintendent of Education (OSSE) |
| **Vendor** | Pearson |
| **Grades Tested** | **Grade 5**, **Grade 8**, **Grade 10** |
| **Testing Window** | March – May |
| **Delivery** | Computer-based; single session |
| **Standards** | DC Science Standards (incorporating NGSS) |
| **Score Scale** | 5 performance levels; scaled score varies by grade |
| **Reporting** | Individual Student Report; School, LEA, District aggregates |

> **CRITICAL NOTE:** DC CAPE Science is administered **only at Grades 5, 8, and 10**. Do not generate DC CAPE Science items for Grades 3, 4, 6, 7, or 11.

> **DC CAPE and NGSS:** DC Science Standards fully incorporate the **Next Generation Science Standards (NGSS)** framework. All items must be three-dimensional: integrating **Disciplinary Core Ideas (DCI)**, **Science and Engineering Practices (SEP)**, and **Crosscutting Concepts (CCC)**.

### Performance Levels

| Level | Label | Description |
|---|---|---|
| 5 | **Exceeded Expectations** | Distinguished three-dimensional science understanding; expertly integrates DCI, SEP, and CCC |
| 4 | **Met Expectations** | Strong three-dimensional understanding; appropriately applies practices and crosscutting concepts |
| 3 | **Approached Expectations** | Moderate understanding; applies DCI content but inconsistently integrates SEP or CCC |
| 2 | **Partially Met Expectations** | Partial understanding; limited to surface-level application of science concepts |
| 1 | **Did Not Yet Meet Expectations** | Minimal understanding; limited to recall of isolated facts |

## 3. Test Structure

DC CAPE Science is a single-session, computer-based assessment. All items are scenario-based with data tables, diagrams, graphs, and models as stimuli.

```
+------------------------------------------------------------------+
|          DC CAPE SCIENCE STRUCTURE (Grades 5, 8, 10)              |
+------------------------------------------------------------------+
|  SINGLE SESSION                                                  |
|  Computer-Based, Fixed-Form                                      |
|  Approximately 90–120 minutes                                    |
|                                                                  |
|  ~40 items per grade                                             |
|                                                                  |
|  Item types:                                                     |
|    Selected Response (SR) — ~55–60% (~24 items)                 |
|    Constructed Response (CR) — ~20–25% (~8–10 items; 0–3 pts)   |
|    Technology Enhanced / Multi-Select — ~15–20% (~6–8 items)     |
+------------------------------------------------------------------+
```

### Grade-Level Test Specifications

| Specification | Grade 5 | Grade 8 | Grade 10 |
|---|---|---|---|
| Total Items (approx.) | ~38–42 | ~38–42 | ~38–42 |
| Selected Response | ~22–26 | ~22–26 | ~22–26 |
| Multi-Select / TE | ~6–8 | ~6–8 | ~6–8 |
| Constructed Response | ~6–10 | ~6–10 | ~6–10 |
| Testing Time | 90–120 min | 90–120 min | 90–120 min |

> **Three-Dimensional Requirement:** Every DC CAPE Science item must integrate at least one **DCI**, one **SEP**, and one **CCC**. Items that test DCI content in isolation are not aligned to the DC Science Standards.

## 5. Item Types & Formats

### Selected Response (SR)

```
+----------------------------------------------------------+
|  SELECTED RESPONSE — 1 point                             |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Scenario, diagram, data table, or model stimulus        |
|  Must integrate DCI + SEP + CCC                          |
|  Machine scored                                          |
+----------------------------------------------------------+
```

**SR Example (Grade 8, DOK 2, MS-ESS2-2 — Geoscience Processes):**

Scientists studying the Potomac River near Washington, DC, found deposits of ancient marine fossils in rock layers along the riverbanks, even though the river is now a freshwater system over 100 miles from the ocean. Which explanation BEST accounts for this observation?

A. The Potomac River once flowed directly into the ocean, depositing marine organisms along its banks
B. Ancient seas once covered the mid-Atlantic region, and tectonic uplift later exposed the marine sedimentary layers that the river now cuts through
C. Ocean fish migrated upstream during floods and their remains became trapped in the riverbank sediment
D. Wind carried shells and marine organisms inland from the Atlantic coast over millions of years

*Correct Answer: B*
*Alignment: MS-ESS2-2 | SEP: Constructing Explanations | CCC: Stability and Change | DOK 2*

---

**SR Example (Grade 5, DOK 2, 5-LS2-1 — Ecosystem Matter Flow):**

A diagram shows: Sunlight -> Oak trees -> White-tailed deer -> Red foxes

Which statement BEST explains the role of oak trees in this Rock Creek Park ecosystem model?

A. Oak trees receive energy from deer through a food chain
B. Oak trees capture energy from the sun and store it in their cells
C. Oak trees are decomposers that break down dead organisms in the forest soil
D. Oak trees get energy from the forest soil through their root system

*Correct Answer: B*
*Alignment: 5-LS2-1 | SEP: Developing and Using Models | CCC: Energy and Matter | DOK 2*

### Constructed Response (CR)

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE — 0–3 points                       |
|                                                          |
|  Written explanation using evidence from the stimulus    |
|  Stimulus always provided (data, diagram, scenario)      |
|  Must demonstrate three-dimensional reasoning            |
|  Human scored                                            |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**CR Example (Grade 8, DOK 3, MS-ESS3-3 — Human Impact):**

*Stimulus: A data table showing dissolved oxygen, E. coli bacteria counts, nitrogen levels, and macroinvertebrate diversity index at four locations along the Potomac River: upstream in rural Maryland, at Great Falls near the DC border, in the Anacostia tributary within DC, and downstream in the tidal Potomac near Alexandria. The Anacostia tributary shows the lowest dissolved oxygen, highest E. coli counts, and lowest biodiversity.*

*"Using data from the table, construct an explanation for the differences in water quality and biodiversity at different locations along the Potomac River system. Include specific evidence from the data and explain the cause-and-effect relationships between human activity and the river's ecological health."*

---

**CR Example (Grade 10, DOK 3, HS-ESS2-2 — Earth Systems Feedbacks):**

*Stimulus: Graph showing average summer temperatures, impervious surface coverage (percentage), and tree canopy coverage for six DC neighborhoods from 2000–2020, showing that neighborhoods with more pavement and less tree canopy have higher average temperatures.*

*"Using evidence from the graph, analyze how changes in land use (impervious surfaces and tree canopy) have affected temperatures across DC neighborhoods. Explain how the urban heat island effect could create feedback effects on other systems, including energy use, air quality, and human health in affected communities."*

## 7. Three-Dimensional Design

Every DC CAPE Science item must reflect all three NGSS dimensions simultaneously.

### Three-Dimensions Alignment Guide

| Dimension | What It Is | Example in DC CAPE Items |
|---|---|---|
| **DCI** (What students know) | Disciplinary science content | Potomac River ecology; Rock Creek Park forest ecosystems; urban heat island; chemical reactions; energy transfer |
| **SEP** (What students do) | How scientists work | Analyze water quality data; construct explanations from evidence; use models to predict ecosystem changes |
| **CCC** (Lens of thinking) | Cross-domain thinking tools | Cause and effect; patterns; energy and matter; structure and function; systems and system models |

### Crosscutting Concepts by Grade Band

| CCC | Grade 5 Emphasis | Grade 8 Emphasis | Grade 10 Emphasis |
|---|---|---|---|
| Patterns | Seasonal cycles in Rock Creek Park ecosystems; weather data | Water quality patterns across Potomac tributaries; population trends | Periodic table patterns; evolutionary change |
| Cause and Effect | Food chain disruption; erosion along river banks | Stormwater runoff impacts on Anacostia River; chemical reactions | Climate feedbacks; homeostasis disruption |
| Energy and Matter | Food webs in urban park ecosystems; water cycle | Chemical reactions; thermal energy in urban heat islands | Metabolic pathways; Earth energy systems |
| Structure and Function | Tree and plant adaptations in urban forests | River system structure; cell structures | DNA and protein structure; organ systems |
| Systems and System Models | Park ecosystems; Potomac watershed | DC stormwater management system; Earth systems | Climate systems; biological feedback loops |

## 8. Scoring Rubrics

### Constructed Response (CR) Rubric — 0–3 Points

| Score | Criteria |
|---|---|
| 3 | Response accurately addresses the science concept; demonstrates clear three-dimensional understanding (DCI + SEP or CCC evident); includes specific, relevant evidence from the stimulus; explanation is complete, accurate, and logically connected |
| 2 | Response addresses the science concept with partial accuracy; shows understanding of the DCI but only partially integrates a practice or crosscutting concept; evidence present but may be incomplete |
| 1 | Response minimally addresses the science concept; shows limited understanding; little or no evidence from stimulus; explanation vague or contains science inaccuracies |
| 0 | Response does not address the concept; blank; off-topic; restates stimulus without explanation |

### CR Scoring Notes

- **Evidence from the stimulus is required.** Responses relying solely on prior knowledge without referencing the provided data earn a maximum of 1 point.
- **Three-dimensional reasoning earns full credit.** A Score 3 integrates content knowledge (DCI) with at least one SEP or CCC.
- **Misconceptions reduce the score.** A significant scientific misconception drops the response by one score point.

## 10. Contextualization — DC Science

When generating DC CAPE Science items, prioritize authentic DC natural and urban settings:

### DC Science Context Guide

| Setting / Phenomenon | Grade | Science Domain | PE Alignment |
|---|---|---|---|
| Potomac River ecology (fish populations, water quality, watershed) | 5, 8, 10 | Life/Earth Science | 5-LS2, MS-LS2, MS-ESS3, HS-ESS2 |
| Rock Creek Park forest ecosystem (deer, foxes, birds, invasive species) | 5, 8 | Life Science | 5-LS2, MS-LS2 |
| Anacostia River restoration and urban water quality | 8, 10 | Earth/Life Science | MS-ESS3, HS-ESS3 |
| DC urban heat island effect | 8, 10 | Earth/Physical Science | MS-ESS3, HS-ESS2 |
| DC stormwater management and green infrastructure | 8, 10 | Earth Science | MS-ESS3, HS-ESS3 |
| National Mall tree health and urban forestry | 5, 8 | Life Science | 5-LS2, MS-LS2 |
| Potomac River tidal patterns and Chesapeake Bay connection | 5, 8 | Earth Science | 5-ESS2, MS-ESS2 |
| DC air quality and transportation emissions | 8, 10 | Earth/Physical Science | MS-ESS3, HS-ESS2 |
| Cherry blossom bloom timing and climate change | 5, 8 | Life/Earth Science | 5-LS2, MS-ESS3 |
| Rock Creek geology and Piedmont-Coastal Plain boundary | 5, 8, 10 | Earth Science | 5-ESS2, MS-ESS2, HS-ESS2 |
| DC solar energy and building efficiency | 8, 10 | Physical Science | MS-PS3, HS-PS3 |
| Kenilworth Aquatic Gardens ecology | 5, 8 | Life Science | 5-LS2, MS-LS2 |

### Suggested Anchoring Phenomena by Grade

**Grade 5 Phenomena:**
- "Every spring, the cherry blossom trees along the Tidal Basin bloom, but over the past 30 years the average bloom date has moved earlier by about a week. How do environmental factors affect when the trees bloom, and where does the energy for flowering come from?"
- "Students visiting Rock Creek Park noticed that the stream was cloudy and fast-flowing after a rainstorm, but clear and slow a few days later. What processes explain these changes?"
- "In Rock Creek Park, scientists found that areas with many white-tailed deer have fewer wildflowers and young trees than areas where deer are less common. How does the number of deer affect the movement of matter through this ecosystem?"

**Grade 8 Phenomena:**
- "Water quality data shows that the Anacostia River has significantly higher levels of bacteria and lower dissolved oxygen than the Potomac River, even though they flow through the same city. What factors explain this difference, and how do they affect aquatic life?"
- "DC neighborhoods with more pavement and fewer trees can be 10–15 degrees Fahrenheit warmer than neighborhoods with more green space during summer heat waves. What mechanisms cause this temperature difference, and how could green infrastructure reduce it?"
- "The Potomac River rises and falls with the tides even though it is over 100 miles from the ocean at DC. What causes tidal effects to reach this far inland?"

**Grade 10 Phenomena:**
- "The Anacostia River watershed has been heavily urbanized over the past century, and scientists have documented declining fish species diversity alongside increasing impervious surface coverage. Analyze how changes in land use create feedback effects across the watershed's ecological and hydrological systems."
- "DC's average temperature has risen faster than the global average over the past 50 years, with the urban heat island effect intensifying in densely built neighborhoods. Explain how urban development, vegetation loss, and increased energy use create interacting feedback loops."

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] Grade verified as 5, 8, or 10 ONLY
- [ ] PE code is a valid NGSS Performance Expectation
- [ ] Item is three-dimensional: DCI + SEP + CCC all identified
- [ ] Anchoring phenomenon is authentic and DC-relevant where possible
- [ ] Stimulus (data table/graph/diagram) has clear labels, units, and realistic data
- [ ] CR prompt directs students to use evidence from the stimulus
- [ ] All distractors represent real misconceptions (not obviously wrong)
- [ ] MS items specify how many answers to select (TWO/THREE)
- [ ] Score 3 anchor response written before finalizing CR item
- [ ] Science content is accurate and reflects current scientific understanding
- [ ] Vocabulary is grade-appropriate

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Writing items for Grades 3, 4, 6, 7, or 11 | DC CAPE Science only at Grades 5, 8, 10 | Restrict to tested grades |
| DCI-only items (no SEP or CCC) | DC CAPE requires three-dimensional items | Always embed a practice and crosscutting concept |
| CR prompts without evidence directive | Students may respond without citing data | Include "Use evidence from the [data/graph/diagram]" |
| Generic science phenomena not anchored to DC | DC CAPE benefits from DC contexts | Use Potomac River, Rock Creek Park, Anacostia, urban heat island contexts |
| MS items with only 2 options in 4 total | Too easy to guess | Use 5–6 options with exactly 2–3 correct |

## 12. Prompt Patterns

### Pattern 1: Data-to-Conclusion (SR, DOK 2)
> "The [graph / table / diagram] below shows [DC science scenario]. Based on the data, which [conclusion / explanation / pattern] is BEST supported?"

### Pattern 2: Phenomenon Explanation (CR, DOK 3)
> "Scientists observed [DC-anchored phenomenon]. Using evidence from the [data / model / diagram], construct an explanation for [specific science focus]. Explain the [cause-and-effect / energy flow / pattern] relationship."

### Pattern 3: Model Evaluation (SR or MS, DOK 2–3)
> "A student made a model showing [DC science concept]. Which statement BEST describes what the model shows about [DCI focus]?"

### Pattern 4: Investigation Design (CR, DOK 3)
> "A scientist in Washington, DC, wants to investigate whether [variable] affects [outcome] in [Potomac River / Rock Creek Park / DC neighborhood]. Describe a procedure the scientist could follow. Include what would be measured and how the scientist would know if the variable made a difference."

### Pattern 5: Evidence-Based Argument (CR, DOK 3)
> "Two students disagree about [DC science claim]. Student A says [misconception]. Student B says [accurate claim]. Using evidence from the [data / diagram], explain which student is correct and why."

### Pattern 6: Human Impact and Solutions (MS or CR, DOK 2–3)
> "Human activities have [impacted DC's urban environment]. Select the TWO strategies that BEST [monitor / reduce / address] this impact."
