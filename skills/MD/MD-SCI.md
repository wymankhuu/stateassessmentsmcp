## 1. Overview

| Field | Detail |
|---|---|
| **Assessment Name** | Maryland Comprehensive Assessment Program (MCAP) — Science |
| **Administering Agency** | Maryland State Department of Education (MSDE) |
| **Vendor** | Cognia / Pearson |
| **Grades Tested** | **Grade 5**, **Grade 8**, **Grade 10** |
| **Testing Window** | March – May |
| **Delivery** | Computer-based; single session |
| **Standards** | Maryland Next Generation Science Standards (MD-NGSS) |
| **Score Scale** | 4 performance levels; scaled score varies by grade |
| **Reporting** | Individual Student Report; School, District, State aggregates |

> **CRITICAL NOTE:** MCAP Science is administered **only at Grades 5, 8, and 10**. Do not generate MCAP Science items for Grades 3, 4, 6, or 7. Grade 10 covers high school physical and life science standards.

> **MCAP Science and NGSS:** The MCAP Science assessment uses the **Next Generation Science Standards (NGSS)** framework as adopted by Maryland. All items must be three-dimensional: integrating **Disciplinary Core Ideas (DCI)**, **Science and Engineering Practices (SEP)**, and **Crosscutting Concepts (CCC)**.

### Performance Levels

| Level | Label | Description |
|---|---|---|
| 4 | **Distinguished** | Demonstrates distinguished three-dimensional science understanding; expertly integrates DCI, SEP, and CCC; constructs sophisticated evidence-based explanations |
| 3 | **Proficient** | Demonstrates strong three-dimensional science understanding; effectively applies science practices and crosscutting concepts |
| 2 | **Developing** | Demonstrates partial understanding; applies some DCI content but struggles with science practices |
| 1 | **Beginning** | Demonstrates minimal science understanding; limited to recall of isolated facts |

## 3. Test Structure

MCAP Science is a single-session, computer-based assessment. All items are scenario-based (no lab practical). Items use data tables, diagrams, graphs, and models as stimuli.

```
+------------------------------------------------------------------+
|         MCAP SCIENCE STRUCTURE (Grades 5, 8, 10)                  |
+------------------------------------------------------------------+
|  SINGLE SESSION                                                   |
|  Computer-Based, Fixed-Form                                       |
|  Approximately 90–120 minutes                                     |
|                                                                   |
|  ~40 items per grade                                              |
|                                                                   |
|  Item types:                                                      |
|    * Selected Response (SR) — ~55–60% (~24 items)                |
|    * Multi-Select Response (MS) — ~15–20% (~6–8 items)           |
|    * Constructed Response (CR) — ~20–25% (~8–10 items; 0–3 pts)  |
+------------------------------------------------------------------+
```

### Grade-Level Test Specifications

| Specification | Grade 5 | Grade 8 | Grade 10 |
|---|---|---|---|
| Total Items (approx.) | ~38–42 | ~38–42 | ~38–42 |
| Selected Response | ~22–26 | ~22–26 | ~22–26 |
| Multi-Select | ~6–8 | ~6–8 | ~6–8 |
| Constructed Response | ~6–10 | ~6–10 | ~6–10 |
| Testing Time | 90–120 min | 90–120 min | 90–120 min |

> **Three-Dimensional Requirement:** Every MCAP Science item must integrate at least one **DCI**, one **SEP**, and one **CCC**. Items that test DCI content in isolation (pure recall) are not aligned to Maryland's science standards.

## 5. Item Types & Formats

### Selected Response (SR)

```
+----------------------------------------------------------+
|  SELECTED RESPONSE — 1 point                             |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Scenario, diagram, data table, or model stimulus        |
|  Must integrate DCI + SEP + CCC                          |
|  Machine scored                                          |
+----------------------------------------------------------+
```

**SR Example (Grade 8, DOK 2, MS-LS2-2 — Ecosystem Interactions):**

Scientists studying the Chesapeake Bay observed that when oyster populations decline, water clarity decreases and algal blooms increase. A student claims this happens because oysters filter algae from the water as they feed. Which additional observation would BEST support this claim?

A. Oysters grow faster in warmer water temperatures during summer months
B. Areas of the bay with healthy oyster reefs have significantly clearer water than areas where oysters have been removed
C. Algal blooms also occur in freshwater lakes that have never contained oysters
D. The shells of oysters provide habitat for small fish and invertebrates

*Correct Answer: B*
*Alignment: MS-LS2-2 | SEP: Constructing Explanations | CCC: Cause and Effect | DOK 2*

---

**SR Example (Grade 5, DOK 2, 5-LS2-1 — Ecosystem Energy Flow):**

A diagram shows: Sunlight -> Bay Grasses -> Blue Crabs -> Striped Bass -> Osprey

Which statement BEST explains the role of bay grasses in this Chesapeake Bay ecosystem model?

A. Bay grasses receive energy from blue crabs through a food chain
B. Bay grasses capture energy from the sun and store it in their cells
C. Bay grasses are decomposers that break down dead organisms on the bay floor
D. Bay grasses get energy from the muddy bay sediment through their root system

*Correct Answer: B*
*Alignment: 5-LS2-1 | SEP: Developing and Using Models | CCC: Energy and Matter | DOK 2*

### Multi-Select Response (MS)

```
+----------------------------------------------------------+
|  MULTI-SELECT RESPONSE — 1 point                         |
|                                                          |
|  5–6 options; select exactly 2 or 3 correct answers      |
|  All must be selected for credit                         |
|  Machine scored                                          |
+----------------------------------------------------------+
```

**MS Example (Grade 8, DOK 2, MS-ESS3-3 — Human Impact):**

Excess fertilizer runoff from Maryland's Eastern Shore farms has been linked to algal blooms in the Chesapeake Bay. Select the TWO strategies that would BEST help scientists monitor and minimize this human impact on the bay ecosystem.

A. Remove all vegetation along riverbanks to reduce shade and algae growth
B. Collect monthly water samples to measure nitrogen and phosphorus levels at major tributaries
C. Introduce non-native fish species to the bay to consume the algae
D. Establish vegetated buffer zones between farmland and tributaries to absorb excess nutrients before they reach the bay
E. Increase the flow rate of rivers by straightening their natural channels

*Correct Answers: B, D*
*Alignment: MS-ESS3-3 | SEP: Constructing Explanations | CCC: Cause and Effect | DOK 2*

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE — 0–3 points                       |
|                                                          |
|  Written explanation using evidence from the stimulus    |
|  Stimulus always provided (data, diagram, scenario)      |
|  Must demonstrate three-dimensional reasoning            |
|  Human scored                                            |

+----------------------------------------------------------+
```

**CR Example (Grade 8, DOK 3, MS-LS2-2 — Ecosystem Interactions):**

*Stimulus: A data table showing the population changes of blue crabs, oysters, and submerged aquatic vegetation (SAV) in the Chesapeake Bay over 20 years. When oyster restoration projects began (Year 10), water clarity improved and SAV coverage increased, followed by increased blue crab populations.*

*"Using data from the table, construct an explanation for how oyster restoration affected blue crab populations in the Chesapeake Bay. Include evidence from the data and explain the cause-and-effect relationships."*

## 7. Three-Dimensional Design

Every MCAP Science item must reflect all three NGSS dimensions simultaneously.

### Three-Dimensions Alignment Guide

| Dimension | What It Is | Example in MCAP Items |
|---|---|---|
| **DCI** (What students know) | Disciplinary science content | Chesapeake Bay food webs; chemical reactions; Maryland coastal geology; blue crab life cycle; genetic inheritance |
| **SEP** (What students do) | How scientists work | Analyze water quality data; construct explanations from evidence; use a model to predict ecosystem changes |
| **CCC** (Lens of thinking) | Cross-domain thinking tools | Cause and effect; patterns; energy and matter; structure and function; systems and system models |

### Sample Three-Dimensional Item Design (Grade 8)

```
+------------------------------------------------------------------+
|  3D ITEM STRUCTURE                                                |
|                                                                   |
|  PHENOMENON: Water quality in the Chesapeake Bay improves         |
|  significantly near restored oyster reefs but remains poor        |
|  in areas without oysters (Authentic MD phenomenon)               |
|                                                                   |
|  DCI: MS-LS2 — Ecosystems; MS-ESS3 — Human impacts               |
|  SEP: Analyzing and Interpreting Data                             |
|  CCC: Cause and Effect                                            |
|                                                                   |
|  STIMULUS: Time-series data table showing nitrogen levels,        |
|  dissolved oxygen, water clarity, and SAV coverage near           |
|  oyster restoration sites vs. control sites, 2010–2025           |
|                                                                   |
|  PROMPT: "Using data from the table, construct an explanation     |
|  for the difference in water quality between the restoration      |
|  sites and control sites. Include specific evidence from the      |
|  data and explain the cause-and-effect relationships."            |
+------------------------------------------------------------------+
```

| CCC | Grade 5 Emphasis | Grade 8 Emphasis | Grade 10 Emphasis |
|---|---|---|---|

## 8. Scoring Rubrics

### Constructed Response (CR) Rubric — 0–3 Points

| Score | Criteria |
|---|---|
| 3 | Response accurately addresses the science concept; demonstrates clear three-dimensional understanding (DCI + SEP or CCC evident); includes specific, relevant evidence from the stimulus; explanation is complete, accurate, and logically connected |
| 2 | Response addresses the science concept with partial accuracy; shows understanding of the DCI but only partially integrates a practice or crosscutting concept; evidence from stimulus is present but may be incomplete or imprecisely used |
| 1 | Response minimally addresses the science concept; shows limited understanding; little or no evidence from stimulus used; explanation vague, overgeneralized, or contains minor science inaccuracies |
| 0 | Response does not address the science concept; blank; off-topic; restates stimulus without explanation; demonstrates no science understanding |

### CR Scoring Notes

- **Evidence from the stimulus is required.** A response that relies solely on prior knowledge without referencing the provided data/diagram earns a maximum of 1 point.
- **Three-dimensional reasoning earns full credit.** A Score 3 response integrates content knowledge (DCI) with at least one SEP or CCC.
- **Misconceptions reduce the score.** A significant scientific misconception drops the response by one score point.

### Suggested Anchoring Phenomena by Grade

**Grade 5 Phenomena:**
- "Scientists studying the Chesapeake Bay noticed that areas with healthy underwater grass beds have more blue crabs and fish than areas without grasses. Why do underwater grasses support more animal life?"
- "Every fall, thousands of monarch butterflies pass through Maryland on their migration south. Scientists observed that monarch populations have declined as milkweed plants have disappeared from Maryland farms. What explains this pattern?"
- "Students visiting Assateague Island noticed that the sand dunes on the ocean side are much taller than the dunes on the bay side. What processes cause this difference?"

**Grade 8 Phenomena:**
- "Scientists monitoring the Chesapeake Bay found that dissolved oxygen levels drop sharply in summer, creating 'dead zones' where fish and crabs cannot survive. What factors contribute to these dead zones, and how do they affect bay organisms?"
- "After Maryland invested in oyster reef restoration in the Choptank River, water clarity improved and underwater grass beds returned within five years. What ecological processes explain this recovery?"
- "Geologists studying Calvert Cliffs found fossil shark teeth, whale bones, and shells from organisms that lived in a tropical sea — even though Maryland's climate today is temperate. What evidence could scientists use to explain how these fossils formed here?"

**Grade 10 Phenomena:**
- "Maryland's Eastern Shore is losing land to rising sea levels at an accelerating rate. Blackwater National Wildlife Refuge has lost over 5,000 acres of marsh since 1938. Analyze the geoscience processes contributing to this change and explain how it creates feedbacks in other Earth systems."
- "Blue crabs in the Chesapeake Bay show wide variation in shell size, growth rate, and salinity tolerance. What evolutionary and environmental factors explain this variation within the population?"

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] Grade verified as 5, 8, or 10 ONLY (not other Maryland grades)
- [ ] PE code is a valid NGSS Performance Expectation
- [ ] Item is three-dimensional: DCI + SEP + CCC all identified
- [ ] Anchoring phenomenon is authentic and Maryland-relevant where possible
- [ ] Stimulus (data table/graph/diagram) has clear labels, units, and realistic data
- [ ] CR prompt directs students to use evidence from the stimulus
- [ ] All distractors represent real misconceptions (not obviously wrong)
- [ ] MS items specify how many answers to select (TWO/THREE)
- [ ] Score 3 anchor response written before finalizing CR item
- [ ] Science content is accurate and reflects current scientific understanding
- [ ] Vocabulary is grade-appropriate for the targeted grade level

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Writing MCAP Science items for Grades 3, 4, 6, or 7 | MCAP Science is only at Grades 5, 8, 10 | Restrict to tested grades |
| DCI-only items (no SEP or CCC) | MCAP requires three-dimensional items | Always embed a practice and crosscutting concept |
| CR prompts without evidence directive | Students may respond without citing data | Include "Use evidence from the [data/graph/diagram]" in all CR prompts |
| Using Grade 11 instead of Grade 10 | Maryland tests Grade 10 for science | Use Grade 10 for high school science items |
| Generic Mid-Atlantic phenomena not anchored to MD | MCAP favors Maryland-specific contexts | Use Chesapeake Bay, Assateague Island, Calvert Cliffs, Baltimore contexts |
| MS items with only 2 options in 4 total | Too easy to guess | Use 5–6 options with exactly 2–3 correct |

## 12. Prompt Patterns

The following patterns reflect the most common MCAP Science item archetypes.

### Pattern 1: Data-to-Conclusion (SR, DOK 2)
> "The [graph / table / diagram] below shows [Maryland science scenario]. Based on the data, which [conclusion / explanation / pattern] is BEST supported?"

### Pattern 2: Phenomenon Explanation (CR, DOK 3)
> "Scientists observed [Maryland-anchored phenomenon]. Using evidence from the [data / model / diagram], construct an explanation for [specific science focus]. Explain the [cause-and-effect / energy flow / pattern] relationship."

### Pattern 3: Model Evaluation (SR or MS, DOK 2–3)
> "A student made a model showing [Maryland science concept]. Which statement BEST describes what the model shows about [DCI focus]? / Select the TWO statements that correctly describe what the model represents."

### Pattern 4: Investigation Design (CR, DOK 3)
> "A scientist in Maryland wants to investigate whether [variable] affects [outcome] in [Maryland ecosystem]. Describe a procedure the scientist could follow. Include what would be measured and how the scientist would know if the variable made a difference."

### Pattern 5: Evidence-Based Argument (CR, DOK 3)
> "Two students disagree about [Maryland science claim]. Student A says [misconception]. Student B says [scientifically accurate claim]. Using evidence from the [data / diagram], explain which student is correct and why."

### Pattern 6: Human Impact and Solutions (MS or CR, DOK 2–3)
> "Human activities have [impacted Maryland environment]. Select the TWO strategies that BEST [monitor / reduce / address] this impact. / Describe TWO effects this has had on [ecosystem/organism]. Then explain ONE method scientists could use to reduce this impact."
