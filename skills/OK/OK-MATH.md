| **Reporting** | Individual Student Report; School, District, State aggregates |

> **OSTP Mathematics:** The Oklahoma School Testing Program measures student mastery of the Oklahoma Academic Standards for Mathematics. Items assess conceptual understanding, procedural fluency, and application in real-world and mathematical contexts.

### Performance Levels

| Level | Label | Description |
|---|---|---|
| 4 | **Advanced** | Thorough understanding; applies mathematics in novel and complex situations; constructs valid mathematical arguments |
| 3 | **Proficient** | Adequate understanding; solves grade-level problems accurately; applies mathematics to real-world contexts |
| 2 | **Limited Knowledge** | Partial understanding; applies procedures in familiar contexts but struggles with novel problems |
| 1 | **Below Basic** | Minimal understanding; significant conceptual and procedural gaps |

## 5. Item Types & Formats

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Real-world or mathematical context                      |
|  Machine scored                                          |
|  DOK 1–3                                                 |
+----------------------------------------------------------+
```

**MC Example (Grade 6, DOK 2, 6.N.4):**

An Oklahoma oil well produces 840 barrels of crude oil in 7 days. At this rate, how many barrels would the well produce in 30 days?

A. 2,520 barrels
B. 3,600 barrels
C. 5,040 barrels
D. 25,200 barrels

*Correct Answer: B (840/7 = 120 barrels per day; 120 x 30 = 3,600)*
*Alignment: 6.N.4 | Number & Operations | DOK 2*

---

**MC Example (Grade 4, DOK 2, 4.GM.2):**

A rectangular section of land claimed during the Oklahoma Land Run measures 160 rods long and 80 rods wide. What is the perimeter of this plot of land?

A. 240 rods
B. 480 rods
C. 12,800 rods
D. 12,800 square rods

*Correct Answer: B*
*Alignment: 4.GM.2 | Geometry & Measurement | DOK 2*

### Constructed Response (CR)

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE — 0–2 points                       |
|                                                          |
|  Show work and explain reasoning                         |
|  Real-world or mathematical context                      |
|  Human scored                                            |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**CR Example (Grade 7, DOK 3, 7.A.2):**

The table below shows tornado reports in central Oklahoma over several years:

| Year | Number of Tornadoes | Property Damage (millions $) |
|---|---|---|
| 2018 | 56 | 112 |
| 2019 | 72 | 180 |
| 2020 | 48 | 96 |

Is there a proportional relationship between the number of tornadoes and property damage? Explain how you know using the data in the table. If it is proportional, write an equation that represents this relationship.

*Scoring:*
- *2 pts: Correctly identifies proportional relationship with valid justification (e.g., constant ratio of $2 million per tornado); writes correct equation (d = 2t or equivalent)*
- *1 pt: Correct identification with incomplete justification, OR correct equation without explanation*
- *0 pts: Incorrect identification or blank*

## 8. Scoring Rubrics

### Constructed Response (CR) Rubric — 0–2 Points

| Score | Criteria |
|---|---|
| 2 | Correct solution with clear mathematical reasoning. Work shown systematically. Explanation demonstrates conceptual understanding. Appropriate mathematical vocabulary used. |
| 1 | Partial understanding with minor errors. Correct approach demonstrated but final answer contains an error. OR Correct answer given without sufficient work or explanation. |
| 0 | Incorrect approach, no understanding shown, or blank. |

### CR Scoring Notes

- **Work must be shown** for full credit on all CR items.
- **Explanations** should reference mathematical concepts, not just describe steps.
- **Computational errors** with correct reasoning earn partial credit (1 point).

## 10. Contextualization — Oklahoma Mathematics

When generating problem contexts, use authentic Oklahoma settings:

### Oklahoma Math Context Guide

| Context | Domain | Grade Band |
|---|---|---|
| Oklahoma oil production (barrels per day, well output) | Ratios, Operations, Data | 4–11 |
| Oklahoma tornado statistics (frequency, damage, speed) | Data Analysis, Statistics | 5–11 |
| OKC population growth and urban development | Statistics, Proportionality, Functions | 5–11 |
| Oklahoma Land Run (acreage, distances, settlers) | Operations, Measurement, Geometry | 3–8 |
| Oklahoma cattle ranching (costs, weights, areas) | Operations, Measurement | 3–7 |
| Oklahoma wind energy production data | Functions, Data Analysis | 6–11 |
| Oklahoma highway distances (I-35, I-40, Route 66) | Ratios, Proportionality | 4–8 |
| Tulsa and OKC economic comparisons | Statistics, Data Analysis | 6–11 |
| Oklahoma wheat farming statistics | Ratios, Fractions, Operations | 3–7 |
| Oklahoma state fair attendance and pricing | Operations, Data Analysis | 3–6 |

### Suggested Problem Contexts by Grade

**Grades 3–5:**
- Counting oil barrels produced from Oklahoma wells over several days
- Measuring the dimensions of a rectangular land plot from the Oklahoma Land Run
- Comparing distances along Route 66 through Oklahoma towns

**Grades 6–8:**
- Analyzing Oklahoma tornado frequency data over 20 years
- Calculating oil production rates and comparing output across Oklahoma counties
- Using proportional reasoning with OKC population growth data

**Grade 11:**
- Modeling Oklahoma wind farm energy output as a function of wind speed
- Analyzing scatter plots of oil prices vs. production volume in Oklahoma
- Using statistical inference with Oklahoma City metropolitan area growth data

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] Oklahoma Academic Standards code is accurate and grade-appropriate
- [ ] MC items have exactly 4 options with one correct answer
- [ ] CR items require work to be shown and reasoning explained
- [ ] CR scored on 0–2 point scale
- [ ] Calculator policy appropriate for grade level
- [ ] Oklahoma real-world context used where appropriate
- [ ] Distractors represent actual student computational or conceptual errors
- [ ] All computations verified before item is finalized
- [ ] DOK level matches actual cognitive demand
- [ ] Grade 11 items reflect high school mathematics complexity

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| CR asking only for a final answer | CR must require explanation | Add "Show your work and explain" |
| Using non-Oklahoma contexts | Misses state contextualization | Use Oklahoma oil, tornadoes, OKC, and Land Run contexts |
| Items testing only rote computation | OSTP targets DOK 2 primarily | Add real-world context to elevate cognitive demand |
| Grade 11 items at middle school level | Underestimates high school expectations | Use algebra, functions, and statistics at HS level |
| Distractors that are obviously wrong | Does not assess real misconceptions | Base distractors on common student errors |

## 12. Prompt Patterns

### Pattern 1: Real-World Application (MC, DOK 2)
> "[Oklahoma context]. [Multi-step problem]. What is [answer]?"

### Pattern 2: Justify and Explain (CR, DOK 3)
> "[Oklahoma scenario]. [Problem]. Show your work and explain how you found your answer."

### Pattern 3: Proportional Reasoning (MC, DOK 2)
> "An Oklahoma [entity] produces/uses [quantity] in [time/unit]. At this rate, how much [quantity] in [different time/unit]?"

### Pattern 4: Data Interpretation (MC, DOK 2)
> "The [table / graph] shows [Oklahoma data context]. Based on the data, which statement is correct?"

### Pattern 5: Multi-Step Problem Solving (CR, DOK 3)
> "[Oklahoma scenario with multiple constraints]. Determine [answer]. Show your work and explain whether your answer is reasonable."

### Pattern 6: Comparison and Reasoning (CR, DOK 3)
> "Two students solved this problem differently. [Method A] and [Method B]. Who is correct? Use mathematics to justify your answer."
