## 2. Standards Framework

> Virginia SOL Mathematics is aligned to the **Virginia Standards of Learning for Mathematics**, organized by content strands that progress from number sense through algebra and data analysis.

### Virginia SOL Mathematics Strands

| Strand | Focus | Grade Emphasis |
|---|---|---|
| **Number and Number Sense** | Place value, fractions, decimals, integers, rational numbers | Primary focus Grades 3–6 |
| **Computation and Estimation** | Operations, fluency, estimation strategies | Grades 3–7 |
| **Measurement and Geometry** | Units, area, volume, angles, transformations, coordinate geometry | All grades |
| **Probability, Statistics, and Patterns** | Data analysis, probability, algebraic thinking | All grades; increases Grades 6–8 |
| **Patterns, Functions, and Algebra** | Expressions, equations, inequalities, functions | Grades 5–8 and EOC |

## 5. Item Types & Formats

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Real-world or mathematical context                      |
|  Machine scored                                          |
|  DOK 1–3                                                 |
+----------------------------------------------------------+
```

**MC Example (Grade 6, DOK 2, SOL.Math6.6):**

A Virginia farmer grows apples in the Shenandoah Valley. The table shows the number of bushels harvested over four years.

| Year | Bushels |
|---|---|
| 2020 | 1,200 |
| 2021 | 1,350 |
| 2022 | 1,500 |
| 2023 | 1,650 |

If the pattern continues, how many bushels should the farmer expect to harvest in 2024?

A. 1,700
B. 1,800
C. 1,900
D. 2,000

*Correct Answer: B*
*Alignment: SOL.Math6.6 | DOK 2*

### Technology Enhanced Item (TEI)

```
+----------------------------------------------------------+
|  TECHNOLOGY ENHANCED ITEM — 1–2 points                   |
|                                                          |
|  Fill-in / numeric entry, drag-and-drop, multi-select,   |
|  graphing, or equation builder format                    |
|  Machine scored                                          |
|  DOK 1–3                                                 |
+----------------------------------------------------------+
```

**TEI Example (Grade 8, DOK 2, SOL.Math8.16 — Fill-In):**

A student recorded the elevation (in feet) and average July temperature (in F) for six locations along the Shenandoah Valley. The data are plotted on a scatterplot.

Based on the scatterplot, what is the approximate elevation at which the average July temperature is 72 F?

Enter your answer: _____ feet

*Alignment: SOL.Math8.16 | DOK 2*

## 7. Mathematical Representations

Virginia SOL Mathematics items frequently require students to move between multiple representations.

### Representation Types

| Representation | Description | Common Item Use |
|---|---|---|
| **Tabular** | Input/output table; data table | Identify patterns; find missing values |
| **Graphical** | Coordinate plane; bar/line graph; scatterplot | Identify slope; read data; compare quantities |
| **Algebraic** | Equations; inequalities; expressions | Solve; write; simplify |
| **Verbal** | Word problem; real-world scenario | Apply to Virginia context |
| **Visual/Geometric** | Diagrams; figures with measurements | Compute area/volume; apply transformations |

### Representation Connections by Grade Band

| Grade Band | Frequent Connections |
|---|---|
| 3–5 | Number line ↔ fraction; table ↔ equation; model ↔ computation |
| 6–7 | Table ↔ equation ↔ graph; ratio ↔ percent ↔ fraction |
| 8/EOC | Equation ↔ graph ↔ table; scatterplot ↔ linear equation; geometric diagram ↔ algebraic equation |

## 8. Scoring Rubrics

### Multiple Choice (MC) — 1 Point

| Score | Criteria |
|---|---|
| 1 | Student selects the correct answer |
| 0 | Student selects an incorrect answer or leaves blank |

### Technology Enhanced Item (TEI) Rubric — 1–2 Points

| Score | Criteria |
|---|---|
| 2 | Response is fully correct (all components accurate — numeric entry, drag-and-drop placement, or graph placement) |
| 1 | Response is partially correct (correct approach with minor error, or at least one component correct in multi-part TEI) |
| 0 | Response is incorrect, incomplete, or blank |

## 10. Contextualization — Virginia Mathematics

When generating math problem contexts, use authentic Virginia settings:

### Virginia Math Context Guide

| Context | Domain | Grade Band |
|---|---|---|
| Chesapeake Bay data (crab population, water levels, salinity) | Data Analysis, Proportionality | 5–8 |
| Shenandoah Valley elevation profiles | Measurement, Data Analysis | 5–8 |
| Virginia highway distances (I-64, I-81, I-95 routes) | Rate, Proportionality, Operations | 4–8 |
| Virginia apple orchards / agricultural yields | Operations, Fractions, Ratio | 3–7 |
| Virginia Beach tourism and revenue data | Data Analysis, Financial Literacy | 6–8 |
| Richmond historic building dimensions | Geometry, Measurement | 4–7 |
| Blue Ridge Parkway mileage and elevation | Rate, Measurement | 5–8 |
| Virginia school fundraiser budgets | Operations, Financial Literacy | 3–6 |
| Chesapeake Bay Bridge-Tunnel dimensions | Measurement, Geometry | 4–7 |
| Virginia state park acreage and visitor data | Data Analysis, Operations | 4–8 |

### Suggested Problem Contexts by Grade Band

**Grades 3–4:**
- A student counts bushels of apples from a Shenandoah Valley orchard and divides them equally among crates
- A class plans a field trip along a Virginia highway and calculates total distance
- A table shows the number of visitors to a Virginia state park each month

**Grades 5–6:**
- Chesapeake Bay water salinity data used to calculate mean, median, and range
- A proportional relationship between distance and time along I-81
- A student tracks elevation changes along the Blue Ridge Parkway

**Grades 7–8:**
- Scatterplot of Shenandoah Valley elevation vs. temperature data; line of best fit
- Virginia highway tolls used for rate comparison and unit rate problems
- Chesapeake Bay crab harvest data analyzed for linear and proportional relationships

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] SOL code is accurate and grade-appropriate
- [ ] Calculator policy followed for the target grade (no calculator Gr 3–5)
- [ ] Real-world context is relevant to Virginia students
- [ ] MC distractors represent actual student errors (not trivially wrong)
- [ ] TEI item uses technology meaningfully (not a disguised MC)
- [ ] DOK level matches the cognitive demand of the problem
- [ ] All computations verified before item is finalized
- [ ] Problems do not rely on specialized knowledge beyond Virginia SOL
- [ ] Answer choices are in logical order (ascending/descending for numeric)
- [ ] Units and labels are consistent throughout the item

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Calculator use at Grade 3–5 | Virginia SOL Gr 3–5 has no calculator | Design problems solvable by hand |
| MCQ distractors that are obviously wrong | Distractors must represent real student errors | Use common computation or conceptual errors |
| TEI items that are trivially simple | TEI should leverage technology meaningfully | Use multi-step or multi-component formats |
| DOK 1 items that only require recall | SOL aims for mostly DOK 2 | Embed problems in real-world context |
| Over-complex word problems at Grades 3–4 | Reading demand should not exceed grade-level ELA | Keep problem setup brief at lower grades |
| Using CCSS codes instead of SOL codes | Virginia uses SOL, not CCSS | Reference Virginia SOL codes exclusively |

## 12. Prompt Patterns

### Pattern 1: Real-World Multi-Step (MC or TEI, DOK 2)
> "[Virginia context — Chesapeake Bay, Shenandoah, highways]. [Specific mathematical question]. What is [quantity]?"

### Pattern 2: Representation Connection (MC, DOK 2)
> "A student created a [table / graph / equation] to represent [relationship]. Which [other representation / statement] represents the SAME relationship?"

### Pattern 3: Data Interpretation (MC or TEI, DOK 2–3)
> "The [table / graph / scatterplot] shows [Virginia data context]. Based on the data, [what is the rate of change / which conclusion / what prediction] is BEST supported?"

### Pattern 4: Geometry Application (MC or TEI, DOK 2)
> "[Virginia landmark or construction context]. What is the [area / volume / perimeter / surface area] of [figure]?"

### Pattern 5: Proportional Reasoning (MC, DOK 2)
> "[Virginia context — distance, recipe, agriculture]. If [proportional setup], then what is [unknown quantity]?"

### Pattern 6: Pattern and Function (MC or TEI, DOK 2–3)
> "The [table / sequence] shows [Virginia data pattern]. If the pattern continues, what will [value at position n] be?"
