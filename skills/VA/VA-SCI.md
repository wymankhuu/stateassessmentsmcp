## 2. Standards Framework

> Virginia SOL Science is aligned to the **Virginia Standards of Learning for Science**. Virginia uses its own state science standards (not NGSS). The SOL Science standards emphasize scientific investigation, reasoning, and logic alongside content knowledge.

### Scientific Investigation SOL (Applicable to All Grades)

| SOL Code | Description |
|---|---|
| SOL.Sci.Process.1 | Plan and conduct investigations; formulate testable questions and hypotheses |
| SOL.Sci.Process.2 | Collect, record, analyze, and interpret data; use appropriate tools and SI units |
| SOL.Sci.Process.3 | Use evidence to construct explanations and draw conclusions |
| SOL.Sci.Process.4 | Communicate scientific information clearly and accurately |
| SOL.Sci.Process.5 | Evaluate the quality of scientific investigations and the validity of conclusions |

## 5. Item Types & Formats

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Scenario-based or data-based stimulus                   |
|  May include diagrams, data tables, graphs               |
|  Machine scored                                          |
|  DOK 1–3                                                 |
+----------------------------------------------------------+
```

**MC Example (Grade 5, DOK 2, SOL.Sci5.9 — Chesapeake Bay Ecology):**

*[Diagram shows a food web in the Chesapeake Bay: Sunlight -> Phytoplankton -> Blue Crabs -> Striped Bass -> Osprey]*

Based on the food web, what would MOST LIKELY happen to the striped bass population if the blue crab population decreased significantly?

A. The striped bass population would increase because there would be less competition
B. The striped bass population would decrease because they would have less food available
C. The striped bass population would not change because they could eat phytoplankton instead
D. The striped bass population would move to a different part of the Chesapeake Bay

*Correct Answer: B*
*Alignment: SOL.Sci5.9 | DOK 2*

---

**MC Example (Grade 8, DOK 2, SOL.Sci8.5 — Shenandoah Geology):**

A geologist studying rock formations in the Shenandoah Valley discovers a layer of limestone containing fossils of ancient marine organisms. Which conclusion is BEST supported by this evidence?

A. The Shenandoah Valley was once covered by volcanic activity
B. The area where the fossils were found was once covered by a shallow sea
C. The fossils were carried to the valley by glaciers during the last ice age
D. Marine organisms migrated to the Shenandoah Valley through underground rivers

*Correct Answer: B*
*Alignment: SOL.Sci8.5 | DOK 2*

```
+----------------------------------------------------------+

|                                                          |
```

**TEI Example (Grade 5, DOK 2, SOL.Sci5.5 — Multi-Select):**

A student heats a piece of iron wool over a flame. The iron wool glows red and a black residue forms. Select the TWO observations that provide evidence a chemical change occurred.

A. The iron wool changed shape when heated
B. A new substance (black residue) with different properties formed
C. The temperature of the iron wool increased during the process
D. The iron wool could not be returned to its original form after heating
E. The iron wool was held over the flame for three minutes

*Correct Answers: B, D*
*Alignment: SOL.Sci5.5 | DOK 2*

## 7. Scientific Investigation Design

Virginia SOL Science emphasizes students' ability to design and evaluate scientific investigations. Investigation skills are embedded throughout the test.

### Investigation Design Components

| Component | Description | SOL Alignment |
|---|---|---|
| **Hypothesis** | Testable prediction about the relationship between variables | SOL.Sci.Process.1 |
| **Independent Variable** | The variable the scientist changes | SOL.Sci.Process.1 |
| **Dependent Variable** | The variable being measured or observed | SOL.Sci.Process.2 |
| **Control Group** | Condition held constant for comparison | SOL.Sci.Process.1 |
| **Controlled Variables** | All other factors kept the same | SOL.Sci.Process.1 |
| **Data Collection** | Measurement using SI units; appropriate tools and techniques | SOL.Sci.Process.2 |
| **Conclusion** | Inference drawn from data; connection back to hypothesis | SOL.Sci.Process.3 |

### Investigation Item Structure

```
+------------------------------------------------------------------+
|  INVESTIGATION DESIGN ITEM (MC or TEI)                            |
|                                                                   |
|  SCENARIO: A Virginia student investigates whether [variable]     |
|  affects [outcome] in a [Virginia-relevant setting].              |
|                                                                   |
|  STEM (MC): Which experimental setup would BEST allow the         |
|  student to test this hypothesis?                                 |
|  — OR —                                                           |
|  STEM (TEI): Drag the labels to correctly identify the            |
|  independent, dependent, and controlled variables.                |
+------------------------------------------------------------------+
```

| Score | Criteria |
|---|---|

| 1 | Response is partially correct; at least one component accurately completed |

## 10. Contextualization — Virginia Science

When generating science items, prioritize authentic Virginia natural settings and phenomena:

### Virginia Science Context Guide

| Setting / Phenomenon | Grade | Science Domain | SOL Alignment |
|---|---|---|---|
| Chesapeake Bay ecology (blue crabs, oysters, seagrass, food webs) | 5, 8 | Life Science | SOL.Sci5.8, SOL.Sci5.9, SOL.Sci8.9 |
| Shenandoah Valley geology (limestone caves, karst topography, fossils) | 5, 8 | Earth Science | SOL.Sci5.6, SOL.Sci8.5 |
| Virginia coal mining regions (Appalachian plateau, environmental impact) | 8, EOC | Earth/Physical Science | SOL.Sci8.4, SOL.Sci8.5 |
| VA coastal ecosystems (barrier islands, salt marshes, erosion) | 5, 8 | Life/Earth Science | SOL.Sci5.4, SOL.Sci5.8 |
| Virginia Piedmont (geology, soil, weathering, erosion) | 5, 8 | Earth Science | SOL.Sci5.6, SOL.Sci8.5 |
| Blue Ridge Mountains weather patterns | 5, 8 | Earth Science | SOL.Sci5.7, SOL.Sci8.4 |
| James River / Rappahannock River ecosystems | 5, 8 | Life/Earth Science | SOL.Sci5.8, SOL.Sci8.9 |
| Virginia Dismal Swamp ecology | 5, 8 | Life Science | SOL.Sci5.8, SOL.Sci5.9 |
| Virginia mineral resources (quartz, granite, coal) | 8 | Earth Science | SOL.Sci8.5 |
| Chesapeake Bay water quality and agricultural runoff | 5, 8 | Earth/Life Science | SOL.Sci5.4, SOL.Sci8.4 |

### Suggested Anchoring Phenomena by Grade

**Grade 5 Phenomena:**
- "Scientists monitoring the Chesapeake Bay noticed that blue crab populations have declined as water temperatures increased. What might explain this change in the ecosystem?"
- "After a heavy rainstorm, students at a Virginia Beach school noticed that the creek near their school was muddy and brown. What process caused this change?"
- "A Virginia farmer noticed that after adding compost to the soil, the plants in the garden grew taller. What scientific question could the farmer investigate?"

**Grade 8 Phenomena:**
- "Geologists studying the Shenandoah Valley discovered caves formed in limestone rock. What chemical and physical processes could explain how these caves formed over time?"
- "Scientists found that certain Virginia coal mining areas have streams with very low pH levels. What evidence connects mining activity to this change in water chemistry?"
- "A student collecting rocks in the Virginia Piedmont found both igneous and sedimentary rocks in the same area. What geological processes might explain this?"

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] Grade verified as 5, 8, or EOC ONLY (not other Virginia grades)
- [ ] SOL code is accurate and grade-appropriate
- [ ] Stimulus (data table/graph/diagram) clearly labeled with units
- [ ] TEI items use technology meaningfully (multi-select, drag-and-drop, labeling)
- [ ] All distractors represent real misconceptions (not obviously wrong)
- [ ] Investigation design items clearly identify variables
- [ ] Science content is accurate and reflects current scientific understanding
- [ ] Virginia context incorporated where possible (Chesapeake Bay, Shenandoah, coal mining)
- [ ] DOK level matches the cognitive demand
- [ ] Vocabulary is grade-appropriate for the targeted grade level

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Writing SOL science items for Grades 3, 4, 6, or 7 | SOL Science only at Grades 5, 8, EOC | Restrict to tested grades |
| Using NGSS codes instead of Virginia SOL codes | Virginia uses its own SOL Science standards | Reference Virginia SOL codes exclusively |
| TEI items that function as basic MC | TEI should use technology meaningfully | Use multi-select, drag-and-drop, or labeling |
| Items assessing factual recall only | SOL Science is ~55–60% DOK 2 | Elevate items with scenarios and data |
| Generic phenomena not anchored to Virginia | SOL favors Virginia-specific contexts | Use Chesapeake Bay, Shenandoah, coal mining, coastal settings |
| MC with two clearly correct options | Creates ambiguity | Review all distractors carefully; only one clearly correct |

## 12. Prompt Patterns

### Pattern 1: Data-to-Conclusion (MC, DOK 2)
> "The [table / graph / diagram] below shows [Virginia science scenario]. Based on the data, which [conclusion / explanation / prediction] is BEST supported?"

### Pattern 2: Cause and Effect (MC, DOK 2)
> "A student [observed / measured / recorded] that [Virginia phenomenon]. Which explanation BEST describes why this [occurred / changed]?"

### Pattern 3: Investigation Design (MC or TEI, DOK 2–3)
> "[Virginia student] wants to investigate whether [variable] affects [outcome] in [Virginia setting]. Which experimental design would BEST test this? / What is the [dependent / independent / controlled] variable?"

### Pattern 4: Food Web / Ecosystem Change (MC or TEI, DOK 2–3)
> "[Virginia ecosystem — Chesapeake Bay / Shenandoah / coastal] diagram shows [food web]. If [organism / factor] were removed or changed, what would MOST LIKELY happen to [other organism / population]?"

### Pattern 5: Geological Process (MC, DOK 2)
> "A geologist studying [Virginia region] discovered [geological feature / rock type / fossil]. Which [process / explanation] BEST accounts for this observation?"

### Pattern 6: Evidence-Based Multi-Select (TEI, DOK 2–3)
> "Select the TWO observations that provide the BEST evidence that [Virginia science phenomenon] occurred."
