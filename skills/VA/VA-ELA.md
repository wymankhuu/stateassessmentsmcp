## 1. Overview

| Field | Detail |
|---|---|
| **Assessment Name** | Virginia Standards of Learning (SOL) — English: Reading, Writing, and Communication |
| **Administering Agency** | Virginia Department of Education (VA DOE) |
| **Vendor** | Virginia DOE (developed in-house) |
| **Grades Tested** | 3, 4, 5, 6, 7, 8; EOC (End-of-Course Reading and Writing) |
| **Testing Window** | May – June (primary window) |
| **Delivery** | Computer-based; paper accommodations available |
| **Standards** | Virginia Standards of Learning (SOL) — English |
| **Score Scale** | Scaled score; 4 performance levels |
| **Reporting** | Individual Student Report; School, Division, State aggregates |

> **SOL ELA Structure:** The Virginia SOL ELA assessment is primarily multiple-choice (MC) and technology-enhanced items (TEI). Reading comprehension items are passage-based, and writing items assess conventions, usage, and composition skills. The test is designed to be straightforward and efficient, emphasizing direct measurement of the Virginia SOL standards.

### Performance Levels

| Level | Label | Description |
|---|---|---|
| 4 | **Advanced** | Demonstrates superior mastery of Virginia SOL content; applies skills in complex and sophisticated ways |
| 3 | **Proficient** | Demonstrates solid understanding of grade-level SOL content; meets the standard for academic achievement |
| 2 | **Below Proficient** | Demonstrates partial understanding of SOL content; approaching but not yet meeting the proficiency standard |
| 1 | **Fail** | Demonstrates minimal understanding of SOL content; significant gaps in mastery of grade-level standards |

> **Item-writing target:** "Proficient" performance. Items should require genuine application of SOL standards at the expected cognitive level — not mere recall.

## 2. Standards Framework

> Virginia SOL ELA is aligned to the **Virginia Standards of Learning for English**, organized by communication and multimodal literacies, reading, writing, and research strands.

### Virginia SOL ELA Strands

| Strand | Focus | Grade Emphasis |
|---|---|---|
| **Communication and Multimodal Literacies** | Speaking, listening, media literacy | Integrated throughout |
| **Reading** | Literary and informational text comprehension; vocabulary; analysis | Primary assessment focus |
| **Writing** | Composition; conventions; editing; revision | Integrated through writing items and extended tasks |
| **Research** | Information gathering; source evaluation; synthesis | Grades 6–8 especially |

| SOL.ELA5.5 | Summarize what is read; draw conclusions and make inferences using textual evidence | 5 | 2–3 |
| SOL.ELA6.5 | Compare and contrast details and themes across two passages | 6 | 3 |
| SOL.ELA7.5 | Analyze the development of theme, characterization, and plot in literary texts | 7 | 3 |
| SOL.ELA8.5 | Analyze how authors use rhetoric, style, and literary devices to achieve their purposes | 8 | 3 |

## 3. Test Structure

Virginia SOL ELA is a single-session, computer-based assessment. The test is primarily MC with TEI items interspersed. Items are passage-based for reading comprehension.

```
+------------------------------------------------------------------+
|            VIRGINIA SOL ELA STRUCTURE (Grades 3–8)                |
+------------------------------------------------------------------+
|  SINGLE SESSION — Timed (varies by grade)                        |
|  Computer-Based                                                   |
|                                                                   |
|  SECTION 1: READING COMPREHENSION                                 |
|  ┌────────────────────────────────────────┐                      |
|  │ Passage 1 (Literary) → 4–6 MC items   │                      |
|  │ Passage 2 (Literary) → 4–6 MC items   │                      |
|  │ Passage 3 (Informational) → 4–6 MC    │                      |
|  │ Passage 4 (Informational) → 4–6 MC    │                      |
|  │ Technology Enhanced items interspersed │                      |
|  └────────────────────────────────────────┘                      |
|                                                                   |
|  SECTION 2: WRITING / EDITING                                     |
|  ┌────────────────────────────────────────┐                      |
|  │ Usage and mechanics items → 6–10 MC   │                      |
|  │ Editing passages → MC-based           │                      |
|  └────────────────────────────────────────┘                      |
+------------------------------------------------------------------+
```

## 5. Item Types & Formats

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |
|  4 options (A, B, C, D) — standard for Virginia SOL      |
|  Always tied to a passage/stimulus                       |
|  May include line-number references                      |
|  Machine scored                                          |
|  DOK 1–3                                                 |
+----------------------------------------------------------+
```

**MC Example (Grade 7 Literary, DOK 3, SOL.ELA7.5):**

*[After reading a short story set along the Shenandoah Valley about a young girl discovering her family's farming traditions]*

Read this sentence from paragraph 5: *"The mountains held their silence like old men guarding a secret, their ridgelines etched against the fading sky."*

What effect does the author's use of personification in this sentence create?

A. It suggests that the mountains are dangerous and should be avoided
B. It creates a sense of mystery and timelessness in the setting
C. It shows that the narrator is frightened of the natural landscape
D. It implies that the story takes place during a storm

*Correct Answer: B*
*Alignment: SOL.ELA7.5 | DOK 3*

---

**MC Example (Grade 5 Informational, DOK 2, SOL.ELA5.5):**

*[After reading an article about the history of Jamestown, Virginia's first permanent English settlement]*

Based on the article, what was the MAIN reason the Jamestown colonists struggled during their first winter?

A. They were unable to communicate with the Powhatan people
B. They lacked the farming skills and supplies needed to survive in an unfamiliar environment
C. The colonists chose to return to England before spring arrived
D. The weather in Virginia was much colder than in any part of England

*Correct Answer: B*
*Alignment: SOL.ELA5.5 | DOK 2*

```
+----------------------------------------------------------+
|  TECHNOLOGY ENHANCED ITEM — 1–2 points                   |
|                                                          |
|  Drag-and-drop, drop-down menu, highlighting,           |
|  or multi-select format                                  |
|  Passage-based                                           |
|  Machine scored                                          |
|  DOK 2–3                                                 |

```

**TEI Example (Grade 6, DOK 2, SOL.ELA6.5 — Drag-and-Drop):**

*[After reading two passages about Virginia Beach — one literary, one informational]*

Drag each detail to the correct column to show whether it appears in Passage 1 (Literary), Passage 2 (Informational), or Both Passages.

[Details: "describes the sound of ocean waves," "provides statistics about tourism," "mentions the lighthouse," "uses descriptive language about sunsets"]

## 8. Scoring Rubrics

### Multiple Choice (MC) — 1 Point

| Score | Criteria |
|---|---|
| 1 | Student selects the correct answer from four options |
| 0 | Student selects an incorrect answer or leaves blank |

### Technology Enhanced Item (TEI) Rubric — 1–2 Points

| Score | Criteria |
|---|---|
| 2 | All components of the response are correct (drag-and-drop, multi-select, or drop-down fully accurate) |
| 1 | Response is partially correct; at least one component accurately completed |
| 0 | Response is incorrect or blank |

## 10. Contextualization — Virginia ELA

When generating passages and prompts, prioritize authentic Virginia settings, history, and culture:

### Virginia Context Guide

| Context | Passage Type | Grade Band |
|---|---|---|
| Jamestown / colonial Virginia history | Literary fiction or Informational | 3–6 |
| Shenandoah Valley landscapes and farming | Literary or Informational | 3–8 |
| Virginia Beach / Chesapeake Bay shoreline | Informational or Literary | 4–8 |
| Richmond history and landmarks | Informational | 5–8 |
| Civil War battlefields (Manassas, Fredericksburg, Appomattox) | Informational or Historical fiction | 5–8 |
| Virginia agriculture (tobacco, peanuts, apples, vineyards) | Informational | 3–7 |
| Blue Ridge Parkway / Appalachian Trail | Literary or Informational | 4–8 |
| Virginia authors (Rita Dove, Earl Hamner Jr., Tom Wolfe) | Literary text or excerpt | 6–8 |
| Chesapeake Bay wildlife (blue crabs, oysters, herons) | Informational | 3–6 |
| Virginia tech innovation / NASA Langley | Informational | 6–8 |

### Suggested Passage Topics by Grade Band

**Grades 3–4:**
- A student discovers the history of Jamestown on a school field trip
- A family explores the Shenandoah Valley during apple harvest season
- An informational article about Virginia's state symbols and natural resources

**Grades 5–6:**
- Historical fiction set during colonial Virginia
- An article about the ecology of the Chesapeake Bay and conservation efforts
- A narrative about growing up on a Virginia farm near the Blue Ridge Mountains

**Grades 7–8:**
- Literary fiction exploring life in Richmond's historic neighborhoods
- Paired informational texts about Virginia Civil War battlefields and their preservation
- An argumentative essay about coastal erosion at Virginia Beach

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] SOL code verified as correct for the targeted grade
- [ ] MC items directly tied to the passage (not general knowledge questions)
- [ ] TEI items use appropriate technology-enhanced format (drag-and-drop, multi-select, drop-down)
- [ ] Distractors represent authentic misconceptions, not obviously wrong answers
- [ ] Lexile of passage matches the grade-level range
- [ ] Passage length appropriate (400–1,000 words for comprehension passages)
- [ ] Virginia context incorporated where appropriate (geography, history, culture)
- [ ] Writing/editing items reference a specific sentence or phrase in context
- [ ] All four answer choices are plausible and similar in length
- [ ] DOK level matches the cognitive demand of the item

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Items not tied to a passage | Virginia SOL ELA is passage-based — all reading items must be passage-dependent | Always tie MC and TEI items to a specific stimulus passage |
| TEI items that function as basic MC | TEI should use technology features meaningfully | Use drag-and-drop, highlighting, or multi-select that requires multi-step reasoning |
| Distractors that are obviously wrong | Reduces item quality and discrimination | Each distractor must represent a plausible misreading or misconception |
| Using CCSS codes instead of SOL codes | Virginia uses its own SOL standards, not Common Core | Reference Virginia SOL codes exclusively |
| Passages with no Virginia connection | Missed opportunity for state context | Use Virginia settings, history, geography, or culture where appropriate |
| Writing items testing isolated grammar rules without context | SOL writing items use passage/draft context | Embed grammar items in student-written draft passages |

## 12. Prompt Patterns

### Pattern 1: Author's Craft and Language (MC, DOK 3)
> "Read [line reference / paragraph reference]. What effect does the author's use of [figurative language / imagery / word choice / structure] create in this [sentence / paragraph / passage]?"

### Pattern 2: Inference and Evidence (MC, DOK 2)
> "Based on [paragraph # / the passage], what can the reader infer about [character / author's purpose / main idea]?"

### Pattern 3: Author's Purpose / Central Idea (MC, DOK 2)
> "What is the author's MAIN [purpose / central idea] in this [article / passage]?"

### Pattern 4: Vocabulary in Context (MC, DOK 1–2)
> "Read this sentence from paragraph [#]: '[sentence with target word].' What does the word [target word] MOST LIKELY mean as used in this sentence?"

### Pattern 5: Compare and Contrast (TEI or MC, DOK 3)
> "Based on both passages, [drag each detail / select ALL statements] that describe a similarity between the two passages."

### Pattern 6: Text Structure and Features (MC, DOK 2)
> "How does the author organize the information in this article? / What is the MAIN purpose of [text feature — heading, diagram, sidebar]?"

### Pattern 7: Writing Conventions (MC, DOK 1–2)
> "Which revision BEST corrects the error in the underlined sentence?"
> "What change, if any, should be made in sentence [#]?"
