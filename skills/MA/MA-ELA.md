# MCAS — ELA (English Language Arts)
## AssessmentForge Skill Guide | Grades 3–8, 10

---

## 1. Overview

| Field | Detail |
|---|---|
| **Assessment Name** | MCAS (Massachusetts Comprehensive Assessment System) — English Language Arts |
| **Administering Agency** | Massachusetts Department of Elementary and Secondary Education (DESE) |
| **Vendor** | Cognia (formerly Measured Progress / Questar) |
| **Grades Tested** | 3, 4, 5, 6, 7, 8, 10 |
| **Testing Window** | March–May (Grade 10 in March; Grades 3–8 in April–May) |
| **Delivery** | Computer-based (CBT) for most; paper accommodations available |
| **Standards** | Massachusetts Curriculum Frameworks for English Language Arts and Literacy (2017) |
| **Score Scale** | Scale score; 4 performance levels |
| **High Stakes** | Grade 10 MCAS ELA is a graduation requirement (Competency Determination) |
| **Reporting** | Individual Student Report; School, District, State aggregates |

> **MCAS** is one of the most rigorous state assessments in the nation. Massachusetts has consistently set high standards through its own Curriculum Frameworks, which predate and exceed CCSS in several areas. The 2017 Frameworks incorporate elements of CCSS while maintaining Massachusetts-specific expectations. Grade 10 MCAS ELA is a **graduation requirement** — students must achieve at least "Meeting Expectations" or qualify through an appeals process.

### Performance Levels

| Level | Label | Description |
|---|---|---|
| 1 | **Not Meeting Expectations** | Student does not demonstrate understanding of grade-level ELA standards; significant intervention needed |
| 2 | **Partially Meeting Expectations** | Student demonstrates partial understanding; approaching grade-level expectations with additional support |
| 3 | **Meeting Expectations** | Student demonstrates grade-level proficiency in ELA standards |
| 4 | **Exceeding Expectations** | Student demonstrates advanced, sophisticated understanding beyond grade-level expectations |

> **Item-writing target:** "Meeting Expectations" performance. Items should require genuine application of the Massachusetts Curriculum Frameworks at the expected DOK level — Massachusetts demands analytical rigor.

## 2. Standards Framework

> MCAS ELA is aligned to the **2017 Massachusetts Curriculum Frameworks for English Language Arts and Literacy**. These frameworks build on CCSS but include Massachusetts-specific enhancements in vocabulary acquisition, literary analysis, and writing expectations. Standard codes use the format MA.ELA-Literacy.[Strand].[Grade].[Standard].

### Framework Strands

| Strand | Focus | Grade Emphasis |
|---|---|---|
| **Reading Literature (RL)** | Fiction, poetry, drama; theme, structure, craft, point of view | All grades |
| **Reading Informational (RI)** | Nonfiction comprehension; central idea, argument, evidence, text structure | All grades |
| **Writing (W)** | Narrative, informational, argumentative composition; research, writing process | All grades; assessed through Essay |
| **Language (L)** | Grammar, conventions, vocabulary acquisition, word analysis | All grades; assessed in selected-response items |

### Key Standards by Grade Band

| Standard Code | Description | Grade Band | DOK |
|---|---|---|---|
| MA.ELA-Literacy.RL.3.2 | Recount stories and determine the central message, lesson, or moral | 3 | 2 |
| MA.ELA-Literacy.RL.4.3 | Describe in depth a character, setting, or event using specific details | 4 | 2–3 |
| MA.ELA-Literacy.RI.5.8 | Explain how an author uses reasons and evidence to support points in a text | 5 | 3 |
| MA.ELA-Literacy.RL.6.5 | Analyze how a particular sentence, chapter, scene, or stanza fits into the overall structure | 6 | 3 |
| MA.ELA-Literacy.RI.7.6 | Determine an author's point of view or purpose and analyze how the author distinguishes it from others | 7 | 3 |
| MA.ELA-Literacy.RL.8.4 | Determine the meaning of words and phrases including figurative and connotative meanings; analyze impact of word choices | 8 | 2–3 |
| MA.ELA-Literacy.RL.10.3 | Analyze how complex characters develop over the course of a text, interact with other characters, and advance the plot or develop the theme | 10 | 3 |
| MA.ELA-Literacy.RI.10.6 | Determine an author's point of view or purpose and analyze how an author uses rhetoric | 10 | 3 |

### Key Writing and Language Standards

| Standard Code | Description | DOK |
|---|---|---|
| MA.ELA-Literacy.W.4.3 | Write narratives to develop real or imagined experiences | 3–4 |
| MA.ELA-Literacy.W.7.1 | Write arguments to support claims with clear reasons and relevant evidence | 3–4 |
| MA.ELA-Literacy.W.10.2 | Write informative/explanatory texts to examine and convey complex ideas | 3–4 |
| MA.ELA-Literacy.L.5.4 | Determine or clarify the meaning of unknown and multiple-meaning words and phrases | 2 |
| MA.ELA-Literacy.L.8.1 | Demonstrate command of the conventions of standard English grammar and usage | 1–2 |

## 3. Test Structure

MCAS ELA is administered across **two sessions** over two days. Session 1 focuses on Reading Comprehension; Session 2 includes the Essay (writing composition).

```
+------------------------------------------------------------------+
|            MCAS ELA STRUCTURE (Grades 3–8, 10)                    |
+------------------------------------------------------------------+
|  SESSION 1: READING COMPREHENSION                                 |
|  ┌────────────────────────────────────────┐                       |
|  │ Passage Set 1 (Literary) → MC, SR      │                       |
|  │ Passage Set 2 (Informational) → MC, SR │                       |
|  │ Passage Set 3 (Literary or Paired)     │                       |
|  │   → MC, SR                             │                       |
|  │ Passage Set 4 (Informational) → MC, SR │                       |
|  └────────────────────────────────────────┘                       |
|                                                                    |
|  SESSION 2: WRITING / ESSAY                                        |
|  ┌────────────────────────────────────────┐                       |
|  │ 1 Essay prompt (passage-based for      │                       |
|  │ Grades 3–8; may be stand-alone for     │                       |
|  │ Grade 10)                              │                       |
|  │ Essay type: Narrative (3–4),           │                       |
|  │   Informational (5–6), Argumentative   │                       |
|  │   (7–8, 10)                            │                       |
|  └────────────────────────────────────────┘                       |
+------------------------------------------------------------------+
```

## 5. Item Types & Formats

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE (MC) — 1 point                          |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Single correct answer                                   |
|  Passage-based (tied to stimulus text)                   |
|  Machine scored                                          |
|  DOK 1–3                                                 |
+----------------------------------------------------------+
```

**MC Example (Grade 5 Literary, DOK 2, MA.ELA-Literacy.RL.5.2):**

*[After reading a story about a child exploring Plymouth Rock and learning about the Pilgrims]*

Which statement BEST describes the theme of this story?

A. Historical places are always interesting to visit
B. Understanding the past helps us appreciate what we have today
C. Plymouth is the most important town in Massachusetts
D. Children learn best when they travel with their families

*Correct Answer: B*
*Alignment: MA.ELA-Literacy.RL.5.2 | DOK 2*

---

**MC Example (Grade 8 Informational, DOK 2, MA.ELA-Literacy.RI.8.6):**

*[After reading an article about the history of Boston's role in the American Revolution]*

How does the author MAINLY develop the central idea that Boston was essential to the success of the American Revolution?

A. By listing every battle that took place in Boston
B. By presenting first-person accounts alongside historical analysis to show how events in Boston inspired the wider movement
C. By comparing Boston to Philadelphia and arguing Boston was more important
D. By describing the geography of Boston Harbor in detail

*Correct Answer: B*
*Alignment: MA.ELA-Literacy.RI.8.6 | DOK 2*

### Short Response (SR)

```
+----------------------------------------------------------+
|  SHORT RESPONSE (SR) — 0–2 points                        |
|                                                          |
|  Brief written response (3–5 sentences)                  |
|  Must reference the text with specific evidence           |
|  Human scored using SR rubric                            |
|  DOK 2–3                                                 |
|  Session 1                                               |
+----------------------------------------------------------+
```

**SR Example (Grade 6 Literary, DOK 3, MA.ELA-Literacy.RL.6.5):**

*[After reading a short story set on Cape Cod during a Nor'easter]*

How does the author use the storm as a structural element in this story? Use specific details from the text to support your answer.

---

**SR Example (Grade 10 Informational, DOK 3, MA.ELA-Literacy.RI.10.6):**

*[After reading an excerpt from Thoreau's "Walden"]*

How does Thoreau's use of imagery from the natural world support his central argument about the value of simple living? Use two pieces of evidence from the text.

### Essay

```
+----------------------------------------------------------+
|  ESSAY — 0–4 points (Grades 3–6)                        |
|          0–8 points (Grades 7–8, 10)                     |
|                                                          |
|  Multi-paragraph composition                             |
|  Grades 3–4: Narrative                                   |
|  Grades 5–6: Informational/Explanatory                   |
|  Grades 7–8, 10: Argumentative or Literary Analysis      |
|  Passage-based or stand-alone (Grade 10)                 |
|  Human scored on multi-trait rubric                       |
|  Session 2                                               |
+----------------------------------------------------------+
```

**Essay Example (Grade 4 — Narrative, 0–4 pts):**

*[After reading a passage about a family's visit to the seashore]*

Write a story about a character who discovers something surprising at the beach. Use descriptive details to develop the setting, characters, and events.

**Essay Example (Grade 8 — Argumentative, 0–8 pts):**

Some communities in Massachusetts have proposed limiting commercial fishing to protect marine ecosystems along Cape Cod. Others argue that fishing is essential to the region's economy and cultural identity. Write an essay in which you take a position on this issue. Support your argument with clear reasons and evidence.

**Essay Example (Grade 10 — Literary Analysis, 0–8 pts):**

*[After reading two poems by Emily Dickinson]*

Write an essay analyzing how Dickinson uses imagery and structure in these two poems to explore the theme of solitude. Support your analysis with specific evidence from both texts.

## 6. Depth of Knowledge (DOK)

| DOK | Label | ELA Application Examples |
|---|---|---|
| 1 | Recall | Identify a vocabulary word meaning using context; locate an explicit fact; name a text structure |
| 2 | Skills & Concepts | Infer a character's motivation; identify the author's purpose; explain how a detail supports the central idea |
| 3 | Strategic Thinking | Analyze how an author's use of figurative language contributes to theme; evaluate the effectiveness of an argument; compare themes across two passages; synthesize evidence from multiple sources |
| 4 | Extended Thinking | Essay prompt — full essay integrating ideas, craft, evidence, and voice across one or more texts |

### DOK Alignment by Item Type

| Item Type | Typical DOK | Notes |
|---|---|---|
| MC | 1–3 | Most MC items are DOK 2; some DOK 1 for vocabulary; DOK 3 for craft analysis |
| SR | 2–3 | Requires written explanation with text evidence |
| Essay | 3–4 | Extended composition integrating multiple skills |

| Factor | Lower Grades (3–4) | Upper Grades (7–10) |
|---|---|---|
| Purpose | Single, clear purpose | Multiple, implicit, or satirical purposes |
| Structure | Sequential, chronological | Complex, non-linear; embedded structures; layered arguments |
| Language | Literal, common vocabulary | Figurative, archaic, or highly academic; rhetorical devices |
| Knowledge Demand | Everyday experience | Disciplinary, cultural, or historical knowledge |

## 8. Scoring Rubrics

### Short Response (SR) Rubric — 0–2 Points

| Score | Criteria |
|---|---|
| 2 | Response provides an accurate, thorough answer. Includes relevant and specific textual evidence that directly supports the response. Demonstrates clear, complete understanding of the text and the question. |
| 1 | Response provides a partially accurate answer. Textual evidence is present but may be vague, incomplete, or loosely connected to the answer. Demonstrates partial understanding. |
| 0 | Response is inaccurate, irrelevant, too brief to evaluate, or blank. No valid textual evidence provided. |

### Essay Rubric — 0–4 Points (Grades 3–6)

| Score | Criteria |
|---|---|
| 4 | Well-developed composition with a clear and focused controlling idea. Effective organization with purposeful transitions. Thorough development with relevant, specific details or evidence. Strong command of conventions with few minor errors. |
| 3 | Adequately developed composition with a controlling idea. Logical organization with transitions. Sufficient development with supporting details. General command of conventions. |
| 2 | Partially developed composition with a vague controlling idea. Inconsistent organization. Limited development with few details. Partial command of conventions with errors that may impede reading. |
| 1 | Minimally developed composition. Controlling idea absent or unclear. Little organization. Negligible development. Frequent errors in conventions. |
| 0 | Blank, off-topic, or insufficient text to evaluate. |

### Essay Rubric — 0–8 Points (Grades 7–8, 10)

The essay is scored on **two traits** with 0–4 points each, combined for a total of 0–8 points:

**Trait 1: Topic Development / Idea Analysis (0–4)**

| Score | Criteria |
|---|---|
| 4 | Insightful analysis; precise, relevant evidence; compelling reasoning and elaboration |
| 3 | Clear analysis; relevant evidence; adequate reasoning and elaboration |
| 2 | Partial analysis; evidence present but underdeveloped; reasoning may be unclear |
| 1 | Minimal analysis; little evidence; weak reasoning |
| 0 | No analysis; off-topic; blank |

**Trait 2: Standard English Conventions / Writing Craft (0–4)**

| Score | Criteria |
|---|---|
| 4 | Sophisticated style and varied sentence structure; strong command of conventions; purposeful word choice |
| 3 | Clear style with some sentence variety; general command of conventions; appropriate word choice |
| 2 | Basic style with limited variety; partial command of conventions; word choice adequate but imprecise |
| 1 | Simplistic style; frequent errors in conventions that impede reading; limited vocabulary |
| 0 | Insufficient to evaluate; blank |

### Suggested Passage Anchors by Grade

**Grades 3–4 Narrative Prompts:**
- "Write a story about a character who finds something unexpected on a beach on Cape Cod"
- "Write about a time you learned something new about the past" (Massachusetts-themed)

**Grades 3–4 Literary Passages:**
- Fiction set in a coastal Massachusetts village
- Stories involving autumn in New England — apple orchards, changing leaves

**Grades 5–6 Informational Passages:**
- Article about the history of Plymouth and the first Thanksgiving
- Article about Cape Cod's geography and how barrier beaches protect the coastline
- Biography of a Massachusetts historical figure

**Grades 7–8 Literary and Argumentative:**
- Literary fiction set along the Massachusetts coast during a storm
- Paired informational texts: perspectives on Massachusetts fishing regulations
- Argumentative prompt related to local community or environmental issues

**Grade 10 Literary Analysis:**
- Excerpts from Thoreau, Dickinson, Hawthorne, or contemporary Massachusetts authors
- Paired poems exploring a common theme through different lenses

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] MA.ELA-Literacy standard code verified for the targeted grade
- [ ] MC items directly tied to the passage (not general knowledge)
- [ ] SR prompt requires textual evidence explicitly
- [ ] Essay type matches grade band (Narrative for 3–4, Informational for 5–6, Argumentative/Literary Analysis for 7–10)
- [ ] Essay scoring uses correct rubric (0–4 for Grades 3–6; 0–8 two-trait for Grades 7–10)
- [ ] Distractors represent authentic misconceptions, not obviously wrong answers
- [ ] Lexile of passage matches the grade-level range
- [ ] Massachusetts context incorporated where appropriate
- [ ] Grade 10 items reflect graduation-requirement rigor
- [ ] Two-session structure maintained (Session 1: Reading; Session 2: Essay)
- [ ] Item type matches correct point value (MC=1, SR=0–2, Essay=0–4 or 0–8)

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Using CCSS codes without MA prefix | Massachusetts uses MA.ELA-Literacy codes | Use MA.ELA-Literacy prefix |
| Essay scored on single-trait rubric for Grades 7–10 | Grades 7–10 use two-trait rubric (0–4 + 0–4 = 0–8) | Apply correct rubric for grade band |
| Forgetting Grade 10 graduation requirement | Grade 10 is high-stakes | Ensure Grade 10 items reflect appropriate rigor |
| SR prompt that does not require evidence | SR items must require specific textual evidence | Include "use evidence from the text" in SR prompts |
| Items not passage-dependent | All Session 1 items must reference a stimulus text | Tie every MC and SR to a specific passage |
| Generic New England context | Massachusetts has distinct history and culture | Use Boston, Plymouth, Cape Cod, Thoreau, Dickinson contexts |
| Treating MCAS as low-rigor | MCAS is one of the most rigorous state assessments | Set high analytical expectations for items |

## 12. Prompt Patterns

### Pattern 1: Theme / Central Idea (MC or SR, DOK 2–3)
> "What [theme / central idea] does this [passage / story / article] develop? How does the author use [specific details / events / language] to develop this [theme / idea]?"

### Pattern 2: Craft & Language Analysis (MC, DOK 3)
> "Read [line reference / paragraph reference]. What effect does the author's use of [figurative language / imagery / word choice / structure] create in this [sentence / paragraph / passage]?"

### Pattern 3: Author's Purpose / Argument (MC or SR, DOK 2–3)
> "What is the author's [main purpose / central argument] in this [article / essay]? How does the author [support / develop] this [purpose / argument]? Use evidence from the text."

### Pattern 4: Short Response — Text Evidence (DOK 2–3)
> "Explain how the author [develops / supports / conveys] [specific aspect of the text]. Use specific evidence from the text to support your answer."

### Pattern 5: Essay — Narrative (DOK 3–4)
> "Write a story about [topic / scenario]. Use descriptive details to develop your setting, characters, and events."

### Pattern 6: Essay — Argumentative (DOK 3–4)
> "[Issue statement presenting two sides]. Write an essay in which you take a position on this issue. Support your argument with clear reasons and evidence."

### Pattern 7: Essay — Literary Analysis (DOK 3–4)
> "[After reading text(s)]. Write an essay analyzing how the author uses [literary technique] to develop [theme / idea]. Use specific evidence from the text(s) to support your analysis."
