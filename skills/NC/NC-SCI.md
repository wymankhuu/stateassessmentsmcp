## 1. Overview

| Field | Detail |
|---|---|
| **Assessment Name** | NC End-of-Grade (EOG) — Science |
| **Administering Agency** | North Carolina Department of Public Instruction (NCDPI) |
| **Vendor** | NCDPI (state-developed) |
| **Grades Tested** | **Grade 5, Grade 8** |
| **Testing Window** | Last 10 instructional days of the school year (typically late May–early June) |
| **Delivery** | Computer-based (NCTest); paper accommodations available |
| **Standards** | North Carolina Essential Standards (NCES) for Science |
| **Score Scale** | Scale score; **5 performance levels** |
| **Item Types** | Multiple Choice (MC) only |
| **Reporting** | Individual Student Report; School, District, State aggregates |

> **CRITICAL NOTE:** NC EOG Science is a **multiple-choice only** assessment. Unlike many state science assessments, North Carolina does NOT include constructed response, open response, or technology-enhanced items on the Science EOG. All items are standard 4-option MC. Science is tested at **Grade 5 and Grade 8 only**.

> **STANDARDS NOTE:** North Carolina uses the **North Carolina Essential Standards (NCES) for Science**, which are state-specific standards distinct from both NGSS and CCSS. NCES Science is NOT NGSS-based. Standard codes follow the format [Grade].[Domain].[Goal].[Objective] (e.g., 5.L.2.1).

### Performance Levels

| Level | Label | Description |
|---|---|---|
| 1 | **Level 1** | Student demonstrates insufficient command of grade-level science knowledge |
| 2 | **Level 2** | Student demonstrates partial command of grade-level science knowledge |
| 3 | **Level 3** | Student demonstrates sufficient command of grade-level science knowledge (Grade-Level Proficient) |
| 4 | **Level 4** | Student demonstrates solid command of grade-level science knowledge (Career and College Ready) |
| 5 | **Level 5** | Student demonstrates superior command of grade-level science knowledge |

## 2. Standards Framework

### North Carolina Essential Standards (NCES) for Science

North Carolina's NCES for Science are organized by content strands with goals and objectives. Standard codes follow the format: **[Grade].[Strand].[Goal].[Objective]**

**Example:** 5.L.2.1 = Grade 5, Life Science, Goal 2, Objective 1

| Code | Strand | Grades |
|---|---|---|
| E | Earth Science | 5, 8 |
| P | Physical Science | 5, 8 |
| L | Life Science | 5, 8 |

### NCES vs. NGSS Comparison

| Feature | NCES (North Carolina — USE THIS) | NGSS (NOT used by NC) |
|---|---|---|
| Adopted by North Carolina | YES — NC-specific | NO — NC did NOT adopt NGSS |
| Standard Code Example | 5.L.2.1 | 5-LS2-1 |
| Structure | Strand > Goal > Objective | Performance Expectation with 3 dimensions |
| Science Practices | Embedded in objectives | Explicit SEPs (8 practices) |
| Crosscutting Concepts | Not explicitly labeled | Explicit CCCs (7 concepts) |
| Assessment focus | Content knowledge + inquiry skills | Three-dimensional performance |

> **KEY RULE:** When writing NC Science items, code standards as **[Grade].[Strand].[Goal].[Objective]** — never use NGSS PE codes.

NC EOG Science is a **single session**, multiple-choice-only assessment.

```
+------------------------------------------------------------------+
|          NC EOG SCIENCE STRUCTURE (Grades 5, 8)                   |

```

## 5. Item Types & Formats

### Multiple Choice (MC) — The ONLY Item Type

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Single correct answer                                   |
|  Machine scored                                          |
|  Some items are scenario-based with data tables,         |
|  diagrams, graphs, and NC-specific phenomena             |
|  ALL items on the Science EOG are MC                     |
+----------------------------------------------------------+
```

**MC Example (Grade 5, DOK 2, 5.L.2.1 — Ecosystems):**

Scientists studying the Outer Banks of North Carolina observed that the salt marsh ecosystem contains many species of grasses, crabs, shrimp, fish, and birds. Which statement BEST explains why this ecosystem supports such a variety of organisms?

A. The salt marsh has the same temperature year-round
B. The salt marsh provides diverse habitats with different food sources, water conditions, and shelter
C. All organisms in the salt marsh eat the same type of food
D. The salt marsh is protected from all storms and weather

*Correct Answer: B*
*Alignment: 5.L.2.1 | DOK 2*

---

**MC Example (Grade 8, DOK 2, 8.E.1.1 — Hydrosphere):**

The Cape Fear River begins in the NC Piedmont region and flows southeast to the Atlantic Ocean near Wilmington. Which statement BEST describes the role of this river in the water cycle?

A. The river creates new water as it flows to the ocean
B. The river transports water from land to the ocean as part of the continuous water cycle
C. The river evaporates completely before reaching the ocean
D. The river only flows during rainstorms

*Correct Answer: B*
*Alignment: 8.E.1.1 | DOK 2*

---

**MC Example (Grade 5, DOK 1, 5.L.2.2 — Ecosystem Roles):**

In a North Carolina forest food chain, oak trees produce acorns that are eaten by deer, and deer are hunted by coyotes. Which organism in this food chain is the producer?

A. Acorn
B. Deer
C. Coyote
D. Oak tree

*Correct Answer: D*
*Alignment: 5.L.2.2 | DOK 1*

---

**MC Example (Grade 8, DOK 3, 8.L.3.1 — Population Factors):**

*Scientists collected data on the loggerhead sea turtle population on North Carolina's barrier islands over a 10-year period:*

| Year | Nesting Females | Hatchlings | Available Beach (km) |
|---|---|---|---|
| 2014 | 120 | 8,400 | 15.2 |
| 2016 | 115 | 7,800 | 14.1 |
| 2018 | 98 | 6,500 | 12.8 |
| 2020 | 82 | 5,200 | 11.3 |
| 2022 | 75 | 4,600 | 10.5 |

Based on the data, which factor is MOST LIKELY contributing to the decline in the sea turtle population?

A. An increase in ocean water temperature
B. A decrease in available nesting habitat due to beach erosion
C. A decrease in the food supply in the ocean
D. An increase in the number of predators on the beach

*Correct Answer: B*
*Alignment: 8.L.3.1 | DOK 3*

## 7. NC Science Standards vs. NGSS: Key Differences

This comparison is critical for avoiding the most common error in NC Science item writing — treating NCES as if it were NGSS.

### Side-by-Side Comparison

| Feature | NCES (NC — USE THIS) | NGSS (NOT used by NC) |
|---|---|---|
| Adopted by North Carolina | YES — NC-specific | NO |
| Standard Code Format | [Grade].[Strand].[Goal].[Objective] | [Grade]-[Domain][#]-[PE#] |
| Example Code | 5.L.2.1 | 5-LS2-1 |
| Organization | Strand > Goal > Objective | DCI > SEP > CCC |
| Science Practices | Embedded; not separately labeled | Explicit SEPs |
| Crosscutting Concepts | Not explicitly required | Required in all items |
| Assessment Item Type | MC only | MC, CR, TE, Performance Tasks |

### Common Standard Code Errors

| Incorrect | Correct | Why |
|---|---|---|
| 5-LS2-1 | 5.L.2.1 | NGSS code format used instead of NCES |
| SC.5.L.17.1 | 5.L.2.1 | Florida code format used instead of NCES |
| S5L1 | 5.L.1.1 | Georgia GSE code format used instead of NCES |

## 10. Contextualization — North Carolina Science

North Carolina's diverse geography provides rich, authentic contexts for science assessment items.

### NC Science Context Guide by Grade

| Context / Phenomenon | Grade | Strand | NCES Standards |
|---|---|---|---|
| Outer Banks geology (barrier island formation, erosion, sand dunes) | 5, 8 | Earth/Life | 5.E.1.1, 8.E.1.1 |
| NC Piedmont region (soil types, rolling hills, rivers) | 5, 8 | Earth Science | 5.E.1.1, 8.E.1.1 |
| Blue Ridge Mountains ecosystems (biodiversity, elevation effects) | 5, 8 | Life Science | 5.L.2.1, 8.L.3.1 |
| Sea turtles on NC barrier islands (nesting, population, habitat) | 5, 8 | Life Science | 5.L.1.1, 5.L.2.3, 8.L.3.1 |
| NC salt marsh and estuary ecosystems | 5, 8 | Life Science | 5.L.2.1, 5.L.2.2, 8.L.3.2 |
| Cape Hatteras and Graveyard of the Atlantic (ocean currents, weather) | 5, 8 | Earth Science | 5.E.1.1, 8.E.2.1 |
| NC hurricane season and severe weather | 5, 8 | Earth Science | 5.E.1.2, 5.E.1.3, 8.E.2.1 |
| Cape Fear River watershed and water quality | 8 | Earth Science | 8.E.1.1, 8.E.1.3, 8.E.1.4 |
| NC forest ecosystems (longleaf pine, Uwharrie) | 5, 8 | Life Science | 5.L.2.1, 8.L.3.1 |
| NC coastal erosion and beach nourishment | 5, 8 | Earth Science | 5.E.1.1, 8.E.1.1 |

### Suggested Anchoring Phenomena by Grade

**Grade 5 Phenomena:**
- "Scientists studying the Outer Banks noticed that after Hurricane Florence in 2018, some beaches lost large amounts of sand while other beaches grew wider. What processes caused these different outcomes?"
- "A student visiting the NC Aquarium at Fort Fisher observed that the salt marsh had many more species of plants and animals than the nearby beach. What explains this difference in biodiversity?"
- "A farmer in the NC Piedmont noticed that heavy rain washed away the topsoil from a hillside field but not from a field with cover crops. What explains this difference?"
- "Weather data from Cape Hatteras shows that hurricanes form over warm ocean water and weaken over land. What energy transfer explains this pattern?"

**Grade 8 Phenomena:**
- "Scientists monitoring water quality in the Cape Fear River found higher levels of pollutants downstream from a factory than upstream. What can be concluded about the relationship between human activity and water quality?"
- "Loggerhead sea turtle populations on NC barrier islands have declined as available nesting beach area has decreased. What relationship between habitat and population does this data support?"
- "The Blue Ridge Mountains in western NC have cooler temperatures and different plant species than the Piedmont. What factors explain how elevation affects ecosystems?"
- "After a controlled burn in a NC longleaf pine forest, scientists observed that new plant growth appeared quickly and wildlife returned within weeks. How does fire affect the cycling of matter and energy in this ecosystem?"

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] Grade verified as **5 or 8 ONLY** (no other grades for NC Science EOG)
- [ ] Standard code uses NCES format: [Grade].[Strand].[Goal].[Objective]
- [ ] No NGSS codes used anywhere in item
- [ ] **ALL items are MC only** — no constructed response, open response, or TE items
- [ ] **5 performance levels** referenced (Levels 1–5), not 4
- [ ] NC-specific phenomenon used in scenario items
- [ ] MC has exactly 4 options (A, B, C, D) with 1 correct answer
- [ ] All MC distractors reflect identifiable student misconceptions
- [ ] Data tables and graphs are clearly labeled with units
- [ ] Science content is accurate and grade-appropriate
- [ ] DOK level matches cognitive demand (ceiling is DOK 3 for MC)

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Using NGSS codes | NC uses NCES, NOT NGSS | Use [Grade].[Strand].[Goal].[Objective] format |
| Including CR/OR/TE items | NC Science EOG is MC only | Use only MC items — no written or tech-enhanced responses |
| Using 4 performance levels | NC uses 5 levels | Use Levels 1–5 |
| Generating items for other grades | NC Science EOG tests only Gr 5 and Gr 8 | Restrict to Grade 5 and Grade 8 |
| Generic coastal phenomena | NC has specific geography | Use Outer Banks, Blue Ridge, Piedmont, Cape Fear River |
| Confusing NCES with NGSS three-dimensions | NCES is not three-dimensional | Focus on content knowledge + inquiry, not DCI/SEP/CCC |
| Items requiring prior knowledge not in stimulus | Items should be answerable from scenario + grade-level science | Include all needed information in the stimulus |
| Overly complex data for MC | MC items have limited space for analysis | Keep data tables to 4–6 rows and 3–4 columns |

## 12. Prompt Patterns

### Pattern 1: Observation to Explanation (MC, DOK 2)
> "Scientists observed [NC organism/phenomenon] doing [specific behavior/change]. Which explanation BEST describes why this occurred?"

### Pattern 2: Data Table Interpretation (MC, DOK 2)
> "The table below shows [NC science data]. Based on the data, which [conclusion / statement / pattern] is BEST supported?"

### Pattern 3: Cause and Effect — Ecosystem (MC, DOK 2)
> "In the [Outer Banks / Blue Ridge / NC Piedmont] ecosystem, [change in one variable] occurred. What would MOST LIKELY happen to [another organism or part of the system]?"

### Pattern 4: Classification (MC, DOK 1)
> "Which organism in the following NC food chain is classified as a [producer / consumer / decomposer]?"

### Pattern 5: Experimental Design (MC, DOK 2–3)
> "A student designed an experiment to test whether [variable] affects [outcome] in a NC [context]. What is the [independent / dependent / controlled] variable?"

### Pattern 6: Weather and Climate (MC, DOK 2)
> "[Weather data from NC location]. Based on the data, which weather event is MOST LIKELY approaching?"
