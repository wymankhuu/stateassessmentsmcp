# NC EOG / EOC — ELA (English Language Arts)
## AssessmentForge Skill Guide | Grades 3–8

---

## 1. Overview

| Field | Detail |
|---|---|
| **Assessment Name** | NC End-of-Grade (EOG) — English Language Arts / Reading |
| **Administering Agency** | North Carolina Department of Public Instruction (NCDPI) |
| **Vendor** | NCDPI (state-developed) |
| **Grades Tested** | 3, 4, 5, 6, 7, 8 |
| **Testing Window** | Last 10 instructional days of the school year (typically late May–early June) |
| **Delivery** | Computer-based (NCTest); paper accommodations available |
| **Standards** | North Carolina Standard Course of Study (NCSCOS) for English Language Arts |
| **Score Scale** | Scale score; **5 performance levels** |
| **Item Types** | Multiple Choice (MC), Technology Enhanced (TE) |
| **Reporting** | Individual Student Report; School, District, State aggregates |

> **KEY NOTE:** NC EOG ELA is **primarily multiple-choice based** with some technology-enhanced items. Unlike many state assessments, NC does NOT include constructed response or extended writing on the EOG ELA. The assessment focuses on reading comprehension, vocabulary, and language conventions through selected-response formats. North Carolina uses **5 performance levels**, which is distinctive among state assessments.

### Performance Levels

| Level | Label | Description |
|---|---|---|
| 1 | **Level 1** | Student demonstrates insufficient command of grade-level knowledge and skills |
| 2 | **Level 2** | Student demonstrates partial command of grade-level knowledge and skills |
| 3 | **Level 3** | Student demonstrates sufficient command of grade-level knowledge and skills (Grade-Level Proficient) |
| 4 | **Level 4** | Student demonstrates solid command of grade-level knowledge and skills (Career and College Ready) |
| 5 | **Level 5** | Student demonstrates superior command of grade-level knowledge and skills |

> **Item-writing target:** Level 3 (Grade-Level Proficient) to Level 4 (Career and College Ready). Items should require genuine application of the NCSCOS at the expected DOK level.

## 2. Standards Framework

> NC EOG ELA is aligned to the **North Carolina Standard Course of Study (NCSCOS) for English Language Arts**, adopted in 2017. NCSCOS ELA incorporates elements of CCSS while reflecting North Carolina's own curricular priorities. Standard codes use the format RL.[Grade].[Standard] (e.g., RL.5.2).

### NCSCOS ELA Strands

| Strand | Focus | Grade Emphasis |
|---|---|---|
| **Reading Literature (RL)** | Fiction, poetry, drama; theme, structure, craft, point of view | All grades |
| **Reading Informational (RI)** | Nonfiction comprehension; central idea, evidence, argument, text structure | All grades |
| **Language (L)** | Grammar, conventions, vocabulary acquisition, word analysis | All grades; embedded in MC/TE items |

### Key Standards by Grade Band

| Standard Code | Description | Grade Band | DOK |
|---|---|---|---|
| RL.3.2 | Recount stories; determine the central message, lesson, or moral using key details | 3 | 2 |
| RL.4.3 | Describe in depth a character, setting, or event using specific details from the text | 4 | 2–3 |
| RI.5.8 | Explain how an author uses reasons and evidence to support particular points | 5 | 3 |
| RL.6.5 | Analyze how a particular sentence, chapter, or section fits into the overall structure | 6 | 3 |
| RI.7.6 | Determine an author's point of view or purpose and analyze how the author distinguishes it | 7 | 3 |
| RL.8.4 | Determine the meaning of words and phrases including figurative and connotative meanings | 8 | 2–3 |
| L.5.4 | Determine or clarify the meaning of unknown words using context clues, affixes, and roots | 5 | 2 |
| L.7.1 | Demonstrate command of conventions of standard English grammar and usage | 7 | 1–2 |

## 3. Test Structure

NC EOG ELA is administered in a **single session** on one day. The test consists entirely of selected-response items (MC and TE) organized around passage sets.

```
+------------------------------------------------------------------+
|          NC EOG ELA STRUCTURE (Grades 3–8)                        |
+------------------------------------------------------------------+
|  SINGLE SESSION — approximately 120–180 minutes (untimed)         |
|  Computer-based (NCTest platform)                                 |
|                                                                    |
|  4–6 passage sets:                                                |
|  ┌────────────────────────────────────────────┐                   |
|  │ Passage Set 1 (Literary) → MC, TE items    │                   |
|  │ Passage Set 2 (Informational) → MC, TE     │                   |
|  │ Passage Set 3 (Literary or Paired) → MC, TE│                   |
|  │ Passage Set 4 (Informational) → MC, TE     │                   |
|  │ Additional sets possible at upper grades    │                   |
|  └────────────────────────────────────────────┘                   |
|                                                                    |
|  Stand-alone Language items: MC for grammar,                      |
|  conventions, and vocabulary                                      |
+------------------------------------------------------------------+
```

### Item Count Summary by Grade Band

| Component | Grades 3–4 | Grades 5–6 | Grades 7–8 |
|---|---|---|---|
| Literary passages | 2 | 2–3 | 2–3 |
| Informational passages | 2 | 2–3 | 2–3 |
| MC items | 36–42 | 40–48 | 44–52 |
| TE items | 4–6 | 5–8 | 6–10 |
| **Total items** | **~42–48** | **~48–54** | **~52–60** |

## 5. Item Types & Formats

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE (MC) — 1 point                          |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Single correct answer                                   |
|  Passage-based (tied to stimulus text)                   |
|  Machine scored                                          |
|  DOK 1–3                                                 |
|  PRIMARY item type on NC EOG                             |
+----------------------------------------------------------+
```

**MC Example (Grade 5 Literary, DOK 2, RL.5.2):**

*[After reading a story about a child exploring the Wright Brothers National Memorial at Kill Devil Hills]*

Which statement BEST describes a theme of this story?

A. Famous inventions are always made by working alone
B. Curiosity and determination can lead to extraordinary accomplishments
C. The Outer Banks is the best place to learn about history
D. All children dream of learning to fly

*Correct Answer: B*
*Alignment: RL.5.2 | DOK 2*

---

**MC Example (Grade 7 Informational, DOK 2, RI.7.6):**

*[After reading an article about the history of the Lost Colony of Roanoke]*

How does the author MAINLY develop the idea that the disappearance of the Roanoke Colony remains one of America's greatest mysteries?

A. By describing the daily routines of the colonists in detail
B. By presenting multiple theories alongside evidence that neither confirms nor disproves any single explanation
C. By arguing that the colonists were rescued by passing ships
D. By comparing Roanoke to other successful colonial settlements

*Correct Answer: B*
*Alignment: RI.7.6 | DOK 2*

---

**MC Example (Grade 4, DOK 2, RL.4.3):**

*[After reading a story about a family hiking in the Blue Ridge Mountains]*

How does the setting of the Blue Ridge Mountains MOST affect the main character?

A. It makes her feel bored because there is nothing to do
B. It challenges her physically but fills her with a sense of wonder and accomplishment
C. It reminds her of stories from school about mountains
D. It causes her to miss her friends back in Charlotte

*Correct Answer: B*
*Alignment: RL.4.3 | DOK 2*

---

### Technology Enhanced (TE)

```
+----------------------------------------------------------+
|  TECHNOLOGY ENHANCED (TE) — 1 point                      |
|                                                          |
|  Formats: multi-select, drag-and-drop, evidence-based    |
|  selected response, drop-down menu                       |
|  Passage-dependent                                       |
|  Machine scored                                          |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**TE Example — Multi-Select (Grade 6, DOK 2, RI.6.5):**

*[After reading an article about the history of Charlotte's growth from a small town to a major city]*

Select TWO text structures the author uses in this article.

A. Problem and solution
B. Chronological order
C. Cause and effect
D. Compare and contrast with other cities
E. Question and answer format

*Correct Answers: B and C*

---

**TE Example — Evidence-Based Selected Response (Grade 8, DOK 3, RL.8.4):**

*[After reading a passage set near the Biltmore Estate]*

**Part A:** What does the phrase "the house breathed history" in paragraph 4 MOST LIKELY suggest?

A. The house was haunted by spirits of the past
B. The age and grandeur of the estate made the past feel alive and present
C. The house needed better ventilation because it was so old
D. The narrator was afraid of old buildings

**Part B:** Which detail from the passage BEST supports the answer to Part A?

F. "Dust motes danced in the light streaming through the tall windows."
G. "Every room seemed to whisper stories of the Vanderbilts' grand ambitions and the mountain people who built their vision."
H. "The guide mentioned that the house had 250 rooms."
J. "They walked through the gardens before entering the main hall."

*Correct Answers: Part A — B; Part B — G*

## 6. Depth of Knowledge (DOK)

| DOK | Label | ELA Application Examples |
|---|---|---|
| 1 | Recall | Identify a vocabulary word meaning using context; locate an explicit fact; name a text structure |
| 2 | Skills & Concepts | Infer a character's motivation; identify the author's purpose; explain how a detail supports the central idea; determine connotative meaning |
| 3 | Strategic Thinking | Analyze how the author's craft choices contribute to theme; evaluate the effectiveness of an argument; compare themes or perspectives across two passages; synthesize evidence from paired texts |

### DOK Alignment by Item Type

| Item Type | Typical DOK | Notes |
|---|---|---|
| MC | 1–3 | Most MC items are DOK 2; DOK 1 for vocabulary/recall; DOK 3 for craft analysis |
| TE (Multi-Select) | 2–3 | Requires identifying multiple correct elements |
| TE (Evidence-Based) | 2–3 | Two-part evidence-based reasoning |

### Passage Characteristics

| Feature | Requirement |
|---|---|
| **Passage length** | 400–1,000 words for comprehension passages |
| **Sentence complexity** | Grade-appropriate syntactic complexity |
| **Vocabulary** | Grade-appropriate Tier 2 and Tier 3 vocabulary |
| **Text structure** | Literary: narrative arc, character development, figurative language; Informational: claim-evidence, compare/contrast, cause/effect, chronological |
| **NC relevance** | Passages should reflect North Carolina culture, geography, history, and authors where appropriate |
| **Paired passages** | Grades 5–8 may include paired passages for cross-text analysis items |

### Qualitative Complexity Factors

| Factor | Lower Grades (3–4) | Upper Grades (6–8) |
|---|---|---|
| Purpose | Single, clear purpose | Multiple or implicit purposes |
| Structure | Sequential, chronological | Complex, non-linear; embedded structures |
| Language | Literal, common vocabulary | Figurative, domain-specific, connotative |
| Knowledge Demand | Everyday experience | Disciplinary or cultural knowledge |

## 8. Scoring Rubrics

### MC and TE Scoring

| Item Type | Scoring Method | Points |
|---|---|---|
| MC | Machine scored; single correct answer | 1 pt |
| TE (Multi-Select) | Machine scored; all correct selections required | 1 pt |
| TE (Evidence-Based) | Machine scored; Part A + Part B (varies: 1–2 pts total) | 1–2 pts |
| TE (Drag-and-Drop) | Machine scored; all elements correctly placed | 1 pt |

> **Note:** NC EOG ELA does **not** include constructed response or essay items. All items are machine scored through selected-response formats. This is a key differentiator from many other state assessments.

```
PASSAGE TYPE: Literary (short story / narrative / poem / drama)
DOK LEVEL: 2–3
POINT VALUE: 1 point

      [DOK 2: Infer / identify / explain]
      [DOK 3: Analyze / evaluate how author develops __]

B [Distractor — partially correct; right domain, weak reasoning]

ALIGNMENT: RL.[Grade].[#] | DOK [2 or 3]
```

### Template B: TE — Evidence-Based Two-Part (DOK 2–3)

```
ITEM TEMPLATE: TE — Evidence-Based Selected Response (DOK 2–3)
----------------------------------------------------------------
TARGET STANDARD: RL.[Grade].[#] or RI.[Grade].[#]
PASSAGE TYPE: Literary or Informational
DOK LEVEL: 2–3
POINT VALUE: 1–2 points

PART A STEM: [Analytical question about theme, central idea,
             author's craft, character development, or argument]
PART A OPTIONS: A, B, C, D (one correct)

PART B STEM: "Which [sentence / detail / quote] from the
             [passage] BEST supports the answer to Part A?"
PART B OPTIONS: F, G, H, J (one correct)

SCORING:
Full credit: Part A correct AND Part B correct
Partial: varies by item (some all-or-nothing, some partial)

ALIGNMENT: [RL/RI].[Grade].[#] | DOK [2 or 3]
```

## 10. Contextualization — North Carolina ELA

When generating passages and prompts, prioritize authentic North Carolina settings, history, and culture:

### North Carolina Context Guide

| Context | Passage Type | Grade Band |
|---|---|---|
| Wright Brothers and Kitty Hawk / Kill Devil Hills | Informational or Literary nonfiction | 3–6 |
| Blue Ridge Mountains / Appalachian culture and heritage | Literary fiction or Informational | 3–8 |
| Charlotte growth and urbanization / Queen City history | Informational | 5–8 |
| Roanoke Lost Colony / Roanoke Island history | Informational or Literary | 4–8 |
| Biltmore Estate / Vanderbilt legacy and Asheville | Literary fiction or Informational | 5–8 |
| Outer Banks geography and lighthouse history | Informational | 3–7 |
| North Carolina Piedmont region / Tobacco Road heritage | Literary fiction or Informational | 5–8 |
| Cape Hatteras / Graveyard of the Atlantic | Informational | 5–8 |
| Cherokee culture and history in western NC | Informational or Literary | 4–8 |
| North Carolina agriculture (tobacco, sweet potatoes, hog farming) | Informational | 3–6 |
| Research Triangle (Raleigh-Durham-Chapel Hill) innovation | Informational | 6–8 |

### Suggested Passage Anchors by Grade

**Grades 3–4 Literary Passages:**
- Fiction set along the Outer Banks featuring a child exploring tide pools or lighthouses
- Stories set in the Blue Ridge Mountains about family traditions and Appalachian heritage

**Grades 3–4 Informational Passages:**
- Article about the Wright Brothers' first flight at Kitty Hawk
- Article about North Carolina lighthouses and how they protect ships

**Grades 5–6 Informational Passages:**
- Article about the mystery of the Lost Colony of Roanoke
- Article about the Biltmore Estate and the Vanderbilt family's impact on Asheville
- Article about the Outer Banks and barrier island ecology

**Grades 7–8 Literary and Informational:**
- Literary fiction set in Charlotte exploring themes of community and change
- Paired informational texts: perspectives on preserving Appalachian culture in a modernizing North Carolina
- Article about the history and significance of the Research Triangle

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] NCSCOS ELA standard code verified for the targeted grade (RL/RI/L format)
- [ ] Items are passage-dependent (not general knowledge)
- [ ] NC EOG does NOT include constructed response or essay items — all items are MC or TE
- [ ] **5 performance levels** referenced (Levels 1–5), not 4
- [ ] TE items use appropriate format (multi-select, evidence-based selected response, drag-and-drop)
- [ ] Distractors represent authentic misconceptions
- [ ] Lexile of passage matches grade-level range
- [ ] North Carolina context incorporated where appropriate
- [ ] EOG is Grades 3–8 only (not high school)
- [ ] Item type matches correct point value (MC=1, TE=1 or 1–2)

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Including constructed response items | NC EOG ELA is MC/TE only — no written responses | Remove all CR/essay items |
| Using 4 performance levels | North Carolina uses 5 levels (1–5) | Use all 5 levels with correct labels |
| Including high school grades | NC EOG ELA is Grades 3–8 only | Restrict to tested grades |
| Items not passage-dependent | All EOG items reference a stimulus passage | Tie every MC and TE to a specific passage |
| Generic Southern context | NC has distinct history and culture | Use Wright Brothers, Blue Ridge, Outer Banks, Lost Colony, Biltmore contexts |
| Using CCSS codes | NC uses NCSCOS; standard codes are similar but distinct | Verify against NCSCOS documentation |
| Forgetting TE items | NC EOG includes technology-enhanced items | Include multi-select and evidence-based items |

## 12. Prompt Patterns

### Pattern 1: Theme / Central Idea (MC, DOK 2–3)
> "What [theme / central idea] does this [passage / story / article] develop?"

### Pattern 2: Craft & Language Analysis (MC, DOK 2–3)
> "Read [line reference / paragraph reference]. What effect does the author's use of [figurative language / imagery / word choice] create?"

### Pattern 3: Author's Purpose / Argument (MC, DOK 2–3)
> "What is the author's [main purpose / central argument] in this article? How does the author [support / develop] this purpose?"

### Pattern 4: Evidence-Based Analysis — TE (DOK 2–3)
> "Part A: What does [detail / phrase / event] reveal about [character / theme / central idea]?
> Part B: Which detail from the passage BEST supports the answer to Part A?"

### Pattern 5: Text Structure (MC or TE Multi-Select, DOK 2)
> "How is information in this article MAINLY organized?" or "Select TWO text structures the author uses."

### Pattern 6: Vocabulary in Context (MC, DOK 2)
> "As used in paragraph [#], what does the word [TARGET WORD] most likely mean?"

### Pattern 7: Cross-Text Comparison (MC or TE, DOK 3)
> "Both passages discuss [SHARED TOPIC]. How do the authors' perspectives on [TOPIC] differ?"
