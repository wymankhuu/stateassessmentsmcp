## 1. Overview

| Field | Detail |
|---|---|
| **Assessment Name** | NC End-of-Grade (EOG) — Mathematics |
| **Administering Agency** | North Carolina Department of Public Instruction (NCDPI) |
| **Vendor** | NCDPI (state-developed) |
| **Grades Tested** | 3, 4, 5, 6, 7, 8 |
| **Testing Window** | Last 10 instructional days of the school year (typically late May–early June) |
| **Delivery** | Computer-based (NCTest); paper accommodations available |
| **Standards** | North Carolina Standard Course of Study (NCSCOS) for Mathematics |
| **Score Scale** | Scale score; **5 performance levels** |
| **Item Types** | Multiple Choice (MC), Gridded Response, Multi-Select (MS) |
| **Calculator Policy** | No calculator Grades 3–4; calculator permitted Grades 5–8 (varies by section) |
| **Reporting** | Individual Student Report; School, District, State aggregates |

> **NC EOG Mathematics** is a primarily selected-response assessment. Unlike many states, North Carolina includes **gridded response** items where students enter numeric answers directly (no answer choices). The test also includes multi-select items. North Carolina uses **5 performance levels**, which is distinctive among state assessments.

### Performance Levels

| Level | Label | Description |
|---|---|---|
| 1 | **Level 1** | Student demonstrates insufficient command of grade-level mathematics |
| 2 | **Level 2** | Student demonstrates partial command of grade-level mathematics |
| 3 | **Level 3** | Student demonstrates sufficient command of grade-level mathematics (Grade-Level Proficient) |
| 4 | **Level 4** | Student demonstrates solid command of grade-level mathematics (Career and College Ready) |
| 5 | **Level 5** | Student demonstrates superior command of grade-level mathematics |

> **Item-writing target:** Level 3–4 performance. Items should require genuine application of NCSCOS at the expected DOK level.

## 5. Item Types & Formats

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Single correct answer                                   |
|  Machine scored                                          |
|  Sections 1 and 2                                        |
+----------------------------------------------------------+
```

**MC Example (Grade 5, DOK 2, NC.M.5.NF.4 — Multiply Fractions):**

A farmer in North Carolina plants sweet potatoes on 3/5 of a field. He waters 2/3 of the planted area each evening. What fraction of the entire field does the farmer water each evening?

A. 5/8
B. 6/15
C. 2/5
D. 1/5

*Correct Answer: C (3/5 x 2/3 = 6/15 = 2/5)*
*Alignment: NC.M.5.NF.4 | DOK 2*

---

**MC Example (Grade 7, DOK 2, NC.M.7.RP.2 — Proportional Relationships):**

Charlotte's population grew from 731,000 to 874,000 over a 5-year period. If the population continues to grow at the same constant rate, what will the approximate population be after 10 total years from the starting point?

A. 1,017,000
B. 960,000
C. 1,143,000
D. 905,000

*Correct Answer: A (growth = 143,000 per 5 years = 28,600/yr; 731,000 + 286,000 = 1,017,000)*
*Alignment: NC.M.7.RP.2 | DOK 2*

---

### Gridded Response

```
+----------------------------------------------------------+
|  GRIDDED RESPONSE — 1 point                              |
|                                                          |
|  Student enters numeric answer (no choices provided)     |
|  May be integer, decimal, or fraction                    |
|  Machine scored                                          |
|  DOK 1–2                                                 |
|  Both sections                                           |
+----------------------------------------------------------+
```

**Gridded Response Example (Grade 6, DOK 2, NC.M.6.RP.3):**

The distance from Raleigh to Wilmington along I-40 is approximately 155 miles. If a family drives at a constant speed and covers 62 miles in the first hour, how many total hours will the trip take? Enter your answer as a decimal.

*Correct Answer: 2.5 hours*
*Alignment: NC.M.6.RP.3 | DOK 2*

---

**Gridded Response Example (Grade 4, DOK 1, NC.M.4.NBT.5):**

A school in Charlotte ordered 36 boxes of pencils. Each box contains 48 pencils. How many pencils did the school order in all?

*Correct Answer: 1,728*
*Alignment: NC.M.4.NBT.5 | DOK 1*

---

### Multi-Select (MS)

```
+----------------------------------------------------------+
|  MULTI-SELECT (MS) — 1 point                             |
|                                                          |
|  5–6 options                                             |
|  Student selects ALL correct answers (typically 2–3)     |
|  Machine scored; all-or-nothing                          |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**MS Example (Grade 8, DOK 2, NC.M.8.EE.7):**

Select ALL equations that have exactly one solution.

A. 3x + 5 = 3x + 5
B. 2x - 4 = 10
C. 5(x + 1) = 5x + 5
D. 4x + 3 = 2x + 9
E. x + 7 = x + 3

*Correct Answers: B and D*
*Alignment: NC.M.8.EE.7 | DOK 2*

## 7. Mathematical Practices

The NCSCOS Mathematics incorporates the **Standards for Mathematical Practice (SMP)**, embedded across all item types.

| SMP | Practice | Assessment Application |
|---|---|---|
| 1 | Make sense of problems; persevere | Multi-step problems; complex word problems with NC contexts |
| 2 | Reason abstractly and quantitatively | Contextual problems requiring decontextualization |
| 3 | Construct viable arguments; critique reasoning | Items requiring students to identify errors or select valid reasoning |
| 4 | Model with mathematics | Real-world NC contexts (population data, distances, agriculture) |
| 5 | Use appropriate tools strategically | Calculator decisions; reference sheet usage |
| 6 | Attend to precision | Labeling units; exact answers in gridded response |
| 7 | Look for and make use of structure | Pattern recognition; algebraic reasoning items |
| 8 | Look for and express regularity in repeated reasoning | Function tables; generalization items |

## 8. Scoring Rubrics

### MC and Gridded Response Scoring

| Item Type | Scoring Method | Points |
|---|---|---|
| MC | Machine scored; single correct answer | 1 pt |
| Gridded Response | Machine scored; exact numeric match (or acceptable equivalent) | 1 pt |
| Multi-Select | Machine scored; all correct selections required | 1 pt |

> **Note:** NC EOG Mathematics does **not** include constructed response or extended response items requiring written explanations. All items are machine scored. Gridded response items require students to enter exact numeric answers.

### Gridded Response Acceptable Formats

| Answer Type | Acceptable Entries |
|---|---|
| Integer | 1728 |
| Decimal | 2.5 or 2.50 |
| Fraction | 3/4 |
| Mixed number | 1 1/2 or 3/2 |
| Negative | -5 or -2.3 |

## 10. Contextualization — North Carolina Mathematics

When generating real-world contexts for NC EOG Mathematics items, prioritize the following authentic North Carolina settings:

### Recommended Math Contexts

| Context | Grade Band | Math Domains |
|---|---|---|
| Outer Banks distances (between lighthouses, towns, ferry routes) | 3–7 | Measurement, fractions, decimals, ratios, rates |
| Charlotte population growth and urbanization data | 5–8 | Large numbers, percent, proportional reasoning, statistics |
| NC agriculture (sweet potatoes, tobacco, hog farming, Christmas trees) | 3–6 | Multiplication, area, fractions, measurement |
| Blue Ridge Parkway distances and elevations | 4–7 | Measurement, unit conversion, fractions, geometry |
| NC highway distances between major cities (Raleigh, Charlotte, Asheville, Wilmington) | 4–8 | Ratios, rates, proportional relationships |
| Outer Banks erosion rates (Cape Hatteras shoreline retreat) | 6–8 | Rates, linear functions, statistics |
| NC school enrollment and budget data by district | 5–8 | Percent, operations, statistics |
| Research Triangle employment data | 6–8 | Statistics, percent, large numbers |
| NC state park trail distances and campground data | 3–6 | Measurement, fractions, decimals, addition/subtraction |
| Cape Fear River flow rates and watershed data | 6–8 | Ratios, rates, expressions/equations |

### Sample Context Sentence Starters

- "The distance from the Cape Hatteras Lighthouse to the Bodie Island Lighthouse is approximately [X] miles..."

- "A North Carolina farmer harvested [X] bushels of sweet potatoes from [Y] acres..."

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] Standard code uses NC.M format (NC.M.[Grade].[Domain].[#])
- [ ] Calculator policy matches section (no calculator in Section 1; permitted Gr 5–8 Section 2)
- [ ] NC EOG Math does NOT include constructed response — all items are MC, Gridded, or MS
- [ ] **5 performance levels** referenced (Levels 1–5), not 4
- [ ] Gridded response items have clean, unambiguous numeric answers
- [ ] All numerical values produce non-ambiguous computations
- [ ] Distractors for MC reflect specific, identifiable student error types
- [ ] DOK level matches cognitive demand
- [ ] Units are clearly specified
- [ ] NC context incorporated where appropriate
- [ ] EOG is Grades 3–8 only (not high school)
- [ ] Item type matches correct point value (MC=1, Gridded=1, MS=1)

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Including constructed response items | NC EOG Math is MC/Gridded/MS only | Remove all written-response items |
| Using 4 performance levels | North Carolina uses 5 levels | Use Levels 1–5 with correct labels |
| Calculator in Section 1 | Section 1 is no-calculator for all grades | Design Section 1 with manageable computation |
| Gridded answers with ambiguity | Students must enter exact answers | Ensure clean numeric answers |
| Using raw CCSS codes | NC uses NCSCOS with NC.M prefix | Always use NC.M prefix |
| Generic Southern context | NC has distinct geography and data | Use Outer Banks, Charlotte, Blue Ridge, NC agriculture |
| Including high school grades | NC EOG Math is Grades 3–8 | Restrict to tested grades |
| MS with 4+ correct answers | NC MS items typically have 2–3 correct | Design MS with 2–3 correct from 5–6 options |

## 12. Prompt Patterns

### Pattern 1: Contextual Computation (MC, DOK 2)
> "[North Carolina context]. [Student/person] needs to find [quantity]. What is [quantity]?"

### Pattern 2: Numeric Entry (Gridded, DOK 1–2)
> "[NC context with given information]. [Question requiring computation]. Enter your answer."

### Pattern 3: Equivalent Representations (MS, DOK 2)
> "Select ALL [expressions / equations / values] that are equivalent to [given value or expression]."

### Pattern 4: Data Interpretation (MC, DOK 2)
> "[Data table or graph from NC context]. Based on the data, which [statement / value] is correct?"

### Pattern 5: Rate and Proportion (MC or Gridded, DOK 2)
> "A [NC context — distance, growth, production rate]. At this rate, [how long / how much / what distance]?"

### Pattern 6: Error Identification (MC, DOK 3)
> "[Student name] solved the following problem and got [incorrect answer]. Which describes the error [student] made?"
