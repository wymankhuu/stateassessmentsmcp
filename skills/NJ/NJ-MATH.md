## 1. Overview

| Field | Detail |
|---|---|
| **Assessment Name** | New Jersey Student Learning Assessments (NJSLA) — Mathematics |
| **Administering Agency** | New Jersey Department of Education (NJDOE) |
| **Vendor** | Cognia |
| **Grades Tested** | 3, 4, 5, 6, 7, 8, 11 |
| **Testing Window** | April – May |
| **Delivery** | Computer-based; multi-session test |
| **Standards** | New Jersey Student Learning Standards for Mathematics (NJSLS-Math) |
| **Score Scale** | 650–850 scale score (varies by grade); 5 performance levels |
| **Reporting** | Individual Student Report; School, District, State aggregates |

> **NJSLA and PARCC:** NJSLA Mathematics is derived from the **Partnership for Assessment of Readiness for College and Careers (PARCC)** design. Key differences from SBAC-based assessments: NJSLA organizes content by **Major, Supporting, and Additional content clusters** rather than SBAC's four-claim structure. Item types include Type I (machine-scored), Type II (reasoning), and Type III (modeling) tasks. Session 1 is non-calculator; Sessions 2–3 permit calculator use.

### Performance Levels

| Level | Label | Description |
|---|---|---|
| 5 | **Exceeded Expectations** | Distinguished command of mathematical concepts; applies mathematics flexibly in novel and complex situations |
| 4 | **Met Expectations** | Strong command of mathematical concepts; applies mathematics effectively to real-world and mathematical problems |
| 3 | **Approached Expectations** | Moderate command; applies procedures in familiar contexts but inconsistent with novel or multi-step problems |
| 2 | **Partially Met Expectations** | Partial command; demonstrates some procedural skill but limited conceptual understanding |
| 1 | **Did Not Yet Meet Expectations** | Minimal command; significant conceptual and procedural gaps |

## 3. Test Structure

NJSLA Mathematics uses PARCC-derived task types organized into sessions. Session 1 is non-calculator; subsequent sessions permit calculator use.

```
+------------------------------------------------------------------+
|          NJSLA MATHEMATICS STRUCTURE (Grades 3–8, 11)            |
+------------------------------------------------------------------+
|  SESSION 1 — Non-Calculator                                       |
|  ~60–75 minutes                                                   |
|  Type I items (machine-scored): SR, EQ, MS, TE                   |
|  Primarily Major content clusters                                 |
|  ~18–22 items                                                     |
|                                                                   |
+------------------------------------------------------------------+
|  SESSION 2 — Calculator Allowed                                   |
|  ~60–75 minutes                                                   |
|  Type I items (machine-scored): SR, EQ, MS, TE                   |
|  Type II items (Reasoning): SCR (0–2 pts)                        |
|  ~18–22 items                                                     |
|                                                                   |
+------------------------------------------------------------------+
|  SESSION 3 — Calculator Allowed (Grades 6–8, 11)                 |
|  ~60–75 minutes                                                   |
|  Type III items (Modeling): Extended Constructed Response (ECR)   |
|  Multi-part real-world problems (0–6 pts)                        |
|  ~4–6 items                                                       |
|                                                                   |
+------------------------------------------------------------------+
```

### PARCC-Derived Task Types

| Task Type | Description | Points | Scored | Session |
|---|---|---|---|---|
| **Type I** — Machine-Scored | SR, EQ, MS, TE — concepts and procedures | 1–2 | Machine | 1 and 2 |
| **Type II** — Reasoning (SCR) | Short constructed response requiring justification | 0–2 | Human | 2 |
| **Type III** — Modeling (ECR) | Extended constructed response; multi-part real-world modeling | 0–6 | Human | 3 |

### Item Type Summary

| Item Type | Abbreviation | Points | Scored | Session |
|---|---|---|---|---|
| Selected Response | SR | 1 | Machine | 1 and 2 |
| Equation/Numeric Entry | EQ | 1 | Machine | 1 and 2 |
| Multi-Select Response | MS | 1 | Machine | 1 and 2 |
| Technology Enhanced | TE | 1–2 | Machine | 2 |
| Short Constructed Response | SCR | 0–2 | Human | 2 |
| Extended Constructed Response | ECR | 0–6 | Human | 3 |

### Grade-Level Test Specifications

| Grade | Session 1 Items | Session 2 Items | Session 3 Items | Total Approx. Points |
|---|---|---|---|---|
| 3–5 | ~18–20 | ~16–20 | — | ~36–42 |
| 6–8 | ~18–22 | ~18–20 | ~4–6 | ~46–54 |
| 11 | ~18–22 | ~18–20 | ~4–6 | ~46–54 |

> **Note:** Grades 3–5 typically have two sessions. Session 3 with Type III modeling items is introduced at Grade 6.

## 4. Claims & Blueprint

### Content Cluster Weightings (PARCC-Derived)

| Cluster | Weight | Description |
|---|---|---|
| **Major** | ~65–70% | Core grade-level content that is essential for college and career readiness |
| **Supporting** | ~15–20% | Content that supports and strengthens the Major clusters |
| **Additional** | ~10–15% | Content that extends mathematical understanding beyond the Major focus |

> **Key difference from SBAC:** NJSLA does not use a four-claim structure (Concepts & Procedures / Problem Solving / Reasoning / Modeling). Instead, content is organized by Major, Supporting, and Additional clusters. However, the three PARCC task types (I, II, III) map loosely: Type I = procedures, Type II = reasoning, Type III = modeling.

### DOK Distribution

| DOK Level | Description | Approximate % |
|---|---|---|
| DOK 1 | Recall; compute; identify | ~20% |
| DOK 2 | Apply; solve in context; connect representations | ~55–60% |
| DOK 3 | Analyze; multi-step reasoning; justify | ~20–25% |

### Session-to-Task-Type Mapping

| Session | Primary Task Types |
|---|---|
| Session 1 (Non-Calculator) | Type I — Concepts & Procedures (Major clusters) |
| Session 2 (Calculator) | Type I — Concepts & Procedures; Type II — Reasoning |
| Session 3 (Calculator, Gr 6+) | Type III — Modeling (multi-part ECR) |

## 5. Item Types & Formats

### Selected Response (SR)

```
+----------------------------------------------------------+
|  SELECTED RESPONSE — 1 point                             |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Real-world or mathematical context                      |
|  Machine scored                                          |
|  DOK 1–3                                                 |
+----------------------------------------------------------+
```

**SR Example (Grade 7, DOK 2, NJSLS.Math.7.RP.A.2):**

A food stand on the Atlantic City Boardwalk sells 4 bags of saltwater taffy for $10.00. At this rate, how much would 7 bags cost?

A. $15.50
B. $17.00
C. $17.50
D. $20.00

*Correct Answer: C*
*Alignment: NJSLS.Math.7.RP.A.2 | Major Cluster | Type I | DOK 2*

---

### Equation/Numeric Entry (EQ)

```
+----------------------------------------------------------+
|  EQUATION / NUMERIC ENTRY — 1 point                      |
|                                                          |
|  Student types numeric answer or expression              |
|  No answer choices provided                              |
|  Machine scored                                          |
|  DOK 1–2                                                 |
+----------------------------------------------------------+
```

**EQ Example (Grade 5, DOK 2, NJSLS.Math.5.NF.A.1):**

A recipe for NJ corn chowder requires 3/4 cup of cream and 1/3 cup of butter. How many cups of dairy ingredients are needed in total?

Enter your answer as a fraction: **13/12**

*Alignment: NJSLS.Math.5.NF.A.1 | Major Cluster | Type I | DOK 2*

---

### Multi-Select Response (MS)

```
+----------------------------------------------------------+
|  MULTI-SELECT RESPONSE — 1 point                         |
|                                                          |
|  5–6 options; select ALL correct answers (typically 2–3) |
|  Full credit only; partial credit not awarded            |
|  Machine scored                                          |
+----------------------------------------------------------+
```

**MS Example (Grade 8, DOK 2, NJSLS.Math.8.EE.C.8):**

Select ALL systems of equations that have the solution (3, 4).

A. y = 2x − 2; y = x + 1
B. y = x + 1; y = −x + 7
C. y = 3x − 5; y = −2x + 10
D. y = 4; y = x + 1
E. y = 2x − 2; y = −x + 7

*Correct Answers: B, C, E*
*Alignment: NJSLS.Math.8.EE.C.8 | Major Cluster | Type I | DOK 2*

---

### Short Constructed Response (SCR) — Type II

```
+----------------------------------------------------------+
|  SHORT CONSTRUCTED RESPONSE — 0–2 points                 |
|  (Type II — Reasoning)                                   |
|                                                          |
|  Explain reasoning in 2–4 sentences                      |
|  Show work required for full credit                      |
|  Human scored                                            |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**SCR Example (Grade 6, DOK 3, NJSLS.Math.6.RP.A.3):**

A school in Trenton, New Jersey is planning a field trip to the NJ State Museum. The school has a budget of $525 for admission. The admission price is $7.50 per student. How many students can attend within the budget? Show your work and explain how you found your answer.

*Scoring:*
- *2 pts: Correct answer (70 students) with clear division work shown; explanation demonstrates understanding of rate reasoning*
- *1 pt: Correct approach with minor arithmetic error, OR correct answer without process shown*
- *0 pts: Incorrect approach or blank*

## 7. Mathematical Representations

NJSLA Mathematics frequently requires students to connect multiple representations.

### Representation Types

| Representation | Description | Common NJSLA Use |
|---|---|---|
| **Numeric** | Numbers, fractions, decimals, percents | Computation; comparison |
| **Algebraic** | Equations, expressions, inequalities | Solve; simplify; write |
| **Tabular** | Input/output tables; data tables | Identify patterns; find missing values |
| **Graphical** | Coordinate plane; graphs | Plot points; identify relationships |
| **Verbal** | Word problems; explanations | Apply to context; justify reasoning |

### Calculator Use by Session

| Session | Calculator Policy |
|---|---|
| Session 1 | **No calculator** — Items designed for mental math or standard algorithms |
| Session 2 | **Four-function calculator** available (online tool); scientific calculator for Grades 7–8 and 11 |
| Session 3 | **Calculator available** — Modeling items may involve complex computation |

## 8. Scoring Rubrics

### Short Constructed Response (SCR) Rubric — Type II — 0–2 Points

| Score | Criteria |
|---|---|
| 2 | Correct solution with clear mathematical reasoning. Work shown systematically. Appropriate mathematical vocabulary used. Explanation demonstrates conceptual understanding. |
| 1 | Partial understanding with minor errors. Correct approach demonstrated even if the final answer contains a computational error. OR Correct answer given without sufficient explanation or work. |
| 0 | Response is incorrect, shows no understanding, or is blank. |

### Extended Constructed Response (ECR) Rubric — Type III — 0–6 Points

| Score | Criteria |
|---|---|
| 6 | All parts correct with clear, complete mathematical reasoning. Work shown systematically. All explanations accurate and complete. Model is appropriate and well-justified. |
| 5 | All parts essentially correct. Minor computational or notational error does not affect overall reasoning. |
| 4 | Correct approach throughout. One significant error or one part incorrect; reasoning otherwise sound. |
| 3 | Correct approach on majority of parts. Multiple minor errors or one major error; some reasoning present. |
| 2 | Partial understanding. Correct approach on at least one part; some valid mathematical work. |
| 1 | Minimal understanding shown. Some relevant mathematical work attempted. |
| 0 | Incorrect, irrelevant, or blank. |

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] NJSLS standard code is accurate and grade-appropriate
- [ ] Session assignment is correct (calculator vs. non-calculator)
- [ ] Task type alignment matches (Type I = procedures, Type II = reasoning, Type III = modeling)
- [ ] Content cluster identified (Major, Supporting, or Additional)
- [ ] SCR items (Type II) require work to be shown (not just a final answer)
- [ ] ECR items (Type III) have exactly three parts of increasing complexity
- [ ] MS items specify "ALL" or number of correct answers
- [ ] New Jersey real-world context used where appropriate
- [ ] Distractors represent actual student computational or conceptual errors
- [ ] All computations verified before item is finalized
- [ ] DOK level matches the actual cognitive demand

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Calculator items in Session 1 | Session 1 is non-calculator | Design Session 1 items for mental math or standard algorithms |
| Using SBAC four-claim structure | NJSLA uses Major/Supporting/Additional clusters + Type I/II/III | Align to PARCC-derived cluster and task type system |
| SCR that only asks for an answer | SCR (Type II) must require explanation/justification | Add "Show your work and explain how you found your answer" |
| ECR with only one part | ECR (Type III) requires multi-part structure | Design 3 parts of increasing complexity and cognitive demand |
| Using CCSS codes without NJSLS prefix | NJ uses NJSLS prefix | Use NJSLS.Math for all standard codes |
| MS items with only 2 options total | Too few options make guessing easy | Use 5–6 options with exactly 2–3 correct |
| Missing Grade 11 | NJSLA tests Grade 11 | Include Grade 11 high school standards |

## 12. Prompt Patterns

### Pattern 1: Real-World Application — Type I (SR, DOK 2)
> "[NJ context]. [Multi-step problem requiring application of concept]. What is [answer]?"

### Pattern 2: Justify and Explain — Type II (SCR, DOK 3)
> "[NJ scenario requiring strategic thinking]. [Multi-step problem]. Show your work and explain how you found your answer."

### Pattern 3: Equivalent Representations — Type I (MS, DOK 2)
> "Select ALL [expressions / equations / graphs / representations] that are equivalent to [given value or expression]."

### Pattern 4: Linear Relationship — Type I or II (SR or SCR, DOK 2–3)
> "The [table / graph] shows [NJ data context]. What is the [rate of change / slope / equation] that represents this relationship? / Is this relationship proportional or non-proportional? Justify your answer."

### Pattern 5: Multi-Part Modeling — Type III (ECR, DOK 3)
> "Part A: [Direct calculation]. Part B: [Extension or comparison]. Part C: [Justify whether... / Evaluate if this is reasonable using mathematics]."

### Pattern 6: Comparison and Reasoning — Type II (SCR or SR, DOK 3)
> "Two students solved this problem differently. Student A says [method/answer]. Student B says [method/answer]. Who is correct? Use mathematics to justify your answer."
