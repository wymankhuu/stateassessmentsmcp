## 1. Overview

| Field | Details |
|---|---|
| **State** | Pennsylvania |
| **Assessment Name** | Pennsylvania System of School Assessment (PSSA) — English Language Arts/Literacy |

| Level | Name | Description |
|---|---|---|

| 2 | Basic | Approaching proficiency; inconsistent performance |
| 1 | Below Basic | Does not demonstrate minimum proficiency |

## 3. Test Structure

PSSA ELA is administered in two sessions over two days.

```
+------------------------------------------------------------------+
|           PSSA ELA STRUCTURE (Grades 3–8)                        |
+------------------------------------------------------------------+
|  SESSION 1 (Day 1) — ~90 minutes                                 |
|  ┌────────────────────────────────────────┐                      |
|  │ LITERARY ANALYSIS TASK (LAT)           │                      |
|  │ • 2 literary passages                  │                      |
|  │ • Multiple-choice items                │                      |
|  │ • Short-answer items                   │                      |
|  │ • 1 Text-Dependent Analysis (TDA)      │                      |
|  │   written response (essay)             │                      |
|  └────────────────────────────────────────┘                      |
|                                                                   |
|  SESSION 2 (Day 2) — ~90 minutes                                 |

|  │ NARRATIVE TASK (NT) OR                 │                      |

+------------------------------------------------------------------+
```

## 5. Item Types & Formats

### Multiple Choice (MC) — 1 Point

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Always passage-dependent                                |
|  Machine scored                                          |
|  DOK 1–3                                                 |
+----------------------------------------------------------+
```

**MC Example (Grade 6, Literary, DOK 2, CC.1.3.6-8.A):**

*[After reading a short story set in rural Pennsylvania]*

What theme does this story develop?

A. People should always follow their parents' advice
B. Hard work alone cannot guarantee success
C. Perseverance in the face of setbacks leads to personal growth
D. Friendship is more important than achievement

*Correct Answer: C*
*Alignment: CC.1.3.6-8.A | DOK 2*

---

### Short Answer (SA) — 0–2 Points

```
+----------------------------------------------------------+
|  SHORT ANSWER — 0–2 points                               |
|                                                          |
|  Brief written response (2–4 sentences)                  |
|  Must cite textual evidence                              |
|  Human scored                                            |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**SA Example (Grade 7, Informational, DOK 3, CC.1.2.6-8.H):**

*[After reading an article about Pennsylvania's steel industry decline]*

Explain how the author uses specific evidence to develop the argument that communities must diversify economically. Use details from the text to support your response.

---

### Text-Dependent Analysis (TDA) — 0–4 Points

```
+----------------------------------------------------------+
|  TEXT-DEPENDENT ANALYSIS (TDA) — 0–4 points             |
|                                                          |
|  Extended written response (multi-paragraph essay)       |
|  Must use textual evidence from assigned passage(s)      |
|  Human scored using holistic rubric                      |
|  DOK 4                                                   |
|  Grades 3–8                                              |
+----------------------------------------------------------+
```

**TDA Prompt Example (Grade 8, LAT):**

*[After reading two paired literary texts]*

How do the authors of both texts use figurative language to develop the central theme? Use evidence from both texts to support your analysis.

## 8. Scoring Rubrics

### Short Answer (SA) Rubric — 0–2 Points

| Score | Criteria |
|---|---|
| 2 | Accurate, specific response addressing the question. Includes directly relevant textual evidence (quoted or paraphrased) that clearly supports the response. |
| 1 | Partially accurate response. OR Accurate response without sufficient or directly relevant textual evidence. |
| 0 | Inaccurate, irrelevant, too brief to evaluate, or blank. |

### Text-Dependent Analysis (TDA) Rubric — 0–4 Points

| Score | Criteria |
|---|---|
| 4 | Response provides an accurate, text-based analysis that fully addresses the prompt. Uses specific, relevant evidence from the text(s) in a well-organized, developed essay. Demonstrates clear understanding of the text(s). Writing shows command of language and conventions. |
| 3 | Response provides an accurate analysis that mostly addresses the prompt. Uses relevant evidence, though elaboration may be uneven. Organization is evident. Minor errors in conventions. |
| 2 | Response provides a partial analysis. Evidence may be limited, vague, or only partially relevant. Some organization. Noticeable convention errors. |
| 1 | Response attempts to address the prompt but analysis is minimal or largely inaccurate. Little or no textual evidence. Weak organization and frequent errors. |
| 0 | Response is blank, off-task, entirely copied from the passage, or too brief to evaluate. |

```
DOK LEVEL: 2

Title: [PASSAGE_TITLE]

[DOK 2: Infer / explain / identify using passage evidence]

OPTIONS:
A [Distractor — plausible but unsupported by text]
B [CORRECT — requires inference from passage evidence]
C [Distractor — literal/surface reading; misses inference]
D [Distractor — correct domain, wrong interpretation]

CORRECT ANSWER: B
```

```
ITEM TEMPLATE: Short Answer (DOK 3)
-------------------------------------
TARGET STANDARD: CC.1.2.[GRADE].[LETTER] or CC.1.3.[GRADE].[LETTER]
DOK LEVEL: 3
POINT VALUE: 0–2 points

"[Explain / Analyze / Evaluate] how [AUTHOR/TEXT] [develops /
 uses / establishes] [THEME / ARGUMENT / CRAFT ELEMENT].
```

### Template C: Text-Dependent Analysis Essay (DOK 4)

```
ITEM TEMPLATE: TDA Essay (DOK 4)
----------------------------------

POINT VALUE: 0–4 points

```

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] PA Core standard code verified for the targeted grade
- [ ] MC items are passage-dependent; no general knowledge items
- [ ] SA prompt requires textual evidence explicitly
- [ ] TDA prompt requires cross-text or deep single-text analysis
- [ ] TDA prompt is open enough for multiple valid interpretations
- [ ] Passage Lexile falls within grade-level range
- [ ] Passages are paired appropriately for LAT or RST task context
- [ ] Distractors represent plausible misconceptions, not trick questions
- [ ] TDA scored using 0–4 holistic rubric
- [ ] Pennsylvania context incorporated where appropriate

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| MC items answerable from prior knowledge | All PSSA ELA items must be text-dependent | Tie every stem to a specific passage |
| SA without explicit evidence requirement | SA requires textual evidence | Include "use evidence from the text" in every SA prompt |
| TDA prompt with a narrow correct answer | TDA should allow multiple valid analytic positions | Ensure prompt invites interpretation, not just recall |
| Using CCSS codes instead of PA Core codes | PSSA uses PA Core standards | Use CC.1.2, CC.1.3, CC.1.4 codes |
| Ignoring paired-passage structure | PSSA tasks use passage sets, not isolated passages | Always design items referencing the full passage set |

## 12. Prompt Patterns

### Pattern 1: Literary Analysis — Theme (MC or SA, DOK 2–3)
> "How does [AUTHOR/TEXT] develop the theme that [THEME STATEMENT]? What [details / events / language choices] contribute to this theme?"

### Pattern 2: Informational — Central Idea and Evidence (MC or SA, DOK 2–3)
> "What is the central idea of [PASSAGE]? How does the author use [evidence / examples / structure] to develop this idea?"

### Pattern 3: Author's Craft — Figurative Language / Structure (MC, DOK 3)
> "How does the author's use of [figurative language / text structure / point of view] in [PASSAGE] contribute to [meaning / tone / theme]?"

### Pattern 4: Vocabulary in Context (MC, DOK 2)
> "As used in paragraph [#], what does the word [TARGET_WORD] most nearly mean?"

### Pattern 5: Cross-Text Comparison — TDA Essay (DOK 4)
> "How do both authors use [CRAFT/STRUCTURAL ELEMENT] to develop [THEME/CENTRAL IDEA]? Use evidence from both texts."

### Pattern 6: Research Synthesis — TDA Essay (DOK 4)
> "Using evidence from all [two/three] sources, explain [CENTRAL QUESTION]. Synthesize information from each source in your response."

### Pattern 7: Argument Evaluation (SA or MC, DOK 3)
> "How does the author of [PASSAGE] support the claim that [CLAIM]? Evaluate the strength of the evidence provided."
