## 1. Overview

| Field | Detail |
|---|---|
| **Assessment Name** | Pennsylvania System of School Assessment (PSSA) — Mathematics |
| **Administering Agency** | Pennsylvania Department of Education (PDE) |
| **Vendor** | Data Recognition Corporation (DRC) |

| **Delivery** | Computer-based and paper-based |
| **Standards** | Pennsylvania Core Standards for Mathematics (PA Core, aligned to CCSS-Math) |
| **Score Scale** | Scale score; 4 performance levels |

> **PSSA and PA Core Standards:** PSSA Mathematics is aligned to the Pennsylvania Core Standards, which are based on the Common Core State Standards for Mathematics (CCSS-Math). PA Core standard codes use a "CC.2.X" prefix (e.g., CC.2.1.5.B.1 for Grade 5 Number & Operations). The assessment consists of 2 sessions administered over 2 days. Calculators are permitted in Grades 6–8 only.

### Performance Levels

| Level | Label | Description |
|---|---|---|
| 4 | **Advanced** | Superior academic performance; demonstrates in-depth understanding and applies mathematical concepts in complex and novel situations |
| 3 | **Proficient** | Satisfactory academic performance; demonstrates adequate understanding and applies mathematical concepts appropriately |
| 2 | **Basic** | Marginal academic performance; demonstrates partial understanding of mathematical concepts with inconsistent application |
| 1 | **Below Basic** | Inadequate academic performance; demonstrates minimal understanding of mathematical concepts and fundamental skill gaps |

## 3. Test Structure

PSSA Mathematics is a two-session assessment administered over 2 days. Calculators are not permitted in Grades 3–5. In Grades 6–8, students may use calculators for both sessions.

```
+------------------------------------------------------------------+
|           PSSA MATHEMATICS STRUCTURE (Grades 3–8)                |
+------------------------------------------------------------------+
|  SESSION 1 — Day 1                                               |
|  ~60 minutes                                                     |
|  Mix of reporting categories                                     |
|  Item types: MC, TEI, CR                                         |
|  ~20–25 items                                                    |
|                                                                  |
+------------------------------------------------------------------+
|  SESSION 2 — Day 2                                               |
|  ~60 minutes                                                     |
|  Mix of reporting categories                                     |
|  Item types: MC, TEI, CR                                         |
|  ~20–25 items                                                    |
+------------------------------------------------------------------+
|  CALCULATOR POLICY:                                              |
|  Grades 3–5: No calculators permitted                            |
|  Grades 6–8: Calculators permitted (both sessions)               |
+------------------------------------------------------------------+
```

## 5. Item Types & Formats

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                               |
|                                                          |
|  4 options (A, B, C, D)                                  |
|  Real-world or mathematical context                      |
|  Machine scored                                          |
|  DOK 1–2                                                 |
+----------------------------------------------------------+
```

**MC Example (Grade 6, DOK 2, CC.2.1.6.D.1):**

A farmer near Lancaster, Pennsylvania sells 5 bushels of corn for $22.50 at a local market. At this rate, how much would 12 bushels cost?

A. $45.00
B. $49.50
C. $54.00
D. $57.50

*Correct Answer: C*
*Alignment: CC.2.1.6.D.1 | Numbers & Operations | DOK 2*

**TEI Example (Grade 8, DOK 2, CC.2.2.8.C.1):**

Drag each equation into the correct column to classify it as a linear function or a non-linear function.

| Linear Function | Non-linear Function |
|---|---|
| [drop zone] | [drop zone] |

Equations: y = 3x + 7 | y = x^2 - 4 | y = -2x | y = 5/x | y = 0.5x - 1

*Correct Classification: Linear: y = 3x + 7, y = -2x, y = 0.5x - 1 | Non-linear: y = x^2 - 4, y = 5/x*
*Alignment: CC.2.2.8.C.1 | Algebraic Concepts | DOK 2*

### Constructed Response — Short (CR-short)

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE (SHORT) — 0–1 point                |
|                                                          |
|  Brief numerical answer or short explanation             |
|  Show work or provide a brief justification              |
|  Human scored                                            |
|  DOK 1–2                                                 |
+----------------------------------------------------------+
```

**CR-short Example (Grade 4, DOK 2, CC.2.1.4.C.1):**

A recipe from a bakery in Pittsburgh calls for 3/8 cup of sugar. Maria says that 3/8 is the same as 6/16. Is Maria correct? Show or explain how you know.

*Scoring:*
- *1 pt: Student correctly identifies that Maria is correct and provides a valid justification (e.g., multiplying numerator and denominator by 2, drawing equivalent fraction models)*
- *0 pts: Incorrect answer or no valid explanation*

### Constructed Response — Extended (CR-extended)

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE (EXTENDED) — 0–4 points            |
|                                                          |
|  Multi-step problem with work and written justification  |
|  Requires explanation of mathematical reasoning          |
|  Human scored                                            |
|  DOK 2–3                                                 |
+----------------------------------------------------------+
```

**CR-extended Example (Grade 7, DOK 3, CC.2.1.7.D.1):**

A class is planning a field trip from their school in Harrisburg to the Pennsylvania State Museum. The bus company charges a flat fee of $150 plus $3.50 per student.

Part A: Write an equation that represents the total cost, C, for s students.

Part B: If the school has a budget of $430, what is the maximum number of students who can go on the trip? Show your work.

Part C: The teacher finds a second bus company that charges no flat fee but $8.00 per student. For what number of students would the two companies charge the same amount? Explain which company is the better deal for a group of 40 students and why.

## 7. Mathematical Representations

PSSA Mathematics requires students to work across multiple mathematical representations and translate between them.

### Representation Types

| Representation | Description | Common PSSA Use |
|---|---|---|
| **Numeric** | Numbers, fractions, decimals, percents, ratios | Computation; comparison; ordering |
| **Algebraic** | Equations, expressions, inequalities, functions | Solve; simplify; write; evaluate |
| **Tabular** | Input/output tables; data tables; frequency tables | Identify patterns; find missing values; organize data |
| **Graphical** | Coordinate plane; bar graphs; line plots; circle graphs | Plot points; interpret relationships; display data |
| **Verbal** | Word problems; written explanations; justifications | Apply to context; justify reasoning; communicate solutions |

### Calculator Policy by Grade

| Grade | Calculator Policy |
|---|---|
| Grade 3 | **No calculator** — All items designed for mental math, manipulatives, or standard algorithms |
| Grade 4 | **No calculator** — All items designed for mental math or standard algorithms |
| Grade 5 | **No calculator** — All items designed for mental math or standard algorithms |
| Grade 6 | **Calculator permitted** — Standard calculator allowed for both sessions |
| Grade 7 | **Calculator permitted** — Standard calculator allowed for both sessions |
| Grade 8 | **Calculator permitted** — Standard calculator allowed for both sessions |

> **Note:** Even in Grades 6–8, items are designed so that calculator use is a strategic choice, not a requirement for every problem. Some items intentionally assess computational fluency and mental math skills.

## 8. Scoring Rubrics

### Constructed Response (Short) Rubric — 0–1 Point

| Score | Criteria |
|---|---|
| 1 | Correct solution with adequate work or explanation shown. Response demonstrates understanding of the mathematical concept. |
| 0 | Incorrect solution, insufficient work shown, no understanding demonstrated, or blank. |

### Constructed Response (Extended) Rubric — 0–4 Points

| Score | Criteria |
|---|---|
| 4 | Complete and correct response. All parts answered with clear, systematic mathematical work. Explanation demonstrates thorough understanding. All calculations are accurate. Justification is complete and uses appropriate mathematical reasoning. |
| 3 | Nearly complete response. Correct approach throughout with minor computational or notational errors that do not significantly affect reasoning. Most parts answered correctly. Explanation demonstrates solid understanding. |
| 2 | Partial response. Correct approach on some parts but contains significant errors or omissions. Some valid mathematical work shown. Explanation demonstrates partial understanding of the concept. |
| 1 | Minimal response. Limited mathematical understanding shown. Attempt at a relevant approach with major errors. Some related mathematical work present but largely incomplete or incorrect. |
| 0 | Incorrect, irrelevant, or blank. No demonstration of mathematical understanding related to the task. |

## 10. Contextualization — Pennsylvania Mathematics

When generating problem contexts, use authentic Pennsylvania settings and scenarios:

### Pennsylvania Math Context Guide

| Context | Domain | Grade Band |
|---|---|---|
| Philadelphia landmarks (Liberty Bell, Independence Hall visitor counts) | Operations, Data Analysis | 3–6 |
| Pittsburgh bridges (lengths, spans, geometric shapes in architecture) | Geometry, Measurement | 4–8 |
| PA Turnpike travel (distances, tolls, fuel costs, travel times) | Rate, Proportionality, Operations | 5–8 |
| Pennsylvania farms and agriculture (crop yields, dairy production, acreage) | Ratio, Data Analysis, Measurement | 4–8 |
| Hershey chocolate production (recipes, ratios, packaging, factory output) | Ratio, Proportion, Fractions, Operations | 3–7 |
| Coal mining history (production data, depth measurements, historical statistics) | Data Analysis, Measurement, Operations | 5–8 |
| Susquehanna River (length, watershed area, water flow rates, flooding data) | Measurement, Rate, Data Analysis | 5–8 |
| Pennsylvania state parks (trail distances, campsite areas, elevation changes) | Geometry, Measurement | 4–7 |

| Pennsylvania weather patterns (temperature ranges, snowfall data, precipitation) | Statistics, Data Analysis | 4–8 |

### Context Integration Guidelines

- Use Pennsylvania city and town names (Philadelphia, Pittsburgh, Harrisburg, Erie, Allentown, Lancaster, Scranton)
- Reference real Pennsylvania geographic features (Appalachian Mountains, Delaware River, Lake Erie, Susquehanna River)
- Include culturally relevant events (Pennsylvania Dutch festivals, Groundhog Day in Punxsutawney, Philadelphia Flower Show)
- Ensure numerical values are realistic and grade-appropriate
- Avoid contexts requiring specialized local knowledge not provided in the problem stem

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] PA Core standard code is accurate and grade-appropriate (CC.2.X format)
- [ ] Calculator policy matches grade level (no calculator Grades 3–5; permitted Grades 6–8)
- [ ] Reporting category alignment is correct (A = Numbers & Operations, B = Algebraic Concepts, C = Geometry, D = Measurement, Data & Probability)
- [ ] CR-extended items require multi-step work and written justification
- [ ] CR-short items require brief work or explanation for 0–1 scoring
- [ ] TEI interaction type is specified (drag-and-drop, multi-select, drop-down, etc.)
- [ ] Pennsylvania real-world context used where appropriate
- [ ] MC distractors represent actual student computational or conceptual errors
- [ ] All computations verified before item is finalized
- [ ] DOK level matches the actual cognitive demand of the item
- [ ] Blueprint weights respected (~30% A, ~30% B, ~20% C, ~20% D)
- [ ] DOK distribution aligned (~15% DOK 1, ~55% DOK 2, ~25% DOK 3, ~5% DOK 4)

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Calculator in Grades 3–5 | Grades 3–5 do not permit calculators | Design items for mental math or standard algorithms at these grades |
| CR-extended scored as 0–2 | Extended CR uses a 0–4 rubric | Use the full 0–4 rubric; reserve 0–1 for CR-short items only |
| Using CCSS codes without PA Core format | PA uses CC.2.X prefix, not CCSS.Math | Convert all codes to CC.2.X.Grade.Strand format |
| MC items with only 3 options | PSSA MC requires 4 answer choices | Always provide options A, B, C, D |
| DOK 1 items dominating the set | PSSA targets ~55% DOK 2 | Ensure majority of items require application, not just recall |
| TEI items without interaction specification | PSSA TEI can be drag-and-drop, multi-select, etc. | Always specify the interaction type in the item design |
| Context-free CR items | CR items benefit from real-world application | Add Pennsylvania-relevant context to elevate engagement and authenticity |
| Unrealistic numerical values in context | Numbers must be plausible for the scenario | Verify that quantities, prices, and measurements are realistic |

## 12. Prompt Patterns

### Pattern 1: Real-World Application (MC, DOK 2)
> "[Pennsylvania context — e.g., a farm in Lancaster County]. [Multi-step problem requiring application of a mathematical concept]. What is [answer]?"

### Pattern 2: Show and Explain (CR-short, DOK 2)
> "[Pennsylvania scenario with a mathematical claim or result]. Is [claim] correct? Show or explain how you know."

### Pattern 3: Multi-Part Problem Solving (CR-extended, DOK 3)
> "Part A: [Direct calculation or setup using Pennsylvania context]. Show your work. Part B: [Extension or comparison]. Show your work. Part C: [Justify which option is better / Explain whether the result is reasonable]. Use mathematics to support your answer."

### Pattern 4: Classification and Sorting (TEI, DOK 2)
> "[Drag / Select / Sort] each [mathematical object] into the correct [category / column / group] based on [property or rule]."

### Pattern 5: Data Interpretation (MC or CR-short, DOK 2)
> "The [table / graph / chart] shows [Pennsylvania data context — e.g., average snowfall in Erie]. Based on the data, [question about comparison, trend, or calculation]."

### Pattern 6: Comparison and Reasoning (CR-extended, DOK 3)
> "Two students solved this problem differently. Student A says [method/answer]. Student B says [method/answer]. Who is correct? Use mathematics to justify your answer. Explain the error the other student made."

### Pattern 7: Proportional Reasoning in Context (MC or CR-extended, DOK 2–3)
> "[Pennsylvania rate/ratio scenario — e.g., toll costs on the PA Turnpike, chocolate production at Hershey]. If [given ratio], then [question requiring proportional reasoning]. [For CR: Show your work and explain your reasoning.]"
