## 1. Overview

| Field | Detail |
|---|---|
| **Assessment Name** | Delaware System of Student Assessments (DeSSA) — Mathematics |
| **Consortium** | Smarter Balanced Assessment Consortium (SBAC) |
| **Vendor** | Smarter Balanced (via Delaware Department of Education) |
| **Grades Tested** | 3, 4, 5, 6, 7, 8, 11 |
| **Testing Window** | Spring (March – May; schools schedule within this range) |
| **Delivery** | Computer-adaptive (CAT) for Part 1 (non-calculator + calculator); fixed-form Performance Task for Part 2 |
| **Standards** | Common Core State Standards for Mathematics (CCSS-M); Delaware Content Standards |
| **Score Scale** | 2000–3000 scale score (varies by grade) |
| **Reporting** | Individual Student Report (ISR); School, District, State aggregate reports via Delaware Report Card |

### Achievement Level Descriptors (ALDs)

| Level | Label | Description |
|---|---|---|
| 4 | **Standard Exceeded** | Student demonstrates sophisticated understanding of mathematical concepts and procedures; applies mathematics fluently in novel situations; constructs valid mathematical arguments |
| 3 | **Standard Met** | Student demonstrates adequate understanding of grade-level concepts and procedures; applies mathematics to real-world and mathematical problems with reasonable accuracy |
| 2 | **Standard Nearly Met** | Student demonstrates partial understanding; can apply procedures in familiar contexts but struggles with novel problems; mathematical explanations are incomplete |
| 1 | **Standard Not Met** | Student demonstrates minimal understanding; makes frequent errors in procedures; cannot explain mathematical reasoning; significant gaps in prerequisite skills |

> **Cut scores** are set by the Smarter Balanced Assessment Consortium and adopted by the Delaware Department of Education. For item-writing purposes, target ALDs 3 and 4 as the proficiency range.

## 2. Standards Framework

> **Reference:** See `_shared/ccss_math_framework.md` for full CCSS-M standards and grade-by-grade progressions. This section highlights the key domains and standards most heavily tested on the Delaware DeSSA Mathematics assessment.

### Grades 3–5: Key Content Domains

| Domain | Gr 3 Focus | Gr 4 Focus | Gr 5 Focus |
|---|---|---|---|
| **OA — Operations & Algebraic Thinking** | Multiply/divide within 100; two-step word problems | Multi-step word problems; factor pairs; patterns | Write and interpret numerical expressions; analyze patterns |
| **NBT — Number & Operations Base Ten** | Place value to 1,000; fluently add/subtract within 1,000 | Multi-digit arithmetic; place value to 1,000,000 | Decimal operations; powers of 10 |
| **NF — Number & Operations Fractions** | Unit fractions; fractions on number line | Equivalent fractions; add/subtract fractions; multiply fraction by whole | All fraction operations; relate fractions to decimals |
| **MD — Measurement & Data** | Area; perimeter; time; mass; volume | Measurement conversion; angle measurement | Volume; measurement conversion |
| **G — Geometry** | Properties of shapes; area and perimeter | Lines, angles, symmetry | Coordinate plane; classify 2D figures |

### Grades 6–8: Key Content Domains

| Domain | Gr 6 Focus | Gr 7 Focus | Gr 8 Focus |
|---|---|---|---|
| **RP — Ratios & Proportional Relationships** | Ratio concepts; unit rates | Proportional relationships; percent problems | (integrated into functions and geometry) |
| **NS — The Number System** | Divide fractions; rational numbers; coordinate plane | Rational number operations; absolute value | Irrational numbers; rational approximations |
| **EE — Expressions & Equations** | Evaluate and write expressions; one-step equations | Two-step equations and inequalities; equivalent expressions | Linear equations; systems of equations; exponents |
| **G — Geometry** | Area, surface area, volume | Scale drawings; cross-sections; angle relationships | Pythagorean theorem; transformations; volume of cylinders/cones/spheres |
| **SP — Statistics & Probability** | Statistical variability; distributions | Probability; sampling; comparing populations | Scatter plots; linear association; two-way tables |
| **F — Functions** | — | — | Define and compare functions; linear functions |

### Grade 11: Key Content Domains

| Domain | Focus |
|---|---|
| **Algebra** | Interpret structure of expressions; create equations; reasoning with equations and inequalities; polynomial and rational expressions |
| **Functions** | Interpret functions (domain, range, graphs); build functions; linear, quadratic, and exponential models; trigonometric functions (intro) |
| **Number & Quantity** | Extend properties of exponents to rational exponents; reason quantitatively with units |
| **Geometry** | Prove geometric theorems; apply trigonometry; geometric measurement (modeling with geometry) |
| **Statistics & Probability** | Interpret data; make inferences; use probability to evaluate outcomes of decisions |

## 5. Item Types & Formats

### SR — Selected Response (1 point)

Standard four-option multiple-choice. Student selects one best answer.

```
+-----------------------------------------------------------------+
|  [Stimulus: problem context, diagram, table, or equation]        |
|                                                                  |
|  Question stem targeting a specific standard and claim.          |
|                                                                  |
|  O  A. [Numerical / expression answer — plausible distractor]    |
|  O  B. [Numerical / expression answer — common error]            |
|  O  C. [Numerical / expression answer — CORRECT]                 |
|  O  D. [Numerical / expression answer — off-track distractor]    |
+-----------------------------------------------------------------+
Points: 1 (correct) / 0 (incorrect)
```

**Construction Rules:**
- Distractors must reflect real student errors (computational errors, conceptual mistakes, operation errors)
- Numerical answers should not reveal the correct answer through magnitude ordering
- Diagrams and tables must be clearly labeled and drawn to reasonable scale

---

### MS — Multi-Select (1 point)

Student selects ALL correct answers from a set of five or six options.

```
+-----------------------------------------------------------------+
|  [Problem context or mathematical statement]                     |
|                                                                  |
|  Select the TWO [equations / values / expressions] that...      |
|                                                                  |
|  [ ]  A. [Option]                                                |
|  [ ]  B. [Option — CORRECT]                                      |
|  [ ]  C. [Option]                                                |
|  [ ]  D. [Option — CORRECT]                                      |
|  [ ]  E. [Option]                                                |
|  [ ]  F. [Option]                                                |
+-----------------------------------------------------------------+
Points: 1 (all correct, none incorrect) / 0 (any error)
```

**Construction Rules:**
- Specify the count in the stem when fixed ("Select the TWO...")
- Use "Select ALL that apply" when count is variable
- Typically 2–3 correct answers from 5–6 options

---

### EQ — Equation / Numeric Entry (1 point)

Student types a number, expression, or short equation into a response box.

```
+-----------------------------------------------------------------+
|  [Problem context: real-world scenario or pure math]             |
|                                                                  |
|  What is the value of [EXPRESSION / VARIABLE / QUANTITY]?       |
|                                                                  |
|  Enter your answer in the box.                                   |
|  +---------------+                                               |
|  |               |  [numeric / expression entry field]          |
|  +---------------+                                               |
|  [Unit label if applicable]                                      |
+-----------------------------------------------------------------+
Points: 1 (exact correct value or equivalent expression) / 0
```

**Construction Rules:**
- Clearly state the expected form (whole number, decimal, fraction, simplified expression)
- Specify units when applicable
- Specify rounding rules when relevant

### SCR — Short Constructed Response (0–2 points)

Student writes a brief explanation or solution.

```
+-----------------------------------------------------------------+
|  [Problem context — multi-step real-world scenario]              |
|                                                                  |
|  [PART A — Computational or procedural question]                 |
|  [PART B — "Explain how you know" or "Show your work"]           |
|                                                                  |
|  +-----------------------------------------------------+        |
|  |  [Student response area — text input + scratchpad]    |        |
|  +-----------------------------------------------------+        |
+-----------------------------------------------------------------+
Points: 0–2 (see rubric, Section 8)
```

---

### PT-ER — Performance Task Extended Response (0–6 points, multi-part)

Complex real-world scenario with 3–5 interdependent sub-parts.

```
+-----------------------------------------------------------------+
|  PERFORMANCE TASK — EXTENDED RESPONSE                            |
|                                                                  |
|  SCENARIO:                                                       |
|  [3–5 sentence real-world context with data]                     |
|                                                                  |
|  Part A: [Introductory computation or setup]                     |
|  Part B: [Intermediate reasoning or application]                 |
|  Part C: [Complex extension — explain, justify, or evaluate]     |
+-----------------------------------------------------------------+
Points: 0–2 per part x 3 parts = 0–6 total
```

## 6. DOK / Cognitive Complexity

### DOK Level Descriptions for Mathematics

| DOK | Label | Description | Example Tasks |
|---|---|---|---|
| **1** | Recall & Reproduction | Recall a fact; perform a routine single-step procedure; read a value from a graph | *calculate, identify, recall, use, recognize, measure* |
| **2** | Skills & Concepts | Solve a multi-step problem; classify or organize information; make inferences from data; apply a concept in a straightforward context | *classify, organize, estimate, compare, interpret, solve [multi-step], apply* |
| **3** | Strategic Thinking | Solve non-routine problems requiring planning; justify a claim; analyze errors; design a mathematical model | *justify, prove, analyze, evaluate, formulate, critique, explain reasoning* |
| **4** | Extended Thinking | Conduct multi-stage investigations; synthesize across domains; design and evaluate complex models | *synthesize, design, evaluate [complex], connect, create* |

> DOK 4 appears primarily in PT Extended Response Part C items, not in individual CAT items.

### DOK Distribution Targets for Item Generation

| Item Type | Target DOK | Rationale |
|---|---|---|
| SR — single computation | 1 | Routine procedure, one step |
| SR — two-step word problem | 2 | Application; concept + computation |
| MS — identify equivalent forms | 1–2 | Depends on conceptual demand |
| EQ — numeric entry | 1–2 | Usually procedural; contextual use raises to DOK 2 |
| TE — graphing | 2 | Requires connecting representations |
| SCR — explain reasoning | 3 | Justification required; non-routine |
| PT-ER Part A | 2 | Setup computation within context |
| PT-ER Part B | 2–3 | Application or partial modeling |
| PT-ER Part C | 3–4 | Full modeling, justify, evaluate |

## 8. Scoring Rubrics

### SCR — Short Constructed Response (0–2 Points)

| Score | Descriptor |
|---|---|
| **2** | The response demonstrates thorough understanding. Correct solution with clear, accurate explanation or justification. Work shown is logical and complete. Minor arithmetic errors do not affect the score if reasoning is sound. |
| **1** | The response demonstrates partial understanding. Partially correct solution or correct solution with incomplete explanation. Computational error with otherwise sound reasoning. OR correct answer with no explanation. |
| **0** | The response is incorrect, irrelevant, or demonstrates no mathematical understanding. |

---

### PT-ER — Performance Task Extended Response (0–6 Points)

#### Part A Rubric (0–2 points)

| Score | Descriptor |
|---|---|
| **2** | Correctly sets up and solves the introductory problem. All calculations correct and clearly shown. Units correctly identified. |
| **1** | Correct approach but contains a computational error, incomplete solution, or missing unit. |
| **0** | Incorrect, missing, or demonstrates no understanding. |

#### Part B Rubric (0–2 points)

| Score | Descriptor |
|---|---|
| **2** | Correctly applies Part A results. Reasoning is clear; comparison or interpretation is accurate. |
| **1** | Partial understanding. May use incorrect Part A value but apply correct reasoning, OR correct conclusion through partially correct work. |
| **0** | Incorrect, missing, or shows no mathematical understanding. |

#### Part C Rubric (0–2 points)

| Score | Descriptor |
|---|---|
| **2** | Sophisticated mathematical reasoning. Accurately uses results to justify a decision or evaluate a model. Explanation is clear and mathematically sound. |
| **1** | Some correct reasoning or partially valid justification. May identify correct conclusion but provide insufficient support. |
| **0** | Incorrect, off-task, or provides only unsupported assertions. |

#### Error-Carried-Forward (ECF) Policy
When a student carries an incorrect value from Part A into Parts B and C, if their work is mathematically correct based on their Part A answer, award full credit for that part. ECF applies only when the error is computational, not conceptual.

## 10. Contextualization

### Delaware-Specific Mathematics Context Bank

Item writers should anchor scenarios in authentic Delaware contexts to maximize student engagement and ecological validity.

#### Delaware Bay Dimensions

| Topic | Mathematical Applications |
|---|---|
| **Delaware Bay measurements** | Area and perimeter calculations; the bay is approximately 52 miles long and 30 miles wide at its mouth; water volume estimates; proportional reasoning with tidal data; measurement conversion between miles and kilometers |
| **Tidal data analysis** | Rate of change; graphing tidal heights over time; average and extreme values; interpreting tide charts; functions (Gr 8, 11) |
| **Delaware Bay shipping lanes** | Distance-rate-time problems; navigation angles (Gr 11); scheduling and elapsed time; container volume calculations; Port of Wilmington cargo data |
| **Horseshoe crab population counts** | Data analysis; population sampling; percent change over time; graphing population trends; ratio of crabs to shorebirds during spawning season |

#### Beach Tourism Data

| Topic | Mathematical Applications |
|---|---|
| **Rehoboth Beach visitor statistics** | Large number operations; percent increase/decrease; seasonal comparison; data displays (bar, circle, line graphs); ~7 million annual visitors to Delaware beaches |
| **Beach rental pricing** | Unit rates; multi-step word problems; comparison shopping; percent markup; tax calculations; budgeting scenarios |
| **Hotel occupancy rates** | Percent; ratio; proportional reasoning; seasonal data comparison; creating and interpreting data displays |
| **Boardwalk vendor economics** | Revenue calculations; profit/loss; unit price; multi-step problems; percent of total revenue; Gr 6–8 equation writing |
| **Beach nourishment project costs** | Large numbers; unit costs (cost per cubic yard of sand); area and volume calculations; budget analysis; argumentative data interpretation |

#### Delaware Population Statistics

| Topic | Mathematical Applications |
|---|---|
| **DE population data** | Large number operations; percent change; data displays; proportional reasoning; Delaware's population of ~1 million; county-level comparisons (New Castle, Kent, Sussex) |
| **Population density** | Division; area calculations; comparing population density across Delaware's three counties; New Castle County (~550,000) vs. Sussex County (~240,000) vs. Kent County (~185,000) |
| **Wilmington metro statistics** | Percent composition; ratio; data analysis; urban vs. suburban growth patterns; employment data |
| **School enrollment trends** | Ratios; proportional reasoning; data analysis; bar and line graphs; per-pupil spending comparisons |
| **Sussex County growth rates** | Percent change; extrapolation; graphing growth over decades; comparing Sussex County's rapid growth to New Castle County stability |

### Grade-Band Contextualization Notes

#### Grades 3–5 Contextualization

| Principle | Guidance |
|---|---|
| **Concreteness** | Contexts should involve tangible quantities (shells collected at the beach, distance walked on a trail, items at a farmer's market) |
| **Accessibility** | Avoid specialized vocabulary or cultural knowledge that disadvantages EL students |
| **Scale of numbers** | Match number magnitude to grade-level standards |
| **Authenticity** | Delaware beach trip, state park visit, school fundraiser, Dover community event — familiar settings |

#### Grades 6–8 Contextualization

| Principle | Guidance |
|---|---|
| **Real data** | Use approximate real data (DE population ~1 million; Delaware Bay dimensions; beach visitor counts) |
| **Multiple representations** | Include tables, graphs, or diagrams alongside word problem contexts |
| **Social relevance** | Topics like tourism economics, environmental data, and community growth resonate with middle-school students |

#### Grade 11 Contextualization

| Principle | Guidance |
|---|---|
| **Workforce readiness** | Career-relevant contexts (banking/financial services in Wilmington, agriculture in Sussex County, healthcare, technology) |
| **Complex data** | Multi-variable data sets; scatter plots; regression; probability in real decision-making |
| **Equity lens** | Include data representing Delaware's diversity; avoid contexts that systematically advantage students from higher socioeconomic backgrounds |

### English Learner (EL) Considerations for Math

| Consideration | Guidance |
|---|---|
| **Mathematical vocabulary** | Pre-teach or define Tier 3 math vocabulary in a glossary; avoid confusing mathematical terms with everyday meanings |
| **Word problem language** | Use simple, direct sentence structure; avoid unnecessarily complex syntax |
| **Bilingual glossary** | EL designated support — mathematical terms in Spanish, Haitian Creole, and other home languages |
| **Diagrams and visuals** | Use clear, labeled diagrams to reduce linguistic load |

## 11. Quality Checklist

Use this checklist before finalizing any generated item or item set.

### Standards Alignment

- [ ] Item is tagged to one primary CCSS Math standard (e.g., 7.RP.A.2)
- [ ] Standard matches the claim and subclaim
- [ ] DOK level is consistent with the cognitive demand of the task
- [ ] Grade-level standard is appropriate for the intended grade band
- [ ] Item does not require knowledge of standards above or below grade level

### Calculator Policy

- [ ] Item is flagged as calculator or non-calculator consistent with grade-level policy (Section 3)
- [ ] Computational complexity is appropriate for the calculator policy
- [ ] Calculator-active items use numbers that would realistically benefit from a calculator

### Reference Sheet

- [ ] For Grades 8 and 11: item does not embed formulas that are on the reference sheet
- [ ] For Grades 3–7: item does not require formulas not taught at grade level
- [ ] Formula reference is given in the item when required for grades without a reference sheet

### Item Quality (All Types)

- [ ] Stem is a clear, unambiguous question or directive
- [ ] All numerical values are internally consistent
- [ ] Units are clearly specified and used correctly
- [ ] No "trick" questions
- [ ] Diagrams are clearly labeled, drawn to reasonable scale, and described in alt text
- [ ] Answer options for SR are plausible and represent specific student errors
- [ ] Correct answer is verified independently
- [ ] Word problem context is realistic and meaningful

### SCR and PT-ER Checks

- [ ] Constructed-response prompt requires both a numerical answer AND explanation
- [ ] Rubric is included with the item
- [ ] PT-ER parts are interdependent and logically sequenced (A -> B -> C)
- [ ] Error-carried-forward (ECF) policy is noted in the rubric
- [ ] Scoring guide anticipates common student errors

### EL and Accessibility

- [ ] Word problem language is clear and concise
- [ ] Mathematical vocabulary is appropriate for the grade
- [ ] Diagrams are usable by students using zoom or screen magnification
- [ ] Item does not require cultural knowledge that disadvantages EL students

## 12. Prompt Patterns

The following patterns map common user requests to generation strategies for the AI.

---

### Pattern 1: "Generate a math problem for Grade [X]"

**Interpretation:** Default to an SR item (1 point) for Claim 1 (Concepts & Procedures) at DOK 2. Use a real-world context from Section 10.

**Generation Recipe:**
1. Identify the primary content domain for the grade
2. Select a Delaware context from Section 10
3. Generate SR using Template 1, ensuring two mathematical steps
4. Construct four options where each distractor represents a distinct common error
5. Tag: state=DE, subject=MATH, grade=[X], claim=2, dok=2

---

### Pattern 2: "Generate a word problem that requires explanation"

**Interpretation:** Generate an SCR (0–2 points) for Claim 3 (Communicating Reasoning) at DOK 3. Use Template 2.

**Generation Recipe:**
1. Select a multi-step context appropriate for the grade (see Section 10)
2. Build Part A as the computational component (DOK 2)
3. Build Part B as the justification requirement (DOK 3)
4. Include a scoring guide (Section 8 rubric)
5. Tag: state=DE, subject=MATH, grade=[X], claim=3, dok=3

---

### Pattern 3: "Generate a Performance Task math problem for Grade [X]"

**Interpretation:** Generate a full PT-ER package using Template 3.
