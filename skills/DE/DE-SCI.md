## 1. Overview

| Field | Detail |
|---|---|
| **Assessment Name** | Delaware System of Student Assessments (DeSSA) — Science |
| **Framework** | Next Generation Science Standards (NGSS) — Three-Dimensional |
| **Vendor** | Delaware Department of Education |

| **Score Scale** | Scale score with four performance levels |

### Achievement Level Descriptors (ALDs)

| Level | Label | Description |
|---|---|---|
| 4 | **Distinguished** | Student demonstrates sophisticated, integrated understanding of disciplinary core ideas, science and engineering practices, and crosscutting concepts; applies three-dimensional reasoning to novel phenomena |
| 3 | **Proficient** | Student demonstrates adequate understanding of three-dimensional science; can use practices and crosscutting concepts to explain grade-level phenomena and solve problems |
| 2 | **Approaching Proficient** | Student demonstrates partial understanding; can identify relevant science ideas but struggles to integrate practices and crosscutting concepts |
| 1 | **Below Proficient** | Student demonstrates minimal understanding of disciplinary core ideas; limited ability to engage in science practices or apply crosscutting concepts |

> **Cut scores** are set by the Delaware Department of Education. For item-writing purposes, focus on ALDs 3 and 4 as the target proficiency range.

## 4. Claims & Blueprint

### Assessment Targets

Delaware DeSSA Science is organized around the three NGSS dimensions. For blueprint purposes, the assessment uses the following reporting categories:

| Reporting Category | Description | Approximate Weight | Dimensions Assessed |
|---|---|---|---|
| **Physical Science** | Properties of matter; forces and motion; energy; waves | **25–30%** | PS DCIs + SEPs + CCCs |
| **Life Science** | Ecosystems; heredity; evolution; organisms | **25–30%** | LS DCIs + SEPs + CCCs |
| **Earth and Space Science** | Earth's systems; Earth's place in universe; human activity | **25–30%** | ESS DCIs + SEPs + CCCs |
| **Engineering Design** | Defining problems; designing solutions; optimizing | **10–15%** | ETS DCIs + SEPs + CCCs |

| SEP | Description | Item Frequency |
|---|---|---|
| **SEP 1** — Asking Questions / Defining Problems | Formulate testable questions; define engineering constraints | Moderate |

| **SEP 4** — Analyzing and Interpreting Data | Use data tables, graphs, and statistical reasoning | High |

| **SEP 7** — Engaging in Argument from Evidence | Support claims with evidence; evaluate competing arguments | Moderate |

## 5. Item Types & Formats

### SR — Selected Response (1 point)

Standard four-option multiple-choice anchored to a phenomenon or data set.

```
+-----------------------------------------------------------------+
|  PHENOMENON / STIMULUS:                                          |
|  [Description of natural phenomenon, data table, diagram,       |
|   or experimental setup — 2–5 sentences or a labeled figure]    |
|                                                                  |
|  Question stem integrating a SEP and CCC with a DCI.            |
|                                                                  |
|  O  A. [Plausible distractor — common misconception]             |
|  O  B. [Correct answer — supported by evidence and reasoning]    |
|  O  C. [Plausible distractor — partially correct reasoning]      |
|  O  D. [Plausible distractor — incomplete understanding]         |
+-----------------------------------------------------------------+
Points: 1 (correct) / 0 (incorrect)
```

**Construction Rules:**
- Item must be anchored to an observable phenomenon or data set
- Stem must require application of at least one SEP (not just recall)
- Distractors should reflect documented student misconceptions
- Avoid "All of the above" / "None of the above"
- Correct answer must be defensible through three-dimensional reasoning

---

### MS — Multi-Select (1 point)

Student selects ALL correct answers from typically five or six options.

```
+-----------------------------------------------------------------+
|  PHENOMENON / STIMULUS:                                          |
|  [Description, data, or diagram]                                 |
|                                                                  |
|  Select the TWO [observations / claims / explanations] that...  |
|                                                                  |
|  [ ]  A. [Option]                                                |
|  [ ]  B. [Option — CORRECT]                                      |
|  [ ]  C. [Option]                                                |
|  [ ]  D. [Option — CORRECT]                                      |
|  [ ]  E. [Option]                                                |
|  [ ]  F. [Option]                                                |
+-----------------------------------------------------------------+
Points: 1 (all correct selected, none incorrect) / 0 (any other)
```

**Construction Rules:**
- Specify number of correct answers in stem when count is fixed
- Typically 2–3 correct from 5–6 options
- Each option should represent a distinct scientific claim or observation
- Distractors should reflect common misconceptions

---

### CR — Constructed Response (0–3 points)

Student writes a multi-sentence explanation, argument, or model description.

```
+-----------------------------------------------------------------+
|  PHENOMENON / STIMULUS:                                          |
|  [Extended description — may include data table, graph,          |
|   diagram, experimental results, or scenario]                    |
|                                                                  |
|  PROMPT:                                                         |
|  [Directive requiring construction of explanation, model         |
|   development, argument from evidence, or solution design]       |
|                                                                  |
|  Be sure to:                                                     |
|    * [Specific guidance bullet 1]                                |
|    * [Specific guidance bullet 2]                                |
|    * [Specific guidance bullet 3]                                |
|                                                                  |
|  +-----------------------------------------------------+        |
|  |  [Student response area — text input]                 |        |
|  +-----------------------------------------------------+        |
+-----------------------------------------------------------------+
Points: 0–3 (see rubric, Section 8)
```

**Construction Rules:**
- Must integrate all three NGSS dimensions (DCI + SEP + CCC)
- Prompt must reference a specific phenomenon, not generic definitions
- Include "Be sure to" guidance bullets (2–3)
- Use Delaware contexts from Section 10 when possible
- Response expectations: Grade 5 (3–5 sentences); Grade 8 (5–8 sentences); Grade 11 (6–10 sentences)

## 6. DOK / Cognitive Complexity

### DOK Level Descriptions for Science

| DOK | Label | Description | Example Tasks |
|---|---|---|---|
| **1** | Recall & Reproduction | Recall a scientific fact; identify a structure; recognize a simple pattern | *identify, define, recall, recognize, label, list* |
| **2** | Skills & Concepts | Classify organisms; interpret a data table; explain cause-effect; apply a concept | *classify, interpret, explain, compare, organize, infer, predict* |
| **3** | Strategic Thinking | Analyze data to draw conclusions; construct evidence-based explanations; evaluate competing claims; design investigations | *analyze, construct, evaluate, justify, design, formulate, synthesize* |
| **4** | Extended Thinking | Multi-step investigations; synthesize from multiple sources; build and revise models; evaluate complex scenarios | *synthesize, design [complex], evaluate [complex], connect, create* |

> DOK 4 appears primarily in CR items with extended phenomena, not in individual SR or MS items.

### DOK Distribution Targets for Item Generation

| Item Type | Target DOK | Rationale |
|---|---|---|
| SR — identify / recall | 1 | Simple recall of terms, structures |
| SR — apply concept to phenomenon | 2 | Connecting concept to observable data |
| MS — evaluate multiple claims | 2–3 | Evaluating each option against evidence |
| CR — construct explanation | 3 | Integration of DCI, SEP, and CCC |
| CR — extended modeling | 3–4 | Multi-step reasoning and model construction |

## 7. Three-Dimensional Item Design

### Integrating the Three Dimensions

Every NGSS-aligned item must assess a student's ability to use a SEP to demonstrate understanding of a DCI, viewed through a CCC lens.

| Item Focus | SEP | CCC | DCI Example |
|---|---|---|---|
| Explain horseshoe crab-shorebird food web | SEP 6 — Constructing Explanations | CCC 5 — Energy and Matter | LS2.B — Cycling of Matter and Energy |
| Analyze coastal erosion data | SEP 4 — Analyzing Data | CCC 7 — Stability and Change | ESS2.A — Earth Materials and Systems |
| Evaluate wetland restoration designs | SEP 7 — Argument from Evidence | CCC 4 — Systems and System Models | ESS3.C — Human Impacts on Earth Systems |
| Model sea level rise effects | SEP 2 — Developing Models | CCC 3 — Scale, Proportion, Quantity | ESS2.D — Weather and Climate |
| Investigate salt marsh plant adaptation | SEP 3 — Planning Investigations | CCC 6 — Structure and Function | LS4.C — Adaptation |

### Phenomenon-Based Design Principles

| Principle | Guidance |
|---|---|
| **Anchoring phenomenon** | Every task set begins with an observable, engaging phenomenon students must explain |
| **Student sense-making** | Items require figuring out the phenomenon, not recalling facts |
| **Multiple dimensions** | The phenomenon naturally lends itself to at least one SEP and one CCC beyond the target DCI |
| **Delaware relevance** | Use Delaware-specific phenomena from Section 10 to increase engagement |
| **Accessibility** | Phenomena must be described clearly enough for students without prior exposure |

### Model Types for Assessment

| Model Type | Description | Grade Band |
|---|---|---|
| **Diagrammatic** | Labeled diagrams showing relationships, flows, or structures | All grades |
| **Mathematical** | Equations, proportional relationships, quantitative predictions | Gr 8, 11 |
| **Conceptual** | Verbal or visual representations of cause-effect chains | All grades |
| **Computational** | Data-driven models; trend analysis; simulation interpretation | Gr 8, 11 |

## 8. Scoring Rubrics

### CR — Constructed Response (0–3 Points)

| Score | Descriptor |
|---|---|
| **3** | Thorough three-dimensional understanding. Accurately applies DCI to explain phenomenon, effectively uses targeted SEP, explicitly connects reasoning to relevant CCC. Scientific vocabulary is precise. Evidence from stimulus is cited accurately and integrated. |
| **2** | Adequate three-dimensional understanding. Applies DCI with minor inaccuracies, uses targeted SEP with some effectiveness, partially connects to CCC. Explanation mostly complete with minor gaps. |
| **1** | Partial understanding. Some DCI knowledge but may have significant misconceptions. SEP used minimally. CCC connection absent or incorrect. Explanation substantially incomplete. |
| **0** | Off topic, demonstrates no understanding, restates prompt without analysis, too brief to evaluate, or left blank. |

**CR Scoring Notes:**
- Score based on scientific accuracy and quality of reasoning, not writing mechanics
- Students must reference the specific phenomenon or data; generic answers should not receive full credit

|---|---|
| **SR** | 1 point for correct answer; 0 for incorrect |
| **MS** | 1 point for all correct selections with no incorrect; 0 for any other combination |

## 10. Contextualization

### Delaware-Specific Science Topic Bank

Item writers should anchor phenomena and scenarios in authentic Delaware contexts when possible. This increases ecological validity and engagement for Delaware students while providing rich, three-dimensional assessment opportunities.

#### Delaware Bay Horseshoe Crab Ecology

| Topic | Scientific Applications |
|---|---|
| **Horseshoe crab spawning** | Life cycles; reproductive behavior; seasonal patterns driven by lunar tides and temperature; population monitoring data from Delaware Bay beaches; cause and effect of environmental factors on spawning timing |
| **Horseshoe crab–red knot interdependence** | Ecological relationships; energy transfer through food webs; population dynamics; the red knot's 9,000-mile migration from Tierra del Fuego to the Arctic depends on horseshoe crab eggs; data on declining populations and conservation |
| **Horseshoe crab blood and biomedical science** | Structure and function; Limulus Amebocyte Lysate (LAL) used to test medical equipment for bacterial contamination; engineering applications of biological systems; trade-offs in harvesting for medicine vs. conservation |
| **Horseshoe crab population management** | Ecosystem stability; human impact; data analysis of harvest limits and population recovery; evaluating conservation strategies; modeling population trends |

#### Delaware Coastal Geology

| Topic | Scientific Applications |
|---|---|
| **Delaware beach formation** | Sediment transport; longshore drift; wave energy and coastal geomorphology; analyzing historical shoreline maps; cause and effect of storm events on beach shape |
| **Barrier island dynamics** | Earth surface processes; Fenwick Island and coastal development; sediment budgets; stability and change in coastal systems; engineering solutions for erosion control |
| **Delaware Bay tidal patterns** | Gravitational forces; lunar cycles; tidal range data (average ~5 feet at the bay mouth); cause and effect of tidal forces; graphing tidal heights; predicting high and low tides |
| **Coastal plain geology** | Sedimentary layers; fossil record in Delaware's Cretaceous and Tertiary deposits; geological time; evidence of ancient marine environments in inland Delaware |

#### Bombay Hook National Wildlife Refuge

| Topic | Scientific Applications |
|---|---|
| **Bombay Hook wetlands ecology** | Tidal salt marsh ecosystems; freshwater impoundments; food webs including migratory waterfowl, muskrats, and fish; energy flow and matter cycling; biodiversity surveys |
| **Migratory bird populations** | Seasonal patterns; animal behavior; population counting methods; data analysis of bird census data over decades; cause and effect of habitat quality on migratory success |
| **Wetland plant communities** | Plant adaptations to saltwater and tidal flooding; Spartina grass zonation; structure and function in plants; comparing freshwater and saltwater marsh species |
| **Wetland ecosystem services** | Water filtration; flood control; carbon sequestration; quantifying ecosystem services; engineering approaches to wetland restoration; cost-benefit analysis |

#### Delaware Wetlands

| Topic | Scientific Applications |
|---|---|
| **Great Cypress Swamp** | Freshwater wetland ecology; bald cypress adaptations; biodiversity in Delaware's largest forested wetland; energy flow through swamp ecosystems; succession and disturbance |
| **Tidal wetland restoration** | Engineering design process; restoring tidal flow to degraded marshes; evaluating restoration success criteria; before-and-after ecological data; trade-offs in restoration methods |
| **Wetland soil chemistry** | Anaerobic decomposition; nutrient cycling (nitrogen and phosphorus); water quality impacts; data analysis of soil composition; matter cycling in wetland systems |
| **Delaware wetland loss** | Historical data on wetland acreage decline; cause and effect of development and drainage; modeling future wetland loss; evaluating conservation policies |

#### Sea Level Rise

| Topic | Scientific Applications |
|---|---|
| **Sea level rise projections for Delaware** | Climate change evidence; data modeling and prediction; interpreting graphs of sea level data from Delaware tidal gauges; Delaware is among the most vulnerable states due to low elevation (highest point ~450 feet, much of the state below 60 feet) |
| **Impact on Delaware coastal communities** | Systems thinking; modeling flood zones; analyzing population and infrastructure data; cause and effect of rising seas on freshwater aquifers (saltwater intrusion) |
| **Adaptation engineering** | Engineering design for sea walls, living shorelines, managed retreat; evaluating trade-offs; cost-benefit analysis; Delaware's Coastal Zone Act and its scientific basis |
| **Thermal expansion and ice melt** | Physical science connections; thermal expansion of water; ice sheet dynamics; energy and matter in climate systems; quantitative analysis of contributing factors |
| **Salt marsh response to sea level rise** | Ecosystem stability and change; marsh migration; accretion rates vs. sea level rise rates; data analysis comparing Delaware marsh elevation data to tide gauge data |

### English Learner (EL) Considerations

| Consideration | Guidance |
|---|---|
| **Scientific vocabulary** | Pre-teach or define Tier 3 science vocabulary in sidebars; avoid conflating everyday and scientific meanings |
| **Sentence structure** | Use clear, direct sentences in stimuli and stems; avoid unnecessarily complex syntax |
| **Visual supports** | Include diagrams, data tables, and labeled figures to reduce linguistic load; all visuals must include alt text |
| **Bilingual glossaries** | Designated support; science terms in Spanish, Haitian Creole, and other home languages |
| **Cultural familiarity** | Include phenomena connecting to students' lived experiences; avoid assuming prior outdoor or coastal recreation experience |

## 11. Quality Checklist

Use this checklist before finalizing any generated item or item set.

### Three-Dimensional Alignment

- [ ] Item is tagged to one primary performance expectation (e.g., MS-LS2-1)
- [ ] Item integrates at least one SEP beyond simple recall
- [ ] Item connects to at least one CCC
- [ ] The DCI matches the target grade band
- [ ] The three dimensions work coherently; none feels forced

### Phenomenon / Stimulus

- [ ] Item is anchored to an observable phenomenon or data set
- [ ] Phenomenon is engaging, age-appropriate, and culturally inclusive
- [ ] Data in tables or graphs is realistic and internally consistent
- [ ] Diagrams are clearly labeled, drawn to reasonable scale, and described in alt text
- [ ] Delaware context is used when appropriate (Section 10)

### Item Quality (All Types)

- [ ] Stem requires application of a science practice, not just recall
- [ ] All options (SR/MS) are plausible and reflect documented misconceptions
- [ ] Correct answer is unambiguously supported by three-dimensional reasoning
- [ ] No "All of the above" / "None of the above"
- [ ] DOK level matches the cognitive demand
- [ ] Item can be answered from the provided stimulus

### CR-Specific Checks

- [ ] Prompt requires three-dimensional reasoning (DCI + SEP + CCC)
- [ ] "Be sure to" bullets provide scaffolding without giving away the answer
- [ ] Scoring rubric is included
- [ ] Rubric distinguishes between levels of three-dimensional understanding
- [ ] Response length expectations are grade-appropriate

### EL and Accessibility

- [ ] Scientific vocabulary is grade-appropriate; specialized terms are defined
- [ ] Visual supports accompany text-heavy stimuli
- [ ] Item does not require cultural knowledge that disadvantages EL students
- [ ] Text-to-speech compatible

## 12. Prompt Patterns

The following patterns map common user requests to generation strategies for the AI.

---

### Pattern 1: "Generate a science item for Grade [X]"

**Interpretation:** Default to an SR item (1 point) at DOK 2, anchored to a phenomenon. Use a Delaware context from Section 10.

**Generation Recipe:**
1. Select a grade-appropriate performance expectation
2. Choose a Delaware phenomenon from Section 10
3. Identify the target SEP and CCC
4. Generate SR using Template 1
5. Ensure all four options reflect distinct scientific reasoning paths
6. Tag: state=DE, subject=SCI, grade=[X], pe=[PE], sep=[SEP], ccc=[CCC], dok=2

---

### Pattern 2: "Generate a constructed response science item for Grade [X]"

**Interpretation:** Generate a CR item (0–3 points) at DOK 3. Use Template 3.

**Generation Recipe:**
1. Select a grade-appropriate performance expectation
2. Choose an engaging phenomenon (Delaware context preferred)
3. Write extended stimulus (4–8 sentences with data or diagram description)
4. Write prompt with 2–3 "Be sure to" scaffolding bullets
5. Include 0–3 scoring rubric
6. Tag: state=DE, subject=SCI, grade=[X], pe=[PE], sep=[SEP], ccc=[CCC], dok=3

---

### Pattern 3: "Generate an engineering design item"

**Interpretation:** Generate a CR item targeting ETS performance expectations. Use Template 4.

**Generation Recipe:**
1. Select a grade-appropriate ETS performance expectation
2. Define a design problem with criteria and constraints (Delaware context preferred)
3. Write stimulus describing problem and relevant data
4. Write prompt requiring solution design, evaluation, or optimization
5. Include 0–3 scoring rubric
6. Tag: state=DE, subject=SCI, grade=[X], pe=[ETS PE], sep=6 or 7, ccc=[CCC], dok=3-4

---

### Pattern 4: "Generate a complete science task set for Grade [X]"

**Interpretation:** Generate a phenomenon-based task set with 3–5 items (mix of SR, MS, CR) anchored to a single phenomenon.

**Generation Recipe:**
1. Select a rich, multi-faceted phenomenon (Delaware context strongly preferred)
2. Identify 2–3 performance expectations connected to the phenomenon
3. Generate items in this sequence:
   - 1–2 SR items (DOK 1–2) — entry-level reasoning
   - 1 MS item (DOK 2–3) — evaluate claims or data patterns
   - 1 CR item (DOK 3) — construct explanation or argue from evidence
4. Ensure the task set integrates multiple SEPs and CCCs
5. Tag each item with PE, SEP, CCC, DOK
6. Include scoring rubric for CR item

---

### Pattern 5: "Generate a data analysis science item"

**Interpretation:** Generate an MS or SR item targeting SEP 4 at DOK 2–3. Include data in the stimulus.

**Generation Recipe:**
1. Select a DCI with quantitative data opportunities
2. Create a realistic data set using Delaware data when possible
3. Use Template 2 for MS or Template 1 for SR
4. Ensure stem requires interpretation beyond simple data reading
5. Tag: state=DE, subject=SCI, grade=[X], pe=[PE], sep=4, ccc=[CCC], dok=2-3
