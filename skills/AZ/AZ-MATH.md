|---|---|

## 2. Standards Framework

> AzM2 Mathematics is aligned to the **Arizona Academic Standards for Mathematics**, organized around mathematical domains that progress in complexity across grade bands.

### Arizona Mathematics Standards — Key Domains by Grade

| Domain | Description | Grade Band |
|---|---|---|
| **Operations & Algebraic Thinking** | Represent and solve problems; understand properties of operations | 3–5 |
| **Number & Operations — Base Ten** | Place value understanding; multi-digit arithmetic | 3–5 |
| **Number & Operations — Fractions** | Fraction concepts; fraction arithmetic | 3–5 |
| **Ratios & Proportional Relationships** | Understand ratios; use proportional reasoning | 6–7 |
| **The Number System** | Rational numbers; integer operations | 6–8 |
| **Expressions & Equations** | Algebraic expressions; linear equations and inequalities | 6–8 |
| **Geometry** | Shape properties; area; volume; coordinate geometry; transformations | 3–8, 10 |
| **Statistics & Probability** | Data analysis; probability; statistical inference | 6–8, 10 |
| **Functions** | Define, evaluate, and compare functions; model relationships | 8, 10 |
| **Number & Quantity** | Extend properties of exponents; complex numbers; quantities | 10 |

## 5. Item Types & Formats

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                                |
|                                                           |
|  4 options (A, B, C, D)                                   |
|  May include real-world context or stimulus               |
|  Machine scored                                           |
|  DOK 1–3                                                  |
+----------------------------------------------------------+
```

**MC Example (Grade 6, DOK 2, AZ.Math.6.RP.3):**

A hiker at the Grand Canyon drinks 3 bottles of water every 2 hours. At this rate, how many bottles of water will the hiker drink during a 10-hour hike?

A. 12
B. 13
C. 15
D. 30

*Correct Answer: C*
*Alignment: AZ.Math.6.RP.3 | DOK 2*

---

**MC Example (Grade 10, DOK 2, AZ.Math.10.S-ID.6):**

The table shows the average monthly temperature (in degrees Fahrenheit) and the number of visitors (in thousands) to a Phoenix park over six months. Which type of function BEST models the relationship between temperature and visitors?

A. Linear with positive slope
B. Linear with negative slope
C. Quadratic with a maximum
D. Exponential growth

*Correct Answer: C*
*Alignment: AZ.Math.10.S-ID.6 | DOK 2*

---

### Multi-Select (MS)

```
+----------------------------------------------------------+
|  MULTI-SELECT — 1 point                                   |
|                                                           |
|  5–7 options; select all correct answers                  |
|  Machine scored                                           |
|  DOK 2–3                                                  |
+----------------------------------------------------------+
```

**MS Example (Grade 7, DOK 2, AZ.Math.7.EE.4):**

Select ALL equations that could represent the following situation: A store in Sedona sells handmade pottery. Each piece costs $12, and there is a flat shipping fee of $8. The total cost is $56.

A. 12x + 8 = 56
B. 12(56) + 8 = x
C. 8x + 12 = 56
D. 56 = 12x + 8
E. 12 + 8x = 56

*Correct Answers: A, D*
*Alignment: AZ.Math.7.EE.4 | DOK 2*

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE — 0–2 points                        |
|                                                           |
|  Show work and/or explain reasoning                       |
|  Multi-step problem or justification                      |
|  Human scored using CR rubric                             |
|  DOK 3                                                    |
+----------------------------------------------------------+
```

**CR Example (Grade 10, DOK 3, AZ.Math.10.S-ID.6):**

The table below shows Phoenix's population (in millions) for selected years from 1970 to 2020. Create a scatter plot and draw a line of best fit. Using your line, predict the population in 2030. Explain how you determined your prediction and whether a linear or exponential model is more appropriate.

## 6. Depth of Knowledge (DOK)

| DOK | Label | Mathematics Application Examples |
|---|---|---|
| 1 | Recall | Perform a basic computation; identify a geometric shape; convert a unit of measurement |
| 2 | Skills & Concepts | Solve a two-step word problem; interpret data in a table or graph; apply a formula in a straightforward context |
| 3 | Strategic Thinking | Solve a non-routine, multi-step problem; model a real-world scenario with an equation; justify a mathematical reasoning process; analyze a pattern and make predictions |
| 4 | Extended Thinking | (Primarily assessed through extended CR tasks requiring modeling, explanation, and multi-step problem solving with justification) |

| Feature | Requirement |

| **Graphs** | Labeled axes with appropriate scales; title included; grid lines when applicable |
| **Diagrams** | Accurate geometric figures with necessary labels; "not drawn to scale" noted when applicable |

| **Calculator designation** | Items must clearly indicate whether a calculator is permitted |

## 8. Scoring Rubrics

### Constructed Response (CR) Rubric — 0–2 Points

| Score | Criteria |
|---|---|
| 2 | Work clearly shows a correct mathematical process. Answer is correct. Explanation (if required) demonstrates understanding of the mathematical concept and uses appropriate mathematical vocabulary. |
| 1 | Work shows understanding of the mathematical concept but contains a minor computational error. OR Correct answer is given without a clear explanation of the process. |
| 0 | Work shows no understanding of the mathematical concept, or response is blank. |

## 10. Contextualization — Arizona Mathematics

When generating items and contexts, prioritize authentic Arizona settings:

### Arizona Context Guide

| Context | Mathematical Application | Grade Band |
|---|---|---|
| Grand Canyon dimensions (depth: 6,093 ft; width: 10 mi; length: 277 mi; trail lengths) | Measurement, ratios, unit conversion, proportional reasoning | 4–10 |
| Phoenix population growth (1950: 107K to 2020: 1.6M metro area) | Percent change, exponential growth, statistics, scatter plots | 6–10 |
| Sonoran Desert temperature ranges (summer highs 110+ F, winter lows near 40 F) | Data analysis, mean/median, graphing, linear models | 3–8 |
| Colorado River flow rates (annual volume, allocation among 7 states) | Fractions, ratios, proportional reasoning, percent, unit rates | 5–10 |
| Arizona copper mining production (state produces 68% of U.S. copper) | Multi-digit multiplication, ratios, unit rates, percent | 4–8 |
| Navajo/Hopi geometric art and weaving patterns | Geometry, symmetry, area, transformations | 3–8 |
| Sedona hiking trail distances and elevation changes | Measurement, rates, slope, functions | 5–10 |
| Arizona agricultural production (cotton, citrus, cattle) | Multiplication, data analysis, ratios | 3–7 |
| Arizona solar energy production | Linear and exponential models, statistics | 8–10 |
| Saguaro cactus growth rates (1 inch per year; 40 ft at 200 years) | Ratios, proportional reasoning, linear functions | 4–8 |

### Suggested Problem Contexts by Grade

**Grades 3–4:**
- Counting saguaro cacti in a desert preserve; grouping and multiplication
- Measuring distances along a nature trail at the Petrified Forest

**Grades 5–6:**
- Calculating water usage per capita in Phoenix vs. Tucson
- Fraction and ratio problems using Arizona crop production data

**Grades 7–8:**
- Proportional reasoning with Grand Canyon trail distances and elevation
- Analyzing temperature data trends across Arizona cities

**Grade 10:**
- Modeling Phoenix population growth with exponential functions
- Statistical analysis of Colorado River flow rate data across decades

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] Arizona Academic Standard code verified as correct for the targeted grade and domain
- [ ] Real-world context is mathematically accurate and grade-appropriate
- [ ] Computation is error-free; answer key verified
- [ ] Distractors reflect authentic student misconceptions or common computational errors
- [ ] MS items have exactly the specified number of correct answers
- [ ] TEI response format is clearly specified (numeric entry, equation, coordinate pair)
- [ ] CR prompt requires multi-step reasoning and/or explanation
- [ ] Calculator policy is correctly applied per grade level
- [ ] Arizona context incorporated where appropriate
- [ ] DOK level matches the cognitive demand of the item

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Context-free computation | AzM2 emphasizes application and modeling | Embed problems in real-world Arizona contexts |
| CR that only requires computation | CR should require explanation or justification at DOK 3 | Include "show your work and explain" in CR prompts |
| Unrealistic numerical values | Context must be mathematically plausible | Verify that numbers make sense in the given scenario |
| Calculator-required item in non-calculator section | Calculator policy varies by grade and section | Clearly designate calculator availability per item |
| MS items with only one correct answer | MS items must have 2+ correct answers | Ensure multiple valid responses exist |
| Using CCSS codes instead of Arizona codes | AzM2 uses Arizona Academic Standards | Reference AZ.Math codes exclusively |

## 12. Prompt Patterns

### Pattern 1: Real-World Computation (MC, DOK 2)
> "[Arizona context with quantities]. [Question requiring computation]. What is the [result / total / difference]?"

### Pattern 2: Multiple Representations (MC or TEI, DOK 2)
> "A [table / graph / equation] shows [relationship]. Which [other representation / statement] represents the SAME relationship?"

### Pattern 3: Justify and Explain (CR, DOK 3)
> "[Multi-step Arizona context problem]. Show your work and explain how you found your answer."

### Pattern 4: Equivalent Expressions / Select All (MS, DOK 2)
> "Select ALL [expressions / equations / values] that are equivalent to [given expression or scenario]."

### Pattern 5: Data Interpretation (MC or CR, DOK 2–3)
> "The [table / graph / chart] shows [Arizona data context]. Based on the data, [what is the rate of change / which conclusion / what prediction] is BEST supported?"

### Pattern 6: Geometric Reasoning (MC or TEI, DOK 2–3)
> "[Arizona context involving measurement or shape]. What is the [area / volume / perimeter / angle measure]? [Show your work / explain your reasoning]."
