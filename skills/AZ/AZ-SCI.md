## 1. Overview

| Field | Detail |
|---|---|
| **Assessment Name** | AzSCI — Arizona Science Assessment |
| **Administering Agency** | Arizona Department of Education (AZ DOE) |
| **Vendor** | Arizona Department of Education |
| **Grades Tested** | **Grade 5**, **Grade 8**, **Grade 10** |
| **Testing Window** | Spring (March–April) |
| **Delivery** | Computer-based (online); paper accommodations available |
| **Standards** | Arizona Science Standards (2018, adopted 2019) |
| **Score Scale** | Scale score with 4 performance levels |
| **Reporting** | Individual Student Report; School, District, State aggregates |

> **CRITICAL NOTE:** AzSCI is administered **only at Grades 5, 8, and 10**. It is **NOT** given at Grades 3, 4, 6, or 7 for state accountability. Do not generate AzSCI-aligned items for non-tested grades.

### Performance Levels

| Level | Label | Description |
|---|---|---|
| 4 | **Highly Proficient** | Thorough understanding of science concepts; applies knowledge in novel and complex situations |
| 3 | **Proficient** | Adequate understanding of grade-level science standards; applies concepts appropriately |
| 2 | **Partially Proficient** | Partial understanding; inconsistent application of science concepts |
| 1 | **Minimally Proficient** | Minimal understanding; significant gaps in science knowledge and practices |

## 2. Standards Framework

> AzSCI is aligned to the **Arizona Science Standards (2018)**, which integrate science and engineering practices, crosscutting concepts, and disciplinary core ideas — following a three-dimensional learning model.

### Science and Engineering Practices

| Practice | Description |
|---|---|
| Asking Questions / Defining Problems | Formulate testable questions and define engineering problems |
| Developing and Using Models | Create, use, and revise models to represent phenomena |
| Planning and Carrying Out Investigations | Design and conduct investigations to collect data |
| Analyzing and Interpreting Data | Use mathematical and computational thinking to analyze data |
| Using Mathematics and Computational Thinking | Apply mathematical tools to analyze and represent data |
| Constructing Explanations / Designing Solutions | Construct evidence-based explanations; design solutions |
| Engaging in Argument from Evidence | Support or refute claims using evidence and reasoning |
| Obtaining, Evaluating, and Communicating Information | Read, synthesize, and communicate scientific information |

### Crosscutting Concepts

| Concept | Description |
|---|---|
| Patterns | Observed patterns guide organization and classification |
| Cause and Effect | Events have causes; investigate and explain causal relationships |
| Scale, Proportion, and Quantity | Relative scales of time, size, and energy matter |
| Systems and System Models | Define system boundaries; model component interactions |
| Energy and Matter | Track flows of energy and cycles of matter |
| Structure and Function | Form and function are complementary |
| Stability and Change | Conditions of stability and change; feedback mechanisms |

## 3. Test Structure

AzSCI is administered in a single session. Items are organized around science phenomena or scenarios, with clusters of items tied to a shared stimulus.

```
+------------------------------------------------------------------+
|            AzSCI STRUCTURE (Grades 5, 8, 10)                      |
+------------------------------------------------------------------+
|  SINGLE SESSION — Approximately 2–3 hours (untimed)              |
|  Computer-Based                                                   |
|                                                                   |
|  STIMULUS-BASED CLUSTERS                                          |
|  +----------------------------------------+                      |
|  | Cluster 1: Science Phenomenon/Scenario |                       |
|  |   -> 3–5 MC + MS + TE items           |                       |
|  +----------------------------------------+                      |
|  | Cluster 2: Investigation/Data Scenario |                       |
|  |   -> 3–5 MC + MS + TE items           |                       |
|  +----------------------------------------+                      |
|  | Cluster 3: Phenomenon/Model Scenario   |                       |
|  |   -> 3–5 MC + MS + TE + CR items      |                       |
|  +----------------------------------------+                      |
|  | Cluster 4–6: Additional clusters       |                       |
|  |   (varies by grade)                    |                       |
|  +----------------------------------------+                      |
+------------------------------------------------------------------+
```

## 5. Item Types & Formats

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                                |
|                                                           |
|  4 options (A, B, C, D)                                   |
|  Always stimulus-dependent (data, scenario, model)        |
|  Machine scored                                           |
|  DOK 1–3                                                  |
+----------------------------------------------------------+
```

**MC Example (Grade 5, DOK 2, AZ.5.L4U3.9):**

*[Stimulus: Diagram showing a Sonoran Desert food web with saguaro cactus fruit, insects, Gila woodpeckers, coyotes, and hawks]*

If the population of insects in this food web suddenly decreased, which organism would MOST LIKELY be directly affected first?

A. Coyotes
B. Hawks
C. Gila woodpeckers
D. Saguaro cactus

*Correct Answer: C*
*Alignment: AZ.5.L4U3.9 | DOK 2*

---

**MC Example (Grade 10, DOK 2, AZ.HS.E1U1.4):**

*[Stimulus: Cross-section diagram of Grand Canyon rock layers with radiometric age data]*

A geologist examines the rock layers at the Grand Canyon. The Kaibab Limestone at the rim is approximately 270 million years old, while the Vishnu Schist at the inner gorge is approximately 1.7 billion years old. Which principle BEST explains why the Vishnu Schist is found below the Kaibab Limestone?

A. The law of superposition — older layers are deposited below younger layers
B. The principle of cross-cutting relationships — intrusions are younger than surrounding rock
C. The principle of uniformitarianism — past processes are the same as present ones
D. The law of conservation of mass — matter cannot be created or destroyed

*Correct Answer: A*
*Alignment: AZ.HS.E1U1.4 | DOK 2*

**MS Example (Grade 10, DOK 2, AZ.HS.E2U1.8):**

*[Stimulus: Data table showing changes in Colorado River water levels and Phoenix metro area population from 1950–2020]*

Select TWO conclusions that are supported by the data in the table.

A. The Colorado River water level has remained constant over time
B. As the Phoenix metro population has increased, the Colorado River water level has decreased
C. The rate of population growth in Phoenix has slowed since 2000
D. There is a correlation between increasing population and decreasing river water levels
E. The Colorado River will be completely dry by 2050

*Correct Answers: B, D*
*Alignment: AZ.HS.E2U1.8 | DOK 2*

## 7. Scientific Investigation Design

### Investigation Components Assessed

| Component | Description | Example |
|---|---|---|
| **Testable Question** | Identify or formulate a question that can be investigated | "How does the amount of water affect saguaro cactus growth?" |
| **Variables** | Identify independent, dependent, and controlled variables | IV: water amount; DV: growth rate; CV: sunlight, soil type |
| **Procedure** | Evaluate or design a step-by-step investigation plan | Multiple trials, single variable changed, appropriate tools |
| **Data Collection** | Select appropriate tools and methods for gathering data | Graduated cylinder for volume; ruler for length; repeated measurements |
| **Data Analysis** | Interpret tables, graphs, and charts to identify patterns | "The graph shows that as temperature increased, evaporation rate increased" |
| **Conclusions** | Draw evidence-based conclusions; identify limitations | "The data supports the hypothesis because..." |

### Stimulus Types

| Stimulus | Description | Use |
|---|---|---|
| **Data table** | Organized numerical data from an investigation | Data interpretation, pattern identification, prediction |
| **Graph** | Bar graph, line graph, scatter plot | Trend analysis, comparison, correlation |
| **Diagram** | System model, food web, anatomical structure, geological cross-section | Model interpretation, process identification |
| **Investigation scenario** | Description of a student conducting an experiment | Variable identification, procedure evaluation, conclusion drawing |
| **Phenomenon description** | Real-world Arizona phenomenon requiring scientific explanation | Explanation construction, evidence-based reasoning |

## 8. Scoring Rubrics

### Constructed Response (CR) Rubric — 0–2 Points

| Score | Criteria |
|---|---|
| 2 | Response accurately interprets or applies the science concept. References specific data, evidence, or values from the provided stimulus. Explanation is clear, logically connected, and demonstrates understanding of the underlying scientific principle. |
| 1 | Response shows partial understanding. Data referenced but not precisely used, OR explanation is accurate but lacks reference to stimulus data. |
| 0 | Response is incorrect, does not address the science concept, is insufficient in length, or is blank. |

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] Arizona Science Standard code verified as correct for the targeted grade (5, 8, or 10 only)
- [ ] Item is stimulus-dependent (tied to data, diagram, model, or investigation scenario)
- [ ] Three-dimensional: item integrates a practice, crosscutting concept, and core idea
- [ ] CR prompt requires evidence-based explanation referencing specific data or observations
- [ ] MC distractors reflect authentic science misconceptions
- [ ] MS items have exactly the specified number of correct answers
- [ ] TE items have clear interaction instructions and unambiguous correct responses
- [ ] Stimulus data is scientifically accurate and grade-appropriate
- [ ] Arizona context incorporated where appropriate (geology, ecology, climate)
- [ ] DOK level matches the cognitive demand of the item and standard

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Items at non-tested grades | AzSCI is only at Grades 5, 8, and 10 | Verify grade before generating items |
| Standalone recall items | AzSCI emphasizes three-dimensional assessment | Embed items in phenomenon-based or data-based stimuli |
| CR without data reference | CR should require specific evidence from stimulus | Include "use specific data/evidence" in every CR prompt |
| Scientifically inaccurate stimuli | Data and scenarios must be realistic | Verify all scientific claims and data values |
| Missing crosscutting concepts | Arizona standards require three-dimensional alignment | Identify the crosscutting concept addressed by each item |
| Using NGSS codes instead of Arizona codes | AzSCI uses Arizona Science Standards (2018) | Reference AZ science standard codes exclusively |

## 12. Prompt Patterns

### Pattern 1: Data Interpretation (MC, DOK 2)
> "Based on the data in the [table / graph], which [conclusion / pattern / trend] is BEST supported?"

### Pattern 2: Investigation Design (MC, DOK 2–3)
> "A student wants to investigate [Arizona-relevant question]. Which experimental setup would BEST allow the student to test this hypothesis?"

### Pattern 3: Cause and Effect (MC, DOK 2)
> "If [variable or condition changes] in this [ecosystem / system / investigation], what would MOST LIKELY happen to [outcome]?"

### Pattern 4: Food Web / Ecosystem Analysis (MC or CR, DOK 2–3)
> "[Sonoran Desert / Arizona ecosystem] diagram shows [food web / interactions]. If [organism / factor] were removed or changed, what would MOST LIKELY happen to [other organism / population]? Use evidence from the [diagram / data] to explain."

### Pattern 5: Model Interpretation (MC or TE, DOK 2)
> "The model shows [process / system / cycle]. Which [label / arrow / component] BEST represents [specific process or interaction]?"

### Pattern 6: Evidence-Based Explanation (CR, DOK 3)
> "Using the data in the [table / graph], explain [science pattern or relationship]. Use specific [values / evidence] from the [data / graph] in your explanation."
