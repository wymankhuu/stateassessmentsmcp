## 1. Overview

| Field | Detail |
|---|---|
| **Assessment Name** | AzM2 — English Language Arts |
| **Administering Agency** | Arizona Department of Education (AZ DOE) |
| **Vendor** | Arizona Department of Education |
| **Grades Tested** | 3, 4, 5, 6, 7, 8, 10 |
| **Testing Window** | Spring (March–April) |
| **Delivery** | Computer-based (online); paper accommodations available |
| **Standards** | Arizona Academic Standards — English Language Arts (2016, updated 2020) |
| **Score Scale** | Scale score with 4 performance levels |
| **Reporting** | Individual Student Report; School, District, State aggregates |

> **KEY NOTE:** AzM2 ELA assesses Arizona Academic Standards for English Language Arts across Grades 3–8 and Grade 10. The assessment includes both machine-scored and human-scored components, with a mix of selected-response and constructed-response items. Grade 10 serves as the high school accountability grade.

### Performance Levels

| Level | Label | Description |
|---|---|---|
| 4 | **Highly Proficient** | Demonstrates thorough understanding; applies grade-level ELA skills in complex situations |
| 3 | **Proficient** | Demonstrates adequate understanding of grade-level ELA standards |
| 2 | **Partially Proficient** | Demonstrates partial understanding; needs additional support to meet grade-level expectations |
| 1 | **Minimally Proficient** | Demonstrates minimal understanding; significant gaps in ELA knowledge and skills |

> **Item-writing target:** "Proficient" performance. Items should require genuine application of Arizona Academic Standards at the expected DOK level — not mere recall.

## 2. Standards Framework

> AzM2 ELA is aligned to the **Arizona Academic Standards for English Language Arts**, organized around key strands that emphasize reading comprehension, writing, language, and speaking/listening.

### Arizona ELA Standards Strands

| Strand | Focus | Grade Emphasis |
|---|---|---|
| **Reading — Literature** | Comprehension of literary texts; analysis of craft, structure, theme | All grades |
| **Reading — Informational Text** | Comprehension of informational texts; argument analysis; text structure | All grades |
| **Writing** | Narrative, informational, and argumentative writing; writing process | All grades; assessed via CR |
| **Language** | Grammar, conventions, vocabulary acquisition and use | All grades |

### Key Reading Standards by Grade Band

| Standard Code | Description | Grade Band | DOK |
|---|---|---|---|
| AZ.ELA.3-5.RL.1 | Ask and answer questions to demonstrate understanding; refer to the text for evidence | 3–5 | 2 |
| AZ.ELA.3-5.RL.3 | Describe characters, settings, events; explain how characters respond to challenges | 3–5 | 2–3 |
| AZ.ELA.6-8.RL.4 | Determine the meaning of words and phrases, including figurative and connotative meanings | 6–8 | 2–3 |
| AZ.ELA.6-8.RL.6 | Analyze how point of view or perspective is developed in a text | 6–8 | 3 |
| AZ.ELA.6-8.RI.5 | Analyze how structure of informational text contributes to development of ideas | 6–8 | 3 |
| AZ.ELA.6-8.RI.8 | Trace and evaluate an argument, distinguishing claims from evidence | 6–8 | 3 |
| AZ.ELA.10.RL.2 | Determine a theme or central idea and analyze its development over the course of a text | 10 | 3 |
| AZ.ELA.10.RI.6 | Determine author's point of view or purpose; analyze how rhetoric advances the purpose | 10 | 3 |

### Key Writing and Language Standards

| Standard Code | Description | DOK |
|---|---|---|

## 3. Test Structure

AzM2 ELA is administered in a single testing session with multiple sections. Items are passage-based, with students reading passages and then answering associated items.

```
+------------------------------------------------------------------+
|            AzM2 ELA STRUCTURE (Grades 3–8, 10)                    |
+------------------------------------------------------------------+
|  SINGLE SESSION — Approximately 3–4 hours (untimed)              |
|  Computer-Based                                                   |
|                                                                   |
|  SECTION 1: READING COMPREHENSION                                 |
|  +----------------------------------------+                      |
|  | Passage Set 1 (Literary) -> MC + MS + TEI items |              |
|  | Passage Set 2 (Informational) -> MC + MS + TEI  |              |
|  | Passage Set 3 (Literary or Paired) -> MC + MS + TEI |          |
|  | Passage Set 4 (Informational) -> MC + MS + TEI  |              |
|  +----------------------------------------+                      |
|                                                                   |
|  SECTION 2: WRITING / CONSTRUCTED RESPONSE                        |
|  +----------------------------------------+                      |
|  | CR items tied to passages              |                       |
|  | (Text-dependent analysis prompts)      |                       |
|  +----------------------------------------+                      |
+------------------------------------------------------------------+
```

## 5. Item Types & Formats

### Multiple Choice (MC)

```
+----------------------------------------------------------+
|  MULTIPLE CHOICE — 1 point                                |
|                                                           |
|  4 options (A, B, C, D)                                   |
|  Always passage-dependent                                 |
|  Machine scored                                           |
|  DOK 1–3                                                  |
+----------------------------------------------------------+
```

**MC Example (Grade 7 Literary, DOK 3, AZ.ELA.7.RL.4):**

*[After reading a short story set near the Grand Canyon]*

Read this sentence from paragraph 6: *"The canyon's silence was louder than any sound she had ever known, filling her ears with the weight of a thousand years."*

What effect does the author's use of figurative language create in this sentence?

A. It shows that the character is frightened by the canyon
B. It suggests the canyon is a dangerous place that few people visit
C. It emphasizes the overwhelming depth and ancient power of the canyon's stillness
D. It implies that the character has never been outdoors before

*Correct Answer: C*
*Alignment: AZ.ELA.7.RL.4 | DOK 3*

---

**MC Example (Grade 5 Informational, DOK 2, AZ.ELA.5.RI.2):**

*[After reading an article about the Sonoran Desert ecosystem]*

What is the central idea of this article?

A. The Sonoran Desert is the hottest desert in North America
B. Plants and animals in the Sonoran Desert have developed unique adaptations to survive extreme conditions
C. The saguaro cactus is the most important plant in Arizona
D. Desert animals are more dangerous than animals in other habitats

*Correct Answer: B*
*Alignment: AZ.ELA.5.RI.2 | DOK 2*

### Multi-Select (MS)

```
+----------------------------------------------------------+
|  MULTI-SELECT — 1 point                                   |
|                                                           |
|  5–7 options; select 2 or more correct answers            |
|  Passage-dependent                                        |
|  Machine scored                                           |
|  DOK 2–3                                                  |
+----------------------------------------------------------+
```

**MS Example (Grade 8 Informational, DOK 2, AZ.ELA.8.RI.1):**

*[After reading an article about the Colorado River water crisis]*

Select TWO details from the article that support the author's claim that the Colorado River faces serious challenges.

A. The river flows through seven U.S. states
B. Prolonged drought has reduced Lake Mead to historically low water levels
C. The river was first explored by Spanish explorers in the 1500s
D. Growing population centers like Phoenix place increasing demand on limited water supplies
E. The Hoover Dam was completed in 1936

*Correct Answers: B, D*
*Alignment: AZ.ELA.8.RI.1 | DOK 2*

### Constructed Response (CR)

```
+----------------------------------------------------------+
|  CONSTRUCTED RESPONSE — 0–2 points                        |
|                                                           |
|  Text-dependent analysis response                         |
|  2–5 sentence written response                            |
|  Must reference textual evidence                          |
|  Human scored using CR rubric                             |
|  DOK 3                                                    |
+----------------------------------------------------------+
```

**CR Example (Grade 10 Literary, DOK 3, AZ.ELA.10.RL.2):**

*[After reading a short story set in a Phoenix neighborhood during summer]*

Using evidence from the story, explain how the author develops the theme of resilience. Identify at least one specific literary device or narrative technique the author uses and explain how it contributes to the theme.

## 6. Depth of Knowledge (DOK)

| DOK | Label | ELA Application Examples |
|---|---|---|
| 1 | Recall | Identify explicit information stated in the text; define a vocabulary word using context clues; name the narrator's point of view |
| 2 | Skills & Concepts | Infer a character's motivation from textual evidence; identify the author's purpose; explain how a detail supports the main idea; determine word meaning using context |
| 3 | Strategic Thinking | Analyze how the author uses figurative language to develop tone or theme; evaluate the strength of an argument; compare perspectives across two texts; synthesize ideas from multiple sections |
| 4 | Extended Thinking | (Assessed primarily through extended CR tasks requiring multi-paragraph analysis with evidence integration) |

## 8. Scoring Rubrics

### Constructed Response (CR) Rubric — 0–2 Points

| Score | Criteria |
|---|---|
| 2 | Response provides an accurate, thorough analysis that addresses all parts of the question. Includes relevant, correctly-used textual evidence (quoted or paraphrased) that directly supports the analysis. Demonstrates clear understanding of the standard being assessed. |
| 1 | Response provides a partially accurate analysis. OR Response is accurate but lacks sufficient or directly relevant textual evidence. OR Response addresses only part of the question. |
| 0 | Response is inaccurate, irrelevant, too brief to evaluate, or blank. |

### Technology Enhanced Rubric — 1–2 Points

| Score | Criteria |
|---|---|
| 2 | All components are correct (e.g., all items correctly ordered, matched, or selected). |
| 1 | At least one component is correct, but the response contains one or more errors. |
| 0 | Response is entirely incorrect or blank. |

## 10. Contextualization — Arizona ELA

When generating passages and prompts, prioritize authentic Arizona settings, history, and culture:

### Arizona Context Guide

| Context | Passage Type | Grade Band |
|---|---|---|
| Grand Canyon geology, ecology, and history | Literary fiction or Informational | 3–10 |
| Sonoran Desert wildlife and plant adaptations (saguaro cactus, Gila monster, roadrunner) | Informational | 3–8 |
| Phoenix urban growth, sustainability, and cultural diversity | Informational | 6–10 |
| Arizona mining history (copper, silver, gold) and its impact on communities | Informational or Literary | 5–10 |
| Navajo and Hopi heritage, art, traditions, and language preservation | Literary or Informational | 4–10 |
| Colorado River management, water rights, and conservation | Informational | 6–10 |
| Arizona statehood and territorial history | Informational | 4–8 |
| Petrified Forest and Painted Desert landscapes | Literary or Informational | 3–6 |
| Arizona monsoon season and desert weather patterns | Informational or Literary | 3–8 |
| Saguaro cactus life cycle and ecological importance | Informational | 3–6 |

### Suggested Passage Anchors by Grade

**Grades 3–4 Literary:**
- Fiction set in the Sonoran Desert featuring desert animals or plants
- Stories about a student visiting the Grand Canyon for the first time

**Grades 5–6 Informational:**
- Article about the life cycle and ecological importance of the saguaro cactus
- Informational text about Arizona mining history and its impact on communities

**Grades 7–8 Literary and Informational:**
- Literary fiction set in a Phoenix neighborhood exploring themes of community and change
- Paired informational texts on Colorado River water rights and conservation

**Grade 10 Literary and Informational:**
- Literary nonfiction exploring Navajo or Hopi cultural traditions and identity
- Argumentative essay about sustainable growth in Arizona's rapidly expanding cities

## 11. Quality Checklist

### Pre-Generation Checklist

- [ ] Arizona Academic Standard code verified as correct for the targeted grade
- [ ] All items are passage-dependent (no standalone general knowledge questions)
- [ ] CR prompts require textual evidence (not just prior knowledge)
- [ ] MC distractors represent authentic misconceptions, not obviously wrong answers
- [ ] MS items have exactly the specified number of correct answers
- [ ] TEI items have clear, unambiguous correct configurations
- [ ] Lexile of passage matches the grade-level range
- [ ] Passage length appropriate (400–1,000 words for comprehension passages)
- [ ] Arizona context incorporated where appropriate (geography, history, culture)
- [ ] DOK level matches the cognitive demand specified in the standard

### Common Pitfalls

| Pitfall | Problem | Fix |
|---|---|---|
| Items not tied to a passage | AzM2 ELA items must be passage-dependent | Always tie MC, MS, TEI, and CR to a specific stimulus |
| CR prompt that only tests recall | CR should require DOK 3 analysis with evidence | Include "using evidence from the text" in every CR prompt |
| MS items with ambiguous correct answers | All correct and incorrect answers must be clearly defensible | Pre-validate each option against the passage |
| TEI items with unclear mechanics | Students must understand how to interact with the item | Provide clear instructions (drag, select, highlight) |
| Using non-Arizona standards codes | AzM2 uses Arizona Academic Standards | Reference AZ.ELA codes exclusively |
| Ignoring Grade 10 | Grade 10 is the high school accountability grade | Ensure Grade 10 items reflect appropriate complexity |

## 12. Prompt Patterns

### Pattern 1: Craft & Language Analysis (MC, DOK 3)
> "Read [line reference / paragraph reference]. What effect does the author's use of [figurative language / imagery / word choice / structure] create in this [sentence / paragraph / passage]?"

### Pattern 2: Central Idea and Evidence (MC or CR, DOK 2–3)
> "What is the [central idea / theme] of this [passage / article]? [How does the author develop this idea using specific details?]"

### Pattern 3: Author's Purpose / Argument (MC or CR, DOK 2–3)
> "What is the author's [main purpose / central argument] in this [article / essay]? How does the author [support / develop] this [purpose / argument]? Use evidence from the text."

### Pattern 4: Evidence Selection (MS, DOK 2)
> "Select [TWO / THREE] details from the [passage / article] that BEST support [claim / central idea / inference]."

### Pattern 5: Text Structure and Organization (MC or TEI, DOK 2)
> "How does the author organize the information in [this section / the passage]? What is the effect of this organizational structure?"

### Pattern 6: Vocabulary in Context (MC, DOK 2)
> "As used in paragraph [#], what does the word [WORD] most likely mean?"

### Pattern 7: Constructed Response — Text-Dependent Analysis (CR, DOK 3)
> "Using evidence from [PASSAGE_TITLE], explain how [the author develops / the character changes / the argument is supported]. Include specific details from the text in your response."
